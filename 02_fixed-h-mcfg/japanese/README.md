## 同期の方針

英語版を唯一の投稿用正本として、定理・補題・命題・系・定義・備考・例・未解決問題の**順序、種類、ラベル**をそろえています。仮定、量化、データ上界、有限群値の積の順序、証明の段階を日本語でも省略しません。訳語と文章の組み替えを除き、数学的主張は英語稿に従います。

### 2026年10月28日の同期内容

- **M1（型付き厚さ）**：旧 `lem:typed-thickness-baseline` を、`t_typ` と `theta_typ` の比較補題 `lem:typed-thickness-equivalence` および一般還元定理 `thm:data-from-typed-thickness` に置換。正語型精密化の指数例と、局所群に関する二分法を `t_typ` に拡張。空語を追加した標本の符号化長の +1 も明記。
- **M5（非可換群の動機）**：`prop:group-agreement` を生成文法・定数規則・非文脈自由性・型付き代入可能性・交換子による分離まで全文翻訳。特に `A=S_3` の固定typingの群成分は `S_3 × S_3` とし、可換群に対する不可能性は**対角一致言語**に関するものであって族全体に対する主張ではないことを維持。
- **局所群の強い境界例**：`prop:li-g-strict` の反例を二文字アルファベット `{a,b}` に更新。任意の群準同型に対する `b^K a^N b^K` と `b^{2K}` の比較を証明に反映。
- **適用範囲**：アリティ1とアリティ2の分離を区別し、型付けを変更した演算子の多項式上界を、元の固定typingでのデータ長の下界と混同しないよう統一。
- **M3（稀な型と下界）**：型の削除補題 `lem:type-deletion`、各実現型の最短語長を合算する下界 `prop:rare-type`、上下の挟み撃ち `cor:typed-sandwich` を日本語でも証明込みで同期。空語の強制は作用素の定義域・特徴標本の存在条件を明示。
- **fan-out 1の境界とfan-out 2への非移行**：擬多様体レベルのLG必要十分性をTCS公開arXiv v5のProposition 6.4へ正しく帰属。二穴の冪移行補題 `lem:power-transfer` と倍増族の移行不能定理 `thm:doubling-no-lift` を全文訳。旧来の二方向の未解決問題は保持し、rare-type最短語長の多項式性を追加の未解決問題として記載。
- 序論、要旨、厚さ比較表、local-groupの証明、結論まで英語版の主張と対応させています。
