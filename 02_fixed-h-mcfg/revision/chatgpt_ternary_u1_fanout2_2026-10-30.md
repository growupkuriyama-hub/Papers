\[
\mu_1(L)=\min\{|w|:w\in L_1\}
\]

\mathcal D_L^{(d)}(\vec x)=\mathcal D_L^{(d)}(\vec y)
\tag{1.1}

が必要である。$d=1$ において $E=\Box_1$ は許容文脈である点を繰り返し用いる。

## 2. 新しい排除原理 I：同型の因子関係は無限の型スライスを強制する

### 定理 2.1（同型因子の汲み上げ）

$L$ を $U_1$ 型付けについて $(1,s)$-代入可能な言語とする。$t\in\{1,\zeta\}$、$u,v\in L$、$s(u)=s(v)=t$ とする。もし

\[
v=p u q,\qquad p,q\in\Sigma^*,\quad |p|+|q|>0,
\tag{2.1}
\]

なら、すべての $k\ge0$ に対して

\[
p^k u q^k\in L_t.
\tag{2.2}
\]

従って $L_t$ は無限である。ここで $L_t=\{w\in L:s(w)=t\}$ である。

**証明。** $u,v\in L$ なので一穴文脈 $\Box_1$ は両方を受理する。型も等しいので、(1.1) の $d=1$ を適用して

\[
\mathcal D_L^{(1)}(u)=\mathcal D_L^{(1)}(v)
\tag{2.3}
\]

を得る。$k=0$ で (2.2) は $u\in L$ そのものである。$p^k u q^k\in L$ を仮定すると、文脈 $p^k\Box_1q^k$ が $u$ を受理する。(2.3) によりこの文脈は $v$ も受理し、

\[
p^k v q^k=p^{k+1}u q^{k+1}\in L
\]

となる。帰納法で全 $k$ が従う。

さらに $t=1$ のとき、$v$ が純なので (2.1) の $p,u,q$ も純であり、(2.2) は全て型 $1$ を持つ。$t=\zeta$ のとき、$u$ 自身が $c$ を含むため、(2.2) も全て型 $\zeta$ を持つ。最後に $|p^k u q^k|=|u|+k(|p|+|q|)$ は $k$ ごとに厳密に増えるので $L_t$ は無限集合となる。$\square$

**注意。** 汲み上げを示すために arity 2 も文法の存在も必要ない。一般の有限半群では (2.2) の受理自体は同様に示せるが、全 $k$ の**型が $t$ にとどまる**部分は $U_1$ の性質を使用している。

### 系 2.2（有限混合スライスにおける単独 $c$ の孤立）

$L\in\mathcal C^{\mathrm{mcf}}_{2,s}$ とする。$c\in L$ かつ $L_\zeta$ が有限なら

\[
L_\zeta=\{c\}.
\tag{2.4}
\]

**証明。** $w\in L_\zeta$ なら $w$ は $c$ を含むため $w=p c q$ と書ける。もし $w\ne c$ なら $|p|+|q|>0$ であり、$s(c)=s(w)=\zeta$ だから定理 2.1 により $L_\zeta$ が無限となる。仮定に反する。従って全 $w\in L_\zeta$ は $c$ である。逆に $c\in L_\zeta$ は仮定から従う。$\square$

特に有限言語で $c$ を単独の「短絡語」として許す場合、**他の全ての混合語が禁止される**。これは先行報告 §8.3 の特定の倍増文法の失敗よりも一般的な、言語だけから従う制約である。

## 3. 新しい排除原理 II：混合語と純文字のアルファベット支持の一致が必要

### 定理 3.1（純文字の支持分離による厚さ下界）

$L_1\ne\varnothing$ とする。ある $\alpha\in\{a,b\}$ について

\[
\alpha\text{ は }L_1\text{ の少なくとも一語に現れるが、}
\quad \alpha\text{ は }L_\zeta\text{ のどの語にも現れない}
\tag{3.1}
\]

と仮定する。$L$ が代入可能であるかどうかに**関係なく**、$L\cap\Sigma^+$ の任意の reduced good MCFG 表示 $G$ について

\[
\boxed{\mu_1(L)\le\bar\theta_G.}
\tag{3.2}
\]

**証明。** $L_1$ から $\alpha$ を含む語 $w$ を一つ取る。$w$ は $G$ の成功導出木 $T$ を持つ。端末 $\alpha$ の少なくとも一つの出現は、$T$ 中のある規則 $R$ のテンプレートで明示的に書かれている。理由は、終端語に現れる各端末は、定数規則または非定数規則のいずれかのテンプレート中に端末として起源を持つためである。

good 表示は線形・非削除であり、導出中に一度書かれた端末はその上位の規則で消去されない。従って $R$ を使う**任意の**成功導出の終端語には $\alpha$ が少なくとも一回残る。仮定 (3.1) により、そのような終端語は混合型 $\zeta$ になれない。よってそれは $L_1$ の元であり、長さは $\mu_1(L)$ 以上である。

$R$ を使う成功導出は少なくとも $T$ が存在するから、規則厚さの定義から

\[
\theta_G(R)=\min\{|z|:z\in L(G),\ R\text{ を使う成功導出が }z\text{ を生む}\}
\ge\mu_1(L).
\]

$\bar\theta_G=\max_{R'}\theta_G(R')\ge\theta_G(R)$ なので (3.2) が得られる。$\square$

### 系 3.2（有限 $c$-短絡候補の一括排除）

$L\in\mathcal C^{\mathrm{mcf}}_{2,s}$、$c\in L$、$L_\zeta$ 有限、$L_1\ne\varnothing$ とする。このとき任意の表示 $G$ について

\[
\boxed{\mu_1(L)\le\bar\theta_G.}
\tag{3.3}
\]

**証明。** 系 2.2 より $L_\zeta=\{c\}$。$L_1$ の任意の語には $a$ または $b$ が現れるが、$c$ には両者が現れない。従ってその出現する純文字を $\alpha$ と選ぶと定理 3.1 の (3.1) を満たす。(3.2) を適用する。$\square$

### 系 3.3（課題 B の必要条件）

$\mu_1(L_n)>\bar\theta_{G_n}$ を満たす候補族では、各 $n$ について

\[
\operatorname{alph}(L_{n,1})\subseteq
\operatorname{alph}(L_{n,\zeta})\cap\{a,b\}.
\tag{3.4}
\]

さらに $L_{n,\zeta}$ が有限なら $c\notin L_n$ でなければならない。

**証明。** (3.4) に反して純受理語に現れる $\alpha\in\{a,b\}$ が混合受理語に全く現れないとすると、定理 3.1 から $\mu_1(L_n)\le\bar\theta_{G_n}$ となり、仮定と矛盾する。また $c\in L_n$ かつ $L_{n,\zeta}$ 有限なら系 3.2 が同じ矛盾を与える。$\square$

これは $\lVert G_n\rVert$ が大きい場合にも、**すべての表示**に適用される。ただし (3.4) は必要条件であって十分条件ではない。また $\mu_1$ の下界に限定され、$\tau$ が大きいだけの候補を排除しない。

## 4. 新しい二穴強制原理：純語の内部位置における置換の一様性

### 定理 4.1（純なホスト中の等ラベル移送）

$L\in\mathcal C^{\mathrm{mcf}}_{2,s}$ とし、$P,w,Q\in\Sigma^*$、$w\in\{a,b\}^+$、$PwQ\in L$ とする。$w$ の内部位置 $i,j$（添字は $0$ から始まり、$1\le i,j\le|w|-2$）に同じ文字 $\alpha\in\{a,b\}$ が現れるとする。

\[
w=p_i\alpha q_i=p_j\alpha q_j
\]

と分解する。ここで $p_i,q_i,p_j,q_j\in\{a,b\}^+$ である。このとき

\[
\boxed{
\mathcal D_L^{(2)}\bigl((p_i,q_i)\bigr)
=\mathcal D_L^{(2)}\bigl((p_j,q_j)\bigr).}
\tag{4.1}
\]

特に任意の $U,V\in\Sigma^*$ と任意の $Z\in\Sigma^+$ について

\[
U p_i Z q_i V\in L
\quad\Longleftrightarrow\quad
U p_j Z q_j V\in L.
\tag{4.2}
\]

**証明。** $p_i,q_i,p_j,q_j$ はすべて純で非空なので、二組 $(p_i,q_i)$、$(p_j,q_j)$ はともに型 $(1,1)$ を持つ。一つの許容二穴文脈

\[
E=P\Box_1\alpha\Box_2Q
\]

を取る。その内側区切りは一文字 $\alpha$ であり**非空**である。二つの組を代入するといずれも $PwQ\in L$ を得る。従って二組は同型の受理文脈を共有している。(1.1) の $d=2$ を適用すれば (4.1) が従う。

次に $F=U\Box_1Z\Box_2V$ を取る。$Z$ は非空と仮定したから $F\in\mathcal E_2$ である。$F$ が左の組を受理することと右の組を受理することが同値であるという (4.1) の定義を展開すると、ちょうど (4.2) になる。$\square$

この移送は $p_i$ と $p_j$ の**長さが違っても**成り立つ。さらに $Z$ は純である必要がない。これは原稿 `lem:app-u1-transfer` の「一文字冪の二成分間で冪数を移す」特殊形とは異なり、**任意の非周期的な純なホストにも適用される**。ただしホスト中で移動させる中心文字 $\alpha$ は同じでなければならない。

### 系 4.2（単一 $c$ マーカーの位置増殖）

$w\in L_1$ を長さ $N\ge3$ の語とする。$w$ の内部のある $\alpha$ の出現を $c$ に置換した語が $L$ に属すると仮定する。このとき $w$ の**他の全ての内部 $\alpha$ 出現**を一個の $c$ に置換した語も $L$ に属する。

$N$ 文字長のちょうど一つの $c$ を含む受理語の数を

\[
M_N(L):=\bigl|\{z\in L:|z|=N,\ |z|_c=1\}\bigr|
\]

と定めれば

\[
M_N(L)\ge |w_2\cdots w_{N-1}|_\alpha.
\tag{4.3}
\]

**証明。** 定理 4.1 に $P=Q=U=V=\varepsilon$、$Z=c$ を代入する。すると一つの内部 $\alpha$ から $c$ への置換が受理されれば、別の内部 $\alpha$ からの置換も受理される。各置換後の語には $c$ が一箇所だけあり、元の語 $w$ は $c$ を含まない。異なる内部位置での置換後の語は、$c$ の位置が異なるので互いに相異なる。従ってその数は内部 $\alpha$ の出現数に等しく、(4.3) が成り立つ。$\square$

両文字 $a,b$ の各々について内部置換が少なくとも一つ受理されれば、内部位置がすべて被覆されるため $M_N(L)\ge N-2$ も従う。ただし**端の位置**は (4.1) の二成分の非空性により、この議論では扱えない。

### 系 4.3（純 singleton に対する混合スライスの個数下界）

$L_1=\{w\}$、$N=|w|\ge7$ とし、$w$ の**少なくとも一つの内部文字**を $c$ に置換した語が $L$ に属するとする。先行報告 Astra の「定理 7.2（長さ $\ge7$ の二文字 singleton の分類）」を前提にすると

\[
M_N(L)\ge\left\lfloor\frac{N-2}{2}\right\rfloor,
\qquad N\le 2M_N(L)+3.
\tag{4.4}
\]

**証明。** 先行報告の定理 7.2 により、$w$ は (i) 内部 $w_2\cdots w_{N-1}$ が一文字だけの反復、または (ii) 完全交互語のどちらかである。(i) なら任意の内部位置の文字は同じ $\alpha$ である。仮定と系 4.2 より $M_N(L)\ge N-2$。(ii) なら内部 $N-2$ 文字は交互であり、内部に現れるどちらの文字の出現数も $\lfloor(N-2)/2\rfloor$ 以上である。仮定で置換可能な内部文字を $\alpha$ として系 4.2 を適用すると同じ下界を得る。両場合で第1不等式が成り立つ。

$M_N(L)\ge\lfloor(N-2)/2\rfloor$ から $\lfloor(N-2)/2\rfloor\le M_N(L)$ なので $N-2<2(M_N(L)+1)$、整数性により $N\le 2M_N(L)+3$ が従う。$\square$

**依存関係の明示。** 系 4.3 の singleton 分類は**今回独立に再証明していない**。先行報告には $N=7$ の全118件の有限証明書と任意長への帰着があり、ここではその**既知の分類**を使って新しい個数下界を導いた。定理 4.1・系 4.2 は当該分類に依存しない。$(4.4)$ は $\mu_1$ と混合スライスの**語数**の関係であって、$\bar\theta_G$ の評価ではない。

## 5. 新しい部分上界：正則言語の NFA 規模から $\tau$ を直接抑える

### 定理 5.1（NFA 経路圧縮による最短同値代表）

$L\in\mathcal C^{\mathrm{mcf}}_{2,s}$、$G$ を任意の指定の表示とする。$L\cap\Sigma^+$ を $n\ge1$ 状態の NFA $\mathcal A$ が認識するなら

\[
\boxed{\tau(G,s)\le 2(4n-1)=8n-2.}
\tag{5.1}
\]

より一般に型付き非終端 $X$ の arity が $d\le2$ のとき $\tau_X\le d(4n-1)$ である。

**証明。** 実現している型付き非終端 $X=A_{\mathbf t}$ を一つ固定する。原稿 `lem:app-u1-fillers` と (1.2) により、$E_A[\vec x]\in L$、$s^{(d)}(\vec x)=\mathbf t$ となる非空成分の組 $\vec x=(x_1,\ldots,x_d)$ が存在し、同じ条件でより短い組を作れば $\tau_X$ の上界となる。

$E_A[\vec x]$ に対する $\mathcal A$ の受理走行を一つ固定する。$x_i$ を読む直前と直後の NFA 状態をそれぞれ $p_i,q_i$ と記す。$x_i$ はこの走行の区間に沿って $p_i$ から $q_i$ に到達している。

各 $i$ について、NFA の状態 $q\in Q$、$c$ を既に読んだかのビット $b\in\{0,1\}$、一文字以上読んだかのビット $e\in\{0,1\}$ の積状態

\[
(q,b,e)\in Q\times\{0,1\}\times\{0,1\}
\]

を考える。元の NFA に $q\xrightarrow{\sigma}q'$ があれば、積グラフに

\[
(q,b,e)\xrightarrow{\sigma}
\bigl(q',\ b\lor[\sigma=c],\ 1\bigr)
\]

を設ける。このグラフには $4n$ 個の頂点がある。$x_i$ が与える走行は $(p_i,0,0)$ から $(q_i,b_i,1)$ への道である。ここで $b_i=0$ は $s(x_i)=1$、$b_i=1$ は $s(x_i)=\zeta$ を意味する。

従って同じ二頂点を結ぶ**最短有向道**が存在する。最短道に同一頂点の重複があれば、その二出現の間の閉路を削除して、始点と終点が同じで短い道が得られる。よって最短道には頂点の重複がなく、その辺数は $4n-1$ 以下である。最短道のラベルを $x_i'$ とする。終点の第3成分が $1$ なので $x_i'\ne\varepsilon$。また終点の第2成分が $b_i$ なので $s(x_i')=s(x_i)$ であり、元の NFA の状態成分は $p_i$ から $q_i$ に到達する。

$E_A$ の固定部については元の受理走行をそのまま使い、各 $x_i$ の走行区間だけを $x_i'$ に対応する走行へ取り替える。各区間の両端の NFA 状態が元と一致するから、つなぎ合わせた走行は $E_A[\vec x']$ の受理走行である。従って $E_A[\vec x']\in L$ であり、各成分の型は $\mathbf t$ に保たれる。各成分長が $4n-1$ 以下なので $\|\vec x'\|_1\le d(4n-1)$。(1.2) より $\tau_X\le d(4n-1)$。これは全ての実現型付き $X$ に成り立つため、最大を取って (5.1) を得る。$\square$

この証明では**語の任意の文脈での同値性を NFA が保証する**とは言っていない。NFA は $E_A$ という一つの受理文脈に対して短い同型組を作る役割を果たし、そこから分布同値性へ進む部分は `lem:app-u1-fillers` の $(2,s)$-代入可能性を使っている。これが (5.1) を任意の表示に対して適用できる理由である。

### 系 5.2（NFA 規模に比例する特徴データ）

定理 5.1 の条件下で、$\mathcal B^{\le r}_{2,s}$ と $\mathcal B_{2,s}$ に共通な特徴標本 $K$ があり、

\[
\boxed{
\|K\|_+\le
3^{2r}g\bigl(1+2\theta+r(8n-2)\bigr)
+\mathbf1_{\{\varepsilon\in L\}}.}
\tag{5.2}
\]

**証明。** 原稿 `cor:distribution-representatives` の (1.3) に定理 5.1 の $\tau(G,s)\le8n-2$ を代入する。$N_{\rm typ}\le3^{2r}g$ を使うと (5.2) が得られる。$\square$

**「すべての表示」についての明確な部分クラス。** $g_{2,r}(L)$ を $L\cap\Sigma^+$ の reduced good fan-out $\le2$・rank $\le r$ 表示のサイズの最小値、$n_{\rm NFA}(L)$ を $L\cap\Sigma^+$ を認識する NFA の最小状態数とする。固定 $C\ge1,k\in\mathbb N$ に対し

\[
\mathfrak R_{C,k}:=
\bigl\{L\in\mathcal C^{\rm mcf}_{2,s}:L\cap\Sigma^+
\text{ は正則},\ n_{\rm NFA}(L)\le C(1+g_{2,r}(L))^k\bigr\}
\tag{5.3}
\]

と定義する。任意の $L\in\mathfrak R_{C,k}$ と**任意の**その表示 $G$ について $g_{2,r}(L)\le g$ であり、(5.2) は

\[
\|K\|_+\le 3^{2r}g\left(1+2\theta+8rC(1+g)^k\right)
+\mathbf1_{\{\varepsilon\in L\}}
\tag{5.4}
\]

を与える。従って (5.3) は要求された「$G$ の取り方に依存しない多項式」の成り立つ**明確に定義された部分クラス**である。この条件は NFA と MCFG の表示簡潔性の差が多項式であることを要求するため、**全ての正則な** $(2,s)$-代入可能言語にまで拡張したわけではない。特に $n_{\rm NFA}(L)$ が $g$ の指数になり得る領域は未処理である。

### 命題 5.3（$c$-run が無界でも安価な例）

\[
L_\star=(ab\mid c)^+
\tag{5.5}
\]

は $\mathcal C^{\rm mcf}_{2,s}$ に属する。任意の reduced good 表示 $G$ に対して

\[
\|K\|_+\le3^{2r}g(1+2\theta+24r)
\tag{5.6}
\]

を満たす特徴標本を持つ。一方、$L_\star$ は任意に長い純な両側因子で挟まれた $c$ を含み、また受理語中の $c$-run 数は無界であり、文字ごとの Parikh 飽和も成り立たない。

**証明。** 状態 $0,1$ と、$a:0\to1$、$b:1\to0$、$c:0\to0$ という、それぞれの文字が一つだけの辺を表す有向グラフを考える。始点・終点をともに $0$ とすると正長の受理経路ラベルは (5.5) である。同じ型の二組が許容文脈を共有した場合、各内側区切りが非空なので、その最初・最後の辺から各穴の両端状態が定まる。外側区切りが空の場合は始点・終点 $0$ が境界を定める。同じ文脈で受理される二組の各成分は同じ両端状態を結ぶ経路であり、別の許容文脈中でも一方が経路として接続できることと他方が接続できることは同値である。したがって全 arity、特に arity $1,2$ で分布が一致する。これは先行報告 Astra §5.1 の位相経路補題の重みなしの場合だが、ここでは直接論証した。言語は二状態の有限オートマトンで認識されるため正則、従って $2$-MCFL である。

$\varepsilon$ を除くため、NFA を3状態 $q_{\rm start},0,1$ とし、遷移を $q_{\rm start}\xrightarrow a1$、$q_{\rm start}\xrightarrow c0$、$0\xrightarrow a1$、$0\xrightarrow c0$、$1\xrightarrow b0$、受理状態を $0$ とする。この NFA はちょうど $L_\star$ を認識する。定理 5.1 と系 5.2 に $n=3$ を代入すると $\tau\le22$、$\|K\|_+\le3^{2r}g(1+2\theta+22r)$ を得る。これは表示したやや緩い (5.6) を含意する。

任意の $D\ge1$ に対して $(ab)^D c(ab)^D\in L_\star$ だから両側の純因子は長さ $2D$ まで大きくなる。$(cab)^m c$ は $m+1$ 個の $c$-run を持ち $L_\star$ に属するから $c$-run 数は無界である。また $ab c\in L_\star$ だが $acb\notin L_\star$ であり、二語の Parikh ベクトルは同じであるため Parikh 飽和でない。$\square$

この反例は**有界 $c$-run が十分条件でしかない**ことを厳密に示す。$L_\star$ 自体は簡単な正則言語なので、課題 A の一般解決を意味しない。

## 6. 有限の独立照合：同じ文字を $c$ に替える位相言語

### 命題 6.1（置換マーカー族）

$N\ge1$ とし、$w_N=(ab)^N$、

\[
Q_N=\{w_N\}\cup
\bigl\{(ab)^i cb(ab)^{N-i-1}:0\le i<N\bigr\}
\tag{6.1}
\]

と置く。$Q_N$ は全 arity で型付き組代入可能であり、有限言語として $2$-MCFL でもある。$Q_N$ における $w_N$ の内部 $a\to c$ 置換はちょうど $N-1$ 種類受理され、最初の $a$ の置換も受理される。任意の reduced 表示 $G$ で $\bar\theta_G=2N$ であり、課題 B の下界族にはならない。

**証明。** 状態 $0,1$ と $a:0\to1$、$c:0\to1$、$b:1\to0$ の三本の辺を持つグラフを考える。各文字は一つだけの辺をラベルとして持ち、始点・終点をともに $0$ とする。その経路言語は $((a\mid c)b)^*$ である。可換群 $H=\mathbb Z^3$ への Parikh 準同型 $\varphi(z)=(|z|_a,|z|_b,|z|_c)$ を使い、型 $1$ に対する値を $(N,N,0)$、型 $\zeta$ に対する値を $(N-1,N,1)$ に固定する。正長の経路語で対応する値を持つものはちょうど (6.1) である。

全 arity の代入可能性を確認する。同型の非空組 $\vec x,\vec y$ が一つの許容文脈 $E$ を共有するとする。各内側区切りは非空であるから、各穴を接続する状態がその区切りの最初・最後の文字の辺で一意に定まる。端の固定部分が空のときは指定始点・終点 $0$ が状態を定める。従って $x_i,y_i$ は各 $i$ で同じ両端状態間の経路である。さらに $s^{(d)}(\vec x)=s^{(d)}(\vec y)$ より $E[\vec x]$ と $E[\vec y]$ の全体型は等しい。両方とも (6.1) に属するので、対応する $H$ 値は型に指定された同じ値となる。準同型の可換性から $E$ の固定部分の値を左右から減じて

\[
\sum_{i=1}^d\varphi(x_i)=\sum_{i=1}^d\varphi(y_i)
\tag{6.2}
\]

を得る。任意の別の許容文脈 $F$ で、経路として受理できるかは前述の同じ両端状態性により一致する。全体型も等しく、(6.2) により Parikh 値も等しいので、所定の型別 $H$ 値を満たすかどうかも一致する。従って $F[\vec x]\in Q_N\iff F[\vec y]\in Q_N$ が成り立つ。

$Q_N$ は有限なので各語を定数規則で生成する $1$-MCFG が存在する。$w_N$ の $a$ は位置 $0,2,\ldots,2N-2$ の $N$ 箇所にあり、そのうち内部は $N-1$ 箇所である。(6.1) はこれらの各位置を $c$ に替えた相異なる語をすべて含み、$b$ を替えた語は含まない。最後に、$Q_N$ のすべての語の長さが $2N$ なので、reduced 表示の任意の規則は少なくとも一つの成功導出で使われ、その成功語は必ず長さ $2N$ である。従ってすべての規則で $\theta_G(R)=2N$、最大も $2N$ となる。$\square$

### 6.2 計算で照合したこと／照合していないこと

付録 A の**独立した Python プログラム全文**により、$N=2,3,4$ の $Q_N$ に対して、各受理語の非空一穴分解と、**非空内部区切りを持つ**全ての二穴分解を列挙した。各観測組について、実際に生じた許容文脈集合を完全に構成し、同型で一つの文脈を共有する組同士の分布が一致することを有限集合として照合した。結果は三例とも一致した。

この計算は有限の3例の完全検査であり、$N\ge5$ を決定したことも、任意長の言語に関する判定手続が存在することも意味しない。**全 $N$ の命題は命題 6.1 の上の証明にのみ依存する**。本報告の定理 2.1–5.3 は計算結果を仮定に使わない。

## 7. 課題 A・B に残る厳密な障害

### 7.1 課題 A

定理 5.1 は $L$ 全体を認識する NFA の大きさ $n$ に依存する。MCFG は NFA より簡潔になり得るので、**任意の** $L\in\mathcal C^{\rm mcf}_{2,s}$ で $n$ が $g,\theta$ の多項式であるとは証明できていない。非正則言語には有限 NFA すら存在しない。従って (5.1) は一般の $\tau(G,s)$ 上界を与えない。

原稿 `lem:app-u1-shallow` は深い挿入のない部分を処理する。先行報告の有界 $c$-run 定理は無数の $c$-run が発生しない部分を処理する。命題 5.3 は、深い挿入と無界 $c$-run と非 Parikh 飽和が**同時に起きても**、代表長が短い場合を与える。従って「深い挿入 $\Rightarrow$ Parikh 飽和」も「無界 $c$-run $\Rightarrow$ 下界」も十分な分岐命題ではない。

定理 4.1 が提供するのは**一つの純なホスト語の、同一中心文字に関する二穴移送**である。異なる中心文字を同一視したり、独立した多数の $c$ マーカーを同時挿入したりはできない。この欠落を埋めて $\tau$ を抑えるためには、導出木の重い反鎖の各純ブロックが実際に作る**複数マーカーの独立性**を証明する必要がある。これは未証明である。

先行報告 Astra §10.1 の命題 SC（短い許容文脈 $E$ に受理される任意の実現型の組に、$g,\theta$ 多項式長の代表がある）は依然として未解決である。SC があれば `lem:app-u1-fillers` と (1.3) により課題 A が肯定的に解けるが、今回の有限 NFA 論法では SC を一般に証明できない。

### 7.2 課題 B

課題 B の最短純語長 $\mu_1(L_n)$ が超多項式で、$g_n\theta_n=n^{O(1)}$ であるとすると、十分大きい $n$ では $\mu_1(L_n)>\theta_n$ である。従って**全ての**そのような候補は系 3.3 の条件 (3.4) を満たす。とくに**有限候補が単独の $c$ を受理する構成は一括して除外**される。以前の $E_i\to c$ 型の失敗は、この一般禁止則の一例である。

しかし $c$ 単独を受理せず、混合語が $a,b$ を含み、十分多くの異なる長さと $c$-run を持つ族を排除する定理は得ていない。純 singleton の内部 $c$ 置換が可能なら系 4.3 が混合語の**個数**を下から抑えるが、文法は短い表示で多数の受理語を生成できるため、その個数下界だけでは $\theta$ の下界にならない。

また $\mu_1$ の上界は $\tau$ の上界を自動的には意味せず、$\tau$ のみが大きくなる反例方式も今回の排除原理では未処理である。課題 A・B のいずれかが解決されたとの主張をしない。

## 付録 A. 実施した有限計算の Python コード全文と出力全文

**実行条件：** Python 3、標準ライブラリのみ。プログラム内の `N=2,3,4` は打切り範囲である。各 $Q_N$ 自体は有限であり、その範囲内では受理語を一つも省かず全分解を調べる。内側区切りに `j<k` を課し、成分には `i<j` と `k<ell` を課す。従って非空条件を緩めていない。

**コード全文：**

```python
from collections import defaultdict


def target(n):
    pure = 'ab' * n
    return {pure} | {pure[:2*i] + 'c' + pure[2*i+1:] for i in range(n)}


def typ(x):
    return tuple(int('c' in z) for z in x)


def observations(L):
    distributions = defaultdict(set)
    shared = defaultdict(set)
    for w in L:
        n = len(w)
        for i in range(n):
            for j in range(i + 1, n + 1):
                x, E = (w[i:j],), (w[:i], w[j:])
                distributions[x].add(E)
                shared[(1, E, typ(x))].add(x)
                for k in range(j + 1, n):
                    for ell in range(k + 1, n + 1):
                        x = (w[i:j], w[k:ell])
                        E = (w[:i], w[j:k], w[ell:])
                        assert E[1]
                        distributions[x].add(E)
                        shared[(2, E, typ(x))].add(x)
    return distributions, shared


def check(L):
    distributions, shared = observations(L)
    for key, tuples in shared.items():
        if len({frozenset(distributions[x]) for x in tuples}) > 1:
            return False, key
    return True, None


for n in range(2, 5):
    L = target(n)
    ok, witness = check(L)
    pure = 'ab' * n
    mixed = {pure[:i] + 'c' + pure[i+1:] for i in range(1, len(pure)-1)} & L
    print(f'N={n} words={len(L)} interior_c_replacements={len(mixed)} '
          f'arity_1_and_2_pass={ok} witness={witness}')
    assert ok
```

**標準出力全文（正常終了、例外なし）：**

```text
N=2 words=3 interior_c_replacements=1 arity_1_and_2_pass=True witness=None
N=3 words=4 interior_c_replacements=2 arity_1_and_2_pass=True witness=None
N=4 words=5 interior_c_replacements=3 arity_1_and_2_pass=True witness=None
```

`witness=None` はこの有限全列挙で違反が見つからなかったことを意味する。定理の証明に代用していない。先行報告 Astra の別検証器による結果は再実行しておらず、その古い出力を今回の出力に混ぜていない。
