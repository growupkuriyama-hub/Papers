## 2. 補題R・定理Dの独立査読（区分C）

### 補題R：**成立**
- (R1) [X] は1つの類：L_X の元は型が等しく導出文脈を共有する。
- (R2) 所属：A の導出文脈は L_A ⊇ L_X を受理し、したがって [X] 全体を受理。内部区切りは good 性で非空。start-link では □ が [X] を受理。規則語は「合成は同値を保つ」補題で L_X の元と同値。
- (R3) Link：ω′(X) と z_R はともに型 t で文脈 χ′(X) を共有。
- (R4) 合成証人：非併合性と非空区切りで子タプルは観測出現になる。
- (R5) rank 0・start・ε・非生産記号・重複語：すべて問題なし。
- (R6) **注意**：v79 正本の rule-only 命題は ω(X)=ρ_X(ω(Y)) を使うが、緩和代表元では成り立たない。したがって緩和証人集合では非終端記号用の語を残す必要があり、個数上界は |V||M|^f+|P||M|^{fr}（|𝓡| ではない）。**二つの最適化を同時に使ってはいけない。**

### 定理D：**成立（一様）**
- 一様性：Γ_T は Λ に依存するが、効くのは |Γ_T| ≤ (2T+1)^{|Σ|} だけで、これは**任意の** Λ で成り立つ。よって C, e は Σ, h, f, r のみに依存し、𝔸・φ・H（特にその指数）に依存しない。
- 整数計画：方程式 |Σ| 本、未知数 ≤ fC_h + 2(2T+1)^{|Σ|}、係数 ≤ T + fC_h。解の存在は任意の u∈L_X が保証し、小解の大きさは poly(T)（次数 O(|Σ|)）。
- ε：E[v] は常に非空なので影響なし。

## 3. 補題P（区分A3）
E[x]=E[y] なら Ψ(x)=Ψ(y)（固定部分が同じだから）。
- 系：v79 の補題 B（冪移送）・B′（局所シフト対）が与える交換対はすべて Parikh 同値。どの文脈にどう適用しても長さは変わらない。
- **「shift の存在」と「短縮」は別物**という指示の要点を定理化したもの。短い代表元 y≡x, ‖y‖<‖x‖ には、**異なる2語**に共通の受理文脈が必要。

## 4. 定理 F1-sl（区分A4、新規）

**設定.** マーカー集合 Σ_c ⊆ Σ、c(w) = [w がマーカーを含む]、h_U = c（2元半束、LG の外）。アーベル群 𝔸、準同型 φ、部分群 H、γ_0, γ_1 に対し

  L = { w ∈ Σ⁺ : φ(w) ∈ γ_{c(w)} + H }.

**定理.** Σ, Σ_c, h（h_U ⪯ h）, f, r を固定すると、ある C, e があって、上の形の任意の L と、その fan-out ≤ f・rank ≤ r の任意の reduced good 表現 G について
  κ_G ≤ C(‖G‖ max{1,θ_G})^e
が成り立ち、B^{≤r}_{f,h} は総長多項式の characteristic sample を持つ。定数は 𝔸, φ, H, γ に依存しない。

**新規性.** h_U ∉ LG なので局所群定理は使えない。g := γ_1 − γ_0 ∉ H のとき L はアーベル型フィルタでない（オフセット写像 {0,1}→𝔸/H, 1↦g が準同型になれないため）ので定理Dも直接は使えない。

**証明の骨格.**
1. 所属：同じ型のタプルは任意の文脈で同じ分岐に入り、共有文脈から φ の差が H に入る（共通の H が本質）。
2. オフセット補題：導出文脈 E がマーカーを含めば L_A の φ 値は H を法として一定。含まなければ c 値の差に g を掛けた分だけずれる。両種の文脈を持つ二型（bi-typed）記号は存在しない（g∉H）。
3. **オフセット剛性（核心）**：マーカーなし文脈をもつ二型記号 A の規則で、テンプレートがマーカーを書かず、マーカー専用の子もないなら、**二型の子は高々1つ**。2つあると z_{10}−z_{00} ∈ g+H と z_{11}−z_{01} ∈ H から g∈H となり矛盾（∨ の冪等性）。
4. 短い正準 yield：マーカーなし/ありの最短 yield は「二型の子が高々1つ」の連鎖で T_0 = |V|(‖G‖ + r t_G) 以下。倍化 A_i → A_{i−1}A_{i−1} は二型連鎖上に現れ得ない。
5. 短い Λ 欠損：型ごとの正準 yield で定義した δ_{R,b} は Λ に入りノルム T_1 = (r+1)T_0 + ‖G‖ 以下。任意の yield の Parikh は正準 yield から Λ_1（短い Λ ベクトルの生成群）の差しかない。
6. 定理D と同じ整数計画で型 t の短いタプルを得て、共通 H により同値性を示し、補題R で結論。

## 5. 失敗した原理（区分B）
- (F1) 「局所可動性 ⇒ 短縮」：補題Pにより方法として不成立。
- (F2) 「分岐整合な和集合は単一フィルタに帰着」：偽（例：Σ={a,c}, φ=#a mod N, γ_0=0, γ_1=1）。それでもデータ上界は剛性で成り立つ。
- (F3) 「分岐ごとに異なる部分群でも同じ証明が通る」：証明は Step 5 で共通 H を使う。h_U では走査範囲の全例が共通 H に正規化できたが、2マーカー内容型付けでは 64 例が分岐別部分群を本当に必要とし、**未カバー**。

## 6. 計算機による検証（有限範囲・定理ではない）
- `v80_branch_union_scan.py`：Σ={a,c}, h_U, φ:Σ*→ℤ/k, k≤6, 全分岐値集合。
  - 判定は可換性により和だけで厳密。所属かつ非自明（単一フィルタでない）な言語 1,364 個（重複除去後）が**すべて** F1-sl 型（共通 H）に正規化可能。
- `v80_content_union_scan.py`：Σ={a,c,d}, 内容型付け h(w)⊆{c,d}, k≤3, **任意の関係** R ⊆ P({c,d})×ℤ/k。
  - 81,456 関係中 6,958 が C(2,h) に所属。6,894 が捻り共通部分群型、64 が分岐別部分群型。他の形は出現せず。

## 7. 予想E への到達度（区分D）
- 証明済み：LG 型付け（v79）、アーベル型フィルタ（D）、半束分割共通部分群和集合（F1-sl）。
- 反証：fan-out 1 でのみ（TCS #1）。
- 反例設計は、剛体的な語（補題 B/B′ で破壊）か型可換な標的（D, F1-sl, 予想 F1-tw）に帰着し、生き残った候補はない。
- **未解決。**

## 8. 次に必要な補題（区分F、量化つき）
- **N1（分岐別部分群）.** 任意の Σ, Σ_c, h⪰h_U, f, r について、ある C,e が存在し：任意の 𝔸, φ, H_0, H_1, γ_0, γ_1 で、Λ_0 ∩ ℤ^{Σ∖Σ_c} = Λ_1 ∩ ℤ^{Σ∖Σ_c} を満たし L = {w : φ(w) ∈ γ_{c(w)} + H_{c(w)}} ∈ C(f,h) が good 表現 G を持つなら、κ_G ≤ C(‖G‖θ_G)^e。
- **N2（変動木）.** 内容型付けで、文脈内容 S_E をもつ導出文脈を持つ記号 A について Var(A) を「g_{S∪{c}} ≠ g_S となる実現可能な内容差のマーカー c の集合」と定義し、各規則で Var ≠ ∅ の子どうしの Var が互いに素であることを示す。これで予想 F1-tw（κ ≤ |Σ_c||V|(‖G‖ + r t_G) 型の上界）が従う見込み。
- **N3（型可換正規形）.** L ∈ C(2,h) で、マーカー部分が豊かなアーベルフィルタ（すべての剰余類にマーカー文脈が当たる）なら、マーカーなし部分は (h(w), φ(w)+H) で決まることを示し、N1–N2 に帰着する。
- **N4（非可換の壁）.** 大域的に「型＋アーベル不変量」で類が決まらない C(2,h) の元を構成する、または存在しないことを示す。後者と N1–N2 で予想 E が従う。
