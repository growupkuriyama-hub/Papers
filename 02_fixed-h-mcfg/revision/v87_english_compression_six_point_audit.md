## A6：一般化した完全性命題の独立した証明検査

対象：`prop:completeness`。仮定は (i) trimmed good typed grammar, (ii) 各非開始記号 X の非空の代表タプルι(X) とタイプ一致, (iii) 各 X の admissible な共通文脈χ(X) と二種類の正例語がKに出現, (iv) typed start promotionを持つXについてχ(X)=□₁。

1. **観測と型**：`χ(X)[ι(X)]∈K` なので `ι(X)` は観測された非空タプル。各親規則の結果 `z=ρ(ι(Y_1),…,ι(Y_q))` は、その第二証拠語により観測される。typed rule constructionと型の準同型性により `h(z)=h(ι(X))`。
2. **Link**：二つの親タプル `ι(X)` と `z` は同じχ(X)でK中に出現し、型が一致するため `[(ι(X))]→[z]` がある。
3. **Const/Comp**：q=0は `[z]→z`。q>0は非削除で各子が非空なので `q≤Σ_j||ι(Y_j)||₁≤||z||₁≤||K||₊`。良形規則の区間分割を第二証拠語が与え、`[z]→ρ([ι(Y_1)],…,[ι(Y_q)])` が存在する。
4. **導出模倣**：子の模倣について帰納法を適用する。開始促進でχ(X)=□₁だから `ι(X)` 自体が正例語となり、Startがある。
5. **結論**：targetのすべての成功導出を模倣でき、`L(G)⊆L(B)`。この方向には分布同値性・代入可能性も、`ι(X)∈L_X`も必要ない。

これは後半 `prop:mcfg-relaxed-witnesses` の非導出代表 `ω^†(X)∈[X]` に直接適用できる。後半では、**文脈が代表と各規則タプルの両方を受理すること**を証明する必要がある。現行後半は、`χ^†(X)`がuntyped非終端Aの導出文脈であり、元の `L_X` からのタプルを受理し、分布同値性および `lem:witnessed-composition` により各第二証拠も受理されると述べている。この依存を明示したほうがよい。

## 先行研究の適用範囲

Yoshinaka (2015) *General Perspective on Distributionally Learnable Classes*, Theorem 1 は本文で `SUBST_D` の Lemmas 2–3 により証明。§6.1 の `SUBST_P` は定義され、§7ではAssumptions 1,2,7 の下で両方の選択を許すと記載されるが、詳細な独立証明は省略されている。本案ではこの違いを明示し、自分の具体的再構成器について健全性・完全性を直接残した。原典： https://aclanthology.org/W15-2308.pdf

規則ランク無制限は単一のbounded-rank signatureからは導かず、`eq:sample-rank` と具体的完全性命題の独立した証明により扱う。Yoshinaka (2011), Corollary 2 との既知範囲の重なりも明記する。
