# R14　正則な骨格のオートマトンによる分類

## 結論（三行）

1. T1 は修正版 VALID。定理Lの代表長は $O(v^{k^\ell f+2}\bar\theta_G^{k^\ell f+1})$。
2. T2 は非空支持で VALID。群付き Euler 歩道の剰余類を決定し、定理Lと同じ次数を得た。
3. T3 は (A)。偶数 run の統語値と固定窓計数のクラスには多項式上界がある。一般の fan-out 2 問題は OPEN。
