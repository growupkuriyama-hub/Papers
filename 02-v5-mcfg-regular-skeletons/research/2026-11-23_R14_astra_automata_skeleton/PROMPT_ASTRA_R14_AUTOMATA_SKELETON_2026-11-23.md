## 1. ここまでの到達点（第四段報告と台帳の要約。これ自体を検証の対象とすること）

記号は第四段報告と同じです。$k=|\Sigma|$、$\ell\ge1$、$K=k^\ell$、$s_\ell:=s_{\ell-1,\ell-1}$（窓型付け）、$N_\ell(w)\in\mathbb N^{\Sigma^\ell}$ は $\ell$ 因子の個数ベクトル、$D_\ell$ は de Bruijn グラフ（頂点 $\Sigma^{\ell-1}$、辺 $\Sigma^\ell$）、$c_\Sigma$ は内容型付けです。

  - 証明の骨格：補題 P0$^\ell$（分布の分類）、頻度の隙間 W2$^\ell$ と印、補題 P1$^\ell$（色＝（ψ の窓型、不純窓の多重集合））、補題 ER$^\ell$（凍結ブロック付きの Euler 再配線）、一段の削除（Y 側・F 側）、§4.6 の窓の数え方。
  - 系 L2：SL$_\ell$ ∩ アーベル剰余類は $\mathcal C^{\rm mcf}_{f,c_\Sigma\times s_\ell}$ に入る。
  - 系 L3：$k\ge2$ なら、$c_\Sigma\times s_\ell$ の像は LG に入らない。
- **2026-11-14 の監査（GPT-6）の判定は FIXABLE** です。原文のままでは VALID ではなく、次の二点を直せば多項式の上界を再構成できる、とされています。

  - **(E2)** $\ell=1$ のとき、$H_0=h_J^{\ell-1}$ が空語になり、空の穴を使ってしまう。別の構成で直せる。

- **観察 D0（第四段 §7）。** 定理Lで本当に効いているのは、骨格のオートマトンが **definite**（最後の有限個の文字で状態が決まる）であることです。(ℓ−1)-definite な DFA の遷移の計数で所属が決まる言語は、ℓ-局所計数言語になります。
- **命題 D2（第四段 §7）。** $E_{\rm ev}=\{w\in\{\mathtt a,\mathtt b\}^+:\text{極大な a-run の長さがすべて偶数}\}$ について、$n\ge\ell$ なら $w_1=\mathtt b\mathtt a^{2n}\mathtt b\mathtt a^{2n}\mathtt b\in E_{\rm ev}$、$w_2=\mathtt b\mathtt a^{2n+1}\mathtt b\mathtt a^{2n-1}\mathtt b\notin E_{\rm ev}$ で、$s_\ell$ と $N_\ell$ が一致します。したがって、どの $\ell$ でも定理Lの仮定の外です。
  - 第四段の注記：型に「端の a-run の偶奇」を加えると分類は回復するが、P1 の置換で状態が run の終わりまで反転し、不純な遷移が run の長さに比例する。ただし遷移の計数の差は run ごとに ±1 なので、差分で色を取れば有界になる見込みがある（予想）。
- **条件付き方向（第四段 §7、予想）。** 有限群の語問題と Parikh 条件の組み合わせ（例：$S_3$ の生成元で値が 1、かつ $|w|_{\mathtt a}=|w|_{\mathtt b}$）について、次の補題があれば方針は通る見込み、とされています。
  - 必要な補題：「十分大きな重複度を持つ文字の多重集合を並べ替えて得られる積の集合は、交換子部分群の剰余類全体になる」（Dénes–Hermann 型。未検証）。
  - 方針：色に成分ごとのアーベル化の値を加える。
- **台帳の現状（R13 まで）。** `op:fanout-two` は **OPEN**、十分性（LG）は全 fan-out で証明済み。`prop:sl-reduction` と R4 系 B により、問題は内容型付けの希少型の問いに帰着するとされています。

## 3. 必須検査（違反した論証は無効）

- 型は、穴ごとの**実際の成分**の型（内容、窓、群値、$\sigma$）で決まる。語全体の計数の一致から、代入の合法性を導かない。
- 穴の語は非空とし、二穴の中央も非空とする。外側の文脈は空でよい。3 つ目の穴を密かに追加しない。
- 各 Rect では、次をすべて書き出す：比較タプル $x,y$、成分ごとの型、共有文脈 $E_0$、試験文脈 $E_1$、四つの語。全 Rect についての主張では、場合分けが網羅的であることを論証する。
- 文法についての主張では、$\|G\|$、**元**厚さ $\bar\theta_G$、reduced/good、fan-out/rank を明示する。アルファベットは族の中で固定する。
- 代表元の長さ $\tau$（分布が同じ最短の組）と、非終端の最短の生成語の長さを区別する。
- $L\in\mathcal C^{\rm mcf}_{f,s}$ は、別途仮定するか証明する。任意の Parikh 集合との交差が自動的に MCFL になる、あるいは代入可能になる、とは主張しない。
- de Bruijn の同期性：部分歩道を置き換えても後続の窓が保たれるのは、端点（ℓ−1 文字の窓）が保たれるときだけである。
- 置換や再配線で成分の**群値**と **$\sigma$ の値**が変わる点を、各段で必ず追跡する。
- 部分木の入れ替えで得た語が $L$ に入るのは、同じ非終端の部分木の交換（文脈自由性）による。代入可能性と混同しない。
- `v2/reviews/PAUSE_FALSE_ROUTES_2026-11-16.md` にある反証済みの推論を前提にしない。小さい $n$ の反例で、大きい $n$ の一般定理を反証しない。有限検査を全称証明と呼ばない。
- 前任者の「VALID」も、11/14 の監査の判定も、自分の判定の根拠にしない。どちらも検証の対象である。
