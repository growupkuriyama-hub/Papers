# R11（Claude Opus 5.5, 2026-11-22）：交差と「ちょうど埋める」— m={a} の最後の二つの障害

## 結論（3 行）

1. 単一文字の類 K={a,x} では、内容型付けと a の連の滑らせ（P1′）だけから a·xⁿ ≡ xⁿ·a が出る。よって K の語の一穴の類は Parikh ベクトルで決まり（補題 RC・NFK）、交差 (R1) もちょうど埋める (R3) も溶解の対になる（補題 SD・定理 1）。単一文字の類では R15 型の反例は作れない（系 2）。
2. (R3) は射影の正規形（補題 PNF・命題 5）で全ての類について閉じる。R10 定理 A は、仮定 (U) を「非 a の文字を二つ以上持つ類」だけに課す形で成り立つ（定理 4。R9 の HΞ と R10 の HΞ\*・Φ2 に依存）。
3. 一般の fan-out 2 での m={a} の多項式上界は OPEN。残るのは二文字以上の類の交差で射影が非可換な対、または内容が成分に分かれる対だけである（系 6。R15 の L_{N,d} は後者）。|Σ|=2 は本稿の `thm:two-letter-content` で既知。

ラベルはすべて報告者の自己判定で、独立監査は受けていない（R4〜R10 と同じモデル系列）。
