# R6_claude_beyond_periodic_2026-11-22

R6（`op:fanout-two`）：周期枠の外での剛性と、繰り返す手の強制。報告者は Claude Opus 5.5（別スレッド）。ラベルはすべて報告者の自己判定で、独立監査は受けていない。

## 結論（3 行）

1. B1 は周期性を使っていない。枠の補題（C1）と整列した移送（C2）により、B1 と B3（一つの手による段の符号化の不可能性）は、Thue–Morse 型を含む任意の宿主で成り立つ（C3）。周期性が効くのは、整列していない宿主への手の値の移送だけである。
2. 共有された手は、段が連続していなくても近道を生む（D1）。しかし、Parikh 差が互いに異なる符号では、鳩の巣原理・切り直し・冪の移送から手の共有は決して生じない（D3）。依頼の形の T2 の主張はこれらの規則からは導けず、言語の段階では OPEN。
3. 長い二文字の因子は文字の 4 乗を強制する（P1, P2）。三文字では語だけからは強制されない（P3）。判断は否定に弱く傾くが、予想であり、確信度は R5 より低い。
