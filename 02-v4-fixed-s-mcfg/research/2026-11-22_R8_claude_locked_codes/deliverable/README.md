# R8：錠のかかった剛い符号と、二つの逃げ道の段階（Claude Opus 5.5, 2026-11-22）

## 結論（3 行）

1. 周期的な背骨と段に一様な逃げ道（符号は任意。錠・剛性・Parikh 差・段ごとの内容を問わない）では、兄弟の逃げ道の語 $\cdots e_ie_i\cdots$ から一穴の合同が出る。合成 $e_{i'}\equiv e_{i_0}^{2^{i'-i_0}}$ と換算 $e_{i_0}e_{i_0}\mathtt a\equiv\mathtt a^{2^{i_0}}e_{i_0}\mathtt a$ である。言語は「重みの代数」$T(N)$ の写しを強制され、これが R7 の閉包の爆発の正体である（定理 H1・H2。$|T(32)|=47{,}350{,}056$）。
2. 重みの軽い並べ方は近道を生む（補題 H3）。そのため、$W$ が最短なら fan-out 2・rank $r$ のどの文法も $|V|\ge2^{(n-2)/(3rq)}/\mathrm{poly}$ を満たし、この設計からは超多項式の希少型は出ない（定理 H4・系 H5）。R7 の残った候補は、近道ではなく文法の大きさで死ぬ。
3. トークンの段階では段は閉じる（障壁、命題 H6）。文字の段階では、試した全ての符号で境界の切り直しが非トークン語を作る。判断は否定に傾く（予想、確信度は R7 より上）。残る設計空間は、節点ごとの逃げ道、周期的でない宿主、一般の強制部分木である。

ラベルはすべて報告者の自己判定で、独立監査は受けていない（報告者は R4〜R7 と同じモデル系列）。
