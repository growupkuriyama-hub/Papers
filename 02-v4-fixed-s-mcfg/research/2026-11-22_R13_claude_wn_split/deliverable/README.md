# R13（Claude Opus 5.5）WN の分裂型の対、根の型 m={a} — 2026-11-22

## 結論（3 行）
1. WN な提示では、比較できない同類の重い対は「殻が互いに素」か「隙間に入れ子」。離れた分裂型の対は、圧縮した殻をアンカーにすれば使える（定理 D-hull、VALID 自己判定）。WN の m={a} に残るのは、入れ子の分裂型の「塔」だけ（系 6′）。
2. 入れ子の分裂型の対では、二側の族の強制は通る（DIS2-nest・WRAP・EX2・NF-nest、VALID）。部分木の入れ替えで得られる語は、言語の上で交差した組み合わせになり、評価できない（OPEN）。組み合わせの条件 (PP) のもとでは数え上げが閉じる（定理 W2-nest、CONDITIONAL）。R15 の G^nest では (PP) が成り立つ。
3. a を含む内容ごとの線形の不変量を持つ言語では μ_{a} ≤ poly(θ̄_G)（定理 LIN、VALID）。R15 型の一般化で会計を非線形にすると代入可能性に反する（命題 NL）。WN の m={a} は閉じていない。
