## 1. ここまでの到達点（R6 まで）

- **R4 系 B**（未監査の補題 4 に依存）：f=2 で答えが肯定 ⟺ ある固定 Σ の内容型付けで、根の希少型が超多項式になる族がある。
- **R5 定理 0.2**：肯定には、超多項式に長い強制節点が一つある族が要る。
- **R6 の剛性定理（周期性は不要）**：
  - C1（枠の補題）：同じ類の二つの W-枠が共通の埋め草を持てば、領域の長さは等しい。
  - C3・D1：一つの手、または二つの段の組で共有される手で段を符号化する設計は、二分の倍増の宿主（Thue–Morse 型を含む）で必ず近道を生む。
- **R6 命題 D3（Parikh の障壁）**：段の組の Parikh 差が互いに異なる符号（例：e_s = c aˢ c b^{s²} c）では、Parikh を保つ閉包（切り直し、冪の移送、Thue–Morse の切り直し）から手の共有は生じない。既知の剛性定理のどれにもかからない。
- **R6 の結論**：残る問いは一点に集約された。
  > Parikh 差の異なる符号を、近道なしに、多項式の大きさと多項式の元厚さを持つ fan-out 2 文法で生成できるか。あるいは、Parikh を変える Rect の段（余白と逃げ道にまたがる組、二つの逃げ道を持つ語）が必ず近道を出すか。

## 2. 課題

### T1. 計算による決着の試み（主課題その 1）
周期的な背骨（A_0→z, A_i→A_{i−1}A_{i−1} | e_i）と Thue–Morse 宿主（A_i→A_{i−1}B_{i−1}, B_i→B_{i−1}A_{i−1}）に、Parikh 差の異なる符号を付ける。少なくとも次を扱うこと。
- e_s = c aˢ c b^{s²} c
- e_s = c aˢ c b^{2^s} c
- 自分で設計した、R6 の D3 の条件を満たす符号を 1〜2 種

それぞれについて、n≥6（可能なら 8）で、種（W と逃げ道一つの語、および L(G_n) 全体）からの SUB₁・SUB₂ 閉包を、長さ |W| 以下に制限して計算すること。
- **より短い型 m の語が出たら**：証明書を取り出し、独立の再生関数で検査する。そのうえで、どの種類の Rect の段（Parikh を保つか、変えるか。余白と逃げ道にまたがるか）が効いたかを分類する。
- **閉包が近道なしで閉じたら**：その有限集合が厳密に (2,c) 代入可能であることを独立の検査で確かめる。そのうえで、n とともにどう伸びるか（語数、構造）を報告する。

R6 の較正（n≤4 では死んだ設計も生き残る）を踏まえ、n を十分大きく取ること。そのために高速な閉包の実装（出現の索引、分布の差分更新など）を設計し、その健全性を説明すること。計算時間の目安は、zip 内の `run_all.py` の再実行で 15 分以内。それ以上かかる探索は、別のスクリプトにしてログだけを同梱してよい（その場合は README に明記する）。

### T2. Parikh を変える段の移送補題（主課題その 2）
T1 の証明書に現れた Parikh を変える段を一般化し、次の形の定理を証明すること。
> 二分の倍増の宿主で、段の数が t ≥ t₀(|Σ|, θ) なら、Parikh 差が互いに異なる符号でも、余白と逃げ道にまたがる二穴の段（または二つの逃げ道を持つ語）によって、C1 が適用できる同じ類の二つの枠が共通の埋め草を持つ。

成り立たない場合は、T1 で閉じた閉包を反例の芽として扱い、その閉包を生成する多項式サイズ・多項式の元厚さの fan-out 2 文法があるか（R5 の (D3)）を検討すること。肯定方向の候補が見つかったら、族として定式化し、全一穴・二穴 Rect の証明に挑むこと（小さい n での総当たりは補助であり、全称の証明の代わりにしない）。

## 3. 必須検査（違反した論証は無効）

- 型は穴ごとの**実際の文字内容**で決まる。語全体の Parikh ベクトルの一致から、代入の合法性を導かない。
- 穴の語は非空、二穴の中央も非空。外側文脈は空でよい。3 つ目の穴を密かに追加しない。
- 各 Rect で、比較タプル x, y・成分ごとの型・共有文脈 E₀・試験文脈 E₁・四語をすべて書き出す。全 Rect の主張では、場合分けが網羅的であることを論証する。
- 文法についての主張では ‖G‖・**元**厚さ θ̄_G・reduced/good・fan-out/rank を明示する。アルファベットは族の中で固定する。
- 閉包の計算で「出ない」は、長さ制限や予算のもとでは何も示さない。閉じたことを主張するときは、予算に当たらず閉じたこと、および独立の代入可能性検査を通ったことを明示する。
- トークンの段階の閉性を、文字の段階の閉性と取り違えない。
- 反証済みの R13 原文 X1、R14 原文 CA、R15 一般 IH、R2 の退化した短縮補題を前提にしない。小さい n の反例で大きい n の一般定理を反証しない。有限検査を全称証明と呼ばない。
