## 2. 緊張関係（R3 の主題）

- 元厚さ θ̄_G が小さいと、G の**各規則**は短い成功文の中に現れる。そのため C は「G のある非終端の yield 全体」の類にはなれず、型付き非終端 A_m（同じ A の型 m の部分）の類として現れるしかない。
- `prop:typed-thickness-exponential` では t_X が指数的だが、同じ意味クラスに短い `a` があるため下界にならない。
- 二穴 Rect の交換（R1 の MS 系、11/01 の補題 5）は、長い部分語の中で切る位置をずらした等価なタプルを大量に作る。これが C_X の中に短い元を作り出してしまうかどうかが、核心の問い。

## 3. 課題

### T1. 構成（主課題）
Σ={a,b,c}, s=c_Σ（または s_U）, f=2, r_max=2 で、次をすべて満たす族 (L_n, G_n) を作ること。

1. L_n∈C^{mcf}_{2,s}（全一穴・二穴 Rect）。
2. G_n は reduced good、fan-out ≤2、rank ≤2。‖G_n‖ と**元**厚さ θ̄_{G_n} は n の多項式。
3. ある型付き非終端 X について、τ_{C_X} が超多項式。つまり C_X の**どの**タプルも長い。t_X だけを評価してはいけない。C_X の全体（L の中で同じ型・同じ分布を持つタプル全部）を特定すること。
4. 条件 (i)：w∉R(L_n∖H_{C_X})。推奨される示し方は、L_n∖H_{C_X}⊆D、w∉D となる (2,s)-代入可能な言語 D を明示すること（soundness から R(L∖H)⊆D が従う）。

根の各実現型に短い代表があってよい（むしろ、それが内部クラス路線の意味）。

### T2. 障壁（構成できない場合）
次の「内部版の希少型予想」を、明示した部分クラスで証明すること。

> **予想 IC。** 固定の Σ, s, r_max に対して多項式 p があり、L∈C^{mcf}_{2,s} の reduced good な提示 G のすべての型付き非終端 X について τ_{C_X} ≤ p(‖G‖, θ̄_G)。

予想 IC が成り立てば内部クラス路線は閉じる。部分クラスとしては、たとえば X の型が根に至るまで一定の重さで制約される場合、fan-out 1 の場合、二文字の場合など。fan-out 1 では `conj:rare-types` 自体が偽である（`rem:fanout-one-data`）。fan-out 1 で予想 IC が成り立つのか、そこでの希少型の反例がどう内部クラスに現れるのかを、まず確かめること。これは予想 IC の妥当性の試金石になる。

### T3. 関係の整理（短く）
予想 IC と `conj:rare-types` の論理関係（どちらがどちらを含意するか、あるいは独立か）を証明付きで述べること。そのうえで、必要性側に残る道（希少型・内部クラス・その他）がまだあるかを一段落で判断すること。

## 4. 必須検査（違反した論証は無効）

- 型は穴ごとの**実際の文字内容**で決まる。意味クラスは型と分布の両方で決まる。t_X（A_m の最短 yield）と τ_{C_X}（クラス全体での最短）を混同しない。
- 穴の語は非空、二穴の中央も非空。外側文脈は空でよい。3 つ目の穴を足さない。
- 各 Rect で x, y・成分型・E₀・E₁・四語をすべて書き出す。全 Rect の主張では、場合分けが網羅的であることを論証する。
- ‖G‖・**元**厚さ θ̄_G・reduced/good・fan-out/rank を明示する。
- X1・CA・一般 IH・R2 の退化した短縮補題を前提にしない。有限検査を全称証明と呼ばない。
