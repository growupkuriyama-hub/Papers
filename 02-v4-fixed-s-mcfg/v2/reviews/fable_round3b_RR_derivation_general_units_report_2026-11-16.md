# Fable 第3回追補：一般単位 `(b^p c^q, b^r c^s)` における RR の導出 — 数学報告

2026-11-16 JST。研究専用。論文本文・PDF・GitHub は未変更。手証明で、**独立監査は未了**。Python は文字列等式と移動回数の検算（`t≤3, q≤5, n≤6`、1秒未満）だけに使った。追加で読んだ資料はない。

## 1. 結論

**PROVED（下記の室の下）：RR は仮定から導出できる。したがって MX は RR なしで成立する。**

- 必要なのは補題A・補題C ではなく、**一つの MS 語を二通りに切る「再切断」二穴交換**だけである。別の単位も a 吸収も使わない。
- Seed は交錯・入れ子のどちらでもよい（同一単位の MS 語 `u^n v^n` は両者で同じ形）。第3回報告で未処理だった入れ子 Seed の `J,K` もこれで閉じる。
- 範囲は a-free 成分で `χ≥2` の場合。`χ=1` は §5 の対称版に回る（未精査）。

## 2. 仮定

第2回 MS と同じ：`Σ={a,b,c}`、型は成分ごとの `alph`、L は1穴・2穴の内容型付き組代入可能、`a^N` は最短の正 a 冪、許容単位は a-free の `(b^p c^q, b^r c^s)`（各指数≥1、欠損≥1）、適法 Single、実在する加法的 Seed（交錯または入れ子）。χ を許容単位の c 指数の最大値とし、それを達成する単位を `K*`、その欠損を `d*` とする。室は

- **(R1)** `6d* ≤ N−4`（MS 語 `u^6 v^6 a^{N−6d*}` の存在）
- **(R2)** 各許容単位 J について `d*+d_J ≤ N−4`、比較する多重集合について `d_m ≤ N−4`（MX の前提そのまま）

小窓 `d ≤ (N−1)/(24θ²)` と `N≥5` の下では、(R1) と (R2) の単位対の部分は自動的に満たされる。`d_m≤N−4` は比較対象への仮定として残る。

## 3. 新しい補題

### 補題RC（再切断）

`x₁, z, y₂` が非空で、`alph(x₁z)=alph(x₁)`、`alph(zy₂)=alph(y₂)`、かつ `l·x₁·z·z·y₂·r∈L` とする。

- 比較組：`x=(x₁, z y₂)`, `y=(x₁ z, y₂)`。実型は仮定により成分ごとに一致。
- `E₀=(l, z, r)`：`E₀[x]=E₀[y]=l x₁ z z y₂ r`（同じ語の二通りの切り方）。中央 z は非空。

よって中央が非空の任意の二穴文脈で x と y は交換できる。すなわち `l' x₁·m·z y₂ r'∈L ⟺ l' x₁ z·m·y₂ r'∈L` で、**z が m を飛び越える**。a 数は変わらない。

### 補題CH（鎖による c 連の汲み上げ）

`t≥1`, `q≥2`, `n≥3` とし、`w=P·(b^t c^q)^n·b^t c·Q∈L` とする（P,Q は任意）。このとき

**`P·b^t c^q·b^t c^{(n−1)(q−1)+1}·(b^t c)^{n−1}·Q ∈ L`**。

*証明。* ブロックを `B₁,…,B_n` と呼ぶ。

**(J1)** 補題RC を `x₁=c b^t`, `z=c`, `y₂=c^{q−2}b^t c` に適用する。証人は w の因子 `c b^t c^q b^t c`（B₁ の末尾 c、B₂、次の `b^t c`）。

- `x=(c b^t, c^{q−1}b^t c)`, `y=(c b^t c, c^{q−2}b^t c)`。実型はともに `({b,c},{b,c})`（q=2 でも `y₂=b^t c`）。
- `E₁=(P b^t c^{q−1}, c^q b^t c, R)`、R は B₃ の残り以降。`E₁[x]=w`。
- 第四語：`w'=P·b^t c^q·b^t c^{q+1}·b^t c^{q−1}·B₄⋯B_n·b^t c·Q∈L`。

**(J2)** `w'` は因子 `c·c·c·b^t c` を含む（B₂ の連は長さ `q+1≥3`）。補題RC を `x₁=c`, `z=c`, `y₂=b^t c` に適用する。

- `x=(c, c b^t c)`, `y=(cc, b^t c)`。実型はともに `({c},{b,c})`。
- 帰結：`l' c·m·c b^t c r'∈L ⟹ l' cc·m·b^t c r'∈L`（m 非空）。

つまり「直後が `b^t c` である c 連の末尾の c」を、それより前の任意の c の直後へ移せる。

**(汲み上げ)** `x₁` を B₂ の連の末尾の c に固定し、B₃,…,B_n の各連から、長さ1を残して c を一つずつ移す。供給側の連は常に長さ≥2 の状態で1個出すので m は非空で、b 連は合流しない。各連の直後には次のブロック（または末尾の `b^t c`）の `b^t c` がある。B₃ から `q−2` 個、B₄…B_n から各 `q−1` 個で、B₂ の連長は `q+1+(q−2)+(n−3)(q−1)=(n−1)(q−1)+1`。∎

### 系（RR の導出）

`K*=(u,v)` の MS 語 `u^6 v^6 a^{N−6d*}∈L`（R1）を取る。χ が u 側（`q=χ`）なら `u^6=(b^p c^χ)^5·b^p c·c^{χ−1}`、v 側（`s=χ`）なら `v^6` を同様に見て、補題CH を `n=5` で適用する。得られる c 連長は

`4(χ−1)+1 = 4χ−3 ≥ 2χ+1`（χ≥2）。

**よって RR が成立する。**

## 4. 定理

**定理。** §2 の仮定の下で、`χ≥2` なら、非 a 総 Parikh が等しい二つの許容多重集合（`d_m≤N−4`）の欠損和は一致する。

*証明。* 系により RR が成立し、MS の前提は仮定に含まれるので、定理MX（独立監査で VALID WITH EXPLICIT RR / MS HYPOTHESES）がそのまま適用できる。∎

`J=(bc,bc)`, `K=(bbcc,bbcc)` では `K*=K`、`χ=2`、c 連長5 が得られ、`2J` と `K` の総 Parikh が等しいので `D=2δ`。第3回の証明とは独立の経路で、入れ子 Seed でも通る。

**証明が依存する箇所。** (i) MX と MS の監査済み部分。(ii) 補題RC の「同一語の二通りの切断は共通文脈を与える」という一点。定義 `def:tuple-substitutable` は共通文脈の存在だけを要求するので合法だが、全体がこの一点に乗っているので監査の最重要箇所である。「Parikh が等しいから並べ替える」は使っていない。

## 5. 位置づけと注意

- **第3回との関係**：補題A（a 吸収）・補題C は不要になった。入れ子化で連を伸ばすのではなく、鎖の中で c を前へ集める。
- **RR / MX**：RR は追加仮定から帰結へ変わった。MX は a-free・χ≥2 で無条件になる。
- **AB16**：連結宿主も `N≥6maxδ+1` も使わない。室は (R1)(R2) のみ。
- **強い構造的帰結**：補題CH は単位や Seed に依らない。クラス内の L が `P(b^t c^q)^n b^t c Q`（q≥2, n≥3）を一語でも含めば、同じ a 数で長い c 連を持つ語を含む。たとえば正則言語 `(bbcc)^*` は alph 型の2穴代入可能ではない。主張が強いので、既知のクラス所属例との整合を監査で確認する価値がある。
- **χ=1 の場合**：全単位が `(b^p c, b^r c)`。b 指数の最大値が2以上なら、文字交換と反転による対称版（b 連の汲み上げと MX の b 版）で同じ結論になるはずだが、MS 前提の対称性を含め**未精査**。全指数が1なら単位は `(bc,bc)` のみで自明。
- **射程外**：内部 a を含む単位、一般 P_tree（木由来性・厚さ・小窓の量化）、一般 AB、非可換 U、正式 `op:fanout-two` は OPEN のまま。

## 6. 次に残る最小課題（1件）

**内部 a を含む混合支持単位への拡張。** 成分が `b^p a^i c^q` 型のとき、`h=δ+内部a数` の会計の下で補題CH の汲み上げ（c が a を含む m を飛び越える再切断）と MS がそのまま通るか。通れば混合支持の Parikh 剛性が P2+ と同じ射程まで揃う。
