## I. 連結宿主がある非可換枠付きAB

```text
内容型付き1/2穴 Rect、a^N 最短
  + 単独 Rot(κ), Rot(κ′)
  + κ=pbcq, κ′=pcbq, p,q∈{b,c}⁺, δ,δ′>0
  + 実在 a^x κ a^y κ′ a^z ∈ L, x+y+z=N−δ−δ′
  + N≥15 max(δ,δ′)
       │
       ├─ R / Rot：κκ′ a^t を実際に受理
       ├─ F： (bc,a^i) ≡ (cb,a^{i+s})、s=δ−δ′
       ├─ 受理語内の b/c の隣接交換（高々12回でxxxxを作る）
       ├─ S/L：同一受理語の二切断から aコスト0 のスライド
       └─ U_shift：同じ非a語に2つの異なる末尾a指数は不可
                   ⇒ δ=δ′
```

- 重要な数式：`t=N−δ−δ′`, `M=max(δ,δ′)`, `s=δ−δ′`、交換J回の安全室は `t≥J|s|+2`。一般p,qに高々12+2=14回、`N≥15M`で十分。
- 依存は**言語Lの1/2穴代入可能性**であり、生成文法・元厚さへの効果を証明していない。
- 拡張：block版は非消去 `μ(A)=a,μ(B)=u,μ(C)=v` の逆像で成立するが、原核の内部aを `h=δ+|κ|_a` で会計する。障壁版では実際の`{b,c}`長因子に交換を閉じ込める。
- **欠けた矢印：** 任意の木由来の核→実在加法的連結宿主。一般IHは反証済み。隣接転置をつなぐ中間核→Rot証人も自動ではない。

## II. 交錯・入れ子を保つ二成分Transport

```text
内容型付き1/2穴 Rect + 最短 a^N
  + reduced good G の木から必要なSingleと実在加法的Seedを
    別途供給する（仮定であって一般存在定理ではない）
  + a-freeの整列混合支持 (b^p c^q, b^r c^s)
       │
       ├─ Comm / R ：単位ブロック全体と a の可換
       └─ MS：交錯 u1...un v1...vn / 入れ子 u1...un vn...v1
              に末尾a^(N−d_m) を付けた語を受理
               │
               ├─ 室：χ≥2 を達成する K*、6d*≤N−4
               ├─ RC：同じ語の合法な二穴切断 (x1,zy2) ↔ (x1z,y2)
               ├─ CH： (b^t c^χ)^6 を含む MS 語から長いc連
               │          (χ≥2なら c-run≥2χ+1)
               ├─ Rc/CC：コスト0の cb^t ↔ b^t c の交換
               └─ MX：正規形が一致するので総非a Parikh一致
                       ⇒ 欠損和一致
```

- 個々の量化：`6d_*≤N−4`; 全許容単位Jで`d_*+d_J≤N−4`; 比較する**各**多重集合の欠損和`d_m≤N−4`。種B,Cに小窓条件を課してよいとは言っていない。
- 内部aがあるとき：ON-loc（局所非aブロックとの`az≡za`）→RED（`π`でa-freeへ）→SEED（順序を変えずa室再配分）→MS→RC/CH→MX。ただし`π(u)=b^pc^q`,成分両端非a、元Singleの外側室`N−h≥4`、実Seedが必要。`δ`は欠損、`h=δ+内部a数`は元の外側室用。
- 重要な別証明：最小切片`J=(bc,bc)`,`K=(bbcc,bbcc)`で、交錯SeedならA/Cから受理`c⁴`を作り直接`D=2δ`。後のRR導出は指定室の下で入れ子Seedにも届く。
- **欠けた矢印：** 任意の元木の多様な成分内容型を、上記整列混合支持やSingle/Seed条件に必ず移せること。一般`P_tree` OPEN。
