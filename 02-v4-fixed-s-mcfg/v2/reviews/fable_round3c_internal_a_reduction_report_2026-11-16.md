# Fable 第3回追補2：内部 a を含む混合支持単位 — a-free への還元 — 数学報告

2026-11-16 JST。研究専用。論文本文・PDF・GitHub は未変更。手証明で、**独立監査は未了**。Python は実行していない。追加で確認した資料は Astra 第16段報告 §5.8（ON 補題と P2+）のみ。

## 1. 結論

**PROVED（下記の仮定の下）：内部 a を含む単位は、同じ欠損 δ を持つ a-free 単位に還元できる。したがって追補1の定理（RR なしの総 Parikh 剛性）がそのまま及ぶ。**

- 問いへの答え：補題CH と MS を内部 a 付きで作り直す必要はない。先に内部 a を外へ出せる。
- 会計：不変量は **δ（a 総数の欠損）**であり、`h=δ+内部a数` は外側 a の室（`N−h≥4`）としてだけ現れる。還元後も欠損は δ のままで、h に取り替えない。これは Astra §5.8 の「d_J は `k_J−α_J` のまま」と同じ扱いである。
- 新しい中身は小さい。Astra の ON 補題の**局所部分**（`a z_i ≡ z_i a`）が、ブロックの単色性にも b相/c相の順序にも依らないことを使うだけである。
- 範囲：a を消すと `(b^p c^q, b^r c^s)` になる成分（a の挿入位置は任意）。`χ=1` と木由来版の量化は未処理。

## 2. 仮定

`Σ={a,b,c}`、型は成分ごとの `alph`、L は1穴・2穴の内容型付き組代入可能、`a^N` は最短の正 a 冪。π を a の消去とする。

- **単位**：`J=(u_J,v_J)`、各成分は非 a 文字で始まり非 a 文字で終わり、`π(u_J)=b^p c^q`, `π(v_J)=b^r c^s`（各指数≥1）。内部 a 数を `ι_J`、欠損を `δ_J≥1`、`h_J=δ_J+ι_J` とする。
- **(Single)** `a^l u_J a^g v_J a^{r'}∈L`、`l,g,r'≥1`、a 総数 `N−δ_J`、外側 a 数 `N−h_J≥4`。種 B,C も同様。
- **(Seed)** 交錯または入れ子の実在受理語で、a 総数が `N−δ_B−δ_C≥2`（加法性は a 総数で述べる）。
- **室**：追補1の (R1)(R2) を δ で読む。`6δ*≤N−4`、`δ*+δ_J≤N−4`、比較する多重集合は `δ_m≤N−4`。

## 3. 補題

### 補題ON-loc（ON の局所部分、ブロック形状に依らない）

`w=a^{e_0}z_1a^{e_1}⋯z_ta^{e_t}∈L`、`e_i≥1`、各 `z_i∈{b,c}^+`、`A=Σe_i<N`、`A≥t+2` とする。このとき各 i について `a z_i ≡ z_i a`（全一穴文脈）。

*証明。* Astra §5.8 の証明の前半そのままである。R（`a^N` による a 連再配分）は、間に非空ブロックがある任意の二つの a 連に適用でき、和は `A<N`。余剰1個を `z_i` の左連へ集めて長さ `m≥2` とすると

`P₀ a^m z_i a^e Q₀∈L`、R により `P₀ a^{m−1} z_i a^{e+1} Q₀∈L`。

- 比較片：`x=a z_i`, `y=z_i a`。実型はともに `{a}∪alph(z_i)`。
- `E₀=(P₀a^{m−1}, a^e Q₀)`：`E₀[x]`, `E₀[y]` が上の二語。

ON が単色性と相順序を使うのは、その後の大域的正規形 `b^Pc^Qa^A` の部分だけである。∎

### 補題RED（内部 a の排出）

§2 の単位 J について `J°=(π(u_J),π(v_J))` とおく。このとき

**`a^{l'} π(u_J) a^{g'} π(v_J) a^{r'}∈L`**、`l',g',r'≥1`、a 総数 `N−δ_J`。

すなわち J° は欠損 `δ_J` の a-free 単位として (Single) を満たす。

*証明。* J の Single 語は ON-loc の形で、a 連数は高々 `ι_J+3`、a 総数は `N−δ_J=(N−h_J)+ι_J≥ι_J+4`。よって各ブロック z（`u_J`,`v_J` を a 連で区切った各片）について `a z≡z a`。`u_J=z_0a^{i_1}z_1⋯` の a を左から順に、`z a→a z` の置換で成分の左外へ出す。`a^{i_2}` は `z_1`、次に `z_0` を越える（各ブロック自身の合同を使い、合流後のブロックの合同は要らない）。`v_J` も同様に中央の連へ出す。置換は a 総数を変えず、外側の連は減らない。∎

### 補題SEED（種の還元）

B,C の合同 `a z≡z a` は全文脈で有効なので、Seed 語の中の同じ因子 `z a` に適用できる。内部 a をすべて成分の左外へ出すと、`B°,C°` の交錯（入れ子）語で a 総数 `N−δ_B−δ_C≥2` のものが得られる。成分の順序は変わらないので、交錯は交錯、入れ子は入れ子のままである。∎

## 4. 定理

**定理。** §2 の仮定の下で `χ≥2`（χ は `π` 後の c 指数の最大値）とする。非 a 総 Parikh が等しい二つの許容多重集合の δ 和は一致する。

*証明。* RED と SEED により、`{J°}` は a-free 単位の族として第2回 MS の前提（Single、Seed、a 室）を欠損 δ で満たす。室の仮定は追補1の (R1)(R2) である。追補1の定理を適用する。非 a Parikh は π で不変。∎

**内部 a 数が異なる場合。** `h_m=δ_m+ι_m` なので、h 和が一致するのは内部 a 数の和も等しいときに限る。剛性が成り立つ量は δ である。

**止まる箇所はないが、依存は三層ある。** (i) 第2回 MS・MX（監査済み）、(ii) 追補1の補題RC・CH（未監査）、(iii) 本報告の ON-loc・RED・SEED。(iii) は短いが、(ii) の監査が通ることが前提である。

## 5. 位置づけ

- **問いの文言との対応**：補題CH は `b^t` を任意の非空語 β（たとえば `b^t a^i`）に替えても文字列等式として成立し、c 連の汲み上げ自体は内部 a 付きでも通る。しかし MX の正規形は `b^{p}a^{i}` の列を保存するので合流しない。合流には結局 `a b^p≡b^p a` が要り、それは ON-loc が与える。したがって還元を先に行うのが正しい順序である。
- **第2回監査の指摘との関係**：「内部 a があると外側指数 `N−d_B−d_C` が実際の外側 a 量と一致しない」という指摘は、還元後の a-free 単位では生じない。内部 a 付きの MS を直接証明してはいない。
- **P2+ との関係**：P2+ は ON の大域形で単色ブロックを正規化した。今回は局所形だけを使い、混合ブロック `b^pc^q` を許す。扱える成分は「`b^pc^q` への a 挿入」まで広がり、P2+ と同じ射程になる。
- **木由来版**：Astra §5.8 の会計（`k_J=h_J`、a 連数≤`α_J+3`、種の余剰が自動）は同じ形で使えるはずだが、今回は**未精査**。
- **射程外**：`χ=1`、a 消去後が `b^pc^q` 型でない成分、一般 P_tree、一般 AB、非可換 U、正式 `op:fanout-two` は OPEN のまま。

## 6. 次に残る最小課題（1件）

**成分形の一般化の最小例：第一成分が `bcb` 型（`π(u)=b^pc^qb^{p'}`）の単位。** MS は成分の形に依らないので語列加法性は得られる。残るのは、補題CH で伸ばした c 連から `c b^t≡b^t c` を全ブロックについて導けるか（MX の「両側を c 連に挟まれる」条件が端の b ブロックで破れる）である。これが通れば、a-free 成分の形の制限そのものが外れる。
