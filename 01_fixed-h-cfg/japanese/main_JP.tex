\begin{abstract}
本論文では，有限モノイドへの準同型 $h:\Sigma^*\to M$ の核
$\sim_h$ の下で文脈自由言語の分布学習を研究する．同じ $h$-値をもち，
一つの文脈を共有する非空因子は，すべての文脈を共有することを要求する．
固定 $h$ に対し，集合駆動型再構成作用素 $\mathcal B_h$ は文脈自由
$\sim_h$-代入可能標的を有限個の正例証拠から厳密に再構成し，別の保守的
逐次学習器はすべての非空標的を Gold の意味で極限同定する．再構成と各更新は
多項式時間である．標準証拠の大きさは後で導入する有限な標的側精密化の
パラメータによって制御されるが，このパラメータは通常の文法厚みより
指数的に大きくなり得る．一つの固定二元型付けに対しては，固定-$h$ クラス
全体で妥当な集合駆動型再構成作用素の特徴データを，縮約済み CFG サイズと
通常の文法厚みの多項式で一様に抑えることはできない．これに対し，任意の
固定接頭辞--接尾辞窓 $(k,\ell)$ では，対応する型付けが Yoshinaka の
$(k,\ell)$-代入可能性をちょうど表し，縮約済み CFG サイズと通常の厚みに
関して多項式の特徴データを得る．任意の固定 $h$ の線形標的では，線形 CFG
サイズに関して多項式の特徴データを得る．さらに，適切な固定準同型に対し，
どの固定窓クラスにも属さない正則・非正則線形・非線形文脈自由の標的を与え，
一種類の括弧の Dyck 言語がどの固定型付けクラスにも属さないことを示す．
\end{abstract}

\section{序論}

\subsection{背景と動機}

Gold~\cite{gold1967} は，すべての有限言語と少なくとも一つの無限言語を含む
言語クラスは，正例データのみから極限同定できないことを示した．文脈自由言語では，
比較してよい部分文字列を文脈間で制限する分布学習により正の結果が回復される．
古典的な例として Clark--Eyraud の代入可能性~\cite{clark-eyraud2007} と
Yoshinaka の $(k,\ell)$-代入可能性~\cite{yoshinaka2008} がある．一般的背景は
de~la~Higuera~\cite{higuera2010} を，$k$-valued 範疇文法の正例学習可能性は
Kanazawa~\cite{kanazawa1996} を参照されたい．

本論文では，この研究計画の可認識合同関係版を考える．
$h:\Sigma^*\to M$ を有限モノイドへの準同型とし，$\sim_h:=\ker h$ とする．
$x\in\Sigma^*$ に対し
$\D_L(x):=\{(u,v):uxv\in L\}$
と書く．言語 $L$ が \emph{$\sim_h$-代入可能}であるとは，非空の $x,y$ について
$h(x)=h(y)$ かつ $\D_L(x)\cap\D_L(y)\ne\emptyset$ ならば
$\D_L(x)=\D_L(y)$ が成り立つことをいう%
\footnote{Clark--Eyraud では $a^+$ が代入可能として扱われるが，
$\lambda$ 自身を比較対象に含めると $a^+$ は除外される．Clark~\cite{clark2013}
も参照されたい．}．文脈自由な $\sim_h$-代入可能言語のクラスを $\Ccf{h}$ と書き，
これを \emph{fixed-$h$ slice} と呼ぶ．したがって，分布の完全な一致を要求するのは，
固定された有限代数的比較の下ですでに一致する因子だけである．

可認識合同関係は自然な有限型付けを与える．
$\mathsf{Acc}\subseteq M$ に対して $L=h^{-1}(\mathsf{Acc})$ が有限モノイド準同型 $h:\Sigma^*\to M$ で認識されるなら，同じ $h$-値を
もつ語は同じ分布をもつので，すべての正則言語は第~\ref{sec:framework}節で定義する
より広いクラス $\mathsf{RS}$ に属する．ただし本論文の学習結果で用いるのは
\emph{固定-$h$} の状況であり，一つの準同型をクラス $\Ccf{h}$ 全体で一様に固定する．
これは Yoshinaka の階層で一つの組 $(k,\ell)$ を固定することに対応する．

この見方は，有用な有限型付けを選ぶ問題と，型付けが与えられた後に学習する問題を
分離する．さらに，固定有限モノイド型付けは，一つの接頭辞--接尾辞窓より広い有限比較を
一つの学習機構のまま扱える．独立な有限特徴は積準同型で合成でき，
第~\ref{sec:linear}--\ref{sec:boundaries}節では，どの固定窓クラスにも属さない
正則・非正則線形・非線形文脈自由の例を与える．一方，無界カウンタや Dyck 型の挙動は，
文脈的に異なる因子を無限に強制し，どの有限型付けでも捉えられない場合がある．
この観点は，外部から与えられる型付け・領域バイアスを用いるオートマトン推論
~\cite{coste-typing2004} と方法論的に関連するが，本論文の $h$ は出現ごとの
オートマトン状態ではなく終端因子に合成的に作用する．

補完的な比較として control-set 学習がある．Takada の方法は，固定文法の生成規則列を
正則制御言語で符号化して標的を表す~\cite{takada1988,takada1995}．関連する正例学習
ではこのような制御に追加制限を課す~\cite{koshiba-makinen-takada1997}．
これに対し，本論文の固定準同型は終端因子に型を与え，比較してよい因子を制限する．
ここでは位置づけのためにこの相違を述べるだけで，両方法論の同値性・包含関係・
一般的なクラス分離は主張しない．

\subsection{貢献と主要結果}

本論文の主要な貢献は三つである．

\begin{enumerate}[label=\textup{(\arabic*)},leftmargin=2.4em]
\item \emph{固定 $h$ に対する学習．}
集合駆動型作用素 $\mathcal B_h$ は，$\Ccf{h}$ の任意の標的を有限個の
標準正例証拠から厳密に再構成する．別の保守的逐次学習器 $\mathcal A_h$ は
すべての非空標的を Gold の意味で同定し，再構成と各更新は蓄積標本に関して
多項式時間である．

\item \emph{定量的境界．}
任意の固定 $h$ では，生成語型付け後の最短生成語は元の文法より指数的に長くなり得る．
一つの固定二元型付け $h_\circ$ に対し，$\Ccf{h_\circ}$ 全体で特徴標本をもつ
集合駆動型再構成作用素には，縮約済み CFG サイズと元の文法の最短生成語長の
多項式による特徴データ上界は存在しない．一方，任意の固定窓 $(k,\ell)$ では
そのような上界が成立し，任意の固定 $h$ の線形標的では線形文法サイズに関して
多項式の特徴データが得られる．

\item \emph{表現力上の位置．}
適切な固定準同型は，どの固定窓クラスにも属さない正則・非正則線形・非線形
文脈自由の標的を許す．一種類の括弧の Dyck 言語は $\mathsf{RS}$ の外にあり，
$\mathsf{RS}\cap\mathrm{CFL}$ は Clark の congruential family に真に含まれる．
\end{enumerate}

\section{準備}
\label{sec:prelim}

$\Sigma$ を有限アルファベットとし，$\Sigma^*$ を単位元 $\lambda$ をもつ自由モノイドとする．また $\Sigma^+:=\Sigma^*\setminus\{\lambda\}$ とおく．対 $(u,v)\in\Sigma^*\times\Sigma^*$ を \emph{終端文脈} と呼ぶ．$L\subseteq\Sigma^*$ と $x\in\Sigma^*$ に対し，$L$ における $x$ の \emph{分布} を
$\D_L(x):=\{(u,v)\in\Sigma^*\times\Sigma^*:uxv\in L\}$
と定める．$L$ の \emph{構文合同関係} は，$x,y\in\Sigma^*$ に対して $x\equiv_L y \Longleftrightarrow \D_L(x)=\D_L(y)$ により定める．$x\equiv_L y$ のとき，$x$ と $y$ は \emph{構文合同} であるという．

語 $w\in\Sigma^*$ と文字 $a\in\Sigma$ に対し，$|w|_a$ は $w$ における $a$ の出現回数を表す．

文脈自由文法（CFG）は有限非終端記号集合 $V$，開始記号 $S\in V$，および $A\in V$, $\alpha\in(V\cup\Sigma)^*$ に対する生成規則 $A\to\alpha$ からなる組 $G=(V,\Sigma,P,S)$ である．\emph{文形式}とは $(V\cup\Sigma)^*$ の任意の語である．$G$ における一段階導出を $\alpha\Rightarrow_G\beta$ と書き，その反射推移閉包を $\Rightarrow_G^*$ と書く．したがって
$L(G):=\{w\in\Sigma^*:S\Rightarrow_G^*w\}$.
$A\in V$ に対して
$L_G(A):=\{w\in\Sigma^*:A\Rightarrow_G^*w\}$
とおく．非終端記号 $X\in V$ に対し，$S\Rightarrow_G^*uXv$ が成り立つとき，終端文脈 $(u,v)$ を $G$ における $X$ の \emph{終端到達文脈} と呼ぶ．非終端記号が $S$ から到達可能な文形式中に現れるとき \emph{到達可能} であるといい，終端語を導出するとき \emph{生産的} であるという．到達可能性または生産性の少なくとも一方を欠く非終端記号を \emph{無用} といい，$\lambda$ を導出する非終端記号を \emph{空語導出可能（nullable）} という．$A,B\in V$ に対する生成規則 $A\to B$ を \emph{単位規則} という．\emph{単位閉包}とは，単位生成規則が非終端記号上に誘導する関係の反射推移閉包である．すべての非終端記号が到達可能かつ生産的である文法を \emph{縮約済み} という．非空言語を生成する文法について，その \emph{トリム}とは，すべての無用な非終端記号と，それらに接続する生成規則を削除して得られる部分文法をいう．各右辺に高々一つの非終端記号しか現れない CFG を \emph{線形} という．\emph{二分化}とは，新たな非終端記号を用いて長い右辺を同値な二項生成規則の鎖へ置き換えることをいう．
$\mathrm{CFL}$ を文脈自由言語全体のクラスとする．任意の有限表現 $r$ に対し，$|r|$ は固定した妥当な符号化の長さを表すものとする．文法については，これは通常の生成規則中の記号数と多項式の範囲で同値である．Yoshinaka の固定窓解析~\cite{yoshinaka2008} に従い，縮約済み文法 $G=(V,\Sigma,P,S)$ について\emph{厚み}パラメータを
\[
 \tau_G:=\max_{A\in V}\min\{\,|w|:A\Rightarrow_G^*w,\ w\in\Sigma^*\,\}
\]
と定める．すなわち $\tau_G$ は，各非終端記号の最短終端生成語の長さを取り，その最大値をとったものである．

\subsection{正例データからの学習}\label{sec:learning}

Gold の explanatory model~\cite{gold1967} を用いる．$H_0$ を，一つの開始記号をもち生成規則をもたない固定 CFG とし，$L(H_0)=\emptyset$ とする．以下のテキスト規約は非空の標的言語に限定する．空言語はこのテキストに基づく Gold の記述から除外し，別途 $H_0$ により表す．同値に，通常の pause 記号をテキストに加えることで空標的を含めることもできるが，余分な記法を避けるためにここでは非空テキスト規約を用いる．非空言語 $L$ に対し，\emph{テキスト}とは，$L$ の各語が少なくとも一度は現れる $L$ 上の無限列 $T=(w_1,w_2,\ldots)$ である．$T[n]=(w_1,\ldots,w_n)$ および $K_n:=\{w_1,\ldots,w_n\}$ と書く．学習器 $\mathcal A$ が非空言語 $L$ を \emph{極限同定}するとは，$L$ の任意のテキスト $T$ に対して，ある $n_0$ と文法 $H$ が存在し，すべての $n\ge n_0$ について $\mathcal A(T[n])=H$ かつ $L(H)=L$ が成り立つことをいう．したがって，仮説表現そのものが最終的に安定する．逐次学習器が \emph{保守的} であるとは，新たに提示された正例データが現在の仮説によって生成されない場合にのみ，その現在の仮説を変更することをいう．

この逐次学習器とは別に，集合駆動型の有限標本作用素 $\mathcal B$ を考える．ここで $\mathcal B(K)$ は有限集合 $K$ のみに依存し，提示順序や重複回数には依存しない．任意の有限標本 $K$ に対して $K\subseteq L(\mathcal B(K))$ が成り立つとき，$\mathcal B$ は \emph{標本整合的} であるという．有限集合 $C\subseteq L$ が $\mathcal B$ に対する \emph{特徴標本} であるとは，任意の有限 $K$ について $C\subseteq K\subseteq L$ ならば $L(\mathcal B(K))=L$ が成り立つことをいう．これは de~la~Higuera の多項式文法推論枠組み~\cite{higuera1997} における有限標本部分である．標本サイズを
$\|K\|:=\sum_{w\in K}(|w|+1)$
で測る\footnote{$+1$ は，$K=\{\lambda\}$ のような非空標本のサイズが $0$ になることを防ぐ．また $|K|\le \|K\|$ となるため，正例数も同じサイズ尺度で抑えられる．}．したがって $\lambda$ も 1 を寄与する．以下の定量的結果では，$\mathcal B(K)$ の多項式時間構成と，多項式サイズの特徴データを組み合わせる．

\subsection{固定有限モノイド型付け}\label{sec:fixed-typing}

有限モノイド $M$ と準同型 $h:\Sigma^*\to M$ を固定する．これらは $M$ の乗法表および各 $a\in\Sigma$ に対する文字像 $h(a)$ によって表現される．したがって $h(w)$ は左から右への積によって $O(|w|)$ 時間で計算できる．以下で固定準同型が \emph{効率的に計算可能} であるというのはこの意味である．

\begin{definition}[固定-$h$ 代入可能性]\label{def:hsubst}
言語 $L\subseteq\Sigma^*$ が \emph{$\sim_h$-代入可能} であるとは，すべての $x,y\in\Sigma^+$ について，$h(x)=h(y)$ と $\D_L(x)\cap\D_L(y)\ne\varnothing$ から $\D_L(x)=\D_L(y)$ が従うことをいう．
\end{definition}
空語は内部の代入可能因子としては用いない．$\lambda\in L$ の場合には，再構成において開始記号を通じて別途処理する．

非空内部因子 $x$ に対して，$h(x)$ をその \emph{生成語型} と呼ぶ．文脈自由 $\sim_h$-代入可能言語のクラスを $\Ccf{h}$ と書き，
\[
\Clin{h}:=\{L\in\Ccf{h}:L\text{ はある線形 CFG により生成される}\}
\]
と定める．したがって $\Clin{h}$ は線形言語からなる部分クラスである．以下の多項式データ上界は，標的について選ばれた線形 CFG 表現を基準に測る．後で構成される再構成仮説自体は線形文法である必要はない．

\section{固定可認識代入可能性}
\label{sec:framework}

固定 $h$ に対し
$\mathsf{RS}_h:=\{L\subseteq\Sigma^*:L\text{ は $\sim_h$-代入可能}\}$
とおく．fixed-$h$ slice は
$\Ccf{h}=\mathsf{RS}_h\cap\mathrm{CFL}$ であり，$\Clin{h}$ はそのうち
線形 CFG で生成される言語からなる．表現力の比較に限り，
$h$ を $\Sigma^*$ 上の有限モノイド準同型全体に動かして
$\mathsf{RS}:=\bigcup_h\mathsf{RS}_h$ とする．アルファベットを明示するときは
$\mathsf{RS}_h(\Gamma)$，$\mathsf{RS}(\Gamma)$ と書き，以下の包含は
アルファベットごとに解釈する．学習結果は常に一つの固定 $h$ を対象とする．
非空アルファベット上では，$\mathsf{RS}$ も
$\mathsf{RS}\cap\mathrm{CFL}$ も正例データから極限同定できない．
命題~\ref{prop:regular-auto} により両者はすべての有限言語と $\Sigma^*$ を含むため，
Gold の定理が適用されるからである．

型付けの精密化には単調性がある．$\ker h'\subseteq\ker h$ ならば，
$h'$ は比較を要求する因子対を減らすので
$\mathsf{RS}_h\subseteq\mathsf{RS}_{h'}$ である．ただし精密化は，
後の定量解析で使う型付き文法を大きくし得る．二つの有限型付け $h,g$ に対し
$\ker(h\times g)=\ker h\cap\ker g$ だから
$\mathsf{RS}_h\cup\mathsf{RS}_g\subseteq\mathsf{RS}_{h\times g}$ であり，
窓情報と別の有限特徴を標的ごとに型付けを変えずに合成できる．

$\ker h$ を $\Sigma^+$ に制限した関係が構文合同 $\equiv_L$ を精密化するなら
$L\in\mathsf{RS}_h$ である．逆は通常の代入可能性ですでに成り立たない．
中心記号付き言語
$P:=\{a^ncb^n:n\ge0\}$ を考える．以下で採用する非空因子規約の下で
$P$ は Clark--Eyraud 代入可能だが，$\equiv_P$ は無限指数である．
実際 $1\le r<s$ に対して文脈 $(a,cb^{r+1})$ は $a^r$ と $a^s$ を区別する．
$\Sigma^+$ への制限は本質的であり，自明モノイドの下で $\lambda$ まで比較すると
$a^+$ のような例まで誤って除外される．

\begin{proposition}\label{prop:regular-auto}
言語が正則であることと，ある有限モノイド $M$ への準同型
$h:\Sigma^*\to M$ と $\mathsf{Acc}\subseteq M$ に対して
$h^{-1}(\mathsf{Acc})$ の形に書けることは同値である．さらに任意の固定 $h$ と
$\mathsf{Acc}\subseteq M$ に対し，$h^{-1}(\mathsf{Acc})$ は
$\sim_h$-代入可能である．従ってすべての正則言語は $\mathsf{RS}$ に属する．
\end{proposition}

\begin{proof}
最初の主張は有限モノイドによる正則言語の標準的特徴づけである~\cite{pin2025}．
$L=h^{-1}(\mathsf{Acc})$ かつ $h(x)=h(y)$ なら，すべての $u,v$ に対し
$h(uxv)=h(uyv)$ なので $\D_L(x)=\D_L(y)$ である．
\end{proof}

\subsection{古典的特殊場合}

Clark--Eyraud の定義~5 は一般の文字列について量化している
~\cite{clark-eyraud2007}．ここでは Clark~\cite{clark2013} が明示する
非空因子規約を採用し，Clark--Eyraud の設定で論じられる $a^+$ のような例も保つ．
すべての $x,y\in\Sigma^+$ について
$\D_L(x)\cap\D_L(y)\ne\emptyset$ から $\D_L(x)=\D_L(y)$ が従うとき，
$L$ を \emph{Clark--Eyraud 代入可能}と呼ぶ．これは定義~\ref{def:hsubst} の
自明モノイドの場合，従って Yoshinaka の $(0,0)$ の場合にちょうど一致する．

特に，一元モノイドをとれば，すべての Clark--Eyraud 代入可能言語は
$\mathsf{RS}$ に属する．

$k,\ell\ge0$ に対し，$\pref_k(w)$ と $\suf_\ell(w)$ をそれぞれ長さ
$\min\{k,|w|\}$ の接頭辞と長さ $\min\{\ell,|w|\}$ の接尾辞とする．
特に $\pref_0(w)=\suf_0(w)=\lambda$ であり，短い語については語全体を返す．一般の文脈記法との衝突を避けるため
Yoshinaka の窓変数を改名して，$L$ が \emph{$(k,\ell)$-代入可能} であるとは，
$p\in\Sigma^k$, $q\in\Sigma^\ell$ および
$x_1,x_2,y_1,y_2,z_1,z_2\in\Sigma^*$ で $py_1q,py_2q\ne\lambda$ のとき
\[
\begin{split}
&x_1py_1qz_1\in L,\quad x_1py_2qz_1\in L,\quad
x_2py_1qz_2\in L\\
&\hspace{35mm}\Longrightarrow\quad x_2py_2qz_2\in L
\end{split}
\]
が成り立つことをいう．

\begin{proposition}\label{prop:yl-special}
任意の固定 $k,\ell\ge0$ に対して有限モノイド準同型 $h_{k,\ell}$ が存在し，
任意の $L\subseteq\Sigma^*$ について，$L$ が $(k,\ell)$-代入可能であることと
$\sim_{h_{k,\ell}}$-代入可能であることは同値である．
\end{proposition}

\begin{proof}
$m_0:=\max\{1,k+\ell\}$ とし，$|w|<m_0$ なら $h_{k,\ell}(w):=w$，
それ以外では，二つの場合を区別するタグを付けて
$h_{k,\ell}(w):=\langle\pref_k(w),\suf_\ell(w)\rangle$ とする．
有限像を $M_{k,\ell}:=h_{k,\ell}(\Sigma^*)$ と書く．短い語 $x,y$ について
\[
\begin{aligned}
x\cdot y&:=h_{k,\ell}(xy),&
x\cdot\langle p,q\rangle&:=\langle\pref_k(xp),q\rangle,\\
\langle p,q\rangle\cdot y&:=\langle p,\suf_\ell(qy)\rangle,&
\langle p,q\rangle\cdot\langle p',q'\rangle&:=\langle p,q'\rangle
\end{aligned}
\]
と積を定める．すると
$h_{k,\ell}(xy)=h_{k,\ell}(x)\cdot h_{k,\ell}(y)$ であり，全射性から結合律が従い，
$h_{k,\ell}(\lambda)$ が単位元になる．

非空 $s,t$ の型が等しいことは，$s=t$ であるか，共通の長さ $k$ の接頭辞 $p$ と
長さ $\ell$ の接尾辞 $q$ を用いて $s=py_1q$, $t=py_2q$ と書けることを意味する
（$k=\ell=0$ も含む）．$L$ が $(k,\ell)$-代入可能なら，共通文脈と片方の任意の
文脈から Yoshinaka の四語条件を適用し，対称性により分布が一致する．逆に
Yoshinaka の前提では $s:=py_1q$, $t:=py_2q$ は非空で，長語側の符号化に属するため
同じ $h_{k,\ell}$-型をもつ．固定-$h_{k,\ell}$ 代入可能性が第三の文脈を移送し，
第四の語を与える．
\end{proof}

\phantomsection\label{crit:kl}
\paragraph{固定窓代入可能性の反例基準．}
$m_0:=\max\{1,k+\ell\}$ とする．$s,t$ が長さ $m_0$ 以上で，同じ長さ $k$ の
接頭辞と長さ $\ell$ の接尾辞をもち，共通文脈をもつ一方で分布が異なるなら，
$L$ は $(k,\ell)$-代入可能ではない．最初の三条件から
$h_{k,\ell}$-型が等しく共通文脈をもち，最後の条件が
$\sim_{h_{k,\ell}}$-代入可能性に反するからである．

従って固定 $(k,\ell)$ クラスはちょうど $\mathsf{RS}_{h_{k,\ell}}$ であり，
第~\ref{sec:fixed-window-thick}節でその多項式厚み付きデータ上界を与える．
$k=\ell=0$ では $h_{0,0}$ は $\lambda$ と非空語を区別するだけで，
一元モノイドと同じ代入可能性条件を誘導する．アルファベット $\Gamma$ に対し
\[
\mathsf{KL}(\Gamma):=
\bigcup_{k,\ell\ge0}
\{L\subseteq\Gamma^*:L\text{ は $(k,\ell)$-代入可能}\}
\]
とし，$\mathsf{KL}:=\mathsf{KL}(\Sigma)$ と略記する．

\subsection{主定理}

\begin{theorem}[固定-$h$ 学習定理]\label{thm:main}
効率的に計算可能な有限モノイド準同型 $h:\Sigma^*\to M$ を固定する．
集合駆動型再構成作用素 $\mathcal B_h$ と保守的逐次学習器 $\mathcal A_h$ が存在し，
次を満たす．
\begin{enumerate}[label=\textup{(\roman*)},nosep]
\item $\mathcal B_h$ は標本整合的で，$\mathcal B_h(K)$ は $\|K\|$ の多項式時間で構成できる．
\item すべての $L\in\Ccf{h}$ は $\mathcal B_h$ に対する有限特徴標本をもつ．
\item $\mathcal A_h$ はすべての非空 $L\in\Ccf{h}$ を Gold の意味で同定し，
各更新はそれまでに見たデータの多項式時間で行える．
\item 固定 $(k,\ell)$ に対し $h=h_{k,\ell}$ とすると，(ii) の標本は，
標的を表す任意の縮約済み CFG $R$ について $|R|$ と $\tau_R$ の多項式サイズに選べる．
\item 任意の固定 $h$ と $L\in\Clin{h}$ に対し，(ii) の標本は，
$L$ を表す任意の線形 CFG $R$ について $|R|$ の多項式サイズに選べる．
\end{enumerate}
項目~(iv)--(v) の定量的機構と，一般の固定型付けに対するその限界は，
第~\ref{sec:typed-thickness}--\ref{sec:linear}節で扱う．
\end{theorem}

クラス $\Ccf{h}$ はすべての有限言語を含むわけではない．
$h(x)=h(y)$ を満たす相異なる非空語 $x,y$ を取り，
$|r|>\max\{|x|,|y|\}$ とする．$\{x,y,rx\}$ では $x,y$ は空文脈を共有するが，
$(r,\lambda)$ は $x$ だけの文脈である．

\section{再構成作用素と逐次学習器}
\label{sec:algo}

\subsection{有限標本からの再構成}
有限標本 $K\subseteq\Sigma^*$ に対し，
$\widehat V(K):=\{[x:u,v]:uxv\in K,\ x\in\Sigma^+\}$
とおく．これらは構文的三つ組である．すなわち規約として，$[x:u,v]=[x':u',v'] \Longleftrightarrow x=x',\ u=u',\ v=v'$ とする．特に，同じ標本語から生じる場合であっても，因子文字列または文脈文字列が異なる二つの出現は，異なる仮説非終端記号である．文法 $\mathcal B_h(K)=\widehat G(K)$ は，非終端記号集合 $\widehat V(K)\cup\{\widehat S\}$ と開始記号 $\widehat S$ をもつ．表示されるすべての角括弧付き非終端記号が $\widehat V(K)$ に属する場合に，次の生成規則をもつ．
\[
\begin{array}{rll}
(R1)&[xy:u,v]\to[x:u,yv][y:ux,v],&x,y\in\Sigma^+,\\[1mm]
(R2)&[x:u,v]\to[x:u',v'],&uxv,u'xv'\in K,\\[1mm]
(R3)&[x:u,v]\to[x':u,v],&h(x)=h(x'),\\[1mm]
(R4)&[a:u,v]\to a,&a\in\Sigma,\\[1mm]
(R5)&\widehat S\to[w:\lambda,\lambda],&w\in K\cap\Sigma^+.
\end{array}
\]
$\lambda\in K$ のときは，規則~(R5) に $\widehat S\to\lambda$ も含める．直観的には，$[x:u,v]$ は観測された因子 $x$ を文脈 $(u,v)$ の中で置き換える候補を表す．$\sim_h$-代入可能な標的に対しては，以下の健全性不変量により，導出されるすべての語が $x$ と同じ $h$-型をもち，分布的に交換可能であることが保証される．規則~(R2) は文脈輸送規則である．同じ観測因子は，その因子自身が観測された任意の文脈で表現できる．二つの周囲文脈の $h$-型に関する条件は不要である．規則~(R3) は，一つの固定生成語型の内部で代表元を変更する．その条件 $h(x)=h(x')$ は，健全性不変量の生成語型部分を保存するためにまさに用いられる．その不変量はその後規則~(R1) および~(R2) で代入可能性を適用するときに用いられる．

\begin{lemma}[標本整合性]\label{lem:sample-consistency}
任意の有限正例標本 $K$ に対して，$K\subseteq L(\mathcal B_h(K))$ が成り立つ．
\end{lemma}
\begin{proof}
$w=a_1\cdots a_m\in K\cap\Sigma^+$ とする．規則~(R5) により $[w:\lambda,\lambda]$ に入る．この $w$ の出現を任意に二分木分解し，それに沿って規則~(R1) を繰り返し適用すると，一文字因子へ到達する．中間で必要となる観測非終端記号はすべて，同じ標本語の因子と，それによって誘導される文脈から生じるため存在する．最後に規則~(R4) が $a_1\cdots a_m$ を出力する．$\lambda\in K$ の場合は，開始規則がこれを直接出力する．
\end{proof}

また $K\subseteq K'$ ならば，$K$ から作られたすべての観測非終端記号と規則~(R1)--(R5) のすべてのインスタンスは $K'$ に対しても残る．したがって $\widehat G(K)$ は $\widehat G(K')$ の部分文法であり，
$L(\mathcal B_h(K))\subseteq L(\mathcal B_h(K'))$.
ゆえに保守的学習器が再構成を行うとき，仮説言語は拡大することしかない．

\begin{theorem}[健全性]\label{thm:soundness}
$K\subseteq L$ かつ $L$ が $\sim_h$-代入可能ならば，$L(\widehat G(K))\subseteq L$ である．
\end{theorem}

\begin{proof}
$[x:u,v]$ を根とする導出木の高さについて帰納法を行い，次を同時に証明する．
\begin{equation}\label{eq:soundness-invariant}
 [x:u,v]\Rightarrow_{\widehat G(K)}^*w
 \quad\Longrightarrow\quad
 uwv\in L\ \text{かつ}\ h(w)=h(x).
\end{equation}
規則~(R1)--(R4) は消去生成規則を含まず，すべての語彙規則は一つの終端記号を出力する．したがって，開始記号以外の仮説非終端記号から導出されるすべての終端語は非空である．特に，以下で定義~\ref{def:hsubst} を適用する語 $w,w_1,w_2$ は $\Sigma^+$ に属する．規則~(R4) の場合は明らかである．規則~(R3) については，帰納法の仮定から $h(w)=h(x')=h(x)$ が得られ，またすでに $uwv\in L$ が得られる．規則~(R2) については，帰納法の仮定から $u'wv'\in L$ および $h(w)=h(x)$ が得られる．さらに $[x:u',v']$ と $[x:u,v]$ は $\widehat V(K)$ に属するので，その定義から $u'xv',uxv\in K\subseteq L$ である．したがって $x$ と $w$ は文脈 $(u',v')$ を共有し，代入可能性により $\D_L(x)=\D_L(w)$ を得る．よって $uwv\in L$ である．

規則~(R1) について，導出語を $w_1w_2$ と書く．二つの帰納法の仮定から
$uw_1yv\in L$, $uxw_2v\in L$,
$h(w_1)=h(x)$, $h(w_2)=h(y)$
が得られる．$uxyv\in K$ なので，$x$ と $w_1$ は文脈 $(u,yv)$ を共有し，同じ型をもつ．したがって両者の分布は一致する．第二の帰納法の仮定により $(u,w_2v)\in\D_L(x)$ である．この文脈に分布の等しさを適用すると $uw_1w_2v\in L$ を得る．さらに帰納法の仮定から $h(w_1w_2)=h(xy)$ である．これで~\eqref{eq:soundness-invariant} が証明された．開始規則を用いれば $L(\widehat G(K))$ に対する主張が従う．$\lambda$ は $\lambda\in K\subseteq L$ の場合にのみ存在する．
\end{proof}

\subsection{逐次学習器}

$\mathcal B_h$ を各データ到着時に再計算しても，文法表現は一般には安定しない．
たとえば $L=\{a^ncb^n:n\ge0\}$ では，長い正例から
$[a^ncb^n:\lambda,\lambda]$ のような新しい三つ組が生じる．
そこで Clark--Eyraud の Substitutable Grammar Learner (SGL, Algorithm~2)
および Yoshinaka の $(k,\ell)$-SGL (Algorithm~1) と同じ保守的ラッパーを用いる
~\cite{clark-eyraud2007,yoshinaka2008}．集合駆動型再構成と逐次学習の区別については
Eyraud--Heinz--Yoshinaka~\cite[Appendix]{eyraud-heinz-yoshinaka2016} も参照されたい．
固定空文法 $H_0$ から始め，$w_n$ を読んだ後
\[
 H_n:=
 \begin{cases}
 H_{n-1},&w_n\in L(H_{n-1}),\\
 \mathcal B_h(K_n),&w_n\notin L(H_{n-1}),
 \end{cases}
 \qquad
 \mathcal A_h(T[n]):=H_n
\]
とする．再構成は常に蓄積標本全体 $K_n$ を用いる．$\mathcal B_h$ は
集合駆動型だが，$\mathcal A_h$ が最終的に安定する文法は提示順序に依存し得る．
主張するのは，標的言語を生成する文法への最終的な構文的安定化だけである
（系~\ref{cor:ilt}）．実際，無限な $L\in\Ccf{h}$ のテキスト $T$ で
学習器が安定するとき，その時点までの標本語より長い $w\in L$ を選べる．
$T$ 上の極限文法は $[w:\lambda,\lambda]$ を含まないが，
$w$ を先頭に追加したテキストでは，最初の再構成以降の全仮説が
この非終端記号を含む．従って，同じ標的に対して異なる極限文法が得られる．

\section{生成語型付き精密化と有限証拠による完全性}
\label{sec:typing}

\subsection{標的の精密化と有限証拠}

再構成作用素と逐次学習器はすでに定義済みである．ここでは完全性の証明のためだけに標的側の精密化を導入する．目標は，対応する正例証拠が出現した後に，仮説文法が有限個の型付き標的導出を模倣できることを示すことである．次の標準形は証明上の道具としてのみ用いる．

\begin{definition}[開始記号分離二分標準形]
CFG $G=(V,\Sigma,P,S_0)$ が \emph{開始記号分離二分標準形}（SSBNF）にあるとは，$S_0$ がいかなる右辺にも現れず\footnote{開始記号を文全体の生成入口として内部の非終端から分離し，型付き精密化と $\lambda$ の特別扱いを単純に保つためである．}，すべての開始規則が $S_0\to A$ または $S_0\to\lambda$ の形であり，すべての非開始規則が $A\to a$ または $A\to BC$ の形であることをいう．
\end{definition}

任意の非空文脈自由言語は，標準的な開始記号分離，無用記号除去，開始記号以外での $\lambda$/単位規則除去，および二分化の手続きにより，同値な縮約済み SSBNF 文法をもつ．標的言語が空集合の場合は自明である．

$L\in\Ccf{h}$ に対する縮約済み SSBNF 文法を $G=(V,\Sigma,P,S_0)$ とする．その \emph{完全生成語型付き精密化} は，開始記号 $\widetilde S$ と，$A\in V\setminus\{S_0\}$, $\mu\in M$ に対する非開始記号 $A_\mu$ をもつ．以下，型添字の併置は $M$ における積を表す．すなわち $\mu\nu=\mu\cdot\nu$ とする．規則は次である．
\[
\begin{array}{ll}
\widetilde S\to A_\mu & (S_0\to A\in P,\ \mu\in M),\\
\widetilde S\to\lambda & (S_0\to\lambda\in P),\\
A_{h(a)}\to a & (A\to a\in P),\\
A_{\mu\nu}\to B_\mu C_\nu & (A\to BC\in P,\ \mu,\nu\in M).
\end{array}
\]
\emph{型付き精密化} $\widetilde G=(\widetilde V,\Sigma,\widetilde P,\widetilde S)$ は，
この文法の縮約部分とする．したがって，規約として $\widetilde G$ のすべての記号は
到達可能かつ生産的である．

$\Sigma$ 上に順序を一つ固定し，それが誘導する \emph{shortlex} 順序を用いる．
すなわち短い語を先に置き，同じ長さなら辞書式順序で比較する．
$\widetilde G$ の各非開始記号 $X$ に対し，$\omega(X)$ をその shortlex 最小終端生成語
とし，これを $X$ の\emph{標準生成語}と呼ぶ．$\widetilde G$ は縮約済みなので
$\omega(X)$ は常に定義される．

生成語型の添字は完全性証明の規則~(R3) に必要である．証明では，型付き親記号の
標準生成語と，型付き子記号の標準生成語を連接した語とを比較する必要がある．
保持された型付き二項規則
$X=A_{\mu\nu}\to Y=B_\mu Z=C_\nu$ に対しては，後で証明する生成語不変量から
\[
 h(\omega(X))=\mu\nu
 =h(\omega(Y))h(\omega(Z))
 =h(\omega(Y)\omega(Z))
\]
が成り立ち，これが規則~(R3) を適用するための等式になる．

この分割の必要性は，型付け前の文法ですでに見える．
$h(w)=|w|\bmod 2$ とし，元の規則を
$A\to a\mid BC$, $B\to a$, $C\to a$ とする．$A$ の最短生成語として $a$ を
選べばその型は奇数である一方，$B,C$ の最短生成語の連接 $aa$ は偶数型である．
したがって，$A$ を生成語型で分割しなければ，対応する規則~(R3) の遷移は保証されない．
生成語型で分割することで必要な等式が不変量となる．一方で周囲の左文脈または右文脈
には型を付けない．再構成作用素がそのような型を一度も検査しないからである．

\begin{proposition}[型付き持ち上げと生成語不変量]\label{prop:typed-core}
型付き精密化は $L(\widetilde G)=L(G)$ を満たす．さらに，$X=A_\mu$ が
$\widetilde G$ の非開始記号であるとき，
$X\Rightarrow_{\widetilde G}^*w$ ならば $h(w)=\mu$ である．
\end{proposition}
\begin{proof}
型注釈を消去すれば，任意の型付き導出は $G$ の導出へ写る．逆に，$G$ の成功した
導出木の各非開始節点に，その終端生成語の $h$-型を注釈する．上で定めた終端規則と
二項規則は，それらの型のボトムアップ伝播則そのものである．したがって注釈付き木は
完全精密化の導出であり，成功した導出木に現れるすべての記号は trim 後も残る．
不変量は型付き導出についての帰納法から従う．
\end{proof}

$\widetilde G$ の各非開始記号 $X$ に対し，$X$ の終端到達文脈の中から
$|u_X|+|v_X|$ を最小化するものとして $\chi(X)=(u_X,v_X)$ を選び，同値な候補が
ある場合は $u_X$ の shortlex 順序，次に $v_X$ の shortlex 順序で決める．
$\chi(X)$ を $X$ の\emph{標準文脈}と呼ぶ．$\widetilde G$ は縮約済みなので，
このような終端到達文脈は存在する．実際，到達可能性により $X$ は到達可能な文形式中に
現れ，周囲の非終端記号の生産性により，その左側および右側のすべての記号を終端文字列へ
展開できる．命題~\ref{prop:typed-core} から $h(\omega(A_\mu))=\mu$ である．

有限証拠集合を
\begin{equation}\label{eq:W}
\begin{split}
\WitnessSet(\widetilde G):={}&
 \{u_X\omega(X)v_X:X\in\widetilde V\setminus\{\widetilde S\}\}\\
&\cup\{u_Xav_X:X\to a\in\widetilde P\}\\
&\cup\{u_X\omega(Y)\omega(Z)v_X:X\to YZ\in\widetilde P\}\\
&\cup\bigl(\{\lambda\}\text{ if }\lambda\in L\bigr)
\end{split}
\end{equation}
により定める．ここに表示したすべての語は $L$ に属し，集合は有限である．特に，
二項規則 $X\to YZ$ に対応する証拠語は
\[
\widetilde S\Rightarrow^*u_XXv_X\Rightarrow u_XYZv_X
\Rightarrow^*u_X\omega(Y)\omega(Z)v_X
\]
により正当化される．アンカーと終端規則証拠についても同様である．
$\WitnessSet(\widetilde G)$ の要素を \emph{標準正例証拠} と呼ぶ．
要素 $u_X\omega(X)v_X$ は $X$ の一つの標準出現を証拠づける $X$ の
\emph{アンカー} であり，他の語は終端または二項の \emph{規則証拠} という別役割がある．

\subsection{厳密再構成と Gold 収束}

\begin{theorem}[有限証拠からの完全性]\label{thm:complete}
非空言語 $L$ に対する任意の縮約済み SSBNF 文法を $G$ とし，固定準同型 $h$ に関するその型付き精密化を $\widetilde G$ とする．有限集合 $K$ が $\WitnessSet(\widetilde G)\subseteq K$ を満たすならば，$L\subseteq L(\widehat G(K))$ である．
\end{theorem}

ここが標的型付けが登場する箇所である．学習器とバッチ作用素は第~\ref{sec:algo}節ですでに定義されており，以下の証明は，それらの仮説非終端記号が生成語型付き標的非終端記号を模倣できることを示す．それ以外では，この主張は純粋に組合せ論的である．型付き文法と包含 $\WitnessSet(\widetilde G)\subseteq K$ だけを用い，代入可能性も追加仮定 $K\subseteq L$ も必要としない．

\begin{proof}
各非開始記号 $X$ に対し，$\widehat X:=[\omega(X):u_X,v_X]$ と書く．~\eqref{eq:W} のアンカー語により，$\widehat X$ は存在する．型付き導出 $X\Rightarrow^*w$ について帰納法を行い，$\widehat X\Rightarrow_{\widehat G(K)}^*w$ を証明する．

最初の規則が $X\to a$ であるとする．証拠 $u_Xav_X\in K$ により $[a:u_X,v_X]$ が存在する．$\omega(X)\ne a$ なら，$h(\omega(X))=h(a)$ なので規則~(R3) が $\widehat X$ を $[a:u_X,v_X]$ に変更する．$\omega(X)=a$ ならこの段階は不要である．その後規則~(R4) が $a$ を生成する．

最初の規則が $X=A_{\mu\nu}\to B_\mu C_\nu$ であるとする．$Y:=B_\mu$ および $Z:=C_\nu$ とおく．~\eqref{eq:W} の規則証拠により三つの観測非終端記号が得られ，規則~(R1) を適用して次を得る．
\begin{equation}\label{eq:binary-reconstruction}
 [\omega(Y)\omega(Z):u_X,v_X]
 \to[\omega(Y):u_X,\omega(Z)v_X]
      [\omega(Z):u_X\omega(Y),v_X].
\end{equation}
$h(\omega(X))=\mu\nu=h(\omega(Y)\omega(Z))$ なので，必要なら規則~(R3) により $\widehat X$ を~\eqref{eq:binary-reconstruction} の左辺へ変更する．すでに$\omega(X)=\omega(Y)\omega(Z)$であるならば，この段階は不要である．次に規則~(R2) により二つの子を $\widehat Y$ および $\widehat Z$ へ輸送する．これらはそれぞれ $Y,Z$ の標準文脈によって定まる．二つの部分導出は帰納法の仮定により完了する．

最後に，任意の非空 $w\in L$ は $\widetilde S\to X\Rightarrow^*w$ という持ち上げられた開始導出をもつ．開始規則そのものにより $(\lambda,\lambda)$ は $X$ の終端到達文脈である．その全長は $0$ であり最小なので，標準選択は $\chi(X)=(\lambda,\lambda)$ となる．そのアンカー $\omega(X)$ は $K$ に属するため，規則~(R5) が上記の導出を開始する．$w=\lambda$ の場合は~\eqref{eq:W} と規則~(R5) から直ちに従う．
\end{proof}

\begin{theorem}[厳密有限標本再構成]
\label{thm:reconstruction-fixed-h}
$L\in\Ccf{h}$ を非空とし，$G$ を $L$ の縮約済み SSBNF 文法，$\widetilde G$ をその型付き精密化とする．$\WitnessSet(\widetilde G)\subseteq K\subseteq L$ ならば，$L(\mathcal B_h(K))=L$ である．
\end{theorem}
\begin{proof}
定理~\ref{thm:soundness} と~\ref{thm:complete} を合わせればよい．
\end{proof}

したがって，任意の非空標的表現 $G$ について，集合 $\WitnessSet(\widetilde G)$ は第~\ref{sec:learning}節の意味で，$\mathcal B_h$ に関する $L(G)$ の特徴標本である．

定理~\ref{thm:reconstruction-fixed-h} は $\{\lambda\}$ を含むすべての非空標的を覆う．残る端点 $L=\emptyset$ については $C_L=\emptyset$ とおけば，$\mathcal B_h(\emptyset)$ は開始生成規則をもたない．これにより定理~\ref{thm:main} の項目~(ii) が確立される．

\begin{corollary}[Gold 同定]\label{cor:ilt}
有限モノイド $M$ への固定準同型 $h:\Sigma^*\to M$ に対し，学習器 $\mathcal A_h$ は $\Ccf{h}$ のすべての非空言語を正例データから同定する．より具体的には，任意の縮約済み SSBNF 標的文法 $G$ とその型付き精密化 $\widetilde G$ に対し，$\WitnessSet(\widetilde G)\subseteq K_{n_0}$ となったとき，段階 $n\ge n_0$ の範囲で生じうる仮説変更は高々一回である．
\end{corollary}

\begin{proof}
本論文のテキスト規約の下では，Gold の主張は非空標的を対象とする．$H_0$ は初期空仮説である．$L$ を非空とし，$T$ を $L$ のテキストとする．$w_1\notin L(H_0)=\emptyset$ なので，学習器は段階 $1$ で再構成する．$\WitnessSet(\widetilde G)\subseteq K_{n_0}$ を満たす $n_0$ を選ぶ．ある段階 $n\ge n_0$ で学習器が再構成するならば，定理~\ref{thm:reconstruction-fixed-h} により新たな仮説はちょうど $L$ となり，その後はいかなる正例も追加の変更を引き起こさない．この場合はこれが最後の仮説変更となる．一方，どの段階 $n\ge n_0$ でも再構成が起こらないと仮定する．健全性から $L(H_{n_0})\subseteq L$ である．さらに，すべての $n$ について $K_n\subseteq L(H_n)$ が成り立つ．再構成時には標本整合性があり，再構成しない段階では新たに提示されたデータがすでに変更されない仮説によって生成されるからである．したがって真の包含 $L(H_{n_0})\subsetneq L$ ならば，段階 $n_0$ までまだ現れていないある $w^\star\in L\setminus L(H_{n_0})$ が存在する．しかし標的のすべての語は最終的にテキストに現れるので，$w^\star$ は後の段階で現れて再構成を強制し，矛盾する．したがって $L(H_{n_0})=L$ である．この場合，段階 $n_0$ 以後に仮説変更は必要ない．
\end{proof}

これは Eyraud--Heinz--Yoshinaka~\cite[Appendix]{eyraud-heinz-yoshinaka2016}
が指摘する delayed-rebuild 現象である．特徴標本をすでに見終えた後でも，
新しい各正例が以前の誤った仮説によって生成されている限り，保守的学習器はその仮説を
保持し得る．その仮説の外にある後続の正例が現れたとき，すでに特徴データを含む
蓄積標本全体から再構成が行われる．上の証明は $\mathcal B_h$ に対するこの安定化を
明示している．

\section{再構成ステップの計算量}
\label{sec:complexity}

\begin{theorem}\label{thm:poly-build}
$h$ を固定すると，$\mathcal B_h(K)$ は $\|K\|$ に関して多項式時間で構成できる．
\end{theorem}
\begin{proof}
$n_K:=\|K\|$ とおく．標本語には $x\ne\lambda$ を満たす分解 $uxv$ が
$O(n_K^2)$ 個あり，従って $|\widehat V(K)|=O(n_K^2)$ である．因子の $h$-値も
固定モノイド中の $O(n_K^2)$ 回の積でキャッシュできる．規則~(R1) の候補は
$O(n_K^3)$，規則~(R2)--(R3) は高々 $O(n_K^4)$ 個である．多項式時間の前処理で
等しい因子と文脈成分に標準識別子を割り当てられる
（例えば $O(n_K^2)$ 個の因子出現をソートすればよい）．この識別子と $h$-値を
キャッシュした後は，固定 $h$ の下で各等値・型検査を定数時間で行える．
各生成規則の符号化長は $O(n_K)$ なので，文法全体を明示的に検査・出力する時間は
$O(n_K^5)$ で抑えられる．
\end{proof}

保守的学習器 $\mathcal A_h$ の各更新も，それまでに見たデータの符号化サイズに
関して多項式時間で処理できる．CFG membership は文法と入力サイズに関して
多項式時間であり，現在の仮説サイズと必要な再構成の計算量はいずれも
定理~\ref{thm:poly-build} によって多項式に抑えられる．

補題~\ref{lem:sample-consistency}，定理~\ref{thm:reconstruction-fixed-h}，
系~\ref{cor:ilt} と合わせて，主定理~\ref{thm:main}(i)--(iii) が得られる．
定量的な (iv)--(v) は第~\ref{sec:fixed-window-thick}--\ref{sec:linear}節で証明する．
文法サイズだけによる上界は不可能である．標準的な doubling family
（de~la~Higuera~\cite{higuera1997} および
Eyraud--Heinz--Yoshinaka~\cite[Example~2.3]{eyraud-heinz-yoshinaka2016} も参照）
は，縮約済み SSBNF 文法
$S_0\to A_n$, $A_0\to a$, $A_i\to A_{i-1}A_{i-1}$ をもち，
生成規則記号数は $O(n)$ だが生成言語は $\{a^{2^n}\}$ である．
任意の singleton 言語は，任意の $h$ に対して $\sim_h$-代入可能である．

\section{一般の固定型付けに対する型付き厚み}
\label{sec:typed-thickness}

\subsection{型付き厚み上界と表現レベルのギャップ}

任意の固定 $h$ に対し，生成語型付けの費用を明示的に測れば，有限証拠構成から
直接的な定量上界が得られる．$G=(V,\Sigma,P,S_0)$ を縮約済み SSBNF 文法，
$\widetilde G$ をそのトリム済み生成語型付き精密化とし，
$N:=|V\setminus\{S_0\}|$,
$N_t:=|\widetilde V\setminus\{\widetilde S\}|$
とおく．この表現の \emph{型付き厚み}を
\[
 \tau_h^{\mathrm{typ}}(G):=
 \max\Bigl(\{\,|\omega(X)|:
 X\in\widetilde V\setminus\{\widetilde S\}\,\}\cup\{1\}\Bigr)
\]
と定める．これは完全な生成語型分割とトリミング後の最短終端生成語を測る
表現依存パラメータであり，学習器への追加仮定ではない．

\begin{lemma}[型付き厚みによる証拠上界]
\label{lem:typed-thickness-bound}
$G,\widetilde G$ を上の通りとし，$\tau:=\tau_h^{\mathrm{typ}}(G)$ と書く．
任意の非開始型付き記号 $X$ に対し
$|u_X|+|v_X|\le (N_t-1)\tau$
であり，任意の $w\in\WitnessSet(\widetilde G)$ に対し
$|w|\le (N_t+1)\tau$
である．$P_{\mathrm{ter}},P_{\mathrm{bin}}$ をそれぞれ $G$ の非開始終端規則と
二項規則の集合とすると
\[
 \|\WitnessSet(\widetilde G)\|
 \le
 \bigl(N|M|+|P_{\mathrm{ter}}|
       +|P_{\mathrm{bin}}||M|^2+1\bigr)
 \bigl((N|M|+1)\tau+1\bigr).
\]
特に固定 $h$ の下で，この上界は $|G|$ と
$\tau_h^{\mathrm{typ}}(G)$ の多項式である．
\end{lemma}

\begin{proof}
$\widetilde G$ の非開始記号を頂点とし，二項規則で親から各子へ辺を張る依存有向グラフを
作る．$\widetilde G$ は縮約済みなので任意の非開始記号 $X$ は到達可能であり，
ある開始子 $A$ から $X$ への経路がある．最短経路を選ぶと型付き記号を反復せず，
辺数は高々 $N_t-1$ である．

経路の各辺について，その辺を実現する二項規則を選び，経路外の子をその標準生成語へ
展開する．$\widetilde S\to A$ から始めれば，これらの展開は $X$ の終端到達文脈を
与える．各経路外の標準生成語長は高々 $\tau$ なので文脈全長は
$(N_t-1)\tau$ 以下であり，標準文脈 $(u_X,v_X)$ はそれより長くない．

アンカーは標準生成語を一つ，終端規則証拠は終端記号を一つ，二項規則証拠は標準文脈に
標準生成語を二つ加える．$\tau\ge1$ だから，式~\eqref{eq:W} の各語の長さは
$(N_t+1)\tau$ 以下である．さらに $N_t\le N|M|$ であり，元の終端規則から生じる
型付き終端規則は高々一つ，元の各二項規則からは高々 $|M|^2$ 個の型付き規則が生じる．
従って第一因子が $\lambda$ の可能な証拠も含めた証拠個数を，第二因子が各
$|w|+1$ を抑える．積をとれば主張が従う．
\end{proof}

\begin{corollary}[型付き厚みからの特徴データ]
\label{cor:typed-thickness-data}
$h$ を固定する．$G$ が非空な $L(G)\in\Ccf{h}$ の縮約済み SSBNF 文法なら，
$\WitnessSet(\widetilde G)$ は $\mathcal B_h$ に対する特徴標本であり，
その符号化サイズは $|G|$ と $\tau_h^{\mathrm{typ}}(G)$ の多項式である．
\end{corollary}
\begin{proof}
定量上界は補題~\ref{lem:typed-thickness-bound}，特徴標本性は
定理~\ref{thm:reconstruction-fixed-h} による．
\end{proof}

完全精密化による議論では，型付き厚みを一般に元文法の通常の厚みへ置き換えられない．

\begin{remark}[元文法と型付き厚みの指数ギャップ]
\label{rem:typed-thickness-gap}
型付き厚みは，元文法のサイズと通常の厚みの多項式では
一般に抑えられない．以下にその例を示す．

$M_{\mathtt c}=\{1,\zeta\}$ を零元 $\zeta$ をもつ二元モノイドとし，
$h_{\mathtt c}(\mathtt a)=1$, $h_{\mathtt c}(\mathtt c)=\zeta$
とする．$n\ge1$ に対し，文法 $G_n^{\mathtt c}$ を
\[
\begin{aligned}
 S_0&\to Y, &
 Y&\to \mathtt a\mid\mathtt c\mid YY\mid A_nC, &
 C&\to\mathtt c,\\
 A_0&\to\mathtt a, &
 A_i&\to A_{i-1}A_{i-1}\mid\mathtt c
 \quad(1\le i\le n)
\end{aligned}
\]
で定める．これはサイズ $O(n)$ の縮約済み SSBNF 文法であり，
$L(G_n^{\mathtt c})=\{\mathtt a,\mathtt c\}^+
\in\Ccf{h_{\mathtt c}}$ である．

まず，$S_0,Y,A_0$ は $\mathtt a$ を，
$C,A_i$ ($i\ge1$) は $\mathtt c$ を生成できる．
つまり，すべての非終端記号が長さ $1$ の語を生成できるため，
通常の厚みは $\tau_{G_n^{\mathtt c}}=1$ である．

一方，型付き精密化で型 $1$ に制限すると，
$h_{\mathtt c}(\mathtt c)=\zeta\ne1$ なので，
$A_i\to\mathtt c$ は使えない．
また，積が $1$ になるのは $1\cdot1$ だけである．
従って帰納法により
$L((A_i)_1)=\{\mathtt a^{2^i}\}$
となる．さらに
$\widetilde S\to Y_\zeta\to(A_n)_1C_\zeta$
により $(A_n)_1$ はトリミング後も残る．
よって型付き厚みは
$\tau_{h_{\mathtt c}}^{\mathrm{typ}}(G_n^{\mathtt c})
\ge 2^n$ である．

元文法のサイズは $O(n)$，通常の厚みは $1$ なのに，
型付き厚みは $2^n$ 以上となる．
従って，この固定型付けに対してさえ，
元文法のサイズと通常の厚みによる多項式上界は存在しない．

ただし，標的言語 $\{\mathtt a,\mathtt c\}^+$ 自体は
$n$ に依存しない．従って，ここで示したのは
完全な型付き精密化に基づく証拠構成の限界である．
学習作用素に依存しない下界は
定理~\ref{thm:ordinary-thickness-lower} で与える．
\end{remark}

\subsection{集合駆動型特徴標本に対する通常厚み下界}
\label{subsec:ordinary-thickness-lower}

まず二つの初等的観察を用いる．

\begin{lemma}[型ファイバーへの制限]\label{lem:fibre-restriction}
$h:\Sigma^*\to M$ をモノイド準同型，$L$ を $\sim_h$-代入可能とする．
任意の $F\subseteq M$ に対し，$L\cap h^{-1}(F)$ も
$\sim_h$-代入可能である．
\end{lemma}
\begin{proof}
$L_F:=L\cap h^{-1}(F)$ とする．同型の非空因子 $x,y$ が $L_F$ で共通文脈を
もてば，$L$ でも共通文脈をもつので $\D_L(x)=\D_L(y)$ である．任意の $u,v$ について
$uxv\in L_F \iff uxv\in L\ \text{かつ}\ h(u)h(x)h(v)\in F$
であり，$x$ を $y$ に置き換えても二条件とも変わらない．
\end{proof}

\begin{lemma}[入れ子標的に対する特徴標本障害]
\label{lem:nested-characteristic-obstruction}
$\mathcal B$ を任意の集合駆動型作用素，$L'\subsetneq L$ とする．同じ $\mathcal B$ に
対し $C,C'$ がそれぞれ $L,L'$ の特徴標本なら
$C\cap(L\setminus L')\ne\varnothing$.
\end{lemma}
\begin{proof}
そうでなければ $C\subseteq L'$ である．$K:=C\cup C'$ とおけば
$C\subseteq K\subseteq L$ かつ $C'\subseteq K\subseteq L'$ なので，
特徴標本性は $L(\mathcal B(K))=L$ と $L(\mathcal B(K))=L'$ を同時に強制し矛盾する．
\end{proof}

\[
 \Sigma_\circ:=\{\mathtt l,\mathtt r,\mathtt a,\mathtt c,
                    \mathtt 0,\mathtt d\}
\]
とし，$M_\circ:=\{1,\zeta\}$ を単位元 $1$ と零元 $\zeta$ をもつ二元モノイドとする．
これは備考~\ref{rem:typed-thickness-gap} と同じ抽象的二元零モノイドだが，
アルファベットと文字像が異なるため準同型には別名を用いる．
$h_\circ:\Sigma_\circ^*\to M_\circ$ を
$h_\circ(\mathtt c)=\zeta$，その他のすべての文字を $1$ に送る準同型とする．
従って $h_\circ(w)=\zeta$ であることと $w$ が $\mathtt c$ を含むことは同値である．

$i\ge0$ に対し $s_i:=\mathtt c\mathtt 0^{\,i+1}\mathtt d$ とし，
有限言語を
\[
 \mathcal T_0:=\{\mathtt l\mathtt a\mathtt r,\,
                    \mathtt l s_0\mathtt r\},
 \qquad
 \mathcal T_i:=\{\mathtt l s_i\mathtt r\}
 \cup\{\mathtt lxy\mathtt r:x,y\in\mathcal T_{i-1}\}
 \quad(i\ge1)
\]
で定める．また
$z_0:=\mathtt l\mathtt a\mathtt r$,
$z_i:=\mathtt l z_{i-1}z_{i-1}\mathtt r$
とおく．$z_i$ は $\mathcal T_i$ の中で $\mathtt c$ を含まない唯一の語であり，
\begin{equation}
 |z_i|=5\cdot2^i-2.
 \label{eq:clean-tree-length}
\end{equation}

下界に必要な木構文解析は初等的だが，本論の流れに比べ記法が長いので
付録~\ref{app:level-coded-substitutability} に回す．要点は，
$\mathcal T_n$ の各語が残余高さに基づく一意な木構文解析をもち，clean tree $z_n$ の
互いに祖先・子孫関係をもたない部分木を level-coded shortcut $s_i$ に置換して
得られることである．レベル符号により置換位置が一意に認識できる．

\begin{lemma}[level-coded tree language の代入可能性]
\label{lem:level-coded-substitutable}
任意の $n\ge0$ に対し，$\mathcal T_n$ は Clark--Eyraud の意味で代入可能である．
\end{lemma}
\begin{proof}
付録~\ref{app:level-coded-substitutability} を参照されたい．
\end{proof}

\begin{theorem}[集合駆動型特徴標本に対する通常厚み下界]
\label{thm:ordinary-thickness-lower}
上で固定した準同型 $h_\circ$ に対し，ある多項式 $p$ が存在し，任意の $n\ge1$ に
ついて縮約済み CFG $R_n,R_n^-$ が存在する．
$\mathcal T_n^-:=\mathcal T_n\setminus\{z_n\}$ とおくと
$L(R_n)=\mathcal T_n$,
$L(R_n^-)=\mathcal T_n^-$
\[
 \mathcal T_n,\mathcal T_n^-\in\Ccf{h_\circ},\qquad
 |R_n|+|R_n^-|\le p(n),\qquad
 \tau_{R_n},\tau_{R_n^-}\le n+5.
\]
両標的に特徴標本をもつ任意の集合駆動型作用素 $\mathcal B$ をとる．
このとき $\mathcal T_n$ の任意の特徴標本 $C_n$ は
\[
 \|C_n\|\ge5\cdot2^n-1
\]
を満たす．従って $\Ccf{h_\circ}$ の全標的に特徴標本をもつ集合駆動型作用素には，
縮約済み CFG サイズと通常の厚みに関する多項式特徴データ上界は存在しない．
特にこれは $\mathcal B_{h_\circ}$ にも適用される．
\end{theorem}

\begin{proof}
$\mathcal T_n$ をちょうど生成する縮約済み CFG $R_n$ を
\[
\begin{aligned}
 S&\to A_n,&
 Z_0&\to\mathtt0,&
 Z_i&\to Z_{i-1}\mathtt0 &&(1\le i\le n),\\
 A_0&\to\mathtt l\mathtt a\mathtt r
       \mid\mathtt l\mathtt cZ_0\mathtt d\mathtt r,\\
 A_i&\to\mathtt lA_{i-1}A_{i-1}\mathtt r
       \mid\mathtt l\mathtt cZ_i\mathtt d\mathtt r
       &&(1\le i\le n)
\end{aligned}
\]
とする．すべての表示した記号は到達可能かつ生産的である．より具体的に
\[
 Z_i\Rightarrow^*\mathtt 0^{\,i+1},\qquad
 A_i\Rightarrow
 \mathtt l\mathtt cZ_i\mathtt d\mathtt r
 \Rightarrow^*
 \mathtt l\mathtt c\mathtt 0^{\,i+1}\mathtt d\mathtt r
\]
なので，$Z_i,A_i$ はそれぞれ長さ $i+1,i+5$ の終端生成語をもつ．
$S\Rightarrow A_n$ なので開始記号にも長さ $n+5$ の証拠がある．従って全非終端記号は
長さ $n+5$ 以下の終端生成語をもち，$\tau_{R_n}\le n+5$ である．
生成規則記号数は $O(n)$ だから，固定した符号化の下で符号化サイズは $n$ の多項式である．

$R_n^-$ は開始記号を $S^-$ とし，生成規則をすべて明示して
次のように定める．
\[
\begin{aligned}
 S^-&\to A_n^-,\\
 Z_0&\to\mathtt0, &
 Z_i&\to Z_{i-1}\mathtt0
 &&(1\le i\le n),\\
 A_0&\to\mathtt l\mathtt a\mathtt r
       \mid\mathtt l\mathtt cZ_0\mathtt d\mathtt r,\\
 A_i&\to\mathtt lA_{i-1}A_{i-1}\mathtt r
       \mid\mathtt l\mathtt cZ_i\mathtt d\mathtt r
 &&(1\le i<n),\\
 A_0^-&\to\mathtt l\mathtt cZ_0\mathtt d\mathtt r,\\
 A_i^-&\to\mathtt l\mathtt cZ_i\mathtt d\mathtt r\\
 &\quad\mid\mathtt lA_{i-1}^-A_{i-1}\mathtt r
       \mid\mathtt lA_{i-1}A_{i-1}^-\mathtt r
 &&(1\le i\le n).
\end{aligned}
\]
ここで $A_i$（$0\le i<n$）はレベル $i$ のすべての語を生成し，
$A_i^-$（$0\le i\le n$）はそのうち少なくとも一つの shortcut を
含む語をちょうど生成する（帰納法による）．
開始規則が $S^-\to A_n^-$ なので，
$L(R_n^-)=\mathcal T_n^-$ である．
$S^-\to A_n^-$ から二項規則をたどればすべての $A_i^-$ が到達可能であり，
各 $A_i$ は $A_{i+1}^-$ の規則で通常の兄弟として現れ，各 $Z_i$ は shortcut 規則に
現れる．従って表示したすべての非終端記号が到達可能である．生産性と厚みも
\[
 Z_i\Rightarrow^*\mathtt 0^{\,i+1},\qquad
 A_i^-\Rightarrow
 \mathtt l\mathtt cZ_i\mathtt d\mathtt r
 \Rightarrow^*
 \mathtt l\mathtt c\mathtt 0^{\,i+1}\mathtt d\mathtt r
\]
で明示できる．各 $A_i$ も表示した shortcut 規則から長さ $i+5$ の
終端語を生成でき，$S^-\Rightarrow A_n^-$ が開始記号の証拠を与える．従ってすべての非終端記号は
生産的で長さ $n+5$ 以下の終端生成語をもち，$R_n^-$ は縮約済みかつ
$\tau_{R_n^-}\le n+5$ である．これも生成規則記号数 $O(n)$，符号化サイズは多項式である．

補題~\ref{lem:level-coded-substitutable} により $\mathcal T_n$ は
$\sim_{h_\circ}$-代入可能である．さらに
$\mathcal T_n^-=\mathcal T_n\cap h_\circ^{-1}(\{\zeta\})$
なので，補題~\ref{lem:fibre-restriction} から $\mathcal T_n^-$ も同じ性質をもつ．
両言語は有限だから $\Ccf{h_\circ}$ に属する．

$C_n,C_n^-$ を同じ $\mathcal B$ に関する二標的の特徴標本とする．
$\mathcal T_n\setminus\mathcal T_n^-=\{z_n\}$ なので，
補題~\ref{lem:nested-characteristic-obstruction} は $z_n\in C_n$ を強制する．
式~\eqref{eq:clean-tree-length} より
$\|C_n\|\ge|z_n|+1=5\cdot2^n-1$ であり，これは $n$ に指数的である一方，
文法サイズは $n$ の多項式，厚みは $n$ に線形である．
\end{proof}

\section{固定窓に対する厚み付きデータ}
\label{sec:fixed-window-thick}

以下の二つの正の定量結果はいずれも $\tau_h^{\mathrm{typ}}$ を上から抑え，
系~\ref{cor:typed-thickness-data} を適用して得られる．$h_{k,\ell}$ では，
型付き非終端記号が保存すべきなのは有界な接頭辞と接尾辞だけなので型付き厚みを
制御できる．備考~\ref{rem:typed-thickness-gap} が示すように，一般の $h$ には
この移送はない．表現サイズと厚みに関して多項式の特徴標本上界は，
Eyraud--Heinz--Yoshinaka~\cite{eyraud-heinz-yoshinaka2016} の用語でいう
identification in polynomial time and thick data (IPTtD) のデータ部分である．
Yoshinaka の定理~1 と補題~6--7 は $(k,\ell)$-代入可能性について同種の上界を与える
~\cite{yoshinaka2008}．ここでは $\mathcal B_{h_{k,\ell}}$ に対応する上界を示すが，
同じ正規形や同じ多項式次数は主張しない．

$k,\ell\ge0$ を固定し $r:=k+\ell$ とおく．$G=(V,\Sigma,P,S_0)$ を縮約済み
SSBNF 文法，$\widetilde G$ をその縮約済み $h_{k,\ell}$-型付き精密化とし，
\[
 N:=|V\setminus\{S_0\}|,\qquad
 N_t:=|\widetilde V\setminus\{\widetilde S\}|,\qquad
 \theta_{k,\ell}(G):=
 \begin{cases}
   \tau_G, & r=0,\\[1mm]
   r+(2r-1)N\tau_G, & r>0
 \end{cases}
\]
とおく．

\begin{lemma}[固定窓型付き生成語の有界性]
\label{lem:window-typed-yield}
$\widetilde G$ の任意の非開始型付き記号 $A_\mu$ に対し
$|\omega(A_\mu)|\le\theta_{k,\ell}(G)$
である．
\end{lemma}
\begin{proof}
付録~\ref{app:fixed-window-bounds} を参照されたい．
\end{proof}

\begin{theorem}[固定窓に対する多項式厚み付きデータ]
\label{thm:window-thick}
任意に固定した組 $(k,\ell)$ とアルファベット $\Sigma$ に対し，多項式
$Q_{k,\ell}$ が存在し，$L(G)\in\Ccf{h_{k,\ell}}$ を満たす任意の縮約済み
SSBNF 文法 $G$ について
$\|\WitnessSet(\widetilde G)\| \le Q_{k,\ell}(|G|,\tau_G)$
が成り立ち，$\WitnessSet(\widetilde G)$ は
$\mathcal B_{h_{k,\ell}}$ に対する特徴標本である．
\end{theorem}
\begin{proof}
補題~\ref{lem:window-typed-yield} より
$\tau_{h_{k,\ell}}^{\mathrm{typ}}(G)\le\theta_{k,\ell}(G)$ であり，
固定 $k,\ell,\Sigma$ の下では右辺は $|G|,\tau_G$ の多項式である．
系~\ref{cor:typed-thickness-data} を適用すればよい．
\end{proof}

上の定理は縮約済み SSBNF 表現について述べている．次の正規化で任意の縮約済み
CFG へ移送する．

\begin{proposition}[厚みを多項式的に保存する SSBNF 正規化]
\label{prop:thick-ssbnf-normal}
固定多項式 $P_1,P_2$ が存在し，非空言語を生成する任意の縮約済み CFG $R$ を
多項式時間で同値な縮約済み SSBNF 文法 $G$ へ変換でき，
$|G|\le P_1(|R|)$,
$\tau_G\le P_2(|R|,\tau_R+1)$
が成り立つ．
\end{proposition}

証明は付録~\ref{app:thick-ssbnf} に与える．文法サイズと最短非空生成語を
多項式に保つため，終端分離と二分化を非開始 $\lambda$-規則除去より先に行う．

\begin{corollary}[固定窓計算量の移送]
\label{cor:window-transfer}
任意の固定 $k,\ell\ge0$ と有限アルファベット $\Sigma$ に対し，
縮約済み CFG $R$ で表される任意の $L\in\Ccf{h_{k,\ell}}$，同値にそのような
$R$ で表される任意の文脈自由 $(k,\ell)$-代入可能標的は，
$\mathcal B_{h_{k,\ell}}$ に対して $|R|$ と $\tau_R$ の多項式サイズの
特徴データをもつ．
\end{corollary}
\begin{proof}
命題~\ref{prop:thick-ssbnf-normal} と定理~\ref{thm:window-thick} を適用する．
同値性は命題~\ref{prop:yl-special} による．
\end{proof}

多項式は固定した窓とアルファベットに依存し，可変な $k,\ell$ に関する一様上界は
主張しない．これはバッチ再構成の特徴データに関する主張であり，保守的逐次学習器の
Gold 安定化は系~\ref{cor:ilt} で別途与える．

\paragraph{一般下界との整合性．}
定理~\ref{thm:ordinary-thickness-lower} は固定窓の結果と矛盾しない．
大きい方の標的 $\mathcal T_n$ は通常の意味で代入可能なので，自明型付けからの
型付け精密化により，任意の固定 $(k,\ell)$ について $\Ccf{h_{k,\ell}}$ に属する．
しかし $n\ge1$ では，入れ子標的 $\mathcal T_n^-$ は通常の意味ですら代入可能でない．
$z_n=p_n\mathtt a q_n$ と書き，$p_n:=\mathtt l^{\,n+1}$ とする．別の高さ $0$ の
body $\mathtt a$ を一つ $s_0$ に置き換えて $\bar q_n$ を得る．すると
$p_n\mathtt a$ と $p_ns_0$ は $\mathcal T_n^-$ で文脈
$(\lambda,\bar q_n)$ を共有するが，$(\lambda,q_n)$ は $p_ns_0$ の文脈であって
$p_n\mathtt a$ の文脈ではない．さらに一般に，任意の固定 $(k,\ell)$ について，
十分大きい $n$ では $\mathcal T_n^-\notin\Ccf{h_{k,\ell}}$ である．
そうでなければ入れ子標的補題と系~\ref{cor:window-transfer} により，指数長の $z_n$ が
多項式サイズに抑えられる固定窓特徴標本へ入ることを強制される．一般下界は任意の
縮約済み CFG 表現に対して測られるので，Coste--Nicolas~\cite{coste-nicolas2019} の
reduced normal form (RNF) で表現された $k,\ell$-local substitutable language に対する IPTtD 結果とも矛盾しない．
そこでは言語条件も表現クラスも異なる．

\section{線形部分クラス}
\label{sec:linear}

線形言語はちょうど 1 ターン・プッシュダウンオートマトンによって受理される
~\cite{ginsburg-spanier1966,autebert1997}．以下の正規化はその文法的対応物を与える．
成功導出には一つの継続する非終端記号の経路があり，これを \emph{spine} と呼ぶ．

\begin{proposition}[linear-spine SSBNF 正規化]\label{prop:linear-normal}
固定多項式 $P_{\mathrm{lin}}$ が存在し，非空言語を生成する任意の線形 CFG $G$ を
多項式時間で同値な縮約済み SSBNF 文法 $G_0=(V_0,\Sigma,P_0,S_0)$ へ変換でき，
$|G_0|\le P_{\mathrm{lin}}(|G|)$ である．さらに各二項生成規則は，
$W_a\to a$ を満たすちょうど一つの新鮮な終端ラッパー子と，
ちょうど一つのそれ以外の非終端子をもつ．
\end{proposition}

構成は付録~\ref{app:linear-normalization} に与える．
$\widetilde G_0$ を型付き精密化，
$n_t:=|\widetilde V_0\setminus\{\widetilde S\}|$ とおく．
各基礎非開始記号は高々 $|M|$ 個の型付きコピーをもつので
$n_t\le|V_0\setminus\{S_0\}|\,|M|$ である．

\begin{lemma}[短い標準生成語]\label{lem:linear-short}
$\widetilde G_0$ の任意の型付き非開始記号 $X$ に対し
$|\omega(X)|\le n_t$
である．従って $\tau_h^{\mathrm{typ}}(G_0)\le n_t$ である．
\end{lemma}

証明は付録~\ref{app:linear-short-proof} に与える．

\begin{theorem}[線形標的に対する多項式特徴データ]
\label{thm:linear-poly}
$h$ を固定する．線形 CFG で表される $\Clin{h}$ の任意の言語は，
$\mathcal B_h$ に対し，標的表現サイズの多項式で
$\|\cdot\|$-サイズが抑えられる特徴標本をもつ．
\end{theorem}
\begin{proof}
$L=\emptyset$ と $L=\{\lambda\}$ では第~\ref{sec:typing}節の標本を用いる．
それ以外では命題~\ref{prop:linear-normal} の $G_0$ を取る．
補題~\ref{lem:linear-short} から
$\tau_h^{\mathrm{typ}}(G_0)\le n_t\le
|V_0\setminus\{S_0\}|\,|M|$ なので，
系~\ref{cor:typed-thickness-data} により
$|G_0|\le P_{\mathrm{lin}}(|G|)$ の多項式サイズの特徴標本を得る．
\end{proof}

定理~\ref{thm:poly-build} と合わせると，任意の有限標本からのバッチ再構成は
多項式時間であり，選んだ線形 CFG 表現に関して特徴データも多項式である．
ただし $\mathcal B_h$ の出力が線形表現であるとは限らないため，保守的逐次学習器
自体を de~la~Higuera の意味で polynomial time-and-data learner とは呼ばない．

\subsection{非正則な線形 \texorpdfstring{fixed-$h$}{fixed-h} 例}

直前の定理は，正則標的や既知の線形代入可能クラスに限定されない．
\[
\begin{split}
L_{\pm,e}:={}&
\{a^{2m}cb^{2m}:m\ge0\}
\cup
\{a^{2m+1}db^{2m+1}:m\ge0\}\\
&\cup
\{a^neb^n:n\ge0\}.
\end{split}
\]
これは線形文法
\[
\begin{array}{lll}
S\to U_{\mathrm{ev}}\mid U_e, &
U_{\mathrm{ev}}\to c\mid aU_{\mathrm{odd}}b, &
U_{\mathrm{odd}}\to d\mid aU_{\mathrm{ev}}b,\\[1mm]
&&U_e\to e\mid aU_eb
\end{array}
\]
で生成される．

$c,d,e$ を \emph{中心記号}と呼ぶ．
$M_{\pm,e}:=\{1,\kappa_{cd},\kappa_e,0\}$ を，$1$ が単位元で，
$\mu\nu=0$ がすべての $\mu,\nu\in\{\kappa_{cd},\kappa_e,0\}$ に対して成り立つ
四元モノイドとする．すなわち三元 null semigroup に単位元を付加したものである．
準同型 $h_{\pm,e}:\{a,b,c,d,e\}^*\to M_{\pm,e}$ を
\begin{equation}\label{eq:lpm-h}
 h_{\pm,e}(a)=h_{\pm,e}(b)=1,\qquad
 h_{\pm,e}(c)=h_{\pm,e}(d)=\kappa_{cd},\qquad
 h_{\pm,e}(e)=\kappa_e
\end{equation}
で定める．従って $h_{\pm,e}(w)$ は，中心記号を含まなければ $1$，
ちょうど一つ含みそれが $c$ または $d$ なら $\kappa_{cd}$，それが $e$ なら
$\kappa_e$，二つ以上含めば $0$ である．

$\operatorname{par}(c):=0$, $\operatorname{par}(d):=1$ とおく．
$m,n\ge0$ と $\xi\in\{c,d,e\}$ に対し
\begin{equation}\label{eq:lpm-membership}
a^m\xi b^n\in L_{\pm,e}
\iff
m=n
\ \text{かつ}\
\bigl[
 \xi=e
 \ \text{または}\
 (\xi\in\{c,d\}
  \ \text{かつ}\
  m\equiv\operatorname{par}(\xi)\pmod2)
\bigr].
\end{equation}

\begin{proposition}\label{prop:linear-separator-example}
言語 $L_{\pm,e}$ は線形かつ非正則であり，式~\eqref{eq:lpm-h} の準同型に対して
$\sim_{h_{\pm,e}}$-代入可能である．一方，Clark--Eyraud 代入可能ではなく，
いかなる固定 $k,\ell\ge0$ に対しても $(k,\ell)$-代入可能ではない．
\end{proposition}

\begin{proof}
線形性は表示文法から直ちに従い，
$L_{\pm,e}\cap a^*eb^*=\{a^neb^n:n\ge0\}$ から非正則性が従う．
以下 $L:=L_{\pm,e}$ とする．

$\sim_{h_{\pm,e}}$-代入可能性について，同じ型の非空因子 $x,y$ が $L$ で
共通文脈をもつとする．$L$ の語に現れる因子が型 $0$ をもつことはない．共通型が
$1$ なら $x,y\in a^+\cup b^+$ であり，共通文脈は
$|x|_a-|x|_b=|y|_a-|y|_b$ を強制する．この値は
$a^+\cup b^+$ の語を一意に決めるので $x=y$ である．

それ以外では
$x=a^i\xi b^j$, $y=a^{i'}\xi'b^{j'}$ と書け，各因子は中心記号を一つ含む．
式~\eqref{eq:lpm-membership} によりその文脈は $(a^m,b^n)$ の形で，
\[
\begin{array}{ll}
(a^m,b^n)\in\D_L(a^ieb^j)
 &\Longleftrightarrow n-m=i-j,\\
(a^m,b^n)\in\D_L(a^i\xi b^j),\ \xi\in\{c,d\}
 &\Longleftrightarrow
 n-m=i-j\ \text{かつ}\
 m\equiv\operatorname{par}(\xi)-i\pmod2
\end{array}
\]
である．従って $e$-因子の分布は $i-j$ により，$c/d$-因子の分布は
$(i-j,\operatorname{par}(\xi)-i\bmod2)$ により決まる．共通文脈は対応する
不変量を一致させ，同じ $h_{\pm,e}$-型であることは同じ分岐に属することを保証する．
よって $\D_L(x)=\D_L(y)$ である．

一方 $c,e\in L$ は空文脈を共有するが
$(a,b)\in\D_L(e)\setminus\D_L(c)$ なので Clark--Eyraud 代入可能ではない．
さらに $k,\ell$ を固定し $N:=2\max\{1,k+\ell\}$，
$w_e:=a^keb^\ell$, $w_c:=a^kcb^\ell$ とおく．両因子は同じ長さ $k$ の接頭辞と
長さ $\ell$ の接尾辞をもち，文脈 $(a^{N-k},b^{N-\ell})$ を共有する一方
$(a^{N+1-k},b^{N+1-\ell}) \in\D_L(w_e)\setminus\D_L(w_c)$
である．従って \hyperref[crit:kl]{固定窓代入可能性の反例基準}より
$L_{\pm,e}\notin\mathsf{KL}$ である．
\end{proof}

従って定理~\ref{thm:linear-poly} は $\mathsf{KL}$ の外にある非正則線形言語にも
適用される．表示文法は even-linear なので，Takada の control-set 枠組みからの
分離は主張しない．

\section{表現力と境界}
\label{sec:boundaries}

ここでは fixed-window 階層と，より広い文脈自由言語族の間で本枠組みを位置づける．

\subsection{\texorpdfstring{$\mathsf{RS}$}{RS} 内の非線形標的}

$\Delta:=\{a^nb^n:n\ge0\}$ とし $\Delta^*$ を考える．
$z\in\{a,b\}^*$ に対し $\beta(z):=|z|_a-|z|_b$，また
$\underline\beta(z)$ を接頭辞バランスの最小値とする．$ba$ の各出現の高さを，
その $b$ で終わる接頭辞の高さと呼ぶ．次の特徴づけを用いる：
\textup{($\star$)} $w\in\Delta^*$ であることと，
$\underline\beta(w)\ge0$，$\beta(w)=0$，かつすべての $ba$ の出現高さが $0$
であることは同値である．順方向は $a^nb^n$ 因子への分解から従い，逆方向は
高さ $0$ となる位置ごとに切れば balanced な $a^*b^*$ segment が得られる．

$\operatorname{fst}(w),\operatorname{lst}(w)\in\{\bot,a,b\}$ を最初と最後の記号
（$\lambda$ では $\bot$）とし，$\operatorname{ba}(w)$ で $w$ が $ba$ を含むかを
記録する．
\[
 h_\star(w):=
 (\operatorname{fst}(w),\operatorname{lst}(w),\operatorname{ba}(w)).
\]
連接の要約は二因子の要約だけから決まる．端点は明らかな仕方で連接され，新しい $ba$ は
境界 $b|a$ でのみ生じ得る．従って有限像
$M_\star:=h_\star(\{a,b\}^*)$ に
$h_\star(x)h_\star(y):=h_\star(xy)$ と積を入れれば，
$h_\star$ は有限モノイド準同型になる．

非空 $x$ と $d\in\mathbb Z$ に対し，
$d+\underline\beta(x)\ge0$ かつ $x$ 内部の各 $ba$ の高さ $\eta$ について
$d+\eta=0$ であるとき，$d$ を \emph{許容進入高さ}と呼び，その集合を
$\mathcal E(x)$ と書く．

\begin{proposition}[非線形 fixed-$h_\star$ 標的]
\label{prop:nonlinear-rs-example}
$\Delta^*$ は文脈自由・非正則・非線形で，$\sim_{h_\star}$-代入可能である．
さらにどの固定 $k,\ell\ge0$ に対しても $(k,\ell)$-代入可能ではない．従って
$\Delta^*\in\mathsf{RS}_{h_\star}(\{a,b\})\cap\mathrm{CFL}$ かつ
$\Delta^*\in\mathsf{RS}(\{a,b\})\setminus\mathsf{KL}(\{a,b\})$ である．
\end{proposition}

\begin{proof}
文法 $S\to TS\mid\lambda$, $T\to aTb\mid\lambda$ は $\Delta^*$ を生成する．
$\Delta^*\cap a^*b^*=\Delta$ から非正則であり，線形言語の正則交差に対する閉包性と
$\Delta^*\cap a^*b^*a^*b^*=\Delta\Delta$
および $\Delta\Delta$ の非線形性~\cite{autebert1997} から非線形である．

代入可能性を示すため，同じ $h_\star$-型をもつ非空因子 $x,y$ が共通文脈
$(u,v)$ をもつとする．$uxv,uyv\in\Delta^*$ なので全体バランスから
$\beta(x)=\beta(y)$ である．\textup{($\star$)} により，$u'xv'$ の membership のうち
$x$ に依存する情報は，最初と最後の記号，$\beta(x)$，および
$\beta(u')\in\mathcal E(x)$ かどうかだけである．従って
$\mathcal E(x)=\mathcal E(y)$ を示せばよい．

両者が $ba$ を含むなら，内部 $ba$ は可能な進入高さを一意に強制し，共通文脈が
その高さを供給するので
$\mathcal E(x)=\{\beta(u)\}=\mathcal E(y)$ である．どちらも $ba$ を含まなければ
$x,y\in a^*b^*$ で，
$\mathcal E(z)=\{d:d\ge-\min\{0,\beta(z)\}\}$ だから
$\beta(x)=\beta(y)$ から等号が従う．従って
$\D_{\Delta^*}(x)=\D_{\Delta^*}(y)$ である．

固定窓からの分離として $k,\ell$ を固定し，
$m:=\max\{1,k+\ell\}$，
$s:=a^mb^m$，
$t:=a^mb^ma^mb^m$ とおく．両者は同じ長さ $k$ の接頭辞と長さ $\ell$ の接尾辞をもち，
空文脈を共有する．さらに $asb\in\Delta^*$ だが，$atb$ の中央の $ba$ は高さ $1$
なので $atb\notin\Delta^*$ である．従って固定窓代入可能性の反例基準から，
$\Delta^*$ はどの $(k,\ell)$ にも属さない．
\end{proof}

従って fixed-$h$ 枠組みは，固定窓階層の外にある第~\ref{sec:linear}節の
非正則線形例 $L_{\pm,e}$ と，非線形文脈自由言語 $\Delta^*$ の双方を含む．
control-set 法一般との分離は主張しない．

比較のため，fixed-window 階層の文脈自由部分それ自体も線形言語に限られない．
$\Gamma:=\{a,b,c,d,e\}$ 上で，第~\ref{sec:framework}節で導入した
center-marker language $P$ を再び用い，
$L_\times:=PdP =\{a^ncb^nd\,a^mcb^m:n,m\ge0\}$
とする．center-marker language $P$ は代入可能である．$c$ を含まない非空因子は
$a$ または $b$ の純冪で，共通 $P$-文脈は balance $|\cdot|_a-|\cdot|_b$ を一致させる
ので因子自体が一致する．$c$ を含む因子は $a^icb^j$ の形であり，その $P$-文脈は
$i-j$ のみに依存する．また $P$ は接頭辞自由かつ接尾辞自由である．
$L_\times$ の各語は $d$ をちょうど一つ含むので，共通文脈をもつ二因子に対して
$d$ は両因子の外側にあるか，両因子の内側にあるかのいずれかである．前者では
$P$ の代入可能性により対応する片側の $P$-文脈を移せる．後者では接頭辞・接尾辞自由性
により空側の場合が固定され，$P$ の代入可能性を $d$ の左右に独立に適用できる．
従って $L_\times$ は通常の意味で代入可能であり，$(0,0)$ fixed-window class に属する．
また $S\to XdX$, $X\to aXb\mid c$ により文脈自由である．

$a,b$ を固定し $c,d,e$ を消去する準同型は $L_\times$ を
$\Delta\Delta=\{a^nb^na^mb^m:n,m\ge0\}$ へ写す．線形言語は準同型で閉じ，
$\Delta\Delta$ は非線形である~\cite{autebert1997} から，$L_\times$ は非線形である．
命題~\ref{prop:linear-separator-example} の反対向きの分離と合わせると，
$\mathsf{KL}(\Gamma)\cap\mathrm{CFL}$ と $\Gamma$ 上の線形文脈自由言語族は
互いに比較不能である．

\subsection{固定窓階層からの正則分離}

$\Sigma_c:=\{\uparrow,\downarrow,\#\}$ とする．
$w=\delta_1\cdots\delta_n$ に対し $\mathrm{ht}_0(w)=0$ とし，
$\uparrow$ で $+1$，$\downarrow$ で $-1$，$\#$ で $0$ にリセットして高さを更新する．
$\rho\ge1$ に対し
\[
\mathrm{CTR}_\rho:=
\{w\in\Sigma_c^*:0\le\mathrm{ht}_i(w)\le\rho
\text{ for all }0\le i\le|w|\}
\]
とおく．

任意の $\rho\ge1$ に対し $\mathrm{CTR}_\rho$ は正則である．実際，DFA が高さ
$0,\ldots,\rho$ を記録し，範囲外に一つの sink を置き，$\#$ で $0$ に戻ればよい．
従って命題~\ref{prop:regular-auto} から
$\mathrm{CTR}_\rho\in\mathsf{RS}(\Sigma_c)$ となる．

\begin{theorem}\label{thm:ctr-non-kl}
任意の $\rho\ge2$ に対し $\mathrm{CTR}_\rho$ はどの $k,\ell\ge0$ についても
$(k,\ell)$-代入可能ではない．
\end{theorem}
\begin{proof}
$k,\ell$ を固定し
$s:=(\uparrow\downarrow)^k\uparrow^{\rho-1}\#^\ell$，
$t:=(\uparrow\downarrow)^k\uparrow^\rho\#^\ell$ とおく．両者は固定窓基準に十分長く，
同じ長さ $k$ の接頭辞と長さ $\ell$ の接尾辞をもち，ともに
$\mathrm{CTR}_\rho$ に属する．一方
$\uparrow s\in\mathrm{CTR}_\rho$ だが
$\uparrow t\notin\mathrm{CTR}_\rho$ で，後者は高さ $\rho+1$ に達する．
従って分布が異なり，反例基準が適用できる．
\end{proof}

$\rho\ge2$ という制限は意図的であり，$\rho=1$ の場合はここで示す分離には必要ない．

従って有限認識準同型 $h_\rho$ をとれば
$\mathrm{CTR}_\rho\in\Ccf{h_\rho}\setminus\mathsf{KL}$ である．
fixed-window 階層は，一つの fixed-$h$ 学習可能 slice の中ですでに正則標的を取りこぼす．

\subsection{\texorpdfstring{$\mathsf{RS}$}{RS} の外にある自然な決定性文脈自由言語}

\begin{lemma}[有限モノイド障害]\label{lem:finite-monoid-obstruction}
$L\subseteq\Sigma^*$ とする．無限集合 $\Xi\subseteq\Sigma^+$ が存在し，
相異なる任意の $x,y\in\Xi$ について
$\D_L(x)\cap\D_L(y)\ne\emptyset$ かつ $\D_L(x)\ne\D_L(y)$ が成り立つなら
$L\notin\mathsf{RS}(\Sigma)$ である．
\end{lemma}
\begin{proof}
有限 $h$ は $\Xi$ の二要素を同一視する．その二語は共通文脈をもち分布が異なるので
$\sim_h$-代入可能性に反する．
\end{proof}

上限を外すと決定性文脈自由言語
\[
\mathrm{CTR}:=
\{w\in\Sigma_c^*: \mathrm{ht}_i(w)\ge0
\text{ for all }0\le i\le|w|\}
\]
を得る．これは reset 付きの明らかな決定性プッシュダウン・カウンタで受理される．

\begin{corollary}[上限なしカウンタの障害]
$\mathrm{CTR}\notin\mathsf{RS}(\Sigma_c)$ である．
\end{corollary}
\begin{proof}
$\Xi=\{\uparrow^i:i\ge1\}$ を用いる．$i<j$ なら
$(\lambda,\downarrow^i)$ は共通文脈だが，
$(\lambda,\downarrow^j)$ は $\uparrow^j$ だけの文脈である．
\end{proof}

一種類の括弧の Dyck 言語
\[
 D_1:=\{w\in\{a,b\}^*: |w'|_a\ge|w'|_b
 \text{ for every prefix }w',\ |w|_a=|w|_b\}
\]
は標準的な決定性文脈自由言語~\cite{ginsburg-greibach1966} である．
ここでの $D_1$ は Dyck 言語全体を表し，
Autebert--Berstel--Boasson~\cite{autebert1997} の規約では $D_1^*$ と書かれる．

\begin{corollary}\label{cor:dyck-not-rs}
$D_1\notin\mathsf{RS}(\{a,b\})$ である．
\end{corollary}
\begin{proof}
$\Xi=\{b^ia^i:i\ge1\}$ を用いる．$i<j$ なら $(a^j,b^j)$ は共通文脈だが，
$(a^i,b^i)$ は $b^ia^i$ だけの文脈である．$b^ja^j$ では接頭辞 $a^ib^j$ が
アンダーフローを起こす．
\end{proof}

従って障害は無界スタック挙動それ自体ではない．非正則 1-turn 言語
$L_{\pm,e}$ は $\mathsf{RS}$ に属する．障害は，文脈的挙動が異なるにもかかわらず
相互に比較可能な因子が無限族をなし，有限 $h$ ではそれらをすべて分離できないことである．

\begin{lemma}[固定語による商]\label{lem:rs-fixed-quotient}
$L$ が $\sim_h$-代入可能で $z\in\Sigma^*$ なら，
$L/z:=\{w:wz\in L\}$ も $\sim_h$-代入可能である．
\end{lemma}
\begin{proof}
$L/z$ の共通文脈 $(u,v)$ は $L$ では $(u,vz)$ になる．$L$ で分布が等しいなら，
任意の文脈 $(s,t)$ の右に $z$ を付加することで $L/z$ に分布等式を移せる．
\end{proof}

$S\to aSS\mid b$ が生成する言語を \emph{\L{}ukasiewicz 言語}と呼ぶ．
本論文の記法では $L_{\mathrm{Luk}}=D_1b$~\cite{autebert1997} で，これは決定性
文脈自由言語でもある~\cite{ginsburg-greibach1966}．もし
$L_{\mathrm{Luk}}\in\mathsf{RS}(\{a,b\})$ なら補題~\ref{lem:rs-fixed-quotient} により
$D_1=L_{\mathrm{Luk}}/b\in\mathsf{RS}$ となり，
系~\ref{cor:dyck-not-rs} に反する．

\subsection{Clark の congruential family との比較}

Clark~\cite{clark2010congruential} は有限初期集合 $I\subseteq V$ を許し，
$L_G[I]:=\bigcup_{A\in I}L_G(A)$ と書く．このような文法が
\emph{congruential} であるとは，各 $L_G(A)$ が $L_G[I]$ の一つの構文合同類に
含まれることをいう．$\Gamma$ 上の congruential grammar が生成する言語全体を
$\mathsf{CONG}(\Gamma)$ と書く．Clark はすでに substitutable および
$(k,\ell)$-substitutable language をこの族に位置づけている．次の命題はこの包含を
すべての fixed-$h$ slice へ拡張する．

\begin{proposition}[Clark の congruential family との比較]
\label{prop:clark-congruential-comparison}
任意の有限アルファベット $\Gamma$ と有限モノイド準同型
$h:\Gamma^*\to M$ に対して
$\Ccf{h}\subseteq\mathsf{CONG}(\Gamma)$ である．従って
$\mathsf{RS}(\Gamma)\cap\mathrm{CFL}\subseteq\mathsf{CONG}(\Gamma)$ であり，
$\Gamma=\{a,b\}$ ではこの包含は真である．
\end{proposition}

\begin{proof}
非空 $L\in\Ccf{h}$ の縮約済み SSBNF 文法と型付き精密化 $\widetilde G$ を取る．
任意の非開始型付き記号 $X=A_\mu$ は終端到達文脈 $(u,v)$ をもち，
命題~\ref{prop:typed-core} より任意の
$w\in L_{\widetilde G}(X)$ は非空かつ $h(w)=\mu$ である．従って
$x,y\in L_{\widetilde G}(X)$ は同じ型と共通文脈 $(u,v)$ をもち，
fixed-$h$ 代入可能性から $x\equiv_L y$ となる．すなわち各型付き非終端記号は
一つの構文合同類の語だけを生成する．

分離された開始記号を削除し，その型付き後続記号を有限初期集合として用いる．
$\lambda\in L$ なら $\lambda$ だけを生成する新しい初期記号を一つ加える．
命題~\ref{prop:typed-core} により，これで $L$ の congruential grammar が得られる．
空言語は生成規則をもたない初期記号で扱える．$h$ 全体に和を取れば包含が従う．

$\{a,b\}$ 上で包含が真であることには，Clark~\cite{clark2010congruential} も論じる
Dyck 例を用いる．任意の $x\in D_1$ に対し
$uxv\in D_1$ iff $uv\in D_1$ なので $x\equiv_{D_1}\lambda$ である．従って
$S\to aSbS\mid\lambda$ は congruential だが，系~\ref{cor:dyck-not-rs} より
$D_1\notin\mathsf{RS}(\{a,b\})$ である．
\end{proof}

\paragraph{有限群だけでは不十分である．}
有限モノイドを用いることは，単なる記法上の一般化ではない．
$\mathsf{GRS}(\Gamma)$ を，$\mathsf{RS}(\Gamma)$ の定義において
証拠となる準同型の余域を有限群に限定して得られるクラスとする．
任意の有限群は有限モノイドなので，
$\mathsf{GRS}(\Gamma)\subseteq\mathsf{RS}(\Gamma)$ である．
しかもこの包含は，一文字アルファベット上ですでに真である．
$L_{\ge2}:=\{a^m:m\ge2\}$
とおく．これは正則言語なので，命題~\ref{prop:regular-auto} より
$L_{\ge2}\in\mathsf{RS}(\{a\})$ である．
一方，$h:\{a\}^*\to G$ を有限群への準同型とし，$g=h(a)$ とおく．
$g$ の位数を $n\ge1$ とすれば
$h(a)=h(a^{n+1})$ である．
非空因子 $a$ と $a^{n+1}$ は，$a^2,a^{n+2}\in L_{\ge2}$ なので
文脈 $(a,\lambda)$ を共有するが，分布は一致しない．実際，
$(\lambda,\lambda)\notin\D_{L_{\ge2}}(a)$ である一方，
$(\lambda,\lambda)\in\D_{L_{\ge2}}(a^{n+1})$ である．
従って $L_{\ge2}\notin\mathsf{GRS}(\{a\})$ であり，
$\mathsf{GRS}(\{a\})\subsetneq\mathsf{RS}(\{a\})$
が従う．すなわち，正則標的の段階ですでに，
非可逆な有限観測を許すことが本質的である．

\section{結論}

任意の固定有限モノイド型付け $h$ に対し，有限個の標準正例証拠からの
多項式時間の集合駆動型再構成と，それとは別の保守的 Gold 学習器を与えた．
特徴データは文法サイズと型付き厚みに関して多項式であるが，一つの固定二元型付けでは，
fixed-$h$ slice 全体を対象とする集合駆動型作用素に，縮約済み CFG サイズと通常の厚みに
関する多項式上界は存在しない．一方，任意の固定接頭辞--接尾辞窓では通常の厚みで十分であり，
線形 fixed-$h$ 標的では文法サイズに関する上界が得られる．

本枠組みには，それぞれ
$\{\uparrow,\downarrow,\#\}$，$\{a,b,c,d,e\}$，$\{a,b\}$ 上で，
どの fixed-window class にも属さない正則・非正則線形・非線形文脈自由標的が存在する．
さらに，観測子を有限群に制限すると一文字正則言語
$L_{\ge2}=\{a^m:m\ge2\}$ すら失われるため，有限群ではなく有限モノイドを
用いることは本質的である．一方 $D_1\notin\mathsf{RS}$ であり，
$\mathsf{RS}(\Gamma)\cap\mathrm{CFL}$ は Clark の congruential family に真に含まれる．
未解決問題として，$\mathsf{RS}\cap\mathrm{CFL}$ の特徴づけ，有用な型付けの選択または
学習，および本枠組みと効率性基準のより豊かな文法形式への拡張がある．

\subsection{補題~\ref{lem:window-typed-yield} の証明}

\begin{proof}[補題~\ref{lem:window-typed-yield} の証明]
$r=0$ のとき，$h_{0,0}$ は $\Sigma^+$ 上で定数なので，
生産的な型付き非終端記号 $A_\mu$ は基礎となる非終端記号 $A$ と
同じ非空生成語をもち，$|\omega(A_\mu)|\le\tau_G$ である．

$r>0$ とし，$A_\mu$ が生産的であるとする．
$\mu$ が $M_{k,\ell}$ の短語要素なら，型 $\mu$ の語はその短語自身なので，
その長さは $r$ 未満である．
残る長語要約要素 $\mu=\langle p,q\rangle$ について，
この型をもつ $A$ の導出木を一つ選び，最初の $k$ 個と最後の $\ell$ 個の
終端葉を印付けする．印付け葉はちょうど $r$ 個であり，そのラベルは必要な順序で
$p$ と $q$ を与える．根から印付け葉への経路の和を $T_0$ とする．

$T_0$ 上でちょうど一つの子だけが $T_0$ に残る非終端ノードの極大鎖を考える．
同じ基礎非終端記号が一つの鎖に二度現れたら，
上側の出現を下側の部分木で置き換える．
これは同じ非終端記号からの正しい導出であり，
印付け葉を含まない兄弟部分木しか削除しないので，
印付けられた境界終端記号とその順序は保存される．
これを繰り返すと，各極大一子鎖には高々 $N$ 個の非終端記号しか残らない．

各極大一子鎖を縮約すると，$r$ 個の印付け葉を結ぶ分岐骨格が得られ，
その頂点数は高々 $2r-1$ である．
したがって，最初の分岐頂点より上にあり得る初期鎖も含め，
極大一子鎖は高々 $2r-1$ 本である．
$T_0$ の外側に省略された兄弟部分木が生じるのは
これらの鎖上のノードだけであり，分岐ノードでは両方の子が $T_0$ に含まれる．
従って省略された兄弟部分木は高々 $(2r-1)N$ 個である．

それぞれをその根の最短終端生成語で置き換えると，
一つにつき高々 $\tau_G$ 個の終端記号を寄与する．
得られる語 $w'$ は依然として $A$ から導出され，
接頭辞 $p$ と接尾辞 $q$ を保つので，同じ $h_{k,\ell}$-型 $\mu$ をもち，
$|w'|\le r+(2r-1)N\tau_G$.

命題~\ref{prop:typed-core} と同じ生成語型注釈により，
この導出は $A_\mu\Rightarrow_{\widetilde G}^*w'$ に持ち上がる．
$A_\mu$ は到達可能であり，この導出木は成功しているので，
木上のすべての型付き記号は trim 後も残る．
したがって $w'$ は $A_\mu$ の型付き生成語であり，
shortlex 最小の型付き生成語 $\omega(A_\mu)$ も同じ長さ上界を満たす．
\end{proof}

\subsection{厚みを多項式的に保存する SSBNF 正規化}
\label{app:thick-ssbnf}

\begin{proof}[命題~\ref{prop:thick-ssbnf-normal} の証明]
$R=(V,\Sigma,P,S)$ を縮約済みで非空言語を生成する文法とし，$n:=|R|$, $\bar\tau:=\tau_R+1$ とおく．文法サイズと最短終端生成語をともに多項式に保つ順序で標準正規化を行う．

まず新しい開始記号 $S_0$ と規則 $S_0\to S$ を導入し，$\lambda\in L(R)$ なら最終的に $S_0\to\lambda$ を残す．長さ 2 以上の右辺に現れるすべての終端記号を新しいラッパー $W_a\to a$ で分離し，長さ 2 を越える右辺を二分化する．得られる文法を $G_{\mathrm{bin}}$ とする．選んだ妥当な符号化の下で，これらの操作の総サイズは $O(n)$ である．元の各非終端記号は同じ終端生成語言語を保つ．新たな各二分化記号は元のある右辺の連続部分を展開し，そこに含まれる元の記号数は高々 $O(n)$ である．その部分に現れる各生産的非終端記号を最短終端生成語で置き換えれば，ある定数 $c_1$ に対して
$\tau_{G_{\mathrm{bin}}}\le c_1 n\bar\tau$
が得られる．

次に，$G_{\mathrm{bin}}$ の空語導出可能記号から得られる最短の \emph{非空} 生成語を抑える．$A\Rightarrow_{G_{\mathrm{bin}}}^*w$ を非空終端語への導出とし，導出木の終端葉を一つ選んで根からの経路をたどる．同じ非終端記号が二度現れれば，上側の部分木を下側の部分木で置き換えてサイクルを削除できる．これを繰り返すと経路上の非終端記号数は高々 $|V_{G_{\mathrm{bin}}}|$ となる．各二項ノードで経路外の兄弟記号をその最短終端生成語へ置き換えると，空語導出可能な兄弟記号は空語を寄与してよく，選んだ終端葉が一文字を寄与するので，ある定数 $c_2$ に対して
\[
 \min\{\,|w|>0:A\Rightarrow_{G_{\mathrm{bin}}}^*w\,\}
 \le 1+|V_{G_{\mathrm{bin}}}|\tau_{G_{\mathrm{bin}}}
 \le c_2 n^2\bar\tau
\]
である．

ここで非開始 $\lambda$-規則をすべて除去する．$G_{\mathrm{bin}}$ は二分文法なので，規則 $A\to BC$ から生じるのは，空語導出可能な子に応じて高々 $A\to BC$，$A\to B$，$A\to C$ であり，指数的な空語導出可能記号の部分集合に関する展開は起こらない．通常の構成は各非終端記号の非空終端生成語言語を保存するので，上の長さ上界も保たれる．続いて単位閉包を計算し，非開始単位規則を除去する．各出発非終端記号と，そこから単位規則だけで到達可能な各非単位規則について，その規則を出発非終端記号にコピーする．この段階の前には非終端記号が $O(n)$ 個，非単位規則も $O(n)$ 個なので，生成される規則は高々 $O(n^2)$ 個である．単位規則消去は各非終端記号の言語を保存するため厚み上界を増加させない．最後に無用記号をトリムする．

得られる文法は縮約済みで開始記号が分離され，各非開始規則は終端規則または二項規則であり，$S_0\to\lambda$ が唯一の可能な $\lambda$-規則である．従って SSBNF である．そのサイズは $n$ の多項式，厚みは高々 $c_2n^2(\tau_R+1)$ であり，すべての変換は多項式時間で実行できる．
\end{proof}

\section{linear-spine SSBNF 正規化の証明}
\label{app:linear-normalization}

命題~\ref{prop:linear-normal} の構成は，標準的な開始記号分離，無用記号・空語導出可能規則・単位規則の除去，および二分化を組み合わせ，第~\ref{sec:linear}節で必要な単一 spine 形を保存する．

\begin{proof}[命題~\ref{prop:linear-normal} の証明]
$L(G)=\{\lambda\}$ なら，単一規則 $S_0\to\lambda$ をもつ縮約済み文法を取ればよい．二項生成規則をもたないので，要求される条件は自明に成り立つ．従って以下では，$L(G)$ が空でない語を含むと仮定する．

$S$ を元の開始記号とする．右辺に決して現れない新しい $S_0$ を導入し，$S_0\to S$ を加え，さらに $\lambda\in L(G)$ なら $S_0\to\lambda$ も加える．以後 $S$ は非開始記号として扱う．無用記号を除去し，$\lambda$ を $S_0$ にのみ保存しつつ非開始 $\lambda$-規則を除去し，その後で非開始単位規則を除去する．開始規則には単位規則消去を適用しないので，最終トリミング後に残る各開始規則は，要求どおり $S_0\to A$ または $S_0\to\lambda$ の形になる．この順序により，$\lambda$-消去によって新たに生じた単位規則も除去される．入力文法は線形なので，各右辺には空語導出可能な非終端記号が高々一つしか現れず，各生成規則から追加される代替右辺は高々一つである．
ここで線形性は二箇所で使われる．第一に，空語導出可能規則の展開を多項式に抑える．第二に，消去後も，残る各非単位右辺には非終端記号が高々一つしか現れないことを保証し，これが以下の「ラッパーでない子を一つだけ持つ」分解を可能にする．単位閉包とラッパー鎖による二分化そのものは，一般 CFG に対しても多項式時間の操作である．単位規則消去では有限な単位到達可能閉包を計算する．すなわち，出発非終端記号と，到達可能な非単位生成規則の各組は，高々一つの複製規則を生じる．従って生成規則数も右辺長の総和も多項式に保たれる．

残るのは，新たな単位規則を作らずに二分化することである．以下の二項生成規則の子として現れる各終端記号 $a$ に対して，新しいラッパー $W_a\to a$ を一つ導入する．同値に，すべての $a\in\Sigma$ に対してそのようなラッパーを導入してもよい．
規則 $A\to uBv$ に対して，$u=a_1\cdots a_m$，$v=b_1\cdots b_n$ と書く．非開始単位規則はすでに消去されているので，$m=n=0$ の場合（これは単位規則 $A\to B$ になる）は起こらない．従って $m+n>0$ である．以下，場合分けを明示する．$m=0$ なら必ず $n>0$ である．$n=1$ なら $A\to BW_{b_1}$ を用いる．
$n\ge2$ なら，新しい $Q_1,\ldots,Q_{n-1}$ を導入し，
\[
 Q_1\to BW_{b_1},\qquad
 Q_j\to Q_{j-1}W_{b_j}\ (2\le j\le n-1),\qquad
 A\to Q_{n-1}W_{b_n}
\]
とする．
次に $m>0$ とする．$n=0$ なら $U:=B$ と定める．ここで $B$ はラッパー導入前の文法の非終端記号なので，この二分化で導入した新しい終端ラッパー記号の一つではない．$n>0$ なら新しい $Q_1,\ldots,Q_n$ を導入して
\[
 Q_1\to BW_{b_1},\qquad
 Q_j\to Q_{j-1}W_{b_j}\quad(2\le j\le n)
\]
とし，$U:=Q_n$ とおく．$m=1$ なら単一の二項規則 $A\to W_{a_1}U$ を用いる．$m\ge2$ なら，新しい $J_1,\ldots,J_{m-1}$ を導入して
\[
 A\to W_{a_1}J_1,\qquad
 J_i\to W_{a_{i+1}}J_{i+1}\quad(1\le i\le m-2),\qquad
 J_{m-1}\to W_{a_m}U
\]
とする．
したがって，$m+n>0$ の下で，$m=0$ または $m\ge1$，$n=0$ または $n\ge1$ のすべての場合が覆われる．また最も内側の二項規則は，新しい単位規則ではなく $B$ 自身を含む．

終端記号のみからなる規則 $A\to a_1\cdots a_m$ について，$m=1$ なら $A\to a_1$ をそのまま残す．$m\ge2$ なら，新しい
$\Theta_2,\ldots,\Theta_m$ を導入し，
\[
 A\to W_{a_1}\Theta_2,\qquad
 \Theta_i\to W_{a_i}\Theta_{i+1}\quad(2\le i\le m-1),\qquad
 \Theta_m\to a_m
\]
とする．（$m=2$ のとき，中間の規則族は空である．）従って新たに得られる非開始規則は，終端規則か，あるいはちょうど一つのラッパー子と一つの別の非終端子をもつ二項規則のいずれかである．構成上，ラッパー $W_a$ は二項規則のラッパー子位置にのみ現れ，継続する非終端子としては決して現れない．一方，終端記号のみの構成は，終端規則をもつ新しい非ラッパー鎖記号で終わる．最終トリミングは，この性質，分離開始形，および縮約済み性を保存する．ラッパーと鎖による分解は，すでに多項式に抑えられた右辺長総和に対して線形であるため，全構成のサイズは多項式であり，多項式時間で実行できる．
\end{proof}

\section{短い標準生成語補題の証明}
\label{app:linear-short-proof}

\begin{proof}[補題~\ref{lem:linear-short} の証明]
命題~\ref{prop:linear-normal} の linear-spine SSBNF 形では，各二項 spine step は
$A\to W_aB$ または $A\to BW_a$ の形で，$W_a\Rightarrow a$ だから，
継続する非終端記号の外側にちょうど一つの終端記号を放出する．

$X$ が終端ラッパーなら $|\omega(X)|=1$ である．そうでなければ，
型付き spine 記号 $X$ からの最短終端導出を取り，spine を
$X=X_0,X_1,\ldots,X_t$ と書く．$X_t$ は終端規則を用い，生成語長は $t+1$ である．
もし $X_i=X_j$（$i<j$）なら，二出現の間を削除して，より少ない spine step をもつ
有効な導出を得られるので最短性に反する．従って $t+1$ 個の型付き spine 記号は
相異なり，すべて非開始記号なので $t+1\le n_t$ である．よって
$|\omega(X)|\le n_t$ が従う．
\end{proof}

\section{level-coded tree language の代入可能性}
\label{app:level-coded-substitutability}

\begin{proof}[補題~\ref{lem:level-coded-substitutable} の証明]
$\mathtt l,\mathtt r$ を対応する木括弧とみなす．残余高さ $0$ の節点は，
body が $\mathtt a$ の clean leaf か，body が $s_0$ の shortcut のいずれかである．
残余高さ $i\ge1$ の節点は，body が $s_i$ の shortcut か，残余高さ $i-1$ の
順序付き二子をもつ二分節点のいずれかである．直列化では各節点を
$\mathtt l,\mathtt r$ で囲む．従って $\mathcal T_i$ はちょうど残余高さ $i$ の
木の直列化全体であり，$z_i$ は shortcut を含まない唯一の直列化である．

$\mathcal T_n$ の各語は一意な構文解析をもつ．高さ $0$ では body の最初の記号が
clean の場合 $\mathtt a$，shortcut の場合 $\mathtt c$ である．正の高さでは
二分節点の場合 $\mathtt l$，shortcut の場合 $\mathtt c$ である．二分の場合，
括弧対応が二つの子を一意に分離し，帰納法で木全体が決まる．従って shortcut 節点は
一意に定まる antichain をなす．shortcut を選ぶと，その根から下の部分木全体が除かれる．

$i\ge1$ に対し $b_i:=z_{i-1}z_{i-1}$，また $b_0:=\mathtt a$ とおく．
$s_i=\mathtt c\mathtt0^{i+1}\mathtt d$ は shortcut body，$b_i$ は残余高さ $i$ の
clean node body である．有効な直列化におけるどちらの body の literal occurrence も，
真の残余高さ $i$ の解析済み節点の body である．$s_i$ では body に括弧がなく，
0 の run がレベルを記録するので明らかである．$b_0=\mathtt a$ も clean leaf body
そのものである．$i\ge1$ では $b_i=z_{i-1}z_{i-1}$ の最初の $z_{i-1}$ の出現を考える．
帰納法により，これは真の残余高さ $i-1$ の解析済み部分木である．直近の親 frame を見ると，
二個目の $z_{i-1}$ が後続するので root ではなく，右子なら次の記号が親を閉じるはずなので
右子でもない．従って残余高さ $i$ の二分節点の左子である．残り suffix の
残余高さ $i-1$ の解析一意性により，続く $z_{i-1}$ はその右の兄弟に強制される．
よって $b_i$ の literal occurrence 全体はその解析済み節点の clean body に一致する．
従って
$s_i\longleftrightarrow b_i$
という literal body replacement は，残余高さ $i$ の節点でちょうど正当に実行でき，
共通の外側括弧 $\mathtt l,\mathtt r$ を残したまま $\mathcal T_n$ 内にとどまる．

任意の語文脈の中で $s_i\leftrightarrow b_i$ という literal body replacement を
有限回行って $r$ から $s$ を得られるとき $r\rightsquigarrow s$ と書く．
上の occurrence recognition から各一段階は replay 可能である．すなわち
$prq\in\mathcal T_n$ かつ一回の body replacement で
$r\rightsquigarrow s$ なら，対応する置換で $psq\in\mathcal T_n$ を得る．

次に代入可能性に必要な局所性を取り出す．相異なる二つの残余高さ $n$ の解析木
$S,T$ の直列化を $w_S,w_T$ とする．二つの root constructor を場合分けしつつ
残余高さについて帰納法を行うと，\emph{difference core} が得られる．
すなわち，語 $p,q,\xi,\eta$ が存在して
$w_S=p\xi q$, $w_T=p\eta q$,
$\xi\rightsquigarrow\eta$
であり，$\xi,\eta$ は非空，その最初の記号どうしも最後の記号どうしも異なる．
これを残余高さについて帰納法で示す．高さ $0$ では clean leaf と shortcut しかなく，
異なる場合は body $\mathtt a$ と $s_0$ を取ればよい．一回の body replacement で
結ばれ，両端記号も異なる．

残余高さ $i\ge1$ とする．一方の root が shortcut，他方が binary なら二つの root body
を取る．まず shortcut body $s_i$ を clean body
$b_i=z_{i-1}z_{i-1}$ に置き換え，その後，異なる子に帰納法を使って二つの clean child を
目標の左・右 child へ独立に変形する．これで二 root body 間の有限 body-replacement
列が得られ，最初と最後の記号は異なる．両 root が binary で順序付き子の一方だけが
異なるなら，その子の中で帰納法を適用し，difference core の外側の一致部分を $p,q$ に
吸収する．両子が異なるなら，各子に帰納法を適用し，左 difference core，二 core 間の
不変部分，右 difference core を連接する．得られた置換列は左子，次に右子を変えるので
$\xi\rightsquigarrow\eta$ であり，最初の記号は左子内，最後の記号は右子内で異なる．
これで全場合を尽くす．

いま $uxv,uyv\in\mathcal T_n$ とし，それぞれの一意な解析木を取る．木が等しければ
cancellation により $x=y$ である．そうでなければ上の difference core を取り
$uxv=p\xi q$, $uyv=p\eta q$
とする．$u$ は共通接頭辞なので $\xi,\eta$ の双方へ真に入り込むことはできない．
次の記号が異なるからである．従ってある $\alpha$ に対し $p=u\alpha$ である．
同様に $v$ は共通接尾辞で，$\xi,\eta$ の最後の記号が異なるので，ある $\beta$ に対し
$q=\beta v$ である．外側の共通部分を cancel すると
$x=\alpha\xi\beta$, $y=\alpha\eta\beta$
を得る．従って difference core 全体は表示した因子の内部にある．
有限列 $\xi\rightsquigarrow\eta$ を $\alpha,\beta$ で文脈化すれば，
$x$ から $y$ への有限で正当な body-replacement 列が得られる．

最後に $rxs\in\mathcal T_n$ とする．replay 可能性により同じ有限列を $x$ の出現内で
再生でき，$rys\in\mathcal T_n$ を得る．よって
$\D_{\mathcal T_n}(x)\subseteq\D_{\mathcal T_n}(y)$ であり，
置換列を逆向きにすれば逆包含も従う．従って $\mathcal T_n$ は代入可能である．
\end{proof}
