## 1. 問い（これまでと同じ）

Σ = {a, b, c}、内容型付け c、L ∈ C_{2,c}、G は L∩Σ⁺ の reduced good な表示（ファンアウト ≤ 2、ランク ≤ r）、v = |V|、θ = θ̄_G。k := μ_a(L) ≥ 5、T を a^k の節点数最小の導出、Γ_b = {a,b}、Γ_c = {a,c}。

> **Q：μ_a(L) は poly(‖G‖, θ) で抑えられるか。**

## 2. 前回の帰着とその弱点

定理2.2 は、二文字の定理を影文法 H_x 全体に当てるので、影の厚さ η_x = θ̄_{H_x}（H_x の全ての規則の厚さの最大）が入る。しかし μ_a を抑えるだけなら、T に現れる非終端の情報だけで足りるはずである。

**局所的な量の提案**：x ∈ {b, c} について
  β_x := max over（T の重い節点に現れる非終端 B）of min{ ‖z‖₁ : z ∈ L_B(G)、z の全成分が Γ_x⁺ に入り、z は a だけではない }
（そのような z がなければ ∞）。β_x は「第三の文字を使わない逃げ道」の最短の長さの、T の上での最大。

## 3. してほしいこと（優先順）

1. **局所的な影の補題（L1）を証明する**：
   > μ_a(L) ≤ poly_r(v, θ, β_x)（x = b, c のそれぞれについて）。

   - 方針：`thm:two-letter-content` の証明（付録I）を、内容 {a} の型付き開始記号の代表長 τ だけに絞って読み直す。各段で何を使っているか（短い生成組 ω_B、短い文脈 E_A、規則が書く終端の数 ≤ θ、L の語の出現に関する補題）を確かめ、ω_B を「T の非終端の Γ_x の逃げ道（長さ ≤ β_x）」に置き換えても証明が通ることを示す。
   - L ∩ Γ_x⁺ が二文字の内容型付けで代入可能であること（前回の補題2.1(3)）を使ってよい。通らない段があれば、その段を特定して書く。

2. **L1 が成り立つ場合の帰結を書く**：反例には、b の逃げ道と c の逃げ道の両方が長いことが要る。つまり：
   - ある重い節点 B_b では、長さ poly 以下の逃げ道が全て c を含む。
   - ある重い節点 B_c では、長さ poly 以下の逃げ道が全て b を含む。
   - とくに最も単純な場合は「短い逃げ道が全て b と c の両方を含む」。これまで壊れた候補 A_i → A_{i−1}A_{i−1} | bc はこの形だった。

3. **二重の影の問い（L2）**：上の条件と代入可能性を両立できるか。
   - **肯定側**：倍増節点で、c を含む逃げ道と b を含む逃げ道を混ぜる（子ごとに入れ替える）ことで、同じ内容で共通の文脈を持ち分布の違う組を作り、矛盾させる。あるいは「短い逃げ道が全て b と c の両方を含む」ことから、b と c の位置関係を使って比べられる二語を作る。
   - **否定側**：上の条件を満たす族を作る。L_n ∈ C_{2,c}（arity 1 と 2 を省略せずに）、G_n が reduced good でファンアウト ≤ 2・ランク ≤ 2、‖G_n‖ と θ̄_{G_n}（n の多項式）、μ_a(L_n)（超多項式）を全て証明する。前回までに壊れた候補（README (92)〜(106) の一覧）は使わない。

4. どれも完了しない場合は、証明できたこと、止まった場所、次に絞るべき一点を書いて終える。

## 4. 計算について

否定側の候補の検査に、有限言語の (1,c)・(2,c)-代入可能性の全数検査を勧める（前回の付録を再利用してよい）。Python 3 の標準ライブラリだけで書き、全文を載せる（Windows の `py -3 script.py` で動く形）。有限の検査の結果から無限の族の代入可能性を推定しない。

## 5. 守ってほしいこと

- 冒頭に、主張ごとの判定（証明済み／反証／観察／未解決）と根拠の節を書いた表を置く。
- 下界には、作用素（B^{≤r}_{2,c}、B_{2,c}、クラス全体に特徴標本を持つ集合駆動作用素）、ファンアウト、ランク、アルファベットの条件を明記する。
- 証明した範囲を超えて書かない。「最大の特徴標本」と書かない。「境界がファンアウトで動く」は、三文字の全ての内容型を証明した場合以外は書かない。
- 新しい結果が文献で既知かどうか、分かる範囲で書く。分からなければ「未確認」と書く。
