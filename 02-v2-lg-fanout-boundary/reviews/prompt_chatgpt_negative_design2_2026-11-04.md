## 1. 前報の候補と、二つの壊れ方（検証済み）

候補族（三文字、fan-out 1、rank 2、‖G_n‖ と θ̄ は n の二次）：

S → A_n、A_0 → ab、A_1 → A_0A_0 | abc、A_i → A_{i−1}A_{i−1} | a^i c b（2 ≤ i ≤ n）。

c を含まない語は W_n = (ab)^{2^n} だけで、μ_{ab}(L_n) = 2^{n+1} である。L_n ∈ C_{2,c} なら `prop:rare-type` で指数の下界になるが、L_n は C_{2,c} に入らない。壊れ方は二つある。

**(i) スロット移送（前報 §4、二穴）。** 許容二穴文脈 □ ab □ を共有する ((ab), (ab)^{N−2}) と ((ab)^{N−2}, (ab)) から、abc(ab)^{N−2} ∈ L は (ab)^k c (ab)^{N−1−k} ∈ L（1 ≤ k ≤ N−2）を強制する。L_n はこれらを含まない。

**(ii) 近道（Claude、一穴だけで起きる）。** n ≥ 3、i = n−1、y_i = (ab)^{2^i−2}abc、R = abc(ab)^{2^i−2} とする。健全な規則 SUB_1 の二段で、次のことが言える。

**L_n を含む全ての (1,c)-代入可能な言語は、ab 語 a(ab)^{2^{n−1}}（長さ 2^n + 1 < 2^{n+1}）を含む。**
- 段1：x = a^i c b、y = y_i、E = (□, R)、F = (a, □)。
  - E[x] と E[y] は、A_n → A_iA_i から得られる L_n の語である。
  - F[x] = a^n c b は A_n の逃げ道である。
  - 内容はどちらも {a,b,c}。よって F[y] = a y_i が強制される。
- 段2：x = (ab)^{2^n−2}、y = a(ab)^{2^i−2}、E = (□, abc)、F = (□, abab)。
  - E[x] ∈ L_n、E[y] = a y_i は段1で得た語、F[x] = W_n。
  - 内容はどちらも {a,b}。よって F[y] = a(ab)^{2^i} が強制される。
- `check_claude_negative_shortcut_2026-11-04.py` が n = 3..7 で検査した。強制閉包の計算でも、n = 3 で同じ語 aabababab が2段で出た。
- 原因は、逃げ道が互いに接頭・接尾でつながっていること（a^{i+1}cb = a·a^icb）にあるらしい。

つまり、この型の候補は、語を足して代入可能に修理しても、型 ab の最短の語が短くなる。ただし今の証明書が示すのは長さが**半分**になることだけで、多項式まで縮むかは分からない。

## 2. してほしいこと（優先順）

1. **近道の検証と一般化。**
   - 上の二段を自分で確かめる。
   - 低い段 i < n−1 で、文脈 P, Q の中の A_{i+1} の塊に同じ近道が使えるか。
   - 近道を繰り返したり、多くの塊に同時に使ったりして、ab 語を多項式の長さまで縮められるか。強制閉包の計算で n = 3, 4, 5 を調べ、長さ cap を |W_n| にしたとき最短の ab 語がどこまで縮むかを表にする。
2. **近道の補題を抽象化する。** 次の形の主張を、成り立つ範囲で証明する。
   - 主張：L ∈ C_{1,c}（または C_{2,c}）で W が型 {a,b} の唯一の語、T がその最小導出、重い節点の短い置き換えが全て c を含むとする。ある条件の下で、W より短い ab 語が強制される。
   - 条件の候補：二つの節点の逃げ道が接頭・接尾でつながる、同じラベルの c を含む生成が二つあり共通の文脈を持つ、など。
   - 支持集合の不変性により、強制には「c を含む語どうしの段」と「W を使う段」の両方が要る。この形を一般の証明書の型として書くこと。
3. **二つの壊れ方を避ける設計を探す。**
   - スロット移送で強制される語を全て生成し、しかも近道を生まない逃げ道の形を探す。例えば、逃げ道どうしが接頭・接尾でつながらない形や、c の位置が動ける「可動欠陥」の形。
   - 判定の手順：候補の言語 L_n の強制閉包を、n = 2, 3, 4 について長さ |W_n| まで計算する。そこに W_n より短い ab 語が出れば、その設計は修理できない（代入可能な上位言語の全てで μ_{ab} が縮む）。出なければ、閉包を生成する小さい文法を探し、所属を証明に進む。
   - 強制閉包は健全な規則だけで作り、強制された語には証明書を付けること。
4. **どちらに転んでも書く。**
   - 設計が生き残れば、所属・下界・文法の大きさを、全て定数付きで証明する。
   - 全ての設計が近道で壊れるなら、「唯一の ab 語と安い逃げ道を持つ設計では μ_{ab} ≤ poly」という肯定の向きの定理を試みる。これは稀な型 {a,b} の上界として、肯定の向きにもそのまま使える。
5. どれも完了しない場合は、次の三つを書いて終える。
   - 証明できたこと
   - 止まった場所
   - 次に絞るべき一点

## 3. 計算について

Python 3 の標準ライブラリだけで書き、全文を載せる（Windows の `py -3 script.py` で動く形）。コードを実行できる環境なら実際に動かし、出力をそのまま載せる。実行できない場合は「未実行」と明記し、出力を推測で書かない。

- 所属は文法から厳密に判定する（前報の `exact_member` のように、長さで切った集合に頼らない）。
- 強制閉包は、健全な規則（共通の許容文脈を持つ、成分ごとの内容が同じ組は分布が等しい）だけを使い、強制された語ごとに種から再生できる証明書を残す。
- 強制閉包を長さで切る場合、その切り方が結論に影響しないこと（「閉包に短い ab 語がある」は切っても正しいが、「ない」は切った範囲での観察にすぎない）を明記する。
- 有限の検査の結果から、無限の族の代入可能性を推定しない。

## 4. 守ってほしいこと

- 冒頭に、主張ごとの判定の表を置く。検証した主張には「独立に確認」「誤り」「確認できず」のいずれかを、新しい主張には「証明済み／反証／観察／未解決」のいずれかを書く。
- 「自明に成り立つが目的には足りない」主張と、既に知られた補題（`lem:power-transfer` など）の特別な場合にすぎない主張は、その旨を表に書く。
- まだ所属を示していない言語に、その所属を前提にした補題を使わない。
- 反例を主張するのは、所属・下界・文法の大きさの全てを証明した場合だけ。欠けていれば「候補」と書く。
- 下界を書くときは、対象の作用素（B^{≤r}_{2,c}、B_{2,c}、またはクラス全体で特徴標本を持つ集合駆動の作用素）、字母、ファンアウト、ランクを明記する。
- 「最大の特徴標本」と書かない。「境界がファンアウトで動く」と書かない。
- 新しい結果が文献で既知かどうか、分かる範囲で書く。分からなければ「未確認」と書く。
