# 依頼：消去的モノイドの原像で、二文字・ファンアウト1の超多項式下界は作れるか

（2026-11-08。Astra 向け。報告書名：`astra_cancellative_preimage_2026-11-08.md`（＋必要なら `.py`）。冒頭に判定表を置くこと。この依頼文だけで読めるように書いてある。）

## 1. 背景（読み飛ばしてよい）

論文 #2（固定有限半群型付けによる MCFG の分布学習）の未解決問題 `op:S1`：二文字 Σ = {a, b} の内容型付け c（または a ↦ 1, b ↦ ζ の型付け s_{U,2}）で、ファンアウト1（CFG）の特徴データの長さは文法の大きさと厚さの多項式で抑えられるか。否定なら、既に証明されている「ファンアウト ≥ 2 では多項式」と合わせて、同じ型付けでファンアウトが境界を動かす分離定理になる。

否定の構成の候補は次々に否定された。特に **有限群の語問題 φ⁻¹(1) は使えない**ことが証明された（定理G：|H| ≤ C(r‖G‖θ̄)^κ、Astra が 2026-11-08 に独立検証済み）。今回の依頼は、群を**消去的モノイド**に一般化した場合である。

## 2. 定義

- **CFG の大きさ** ‖G‖ = |V| + Σ_{X→γ}(1 + |γ|)。G は reduced（全ての非終端が到達可能かつ生産的）、**good**（ε 規則なし。ファンアウト1では「ε なし」と同じと思ってよい）、規則のランク（右辺の非終端の数）≤ r、r ≥ 2。
- **規則の厚さ** θ̄_G：各規則について、その規則を少なくとも一回使う開始記号からの導出が生成する最短の語の長さ、の最大値（Yoshinaka 2011）。
- **内容型付け c**：語の型はその語に現れる文字の集合（{a}, {b}, {a,b}）。
- **(1,c)-代入可能**：同じ内容の空でない語 x, y が L の中で一つの文脈 (l, r)（l x r, l y r ∈ L）を共有すれば、x と y の文脈の集合（分布）は等しい。このクラスを C_{1,c} と書く。型付けなし（全ての語を比べる）なら Clark–Eyraud の代入可能性。
- **下界の仕組み**（論文の `prop:rare-type`）：L ∈ C_{1,c} で、L の純な a の語のうち最短のものが a^N なら、c の標準的な学習作用素の全ての特徴標本は純な a の語を含むので、長さ ≥ N。従って **「L ∈ C_{1,c}、L の文法 G_n で ‖G_n‖, θ̄_{G_n} ≤ poly(n)、しかし最短の純な a の語の長さ N_n が超多項式」という族があれば `op:S1` は否定**。

## 3. 消去的モノイドの原像という枠組み（Claude の観察、証明つき）

M を消去的モノイド（xz = yz ⇒ x = y、zx = zy ⇒ x = y）、ψ: Σ* → M をモノイドの準同型、m ∈ M、L := ψ⁻¹(m) ∩ Σ⁺ とする。

- **(O1)** L は型付けなしで一穴代入可能：l x r, l y r ∈ L なら ψ(x) = ψ(y)（消去律）、よって分布が等しい。特に L ∈ C_{1,c}。
- **(O2)** a^N ∈ L で ψ(a) が無限位数なら、純な語は a^N だけ。2. の下界の仕組みで、特徴標本の長さ ≥ N。
- **(O3)** 群の場合と違い、L は有限でもよい（例：Baumslag–Solitar の正のモノイド ⟨a, b | ba = a²b⟩ では、各元の原像は b の個数が一定の有限集合）。有限群の場合は定理G で除かれている。
- **(O4) 必要条件【証明】**：反例として働くには、**ψ(Σ*) からの (Q, +) へのモノイド準同型 λ は全て自明**でなければならない（M が群に埋め込めるなら、生成される群の可換化が有限）。
  証明：a^N の節点数最小の導出で、生成語の長さが θ̄ を超える節点を「重い」と呼ぶ。重い節点のラベル B は長さ ≤ θ̄ の生成語 ω_B（b を含む）を持ち、a^p ω_B a^q ∈ L と消去律から ψ(ω_B) = ψ(a^{n_B})、よって λ(ω_B) = n_B λ(a)。λ(a) > 0 のとき、λ(b) ≤ λ(a) なら n_B ≤ |ω_B| ≤ θ̄ で矛盾、λ(b) > λ(a) なら L は非負の加法的な重みの一つの水準に入り、既知の定理（全ての語の重みが一定なら最短の純な a の語は ≤ (r+1)²θ̄³）で多項式。λ(a) < 0 も同様。λ(a) = 0 なら λ(ω_B) = λ(b)·#_b(ω_B) = 0 から λ(b) = 0。□
- **帰結**：BS(1,2) 型は除かれる（b の個数が保存され、純な語が作れない）。反例には次の三つを同時に満たす対象が要る：
  - (C1) ψ(Σ*) から Q への非自明な準同型が無い（可換化が有限）；
  - (C2) 正のモノイドの中で ψ(a) が**指数的に歪む**：ψ(a)^{n} の多くが長さ poly(log n) の正の語で書ける（重い節点の短い生成語のため）；
  - (C3) 原像 ψ⁻¹(m) が、大きさ・厚さとも poly の CFG を持つ（特に文脈自由）。

## 4. 依頼

**課題1（文献）.** (C1)–(C3) に関係する既知の結果を調べて、出典つきで整理する。
- 正のモノイド（部分モノイド）の中での歪み（distortion in submonoids）、指数的に歪む元を持つ有限生成群・モノイド（Baumslag–Solitar、Lubotzky–Mozes–Raghunathan の高階格子の冪単元、Thompson 群、Grigorchuk 群など）で、正の生成元だけで短い表示が得られる例。
- 群・モノイドの「正の語問題」や一つの元の原像が文脈自由・正則になる条件（Muller–Schupp の正のモノイド版、Gilman–Hermiller–Holt–Rees などの「ε-free な正の語問題」、自己同型群・自動的群の文脈）。
- 消去的モノイドで、可換化（Q への準同型）が自明なものの例（例：一関係子モノイドで、関係子の Parikh ベクトルの差が Q² を張るもの）。

**課題2（構成：本命）.** (C1)–(C3) を満たす族を作る、または作れそうな候補を挙げる。
- 二文字の一関係子・二関係子の消去的モノイド（Adjan の判定条件で消去性を確認できるもの）で、関係子の長さが違い Parikh 差が Q² を張るものを系統的に調べる。例：⟨a, b | ba = a²b, b^k = …⟩ の形は群になりやすく有限群に落ちるので注意（有限群は定理G で除外）。
- 各候補について：ψ(a) の位数、ψ(a)^{2^j} の最短の正の語の長さ（数値で j ≤ 10 程度）、原像 ψ⁻¹(ψ(a^N)) の大きさ（有限か）、それを生成する小さい文法と厚さの試算。
- 有限の原像になる候補なら、原像を明示的に列挙して (1,c)-代入可能性を直接検査する（(O1) で自動的に成り立つはずなので、成り立たなければ消去性の誤り）。

**課題3（否定の向き：同じくらい歓迎）.** 「(C1)(C2)(C3) を同時に満たすものは無い」、あるいはそのどれか二つの両立の不可能性を示す。例えば：
- 原像が文脈自由で非終端に値が一意につく（(O1) から、各非終端の生成語は全て同じ ψ の値を持つ）ことと、重い節点の値 ψ(a^{n_B}) の歪みから、文法の大きさの下界を導く（有限群では、全ての単位元語を数える計数と混合時間でこれができた）。
- 原像が有限のとき、ψ の値の個数と文法の大きさの関係（各非終端は一つの値しか持たない）。

**課題4（任意）.** (O4) の証明を検証する。特に「非負の加法的な重みの一つの水準に入れば最短の純な語は ≤ (r+1)²θ̄³」は別の報告の結果なので、その仮定（重みが非負の有理数でよいか、λ(a) > 0, λ(b) > 0 の両方が必要か）を、この依頼の状況で使ってよいかを確かめる。
