## 1. 問い

原稿の定理B は、ファンアウト1では「多項式データを許す擬多様体はちょうど局所群 LG」と示しています。ファンアウト2で同じことが成り立つかは未解決です。

Claude の観察（理論側は ChatGPT が検証中）：
- LG に含まれない擬多様体は、必ず**有限半束全体 SL** を含みます。したがって、ファンアウト2で境界が LG であることは、**SL がファンアウト2で一様な多項式データを持たないこと**と同値です。
- 半束の型付けの中で最も細かいのは**内容型付け** c_Σ(w) = {w に現れる文字}（空でない部分集合の和集合への全射）で、これで探せば十分です。型付けが細かいほどクラスは大きくなります。
- 示したいのは、ある**固定**アルファベット上の c_Σ について、次を満たす族 (L_n, G_n) の存在です。
  - L_n ∈ C_{2,c_Σ}（ファンアウト1と2の両方の代入可能性）
  - ‖G_n‖ と θ̄ が n の多項式
  - ある内容型の最短の語の長さが超多項式
- そうした語が一つの型にただ一つしかなければ、稀な型の議論（`prop:rare-type`）で、特徴標本の長さの超多項式の下界が直ちに出ます。

**既知の障害**（避ける必要があるもの）：
1. **冪の移行**（`lem:power-transfer`）：語が因子 u⁵ を含むと、二穴で u の冪をやり取りされて所属が崩れます（半束では i₀ = q = 1）。括弧付き倍増族は ⌊ⁿ の連なりでこれに引っかかり、ファンアウト2で失敗します（定理C）。→ **重なりのない語**（Thue–Morse 語など）は u³ すら含まないので、この障害を受けません。
2. **二繊維型の定理**（あなたの以前の報告）：純な語と混合の語がそれぞれ一つの加法量の値しか持たない言語では、最短の純な語は (2r+1)|V|θ̄ 以下です。加法量で稀さを作る設計は使えません。

## 2. 定義（計算に必要なもの）

- **(f,s)-組代入可能**：1 ≤ d ≤ f、空でない成分の d 組 x, y について、成分ごとに s の値が等しく、かつ共通の許容文脈（d 穴文脈 E = v₀□v₁…□v_d で、内部の区切り v₁,…,v_{d−1} は空でない）で E[x], E[y] ∈ L となるなら、全ての許容文脈 F について F[x] ∈ L ⟺ F[y] ∈ L。
- 有限言語なら、全ての語の全ての d 組の出現を列挙し、（型の組, 文脈）でまとめて、分布の一致を確かめれば全数検査になります。違反があれば、証人（x, y, E, F）を文字列の連結で再検査してください。
- ‖G‖ は原稿 `def:standard-mcfg` の数え方（非終端の数 ＋ 各規則の 1 ＋ ランク ＋ 右辺の記号数）。θ̄ は「各規則を使う最短の文の長さ」の最大値（1 以上）。

## 3. やってほしいこと

**T1（基盤と検算）**
有限言語の (f,s)-代入可能性の判定器（f = 1, 2、任意の型付け。少なくとも内容型付けと U₁ 型付け）を作り、既知の例で検算してください。
- 括弧付き倍増族 L_n（E_0 → a、E_i → ⌊E_{i−1}E_{i−1}⌋ | ⌈E_{i−1}⌉）は、ファンアウト1では全ての型付けで代入可能。
- 三文字の族 K_2 はファンアウト2で失敗（あなたの以前の報告と同じ証人）。P_{N,2} は通る。

**T2（重なりのない倍増族の計算）**
次の族とその変種を作り、n = 1, 2, 3（可能なら 4）で調べてください。
- **基本案**：括弧付き倍増族の「倍増」を Thue–Morse 型にする。例えば
  A_0 → a、B_0 → b、A_i → A_{i−1}B_{i−1} | ⌈A_{i−1}⌉、B_i → B_{i−1}A_{i−1} | ⌈B_{i−1}⌉（開始 A_n）
  と、そこに解析を決定的にする区切りの文字を足したもの。印 ⌈ を使わない語は Thue–Morse 語 t_n ただ一つで、長さ 2ⁿ です。
- **変種**：Thue の三文字の平方のない形態素（a → abc、b → ac、c → b）など、他の重なりのない・平方のない形態素で背骨を作るもの。区切りの文字の置き方を変えたもの。
- 各候補について、次を表で報告してください。
  - 語数、最長の長さ、‖G_n‖、θ̄、各内容型の最短の長さ、印を使わない語の個数と長さ
  - 全ての語が u⁵（および u³）を因子に持たないか
  - ファンアウト1の代入可能性、ファンアウト2の代入可能性（違反があれば証人）

**T3（系統的な探索）**
基本案が通らない場合に備えて、小さな「倍増の型」を系統的に探してください。
- 例えば、非終端 E_i, F_i と、E_i → α E_{i−1} β F_{i−1} γ | δ E_{i−1} ε のような形で、α,…,ε を固定アルファベットの短い語（長さ 0〜2）から選ぶ。
- 各型について、n = 1〜3 で、(a) ファンアウト2の代入可能性（内容型付け）、(b) 稀な内容型の最短の長さが指数的に増えること、(c) θ̄ が n の一次で増えること、を確かめます。
- 条件を全部満たす候補を、増え方の表とともに報告してください。言語の大きさが急に増えるので、語数が多すぎる型は打ち切って構いません（打ち切った条件を書いてください）。

**T4（失敗の構造）**
ファンアウト2の代入可能性が崩れる場合、証人の形を分類してください。特に、冪の移行（同じ因子の繰り返し）以外のどんな二穴の交換が族を潰しているかを、例とともに報告してください。これは理論側（ChatGPT）が「より一般的な二穴の移送の補題」を作る材料になります。

**T5（証明できるところ）**
計算で見えた規則性のうち、証明できるものは証明してください。特に、有望な候補が見つかった場合の (i) 全ての n での代入可能性、(ii) ‖G_n‖・θ̄・最短の長さの式。
