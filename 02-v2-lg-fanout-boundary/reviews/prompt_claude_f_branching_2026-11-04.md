## 1. 到達点（別のスレッドの Claude の検証による整理）

Σ = {a, b, c}、内容型付け c、L ∈ C_{2,c} とする。G は L∩Σ⁺ の reduced good な表示で、ファンアウト ≤ 2、ランク ≤ r。v = |V|、θ = θ̄_G とおく。k := μ_a(L) ≥ 5 とし、T を a^k の節点数最小で一様な導出とする。F は重い両文字型節点の集合である。

- **定理4.1 (K)（証明済み、別のスレッドの Claude が定数も含めて検算）**
  - N_bc ≤ P + … + P^h。P = q₀q₁²、q₀ = 1+(r−1)(18v+vθ+1)、q₁ = 1+(r−1)(v(19+2θ+θ²)+1)。
  - したがって k ≤ 19(r+1)³v³θ³(θ+20+Σ_{j≤h}P^j)³。
  - **両文字型ラベルが定数個なら、μ_a ≤ poly_r(v, θ)。**
- **F 骨格木。** 頂点は F の節点で、各頂点からその最初の真の F 子孫へ辺を張る。各頂点の子は P 個以下で、深さは h ≤ v である。
  - 子が二つ以上ある頂点を「**F 分岐**」と呼ぶ。
  - どの道の上でも F 分岐が s 個以下なら、N_bc ≤ h·P^{s+1} となる（S が F に入らないときの仮想根の分を +1 で含めた）。
  - したがって超多項式の反例には、F 骨格木の一本の道の上に、**s → ∞ 個の F 分岐**が要る（正確には s·log P = ω(log(v+θ))）。
- **段の交換 (L)** は、条件付きの分布等式としては正しい。しかし一回の交換では骨格がそろわない（補題5.1）。

## 2. 別のスレッドの Claude の観察（確かめること）

以下は、報告を検証している別のスレッドの Claude の観察で、まだ誰も証明していません。同じモデルの観察なので、同じ見落としを共有している恐れがあります。**鵜呑みにせず、反例を探すつもりで確かめてください。**

**(R) 全文字の骨格による剛性。** X ⊆ {b, c} を、x⁴ が L の語の因子として現れる文字 x の集合とする（a⁴ は a^k に現れる）。σ_X(w) を、w の a の極大連と X の文字の極大連をそれぞれ一文字に縮めた語とする。このとき次が成り立つ。

> w, w' ∈ L が σ_X(w) = σ_X(w')、|w|_b = |w'|_b、|w|_c = |w'|_c、0 < |w|_a, |w'|_a < k を満たすなら、|w|_a = |w'|_a。

観察した側の証明の筋は次のとおり。
1. 系2.2 により、w' の X の文字の連の長さを、w と同じになるまで再配分してよい。その間、所属は変わらず、他の文字の連も変わらない。
2. 再配分の後の w'' は σ_a(w'') = σ_a(w) を満たす。
3. 定理S により、|w''|_a = |w|_a となる。

特に場合 I（b⁴ と c⁴ が両方現れる）では、σ_X は全文字の連の骨格 σ である。このとき定理S の「同じ a 骨格」という条件は、「**同じ全文字の骨格で、b と c の個数が等しい**」まで弱まる。骨格の一致が問題になっていた (L) や交差 (X) では、b と c の正確な位置をそろえる必要がなくなる。

**(P) 偶数の塊の障害の一般化。** 定理3.2 の障害（a の塊が全て偶数長）は、倍増を一様に選ぶ型に固有のものか。一様な T の上で F 分岐が何段も起こると、反鎖の差し替えで得られる語の a の連の長さに、何らかの整除の不変量が生じ、再配分（a⁴ による）と矛盾するか。

## 3. してほしいこと（優先順）

1. **(R) を厳密に確かめて述べる。** 特に次の二点を確かめること。
   - 系2.2 の再配分が、定理S の仮定（a の個数が 0 と k の間）を壊さないか。
   - 連が隣り合う二つの差し替えの塊が合流する場合の扱い。
2. **場合 I（b⁴ と c⁴ が現れる）で、F 分岐の段数 s を抑える。** 目標は s = O(1)、または s ≤ poly(v, θ) でかつ P を掛けない形。手がかりは次のとおり。
   - (R)
   - 二つの F 分岐 w ⊃ w'（ラベル B₁、B₂）での反鎖の差し替えの比較。異なる数の塊を、塊の合流や一色型の塊を挟むことで同じ全文字の骨格にそろえる。
   - 前回の (L)、損失 d_B、a の再配分

   まず次の場合を目標にしてよい。
   - ファンアウト1・ランク2
   - 両文字型の代表の全文字の骨格が全て同じ（例えば全て bc）
   - 入れ子が二段
3. **場合 II（b⁴ も c⁴ も現れない）と場合 III（一方だけ）。** b と c の連は長さ 3 以下である（場合 III では一方だけ）。既報の近い候補 D → bc | bc D は場合 II である。この場合に、F 分岐の段数を抑えるか、反例の設計の余地があるかを調べる。
4. **否定側。** 次を全て満たす G_n を作る。
   - F 骨格木の一本の道に s → ∞ 個の F 分岐がある
   - L_n ∈ C_{2,c}
   - ‖G_n‖ と θ̄_{G_n} が n の多項式
   - μ_a(L_n) が超多項式

   新しい候補では、次の三つをどう避けるかを先に説明すること。
   - □ と □a による a の個数の漏れ
   - 偶数の塊の障害（定理3.2）
   - 場合 I なら (R)

   作れたら、次を全て証明する。
   - arity 1 と 2 の代入可能性（省略しない）
   - reduced good であること

## 5. 守ってほしいこと

- 冒頭に、主張ごとの判定（証明済み／反証／観察／未解決）と根拠の節を書いた表を置く。
- 「自明に成り立つが目的には足りない」主張は、その旨を表に書く（前回の報告の h ≤ v の書き方がよい例）。
- 言い換えると中身が弱くなる主張（例：新しい量の上界が、実は既知の量で抑えているだけ）は、そう分かる形で書く。
- まだ所属を示していない言語に、その所属を前提にした補題を使わない。
- 下界には次の条件を明記する。

- 「最大の特徴標本」と書かない。
- 「境界がファンアウトで動く」は、三文字の全ての内容型を証明した場合にだけ書く。
