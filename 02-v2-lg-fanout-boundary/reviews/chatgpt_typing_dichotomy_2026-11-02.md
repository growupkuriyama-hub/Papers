### 厳密な射程

以下の指数下界は、**ファンアウト1・規則ランク上限 `r_max ≥ 2`** で、原稿の `\mathcal B^{\le r_max}_{1,s}`、`\mathcal B_{1,s}`、および **`\mathcal C_{1,s}` の全標的に特徴標本を持つ任意の集合駆動作用素**に成立する。最後の主張は、作用素がクラス全体（少なくとも対象言語とその希少型除去言語の両方）について特徴標本を持つ場合に限る。任意の Gold 型逐次学習器の収束時間・最終時点についての下界ではない。

## 1. 正本の定義・必要な既知結果

型付け `s:Σ⁺ ↠ S` は有限半群への**全射半群準同型**である。空語の型は fresh identity completion で分離する。ファンアウト1では、正の長さの因子 `x,y` について、`s(x)=s(y)` かつ共通する受理文脈が存在するとき、全二側分布 `D_L(x)=D_L(y)` を要求する（`def:tuple-substitutable`）。Clark–Eyraud 型はさらに強く、`s(x)=s(y)` を仮定しない。

`good` は λ-free、nondeleting、nonpermuting、nonmerging、`reduced` は全非終端の reachable・productive を意味する（`def:grammar-properties`）。`||G||` は非終端数と各規則のランク・テンプレート長を用いる原稿の記号数サイズであり、`θ̄_G=max(1, max_R θ_G(R))` は**各規則を使用する最短成功文の最大長**である。

必要な原稿の事実：

1. `prop:three-letter-family`：抽象アルファベット `A,B,C` 上の `K_0={A}`, `K_i = B K_{i-1} K_{i-1} B ∪ C K_{i-1} C` は有限の Clark–Eyraud 代入可能言語。原稿 `app:u1-typings` に、到達可能なスタックでの単射性を用いた証明がある。
2. `lem:type-deletion`：型 m の**全単語**の除去 `L\s^{-1}(m)` は、`L∈C_{f,s}` なら同じクラスに属する。
3. `prop:rare-type`：標的に型 m が現れれば、上記作用素の特徴標本は型 m の語を少なくとも1つ含む。型 m の語が唯一ならその語自体が必須である。
4. `thm:lg-characterization`：S∉LG ⇔ S に `U_1={e,z}` のコピー（相異なる冪等元で `ez=ze=z`）が存在する。
5. `lem:power-transfer`：ファンアウト2以上では、十分長い同一語の冪の存在と同型条件から、離れた二つの穴の間で冪を移送できる。

## 2. 新しい補助補題：有限 CE 言語と位置識別符号

**定義（位置識別符号）**。抽象アルファベット `Δ` と、非消去準同型 `h:Δ*→Σ*` をとる。異なる**符号語内の異なる文字位置も含めて**、`h(d)` (`d∈Δ`) に出現する各ターミナルは全体でちょうど1回しか出現しないと仮定する。すなわち、全ての `h(d)` を並べたとき文字の重複がない。各文字は「どの符号語の何番目の位置か」を一意に知らせる。この仮定は、単なる prefix code / uniquely decipherable code より強い。

**補題2.1（有限 CE 言語の挿入不能性）**。`L⊆Δ⁺` が有限かつ Clark–Eyraud 代入可能なら、`p,q∈Δ*`、`t∈Δ⁺` について `pq∈L` と `ptq∈L` は同時に成立しない。

**証明**。`p≠ε` なら、`p` と `pt` は文脈 `(ε,q)` を共有し、代入可能性より同一分布を持つ。`pt^kq` の先頭因子 `p` を `pt` に交換すると `pt^{k+1}q∈L`。`k=0` からの帰納で無限に異なる語を得る。`p=ε` なら `q≠ε`（`pq∈Δ⁺`）なので、`q` と `tq` は文脈 `(ε,ε)` を共有し、`t^kq` の末尾因子 `q` を `tq` に交換すれば同じ矛盾が生じる。□

**補題2.2（位置識別符号による有限 CE の保存）**。`L⊆Δ⁺` が有限で Clark–Eyraud 代入可能、`h` が位置識別符号なら、`h(L)` も Clark–Eyraud 代入可能である。

**証明**。`H=h(L)` と書く。`x,y∈Σ⁺` と `p,q∈Σ*` が `pxq,pyq∈H` を満たすとする。任意の `p',q'` に対し `p'xq'∈H ⇒ p'yq'∈H` を示す（対称性で逆も成立）。

**(i) 分割位置の一意性。** `H` の任意の語を符号語に分割する方法は一意である。さらに、語の任意の一文字から、その文字が属する符号語の名前とその符号語内のオフセットが復元できる。したがって因子 `x` の任意の出現では、その始点・終点のオフセット、両端にある不完全符号語の**具体的な接尾片・接頭片**、およびその間に含まれる完全符号語の列が決定される。これは始点や終点が符号語の**途中**にある場合にも成立する。因子が符号語1個の内部に完全に収まる場合はその符号語・両切断位置が決定され、因子が隣接する二つの符号語だけを横断する場合も両符号語と切断位置が決定される。

**(ii) ゼロ個の完全符号語を含む穴。** 共通文脈 `(p,q)` で `x` の穴に完全符号語が一つも含まれない場合、穴は一つの符号語の内部、または隣接二つの符号語にまたがる断片である。文脈 `p` の末端は切断の直前までの符号語位置を固定し、`q` の先頭は直後からの符号語位置を固定する。`y` の穴も完全符号語を含まず、その間に符号語の追加もなければ、間の物理的な文字列は一意であり `x=y`。一方 `y` が余分な完全符号語を含む、あるいは左右の不完全片が**同一符号語に属する場合**に間へ符号語を追加するなら、`pxq` と `pyq` を逆符号化した二つの `L` の語は、一方が他方に空でない抽象語を一箇所挿入した関係になる。これは補題2.1に反する。`x,y` の役割を逆にした場合も同様。よって `x≠y` の共通受理文脈があるとき、両穴にはそれぞれ**1個以上の完全符号語**が入る。

この場合の「挿入」の確認を明示しておく。`p` の末端が符号語 `d` の途中、`q` の先頭が `d'` の途中なら、左右の既出トークン `d,d'` を固定し、その**間**に介在する完全符号語列が穴の可変部分となる。介在列が空なら、非空の別の介在列をもつ語は明らかに挿入で得られる。両端が**同一の1個の** `d` にある短い穴に対し、長い穴ではその `d` が左右の二つの出現に分かれるため、長い方は `d` と次の `d` の間の列を増やした挿入語となる。片側が符号語境界であるときは該当する `d` または `d'` を一つ省いた同じ議論である。どのケースも補題2.1に帰着する。

**(iii) 両穴に完全符号語がある場合。** 各因子は一意に

`x=α h(X) β`, `y=α h(Y) β`, `X,Y∈Δ⁺`

と書ける。ここで `α` は左端に残る適切な（空でもよい）**不完全符号語の接尾片**、`β` は右端に残る適切な**接頭片**である。共通文脈 `(p,q)` の左右切断位置が同じなので、`α,β` は `x,y` に共通である（位置識別性が重要）。さらに逆符号化すると、ある共通の抽象文脈 `(P,Q)` に対して `PXQ,PYQ∈L`。Clark–Eyraud 代入可能性から `D_L(X)=D_L(Y)` を得る。

`p'xq'∈H` を任意にとる。`x` の各文字は符号語位置を指定するため、この出現でもその端の不完全片 `α,β` と完全符号語列 `X` は変わらない。したがってある抽象文脈 `(P',Q')` で `P'XQ'∈L` と表せる。`D_L(X)=D_L(Y)` より `P'YQ'∈L`。同じ両端断片 `α,β` の間で `h(X)` を `h(Y)` に交換したものが、まさに `p'yq'` である。よって `p'yq'∈H`。逆も同じ。□

**注意**：この補題は **有限** の CE 言語に対して述べた。無限言語への無条件拡張は、補題2.1（挿入不能性）が使えないので主張しない。また一般の語準同型による CE 保存を主張していない。位置識別性が「符号語の途中で切れる穴」に必要な整列情報を与えるのである。

## 3. 部分定理：位置識別語による指数障害

**定理3.1（位置識別された語の障害）**。`r_max≥2` とし `s:Σ⁺↠S` を固定する。相異なる冪等元 `e,z` が `ez=ze=z` を満たすとする。`u,v,w∈Σ⁺` が

- `s(u)=s(v)=e`、`s(w)=z`、`uv≠vu`、
- `u,v,w` を通じた**全ての文字出現が相異なる**（定義2の位置識別符号条件）

を満たすなら、`C_{1,s}` において、rank 2 の reduced good CFG `G_n`（`||G_n||, θ̄_{G_n}=O(n)`）をもつ有限標的 `H_n` があり、全ての特徴標本は長さ `2^{Ω(n)}` の語を含む。下界は冒頭に挙げた三種類の集合駆動作用素について成立する。

**証明**。抽象字母 `A,B,C` 上の原稿 `K_n` に `h(A)=u, h(B)=v, h(C)=w` を施して `H_n=h(K_n)` とする。`K_n` は有限 CE 言語なので、補題2.2から `H_n` も CE である。したがって特に `H_n∈C_{1,s}`。文法については §4 で評価する。型 `e` の唯一語についても §4 で明示する。唯一語を `V_n` とすれば `H_n\s^{-1}(e)=H_n\{V_n}` は原稿の `lem:type-deletion` により `C_{1,s}` に属する（有限なので CFG でもある）。原稿の `prop:rare-type` を `m=e` について適用すると、指定した各作用素の特徴標本は `V_n` を含む。`|V_n|` の指数増大は §4 の式により従う。□

`uv≠vu` は定理の仮定として残してあるが、**位置識別符号**なら `u,v` の文字集合が互いに素なので実際には自動的に成り立つ。したがってこれは一般の非可換語対の証明ではない。位置識別条件を任意の非可換語から導く命題も**証明されていない**。

## 4. 文法サイズ・厚さ・希少語の定量評価

具体的な規則は

```text
S  -> E_n
E_0 -> u
E_i -> v E_(i-1) E_(i-1) v   |   w E_(i-1) w       (1<=i<=n).
```

`u,v,w` は固定の非空文字列であり、右辺で各非終端の変数は1回ずつ現れる。よって fan-out 1、rank 2、λ-free、nondeleting、nonpermuting、nonmerging。`w` 分枝を上に重ねれば各 `E_i` および全ての規則を成功導出中で使えるので reduced good である。

`a=|u|, b=|v|, c=|w|` とおく。原稿 §2 のサイズの定義に従い

`||G_n|| = (2b+2c+9)n + (a+6)`.

どの規則も、上のレベルを全て `w` 分枝、子部分木も全て `w` 分枝とする成功文中で使用できる。特に第 `i` レベルの `v` 分枝を使う文の長さは

`2(n-i)c + 2b + 2(a+2(i-1)c) = 2a+2b+2(n+i-2)c`.

他の規則のための文は `a+2nc` 以内である。ゆえに

`θ̄_{G_n} ≤ max{1, a+2nc, 2a+2b+(4n-4)c} = O(n)`.

`V_0=u, V_i=v V_(i-1) V_(i-1) v` とおく。全ての規則の各ブロック型は `e` または `z` であり、`e²=e`, `ez=ze=z`, `z²=z` なので、`H_n` の語の型が `e` であることは、その導出が一度も `w` 分枝を使わないことと同値である。各レベルで `v` 分枝しか使わない導出は**ただ一つの出力語** `V_n` を与える（位置識別性により別導出との衝突もない）。長さは

`|V_n| = 2^n a + 2b(2^n-1) = (a+2b)2^n-2b`.

従って全ての対象特徴標本 `F` は `V_n∈F` を満たし、原稿の符号長 `||F||_+` について

`||F||_+ ≥ |V_n|+1 = (a+2b)2^n-2b+1`.

各定数は固定した `u,v,w` に依存してよい。表現のサイズが O(n)、普通の規則厚さが O(n) でも指数である。

## 5. T2：既存の文字障害を真に超える型付け

有限**可換**半群 `S={1,g,z}` を、`1` は単位元、`g²=1`、`z` は全元に対する零元（`xz=zx=z`）として定義する。アルファベット

`Σ={a,b,c,d,t}`

で

` s(a)=s(b)=s(c)=s(d)=g,    s(t)=z `

とする。`g` と `z` は文字像、`1=g²` は正語像なので `s` は全射である。`e=1` とすれば `e,z` は異なる冪等元で `ez=ze=z`。しかし**型1の文字は0個**であり、原稿 `cor:typing-level-obstruction` の仮定は満たさない。

選ぶ語は

`u=ab,  v=cd,  w=t`.

すると `s(u)=g²=1=s(v)`、`s(w)=z` で、`uv=abcd≠cdab=vu`。さらに `ab`,`cd`,`t` の各文字は全て異なるため、位置識別符号の条件を満たす。定理3.1が**実際に**適用できる。

その標的・文法を直接書くと

```text
E_0 -> ab
E_i -> cd E_(i-1) E_(i-1) cd  |  t E_(i-1) t
S   -> E_n
```

であり、定量値は

- `||G_n|| = 15n+8`。
- `θ̄_{G_n} = 4n+4`（各 `w` 分枝が最短で、最も厚い規則は最上位の `cd E_(n-1) E_(n-1) cd`）。
- 型 `1` の語は `V_0=ab`, `V_i=cd V_(i-1) V_(i-1) cd` の**唯一語**であり、`|V_n|=6·2^n−4`。
- したがって `||F||_+≥6·2^n−3`。下界は `B^{≤r}_{1,s}` (`r≥1`)、`B_{1,s}`、および `C_{1,s}` 全体に特徴標本を持つ集合駆動作用素に成立する。これを**多項式非存在**の結論として用いる場合は `r_max≥2` とする。

この例では、**非可換な同型語があるのに型 e の文字は存在しない**。それゆえ、原稿の従来の「同型の二文字」障害が個々の型付けに対する必要条件ではないことを示す。`S` はそもそも可換なので、障害の核心は `S` が非可換なことではなく、自由半群の正語のなかに異なる並び方を持つ `e` 型語があることだと分かる。

## 6. T1 の一般形について残る障害

任意の非可換な `u,v` が `s(u)=s(v)=e` を満たすとき、二語集合 `{u,v}` がコードになるという語の組合せ論の事実だけでは本証明は完結しない。**復号可能性**は完成した符号語列に対する性質であり、代入可能性は符号語を途中で切った**全ての因子と二側文脈**を比較するためである。

今回使った位置識別符号では、たとえば `u=ab` の途中の因子 `b` は「`u` の第2文字」だと一意に分かる。これに対し `u=ab,v=ba` では一文字 `a` が `u` の第1文字にも `v` の第2文字にもなり、補題2.2の「因子の端点が一意な符号語位置を指定する」が成立しない。`{ab,ba}` は長さ一定のコードであっても位置識別符号ではない。

一般予想Aを進めるなら、次のいずれかが必要になる。

1. `u,v,w` から型を保ちながら、切断位置を**有限状態と文脈で一意に復元できる同期コード**を組み立て、その復元補題を証明する。
2. 分布一致を扱うスタック・パーザを直接定義し、符号語途中の遷移を加えた上で、元原稿 `app:u1-typings` の到達可能スタックの単射性と branch synchronization を完全に再検証する。
3. 位置が決まらないときの複数の復号を、型 `s` の等しさによって排除する新しい typed substitutability の議論を構築する。

いずれも今回の証明には**含まれていない**。特に、非可換性のみから常に comma-free な3符号語を作れる、という未検証の主張を採用しない。

**計算上の観察**：`u=ab,v=ba,w=c` や `u=aab,v=aba,w=c` について、小さい `n` の `h(K_n)` は CE 検査を通った。ただしこれはこの二つの符号に関する全称命題でも、予想Aの証明でもない。

## 7. T3：予想Bの正確な量化と位置づけ

`S` の冪等元集合を `E(S)` として

`U(S) = {(e,z)∈E(S)² : e≠z, ez=ze=z}`

とおく。`S∉LG` ⇔ `U(S)≠∅`。各 `e` について `F_e=s^{-1}({e})⊆Σ⁺` は、`s` が全射なので非空である。

**予想Bの精密化（未解決）**：`S∉LG` かつ

`∀(e,z)∈U(S)  ∀u,v∈F_e : uv=vu`

を満たす全射型付け `s` について、固定 `r_max≥2` のもと、ある多項式 `p_s(X,Y)` が存在して、全ての `L∈C_{1,s}` とその任意の reduced good rank≤`r_max` 文法 `G` に対し、`B^{≤r_max}_{1,s}` が `||F||_+≤p_s(||G||,θ̄_G)` の特徴標本を持つか。これを確定するには、**単なる文法サイズでなく普通の厚さを含む**長さ上界が必要である。

**補題7.1（共通原始根への還元）**。`F_e` の語が全て互いに可換なら、ある原始語 `p_e` があり `F_e⊆p_e^+`。**証明**：`u∈F_e` を一つ固定し、その原始根を `p_e` とする。全ての `v∈F_e` は `uv=vu` を満たす。自由半群の二語の可換性定理（Lyndon–Schützenberger の標準的事実）により `u,v` は同一の原始根の冪なので `v∈p_e^+`。□ ただし `s(p_e)=e` とは限らない（ある冪だけが `e` になってもよい）。

**論理的な分割**：`S∉LG` の全ての型付けは、

- (A条件) `∃(e,z)∈U(S) ∃u,v∈F_e : uv≠vu`、または
- (B条件) `∀(e,z)∈U(S) ∀u,v∈F_e : uv=vu`

のちょうど一方を満たす。これは量化された命題の否定律による**代数的な二分**である。ただし、A条件なら全て指数、B条件なら全て多項式という**学習データ量の二分法は未成立**。`S∈LG` は別途原稿 `thm:local-group-polydata` によって多項式側に入る。

- `s_{U,2}`（`a↦1,b↦z`）の `F_1={a^k:k≥1}` は B条件を満たす。
- 原稿 `prop:binary-u1-quadratic` は、この型付けで少なくとも `θ̄_G` に関して二次の標本長を必要とすることを示すので、**B条件から線形**の結論は偽。ただし**多項式**の可能性は排除しない。
- 原稿 `op:S1` はまさにこの最小例における多項式性を未解決としている。したがって B 全体を本報告で肯定することはできない。
- **追加条件付き多項式の即時系**：もし対象表示について、full yield-type refinement の厚さ `t_typ(G,s)` が `||G||, θ̄_G` の固定多項式で抑えられるなら、原稿 `cor:typed-sandwich` の上界から `B^{≤r_max}_{1,s}` のデータは多項式である。これは新たな B の構造定理ではなく、必要な不足補題を明確にする条件付き命題である。
- rank 1（線形 CFG）に制限した場合は、原稿が引用する companion CFG 論文の線形定理により任意の固定型付けで多項式になる。しかしこれは rank 2 の `op:S1` を解決しない。

## 8. T4：本部分定理の族はファンアウト2から外れる

位置識別符号による `H_n` では、希少型唯一語は `V_n=vV_{n-1}V_{n-1}v` であり、`V_n` の先頭には **`v^n u`** が現れる。第二の `V_{n-1}` の先頭にも `v^{n-1}u` が現れる。ここで `u` の先頭は `v` の先頭と異なる文字なので、先頭の `v` ブロック数は確定している。

`n≥5` とし、原稿の `lem:power-transfer` の冪対象を `v` とする。`s(v)=e=e²` より eventual index `i_0=1`、period `q=1` が使える。`a=1`, `d=1`, `b=n−4≥1` とすれば `a+d+b+2=n` である。`V_n` は因子 `v^n` を含む。

別の位置で、`V_n` の初頭の第一 `v` を `w_L`、直後の `v^a` を第一穴、第二の `V_{n-1}` の先頭にある `v^{n-1}` の末尾 `v^{d+b}=v^{n-3}` を第二穴に選ぶ。中間語 `w_M` は少なくとも最初の `u` を含むので空でない。従って

`V_n=w_L v^a w_M v^{d+b} w_R`.

もし `H_n∈C_{2,s}` なら `lem:power-transfer` から

`w_L v^{a+d} w_M v^b w_R ∈ H_n`

を得る。変換は `v` だけを一方の穴から他方へ移すので `s` 型は依然 `e`。しかし変換後の語の初頭の `v` の連続ブロックは `v^{n+1}u` となり、もとの唯一の型 `e` の語 `V_n` の初頭 `v^n u` と異なる。`H_n` に型 `e` の語は `V_n` しかないため矛盾。ゆえに `n≥5` で `H_n∉C_{2,s}`、従ってどの `f≥2` にも入らない。□

これは既知の `lem:power-transfer` を本族に適用した帰結であり、fan-out 2 の新しい指数下界ではない。

## 9. 全数検査（Windows Python 3 標準ライブラリ）

次のコードは具体例 §5 の `n=1,2,3` に対し、**全ての出現因子** `x` とその全二側文脈 `(p,q)` を列挙し、共通文脈を持つ二因子の分布集合が等しいかを厳密に比較する。型条件なしの CE 検査と型条件ありの検査を両方実行する。有限集合を完全に走査する限り、この `n` に関しては正確であるが、**全 n の定理を証明するものではない**。

保存名の例：`check_typing.py`。Windows では `py -3 check_typing.py`。

```python
from collections import defaultdict

ALPHA = 'ab'
BETA = 'cd'
GAMMA = 't'

def make_k(n):
    words = {ALPHA}
    for _ in range(n):
        words = ({BETA + x + y + BETA for x in words for y in words}
                 | {GAMMA + x + GAMMA for x in words})
    return words

def value(word):
    if 't' in word:
        return 'z'
    return len(word) % 2  # a,b,c,d -> g; g^2=1

def substitutable(words, typed=False):
    dist = defaultdict(set)
    ctx = defaultdict(set)
    for word in words:
        for i in range(len(word)):
            for j in range(i + 1, len(word) + 1):
                factor = word[i:j]
                context = (word[:i], word[j:])
                dist[factor].add(context)
                ctx[context].add(factor)
    for context, factors in ctx.items():
        groups = defaultdict(list)
        for x in factors:
            groups[value(x) if typed else '*'].append(x)
        for group in groups.values():
            if not group:
                continue
            distribution = dist[group[0]]
            for y in group[1:]:
                if dist[y] != distribution:
                    return (context, group[0], y)
    return None

def unique_rare(n):
    v = ALPHA
    for _ in range(n):
        v = BETA + v + v + BETA
    return v

for n in (1, 2, 3):
    words = make_k(n)
    v = unique_rare(n)
    rare = [x for x in words if value(x) == 0]
    ce = substitutable(words)
    typed = substitutable(words, True)
    assert ce is None and typed is None, (n, ce, typed)
    assert rare == [v], (n, len(rare))
    assert len(v) == 6 * (2 ** n) - 4
    print('n=%d  |L|=%d  maxlen=%d  rarelen=%d  CE=pass  typed=pass' %
          (n, len(words), max(map(len, words)), len(v)))
```

検査結果：

```text
n=1  |L|=2  maxlen=8  rarelen=8  CE=pass  typed=pass
n=2  |L|=6  maxlen=20  rarelen=20  CE=pass  typed=pass
n=3  |L|=42  maxlen=44  rarelen=44  CE=pass  typed=pass
```

**検査の限界**：`n=1,2,3` の CE 性と希少型の唯一性は全探索済みだが、補題2.2の全称命題、定理3.1の全 `n`、ファンアウト2の非所属を計算で代替していない。それらは上の数学的証明による。`n=4` 以降の言語は分枝数が急増するため、有限全探索をもって無限族の裏づけを誇張しない。

## 10. 結論・研究上の次の一手

**今回証明した最も強い主張**は、任意の非可換語対ではなく、**文字位置を完全に識別できる三つの符号語**をもつ型付けについて、既存の三文字倍増族から指数特徴データ下界を移植できる、というものである。その特別な場合だけでも、**型 e の文字がゼロ個**の明示的型付けで指数障害が成立するため、既存の文字障害を真に拡張する。

他方、`uv≠vu` のみから同期コードを作る全称補題、任意の符号途中因子を扱うパーザの到達状態単射性、そして B 側の rank-2 多項式性は解決していない。今後の本命は、位置識別符号という非常に強い仮定を、**bounded synchronization delay と有限状態の位相復元**に弱めることである。この弱化ができれば、`u=ab,v=ba` のような実際に重なり合う語に進める。
