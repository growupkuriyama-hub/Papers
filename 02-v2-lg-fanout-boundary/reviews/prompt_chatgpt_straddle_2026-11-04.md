## 1. 報告の主張（Claude の検証による整理）

Σ = {a, b, c}、内容型付け c、L ∈ C_{2,c} とする。G は L∩Σ⁺ の reduced good な表示で、ファンアウト ≤ 2、ランク ≤ r。v = |V|、θ = θ̄_G とおく。k := μ_a(L) ≥ 5 とし、T を a^k の節点数最小で一様な導出とする。場合 I は、b⁴ と c⁴ がともに L の語に現れる場合である。節点が**内部**とは、範囲（出力の最初の文字から最後の文字まで）が a^k の最初の文字も最後の文字も含まないこと。

- **補題E（詰め物付きの交換）**：a を含まない語 P、Q（b と c を含む）が単一塊の性質 SB を持つとする。SB(P, d) は「s, t ≥ 1、s+t = k−d なら a^s P a^t ∈ L」を意味する。d_P ≤ d_Q ≤ k−3 なら D(a^{1+d_Q−d_P}P) = D(aQ)。
- **補題F（a の移送）**：u の両端が a でなく、L のある語に a^i u a^t（i ≥ 2、t ≥ 1、極大な連）が現れるなら、D(a²u) = D(aua)。
- **系F**：これにより、塊の間の一文字の a を取り除いて塊を融合でき、逆に入れて分離もできる。
- **系2.3**：内部の両文字型ラベル X の代表の a を含まない部分を全てつないだ塊 F_X について、SB(F_X, d_X) が成り立つ。
- **補題V**：範囲が互いに素な内部の両文字型節点が n 個あれば、低いラベルの融合した塊を、どの順序でも並べた語が L に入る。
- **定理C**：d_X = Λ(κ_X) + μβ_X + νγ_X。μ, ν は核によらない。
- **命題4.1**：融合した塊の鎖も SB を持ち、損失は足し算になる。
- **補題P**：場合 I では、同じ偶奇類（先頭の文字、連の数の偶奇）の低い内部の両文字型ラベルについて、d_X = ⟨φ_P, (n'_X, β_X, γ_X)⟩（定数項なし）。理由は、鎖の核が (先頭の文字, Σn') だけで決まり、鎖の長さに依らないことである。
- **定理D**：場合 I で、条件 (S1)（範囲が互いに素な内部の両文字型節点が二つある）の下で、μ_a ≤ max{4θ+8, K_D^{43}R^{42}θ}。ここで K_D = (2v+E_D)(2r+1)、E_D = v(48θ³+θ+20)、R = θ+2v+2。
- **系D**：場合 I で G がファンアウト1なら、無条件に μ_a ≤ poly_r(v, θ)。(S1) が成り立たなければ、内部の両文字型節点は一本の道に乗り、N_bc ≤ 3v となるからである。

**Claude の検証で補ったこと（確かめること）。** 補題V では、差し替えの元にする節点 z_i にも k − ℓ_{z_i} ≥ θ+2（系2.3 の前提）が要る。報告はこれを明記していない。Claude の読みでは、これは自動的に成り立つ。互いに素な内部の重い節点 z₁, z₂ について ℓ₁ + ℓ₂ ≤ k − 2 で、ℓ₂ > θ だから k − ℓ₁ ≥ θ + 3 となる。

## 2. してほしいこと（優先順）

1. **独立の検証（最優先）。** 次の各点を、反例を探すつもりで確かめる。誤りがあれば反例か正しい形を、正しければ「どの段を自分で確かめたか」を書くこと。
   - 補題F の「再配分」の段：a^i から a^t へ一文字移すのが系2.2 で許されるか。u が b と c を含み、a⁴ だけを使う。
   - 系2.3 と補題V の a の予算。特に、差し替えの元にする節点が大きい場合と、範囲が隣り合う場合の分離。
   - 命題4.1 の鎖の帰納法（補題E で鎖 C を塊として交換する段）。
   - 補題P で、**個数の違う多重集合どうし**を比べてよいこと。鎖の核が個数によらないことと、(R) の適用条件を確かめる。
   - 定理D で、前回の補題3.1・3.2 を偶奇類の区分にそのまま使ってよいこと。群の値の窓、例外の数え方、点 (n', β, γ) が [1, θ]³ に入ること。
   - 系D の場合分け（ファンアウト1で (S1) が成り立たないなら、内部の両文字型節点は祖先関係で一列に並ぶ）。
2. **場合 I・ファンアウト2の「跨ぎ」の場合を解く。** (S1) が成り立たないなら、全ての内部の両文字型節点の範囲は一点 p を含む（報告 §5.5）。目標は、この場合も μ_a ≤ poly_r(v, θ) を示して、場合 I を全てのファンアウト ≤ 2 の表示で解くこと。Claude の観察（確かめること）は次のとおり。
   - 入れ子の対 x₁（左の成分 L₁、右の成分 R₁）と、その間にある x₂（L₂、R₂）を両方差し替え、補題F で L₂ と R₂ を融合すると、L₁ a^p F_{X₂} a^q R₁ の形の語が得られる。さらに補題E で、F_{X₂} を任意の低い内部ラベルの塊 F_Y に替えられる。
   - ここから、二つの完全な塊が離れて並ぶ語（(S1) の代わり）を作れるか。作れなければ、L₁ と R₁ を「外側の殻」として扱う二穴版の補題E・F と、二穴の鎖で補題P を作り直せるか（報告 §5.5 の筋）。
   - 跨ぐ節点が少ない（例えば poly(v, θ) 個以下）場合は、第十報の (4.2) で片付くかも確かめる。
3. **場合 II・III。** 定理C（D = m+2, m+3）より先へ進める。
   - 場合 II では核は a を含まない部分の語そのものなので、鎖どうしの関係は語として一致する場合だけである（Lyndon–Schützenberger）。
   - 一方、命題4.1 により L は塊の任意の鎖を含む。b と c の連が長さ 3 以下という条件と、鎖の中の部分語どうしの arity 1・2 の代入可能性から、塊の集合に制約（符号になれない、など）が出るか。
   - 否定側では、全ての並べ替えと融合を含む言語を小さい文法で作れるか。
4. **否定側。** 場合 II か III で、次を全て満たす G_n を作る。
   - L_n ∈ C_{2,c}
   - ‖G_n‖ と θ̄_{G_n} が n の多項式

   新しい候補では、次をどう避けるかを先に説明すること。

   - arity 1 と 2 の代入可能性（省略しない）

## 3. 計算について

- 無限言語の候補は、正確な所属判定器で検査する。

## 4. 守ってほしいこと

- 冒頭に、主張ごとの判定（証明済み／反証／観察／未解決）と根拠の節を書いた表を置く。検証した主張には「独立に確認」「誤り」「確認できず」のいずれかを書く。
- 「自明に成り立つが目的には足りない」主張は、その旨を表に書く。
- まだ所属を示していない言語に、その所属を前提にした補題を使わない。
- 下界には次の条件を明記する。
  - 作用素：B^{≤r}_{2,c}、B_{2,c}、クラス全体に特徴標本を持つ集合駆動作用素
  - ファンアウト、ランク、アルファベット
- 証明した範囲を超えて書かない。特に、場合 I の結果を三文字の全ての場合に広げて書かない。
- 「最大の特徴標本」と書かない。
- 「境界がファンアウトで動く」は、三文字の全ての内容型を証明した場合にだけ書く。
- 新しい結果が文献で既知かどうか、分かる範囲で書く。分からなければ「未確認」と書く。
