## 1. 結論

**PROVED（交錯 Seed・下記の室の下。RR は仮定しない）：`D=2δ`。**

- RR は不要である。長さ4の c 連を持つ受理語が仮定から**導出**され、そこから `cb≡bc` が出る。
- 方向B の前提「極大 b 連・c 連長が2以下」は Single・Seed・二穴代入可能性と**両立しない**（補題N）。
- 一穴代入可能性だけでは `D=2δ` は出ない（命題M、有限言語レベル）。二穴が本質的である。
- **未処理**：入れ子 Seed のみの場合（§4 末尾）。

## 2. 仮定

`Σ={a,b,c}`、型は成分ごとの `alph`。L は1穴・2穴の内容型付き組代入可能、`a^N` は最短の正 a 冪。`J=(bc,bc)`, `K=(bbcc,bbcc)`、欠損 `δ,D≥1`、`Δ=D−δ`、`M=N−δ−D`。MS の前提（適法 Single、実在する加法的**交錯** Seed、Comm）を仮定し、室は

**(H)** `2·max(δ,D) ≤ N−4`。

MS から次を受理済みとして使う（J,K はブロック `bc`,`bbcc` の略記）。

- `W_J=JJ a^{N−δ}`、`W_K=KK a^{N−D}`、`W_JJ=JJJJ a^{N−2δ}`、`W_JK=JKJK a^{M}`、`W_KK=KKKK a^{N−2D}`

## 3. 新しい補題

### 補題A（閉単位の a 吸収、一穴）

- 比較片：`x=bcbc·a^k`, `y=bbccbbcc·a^{k−Δ}`。実型はともに `{a,b,c}`。`k=max(1,1+Δ)`。
- `E₀=(ε, a^{N−δ−k})`：`E₀[x]=W_J`, `E₀[y]=W_K`。
- `E₁=(bcbc, a^{N−2δ−k})`：`E₁[x]=W_JJ`。
- 第四語：**`JJKK a^{M}∈L`**。

室は `k≤N−2δ` で、(H) から従う。単位数が変わる置換だが、a 指数は E₀ の二語で直接照合しており、CA 型の推論は使っていない。得られる語は平方 `σσ` の形ではなく、MS の外にある。

### 補題C（入れ子化交換、二穴）

- 比較組：`x=(bbcc, c)`, `y=(bcb, cc)`。実型はともに `({b,c},{c})`。
- `E₀=(bc, b, bbcc·a^{M})`：`E₀[x]=bc·bbcc·b·c·bbcc a^M=W_JK`、`E₀[y]=bc·bcb·b·cc·bbcc a^M=JJKK a^M`（補題A）。
- 中央 `b` と各成分は非空。

よって中央が非空の任意の二穴文脈で `(bbcc,c)` を `(bcb,cc)` に替えられる。因子 `bbcc` を1個消費して、後方の c 連を1伸ばす交換であり、a 数は変わらない。

### 補題N（連長2の破れ）

`E₁=(ε, bbc, a^{N−D})`：`E₁[x]=bbcc·bbc·c·a^{N−D}=W_K`。したがって

**`bc·bbbccc·a^{N−D}∈L`**。

b 連・c 連の最大長が2という制約は、仮定の下では成立しえない。

### 補題R（c⁴ の導出）

`W_KK` に補題C を2回適用する。

1. `E₁=(bbccbbcc, bbc, a^{N−2D})`：`E₁[x]=W_KK` → `V₁=bbcc·bbcc·bc·bbbccc·a^{N−2D}∈L`。
2. `E₁=(bbcc, bcbbb, cc·a^{N−2D})`：`E₁[x]=V₁` → **`V₂=bbcc·bc·b·bc·bbb·c⁴·a^{N−2D}∈L`**。

### 命題M（一穴だけでは不足、有限言語）

`e₁≠e₂`, `gcd(e₁,e₂)=1`, `e₁e₂>N` とする。L_M を「(b,c) を括弧と見た深さ2以下の Dyck 語の深さ0にだけ a を挿入した語で、`#a+e₁·(深さ1の対の数)+e₂·(深さ2の対の数)=N`」とする。

- 3状態の両決定性オートマトン（b=+1, c=−1, a は深さ0のループ）で受理される。a を含む因子は開始状態が一意、a を含まない因子は平行移動で、`e₁e₂>N` から重みが対の数 `(u₁,u₂)` を一意に決める。これにより一穴内容型代入可能性が手で確認できる。
- `δ=2e₁`, `D=2(e₁+e₂)≠2δ`、連長は2以下、Single と加法的交錯語を持つ（例：`e₁=20, e₂=21, N=400`）。
- しかし二穴は破れる。補題C の x,y は文脈 `(a^i, b, ·)` を共有するが、`bbcc·ab·c` は受理され、`bcb·ab·cc` は深さ1に a が入るので受理されない。

これは有限言語レベルの観察で、**木由来 P_tree の反例ではない**。

## 4. 定理と証明

**定理。** §2 の仮定の下で `D=2δ`。

*証明。*

**(Rc)** `V₂=l₀·c⁴·a^{N−2D}`（`l₀=bbccbcbbcbbb`）。`x=(cc,c)`, `y=(c,cc)`、型 `({c},{c})`、`E₀=(l₀, c, a^{N−2D})`、`E₀[x]=E₀[y]=V₂`。

**(CC)** `W_JK=bcbb·cc·b·c·bbcc·a^M`。`E₁=(bcbb, b, bbcc·a^M)` で `E₁[x]=W_JK`、よって `w₂=bcbb·c·b·cc·bbcc·a^M∈L`。

- 比較片：`cb`, `bc`。実型はともに `{b,c}`。
- `E₀=(bcbbc, c·bbcc·a^M)`：`E₀[cb]=W_JK`, `E₀[bc]=w₂`。
- 帰結：**`cb≡bc`**（全一穴文脈、コスト0）。

**(終結)** `cb→bc` を繰り返すと `W_JJ` から `b⁴c⁴a^{N−2δ}∈L`、`W_K` から `b⁴c⁴a^{N−D}∈L`。文脈 `(b⁴c⁴,ε)` を共有するので `a^{N−2δ}≡a^{N−D}`（型 `{a}`、(H) により両指数≥4）。`a^N` に適用すると `a^{N+2δ−D}`, `a^{N+D−2δ}∈L`。`D≠2δ` なら一方が N より短い正 a 冪となり、最短性に反する。∎

「Parikh が等しいから並べ替える」は使っていない。並べ替えはすべて導出済みの合同 `cb≡bc` による。中間核の Rot 証人も使っていない。

**証明が止まる箇所（入れ子 Seed）。** 入れ子の MS は `JKKJ`, `KJJK` を与え、`JKJK` を与えない。補題A は Seed の種類によらず `JJKK`, `JKKJ`, `KKJJ` を与えるが、補題C の E₀ には `P·KJ·Q` と `P·JK·Q` の同時受理が要り、この4語の中にその対は無い。入れ子ではここが最初の未構成箇所である。

## 5. MS・MX・RR・AB16 との関係

- **MS**：出発語5個の供給源。補題A が MS に無い非平方語 `JJKK` を足す。
- **RR / MX**：この最小例では RR は仮定ではなく帰結になる。t=1 の CC だけで足りるので、閾値は `m≥2χ+1=5` ではなく `m=4` で済んだ。MX を引用せず直接閉じている。
- **AB16**：連結宿主 `a^*bbcc a^*` も `N≥6maxδ+1` も使わない。宿主の役は補題C が作る深い語 `V₂` が担う。
- **依存**：MS（監査で VALID WITH CLARIFICATIONS）と (H)。`W_KK` は補題A を `JJKK` に再適用しても得られ、`D≥δ` なら室は `N≥2D+1` まで緩む（未精査）。
- **射程**：一般 P_tree、一般 AB、非可換 U、正式 `op:fanout-two` は OPEN のまま。内部 a を含む単位は扱っていない。

## 6. 次に残る最小課題（1件）

**交錯 Seed の一般単位 `(b^p c^q, b^r c^s)` で、補題A＋補題C 型の「入れ子化交換」により RR（長さ `2χ+1` の c 連）を仮定から導出できるか。** できれば MX が無条件になり、a-free 混合支持の Parikh 剛性が RR なしで閉じる。
