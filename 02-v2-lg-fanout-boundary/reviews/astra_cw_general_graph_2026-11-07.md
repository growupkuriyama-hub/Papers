正本の good は λ-free・nondeleting・nonpermuting・nonmerging。λ-free により全生成の全成分が非空。SUB₁ は非空語を比較し、外側の文脈は空でもよい。零型の非経路語は受理されず、その分布は空である。

### 1.2 203という数の意味

6つの端点を順に (tail a,head a,tail b,head b,tail c,head c) と並べる。グラフは、この6位置のどれが同じ頂点かという集合分割と同じデータである。孤立頂点を認めず、文字ラベルを固定するので過不足がない。

頂点数別の数は Stirling 数 S(6,k)：1,31,90,65,15,1。その和が203。S(n,k)=kS(n−1,k)+S(n−1,k−1) から手で計算できる。独立スクリプトは既存頂点0,…,m−1か新頂点mを順に選ぶ restricted growth string を生成する。頂点置換を総当たりしたり原スクリプトを呼んだりしない。文字a,b,cまで置換で同一視する数ではない。

### 1.3 「長い」「内部」の正確な意味と17種の導出

原S9の `unbounded_ab` は、長さ≤4の歩道のうち**内容がちょうどabで長さ≥3**のものがあるかを判定する。これはこの2辺の場合には本当に非有界性と同値である。

理由：両文字を含む長さ≥3の語には、同じ文字の隣接 aa または bb があるか、交互の aba または bab がある。前者は一方の辺がループ、後者は逆向きの2辺サイクルを強制する。したがって ab部分グラフは次のどれか：

- 同一頂点のa,bの二つのループ（1種）。
- 逆向きのa,bの二辺サイクル（1種）。
- 一方がループ、他方がその頂点に接続する非ループ辺（文字の選択×向きで4種）。

いずれもループまたはサイクルを繰り返して長いab歩道が得られ、長さ3の証人もある。従って長さ4の上限を超えたところで新しい「長い」形が出ることはない。

原S9の `interior` は、**a,bの両方を含む経路語で、最初でも最後でもない位置にcが少なくとも一つ現れること**。cが複数回あってもよい。独立計算では「直前の非初文字がc」「既に内部cを見た」の有限状態を使い、長さを制限せず判定した。

上の6種へのcの置き方を調べる。

1. 二ループ一頂点の場合：cもその頂点のループのときだけ内部cが可能。1種。
2. ab二サイクルの場合：cの両端がその2頂点内にある場合だけ可能。ループ2通り、平行辺2通り、計4種。新頂点を持つcは、入る辺なら最初、出る辺なら最後にしか使えない。
3. ループℓと非ループ辺dの場合：cはdの両端のどちらかのループ（2通り）、またはdの逆向き辺（1通り）だけ。新頂点に接続すればcは端にしか来ない。dと同方向の平行辺ならdとcを同一歩道で両方使えない。4×3=12種。

合計1+4+12=17。以下の群I=5種、II=4種、III=8種とする。「強連結5種」は **D_ab と D_abc の両方**が強連結という意味。群IIもD_abcだけは強連結である。

## 2. (CW) の有限生成による証明

### 2.1 強連結支持の一般補題

Mの辺を全て使う部分グラフが強連結とする。頂点x上の閉歩道のパリクの格子は

\[
 C_x^M=\ker_{\mathbb Z}\partial_M.
\]

ここでM外の座標は0とする。証明：各辺を通る閉歩道を連結して、全M座標が正の閉歩道ベクトルzを得る。任意の整数循環hに対し、NzとNz+hを全座標正にできる。両者は境界0、支持が強連結なのでxを始点とするオイラー閉歩道を持つ。その差hがC_x^Mに入る。逆包含は境界0から明らか。

同じ条件で、任意のs,tについて

\[
 D_{stM}=\ker_{\mathbb Z}\partial_M.
\]

実際、全Mを使うs→t歩道pを一つ取る。任意のh∈ker∂に対してp+Nz、p+Nz+hを全座標正にすれば、境界は1_t−1_s、支持は強連結なので共にs→tのオイラー歩道が存在する。この2歩道の差がhである。これで**任意長の歩道が作る格子を尽くした**。単なる有理線形空間の議論ではなく整数格子の等式である。

今回の1・2頂点の場合、この整数核の短い生成元は、ループの単位ベクトルと、逆方向の辺を一つずつ組にした二サイクルのベクトルだけである。唯一の非自明な境界式は「0→1の総数＝1→0の総数」。以下で個々の生成元が短い閉歩道の整数結合として実現することまで示す。

### 2.2 群I：両支持が強連結（番号1,11,12,13,14）

記号 e_a,e_b,e_c を標準基底とする。

**番号1。** C₀^{ab}=D₀₀,ab=⟨e_a,e_b⟩、C₀^{abc}=D₀₀,abc=ℤ³。閉歩道a,b,cが生成元を与える。w₂=ab,w₃=abcで差e_c。r=0。全CW成立。

**番号11,14（cがループ）。** u=e_a+e_b。abについて、全s,tに対しC_s^{ab}=D_st,ab=⟨u⟩。両頂点の閉歩道ab,baがuを与える。abcについて全s,tでC_s^{abc}=D_st,abc=⟨u,e_c⟩。

cの頂点では閉歩道cがe_cを与える。他の頂点では、二サイクルと「行ってcを一度通り戻る」長さ3の閉歩道の差がe_c。したがってCは長さ≤3の閉歩道で生成される。任意のab歩道w₂はcの頂点も通るのでそこにcを一度挿入したw₃との差はe_c。cを含む閉歩道は両端点上に存在する。rはどちらの頂点でもよい。CW1–3成立。

**番号12,13（cが平行辺）。** dをcの逆向きのab辺とし、u=e_a+e_b、v=e_c+e_d。全s,tに対しC_s^{ab}=D_st,ab=⟨u⟩、C_s^{abc}=D_st,abc=⟨u,v⟩。閉歩道ab/baとcd/dcが各頂点で生成元を与える。境界方程式から整数核がこの2元で尽くされる。任意のw₂の始点にc,dの二サイクルを挿入してw₃を作れば差v。CW2のc付き閉歩道もこれ。rはどちらでもよい。

### 2.3 群II：ループと、cで戻れる辺（番号3,6,9,16）

ℓ∈{a,b}をループ、dを残るab辺、cをdの逆向き辺とする。ℓの頂点をp、もう一方をqとする。ab歩道の端点対は (tail d,head d) の一つだけ。全てのabパリクは

\[
 n e_\ell+e_d\quad(n\ge1),
\]

ゆえにD_ab=⟨e_ℓ⟩。C_p^{ab}=⟨e_ℓ⟩、C_q^{ab}=0。

abc部分は強連結。u=e_d+e_cとして、全4端点対でD_st,abc=C_p^{abc}=C_q^{abc}=⟨e_ℓ,u⟩。pではℓと二サイクル、qでは二サイクルと「pに行ってℓを通り戻る」長さ3の閉歩道がこの格子を生成する。後者2本の差がe_ℓである。

abとabcが両方存在する唯一の端点対では、任意のab歩道w₂の始点にd,cのサイクルを挿入してw₃を得る。差u、c付き閉歩道は同サイクル。CW3にはr=pを取る。他の3対はabcだけなのでCW2・CW3は空条件で、CW1は上記等式。これで16組全てを扱った。

### 2.4 群III：一方向の辺とループ（番号2,4,5,7,8,10,15,17）

ℓをabのループ、dを非ループ辺、cはdのどちらかの端点のループ。唯一の端点対は (tail d,head d)。非ループ辺dはちょうど一度しか使えず、任意の経路パリクは

\[
 \Pi_{ab}=\{n e_\ell+e_d:n\ge1\},\qquad
 \Pi_{abc}=\{n e_\ell+e_d+k e_c:n,k\ge1\}.
\]

どのn,kも、各ループをその頂点で回ってdを一度渡ることで実現できる。従ってD_ab=⟨e_ℓ⟩、D_abc=⟨e_ℓ,e_c⟩。C_x^MはxにあるMのループの単位ベクトルで生成される格子で、それ以外の閉歩道はない。よってD=C_s+C_tでCW1。

w₂をℓとdを一度ずつ使う歩道とし、cの頂点でcを挿入してw₃を作る。差e_c、c自体が端点上の閉歩道なのでCW2。rをℓの頂点に取ればCW3。8組全てを扱った。

### 2.5 格子の有限生成をさらに明示する

上の証明はCを長さ≤3の閉歩道で生成し、Dを明記した整数格子に等しいと示した。Dの生成元も短い経路の差で実現できる。

- 強連結支持では、所定のs,tについて全Mを使う基準歩道を取る。今回の形では長さ≤5で取れる。各閉歩道の単純サイクルを、そのサイクル上の頂点を通る位置に挿入する。基準歩道は全辺を通るので必要な頂点を通る。挿入するサイクルは長さ1または2。この差が上の整数核の生成元になる。
- 群IIのabではℓdとℓ²d（向きによりdℓ,dℓ²）がe_ℓを与える。
- 群IIIではℓ,d,cを各一度使う歩道と、ℓまたはcを一度増やす歩道との差が生成元。

基準歩道の長さ≤5は、二サイクル＋ループなら全辺を含む長さ3の閉歩道に高々1辺を足せばよく、二サイクル＋平行辺なら全辺を含む長さ4の閉歩道に高々1辺を足せばよいことから従う。よって**長さ≤7の歩道の差でDの全格子が既に生成される**。原観察の上限7は、この分類では結果的に十分だった。

格子の表現と計算HNFの全一致は付録B。安定性だけでは上の証明を置き換えられない。

### 2.6 (CW) を全グラフに主張してはいけない

Dを a:0→1, b:1→2, c:1→1 とする。s=0,t=2ではab歩道はabのみ、abc歩道はac^k b (k≥1)。従ってD_st,abc=ℤe_cだがC₀^{abc}=C₂^{abc}=0。CW1・CW2が失敗する。

それでも各内容の受理ab語は空か{ab}で、受理ab語があればμ_ab=2。これは系3.6(b)の反例ではない。今回の目標に必要なのは17種のCWであり、全203種のCWではない。

この例では有限A・SUB₁のときabcの受理値も一剰余類になる：c^iを共通文脈(a,b)で比較し、cの前後への追加による有限巡回群上の移動を使えばよい。abの実現値は一つだけなので、(16)の共通Hにも障害はない。従ってCWの失敗から直ちにK1,K2の反例は得られない。

## 3. 定理2.9の証明の点検と補足

### 3.1 補題2.9a：[正しい]

B_x^Mを、空語の値0と、x上・内容⊆Mの非空閉歩道の値全体とする。連結に閉じるのでAの部分モノイド。有限群内では各bについて−b=(ord(b)−1)bもB_x^Mに属する。従ってB_x^Mは部分群。

C_x^Mは閉歩道パリクの**整数**生成格子なので、Φ(C_x^M)は同じ閉歩道値の生成部分群。よってB_x^M=Φ(C_x^M)。二端点の和もそれぞれの閉歩道α,βで実現する。

c付き閉歩道γがsにあるなら、その値hを先に取り、g−hを残りのα₀,βで実現する。α=γα₀とすれば内容⊆Mを保ち、cを含み、値の和はg。tの場合も同じ。負の係数を歩道として実現できるところにAの有限性が必要である。

### 3.2 補題2.9b：[正しい]

y,y′はr上の非空閉歩道、内容S、同分布。u=u₁u₂はrで切る。u₁またはu₂が空でもよい。o=ord φ(y)≥1とするとu₁y^o u₂は経路、値はφ(u)、内容はS⊆cont(u)によりcont(u)、端点も不変。従ってuと同じ型。

文脈(u₁y^{o−1},u₂)に同分布を適用して、最後のyをy′に交換する。値だけがg=φ(y′)−φ(y)動く。o=1ならy^{o−1}=εであり、外文脈の空は許される。非空成分を空語と比較しているわけではない。

### 3.3 K1：[正しい]、Λの剰余類の説明を補う

M∈{ab,abc}、受理値pを固定し、B=Φ(D_stM)、E=Φ(C_s^M+C_t^M)とする。CW1よりB⊆E。

逆に、任意のs上またはt上の閉歩道を、内容Mの固定s→t歩道の端に加えると、内容Mの2歩道の差になる。従ってC_s^M+C_t^M⊆D_stM、ゆえにB=E。この逆包含は任意の長さについて真である。

Λ⊆p+BはDの定義から明らか。p+B⊆Λは詰め物補題から従うのでΛ=p+B。

p,p′を受理する同内容語w,w′は空文脈を共有するためSUB₁で同分布。x∈Λに対し値x−pの詰め物α,βを取り、同一文脈(α,β)で比較すると

\[
x\in P_{stM}\iff x+(p'-p)\in P_{stM}.
\]

各差による移動はΛを保つ。したがってH′_M=⟨P−P⟩に不変であり、P=p+H′_M。単にΛとの交わりでなく、剰余類全体が実現される。これはK1の主張どおり。

### 3.4 K2(i)：両方の受理集合が非空なら正しい

以下P₂,P₃≠∅とする。CW2の証人w₂⁰,w₃⁰を固定する。任意のabc歩道uとab歩道wについて

π(u)−π(w)=[π(u)−π(w₃⁰)]+[π(w₃⁰)−π(w₂⁰)]+[π(w₂⁰)−π(w)]。

第一項はCW1のabc格子、第二項はCW2、第三項はCW1のab格子により、全てC_s^{abc}+C_t^{abc}に入る。従って任意のx∈Λ₃を、受理ab語wにc付き詰め物を付けて実現できる。同分布の受理ab語w,w′を比較するとP₃はd=φ(w′)−φ(w)に不変。P₃は非空なのでd∈H′₃。ゆえにH′₂⊆H′₃。

**非空性の必要性：** P₃=∅ならこの議論からH′₂⊆H′₃=0とは言えない。この場合は後述の別枝にする。

### 3.5 K2(ii)：g=0と空の閉歩道集合を補う

g∈H′₃∩Φ(D_st,ab)を取る。**g=0なら結論は自明なのでここで終える。** g≠0の場合、CW3のrについてΦ(C_r^{ab})が非零。従ってr上の非空ab閉歩道が存在する。

S_rはそのような閉歩道の内容の合併。S_r≠∅。各文字を含む閉歩道を有限個選んで連結すれば内容がちょうどS_rの閉歩道ζが得られる。B_r=Φ(C_r^{ab})。詰め物により、内容S_rの閉歩道の値はφ(ζ)+B_rを尽くす。よってy=ζと、同内容でφ(y′)=φ(y)+gのy′が取れる。

受理abc語ωは辺a,bを使うので、それらの始点・終点を全て訪問する。従って任意のr∈V_abを通り、その訪問の切れ目でω=ω₁ω₂と分けられる。ω₁の終点・ω₂の始点はrであり、両方が存在するとは限らないが、空文脈端は許される。

o=ord φ(y)。ω₁y^oω₂はωと同じ型で受理。ω₁y^{o−1}y′ω₂は同じ端点、同じabc内容で値がgだけ増える。K1とg∈H′₃からこれも受理。従ってy,y′は文脈(ω₁y^{o−1},ω₂)を共有し、内容S_rが等しいためSUB₁により同分布となる。

任意のab語u∈Path(s,t)もrを通りS_r⊆ab=cont(u)。補題2.9bが適用され、P₂+g=P₂。P₂≠∅なのでg∈H′₂。これでH′₃∩Φ(D_ab)⊆H′₂。

原文はS_r=∅でもζを取るように読めるが、その場合C_r^{ab}=0でg=0しかない。上の一行の分岐で修正できる。

### 3.6 K2(iii)と空集合の正しい定式化

P₂,P₃が共に非空なら、B₂=Φ(D_st,ab)、H=H′₃と置くと、(i)(ii)よりH∩B₂=H′₂。Λ₂=g₂+B₂、K1よりP₂=g₂+H′₂だから

\[
 (g_2+H)\cap\Lambda_2=g_2+(H\cap B_2)=P_2.
\]

P₃=g₃+Hであり(16)の形になる。

空集合の場合も明記する：

- P₂≠∅,P₃=∅：許容内容集合を{ab}、H=H′₂とする。
- P₂=∅,P₃≠∅：許容内容集合を{abc}、H=H′₃とする。
- 両方空：許容内容集合を空にする。

**原文の「P_ab=(g_ab+H)∩Λ_ab」を空のP_abにも無条件に書くのは誤り。** 例えば一頂点・自明群でLが全abc語なら、H=0、Λ_ab={0}で、どの剰余類も空にならない。しかし(16)の許容内容集合からabを外せば正しく表せる。したがって構造定理自体には穴はなく、表示の省略を直すべきである。

## 4. 定理3.2・補題3.8・系3.6(b)の点検

### 4.1 端点対を合算しない理由

全体Lの最短ab語Wを選び、その始点・終点(s,t)を固定する。Wの最初・最後の位置に印を置き、それだけでa,b両方を覆わなければ不足文字の一出現にも印を置く。印は区別された位置で高々k=3個。

一文字一辺なので、先頭文字と末尾文字が保たれれば語の始点と終点も保たれる。以後、受理語であることは元のGで、端点保持はこの印で確保する。L∩Path(s,t)の別文法を作る必要がなく、端点対の数を上界に掛ける必要もない。

最短長のWの導出のうち節点数最小のものを選ぶ。これを省くと、長さを減らさず単位規則の鎖だけ短縮する場合の議論が不明確になる。

### 4.2 定理3.2の場合A

印を含まない重い節点z（|y(z)|>θ_loc）の最短生成への置換は、印を保って短くなる。従ってその最短生成はcを含まなければならない。λ-freeにより全成分が非空なので、外にある最初・最後の印も端の位置を保つ。

比較不能な二節点z,z′があるなら、単独・同時に置換した3語W_z,W_z′,W_zz′は同じ(s,t)のabc語。P₃が空なら矛盾。P₂とP₃の剰余類が異なる場合には

φ(W)=φ(W_z)+φ(W_z′)−φ(W_zz′)∈g₃+H

となりφ(W)∈g₂+Hと矛盾。従って印なし重い葉は高々1、印あり重い葉は高々3。

各根葉道で印集合は包含により単調に減り、高々4区間。同一印集合の区間で同ラベルが繰り返すと、H報告補題3.1の短絡で、短いab語か同長で少節点の導出を得て矛盾する。この短絡時の端点保持は不要。最短性はL全体で選んでいるからである。

重い節点数は高々4葉×4区間×v=16v。H報告と同じ重い木の境界の数え上げで|W|≤16(r+1)vθ_loc。根が重くなければ|W|≤θ_locで直接成立。

### 4.3 補題3.2′の代表と場合B

代表の条件は、区別された各印について所定の成分にその文字の出現を選べること、先頭・末尾の印があればその成分の先頭・末尾にあること、と厳密化する。重複文字の印も位置として区別する。各局所状態は、各大域印について「不在」または成分1,…,fのどれか、計高々(f+1)^k通り。

印のある部分木の祖先の和集合を背骨とする。背骨外の子を最短生成にする。同じラベルと同じ局所状態が祖先・子孫で繰り返したら短絡する。先頭印を含む成分はその印から始まり、子孫の対応する成分もその印を含む部分語なので、その印から始まる。型が同じなら成分番号も一致する。末尾も同様。これで短絡は端点条件を保存する。

各印への道は高々v(f+1)^k節点、背骨は高々kv(f+1)^k節点。各背骨節点の直接終端と背骨外の最短生成の総和は(T3)でθ_loc以下。従って印あり代表は長さ≤kv(f+1)^kθ_loc≤81vθ_loc。**印なしの代表はτ(B)≤θ_loc**と別に定義する（k=0を乗じて0とはしない）。

p_zをこの代表、p′_zを元規則に子の代表を代入した生成、δ_z=π(p′_z)−π(p_z)、p₀=π(rep(S))とする。規則の先頭・末尾に来る印は、その終端自身か先頭・末尾の子成分にあり、代表でも維持される。両証人W[z←p_z],W[z←p′_z]は元のGの生成で、同じ先頭・末尾文字とa,bの印を持つ。従ってPath(s,t)に入る。

\[
\pi(W)=p_0+\sum_z\delta_z.
\]

印ありの子は高々3。印なしの子は最短生成なので(T3)にまとめて数え、

\[
 |p_z|,\|p_0\|_1\le81v\theta_{loc}=\Theta_0^E,

\begin{aligned}

元の定数は正しい。なお、abcが空の場合は場合Aに入れてよく、H報告自身がそれを場合Bにも含める記述との違いは結果を変えない。

### 4.4 補題3.8

グラフに内部c付きabc歩道がないとする。印なし重い節点があれば、短い生成への置換はcを導入する一方、最初・最後の位置の印は外にあるため不変。従って導入されたcは内部位置にあり、a,bも残る。グラフの仮定に矛盾。

### 4.5 無条件化に際する論理の注意

## 5. 独立計算の方法と結果

### 5.1 分類・格子

標準ライブラリだけで独立実装した。203コードをrestricted growth stringで生成し、内部cは有限状態の到達可能性で厳密に判定した。歩道の計算は語を全列挙せず、(始点,終点,パリク)を動的計画法で全て保持する。この併合でC,Dに必要な情報は失われない。

長さ7,10,14について、対象17種の全頂点のC（2内容合計66個）と存在する全端点対のD（2内容合計70個）を計算した。整数のEuclid行操作により、正のピボットと、その上を剰余に還元した**標準的な行Hermite標準形**を作り、完全一致を確認した。単なる階数や有理張りの比較ではない。§2で導いた「ループと逆向き辺の対」の生成格子とも全て一致。CW違反は0。

別途、非飽和格子を含む500例で整数可逆行操作に対するHNFの不変性・冪等性を確認した。これも手の証明の代用ではなく、実装の点検である。

### 5.2 型の厳密なSUB₁判定

各グラフ・文字値を固定し、単文字型から右に1文字ずつ加えて到達可能型Rを閉じる。Rが有限なのでこれは無限長の全語を正確に覆う。文脈の左右をR∪{ε}から取れば、零を受理しない限り全ての非空分布を正確に判定できる。非経路の因子は分布が空であり、SUB₁違反を作れない。

型τと文脈eの結果をF_e(τ)∈R∪{⊥}と書く。同内容のτ,τ′に対しSUB₁は、全e,fについての次の有限論理条件と同値：

\[
 P(F_e(\tau))\land P(F_e(\tau'))\land P(F_f(\tau))
 \Longrightarrow P(F_f(\tau')),
\]

およびτ,τ′を交換した式。P(⊥)は常に偽。スクリプトはこれを、共通文脈が受理されたら全ての文脈の受理ビットを等しくする、という形で実装する。**K1,K2を列挙の枝刈りに仮定していない。**

全Pの検証を二つの方法で行った。

1. **全モデル列挙。** 各受理ビットの真偽を分岐し、上の論理条件の正・負リテラルを伝播する。条件違反の枝だけを捨てるので全SUB₁集合を漏れなく列挙する。各完成PでK1,K2を検査した。初回の3群の検査は全完成Pで分布も直接照合。最終スクリプトでは論理条件自体が厳密なSUB₁判定であり、分布による独立照合は最初の10件と1000件ごとに行う。
2. **全Pに対する含意検査。** ℤ/6の大きなモデル列挙を完走する代わりに、下記の必要十分な有限含意を全て検査した。これはランダム標本でも、有限語長による近似でもない。指定した型系の**全Pに量化した検証**である。

全モデル列挙器自体について、17グラフの自明な値写像と一頂点の非自明なℤ/2の型系、計18系・117,632個の生の全ビット集合を列挙し、分布からの直接判定との完全一致を確認した。さらにℤ/2の全17グラフ・全8写像のモデル数は、正リテラルのみを伝播する先行実装と正負を伝播する実装で全て一致した。

### 5.3 全P含意検査がK1,K2を尽くす理由

非空の集合S⊆Aが一剰余類であることは、x,y,z∈S⇒x+y−z∈Sと同値である。基点p∈Sを引けば、S−pが加法と逆元に閉じることになる。従ってK1は各(s,t,M)内の全三つ組についての受理含意で検査できる。結論値が実現不能なら、その前提がSUB₁と両立不能であることを要求する。

K1を全Pについて確立した後、両内容が非空の場合のK2は、次の全三つ組の含意で検査できる：

- x∈P₃, y,z∈P₂ ⇒ x+y−z∈P₃。
- x∈P₂, y,z∈P₃, x+y−z∈Λ₂ ⇒ x+y−z∈P₂。

第一式はH′₂⊆H′₃、従ってP₂⊆g₂+H′₃を与える。第二式は任意のx=g₂∈P₂と、実現可能なx+h（h∈H′₃）に対して受理を保証し、逆包含(g₂+H′₃)∩Λ₂⊆P₂を与える。K1からP₃は剰余類なので、H′₃の任意の元を**一つの差y−z**として取り出せる。このため長い差の和を別に列挙する必要がない。空の内容は§3.6どおり省く。この含意への変換にはCWを仮定しない。

各含意の前提（高々3個の受理型）から、SUB₁論理条件の最小閉包を求めた。閉包が矛盾ならその前提を含むSUB₁集合はない。矛盾せず結論を含めば、前提を含む全SUB₁集合が結論を含む。結論が含まれないなら閉包自身が反例になる。各閉包のSUB₁は分布からも直接点検した。

この方法はK1,K2のグラフによる証明を仮定しない。論理含意の変換は上記の初等群論だけを使う。

def plus(a,b): return tuple(x+y for x,y in zip(a,b))
def minus(a,b): return tuple(x-y for x,y in zip(a,b))
def mask(p): return sum(1<<i for i,x in enumerate(p) if x)
def graphs(prefix=(0,)):
    if len(prefix)==6:
        yield prefix; return
    for x in range(max(prefix)+2): yield from graphs(prefix+(x,))
def edges(g): return tuple(zip(g[::2],g[1::2]))
def walks(g,limit):
    """DP of (start,end,Parikh); preserves all Parikh vectors, not word multiplicity."""
    E=edges(g); allstates=set(); layer=set()
    for i,(s,t) in enumerate(E):
        p=tuple(int(j==i) for j in range(3)); layer.add((s,t,p))
    for _ in range(limit):
        allstates |= layer; nxt=set()
        for s,t,p in layer:
            for i,(u,v) in enumerate(E):
                if t==u:
                    q=list(p); q[i]+=1; nxt.add((s,v,tuple(q)))
        layer=nxt
    return allstates

def interior_c(g):
    # State remembers a noninitial c awaiting a following letter, or witnessed interior c.
    E=edges(g); seen={(t,1<<i,False,False) for i,(s,t) in enumerate(E)}; todo=list(seen)
    while todo:
        v,m,pending,done=todo.pop()
        if done and m&3==3: return True
        for i,(s,t) in enumerate(E):
            if s!=v: continue
            z=(t,m|1<<i,i==2,done or pending)
            if z not in seen: seen.add(z); todo.append(z)
    return False

def strong(g,letters):
    E=[edges(g)[i] for i in letters]; V=set(sum(([s,t] for s,t in E),[]))
    for start in V:
        reach={start}
        while True:
            nxt=reach|{t for s,t in E if s in reach}
            if nxt==reach: break
            reach=nxt
        if reach!=V: return False
    return True

def classification(g):
    long=any(mask(p)==3 and sum(p)>=3 for s,t,p in walks(g,4))
    return long,interior_c(g),strong(g,[0,1]) and strong(g,[0,1,2])

def hnf(vectors):
    """Canonical row Hermite normal form: positive pivots; entries above reduced."""
    a=[list(v) for v in set(vectors) if any(v)]; k=0
    for j in range(3):
        cand=[i for i in range(k,len(a)) if a[i][j]]
        if not cand: continue
        a[k],a[cand[0]]=a[cand[0]],a[k]
        for i in range(k+1,len(a)):
            while a[i][j]:
                q=a[k][j]//a[i][j]
                a[k]=[x-q*y for x,y in zip(a[k],a[i])]
                a[k],a[i]=a[i],a[k]
        if a[k][j]<0: a[k]=[-x for x in a[k]]
        for i in range(k):
            q=a[i][j]//a[k][j]; a[i]=[x-q*y for x,y in zip(a[i],a[k])]
        k+=1
    return tuple(tuple(r) for r in a[:k])
def subset(A,B): return hnf(list(A)+list(B))==hnf(B)

def lattice_data(g,L):
    W=walks(g,L); V=range(max(g)+1); C={}; D={}; bases={}
    for x in V:
        for m in (3,7): C[x,m]=hnf(p for s,t,p in W if s==t==x and mask(p)&~m==0)
    for s,t in it.product(V,repeat=2):
        for m in (3,7):
            ps=sorted(p for a,b,p in W if (a,b)==(s,t) and mask(p)==m)
            if ps:
                bases[s,t,m]=ps[0]; D[s,t,m]=hnf(minus(p,ps[0]) for p in ps)
    pairs=sorted({(s,t) for s,t,m in D})
    for s,t in pairs:
        for m in (3,7):
            if (s,t,m) in D: assert subset(D[s,t,m], C[s,m]+C[t,m]),(g,s,t,m,'CW1')
        if (s,t,3) in D and (s,t,7) in D:
            assert any(x[2] for x in C[s,7]+C[t,7]),(g,s,t,'CW2c')
            assert subset([minus(bases[s,t,7],bases[s,t,3])],C[s,7]+C[t,7])
            assert any(subset(D[s,t,3],C[r,3]) for r in set(g[:4]))
    return C,D,pairs

def predicted_lattices(g, C, D):
    E=edges(g); unit=[tuple(int(i==j) for i in range(3)) for j in range(3)]
    # For a two-vertex support, integer circulations are generated by loops
    # and pairs consisting of one edge in each direction.
    def cycles(m):
        gens=[]
        for i,(s,t) in enumerate(E):
            if m>>i&1 and s==t: gens.append(unit[i])
        for i in range(3):
            for j in range(i):
                if m>>i&1 and m>>j&1 and E[i][0]!=E[i][1] and E[i]==E[j][::-1]:
                    gens.append(plus(unit[i],unit[j]))
        return hnf(gens)
    for (x,m),actual in C.items():
        letters=[i for i in range(3) if m>>i&1]
        if strong(g,letters): expected=cycles(m)
        else: expected=hnf(unit[i] for i in letters if E[i]==(x,x))
        assert actual==expected,('C formula',g,x,m,actual,expected)
    for (s,t,m),actual in D.items():
        # Every allowed support here is either strongly connected or one bridge plus loops.
        assert actual==cycles(m),('D formula',g,s,t,m,actual,cycles(m))

class FiniteTypes:
    def __init__(self,g,moduli,phi):
        self.moduli=moduli; self.zero=(0,)*len(moduli)
        self.add=lambda a,b:tuple((x+y)%n for x,y,n in zip(a,b,moduli))
        self.sub=lambda a,b:tuple((x-y)%n for x,y,n in zip(a,b,moduli))
        E=edges(g)
        seen={(s,t,phi[i],1<<i) for i,(s,t) in enumerate(E)}; todo=list(seen)
        while todo:
            s,t,v,m=todo.pop()
            for i,(u,w) in enumerate(E):
                if t==u:
                    z=(s,w,self.add(v,phi[i]),m|1<<i)
                    if z not in seen: seen.add(z); todo.append(z)
        self.R=sorted(seen); self.index={z:i for i,z in enumerate(self.R)}; self.n=len(seen)
        # Context words are either empty or a realizable nonempty path type.
        context=[None]+self.R; rows=[]
        for x in self.R:
            row={}
            for li,l in enumerate(context):
                if l is not None and l[1]!=x[0]: continue
                for ri,r in enumerate(context):
                    if r is not None and r[0]!=x[1]: continue
                    z=(l[0] if l else x[0],r[1] if r else x[1],
                       self.add(self.add(l[2] if l else self.zero,x[2]),r[2] if r else self.zero),
                       (l[3] if l else 0)|x[3]|(r[3] if r else 0))
                    row[li,ri]=self.index[z]
            rows.append(row)
        self.rows=rows
        # Each comparison stores distinct pairs of context outcomes. -1 means non-path.
        comparisons=set()
        for i,x in enumerate(self.R):
            for j in range(i):
                if self.R[j][3]!=x[3]: continue
                pairs={(rows[i].get(c,-1),rows[j].get(c,-1)) for c in rows[i].keys()|rows[j].keys()}
                if all(a==b for a,b in pairs): continue
                positive=tuple(sorted({(1<<a)|(1<<b) for a,b in pairs if a>=0 and b>=0}))
                if not positive: continue
                moves=tuple(sorted({(1<<a if a>=0 else 0,1<<b if b>=0 else 0) for a,b in pairs if a!=b}))
                comparisons.add((positive,moves))
        self.comparisons=list(comparisons)
        self.k_cache={}
        self.blocks=defaultdict(list)
        for i,(s,t,v,m) in enumerate(self.R):
            if m in (3,7): self.blocks[s,t,m].append((i,v))

    def close(self,p,negative):
        # Propagate positive and negative literals of the exact SUB1 implications.
        while True:
            old=(p,negative)
            for triggers,moves in self.comparisons:
                active=any(p&t==t for t in triggers)
                if active:
                    for a,b in moves:
                        if p&a or p&b:
                            if not a or not b: return None
                            p |= a|b
                        if not a or not b or negative&a or negative&b:
                            negative |= a|b
                else:
                    mismatch=any((p&a and (not b or negative&b)) or
                                 (p&b and (not a or negative&a)) for a,b in moves)
                    if mismatch:
                        for t in triggers:
                            missing=t&~p
                            if missing and missing&(missing-1)==0:
                                negative |= missing
                if p&negative: return None
            if (p,negative)==old: return p,negative

    def exact_sub1(self,p):
        # Independent final criterion: distributions disjoint or equal.
        seen=defaultdict(dict)
        for x,row in zip(self.R,self.rows):
            dist=frozenset(c for c,i in row.items() if p>>i&1)
            inv=seen[x[3]]
            for c in dist:
                if c in inv and inv[c]!=dist: return False
                inv[c]=dist
        return True

    def subgroup(self,gens):
        h={self.zero}; todo=[self.zero]
        while todo:
            x=todo.pop()
            for g in gens:
                y=self.add(x,g)
                if y not in h: h.add(y); todo.append(y)
        return h

    def check_K(self,p):
        sets={}; groups={}
        for key,block in self.blocks.items():
            local=p&sum(1<<i for i,v in block)
            cachekey=(key,local)
            if cachekey not in self.k_cache:
                vals={v for i,v in block if local>>i&1}
                H=set()
                if vals:
                    base=min(vals); H=self.subgroup([self.sub(v,base) for v in vals])
                    assert vals=={self.add(base,h) for h in H},('K1',key,vals)
                self.k_cache[cachekey]=(vals,H)
            vals,H=self.k_cache[cachekey]; sets[key]=vals; groups[key]=H
        for s,t in {(s,t) for s,t,m in sets}:
            a=sets.get((s,t,3),set()); b=sets.get((s,t,7),set())
            if not a or not b: continue  # inactive contents excluded from (16)
            H=groups[s,t,7]; base=min(a)
            realized={v for i,v in self.blocks[s,t,3]}
            assert a==realized&{self.add(base,h) for h in H},('K2',s,t,a,b)

    def universal_K(self):
        """Exhaustive universal Horn entailment, quantifying over ALL P.

        Finite nonempty sets are cosets iff closed under x+y-z.
        After K1, common-H K2 is equivalent to the two cross-content shifts.
        Each query is decided by the least SUB1 model containing its premises.
        """
        queries={}
        def require(premises,key,value):
            seed=sum(1<<i for i in set(premises))
            target=self.index.get((key[0],key[1],value,key[2]))
            queries.setdefault(seed,set()).add(target)
        for key,block in self.blocks.items():
            for (i,x),(j,y),(k,z) in it.product(block,repeat=3):
                require([i,j,k],key,self.sub(self.add(x,y),z))
        for s,t in {(s,t) for s,t,m in self.blocks}:
            two=self.blocks.get((s,t,3),[]); three=self.blocks.get((s,t,7),[])
            realized={v for i,v in two}
            for (i,x),(j,y),(k,z) in it.product(three,two,two):
                require([i,j,k],(s,t,7),self.sub(self.add(x,y),z))
            for (i,x),(j,y),(k,z) in it.product(two,three,three):
                value=self.sub(self.add(x,y),z)
                if value in realized: require([i,j,k],(s,t,3),value)
        impossible=0
        for seed,targets in queries.items():
            closed=self.close(seed,0)
            if closed is None:
                impossible+=1; continue
            p,negative=closed
            assert self.exact_sub1(p)
            for target in targets:
                assert target is not None and p>>target&1,('universal K counterexample',seed,p,target)
        return len(queries),impossible,sum(map(len,queries.values()))

    def all_models(self):
        full=(1<<self.n)-1
        def visit(p,negative):
            closed=self.close(p,negative)
            if closed is None: return
            p,negative=closed
            remaining=full&~(p|negative)
            if not remaining:
                yield p; return
            bit=remaining&-remaining
            yield from visit(p,negative|bit)
            yield from visit(p|bit,negative)
        yield from visit(0,0)
