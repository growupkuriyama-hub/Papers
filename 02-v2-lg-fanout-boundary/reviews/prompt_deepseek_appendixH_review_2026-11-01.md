### 1.2 査読してほしいこと（理論）

各補題について、**証明を一文ずつ**確かめ、次の形で表にしてください：補題名／判定（正しい・修正が必要・誤り）／問題の箇所と理由／直し方の提案。特に次の点を重点的に見てください。

1. **`lem:app-two-runs`(i)**：二つの塊の間の因子 Z が空でないこと、許容文脈の条件、「正の整数への分割は一単位ずつの移動でつながる」こと。
2. **`lem:app-two-runs`(iv)**：W_2 と W_1 が本当に存在するか（予備の x があることから、R の長さを 2 と 1 にでき、他の塊が全て長さ 1 以上で済むか）。文脈 (U, xV′) と (U_1, y^{e′}V_1) の分解が正しいか。y^{e+e′} が本当に因子として現れるか。
3. **`lem:app-two-alternate`**：塊が4個以上なら、両方の文字について内部の塊があるか。y の再配分で β を長さ1にするとき、x の塊が変わらないこと。
4. **`lem:app-two-insertion`**：
   - 印が ≤ 8 個で、Q_0 の大きさが |Q| − 8 以上になること。
   - 単独の差し替えで「純な成分に他の文字が入る」ことの議論（`lem:witness-length-template`(i) を λ = ĉ で使えるか）。
   - 独立集合 I の大きさ |Q_0|/5 以上（最大次数 ≤ 4）。
   - 同時の差し替えで、異なる持ち主の挿入が別の塊になり、その塊が内部の塊（両隣が元の文字）になること。
   - 異なる文字の純な成分に入る場合に、6個の別々の塊ができること。
5. **`prop:app-two-nonsaturated`**：三つの場合（a⁴ と b⁴ がどちらも現れない／両方現れる／片方だけ現れる）で矛盾が本当に出るか。型付きラベルが ≤ 9|V| 個で、パス上で繰り返さないこと（切っても長さが増えず節点が減る）。重い節点の数え上げ 13 · 9|V| と、長さの上界 117(r+1)|V|θ̄。
6. **`lem:app-two-saturated`**：
   - 和が Σ の場合：内容の型が 𝐭 の組が「n_a ≥ t_a、n_b ≥ t_b」のときだけ存在すること、c_x = n_x − t_x + 1 を使った二つの最小性の議論、不等式 ⌊(p+n)/(n−t+1)⌋ ≤ p+t、値の個数 ≤ θ̄+5、同じ深さの重い節点 ≤ θ̄+4、最後の 30(r+1)|V|θ̄³。
   - 一文字の場合の (P1)–(P6)：使っている代入可能性が a と a^{1+δ}（どちらも内容 {a}）の一穴の比較だけであること。(P4) の頻出ラベルの比の議論、(P5) の α* の上界、(P6) の数え上げと定数 42r(r+1)+5。
7. **定理の証明**：|S♯| = 4 で N_typ ≤ 4^{2r}‖G‖ になること、二つの場合の上界がどちらも C_r|V|²θ̄⁵（C_r = 42r(r+1)+117(r+1)、r ≥ 2）以下になること、特徴標本の長さの二つの式の算術。
8. **`cor:two-letter-semilattice`**：二文字の半束型付け s が s ⪯ c を満たし、`lem:typing-monotone` が使える向きになっていること。
9. **本文の説明**：§8 の説明文、要旨、序論、`op:S1`、`op:fanout-two` の書き換えが、証明した範囲を超えていないか。

### 1.3 計算による検証（Python 3 標準ライブラリのみ）

次を行い、スクリプトの全文と出力を報告書に載せてください（Windows の `py -3 script.py` で動く形）。有限の検査は「観察」として扱い、証明とは区別してください。ただし、具体的な反例が見つかった場合は、それ自体が証明になります。

1. **有限言語での補題の検査**：Σ = {a,b} 上の小さな有限言語（例：長さ ≤ 7 の語からなる集合）を、ランダムに、または系統的に多数作り、(2,c)-代入可能性（d = 1 と 2、許容文脈は二穴の間が空でない）を**全数検査**して、通ったものを集めてください。有限言語では分布は観察された文脈の集合なので、この検査は正確です。通った言語について、次が成り立つかを調べてください。
   - `lem:app-two-runs`(i)：x⁴ が現れるなら、同じ x 骨格・同じ x の個数の二語で、所属が一致する。
   - (ii)：xxyx か xyxx を含む語があれば、Parikh 飽和。
   - (iii)：飽和でなければ、xx を含む語の内部の y の塊は長さ ≥ 2。
   - (iv)：飽和でなく y⁴ が現れなければ、xx を含む語の内部の y の塊は高々一つ。
   - `lem:app-two-alternate`：飽和でなく a⁴, b⁴ が両方現れれば、塊が4個以上の語は全ての塊が長さ1。
   
   注意：有限言語で x⁴ が現れると、補題の前提を満たす言語は少ないかもしれません。その場合は、言語の大きさや語の長さの範囲を工夫してください（例：a の塊の長さだけを変えた語の族を混ぜる）。どの範囲を調べたかを正確に書いてください。
2. **不等式の検査**：⌊(p+n)/(n−t+1)⌋ ≤ p+t（n ≥ t ≥ 1、p ≥ 0）、(θ+4)(θ+5) ≤ 30θ²（θ ≥ 1）、(P5)・(P6) の各不等式、定理の証明の最後の算術を、小さい範囲の全数と、記号的な確認の両方で確かめてください。
3. **（余力があれば）小さな文法での τ の計算**：小さな reduced good な文法（ファンアウト ≤ 2、ランク 2）で、生成する言語が (2,c)-代入可能なものを作り、型付き非終端の代表の長さ τ_X を全数探索で求めて、定理の上界と比べてください。
