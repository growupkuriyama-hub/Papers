## 2. 定義

- $\ell\ge1$、$k=|\Sigma|$ とする。
- $s_\ell:=s_{\ell-1,\ell-1}$（`def:prefix-suffix-typing`）。長さ $<2(\ell-1)$ の語は語そのものを、長い語は (接頭ℓ−1, 接尾ℓ−1) を記録する。$T_\ell:=|s_\ell(\Sigma^+)|$。
- **de Bruijn グラフ** $D_\ell$：頂点 $\Sigma^{\ell-1}$、辺 $\Sigma^\ell$（$a_1\cdots a_\ell:\ a_1\cdots a_{\ell-1}\to a_2\cdots a_\ell$）。$K:=k^\ell$。
- 長さ $\ge\ell-1$ の語 $w$ は、頂点 $\mathrm{pref}_{\ell-1}w$ から $\mathrm{suf}_{\ell-1}w$ への歩道 $\mathrm{walk}(w)$ と一対一に対応する。各辺は ℓ-窓で、ラベルは末尾文字。
- $N_\ell(w)\in\mathbb N^{\Sigma^\ell}$ は辺の個数ベクトル。$\Psi(w)=\Psi(\mathrm{pref}_{\ell-1}w)+\pi(N_\ell(w))$（π は末尾文字）。

**基本事実（de Bruijn の同期性）。** 頂点 $u$ から始まる長さ $\ge\ell-1$ の歩道の最後の ℓ−1 文字は、到着頂点そのものである。部分歩道 $p\to q$ を同じ端点の別の歩道に置き換えても、その後の辺列は（窓として）変わらない。

**定義（ℓ-局所計数言語）。** ある $\mathcal Q$ について次が成り立つとき、$L$ を ℓ-局所計数言語と呼ぶ。
$$L\cap\Sigma^+=\{w\in\Sigma^+:(s_\ell(w),N_\ell(w))\in\mathcal Q\}.$$

**例**（すべて任意の $Q\subseteq\mathbb N^\Sigma$ と交わってよい）：
- (a) SL_ℓ（許可された ℓ-因子集合と接頭・接尾条件）、LT_ℓ（ℓ-因子集合のブール結合）、LTT_ℓ（ℓ-因子の閾値計数）。
- (b) $\mathrm{Path}_D(s,t)$（各文字が $D$ の一意な辺）。歩道性は「2-因子 $ab$ で $\mathrm{hd}(a)=\mathrm{tl}(b)$」、端点は接頭・接尾1文字なので **ℓ=2**。
- (c) ℓ=1 では $s_1$ は自明、$N_1=\Psi$。したがって $\Psi^{-1}(Q)$。
- (d) ℓ-因子の個数条件（例：$|w|_{ab}=|w|_{ba}$）。
- ℓ-局所計数ならば (ℓ+1)-局所計数でもある。

## 3. 定理L：主張

**定理L** [独立に証明]。

**仮定**：
- $f,r,\ell\ge1$。
- $L$ は ℓ-局所計数言語。
- 型付け $s$ は $s\preceq c_\Sigma\times s_\ell$ を満たす（内容型付け $c_\Sigma$ 自身や、$c_\Sigma\times s_{p,q}$（$p,q\le\ell-1$）を含む）。
- $L\in\mathcal C^{\rm mcf}_{f,s}$。

**主張**：$L\cap\Sigma^+$ の任意の reduced good 表示 $G$（fan-out $\le f$、rank $\le r$、非終端数 $v$、**元の** $\theta=\bar\theta_G$）について
$$\tau(G,s)\ \le\ f\ell+\ell N_{\rm sk}\theta+2\ell frN_{\rm sk}+\ell rN_{\rm sk}\,C_L\,H\theta\ =\ O_{k,\ell,f,r}\bigl(v^{Kf+2}\theta^{Kf+1}\bigr).$$

**定数**（すべて $k,\ell,f$ のみで決まる。$H$ だけは $v$ に比例）：
- $V_\ell=k^{\ell-1}$、$\lambda=K(2V_\ell-1)$、$\lambda'=2(\ell-1)\lambda$。
- $c_1=1$、$c_{i+1}=Kc_i+f+\lambda'+2$、$c_*=c_{K+2}$。
- $H=v\,|s(\Sigma^+)^\sharp|^f\le v\bigl((2^k-1)T_\ell+1\bigr)^f$。
- $N_{\rm sk}=\ell c_*KfH$。
- $C_L=T_\ell^{\,f}\bigl(1+rH(\theta+f\ell)\bigr)^{Kf}$。

`cor:distribution-representatives` により、$\|K\|_+\le N_{\rm typ}(1+2\theta+r\tau)+\mathbf 1_{\eps\in L}$ の特徴標本がある（**総長**が多項式）。

**系L1**：定理Pの言語（ℓ=2）。指数は $k^2f$ で、第三段の $kf$ より弱いが多項式である。

**系L2**：$R\in$ SL_ℓ、$g:\Sigma^*\to\mathsf A$ をアーベル群への準同型とし、$L=R\cap g^{-1}(\gamma+\mathsf H)$ が $f$-MCFL ならば、$L\in\mathcal C^{\rm mcf}_{f,c_\Sigma\times s_\ell}$ であり定理Lが適用できる。

*系L2の証明* [独立に証明]：
- $R$ は $(f,s_\ell)$-代入可能である。共通の受理文脈 $E$ があれば各 $\mathrm{Fac}_\ell(x_i),\mathrm{Fac}_\ell(y_i)$ は許可集合に入る。任意の $E'$ について、$E'[x]$ の因子集合は「文脈片の因子 ∪ 成分の因子 ∪ またがり因子（型の列で決まる）」である。よって $E'[x]\in R\iff E'[y]\in R$。
- `def:class-cmcf` (a) で $c_\Sigma\times s_\ell$ に持ち上がる。`prop:abelian-coset-filter` (i)(ii) で剰余類と交わる。∎

**系L3（非LG性）** [独立に証明]：$k\ge2$ なら $c_\Sigma\times s_\ell$ の像は LG に入らない。
- $e=$（$a^{2\ell}$ の型）は冪等元である。

したがって系L2の言語は、**LG外の型付けで、Theorem A の射程外**にある。窓型付け $s_\ell$ だけなら LG なので Theorem A に含まれる。

**注意（$s=c_\Sigma$ 単独の場合）。** 代入可能性の仮定は内容型だけでは重い。ℓ≥3 で $c_\Sigma$-代入可能な自然な例（ℓ=2 の経路言語以外）は、今回は確定していない。例えば $(aab)^+$ の扱いは [未解決]。

## 4. 定理Lの証明

以下、$X=A_{\mathbf T}$ を型付き非終端（arity $d$）とし、$x\in L_X$ を節点数最小の導出木の組とする。
- 補題A（監査S §1.A、型付け $s$ で同じ証明）により、高さは $\le H$。
- $w=E_A[x]\in L$。

### 4.1 補題 P0^ℓ（分布同値の分類） [独立に証明]

**主張**：$y,y'\in(\Sigma^+)^d$ が各成分で $s_\ell(y_i)=s_\ell(y'_i)$、$\mathrm{alph}(y_i)=\mathrm{alph}(y'_i)$ を満たし、さらに $\sum_iN_\ell(y_i)=\sum_iN_\ell(y'_i)$ ならば、すべての $E\in\mathcal E_d$ で $E[y]\in L\iff E[y']\in L$。とくに $y\equiv_{L,s}y'$。

*証明*：
1. $\widehat s_\ell$ はモノイド準同型なので $s_\ell(E[y])=s_\ell(E[y'])$。
2. $E[y]=v_0y_1v_1\cdots y_dv_d$ の ℓ-窓は、(a) 一つの片の内部、(b) 二つ以上の片にまたがるもの、に分かれる。
3. (b) の窓は、ある片の長さ $\le\ell-1$ の接尾、完全に含まれる中間片、ある片の長さ $\le\ell-1$ の接頭からなる。中間片は長さ $\le\ell-2$ なので、$s_\ell$ が語全体を記録する（空の片は単位元）。よって (b) の多重集合は片の型の列で決まる。
4. (a) の和は $\sum N_\ell(v_m)+\sum_iN_\ell(y_i)$。
5. 以上から $(s_\ell,N_\ell)(E[y])=(s_\ell,N_\ell)(E[y'])$。∎

**依頼文 §4 の小問1・2への回答**：境界情報は各成分の $s_\ell$ 型、加法情報は成分内 ℓ-因子計数の**総和**である。穴の間の固定区切りが ℓ−1 文字未満でも、短い片の型が語全体を記録するので問題ない。代入可能性は使わない。

### 4.2 頻度の隙間と印

**W2^ℓ** [独立に証明]：W2（監査P §2）の証明は「歩道」と「辺の種類が $K$ 個」しか使わない。そこで、$|x_i|\ge\ell$ の各成分の歩道 $\mathrm{walk}(x_i)$ に適用する。
- $k+1$ 個の区間 $[c_g,c_{g+1})$ の中に、どの辺の出現数も入らない $g=g_i$ が存在する。
- 出現数 $\ge c_{g+1}$ の辺を**頻出**、$<c_g$ の辺を**稀**と呼ぶ。
- 頻出辺の弱連結成分 $J$ は強連結である。
- 稀な出現は $\le(K-1)(c_g-1)$ 個である。
- 頻出辺の極大な連（**区間**）は、それぞれ一つの $J$ に入る。
- $J$-区間の数を $s_{i,J}$ とすると $s_{i,J}\le(K-1)(c_g-1)+1$。

**印**：各成分・各辺について、最初の $c_*$ 個の出現の窓の**全位置**（ℓ 個ずつ）に印を付ける。
- 印の数は $\le\ell c_*Kf$、骨格節点は $\le N_{\rm sk}$。
- (a) 稀な出現は全部印になる（出現数 $<c_g\le c_*$）。
- (b) 自由因子 $\varphi$（印を含まない節点の成分）の**内部窓**はすべて頻出である。窓は連続するので、一つの区間・一つの $J$ に入る。
- (c) 頻出辺は $\ge c_{g+1}$ 個の印付き出現を持つ。
- 長さ $<2(\ell-1)$ の成分では、各辺の出現数が $\le\ell-2<c_*$ なので全窓が印になり、削除は起きない。この成分は $x_i$ のまま残す。

### 4.3 補題 P1^ℓ（不純窓の色） [独立に証明]

**設定**：
- 極大自由節点 η の成分を $\varphi_1,\dots,\varphi_g$ とする。
- $I_j$・$U_j$・$W_j=E_A[x_{I_j}]$ は監査の DFS 構成のとおり。$I_j$ の各節点を $\theta$ 以下の**無型**の短い生成組 $u_{B_\nu}$（空成分なし）に置き換える。
- $\psi^{(j)}_\kappa$ は置換後の η の第 κ 成分。
- $\psi^{(j)}_\kappa$ の内部窓で置換文字を含むものの多重集合を $\mathrm{Imp}_\kappa(j)$ とする。
- **色**は $\mathrm{col}(j)=(s_\ell(\psi^{(j)}_\kappa),\mathrm{Imp}_\kappa(j))_\kappa$。
- $\varphi_\kappa$ の内部窓で $U_j$ と交わらず $U_{j'}$ と交わるものの多重集合を $Z_\kappa$ とする。

**主張**：$\mathrm{col}(j)=\mathrm{col}(j')$（$j<j'$）ならば、
1. $N_\ell(\psi^{(j)}_\kappa)-N_\ell(\psi^{(j')}_\kappa)=Z_\kappa\ge0$。
2. $Z_\kappa$ は $D_\ell$ の circulation で、台は $E(J_\kappa)$ に含まれる。
3. $N_\ell(W_j)-N_\ell(W_{j'})=\sum_\kappa Z_\kappa$。
4. $s_\ell(W_j)=s_\ell(W_{j'})$。

**色の数**：$\sum_\kappa|\mathrm{Imp}_\kappa(j)|\le\sum_{\nu\in I_j}(\|u_{B_\nu}\|_1+f(\ell-1))\le rH(\theta+f\ell)$。よって色は $\le C_L$ 種類。

*証明*：
1. 置換は空でない語で $U_j$ の連を置き換える。よって $\psi^{(j)}_\kappa$ の原文字だけからなる窓は、$\varphi_\kappa\setminus U_j$ の一つの極大連の窓である。逆も成り立つ。
2. したがって $N_\ell(\psi^{(j)}_\kappa)=\mathrm{Pure}_\kappa(j)+\mathrm{Imp}_\kappa(j)$。ここで Pure は $U_j$ と交わらない $\varphi_\kappa$ の内部窓。
3. $U_j\subseteq U_{j'}$ と Imp の一致から、主張1が出る。
4. 長さ $\ge\ell-1$ の語の内部窓は $\mathrm{pref}\to\mathrm{suf}$ の歩道であり、型が等しければ端点が等しい（短い場合は語が等しく、差は 0）。よって主張2。台は 4.2(b) による。
5. $W_j$ と $W_{j'}$ は η の成分以外の片が一致する。P0^ℓ の証明3と同じく、またがり窓は片の型の列で決まる。よって主張3・4。∎

**依頼文の小問3への回答**：境界をまたぐ因子の補正項は、次の二つに正確に分かれる。
- 内部では $\mathrm{Imp}$（置換文字を含む窓）。
- 外部では $s_\ell(\psi)$ が決めるまたがり窓。

両方を色に入れれば補正は消える。どちらかを欠くと偽になる（§8、数値の対照）。

### 4.4 補題 ER^ℓ（凍結ブロック付き Euler 再配線） [独立に証明]

**仮定**：
- $J$ は $D_\ell$ の強連結部分グラフ。
- 柔軟な連 $F_1,\dots,F_m$（$J$ の辺の部分歩道、端点 $p_l\to q_l$）と、その間の凍結された辺列がある。
- 指定された $M\in\mathbb N^{E(J)}$ が $\partial M=\sum(e_{q_l}-e_{p_l})$ を満たす。
- 主連 $F_{l^*}$ と、$J$ の頂点 $u$、$u$ を基点とする $J$ の閉歩道 $g$ を選ぶ。
- $M(e)\ge(m-1)+1+N(g)(e)+1$（$e\in E(J)$）。

**主張**：次の歩道で置き換えられる。凍結辺列は窓として不変であり、合計個数は $M$ になる。
- $l\ne l^*$ の連：最短路 $\pi_l$。
- 主連：$\pi(p_{l^*}\to u)\cdot g\cdot P$。ここで $P$ は残差の Euler 歩道 $u\to q_{l^*}$。

*証明*：
1. 単純路は各辺を高々1回しか使わないので、残差 $M-\sum\pi_l-\pi-N(g)$ は $E(J)$ 上で $\ge1$ である。
2. その台は強連結で、流量は $e_{q_{l^*}}-e_u$ なので Euler 歩道が存在する。
3. 各連の端点（頂点＝ℓ−1 窓）を保つので、de Bruijn の同期性により後続の凍結辺は同じ窓のまま残る。∎

### 4.5 一段の削除

**状態と不変量 (Inv^ℓ)**：
- 各成分の辺個数ベクトル $N_i$（初期値 $N_\ell(x_i)$）を状態とする。
- $N_i$ は「$N_\ell(x_i)$ から、各段で削った circulation（台は $x_i$ の頻出 $J$）を引いたもの」で、印付きの出現は一度も引かない。
- $(s_\ell(x_i),\mathrm{alph}(x_i),N_i)$ を実現する組は、すべて $x$ と $\equiv_{L,s}$ である。
- 初期状態では P0^ℓ により成り立つ。

**段**：同色の $j<j'$ について、$Z_{(i,J)}:=\sum_{\kappa\to(i,J)}Z_\kappa$（非零のもの）とする。
- 一つの $\varphi_\kappa$ の窓の集合 $\{e:j_e\in(j,j']\}$ は段ごとに互いに素である（$j_e:=\min\{j:\text{窓}\cap U_j\ne\varnothing\}$）。
- したがって印は保存され、$N_i(e)\ge(\text{印の数})+Z(e)$。

**穴と $h,t$**：
- 各穴 $(i,J)$ の**錨区間**は、「$x_i$ の $J$-区間のうち、$W_{j'}$ で柔軟な窓を含む最初のもの」とする。
  - 柔軟な窓とは、ℓ 位置がすべて $x_i$ の原位置で、η の外にあり、連続しているもの。
  - 印付きの窓は η と交わらず連続なので柔軟である。よって 4.2(c) から錨区間は存在する。
- $u_J:=$ $J$ の固定頂点。$h_J$ は $J$ の全辺を通る長さ $\le\lambda$ の閉歩道。
- $H_0:=h_J^{\ell-1}$、$h:=H_0H_0$、$t:=H_0\cdot\mathrm{Euler}_{u_J}(N(H_0)+Z_{(i,J)})$。
- 台は強連結な $E(J)$ で、釣り合っているので $t$ は存在する。$N(t)=N(h)+Z$。
- **型の一致**：$t,h$ の語（ラベル）は長さ $\ge2(\ell-1)$。接頭ℓ−1 は共通の $H_0$ の最初の ℓ−1 辺のラベル、接尾ℓ−1 は到着頂点 $u_J$ そのものである。内容は $\pi(E(J))$。よって $s(t)=s(h)$。これで依頼文の小問4（窓を損なわない再構成）が解決する。

**補題Y^ℓ（y 側）** [独立に証明]：
- 各成分について、$x_i$ の稀骨格（稀辺の列）を固定する。
- 各 $J$ の区間に ER^ℓ を適用する（主＝錨区間、$g=t$）。
- 条件は $N_i(e)-Z(e)\ge c_{g+1}\ge(K-1)(c_g-1)+\lambda'+2\ge s_{i,J}+N(h)(e)+1$（$c$ の定義）。
- 穴のない $J$ は $g=\varnothing$ で同様に扱う。
- 結果の $y^\pi_i$ は始点が $\mathrm{pref}_{\ell-1}(x_i)$ で、型・内容・$N_i$ が一致し、錨区間の中で $u_J$ に $t$ を因子として持つ。
- $y'_i$ は $t\to h$ と置き換えたもので、$N=N_i-Z_{(i,\cdot)}$、型と内容は不変である。

**補題F^ℓ（F 側）** [独立に証明]：
- $W_{j'}$ で、柔軟な窓の極大連を柔軟な連とし、それ以外（ψ に触れる窓、稀辺、文脈にかかる窓）を凍結する。
- 各 η 成分は高々一つの連を割るので、$m\le s_{i,J}+f$。
- 印付きの出現は全部柔軟なので $M_J(e)\ge c_{g+1}\ge(K-1)(c_g-1)+f+\lambda'+2$。
- ER^ℓ（主＝錨区間の中の最初の柔軟な連、$g=h$）を適用して $W'$ を得る。
- $(s_\ell,N_\ell)(W')=(s_\ell,N_\ell)(W_{j'})$ なので $W'=F[h]\in L$。
- $h\to t$ と置き換えた $F[t]$ は、$s_\ell$ が同じで $N_\ell(F[t])=N_\ell(W_{j'})+\sum Z=N_\ell(W_j)$。$s_\ell(W_j)=s_\ell(W_{j'})$（色）なので $F[t]\in L$。**Q は任意のまま。**

**穴の順序と区切り**：
- 両側とも、穴は（成分 $i$、錨区間の位置）の辞書式順に並ぶ。稀骨格は共通である。
- 同じ成分の異なる $J$ の錨区間の間には稀辺（1文字以上）がある。異なる成分の間には文脈片（空でない）がある。
- よって $F\in\mathcal E_e$（$e\le f$）であり、任意の $E\in\mathcal E_d$ について $F_E$ も admissible である。

**接合**：
1. $F[t],F[h]\in L$、$s^{(e)}(t)=s^{(e)}(h)$ なので、代入可能性から $\mathcal D(t)=\mathcal D(h)$。
2. よって $E[y^\pi]=F_E[t]\in L\iff F_E[h]=E[y']\in L$、つまり $y'\equiv y^\pi\equiv x$。
3. P0^ℓ により、$N_i-Z$ を実現する組はすべて $x$ と同値。(Inv^ℓ) が保たれる。∎

### 4.6 長さ

最終的に残る窓は次の二種類である。
- (a) 一つの自由成分に収まらない窓：骨格の文字を含むか、自由成分の境界をまたぐ。$\le\ell N_{\rm sk}\theta+2\ell frN_{\rm sk}$。
- (b) 各 η で、残した添字 $i$（色が相異なり $\le C_L$ 個）について $j_e=i$ となる窓：$\le\ell|U_i\setminus U_{i-1}|\le\ell H\theta$。

成分ごとに頭の ℓ−1 文字を足すと、§3 の評価になる。$N_{\rm sk}\propto H$、$C_L\propto(H\theta)^{Kf}$ なので $O(H^{Kf+2}\theta^{Kf+1})$。**型付き積文法の厚さは使っていない**（使うのは元の $\theta$ と $|I_j|\le rH$ だけ）。∎

## 5. ブロック積への拡張 L^⊗

**定理 L^⊗** [独立に証明（定理Lとの差分を以下に記述。独立監査を推奨）]。

**仮定**：
- $\Sigma=\Sigma_1\uplus\cdots\uplus\Sigma_p$ とし、$\pi_b$ を $\Sigma_b$ への射影とする。
- $L\cap\Sigma^+=\{w:((s_\ell,N_\ell)(\pi_bw))_b\in\mathcal Q\}$（自動的に、ブロックをまたぐ文字対は統語的に独立）。
- $L\in\mathcal C^{\rm mcf}_{f,c_\Sigma}$。

**主張**：$\tau(G,c_\Sigma)=O(v^{K^\otimes f+2}\theta^{K^\otimes f+1})$、$K^\otimes=\sum_b|\Sigma_b|^\ell$。

**定理Lとの差分**：
1. **P0^⊗**：所属は各ブロック射影の $(s_\ell,N_\ell)$ で決まる。射影された文脈は区切りが空になりうるが、型の列で決まる議論は空の片を許すので、そのまま通る。
2. **窓の span**：$\pi_b(\varphi)$ の窓の span（$\varphi$ の中の最初から最後の位置まで）を使う。
   - 純窓とは、span が置換位置を含まないもの。不純窓とは、span が置換位置を含むもの（置換片に $\Sigma_b$ の文字がなくても、それをまたぐ窓は不純）。
   - 置換片一つあたり、不純窓は $\le(\Sigma_b\text{の文字数})+\ell-1$ 個。
   - 以後の P1 はブロックごとに同じ証明で通る。
3. **印と柔軟性**：$\Sigma_b$ の文字を持たない η 成分は、印付き窓の span の中に入りうる。この窓は F 側で凍結されるが、その数は各ブロックで $\le f(\ell-1)$ 個である。$c_{i+1}$ に $f\ell$ を足せば足りる。
4. **再組立て**：y 側は $y^\pi_i:=P_1P_2\cdots P_p$（各ブロックの実現の連結）。F 側も $W_{j'}$ の $x_i$ 領域を同じように並べ替える。
   - 射影は再配線したものと一致するので、所属は保たれる。
   - 穴の順序は（$i$、ブロック、錨区間）。異なるブロックの穴の間には Euler 残差（1文字以上）がある。
5. **型付けの制限**：並べ替えで成分の窓型は変わるので、**型付けは $c_\Sigma$（またはそれより粗い型付け）に限る**。窓型付きの L^⊗ は [未解決]。

**含まれるもの**：
- 定理L（$p=1$）。
- 可換言語（全部単集合、ℓ=1）。
- **依存関係が推移的（依存グラフが互いに素なクリークの和）な定理Sの言語**。各クリーク内の非交互性は「各文字が一ブロック」で、射影の $(\mathrm{pref}_1,N_2)$ で表せる。

## 6. 定理S・Pとの関係（第一任務への回答）

**命題N1（定理Sは定理Lに含まれない）** [明示反例・計算確認]。
- $L_S=\{w\in\{a,b,c\}^+:\ b\text{ の後に }a\text{ が来ない},\ |w|_a=|w|_b\}$ とする。
- $L_S$ は定理Sの仮定を満たす（$a,b$ は依存かつ非交互、$c$ は両方と独立）。
- $L_S$ は $\mathcal C^{\rm mcf}_{2,c_\Sigma}$ に入る。正則部分は「内容と文脈で順序の合法性が決まる」ので代入可能（監査S §4 の $L_{\rm natural}$ と同じ論法）で、`prop:abelian-coset-filter`(ii) と CFL 性による。
- 任意の ℓ と $n\ge\ell$ について、$w_1=ac^nac^nbc^nb\in L_S$、$w_2=ac^nbc^nac^nb\notin L_S$ だが、$s_\ell(w_1)=s_\ell(w_2)$ かつ $N_\ell(w_1)=N_\ell(w_2)$。
  - 理由：長さ ℓ の窓は特殊文字を高々一つしか含まない（間隔 $n+1>\ell-1$）。特殊文字の多重集合は中央で $\{a,b\}$、端で $a,b$ と一致する。
- `check_S_not_local_2026-11-14.py` で ℓ≤8、n=ℓ..ℓ+3 を確認した。

**命題N2（定理Sは L^⊗ にも含まれない）** [明示反例]。
- $L_{\rm natural}=\{w\in ND_P:|w|_a=|w|_d\}$（$P$: $a<c,\ b<c,\ b<d$）を考える。依存グラフ $a\!-\!c\!-\!b\!-\!d$ は連結である。
- L^⊗ では依存対は同じブロックに入るので、ブロックは一つ。よって ℓ-局所計数でなければならない。
- $w_{1,2}=a^{3n-1}d^n\,\{a,c\}\,d^n\,\{c,a\}\,d^n\,c$ で N1 と同じ議論が通る（$L_{\rm natural}\in\mathcal C^{\rm mcf}_{2,c_\Sigma}$ は監査S §4 の主張を引用。本報告では再証明していない）。$w_1\in L_{\rm natural}$、$w_2\notin L_{\rm natural}$（$c$ が $a$ より前）、型と ℓ-窓は一致。
- 推移的でない依存のもとで、遠くの独立文字が局所性を壊す。これが S の本質である。

**命題N3（定理Pは定理Sに含まれない）**（第三段で既知）：2-閉路を持つ経路言語は交互である。

**包含関係のまとめ**：
- 定理P ⊂ 定理L（ℓ=2）。
- 可換言語 ⊂ 定理L（ℓ=1）。
- 定理L ⊂ L^⊗。
- 定理S ∩ L^⊗ ⊇ 推移依存の S。
- 定理S ⊄ L^⊗（N2）、L ⊄ S（N3）。

**予想U（完全な統一）** [予想]。
- 被覆族 $\mathcal C$（すべての依存対を含む部分アルファベットの族）について、所属が $((s_\ell,N_\ell)(\pi_Cw))_{C\in\mathcal C}$ で決まり、$L\in\mathcal C^{\rm mcf}_{f,c_\Sigma}$ なら、τ は多項式である。
- 定理Sは $\mathcal C=$ 依存対、ℓ=2（非交互＝射影が $x^*y^*$）の場合である。トレースの二文字射影判定により、所属は射影データで決まる。
- 定理 L^⊗ は $\mathcal C$ が分割の場合である。

**障壁（正確な形）**：
- 射影 $C,C'$ が文字を共有し、どちらにも閉路がある場合、各射影の Euler 再配線を**一つの語で同時に実現**する必要がある。共有文字の出現順の整合性の問題である。
- 定理Sでは各射影が「ループ＋非巡回」なので、再配線は可換な移動だけで済む。L^⊗ では射影が互いに素である。
- 最小の未解決型は、依存グラフが非推移的で、かつ閉路を持つ射影を含む言語である。例えば次の構造：$a\!-\!c$ の射影が $(ac)^+$ 型で交互、$c\!-\!b\!-\!d$ が順序制約、$d$ が $a,c$ と独立な詰め物。

## 7. 有限オートマトン基底（第三任務）

**観察D0（鍵は definite 性）** [独立に証明]。
- de Bruijn 自動機械は (ℓ−1)-definite（任意の語の、長さ ℓ−1 以上の部分を読んだ後の状態が最後の ℓ−1 文字で決まる）である。
- 定理Pの「各文字＝一意な辺」は 1-definite 性（文字 $a$ の後の状態が $\mathrm{hd}(a)$）にあたる。
- 一般に、**(ℓ−1)-definite な DFA $\mathcal A$ の遷移計数**（任意の始状態から、遷移の個数ベクトル）と終状態で所属が決まる言語は、ℓ-局所計数である。最初の ℓ−1 文字以後の遷移は ℓ-窓と一対一だからである。
- よって定理Lは「definite 自動機械＋任意の遷移計数条件」の定理として読める。依頼文の「固定オートマトンの経路の存在」と「文字＝一意な辺」の違いは、**状態が有限の過去から復元できるか**に帰着する。

**命題D1（射程）** [独立に証明]。
- $R$ が LT_ℓ と可換正則言語のブール結合ならば、$R\cap\Psi^{-1}(Q)$ は ℓ-局所計数である（可換正則条件は Q に吸収できる）。
- ブロック積で、ブロックごとの LT と可換条件も扱える。

**命題D2（非 definite な基底では P0 型の分類が成り立たない）** [明示反例]。
- $E_{\rm ev}=\{w\in\{a,b\}^+:\text{極大 }a\text{-run がすべて偶数長}\}$ とする。
- $n\ge\ell$ について $w_1=ba^{2n}ba^{2n}b\in E_{\rm ev}$、$w_2=ba^{2n+1}ba^{2n-1}b\notin E_{\rm ev}$ は、$s_\ell$ と $N_\ell$ が等しい。
- したがって、どの ℓ でも定理Lの仮定外である。
- 分類を回復するには、型に「端の run の偶奇」（群 $\mathbb Z_2$ の成分）を加える必要がある。そうすると P1 の置換で、置換点から run の終わりまで状態が反転し、**不純な遷移が run 長に比例する**。
- ただし、遷移計数の差は run ごとに ±1 しか変わらないので、色を「差分」で取れば有界になる見込みがある [予想]。

**条件付き方向** [予想]：
1. **同期語が頻出する DFA**：頻出成分のすべての閉路が同期語を含むなら、置換の影響は次の同期点までの有界区間に収まり、P1 が通ると予想する。
2. **有限群の語問題 ∩ Parikh**（例：$S_3$ の生成元で値が 1、かつ $|w|_a=|w|_b$）：
   - 型は「成分の群値＋内容」、加法情報は Ψ。
   - $t,h$ の群値を合わせるには、「十分大きな重複度を持つ文字の多重集合の並べ替えで得られる積の集合は、交換子部分群の剰余類全体になる」という補題（Dénes–Hermann 型の事実と予想。未検証）が要る。
   - 色に成分ごとのアーベル化の値を加えれば $Z_\kappa\mapsto0\in G^{\rm ab}$ となり、方針は通る見込みである。

一般の DFA は [未解決]。
