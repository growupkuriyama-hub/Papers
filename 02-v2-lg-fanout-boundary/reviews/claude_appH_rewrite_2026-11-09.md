## 1. 新しい主張

### Definition 7.9（孤立した文字）`def:isolated-letter`
文字 a が型付け s で**孤立**しているとは、s⁻¹(s(a)) = a⁺ であり、a を含み a⁺ にない語が全て一つの型を持つこと。
- Σ = {a,b} の内容型付け c：a, b とも孤立。
- s : Σ⁺ ↠ U₁ で型1の文字が a だけ：a は孤立（Σ は任意）。
- |Σ| ≥ 3 の c_Σ：どの文字も孤立しない。

### Theorem 7.10（`thm:two-letter-fanout-one`、ラベルは維持）
a が s で孤立、L ∈ C_{1,s}、G は L∩Σ⁺ の reduced good・ファンアウト1・任意ランクの表示。G または G′ の非終端 A が a⁺ の産出を持てば

  τ_{A_{s(a)}} ≤ C(‖G‖+2)^{22} θ̄_G^{8}、C < 10⁴³（絶対定数）。

特に L∩a⁺ の最短語も同じ評価。
- 旧版（c、全ての型、(76, 21)）との違い：**型 s(a) だけ**を扱う。混合型は補題 H.10 に移し、系の証明で使う。

### Corollary 7.11（`cor:two-letter-fanout-one`、ラベルは維持）
r_max ≥ 2。(i) Σ = {a,b} で正の像が半束の型付け、または (ii) 任意の Σ で、型1の文字がちょうど一つの s : Σ⁺ ↠ U₁。このとき

  ‖K‖₊ ≤ C′ r_max (‖G‖+2)^{23} θ̄_G^{8} + 1_{ε∈L}、C′ < 10⁴⁵。

### Corollary 7.12（新、`cor:u1-classification`）
r_max ≥ 2、s : Σ⁺ ↠ U₁。Def 7.2 で各型付けに要求される評価が成り立つ ⟺ 型1の文字がちょうど一つ。
- 一つ：系 7.11(ii) の多項式。Prop 7.8 により p(‖G‖)θ̄ の形にはならない。
- 二つ以上：系 7.7 の指数の族。
- 全射性から、型1の文字も型 ζ の文字も必ずある。

### 3.2 ChatGPT 査読 G4 の懸念への答え

懸念は「第三の文字 c があると b, c の順序・文脈差が新しい情報を持ち、b, c を一つの文字に潰すことは正当化されない」というもの。

- 新しい証明は文字を潰さない。
- Σ の大きさを使うのは前終端記号の数（σ_G）だけ。

- 数え上げは G′ の部分木の差し替えだけを使う。

従って、懸念された箇所は証明に存在しない。ただし、これは私の通読による確認である。検証者には (I2) の使用箇所（下の §4 の 2）を一つずつ確かめてほしい。

### 3.3 系 7.7 から分類の「二つ以上」が出ること

- U₁ = {1, ζ} で、e = 1, z = ζ は相異なる冪等元で、ez = ze = z。
- 型1の二文字 a ≠ b と型 ζ の文字 c（全射性から存在）で、u = a, v = b, w = c は letter-disjoint。
- 系 7.7 の結論「この型付けでは Def 7.2 の多項式が存在しない」がそのまま使える。

### 3.4 新しい選択規則と形式的な値の整合

i < i₀ では v_i = n ≥ Λ。取る値は S + v < Λ ≤ n を満たすので、形式的な添字は取られない。逆に候補としては常に存在するので、旧版の「道が尽きる」場合は起きない（スクリプト (D) で 199,619 例を検査）。
