## 1. 背景

`cor:typing-level-obstruction` は、文字を共有しない語 u, v, w（s(u) = s(v) = e、s(w) = z、ez = ze = z、e ≠ z は冪等）があれば、ファンアウト1で特徴データが指数になることを示す。文字を共有しない条件のため、少なくとも三文字が要る。二文字のアルファベットでの指数の下界は、原稿にない。

**候補**（Claude の観察）：
- Σ = {a, b}、型付け t(w) = (先頭の文字, 末尾の文字, bb を部分語に含むか)。積は (f₁,l₁,β₁)(f₂,l₂,β₂) = (f₁, l₂, β₁ ∨ β₂ ∨ [l₁ = f₂ = b]) で、局所試験的な型付けである。
- e := t(ab) = t(aab) = (a, b, 偽)、z := t(abb) = (a, b, 真)。e, z は冪等で ez = ze = z。t の像は U₁ の写しを含み、LG に入らない。
- h : a ↦ ab、b ↦ aab、c ↦ abb、H_n := h(L_n)。H_n で型 e の語は h(W_n) だけである（bb は abb からしか生じない）。
- **計算**：H_n は n = 1, 2, 3 で Clark–Eyraud 代入可能（`reviews/check_claude_compression_2026-11-02.py` の Part B）。n = 4 は未検査。
- **注意**：`lem:app-u1-code` を「符号語が全て a⁺b⁺ の形」に一般化した主張は偽（有限の代入可能な L で反例多数、例：L = {xxxy, zzyy}）。comma-free 符号でも偽。したがって証明は L_n の構造（付録F のパーザ）を使う必要がある。

## 2. 問い

> **全ての n ≥ 1 で H_n は Clark–Eyraud 代入可能か。**

肯定なら、次がそのまま従う（確かめてください）：H_n ∈ C_{1,t}、h(G_n) は reduced good でランク2、‖·‖ と θ̄ は O(n)、`prop:rare-type` により特徴標本は h(W_n) を含み、|h(W_n)| = 8·2^n − 6（n = 1, 2, 3 で 10, 26, 58）。つまり **二文字のアルファベット上の一つの（局所試験的な）型付けで、ファンアウト1の特徴データが指数**になる。

## 3. 調べてほしいこと（優先順）

**P1（本題）**：H_n の代入可能性を全ての n で証明する。
- 方針の例：付録F のパーザを二文字の上で作り直す。符号語は全て一つの a の走りと一つの b の走りからなり（ab, aab, abb）、語の中の符号語の境界はちょうど「ba」の位置にある。部分語の両端で切れた符号語（走りの途中で切れた部分）の扱いが核心になる。
- 証明は、arity 1 の条件について省略せずに書いてください。

**P2（P1 が失敗する場合）**：
- 反例（共通の文脈を持ち、分布の違う二つの部分語）が n ≥ 4 で出るなら、それを明示してください。
- その場合、符号を取り替えて（例：{aaab, aabb, abbb}、型付けは「bbb を含むか」）同じ問いを調べてください。

**P3（余力があれば）**：同じ方法で、二文字のアルファベットのどの型付けが「ファンアウト1で指数」になるかの十分条件を書いてください（`cor:typing-level-obstruction` の二文字版）。

計算による確認を勧めます。Python 3 の標準ライブラリだけで書き、全文を載せてください（Windows の `py -3 script.py` で動く形）。有限の検査から無限の族の代入可能性を推定しないでください。
