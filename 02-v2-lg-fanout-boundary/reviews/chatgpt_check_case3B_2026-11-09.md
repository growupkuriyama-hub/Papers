## 2. O1：F′ と削除の独立点検

### 2.1 移送

px⁴q∈L に対し、E=(p,x,q) は (x,xx) と (xx,x) を同じ px⁴q に写す。成分内容は ({x},{x})、中央 x は非空。H=(U,Z,V)、Z≠ε に移せば UxZxxV と UxxZxV の交換が得られる。Z に x や a が含まれてもよい。

極大 x 連の長さは、各連を正に保ったまま任意に再配分できる。異なる極大連の間には非空の非 x 部分があり、移送文脈が許容的だからである。

### 2.2 左の連へ集める F′ₓ

総 x 個数≥連数+1 から、消す連を1文字、生き残りを2文字以上にできる。正規化した語を W₁=UxxuxV とし、xx は生き残りの末尾、単独 x は消す極大連とする。u≠ε。移送で W₂=UxuxxV∈L。

| SUB₁ の項 | 文字列 | 所属の根拠 |
|---|---|---|
| E=(U,xV), X=xux | E[X]=UxuxxV | W₂ |
| Y=xxu | E[Y]=UxxuxV | W₁ |
| H=(Ux,V) | H[X]=UxxuxV | W₁ |
| 帰結 | H[Y]=UxxxuV | SUB₁ |

X,Y は非空で、内容はともに {x}∪c(u)。消した x の分は左の連に移り、総数は保存される。正規化前の他の連の長さを指定したければ、最後に再配分すればよい。

鏡像は W₁=UxuxxV、W₂=UxxuxV とし、E=(Ux,V)、X=xux、Y=uxx、H=(U,xV)。E[X]=W₂、E[Y]=H[X]=W₁、H[Y]=UuxxxV。反転言語への移行を仮定する必要はない。

**極大性の役割。** 左へ集める場合、u の末尾と V の先頭（存在すれば）は x でない。鏡像では U の末尾と u の先頭が x でない。これは「指定した極大連を丸ごと削除した」「別の x 連を併合していない」と言うために使う。SUB₁ 自体の型一致は極大性を要求しない。

**B-del。** 一つの生き残りを固定し、他の指定連を左右いずれの方向からでも削除する。削除後に他の文字の連が合流することはあるが、他の x 連は合流しない。総 x 個数は不変、x 連数は毎回1減るので余分な x の条件は強くなる。最後の再配分も可能。削除集合が空なら恒等操作として扱う。

## 3. 鎖の補題：穴と修正

### 3.1 補題 E は正しい

e≥d のとき、X=a^{1+e−d}P、Y=aC、E=(ε,a^{k−e−1})。E[X] の a 個数は k−d、E[Y] は k−e。e≤k−2 なら右端が正で、両方 SB から得られる。逆向きも同じ。型は {a,b,c}。P=C であっても問題はない。

### 3.2 §2.2 主張1の固定順序は正当化されていない

原文は P→C を先に行い、

δ−d_P≤k−d_P−d_Q−3

を δ+δ′≤k−3 から導いている。しかし必要なのは δ+d_Q≤k−3 であり、δ′<d_Q では導けない。

具体的な**予算の反例**は

θ=2, k=1200, d_P=d_Q=3, δ=1196, δ′=1。

初期の低損失条件 d_P,d_Q≤k/(50θ³)=3 と最終条件 δ+δ′=k−3 は成立する。しかし初期の先頭 a 連に集められる最大長は k−d_P−d_Q−2=1192、必要長は 1+δ−d_P=1194。先の交換は実行できない。

これは不等式・証明順序への反例であり、これらの種を含む場合 III の言語の存在証明でも、鎖の結論への反例でもない。実際、結論は次の修正で救える。

### 3.3 修正証明：a が増える交換を先にする

二つの変化量を Δ₁=δ−d_P、Δ₂=δ′−d_Q とする。Δ≤0 の交換を先に行い、Δ>0 の交換を後に行う。塊の左右の位置は変えず、操作順だけを変える。

初期 a 個数 N₀=k−d_P−d_Q≥3、最終個数 N_f=k−δ−δ′≥3。先に個数を増やしてから減らすので、途中でも≥3。

Δ>0 の交換直前の個数を N とすると、交換後 N−Δ≥3。三つの a 連のうち当該塊の直前へ N−2 文字を集めれば

N−2≥1+Δ。

これが必要な詰め物を確保する。Δ≤0 の場合は直前に1文字あれば足りる。各操作に補題 E を使い、最後に三連を任意の正配分へ再配分する。この証明は損失の極端な偏りも扱う。

主張2は合計損失≤k−4 により a 個数≥4、連数=3 なので F′_a の条件を満たす。中央連の両隣は a-free な塊であり、消す連は極大。融合後の両端は正に保たれる。

帰納法で、正の損失の和≤k−4 の任意列が SB を持つ。**同じラベル、同じ塊の反復を排除する条件はない。** 部分和も上限以下なので帰納法が適用できる。

定理 III-B に必要な短い鎖は損失≤k/2 の余裕があり、原文の順序でも足りる。しかし一般の鎖の主張と β(i) を共通に正当化するには、上の修正を入れるのが明確である。

### 3.4 (B*) の補い

二塊の初期語の a 個数が n なら、Q を P に替え融合して得る PP の損失は k−n−d_Q+d_P。これを 2d_P と同定するには n=k−d_P−d_Q が必要である。旧 (B) の文面だけからこの同定をしてはならない。

T(i)(ii) は同名二出現を差し替えるので、操作直後の a 個数は k−2ℓ_X+2|ρ_X|_a=k−2d_X。融合・分離・再配分は個数を保存する。T(iii) の型板も同じ個数を持つ。

V の配置語についても、差し替え直後は k−Σd_{Z_i}、Z_i→Y_i の交換は a 個数を d_{Z_i}−d_{Y_i} だけ変えるため、完成語は k−Σd_{Y_i}。したがって**V が供給する二塊語の損失会計は (B*) と一致する**。ここで V の任意個数版の配置存在定理を新たに全面承認しているのではなく、今回求められた完成語の個数を確認している。定理 III-B 自体は (B*) を仮定するので V による初期語の構成を必要としない。

(B*) の不成立を新しい (S*) と定義しても、T による「二つの内部出現があり二塊を作れないなら型板を持つ」という含意は維持される。ただし旧 (B)=(B*)、旧 (S)=(S*) を証明したわけではない。

## 4. 交代語・共通根・損失

### 4.1 (KL) の持ち上げ

付録Aの五つの基礎証明書を別検査器で種から再生した。非消去準同型 h と左の固定接頭辞 a^{k−6d} による持ち上げは、各 SUB の三つの前提と結論を同じ像へ送る。内容一致は文字像の内容集合の和で保たれ、二穴中央の非空性は非消去性で保たれる。

基礎の a^6、SB(B^j,j)（j≤3）、分離二塊の像は、それぞれ a^k、SB(F^j,jd)、a 個数 k−2d の分離二塊。k≥6d なら全ての外側・中央 a 連が正である。両端 c の F=cUc では U が b を含むため非空であり、bcb 型の像が c⁴ を出す。この端点証明書は F に bb/cc があることを要求しない。

### 4.2 四つの端点の場合

β=|F|_b、γ=|F|_c≥1、ρ=F の b 極大連数と置く。F^4 の b 連数は

4ρ−3·[F の両端が b]。

|F|≤9 の1004個の両文字語でもこの恒等式を独立に確認したが、一般の証明は三つの接合点それぞれで合流するかどうかだけである。

| F の端点 | 排除・残存の論理 |
|---|---|
| b,b | b 個数4β≥4ρ、連数4ρ−3 なので余分がある。最初の b 連を保持し、c の最初と最後の間の b 連を消す。c^{4γ} が生じる |
| b,c | cc があれば KL。bb があれば β≥ρ+1、連数4ρ、個数4β で余分がある。最初の b 連は全 c の左外にあるので、他を消して c^{4γ}。残るのは (bc)^j |
| c,b | 前行の鏡像。保持する最後の b 連は全 c の右外。残るのは (cb)^j |
| c,c | F=cUc、U≠ε。端点型 KL により c⁴ |

b,c の場合、末尾 cc があれば F=Ucc、U は b を含み非空。末尾にない内部 cc を選べば F=PccQc とできる。P は先頭 b を含むので非空。Q=ε だと末尾が ccc となり末尾 cc の場合に含まれるため、残る場合は Q≠ε。c,b は cPccQ の鏡像で同様。消す b 連が初めから存在しない場合、必要な c⁴ が既にある場合を恒等操作として扱えばよい。

O2(a) も同じ計算を F² で行う。b 連数=2ρ−[両端 b]、c 個数2γ≥4。少なくとも一端 b という条件が、保持連を全 c の範囲外へ置くために必要である。

### 4.3 混合根を消す二証明

P=(bc)^i、Q=(cb)^j（i,j≥1）がともに低い SB 塊なら C=PQ は両端 b。C² は接合に余分な b を持ち、c 個数2(i+j)≥4。左端を保持した B-del で c⁴。

逆順 QP は両端 c。損失 d_P+d_Q で SB、三乗までの鎖と分離二塊を作り、cUc 型 KL を適用できる。低さから 6(d_P+d_Q)≤12k/(50θ³)≤k。四乗を使う場合も8原子以下で十分である。

4d≤k−4、6d≤k は III.1 の仮定。定理の低い原子にはこれらが成立し、混合鎖・指数を交差させる鎖も原文 §2.4 の予算内にある。両文字型の代表があるとき θ≥2 だが、粗い予算は θ≥1 でも足りる。

### 4.4 III.3 と定理 S

同じ a 骨格の二語を再配分すると、選んだ一連以外の a 連を1文字にできる。選んだ連の短い方の長さが h≥1 なら、その h−1 文字を固定文脈に取り込む。これで UaV と Ua^{1+δ}V を得る。「短い方の選んだ極大連そのものが1文字」と仮定する必要はない。

0<δ<k ならこの共有文脈から D(a)=D(a^{1+δ})。a^k の a^{1+δ} を a に替えれば a^{k−δ}∈L となり最小性に反する。

F_X=u^{j_X}、F_Y=u^{j_Y} なので F_X^{j_Y}=F_Y^{j_X}。両側の鎖の損失は≤k/(100θ²)、a 個数は正かつ k 未満。同じ骨格に定理 S を当てれば j_Yd_X=j_Xd_Y。従って φ=d_X/j_X∈Q_{>0} が共通。b の再配分を使う (R) は不要で、定数項は生じない。ラベル集合が空なら群を作らない。

## 5. 例外計数と尺度補題の独立再検証

### 5.1 導出木について使う条件

原稿の厚さ補題から、各規則の直接終端書込み≤θ、各非終端に総長≤θ の代表がある。純粋 a の短い代表を持つ重いラベルを差し替えると k の最小性に反するため、重いラベルは一色型か両文字型に分類できる。

同名ラベルの二出現の総長が異なれば、長い方を短い方に差し替えて k を縮められる。同総長で部分木の節点数が違えば、節点数最小性に反する。従って同名ラベルの総長と節点数は一定。親ラベルから子ラベルへ部分木節点数は厳密に減るのでラベル依存は非巡回で、同名出現は反鎖、深さ≤v。一様化はこの順に選んだ規則を展開して行える。

線形・非削除性により、同じ深さの出力は根語内で互いに素。二成分は good の nonmerging と各成分の非空性により、根語でも非空部分に隔てられる。以下の計数は成分区間の凸包が交差しないとは仮定していない。

### 5.2 一色型：場合 III でも同じ数になる

L_x=L∩{a,x}⁺ は二文字文脈への制限により (2,c)-代入可能性を継承する。L 全体に b⁴ があっても L_b にあるとは限らず、ここを混同してはいけない。

非飽和 L_x に aa と二つの内部 x 連がある語を作れたとする。

- L_x に x⁴ がなければ `lem:app-two-runs`(iv) を、同補題の x=a、y=x として使う。a⁴ があり、非飽和で、y⁴ がないという全条件を満たす。同補題(iii)から二つの内部連が各長さ≥2、その間の a 連を融合操作で消すことで y⁴ を得る証明も確認した。
- L_x に x⁴ があれば a⁴ と x⁴ がそろい、`lem:app-two-alternate` を使う。内部 x 連が二つなら少なくとも a,x,a,x,a の五連があり、四連以上の条件を満たす。全連長1という結論が残した aa と矛盾する。同補題は内部 y 連を1文字に再配分して(iii)を使うので、二文字の内部で完結する。

同深さの同色重節点が10個あれば、根語の最初・最後の各2文字を所有する高々4節点を除いて6個残る。二成分区間の隣接グラフは最大次数≤4 なので独立な二点を選べる。各自の二成分間にも非空の a があり、選んだ二節点の出力は接しない。これらだけを一色代表に替えると、二つ以上の内部 x 連と境界 aa を持つ L_x の語になる。従って各色・各深さ≤9、二色合計≤18v。

飽和 L_x では、同じ x 個数で a 個数の正の差 δ<k があると、飽和性で x^q a^p、x^q a^{p+δ} を得て、定理 S と同じ SUB₁ で a^{k−δ} を得る。頻出同色ラベル B,C に対して、それぞれ別の語で q_C 個の B、q_B 個の C を短い代表へ替える。出現数>θ≥q_B,q_C なので未交換の a 部分木が残り、a 個数は正。x 個数は q_Bq_C で等しい。よって d_B/q_B=d_C/q_C=α_x>0。

従って一色型の群は色ごとの1変数 α_xq、1≤q≤θ、長さの窓 [α_xq,α_xq+θ]。ここで b⁴ の有無は追加条件にならない。

### 5.3 例外表：和集合の上界として読む

| 対象 | 根拠 | 上界 |
|---|---|---:|

| 飽和色の一色型で出現≤θ | ラベル別に≤θ | vθ |

**重複はある。** 高い非内部出現は第3・4行に重なり、第5行をラベルの全出現と読めば非内部部分が第3行に重なる。したがって「重複しない分割の正確な個数」としては読めない。しかし例外集合の和集合の大きさは和以下なので

|例外|≤v(18+θ+2+50θ³+3)=E_B

は正しい。厳密な分割が必要なら表の上から既に選んだ節点を除いて数えればよい。内部出現0の低ラベルは全て第3行、内部出現1は第5行、2以上は群に入り、漏れはない。一色型の色は一ラベル一色に固定する。

### 5.4 尺度補題3.1：原文の芯の証明

第十一報 `claude_f_branching` §3.2 を読み直した。以下、群値を g と書き、次元 D と区別する。ĝ=max(g,θ)、相異なる値を ĝ₁<⋯<ĝ_m、ĝ₀=θ と置く。重い群節点の長さは [ĝ,2ĝ] に入る。

値 ĝ_j の節点 u を選ぶ。ℓ_u≤2ĝ_{j−1} なら直ちに ĝ_j≤2ĝ_{j−1}≤K_Bĝ_{j−1}。そうでなければ u 以下の ℓ_z>2ĝ_{j−1} の節点を芯とする。長さは子孫へ非増加なので芯は根付き連結部分木になる。

芯の非例外節点 z の群値は ĝ′>ĝ_{j−1}、従って ĝ′≥ĝ_j、ℓ_z≥ĝ_j。同深さのこのような節点数は ℓ_u/ĝ_j≤2、全深さで≤2v。例外は全体で≤E_B。

芯の各節点は終端を≤θ 書き、芯の外に出る子は≤r、各長さ≤2ĝ_{j−1}。したがって

ĝ_j≤ℓ_u≤(2v+E_B)(θ+2rĝ_{j−1})≤K_Bĝ_{j−1}。

根については ℓ>2ĝ_m の節点は全て例外。根がこの範囲外なら k≤2ĝ_m、範囲内なら同じ刈込みにより k≤E_B(2r+1)ĝ_m。どちらも k≤K_Bĝ_m。群がない場合も k≤K_Bθ を直接得る。

この証明に場合 I の文字連再配分も (R) も要らない。必要なのは深さ、規則書込み、ランク、出力長の加法性、例外数、窓だけであり、全て前節までで確保した。原文の「u が芯の根」の説明には上の自明ケースの分離を補うと厳密になる。

### 5.5 尺度補題3.2：部分和の単射

R′=θ+2v、R=R′+2。ĝ₁ を始点として、次に R 倍以上になる最小の群値を取る貪欲列 y₁,…,y_n を作る。隣接尺度補題から y_{i+1}<K_BRy_i、最終値 ĝ_m<Ry_n、始点 y₁≤K_Bθ。

N=n−1、z_i=y_{i+1} と置く。z_i>θ なので切上げ値ではなく実際の群値であり、各区分 π(i) の整数点 p_i∈[0,θ]^{dim π(i)} 上の線形形式である。

z_{i+1}≥Rz_i から R′Σ_{j≤i}z_j<z_{i+1}。したがって c_i∈{0,…,R′} の全ての和 Σc_i z_i は相異なる。最大の相違添字の項を、それ以前の全項で打ち消せないからである。

一方、各区分で P_π=Σ_{π(i)=π}c_i p_i とすれば全ての和は Σ_π⟨φ_π,P_π⟩。座標が整数で 0≤P_π≤NR′θ だから

(R′+1)^N≤(NR′θ+1)^D。

群は各ラベルに一つの点を割り当てるので、その個数は≤v。従って N≤v−1≤R′/2、θ≤R′、NR′θ+1≤R′³。N≥1 なら R′^N<(R′+1)^N≤R′^{3D}、よって N<3D、n≤3D。N=0 は群があれば D≥1 なので n=1≤3D と別扱いすればよい。

以上から ĝ_m≤(K_BR)^{3D}θ、従って

k≤K_B^{3D+1}R^{3D}θ≤K_B^{10}R^9θ。

k<4θ+12 の場合を合わせて指定の max の上界になる。D=0 の場合は群なしの直接評価を使う。ランク上限を r=0 と解釈する場合、導出は定数規則だけで k≤θ となり別途自明である。

**尺度補題は本検証で原文まで確認した。未読の依存仮定として残していない。**

## 6. 定理に使わない補助主張

### 6.1 B-cap

W 全体に余分な b があれば、対象 a-free 因子 G の最初の b 連へその余分を移せる。余分が最初から G 内にある必要はない。G 内の他の b 連を全て消すと、最初の連より右の c が一つに集まる。G 内に a がないことがここで必要であり、c⁴ 禁止からその個数≤3。鏡像も成立。

最初の b 連より左は一つの c 連なので≤3、合計≤6。G が b を含まなければ G=c^j、j≤3。従って対象報告冒頭の、b を含まない因子も含めた要約も正しい。

### 6.2 補題 N の符号と S-III

依存元 `claude_straddle` §3.4 の補題 N の本文には、内部塊 F₀ を Q（損失 t=Λ−e₁）へ替える段で

「aF₀ を a^{1+t−e₀}Q に」

という逆符号の記述がある。正しくは

- t≥e₀：a^{1+t−e₀}F₀ → aQ。
- t<e₀：aF₀ → a^{1+e₀−t}Q。

これは補題 E をそのまま適用した式であり、交換後 a 個数は k−e₀−t になる。

修正後の N の予算も確認した。型板の a 個数 k−2e₀≥3k/4、五連を四連にする最初の融合に十分。内部交換後は k−e₀−t≥3k/8、最終外側殻交換後は k−Λ≥k/2。k≥4θ+12≥16 なら全て四連の正配分と必要な詰め物を確保できる。外側交換の二穴中央は Q を含んで非空、成分内容は殻の型一致から等しい。最後に四連を両端二連へ融合する。これで N の帰納法を再構成できる。

S-III の N_m=A^{m+1}B^{m+1} は、仮定 (m+1)d_X≤k/2 の下で SB を持つ。c 個数≥m+1≥7 なので余分な b があれば B-cap に反する。従って全 b 連は1文字。混合殻も、各殻に少なくとも一つ c、中心に少なくとも一つ c、殻数≥6、合計損失≤k/2、型板の型一致を明示すれば同じ論証になる。

対象 §7.1 の「(m+1)d_X≤7k/(50θ³)」は**一般の m≥6 には成立しない**。これは m=6 を選んで、少なくとも一つの必要な入れ子が作れると示す式である。一般 m は主張に明記された (m+1)d_X≤k/2 を使う。S-III の結論は変わらない。

S-III-cond は、交代語という追加仮定の下で、同じ細類の先頭文字と総長から入れ子の文字列が決まる。n_Y 個の X と n_X 個の Y を同じ中心 P の周りに入れれば語は等しく、中心の損失 d_P は相殺する。必要殻数≤θ、中心を含めた損失≤(θ+1)k/(50θ³)≤k/2。定理 S により n_Yd_X=n_Xd_Y。追加仮定を取り去る論証にはなっていない。

### 6.3 命題 β：共有文脈を修正する

(i) 対象 §8 は SB の二語 a^sFa^t と a^{s−1}Fa^{t+1}（s+t=k−d、s≥2）に、E=(a^{s−2},a^{t−1}) を指定している。しかし E[a²F]=a^sFa^{t−1} であり、指定の第一語より a が1文字少ない。

**修正は E=(a^{s−2},a^t)。** これで E[a²F]=a^sFa^t、E[aFa]=a^{s−1}Fa^{t+1}。ゆえに D(a²F)=D(aFa) が成立する。

t₀=⌊(k−1)/(d+2)⌋ とすると k−t₀d≥2t₀+1。t₀≥2 なら鎖予算 t₀d≤k−5≤k−4、t₀=1 は元の SB、t₀=0 は自明。鎖 F^{t₀} を作り、各境界を上の等分布で分離する。再配分で次の操作位置に2文字集められるので、t₀ 個の a-free 極大因子を持つ語が得られる。従って β(L)≥t₀。

(ii) h=⌊k/(4d+4)⌋ と置く。h=0 は自明、h≥1 なら N を m=h−1、中心 AB に適用して SB(A^hB^h,hd)。hd≤k/4、k−hd≥3k/4。

SB₂(A,B;d) から使う共有文脈は、例えば n=k−d≥4 として

- A 用：E_A=(ε, aBa^{n−3})。穴は a²A と aAa。
- B 用：E_B=(aA, a^{n−3})。穴は a²B と aBa。

それぞれ三つの a 連が正で、埋めた二語の a 個数はともに n。従って D(a²A)=D(aAa)、D(a²B)=D(aBa)。必要な境界を順に分離すると 2h 個の因子を得る。正の a 連は最終的に2h+1 本であり、3k/4≥2h+1（k≥16、d≥1）で足りる。隣接する A,B の文字が等しくても、挿入した a が区切るので個数は2h。

したがって双方の β 下界は修正後に成立する。冒頭に引用された M_β そのものは今回の定理にも β 下界の証明にも使わず、その別定理の全面検証は本報の判定に含めていない。
