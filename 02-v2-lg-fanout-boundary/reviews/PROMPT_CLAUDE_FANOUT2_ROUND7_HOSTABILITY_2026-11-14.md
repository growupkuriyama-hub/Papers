## 1. 対象・量化・最優先の型

- 第一標的：`Σ={a,b,c}`, `A={a,c}`, `B={b,c}`, `C=A∩B={c}`、射影 `π_A`, `π_B`、**ℓ=2、fan-out f=2、rank r≤2**。
- 局所データ：
  `dat_ov(w)=((ŝ₂(π_Aw),N₂(π_Aw)),(ŝ₂(π_Bw),N₂(π_Bw)))`。
  ここで `ŝ₂` は短語を区別する `s_{1,1}` のcompletion、`N₂` はbigram計数。射影が空の場合・長さ1の場合の短語タグを省略しない。
- 言語：`L ∩ Σ⁺ = {w∈Σ⁺ : dat_ov(w)∈Q}`、**Q は任意集合**。別途 `L` が f-MCFL で `(f,s)`-tuple-substitutable を仮定する。
- **最優先 s=c_Σ（内容型）**。精密な `s≼c_Σ×(ŝ₂∘π_A)×(ŝ₂∘π_B)` を扱う場合は、穴語 `(t,h)` の **s型一致を改めて証明**する。`h=ab,t=aabb` は内容型なら一致するが、A射影は `a` 対 `aa` であり短語タグ型は一致しない。
- 元の任意の reduced **good MCFG** `G` に対して論じる。ε-free、linear、nondeleting、nonpermuting、nonmergingの条件を確認。出発点 `η` は**実際に印を一つも含まない極大自由部分木**。型付き節点数最小導出、頻出窓の閾値、DFS同色切り口の証明仮定を飛ばさない。
- `v=|V(G)|`、`θ=\bar θ_G`（**元の文法の厚さ**）。目標の多項式は v と θ に関する。型精密化後の厚さに置き換えない。`τ(G,s)` の短い代表は元Gで導出可能でなくてもよい。
- 文脈 `E_e = v_0 □ v_1 □ ... □ v_e` の各穴は**非空語**を入れ、内側区切り `v_1,...,v_{e-1}` は**全アルファベットで非空**。穴数 `1≤e≤f`（削除差なしなら穴0を使わずそのまま進める）。同じ根成分内の穴順序と固定separatorを保存する。

### 各根成分内の符号と差分

DFS同色切り口 `j<j'` の `η` 各成分 `κ` について、

`Z_{κ,A}=N₂(π_A ψ_κ^(j))−N₂(π_A ψ_κ^(j'))`,  
`Z_{κ,B}=N₂(π_B ψ_κ^(j))−N₂(π_B ψ_κ^(j'))`。

**要確認**：P1の純／不純窓の差分と各 `Z` の成分別**非負性**（H*の仮定）、circulation性、共有 c の数の一致。色から任意の符号付きcirculationが出るなら、H*を勝手に適用しない。確立していない条件は明示し、必要ならより細かい色に改良する。

## 2. すでに判明した事項（再発明より、未解決に進む）

**U1a（語）**：`P∈A*`, `Q∈B*` に同時射影原像がある iff `π_C(P)=π_C(Q)`。一文字共有なら c の個数一致。  
**U1b（穴付き）**：同時実現には**穴と固定区切りの一片ずつ**共有射影が一致する必要十分条件（加えて穴と内側区切りの非空性）。全語の c 個数一致だけでは不十分。  
**K（共有計数保存）**：各κの `Z_{κ,A}`, `Z_{κ,B}` について `Z_{κ,A}(→c)=Z_{κ,B}(→c)`。ただし頻出SCC `J` 別に再集約するとκの分割がずれ、同じ恒等式は保証されない。  
**例R**：`A={a,c,e}, B={b,c}` の good fan-out2/rank2表示で、A側SCC穴1個・B側SCC穴2個。**同順位束ねは失敗**。`κ`別に `h=(ab,ca)`, `t=(aabb,caca)` とすれば例Rでは2穴修復可能。極大ηを B_6 に修正した独立検査を採用する。これは**旧手法への反例 (A)** であって新定理や特性データ長上界の反例ではない。  
**G（ℓ=2の間隔表示）**：`w=w_0 c w_1 ... c w_n`、各区間 `w_i∈{a,b}*` のa,b個数 `α_i,β_i` により `dat_ov` が完全に決まる。`n, |w|a, |w|b`、内部区間の `α_i>0` と `β_i>0` のそれぞれの個数、端区間の占有有無で足りる（空・短語例外に注意）。**同一区間でaとbが同時に現れるかの相関自体は、このデータから直接には定まらない。**  
**H*（ℓ=2の局所膨張）**：非負circulationの組を

`Z_A=p·aa+q·cc+r·(ac+ca)`、  
`Z_B=p'·bb+q'·cc+r'·(bc+cb)`、  
`p,q,r,p',q',r'≥0`, `q+r=q'+r'=m` と書く。`h` が必要文字を含むなら、最初のa/bを繰り返し、最初のcを `c(Y_1c)...(Y_mc)` に膨らませて `t` を構成し、任意の外部文脈でbigram差分 `N₂(π_b(utv))−N₂(π_b(uhv))=Z_b` を得られる。**穴語の正確なs型が一致するかは別問題**。

**絶対に未解決のままの箇所**：Y/F双方に使える単一 `h_κ` を、穴数 `≤fan(η)`、順序と区切りを保って選べるという一般的 **hostability (HC)**。同じ `h` がY側にもF側にも*各データの語*として実現できることが重要で、H*自体はこの存在を与えない。

## 3. メイン研究問題：{a,b} 型hostabilityを完全に片づける

### 3.1 最小の難所

特に `Z_{κ,A}=p·aa`, `Z_{κ,B}=p'·bb`（`p,p'>0`, `Δ_c=0`）を調べる。望む穴語は `h=ab` もしくは `ba`、または共有 c を通る `h=a c^m b` / `b c^m a` 等。ただし c を含む穴なら、t/h両方の c 個数一致を確認する。

**F側障壁**：`W_{j'}` と同じ `dat_ov` を持つ語の中に a,b を同じ c 区間に置けるものがない場合、`ab` と `ba` は使えない。**Y側**ではその区間が存在しても、両側で同じ `a c^m b` を置けるとは限らない。

検討すべき点：

1. 各側の `Γ` データから、**ある因子 h（a,bを含む）を持つ代表が存在する条件**を必要十分で書く。候補 `ab`, `ba`, `ac^m b`, `bc^m a` で十分か、それ以外が必要かを証明／反証。
2. YデータとFデータの双方が実現可能な **共通の `h` の集合**を構造的に比較。射影窓の出現数、稀骨格、先頭保護窓、ηの各成分と分離区切りを織り込む。単なる任意の Γ 値の組で交わらない例は**原定理の反例ではない**。DFS同色切り口から実際に生じる Γ 同士に制限せよ。
3. **同じ根成分に2穴ある場合**、それぞれの h の選択だけでなく、二つの出現位置の間に非空な固定区切りを確保。穴を一つにまとめる場合、**元のκ差分の分担**と s型を保存。
4. `F[h],F[t]∈L` を **任意Q** で保証するには両語の `dat_ov` が既知の受理語と一致することを証明。Y側 `y^π` は現在の目標データを実現すること、`y'=y^π[t→h]` は削除後の目標データを実現することを別々に確認。
5. 先にYとFで穴を選んでから構成する順序と、各側でEuler再配線してから共通穴を探す順序が交換可能か。駄目なら、**共通穴を先に設計する**新しい補題を提案。

### 3.2 目標の正確な定理形式

**第一候補**：`f=2,r≤2,ℓ=2,A={a,c},B={b,c},s=c_Σ` において、任意の `reduced good G` と、合法な型付き最小導出・極大自由節点η・同色DFS切り口が満たす仮定の下で、`κ`別の非空穴組 `(t_κ,h_κ)` と admissible `F` および `y^π` を構成し、(i) `e≤f`, (ii) s型一致, (iii) Y/F双方の窓データ差分, (iv) 非空区切り, (v) 元Gの厚さを使う長さ減少を証明する。

これが難しければ、**第二候補**として条件付き補題を厳密に証明する。例えば「F側でもa,bが同じc区間で共存」「全てのκで c を含む削除差分」「対象root成分が一つ」「fan-out 1」等の十分条件を最小化し、条件が自明／空虚でない具体例と、外すと破綻する反例を付す。

**第三候補**：メインHCを一般に否定する最小の構造反例。このとき原論文の good MCFG、型付き最小性、印数、極大η、同色切り口、元Gの厚さ、言語の f-組代入可能性まで確かめる。**hostability補題の反例と多項式上界結論の反例は別物**。

## 4. 強い反証探索：量化を区別する

出力で反例を必ず次のいずれかに分類する。

- **(A)** 特定のアルゴリズム（同順位束ね、固定向きh、greedy配置など）が失敗。
- **(B)** 一般化した補題HCの**実際の全仮定**の下で結論が偽。
- **(C)** 型付き代入可能性を使う補題が成立しない（具体的な型・受理文脈を示す）。
- **(D)** 一様多項式**特徴データ総長**の下界（極めて強い主張。単なるアルゴリズム失敗ではない）。

無制約のParikhデータ間の矛盾や小さい短語タグ不一致は(A)または補助補題の反例であり、自動的に(B)/(D)へ昇格しない。先行の例Rは(A)である。

### 有界計算の推奨

Python3標準ライブラリだけで十分。乱数シードを固定し、できれば小さなサイズは全列挙とする。

- `Σ={a,b,c}` の `|w|≤n` と、`Γ(w)` の同値類、実現できる2穴分割を計算。
- `Γ` ごとに `h∈{a,b,c}^+`（例えば最初は長さ≤6）の**hostableな穴語の集合**を列挙し、Y/F双方の集合の交差を見る。**実際の導出・η・印・同色条件**も別のモードでテストし、抽象データの反例と混同しない。
- 共有 c の差分0、`p,p'>0` に限定した全ケースから入り、方向 `ab/ba`、距離m、端区間、中間のν_A,ν_B、凍結窓数で整理する。
- `f=2,r=2` の交差MCFGテンプレートも必ず少数入れる（単なる正則/CFLのみで一般MCFGを検証したと主張しない）。`good`、再帰高さ、極大ηの確認assertは**実際に真偽を分ける式**で書き、`or True` 等の空検査を禁止。
- すべてのassertが通っても有限実験は無限族の証明ではない。

探索を尽くしてもHCが成立しない場合、**最小の未処理例と、その例で必要な新補題を明示して止めてよい**。現実の数学的進展を優先する。

## 5. H*・P1・Euler接合に関する監査チェックリスト

1. `Z_κ` は**窓計数差**であり、生文字差ではない。circulationとしての入出次数の保存には `ŝ_ℓ` による端点型一致を使う。c保存則はκ単位で保持。
2. `Z_κ` の全成分非負と「全ての削除差を同じhに挿入できる」は別命題。H*は非負循環差分の場合だけ保証。
3. 局所データの境界またぎ窓は、射影後に隣接する位置の**全文字上span**で純／不純を判定する。射影で消える文字を無視しない。
4. 固定ブロックψや稀辺をF側で凍結すると、自由に動かせる区間が減る。各 frequent edge の残数を **数値不等式**で評価し、適当な定数`C_*`を後付けするだけで済ませない。
5. Eulerグラフ上の辺列と、元アルファベットへ挿入する語は同一ではない。端点と重複境界（ℓ−1文字）を正確に管理。
6. `h,t` 両方が空でないこと、同じ `s` 型を持つこと、**Fが共通の**admissible文脈であることを検証。
7. 厚さθ、型付き高さH、骨格節点数、自由部分木数、DFS反鎖、色数、貪欲削除の各段を明記し、最終指数を根拠なく既存定理からコピーしない。
8. 必要な型がcontentより細かいなら **contentでの境界問題への成果と別扱い**。任意Qの言語がf-MCFL・代入可能という別仮定を忘れない。
