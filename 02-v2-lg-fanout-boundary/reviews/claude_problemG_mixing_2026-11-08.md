## 1. 設定

Σ = {a, b}。H は有限群、φ: Σ* → H はモノイドの準同型で、φ(Σ*) = H（有限群なので、正の語の値で H 全体が覆われることと、φ(a), φ(b) が群として H を生成することは同値）。α = φ(a), β = φ(b)。L = φ⁻¹(1) ∩ Σ⁺。G は L(G) = L となる ε なしの CFG（ランク・good 性は使わない）。‖G‖ = |V| + Σ_{X→γ}(1+|γ|)。θ_S を L の最短の語の長さとする（θ_S ≤ t_G ≤ θ̄_G）。

## 2. 準備

**(P1) 値の一意性。** G を reduced にしても大きさは増えず言語は変わらない。reduced な G の各非終端 X は S ⇒* lXr となる成功文脈を持つので、X の任意の生成語 y, y′ について φ(l)φ(y)φ(r) = 1 = φ(l)φ(y′)φ(r)、従って φ(y) = φ(y′) =: g_X。

**(P2) 二分化。** 長さ ≥ 2 の右辺を二分化し、右辺の中の終端を補助非終端 T_a, T_b に置き換えた文法 G′ は同じ言語を生成し、|V′| ≤ ‖G‖ + 2（`chatgpt_problemG_2026-11-01.md` 定理3の計算と同じ）。G′ の補助非終端の生成語は、G の記号の決まった列の生成語の連接なので、やはり値が一意。単位節点を縮めた G′ の導出木は、葉が文字の二分木。

**(P3) 中間の部分木。** 葉が m ≥ 3 個の二分木には、葉の数が [m/3, 2m/3] に入る部分木がある（根から葉の多い方の子をたどり、初めて 2m/3 以下になった節点。その親は 2m/3 を超え、この節点は親の半分以上なので m/3 を超える）。

**(P4) 計数補題（`chatgpt_problemG` の一般形）。** F ⊆ L ∩ Σ^m（m ≥ 3）とし、長さ q−p ∈ [m/3, 2m/3] の全ての区間 [p, q) と全ての g ∈ H について #{w ∈ F : φ(w[p:q]) = g} ≤ K とする。すると |F| ≤ |V′|(m+1)²K。
証明：各 w ∈ F の導出木から (P3) の節点を一つ選び、(ラベル X, p, q) を記録する。(P1)(P2) より φ(w[p:q]) = g_X。一つの三つ組に対応する w は K 個以下で、三つ組は |V′|(m+1)² 個以下。

**(P5) 周期。** d を L の語の長さの gcd とする。χ(φ(u)) := |u| mod d は H から Z/d への全射準同型としてうまく定義される。
証明：φ(u) = φ(v) なら φ(z) = φ(u)⁻¹ となる正の語 z を取ると uz, vz ∈ L、従って |u| ≡ −|z| ≡ |v|。準同型なのは明らか、全射なのは χ(α) = 1 だから。H₀ := ker χ、C_ℓ := χ⁻¹(ℓ mod d) とおくと |C_ℓ| = |H₀| = |H|/d。d ≤ θ_S。

**(P6) 混合時間。** P_ℓ(g) := #{u ∈ Σ^ℓ : φ(u) = g}/2^ℓ とする。P_ℓ は C_ℓ の上に台を持つ。
- 単調性：P_{ℓ+1}(g) = ½P_ℓ(gα⁻¹) + ½P_ℓ(gβ⁻¹) で、g ∈ C_{ℓ+1} なら gα⁻¹, gβ⁻¹ ∈ C_ℓ。従って max_{C_ℓ} |H₀|P_ℓ は ℓ について非増加、min は非減少。
- 収束：P は H 上の既約な二重確率の推移で、単位元からの閉じた道の長さの gcd が d なので周期 d。よって g ∈ C_ℓ について |H₀|P_ℓ(g) → 1。
- 定義：t := min{ℓ : max_{g ∈ C_ℓ} | |H₀|P_ℓ(g) − 1 | ≤ 1/2}。単調性より ℓ ≥ t の全てで同じ不等式が成り立つ。

## 3. 定理M

**定理M.** 上の設定で
\[
 |H| \le \tfrac92\,\theta_S\,(\|G\|+2)\,(6t+\theta_S+4)^2 .
\]
特に ord(α) ≤ |H| も同じ式で抑えられる。

**証明.** m を、m ≥ max{6t, 3} を満たす最小の d の倍数とする（m ≤ 6t + d + 3）。F := L ∩ Σ^m。

- 下界：m ≡ 0 (mod d) なので 1 ∈ C_m、m ≥ t より |F| = 2^m P_m(1) ≥ 2^m/(2|H₀|)。
- 上界：区間 [p, q) の長さ ℓ = q − p ∈ [m/3, 2m/3]、s := m − q とする。p + s = m − ℓ ≥ m/3 なので max{p, s} ≥ m/6 ≥ t。また ℓ ≥ m/3 ≥ 2t ≥ t。語を前・中・後に分けると
  \[
  \#\{w\in F:\varphi(w[p:q])=g\}=\sum_{x\in H}N_p(x)\,N_\ell(g)\,N_s(g^{-1}x^{-1}),\qquad N_k:=2^kP_k .
  \]
  s ≥ t なら全ての h で N_s(h) ≤ (3/2)2^s/|H₀| なので、和は ≤ N_ℓ(g)·(3/2)2^s/|H₀|·Σ_x N_p(x) = N_ℓ(g)(3/2)2^{p+s}/|H₀|。p ≥ t なら x を動かす和で役を入れ替えて同じ式。さらに N_ℓ(g) ≤ (3/2)2^ℓ/|H₀|。よって K ≤ (9/4)2^m/|H₀|²。
- (P4) より 2^m/(2|H₀|) ≤ |V′|(m+1)²(9/4)2^m/|H₀|²、すなわち |H₀| ≤ (9/2)|V′|(m+1)²。|H| = d|H₀|、d ≤ θ_S、|V′| ≤ ‖G‖+2、m + 1 ≤ 6t + θ_S + 4 から主張が出る。∎

**注意。** 定理M は文法のランクにも good 性にも厚さにもよらない（θ_S は最短の単位元語の長さだけ）。厚さ θ̄ が効くのは次の系を通してだけ。

## 4. 系と、問題G への意味

**系M1.** 問題G の反例の族（ord φ_n(a) が ‖G_n‖, θ̄_{G_n} のどの多項式でも抑えられない）では、‖G_n‖θ̄_{G_n} = |H_n|^{o(1)} であり、従って
\[
 t_n \ge |H_n|^{1/2-o(1)} .
\]
つまり**正の生成元による酔歩がほとんど「可換群並みに遅く」混ざる群**でなければならない。一方、厚さを小さく保つには α^{2^j} 型の大きな冪に短い正の語が要る（指数的な歪み）。

**H_n（`chatgpt_problemG` 定理3の群）。** `check_claude_hn_mixing_2026-11-08.py` の計算では t ≈ 1.15 n log₂ n（n = 3..12）。これを証明すれば定理M から ‖G‖ ≥ 2ⁿ/O(n³ log² n) となり、既知の 2^{(2/3−o(1))n} を改良する。証明の候補：b の個数を法 n で見ると a の重みが 2^j になるので、Chung–Diaconis–Graham の過程 X ↦ 2X + ε (mod 2ⁿ−1) と同種の評価。未着手。

## 5. 問題G を肯定で閉じる道（未完）

1. **(R1) 有向の酔歩の混合時間を直径で抑える。** 対称な生成系では λ₁ ≥ 1/(8 diam²)（Breuillard–Tointon, Adv. Math. 289 (2016) の (1.3)）から t ≤ O(diam²·log|H|) が出る。正の生成元 {α, β} の有向の酔歩では、μ^{*k} * μ̌^{*k} の対称化で同様の評価を出す必要がある。**穴。**
2. **(R2) 直径が大きい群の構造。** Breuillard–Tointon の定理1.3：対称な生成系 S の Cayley 図が ε-almost flat（diam_S(G) ≥ (|G|/|S|)^ε）なら、正規部分群 N で G/N が階数・指数が ε（と β）だけで抑えられる可換部分群を持つものがある（N は S の O_{ε,β}(γ^β) 乗の球に含まれる、γ = diam）。文献による。
3. **(R3) 可換群の定理1 を「有界指数の可換部分群を持つ商」へ広げる。** **2026-11-08 に補題R3 として証明（§7）。**

(R1) が成り立てば（(R2)(R3) は済み）：t が小さければ定理M で |H| が多項式、t が大きければ直径が大きく (R2)(R3) で |H| が多項式。**問題G は肯定で、群の原像による (S1-U) の道は閉じる**。そのときは、問題G の肯定が単独の小さな結果になる（有限群の語問題の CFG の大きさと厚さ）。

## 7. 補題R3（可換群の定理1 の、仮想可換な商への一般化）【2026-11-08 追記、独立検証待ち】

**設定.** G は reduced good、ε なし、ランク ≤ r、L(G) = φ⁻¹(1)∩Σ⁺、T := θ̄_G。π: H → Q を全射準同型、A ◁ Q を可換な正規部分群、k := [Q : A] とする。

**補題R3.** |A| ≤ ((r+2)T)^{k+1}、従って |Q| ≤ k((r+2)T)^{k+1}。

（k = 1 で可換群の定理1 と同じ次数 2 の評価になる。）

**証明.**
1. *剰余類グラフ.* Γ を Q/A（右剰余類）を頂点とし、各頂点 c と文字 x に辺 c → c·π φ(x) を置く有向グラフとする（頂点 k 個、辺 2k 本）。φ が全射なので Γ は強連結。Z^E（E は辺の集合）の中の閉路空間 Z_cyc（各頂点で入次数＝出次数の整数ベクトル）は階数 2k − k + 1 = k + 1。
2. *一般化 Parikh ベクトルと余輪体.* 語 w を剰余類 c から読んだときの各辺の通過回数を N(w; c) ∈ Z^E とする。代表元 t_c（t_A = 1）を固定し、τ(c, x) := t_c π φ(x) t_{c·x}⁻¹ ∈ A とおく。A が可換なので
   t_c π φ(w) t_{c·φ(w)}⁻¹ = Σ_{e} N(w; c)_e τ(e) =: ψ(N(w; c))
   （加法的に書いた）。従って φ(y) = φ(y′) なら全ての c で ψ(N(y; c)) = ψ(N(y′; c)) で、N(y; c) − N(y′; c) ∈ Z_cyc。
3. *ψ は Z_cyc から A への全射.* a ∈ A に対し π φ(w) = a となる正の語 w は剰余類 A から読むと閉じた道で、ψ(N(w; A)) = a。よって Λ := ker(ψ|_{Z_cyc}) は Z_cyc の中で指数 |A|。
4. *短い格子ベクトル.* 各非終端 X の長さ ≤ T の生成語 u_X（値 g_X、P1）、各規則 R: X → v_0 Y_1 v_1 ⋯ Y_m v_m の展開語 e_R := v_0 u_{Y_1} v_1 ⋯ u_{Y_m} v_m について、全ての剰余類 c で z_{R,c} := N(e_R; c) − N(u_X; c) ∈ Λ（φ(e_R) = φ(u_X) = g_X と 2.）。‖z_{R,c}‖₁ ≤ T + rT + T = (r+2)T（定理1 と同じ評価）。q_S := N(u_S; A) ∈ Λ（u_S は単位元語）、‖q_S‖₁ ≤ T。
5. *望遠鏡和.* w ∈ L の導出木で節点 v の生成語の始まりの剰余類を c_v とすると、子の始まりの剰余類は c_v と前の部分の値だけで決まり、その値は実際の生成語でも u_Y でも同じ。従って
   N(w; A) = q_S + Σ_v z_{R(v), c_v}。
6. *階数.* {N(w; A) : w ∈ L} は Z_cyc ⊗ Q を張る：Γ の任意の有向閉路 C について、A から C へ行き一周して戻る語 x と、一周しない語 x′ を取ると、x^{|H|}, x′^{|H|} ∈ L で N(x^{|H|}; A) − N(x′^{|H|}; A) = |H|·C。強連結な有向グラフの有向閉路は閉路空間を張る。5. より、{q_S} ∪ {z_{R,c}} も Z_cyc ⊗ Q を張る。
7. *体積.* その中から一次独立な k+1 本を選び、生成する格子を Λ″ とする。Λ″ ⊆ Λ ⊆ Z_cyc。Z_cyc は整数格子なので covol(Z_cyc) ≥ 1（グラム行列式は正の整数）。Hadamard の不等式と ℓ₂ ≤ ℓ₁ から
   |A| = [Z_cyc : Λ] ≤ [Z_cyc : Λ″] ≤ covol(Λ″) ≤ ((r+2)T)^{k+1}。∎

**問題G への使い方.** Breuillard–Tointon の定理1.3（対称な生成系 S = {α^{±1}, β^{±1}}、直径 γ ≥ (|H|/4)^ε）により、正規部分群 N₀ ⊆ S^{O(γ^β)}（1/2 < β < 1）で、Q = H/N₀ が指数 O_ε(1) の可換部分群を持つものがある。その正規核を A とすると k = O_ε(1)、補題R3 で |Q| ≤ poly(θ̄)。diam(Q) ≥ γ − O(γ^β) なので γ ≤ poly(θ̄)。

**残る穴 (R1)**：正の生成元による有向の酔歩 μ = ½(δ_α + δ_β) の sup 混合時間 t（P6）が poly(γ, log|H|) で抑えられるか。成り立てば：
- almost flat でない場合（γ < |H|^ε）：t ≤ |H|^{O(ε)}、定理M で |H|^{1−O(ε)} ≤ poly(‖G‖, θ̄)；
- almost flat の場合：上の議論で γ ≤ poly(θ̄)、t ≤ poly(θ̄, log|H|)、定理M で |H| ≤ poly(‖G‖, θ̄, log|H|)。
どちらでも ord φ(a) ≤ |H| ≤ poly(‖G‖, θ̄) となり**問題G は肯定**。(R1) の難しさ：μ は対称でなく、μ * μ̌ の台 {1, αβ⁻¹, βα⁻¹} は H₀ 全体を生成するとは限らない（αβ⁻¹ の正規閉包が H₀）。既約表現 ρ では ‖ρ(μ)v‖² = (1 + Re⟨ρ(α⁻¹β)v, v⟩)/2 なので、一歩では縮まない向きがありうる。

## 8. 補題R1′ と定理G（問題G の肯定）【2026-11-08 午後追記、独立検証待ち】

記号：σ := α⁻¹β、s_j := α^{−j} σ α^{j}（j ∈ Z）。γ := Cay(H, {1, α^{±1}, β^{±1}}) の直径。B := (r+2)θ̄_G。m := |u_S|（最短の単位元語、m ≤ θ̄_G ≤ B）。

### 8.1 酔歩の分解

長さ ℓ の語 w = x_1⋯x_ℓ で x_i = b なら ε_i = 1、a なら 0 とすると（a = α、b = ασ）
  φ(w) = α^ℓ · s_{ℓ−1}^{ε_1} s_{ℓ−2}^{ε_2} ⋯ s_0^{ε_ℓ}
（ασ^{ε_1}ασ^{ε_2}⋯ の α を左へ集める。ℓ = 2 で α²·α⁻¹σ^{ε_1}α·σ^{ε_2} = ασ^{ε_1}ασ^{ε_2}）。s_j ∈ H₀ なので、P_ℓ は「α^ℓ × Y_ℓ」の分布で、Y_ℓ は H₀ 上の怠惰な一歩 ν_j := ½(δ_1 + δ_{s_j}) を j = ℓ−1, …, 0 の順に掛けたもの。P_ℓ が C_ℓ = α^ℓH₀ 上で一様に近いことと、Y_ℓ が H₀ 上で一様に近いことは同じ。

s_j 全体の生成する部分群は σ の正規閉包 N で（α と σ で正規化される）、H/N は α で生成される巡回群。H/N で単位元語の値は α^{|w|} なので ord(αN) | d、また χ は N 上自明なので d | ord(αN)。よって **N = H₀**。

### 8.2 α^d を s_j の短い積で書く

各規則 R: X → … の展開語 e_R と u_X は同じ値なので、自由群の語 ρ_R := e_R u_X⁻¹ は値 1、長さ ≤ B、指数和 Δ_R := |e_R| − |u_X|。全ての単位元語の長さは m + Σ Δ_R の形（補題R3 の 5. と同じ望遠鏡和）なので d = gcd(m, {Δ_R})。g := m から始めて gcd を真に下げる Δ_R を順に足すと、各段で g は半分以下になるので、高々 k ≤ 1 + log₂B 個の数 x_1 = m, x_2, … で gcd が d になる。Bezout の係数は、i ≥ 2 の c_i を mod x_1 で簡約して c_1 で調整すれば |c_i| ≤ kB にできる。従って自由群の語 ρ_d := u_S^{c_1} Π ρ_{R_i}^{c_i} は、値 1、指数和 d、長さ λ ≤ k²B²。

a^{±1}, b^{±1} の語を α^{±1}, σ^{±1} に書き換え（b = ασ）、α を右へ集めると、長さ n の語は「n 個以下の s_j^{±1}（|j| ≤ n）の積 × α^{指数和}」になる。ρ_d に当てはめて **α^d は |j| ≤ λ の s_j^{±1} の λ 個以下の積**。

### 8.3 H₀ の直径

h ∈ H₀ は長さ ≤ γ の語を持つので h = (|j| ≤ γ の s_j^{±1} の γ 個以下の積)·α^E、|E| ≤ γ、d | E（h と s_j が H₀ に入るので α^E ∈ H₀）。α^E = (α^d)^{E/d} を 8.2 で置き換えると、W := max{γ, λ} として、h は |j| ≤ W の s_j^{±1} の **D′ := γ + (γ/d)λ ≤ γ(1+λ)** 個以下の積。α^W による共役（H₀ の自己同型で s_j ↦ s_{j+W}）で、窓 {s_0, …, s_{w−1}}、w := 2W+1 についても H₀ の直径 ≤ D′。どの連続する w 個の添字の窓も、この窓の α 冪による共役なので同じ。

### 8.4 窓ごとの縮小

ρ を H₀ の非自明な既約ユニタリ表現、v を単位ベクトル、v_0 = v、v_k = ρ(ν_{j_k}) v_{k−1}（一つの窓を順に）とする。‖½(I+U)x‖² = ‖x‖² − ¼‖(U−I)x‖² より S := Σ_k ‖(U_k − I)v_{k−1}‖² とおけば ‖v_w‖² = 1 − S/4、‖v − v_{k−1}‖ ≤ ½√(wS)。よって窓の全ての j で ‖(ρ(s_j) − I)v‖ ≤ 2√(wS)。h を長さ ≤ D′ の積に書けば ‖(ρ(h) − I)v‖ ≤ 2D′√(wS)、そして Σ_h ρ(h)v = 0 なので 1 = ‖|H₀|⁻¹Σ_h (v − ρ(h)v)‖ ≤ 2D′√(wS)。従って S ≥ 1/(4wD′²)、**窓一つの作用素ノルム ≤ 1 − 1/(32wD′²)**。

### 8.6 定理G

**定理G（問題G の肯定）.** 絶対定数 C, κ があって、任意の有限群 H、全射なモノイド準同型 φ: {a,b}* → H、φ⁻¹(1)∩Σ⁺ の任意の reduced good、ε なし、ランク ≤ r の CFG G について
  ord φ(a) ≤ |H| ≤ C (r‖G‖θ̄_G)^κ。

*証明.* ε := 1/20、β := 3/4 とし、Breuillard–Tointon の定理1.3 の定数を K = K(ε, β)（指数の上界）、C₀ = C₀(ε, β)（N₀ ⊆ S^{C₀γ^β}）とする。以下 poly は r‖G‖θ̄ の固定次数の多項式。

- *(i) γ < (|H|/5)^ε の場合.* 補題R1′ で t ≤ poly·|H|^{4ε}·log|H|。定理M で |H| ≤ poly·(t+θ̄)² ≤ poly·|H|^{8ε}·log²|H|、8ε = 2/5 なので |H| ≤ poly。
- *(ii) γ ≥ (|H|/5)^ε の場合（ε-almost flat）.* 正規部分群 N₀ ⊆ S^{C₀γ^β} で、Q := H/N₀ が指数 ≤ K の可換部分群を持つ。その正規核 A の指数 k ≤ K!。補題R3 で |Q| ≤ k((r+2)θ̄)^{k+1} = poly。H の元は「Q の元の長さ ≤ diam Q の持ち上げ」×「N₀ の元（長さ ≤ C₀γ^β）」なので γ ≤ |Q| + C₀γ^{3/4}、従って γ ≤ max{(2C₀)⁴, 2|Q|} = poly。補題R1′ で t ≤ poly·log|H|、定理M で |H| ≤ poly·log²|H|、よって |H| ≤ poly。∎

**注意.**
1. κ と C は Breuillard–Tointon の定数（Breuillard–Green–Tao の構造定理を経由するので非有効）に依る。多項式の存在だけが言える。
2. 定理G は群の原像に限る。`op:S1` の肯定ではない。ただし `claude_two_letter_fanout1_2026-11-01.md` 系A1 の「問題G の否定 ⇒ ファンアウトの分離」の道は**閉じる**。
3. 単独でも意味のある結果：「有限群の（正の）語問題を生成する文脈自由文法は、大きさか厚さが群の位数の多項式根以上」。可換群の定理1（次数2で最良）と H_n の 2^{(2/3−o(1))n} を含む。H_n では定理M と混合時間 O(n log n) の証明があれば 2ⁿ/poly(n)。
