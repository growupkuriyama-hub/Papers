## 3. P1：statement と証明

### 3.0 記法

- τ は型付き根 X=A_T の導出木、x=(x_1,…,x_d)（d≤2）はその出力である。x の各文字に**原位置タグ**（規則出現と添字）を付ける。
- X∈{A,B} について、π_X x_i の**窓**は、x_i の中の位置の組 p<q で、x[p],x[q]∈X、かつ間に X の文字がないものをいう。型は x[p]x[q]、**Σ-span** は閉区間 [p,q] である。
- **印 𝓜**：各 (i,X,e) について、型 e の最初の c\* 個の窓の**両端点**に印を付ける（端点方式）。
- **η**：印を含まない極大節点。成分 φ_κ=x_{i_κ}[s_κ,e_κ) とする。
- **DFS**：η の葉を DFS 順に ℓ_1,…,ℓ_m と並べる。
  - I_j は「葉集合 ⊆ {ℓ_1,…,ℓ_j} の節点のうち極大なもの」。
  - U_j は I_j の各部分木が生成する原位置の集合。
- **置換**：各 ν∈I_j（ラベル B）を、任意の u_ν∈L_B(G)、‖u_ν‖₁≤θ の導出で置き換える（`lem:thickness-equivalence`(ii)）。
  - u_ν の選び方は j や ν に依存してよい。
  - 挿入文字には**挿入タグ**を付ける。
  - 結果を x^{(j)}、その η 部分の第 κ 成分を ψ^{(j)}_κ、W_j:=E_A[x^{(j)}] とする。
- **span 不純**：π_Xψ^{(j)}_κ の窓の Σ-span（ψ の中の閉区間）に挿入タグが一つでもあれば不純、なければ純とする。
- **色**：Imp_{κ,X}(j) は不純窓の型の多重集合。色は
  col(j):=(ŝ₂(π_Xψ^{(j)}_κ), Imp_{κ,X}(j))_{κ≤fan(η), X∈{A,B}}。

### 3.1 補題0（構造）[証明]

(i) good（線形・非削除）なので、任意の節点の各成分の出力は根成分の連続因子になる。異なる (ν,k) の因子は、ν が比較不能なら互いに素である。

(ii) ψ^{(j)}_κ は、φ_κ の中で ν∈I_j の第 k 成分が占める因子を、それぞれ非空語 u_{ν,k} に置き換えた語である。I_j は反鎖なので、この置換は well-defined である。

(iii) j≤j' なら U_j⊆U_{j'}。I_j の各節点は I_{j'} のある節点の子孫か、その節点自身だからである。

(iv) W_j∈L。x^{(j)}∈L_A(G) であり、`lem:thickness-equivalence`(iv) の E_A は L_A(G) の全ての組を受理するからである。**Q や代入可能性は使わない。**

*証明.* (i) 規則ごとの帰納法による。(ii) は (i) と ε-free 性（`def:grammar-properties` の直後の注意：全成分が非空）から従う。(iii)(iv) は定義から従う。∎

### 3.2 補題1（純窓の全単射）[証明]

各 j, κ, X について、次の写像は型を保つ全単射である。

- 定義域：π_Xφ_κ の窓 (p,q) で、[p,q]∩U_j=∅ を満たすもの。
- 値域：π_Xψ^{(j)}_κ の純窓。
- 写像：同じ二文字の組を対応させる。

*証明.*

(→) [p,q] に U_j の位置がないとする。置換される因子は U_j に含まれる連続区間なので、[p,q] と交わらない。非空の連続区間が [p,q] の内部に入れば [p,q] と交わるので、そうした因子もない。したがって φ[p..q] は ψ の中に**連続因子としてそのまま**残り、挿入文字を含まない。X 文字の連続性も保たれる。

(←) ψ の純窓 (p',q') を取る。ψ[p'..q'] は原文字だけからなる。ψ の中で隣接する原文字 u,v は φ でも隣接する。隣接しなければ、間の φ 文字はすべて置換因子に入り、その因子は**非空**の語で置き換えられて ψ の u と v の間に入るので、矛盾である。よって ψ[p'..q']=φ[p..q] となる連続区間 [p,q] がある。[p,q] が U_j の位置を含むなら、その位置は置換因子に属して ψ から消えているはずなので、矛盾である。X 文字の連続性も移る。∎

**ε-free 性は本質的である。** 置換片が空になると (←) が崩れる（負の対照：φ=babab の中央の b を空にすると、span の色は等しいのに恒等式が壊れる）。

### 3.3 定理 P1-b（成分別の差分）[証明]

col(j)=col(j')、j<j' とする。各 κ, X について

Z_{κ,X}:=N₂(π_Xψ^{(j)}_κ)−N₂(π_Xψ^{(j')}_κ) は、多重集合 𝒟_{κ,X}(j,j')（π_Xφ_κ の窓で、Σ-span が U_{j'} と交わり U_j と交わらないものの型）に等しい。

とくに次が成り立つ。

- Z_{κ,X}(e)≥0（全ての辺 e で）。
- ∂Z_{κ,X}=0。
- 𝒟 の窓はすべて π_X x_{i_κ} の**印なしの原窓**である。

*証明.*

1. N₂=（純窓の型）+Imp と分けられ、Imp は j と j' で等しい。
2. 補題1 より、純窓の型の多重集合は 𝒫_j:={[p,q]∩U_j=∅ の窓の型} である。
3. U_j⊆U_{j'} なので 𝒫_j−𝒫_{j'}=𝒟 となり、これは非負である。
4. ∂：長さ≥1 の語 u について ∂N₂(u)=e_{last}−e_{first}。ŝ₂ が等しければ、先頭・末尾の文字（または短語そのもの）が等しいので ∂ の差は 0 である。
5. 𝒟 の窓は φ_κ の内部窓である。φ_κ は x の連続因子なので、それは π_X x の窓でもある。両端点は η の中にあり印を持たない。印付き窓は両端点に印があるので、𝒟 には入らない。∎

### 3.4 定理 P1-c（全語の恒等式）[証明]

col(j)=col(j') なら、X=A,B について

N₂(π_XW_j)−N₂(π_XW_{j'})=Σ_κZ_{κ,X}、　ŝ₂(π_XW_j)=ŝ₂(π_XW_{j'})。

*証明.*

1. W_j を次の片の連接として書く：E_A の固定区切り、x の η 外部分、ψ^{(j)}_κ。片は空語でもよい。
2. 射影すると、π_XW_j は π_X（片）の連接になる。空の片は単位元として扱う。
3. 連接の N₂ は「各片の N₂ の和」と「片をまたぐ窓」の和である。片をまたぐ窓は、次の二つで決まる：ある片の最後の X 文字と、次の**非空**片の最初の X 文字。どの片が空か、先頭・末尾の文字は何かは、片ごとの ŝ₂ が全て記録している。
4. j と j' で ψ 以外の片は文字どおり同じで、ψ の ŝ₂ は色により等しい。よって境界窓の多重集合は等しく、ŝ₂（モノイド準同型）も等しい。
5. 次の場合も同じ議論に含まれる。
   - 射影で空になる区切り
   - 同じ根成分の二つの η 成分（間の因子が空かどうかは j によらない）
   - E_A の内側区切り（Σ 上で非空。射影で空になってもよい）

∎

**注.** P1-c は ŝ₂ を含むどの色でも成り立つ。Imp が要るのは P1-b（非負性と原窓との対応）のためだけである。

### 3.5 定理 P1-d（共有文字保存と参加型）[証明]

col(j)=col(j') なら、各 κ について

- Z_{κ,A}(ac)+Z_{κ,A}(cc)=Z_{κ,B}(bc)+Z_{κ,B}(cc)
- Z_{κ,A}(ca)+Z_{κ,A}(cc)=Z_{κ,B}(cb)+Z_{κ,B}(cc)

さらに、Z_{κ,A}=0 なら Z_{κ,B}∈ℕ·bb であり、Z_{κ,B}=0 なら Z_{κ,A}∈ℕ·aa である。

*証明.*

1. 非空の u∈X^\* について、Σ_y N₂(u)(yc)=|u|_c−[u_1=c]、Σ_y N₂(u)(cy)=|u|_c−[u_{last}=c]。
2. |π_Aψ|_c=|π_Bψ|_c=|ψ|_c であり、ŝ₂ の一致から先頭・末尾の文字は j と j' で同じである（空語・一文字も ŝ₂ が区別する）。よって最初の二式が成り立つ。
3. 参加型：Z_{κ,A}=0 なら、Z_{κ,B} の c への入次数も c からの出次数も 0 なので、台は {bb} に入る。∎

**注意.** この保存則は**各 κ ごと**（したがって各根成分の和）の主張である。頻出成分 J ごとに分けて独立に合算した後も保存されるとは主張しない（第六段の例R）。

### 3.6 色数 [証明。H は引用]

- ŝ₂ の値は各射影で 7 通り（ε、一文字 2、両端の組 4）。
- 不純窓は、ある置換因子 F と span が交わる窓である。一つの F につき高々 |F|_X+1 個。
- |I_j|≤rH（引用）、各節点の成分は ≤2、挿入文字は ≤|I_j|θ。よって |Imp_{κ,X}|≤rH(θ+2)。
- 窓の型は射影ごとに 4、(κ,X) の組は ≤4。したがって

  H=O(v) を認めれば O((vθ)^{16}) で、第六段の指数と整合する。**H の評価（型付き高さ補題）は今回再証明していない。**

## 4. B6：statement と証明

### 4.1 手続き（一つのループとして）

1. **固定するもの。** τ、𝓜、極大自由節点 η_1,…,η_g。これらは比較不能なので、生成する位置は互いに素である。
2. **段の選び方。** 各 η について、色列 col(0),…,col(m) を**原木だけから**計算する。k=0 から始め、col(j')=col(k) となる最大の j'>k があれば段 (k,j') を作って k:=j' とし、なければ k:=k+1 とする。
   - 段の列は**事前に確定**し、現在の状態には依存しない。
   - 同じ η の中では j_{t+1}≥j_t' が成り立つ。
3. **状態。** 段 t の削除窓集合を D_t:=⋃_{κ,X}𝒟_{κ,X}(j_t,j_t')（原窓 (i,X,p,q) の集合）とする。状態は
   S_t(i,X):=N₂(π_Xx_i)−Σ_{s≤t}Σ_{κ:i_κ=i}Z^{(s)}_{κ,X}
   で、ŝ₂ と alph(x_i) は x のものに固定する。
4. **一段の処理（第八段 R′ の枠組み）。**
   - F 側の証人には、その段の W_{j_t'}（原木から作る）を使う。
   - Y 側では、状態 S_{t−1}−ΣZ を実現する任意の語 y′ に穴を置く。
   - y^π≡y′ を示し、P0 によって状態を S_t に更新する。
   - 表現語 y^{(t)} は Γ から作る**非局所的な再配列**であり、原位置は保たない。

### 4.2 定理 B6 [証明]

上の手続きについて、全ての t で次が成り立つ。

1. **互いに素.** s≠t なら D_s∩D_t=∅。
2. **印に触れない.** D_t∩{印付き窓}=∅。
3. **計数の上下界.** 全ての (i,X,e) で min(N₀(e),c\*)≤S_t(e)≤N₀(e)。S_t は t について単調非増加。ŝ₂・内容は不変。
4. **実現可能性.** 内容 alph(x_i) をもち、dat_ov(y)=S_t(i) となる語 y が存在する。
5. **旗（第七段の補題P）.** c\*≥2 なら、次の値は x と一致する：[ν_X≥1]、端区間の占有、「x で窓 e の印なし出現がある ⇒ S_t(e)≥c\*」。
6. **受理.** W_{j_t},W_{j_t'}∈L（補題0(iv)）。

*証明.*

(1) 同じ η の中で s<t とする。D_t の窓は U_{j_t} と交わらない。j_t≥j_s' と補題0(iii) から U_{j_t}⊇U_{j_s'} なので、D_t の窓は U_{j_s'} とも交わらない。一方 D_s の窓は U_{j_s'} と交わる。異なる η の場合、D の窓の両端点は η の中にあり、η の位置集合は互いに素である。

(2) P1-b の最後の主張による。

(3) Z^{(s)}_{κ,X} は 𝒟 の型の多重集合と**一致**する（P1-b）。よって S_t(e)=N₀(e)−#(⋃_{s≤t}D_s の型 e の窓) で、これは互いに素で印なしの原窓の個数を引いたものである。印なしの型 e の窓は N₀(e)−min(N₀(e),c\*) 個しかない。

(4) 構成による。
- S_t(i,X) は非負で、∂S_t=∂N₀ である（引くのは circulation）。
- (3) から台は N₀ の台と同じで、これは π_Xx_i の歩道の台なので連結である。したがって先頭から末尾への Euler 歩道 P_X がある。π_X x_i の長さが <2 なら、ŝ₂ の短語そのものを使う。
- |P_A|_c=|P_B|_c が成り立つ。初期値で等しく、P1-d が κ ごとに c の入次数差を A/B で一致させるからである。
- c で区切って a-ブロックと b-ブロックを交互に並べれば y が得られる（Fable 第五段 §9 の観察）。
- 内容：(3) より窓の型は一つも消えないので、文字の有無は保たれる。

(5) 第七段の補題P の証明そのものである。ν_X=N(cX)−[末尾が X] で、末尾は ŝ₂ が決める。N(cX)≤c\* なら全て印付きで不変、>c\* なら S_t≥c\*≥2。

(6) 補題0(iv)。∎

### 4.3 成り立たない強い形（B6 の位置形）

「原文の最初の c\* 窓が、現在の表現語 y^{(t)} の中に追跡可能な位置として残る」という形は、**定式化すらできない**。y^{(t)} は Γ から作る別の語であり、x との位置写像を持たないからである。

さらに弱い「W_j の中で印付き窓が窓として残る」も偽である（§5.2）。定理 B6 は、これらのどちらも使わない。

## 5. 反例（すべて分類 (A)：特定の構成への反例）

### 5.1 射影タグの色（全仮定を満たす実導出）

**文法.** OV2(M=4)。
- S は L_eq の CFG：S→SS | aSb | bSa | ab | ba | c、および S→(x1.1 x2.1 x1.2)(B₄,S)。
- B_m→(x1.1x2.1, x1.2x2.2)(B_{m−1},B_{m−1})
- B_m→(x1.1x2.1, x2.2x1.2)(B_{m−1},B_{m−1})（交差）
- B₀→(aac,cbb) | (aca,bcb)
- B_m→(b,a) | (cb,ac)（全ての m）

**文法の性質.**
- good、reduced、fan-out 2、rank 2。全規則の a−b 収支が 0 なので、L(G)=L_eq={w∈Σ⁺:|w|_a=|w|_b}（長さ≤6 は完全一致）。
- L_eq は `prop:abelian-coset-filter`(ii) により (2,c_Σ)-代入可能で、CFL である。所属は |w|_a,|w|_b で決まり、これは dat_ov の関数である。
- 型付き根 (B₄)_T、T=({a,c},{b,c}) の最小導出は全二分木だけ（31 節点。DP で確認）。

**反例の配置.** c\*=1。η は節点 17（B₃、8 葉）。φ=(`aacaacaacacaacaacaaacaca`, `bcbcbbbcbbcbcbbcbbbcbcbb`)。
- j=1：葉20（B₀=(aac,cbb)）を (b,a) に置換。ψ₂=`bcbcbbbcbbcbAcbbbcbcbb`。
- j'=2：B₁（節点19）を (b,a) に置換。ψ₂=`bcbcbbbcbbcbAbcbcbb`（大文字が挿入）。

**何が壊れるか.**
- 射影タグの色は一致し、span の色は一致しない。
- κ=1、B 側で Z={bb:1, bc:1, cb:1} だが、実際に削除された原窓は {bb:2, cb:1}。
- j=1 では、B 上で空の挿入片 `A` を跨ぐ B 窓 `bc` が、射影タグでは「純」と判定される。
- W_1,W_2∈L_eq。

**帰結.** 射影タグを使うと、「削除＝印なし原窓」という B6 の帳簿が崩れる。乱数検査では 2,189 組中 321 組で破綻した。

### 5.2 印付き窓の span が η を跨ぐ

印付き窓の両端点は η の外にあるが、span の中に η の成分（X 文字を持たない）を含むことがある。置換片が X 文字を持ち込むと、W_j でその二文字は連続しなくなる（490 件。例：RAND2 の A 窓 `ca`、OV3 の B 窓 `bc`）。

これは**計数**には影響しない。その窓は η の内部窓ではないので、Z に数えられることはない。

### 5.3 span 保護方式は採らない

η が印付き窓の span 全体を避けるように定義すると、W_j で印付き窓が窓のまま残る。しかし span は任意に長くなり得る（π_B x=c aⁿ c の `cc` 窓）。その結果、保護位置の祖先骨格が O(H) で押さえられず、長さ評価が壊れる。

**端点方式で P1/B6 は足りる。**
