## H1. ファンアウト1では2文字で線形因子の下界が出る

### 主張
Σ ⊇ {a, d}（2文字）、q ≥ k ≥ 1、W := 2q + 2 + 2^k とし、
  w_i := aⁱ d aⁱ d a^{2(q−i)+2^k}（0 ≤ i ≤ q）、L := {w_0, …, w_q}
とおく（`prop:linear-factor-all-fanout` の f = 1 の族で、a_1 = a_2 = z = a、d_1 = d_2 = d としたもの）。
- (i) L の全ての部分集合は Clark–Eyraud 代入可能。したがって全ての型付け s で C_{1,s} に入る。
- (ii) B_{1,s}、B^{≤r}_{1,s}（r ≥ 1）、クラス全体に特徴標本を持つ集合駆動作用素について、L の唯一の特徴標本は L 自身。
- (iii) 原稿の (iii) の文法で文字をまとめたものは reduced good、ファンアウト1、ランク2、大きさ 18q + 6k + 13、θ̄ = W。L のどの reduced good な表示も θ̄ = W、‖G‖ ≥ q + 1。

### 証明
(i) 全ての語の長さは W。J ⊆ L、x, y ∈ Σ⁺、文脈 (u, v) で uxv = w_i ∈ J、uyv = w_j ∈ J とする。
- i = j なら x = y。
- i ≠ j とする。u は w_i と w_j の共通の接頭辞なので、u が d を含めば最初の d の位置 i+1 = j+1 となり矛盾。よって u ∈ a*。同様に v が d を含めば、最後の d の末尾からの距離 2(q−i)+2^k = 2(q−j)+2^k となり矛盾。よって v ∈ a*。したがって x は w_i の二つの d を両方含み、因子 d aⁱ d を持つ。
- d aⁱ d を因子に持つ L の語は w_i だけで、その中の x の出現は一意（二つの d が w_i の二つの d に重なる）。よって p x q ∈ J なら p = u、q = v で、p y q = w_j ∈ J。逆向きも同じ。

(ii)(iii) 原稿の証明がそのまま通る（(ii) は (i) と `lem:distinguishing`。(iii) の大きさは文字の種類に依らず、f = 1 の式 (7f+11)q + 6k + 3f + 10 = 18q + 6k + 13）。

**最良性**：一文字 {a} では、二語 aᵐ, aⁿ（m < n）は文脈 □ を共有し、aⁿ⁻ᵐ□ が aᵐ だけを受理するので、二語以上の有限の標的は代入可能でない。

### 原稿への反映案
- `prop:linear-factor-all-fanout` に「f = 1 では {a, d} の2文字で足りる」を一項として加え、証明は上の (i) を付録H に数行で足す。
- 定理A(ii)(iii)、要旨、`cor:trivial-exact` の条件を「|Σ| ≥ 4f+1、ただし f = 1 では |Σ| ≥ 2」にする。
- 表2 の該当行。

## H2. f ≥ 2 では同じ削り方は通らない（観察と反例）

f = 2、q = 2、k = 1 で次の違反が出る（`check_claude_review2_2026-11-02.py` の Part 2）。
- **文字 a_h を一つの a にまとめる**：x = (a, Aaa)、y = (aaA, a)、共通の文脈 □₁ a □₂ BaaCaaDzz。二つの穴の間で a を移す冪の移行（`lem:power-transfer` と同じ形）が起きる。
- **マーカー d_h を一つの D にまとめる**：x = (D, DDz)、y = (DDD, z)。
- 他に「z を最後の a_h や d_h と同じにする」「a_h を二文字で交互に使う」も、q = 2 または q = 3 で壊れた。

したがって f ≥ 2 で 4f+1 を下げるには、別の族の設計が要る（未解決。方向性 B2）。

## T1. §9 の段落に F_n の評価を記録する

段落「Tightness of the exponents」は「既知の例は ‖G‖ 一つ分の差を閉じない」と書いている。README (96) で検証した結果により、最有力の候補だった F_n（窓の型付け s_{1,1}、ファンアウト1）も、作用素 B について n² + 7n + 4 ≤ cs ≤ O(n² log n) = O(‖G‖θ̄ log ‖G‖) で、差を閉じない。一文で記録すれば、この段落の主張に具体的な根拠が付く。

## N1. `lem:no-insertion` の結論を具体化する

証明は E_j（各穴を p_h^j □ q_h^j で囲んだ文脈）について E_j[x] ∈ L を全ての j で示している。結論を「L は無限」から「全ての j ≥ 0 で E_j[x] ∈ L（長さは真に増加）」に強めても証明は変わらない。使う側（`op:S1` の注、有限の標的についての議論）はそのまま。
