## 1. 問い（前回と同じ）

Σ = {a, b, c}、内容型付け c、L ∈ C_{2,c}（arity 1 と 2、arity 2 の区切りは空でない）、G は L∩Σ⁺ の reduced good な表示（ファンアウト ≤ 2、ランク ≤ r）。

> **Q：μ_a(L) := min{k : a^k ∈ L} は poly(‖G‖, θ̄_G) で抑えられるか。**

否定の族があれば `prop:rare-type` により中心の問い `op:fanout-two` が否定で解ける（LG がファンアウト2でも境界）。

## 2. 新しい構造補題（Claude が証明したもの。確かめてから使うこと）

k := μ_a(L) ≥ 5 とする（a^k が因子 a⁴ を持つので再配分が使える）。語 w の **a 骨格** σ_a(w) は a の極大な走りを一文字 a にしたもの。a を含む a 骨格 σ について
  N_σ := { |w|_a : w ∈ L, σ_a(w) = σ }
とおき、Δ := { n′ − n > 0 : ある σ で n, n′ ∈ N_σ } とする。

**補題S（a の個数のスペクトル）.**
- (i) Δ ⊆ [k, ∞)。
- (ii) Δ が空でなければ、ある g ≥ k について Δ = {g, 2g, 3g, …}。
- (iii) Δ が空でなければ、a を含む全ての a 骨格 σ で N_σ = n_σ + gℕ（n_σ := min N_σ）。とくに a だけの語は a^{k+jg}（j ≥ 0）。Δ が空なら、各 σ で N_σ は一点。

*証明の要点.* δ ∈ Δ なら、再配分（補題3.1）で二語の差を一つの a の走りに集め、個数の漏れ（系3.2(iii)）で D(a) = D(a^{1+δ})。
- (i) δ < k なら、a^k の中の a^{1+δ} を a に替えて a^{k−δ} ∈ L、k の最小性に矛盾。
- D(a) = D(a^{1+δ}) から、a を含む全ての語で、a の走りを δ だけ伸ばせる。また、a の個数が（走りの数）+ δ 以上なら、再配分で一つの走りを 1+δ 以上にしてから δ だけ縮められる。
- よって各 N_σ は +δ で閉じる。δ′ < δ がともに Δ の元なら、n_σ + δ から δ′ を引いて n_σ + δ − δ′ ∈ N_σ なので、δ − δ′ ∈ Δ。
- 加法と正の差で閉じた正整数の集合は、その最小元 g の倍数全体。(ii)(iii) が出る。

**系S（不足の加法性）.** a^k の節点数最小の導出で、印の無い重い節点の反鎖 J を同時に短い生成組に差し替えた語の a 骨格を κ_J とすると、その a の個数 k − Σ_{h∈J} w_h（1 以上 k 未満）は N_{κ_J} の元で、g ≥ k 未満なので n_{κ_J} に等しい。つまり **不足 e_κ := k − n_κ は反鎖の上で加法的**で、各重みは「差し替えた後の骨格の最小の a の個数」で決まる。

## 3. この補題が示す二つの場合

- **(α) Δ が空でない場合**：L の a の個数は、骨格ごとに mod g（g ≥ k）で固定される。a^{k+g} ∈ L。a だけの語の導出で、同じ非終端が祖先と子孫に現れれば、その間を切った語も a だけで、切った長さは g の倍数（したがって ≥ k）。
  - **狙い**：文法が多項式の大きさのとき、g（したがって k）が多項式で抑えられることを示す。例えば、a^{k+g} の導出の中で、骨格を保ったまま a の個数を g 未満だけ変える置き換えを見つけて矛盾させる。あるいは、mod g の不変量が「可換群への写像」に近いことを使って `prop:abelian-filter-short` の方法（規則ごとの差 δ_R の和）に持ち込む。
- **(β) Δ が空の場合**：各骨格で a の個数は一意。とくに a だけの語は a^k ただ一つ。
  - **狙い**：唯一語の道の既知の制約（`lem:no-insertion`、`lem:unique-word-gap`(ii)、剛性）と合わせて μ_a を抑えるか、この強い条件を満たす反例の族を作る。各骨格で a の個数が一意という条件は、無限の言語ではかなり強い（骨格が無限にある必要がある）。
