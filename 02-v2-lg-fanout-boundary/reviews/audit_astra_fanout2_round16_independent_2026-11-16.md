## 2. AB16の独立再構成

`B=bbcc`、`C=bcbc`、外側のRot量を `λ_i=N−d_i`、`d_i=δ_i≥1` とする。受理済み単独Rot語に加え、

`a^x B a^y C a^z∈L`, `x+y+z=N−d₁−d₂`

という**実在・加法的**種を仮定する。`M=max(d₁,d₂)`、`s=d₁−d₂`、`t=N−d₁−d₂`。条件 `N≥6M+1` により、以下の操作はすべて正の指数、正の穴、非空の二穴中央を保つ。

**(i) 枠内交換。** `b[bc]c=B`、`b[cb]c=C` を使い、`i≥1`、`i+s≥1` で 

- 比較片 `x=(bc,a^i)`、`y=(cb,a^{i+s})`：実型は `({b,c},{a})`。
- 共通宿主 `E₀=(a^{λ₁−i}b,c,ε)`：`a^{λ₁−i} B a^i` と `a^{λ₁−i} C a^{i+s}` はどちらもRot合同により受理。
- 試験文脈 `E₁=(P,Q,a^{e−i})`、`Q≠ε`：`PbcQ a^e` から `PcbQ a^{e+s}` が従う。逆変換も同様。

`i=1+max(0,−s)` 等を選べば必要な範囲を満たす。この移動は**同Parikhだから受理**という主張ではない。

**(ii) 加法的宿主からの初期語。** Rotにより外側`a`を右へ集めて `BC a^t∈L` とする。単独C/BのRot文脈を用いた合法な一穴置換で

`BB a^{N−2d₁}=bbccbbcc a^D∈L`, `D=N−2d₁`。

**(iii) 交換列と二分割恒等。** 上記枠交換を4回実行すると

`bbbbcccc a^E∈L`, `E=N−6d₁+4d₂=D−4s`。

ここから逆交換3回により `bcbbbccc a^T∈L`、`T=E+3s=N−3d₁+d₂` が得られる。`bbbbcccc a^E` の二つの同一分割を共通宿主に取る：

- `x=(b,bb)`、`y=(bb,b)`、実型 `({b},{b})`。
- `E₀=(ε,b,cccc a^E)` は**両側とも同じ受理語**を与える。
- `E₁=(ε,c,bccc a^T)` は `E₁[x]=bcbbbccc a^T∈L`、従って `E₁[y]=bbcbbccc a^T∈L`。

一方、直前の交換列の第6段で `bbcbbccc a^{T−s}∈L` も得られる。`s≠0` なら、同じ接頭語で末尾`a`の正の長さが `|s|∈[1,N−1]` だけ異なる。

**(iv) U_shiftの確認。** `Pa^u,Pa^{u+g}∈L`、`u≥1`、`1≤g<N` とすると、比較片 `a^{g+1},a`、共通宿主 `(P,a^{u−1})`、試験文脈 `(a^{N−g−1},ε)` は `a^{N−g}∈L` を強制し最短性に反する。**末尾指数がN以上でも有効**。従って `s=0`、すなわち `d₁=d₂`。

`N≥6M+1` から `D≥4M+1`、`E>0`、`T>0`、各交換に使う最小`a`数も正であることを確認した。`C=6`は十分定数であり、最適性は示していない。

**AB16-block** は非消去準同型 `μ(A)=a, μ(B)=u, μ(C)=v` による逆像の内容型付きtuple-substitutability保存から従う。形式語 `BBCC/BCBC` の欠損は元の `h₁,h₂` に対応する。よって室は `N≥6max(h₁,h₂)+1`。元の核の内部`a`数は双方等しいから `h₁=h₂ ⇒ δ₁=δ₂`。この証明は新たな文法やその厚さを導入しない。

## 3. P2の独立再構成

単位 `J=(p_J,q_J,d_J)` の単独語は `a^l b^{p_J} a^g c^{q_J} a^r∈L`、`l,g,r≥1`、`l+g+r=N−d_J≥4` とする。正の`a`再配分Rから `a b^{p_J} a c^{q_J} a^{N−d_J−2}∈L` を作り、二つの適法な一穴共通文脈により**それぞれのブロック全体**について `ab^{p_J}≡b^{p_J}a`、`ac^{q_J}≡c^{q_J}a` を得る。一般の文字の可換性は要しない。

交錯・入れ子の**実在種**の非`a`順序が `b^{p_B}b^{p_C}c^{q_B}c^{q_C}` または `b^{p_B}b^{p_C}c^{q_C}c^{q_B}`、その総`a`数が `N−d_B−d_C≥1` なら、上の一穴合同によって `b^{p_B+p_C}c^{q_B+q_C}a^{N−d_B−d_C}∈L` を得る。`bc→cb` はしていない。

**核心Transport：** `X=(p,q,d)` と `Y=(p',q',d')`、保持単位 `R=(r,s,e)`、`i=N−d−e≥1`、`i'=N−d'−e≥1` で、比較する二成分と文脈は

```
x  = (b^p,  c^q a^i)
y  = (b^p', c^q' a^i')
E0 = (a^(e−1), a, ε)
E1 = (ε, b^r, c^s)
```

である。実型はそれぞれ `({b},{a,c})`、二穴中央は `a` と `b^r` で非空。`E₀[x]`、`E₀[y]` は各単位の単独Canon語と一穴合同から構成できる。`E₁[x]` は既知の成分和語から、保持側の`c^s`との一穴合同で得られる。従って二穴Rectから `E₁[y]` が受理され、再び保持側の`c^s`との一穴合同で

`b^{p'+r}c^{q'+s}a^{N−d'−e}∈L`

を得る。**第三の穴を追加していない。**

種側の小さい欠損単位を保持すれば、任意の二つの許容単位へ二段階Transportできる。許容単位の欠損 `d_J≤(N−1)/2` により中間・最終の末尾`a`は正。任意の非空多重集合は総欠損 `d_m≤N−4` の範囲で、合成された単位を新たな`X`として帰納的にTransportすることで

`b^{P_m}c^{Q_m}a^{N−d_m}∈L`

を得る。二つの多重集合の `(P_m,Q_m)` が一致すると、同じ接頭語と異なる正の末尾`a`はU_shiftと矛盾するため欠損総和が等しい。

**木への移植条件を消してはいけない。** 単色二成分の短い組、内部分岐の実在木、木由来加法的種、正の室が必要。種B,Cは小窓である必要はない一方、交換対象Jの内容・型・欠損条件は保持する。`P_tree` の全内容クラスに一般化したわけではない。

## 4. ON / P2+ の監査

`z₁,...,z_t` がそれぞれbだけ、またはcだけの非空ブロックで、b相が全てc相より前にあり、各隙間の正の`a`連 `e₀,...,e_t` が `A=Σe_i<N`、`A≥t+2` とする。まずRで対象ブロック前に余剰`a`を集め、`P₀ a^h z_i a Q₀` と `P₀ a^{h−1} z_i a² Q₀`（`h≥2`）を実際に受理させる。比較片 `az_i,z_i a` の**実型**を一致させ、**一穴合同を先に証明した後**で初めて零長の隙間を作る。この順序は正当で、R単独で0にする誤用はない。

木由来P2+では各短い組の第一成分にbのみ（aの混入可）、第二成分にcのみ（aの混入可）、両者の非a出現を仮定する。元a部分木収率 `k_J`、短い組中のa総数 `α_J`、`δ_J=k_J−α_J`。単独語の正a連数は高々 `α_J+3`、総a数は `N−k_J+α_J`。`N−k_J≥4` ならONの余剰条件を満たす。種B,Cは別途、内部比較不能節点のため `k_B+k_C≤N−2` から同条件を得る。各個別ブロックの一穴合同を実際の二重置換語へ移し、aを右へ動かせる。

**限定：** 成分内部にbとcが混在する場合、片成分がaのみの場合、成分支持が異なる単位の橋渡しは未証明。許容小窓 `d_J≤(N−1)/(24θ²)` と短い組長≤θから `k_J≤d_J+θ` なので、追加の十分条件 `N≥(N−1)/(24θ²)+θ+4` は明示して保持する。
