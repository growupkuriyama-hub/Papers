## 1. 反例が満たすべき必要条件（証明済み。違反する設計は最初から捨てる）

- N1：二文字では全てのファンアウト f ≥ 2 で多項式（定理E）。全成分が全文字を含む型は多項式（`prop:full-content-types`）。→ 標的の型は文字の欠けた型で、三文字が要る。
- N2：μ_{ab} ≤ 3(r+1)vθ(q+2)（(153) 補題1）。q は、最短の ab 語 W の最小導出 T における c-強制の重い節点（短い代替の生成が全て c を含む節点）の反鎖の最大の幅。→ q が超多項式であることが必要。
- N3：(158) 定理6.2 の証明から、T の q 個の反鎖のうち q/5 個以上を短い生成に同時に置き換えた語が L に入り、q/5 個以上の c の極大連を持つ。→ c の連を超多項式個含む語が L に必要。
- N4：(155) 定理6.1：言語全体が、λ(a) = λ(b) > 0 となる非負の加法的な重みの一水準に入るなら μ_{ab} ≤ (r+1)θ²。→ そのような水準構造は不可。λ(a) ≠ λ(b) の重みや、加法的でない不変量は可。
- N5（スロット移送、(158) 補題4.1）：p^M ∈ L かつ p^iβp^j ∈ L で M ≥ i+j+1 なら、全ての 1 ≤ h ≤ i+j−1 で p^hβp^{i+j−h} ∈ L。→ 周期ブロックに入る逃げ道は、全ての内部の位置に入らなければならない。(149) の候補は n = 2 でこれに違反した。
- N6（近道の既知の型。どれかの前提が全て揃えば失格）
  - 型P（(153) 補題7）：W = lYY′r、lYβr ∈ L、lsβr ∈ L、cont(lY) = cont(ls)、|s| < |Y|。
  - 型PP（補題7′）：βUe, ββ, UZUZ, UZUe, sβ ∈ L、cont(β) = cont(Ue)、cont(UZU) = cont(sU)、|s| < |UZ| で、sUZ が強制される。(149)(150) の候補の n ≥ 3 での失格の原因。逃げ道が接頭でつながる設計はこれに当たる。
  - 型V（(158) 定理3.1）：ca^kb, ca^{2k}b, a^kba から、c を含まない文脈での位置のずれで ba が強制される。
  - 型R・型T：c の連の重なりと多段の連鎖。具体例だけで、一般形は未知（(158) 付録B の10件）。
- N7：一段ごとに逃げ道を一つ持つ CFG の倍増族 A_i → A_{i−1}A_{i−1} | e_i は、m = 3, 4 で調べた全ての設計（10件）で近道があった（(153)(155)(158)）。
- N8：命題5（トークンの障壁）。逃げ道を中身の見えない記号として扱う模型は代入可能になりうる。→ トークンの段階で閉じた模型を作り、それを実際の語に実現するときに近道を作らない、という設計は筋が通る。

注意：K = {abab, abc, cab, cc, ac} は C₁∩C₂ に入り、近道を持たない（(155)(158)）。「文字の一致らしきもの」があるだけでは失格にならない。失格の判定は必ず具体的な証明書で行うこと。

## 2. 課題：異なる設計原理による候補族を少なくとも二つ

### 設計 (a)：ファンアウト2の非終端で、スロット移送を最初から満たす
これまでの候補は全てファンアウト1の文法だった。二成分の非終端（例：(p^h, p^{n−h}) を全ての h で生成する非終端）を使い、N5 が要求する全ての位置への挿入を文法が初めから生成するように作れ。そのうえで N6 の各型と N3 を避けられるかを調べる。

### 設計 (b)：閉包を先に、文法を後に
言語 L_n を、文法ではなく構造的な性質 P_n（例：λ(a) ≠ λ(b) の重みの組、c の連の間の語に課す条件、有限の標識を持つ符号など）で定義する。(i) SUB₁・SUB₂ について閉じていることを P_n の上で証明し、(ii) μ_{ab} の下界を証明し、(iii) 最後に、L_n を生成する多項式の大きさで θ̄ の小さな文法を与える。閉じていること（(i)）と文法が小さいこと（(iii)）は別の条件なので、混同しないこと。

### 設計 (c)：自由
(a)(b) 以外の原理でもよい。例：トークンの段階で閉じた模型（N8）を、近道を作らない語で実現する。

### 各候補について報告すること

## 1. 背景：前回までに分かったこと

## 2. 道具：枠の同値（まず検証せよ）

**定義。** 枠とは組 (u,v) ∈ Σ*×Σ* のこと。その中身の集合を Z_L(u,v) = {z ∈ Σ⁺ : uzv ∈ L}、輪郭を π(u,v) = (cont(u), cont(v))（cont(ε) = ∅）とする。

## 1. 目的：定理 H の代数的な閉包

定理 H の言語は、準同型
ψ = (π_D, φ, cont) : Σ⁺ → B(D) × A × (2^Σ, ∪)
の逆像です。ここで π_D は D の経路の半群（経路でない語は零）への写像です。そこで、**この形の準同型で認識される言語全体**

L = ψ^{-1}(P)（P ⊆ ψ(Σ⁺) の任意の部分集合）

を考えます。各文字はまずちょうど一本の辺のままとし、余力があれば §3 で一般化します。

P が全く任意なら、L は代入可能とは限りません。例えば、言語 J の読み2（内容が {a,b} のときだけ長さが奇数、他の内容は長さ自由）は代入可能ではありません。E = □、x = a、y = aa、F = □ab で、aab ∈ L だが aaab ∉ L となるからです。**問いは、代入可能性がこのクラスの言語の形をどこまで縛るか、そしてその縛りの下で定理 H がクラス全体に延びるか、です。**
