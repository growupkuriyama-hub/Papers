## 2. 対象のクラス

### 2.1 主な対象：クラス 𝒦

Σ = Γ₁ ⊔ ⋯ ⊔ Γ_t を順序付きの空でない文字群とし、w が**段非減少**であることを、文字の段番号が非減少であることとします（全ての段を含むことは要求しない）。

A を可換群（無限でもよい）、Φ : ℤ^k → A を文字の値からの準同型とします。内容の族 𝓜 ⊆ 2^Σ∖{∅} の各 M について、部分群 H_M ≤ A と g_M ∈ A を与え、

  L = { w ∈ Σ⁺ : w は段非減少、cont(w) ∈ 𝓜、Φ(Ψ(w)) ∈ g_{cont(w)} + H_{cont(w)} }

とします。

- t = 1 は一頂点（パリク飽和）の場合で、受理するパリクの集合は内容ごとの剰余類の和になる。
- H_M が全て同じで t = 1 なら、定理 H の (16) の一頂点版。
- 内容が一つで H = 0 なら、定理 S のクラスに含まれる。

### 2.2 副次的な対象：一頂点の一般の場合

一頂点の一般の場合（L = π⁻¹(Q)、Q は (T) を満たす任意の集合）は §3 の課題3 で扱います。F₄・E₁ はクラス 𝒦 に入りません。

## 3. 課題

### 課題1：クラス 𝒦 の所属の特徴づけ

L ∈ C_{2,c_Σ}（SUB₁ と SUB₂）となる (𝓜, (g_M, H_M)) の条件を、必要十分の形で求めてください。
- 閉包報告の定理2.5（有限群：部分群は共通の文字が生成する部分群の上で一致する）が参考になります。
- 無限群で何が変わるか（例2.8 T_n の現象）を述べてください。
- 段（t ≥ 2）があると、内容の違う語どうしの移動がどう制限されるかも述べてください。
- 所属は、全ての arity について**手で**証明してください。有界な長さの検査で代用しないこと。

### 課題2（主）：全ての型の τ の上界

クラス 𝒦 の C_{2,c_Σ} の言語と、その任意の既約 good な表示 G（ファンアウト ≤ f、ランク ≤ r）について、

  τ(G, c_Σ) ≤ poly_{k,f,r}(θ)

（v に依らない形が望ましいが、poly(‖G‖, θ) でもよい）を示すか、どこで失敗するかを示してください。

定理 S の証明は二か所で「一つの値」を使っています。
1. **補題 S2(b)**：A の全ての生成組は、同じ短い文脈 E_A に入れると同じ群値を持つ。
2. **定理 S の戻し**：同じ格子剰余類の短い点は受理される。

内容ごとに値が変わると、A の生成組の内容が違えば値も違いえます。次の方向を検討してください。
- 型付き非終端 X = A_(M₁,…,M_d) ごとに、内容を保つ短い規則差分だけから格子 H_X を作る。
- 「同じ内容の面の中」の差分で、θ に有界な生成系が得られるか（SUB₁・SUB₂ を使ってよい）。
- 有限個の内容の面の間の整合条件（課題1 の答え）で、戻しを保証する。

**罠**：
- 型付きの積の文法の厚さに頼ると、あなたの前回の障壁 III に戻ります。型付き非終端の最短の**生成**は長くなりえます。必要なのは分布の代表です。
- 型付き非終端の短い文脈が、元の文法の短い文脈から作れるかを明記してください。

**成功したときの形**：「クラス 𝒦 の C_{2,c_Σ} の言語の任意の既約 good な表示で τ ≤ U(k,f,r,θ)」、従って特徴データは O(‖G‖·poly(θ))。

**失敗したときに欲しいもの**：短い規則差分では結び付かない具体的な二つの内容の面か、μ は短いのに τ の補完が失敗する具体例。所属の手の証明を付けること。

### 課題3（副）：一頂点の命題7.4 への応用

t = 1 で Q が (T) を満たす任意の集合（剰余類の和でなくてよい）のとき、補題 S2(c) の格子 H（短い規則差分が生成する）と条件 (T) を組み合わせて、μ_ab（あるいは τ）が抑えられるかを調べてください。

- 例：F₄ ∪ {P}、E₁ ∪ {(6,5)}、族 F_n。
- 狙いは次の形です。Q₂ の点 P は p_S + H に入る。(T) の移動（同じ支持の二点の差）で、p_S + H の中の短い ab の点が Q₂ に入ることを導けるか。
- 予想7.7・補題 C との関係も述べてください。
- 部分結果（特別な場合の証明、または「この方法では届かない」ことを示す具体例）で構いません。

### 課題4（失敗した場合の否定の向き）

課題2 が失敗する場合は、クラス 𝒦 の中で次を満たす族を構成してください。
