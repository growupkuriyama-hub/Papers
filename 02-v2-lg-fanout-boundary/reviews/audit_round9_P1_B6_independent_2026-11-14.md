## 1. P1 を成立させる核

原語の η 成分 φ_κ と射影 X∈{{a,c},{b,c}} を固定する。DFS 接頭反鎖 I_j の原位置和 U_j は U_j⊆U_j'。I_j に属する原語の相互に素な連続因子を **Σ 上で非空** な語で置換したものを ψ_κ^(j) とする。

ψ の射影窓が「純」であるとは、その二端点を結ぶ **Σ 上の閉区間** が挿入タグを一切含まないこととする。このとき純窓は、原 φ の射影窓で span∩U_j=∅ のものと型を保って一対一に対応する。

- 元窓の span が U_j を避ければ、原区間は置換から影響されず、その窓は純のまま。
- ψ の純窓に挿入タグがないなら、二端点間の原区間に削除した文字はない。もしあればその位置の置換因子が **非空の挿入語** を残し、ψ で純とはなれない。

従って N₂(π_Xψ^(j)) = Pure(j)+Imp(j) と分解できる。同色 col(j)=col(j') は Imp(j)=Imp(j') と ŝ₂ の一致を保証するため、

```
Z_{κ,X} = N₂(π_Xψ_κ^(j)) - N₂(π_Xψ_κ^(j'))
        = # {原 φ_κ の X-窓 : span∩U_j=∅, span∩U_j'≠∅} ≥ 0 .
```

ŝ₂ の一致から両端点が同じなので、∂Z=0。原 φ_κ 内部窓の端点は自由 η の印なし文字であり、これらは印付き原窓には含まれない。射影で空になる挿入片も span 判定は捕捉する。

全語 W_j の N₂ 差は各 κ の Z の和になる：非 η 片は固定、η 片の ŝ₂ は同色なので、境界を跨ぐ射影窓は一致する。両射影の同一 ψ について |π_Aψ|_c=|π_Bψ|_c を使い、各 κ ごとに c 入出次数差を保存。片側 Z が0なら他側の台は非共有文字の自己ループ（aa または bb）のみ。

## 2. B6 の計数形を成立させる核

段 (j_t,j'_t) はすべて **固定した原導出木** から先に選ぶ。同じ η について次段の j は前段 j' 以降、別 η は原位置集合が互いに素。各段で消す原窓 D_t は、(1)その区間の U_j' に交わり、(2)U_j を避け、(3)両端点が同じ η 成分にある、という条件で同定される。

同一 η の D_s, D_t は U の単調性により交差しない。異なる η でも窓の両端点が各別の自由部分木にあるので交差しない。どの窓も印なし。窓種 e の先頭 c_* 出現に印があるので、残る N_t(e) は

```
min(N_0(e),c_*) ≤ N_t(e) ≤ N_0(e).
```

Z が circulation だから入出次数収支・ŝ₂ は不変。c_*≥1 で元の各正辺数は正のままなので、元の射影歩道が持つ（弱）連結な辺台を保つ。Euler 歩道により残存する A, B の射影語が実現でき、各 κ の c 保存則と端点からそれぞれの c 個数が一致する。同じ c の発生点を合わせて両射影語をインターリーブすることにより、**各根成分の**実現語が存在する。これは語としての実現性であり、L に属することの証明ではない。

注意：表示用に作る新語 y^(t) は一般に原語と位置対応を持たない。印付き窓の **位置やその窓としての連続性** は保存されず、これを不変量にする証明は不可。原木から作る各段の F 側証人 W_j' と、Y 側で必要な計数下限を分けるのが正しい。
