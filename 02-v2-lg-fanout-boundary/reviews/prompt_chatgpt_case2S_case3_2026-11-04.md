## 1. 到達点（検証済み）

Σ = {a, b, c}、内容型付け c、L ∈ C_{2,c}、a^k ∈ L（k = μ_a(L) ≥ 5）。SB(F, d) は、s, t ≥ 1、s+t = k−d の全てで a^s F a^t ∈ L であること。

- **定理 II-B**：場合 II の分岐 (B) で μ_a ≤ max{4θ+12, K_B^{10} R^9 θ}。ここで E_B = v(50θ³+θ+23)、K_B = (2v+E_B)(2r+1)、R = θ+2v+2。

## 2. Claude の観察（確かめること）

場合 III では b⁴ が現れるので、補題 F′ を文字 b について使える。F′ の証明は x⁴ だけを使い、a に固有の性質は使わない、と Claude は読んでいる。これが正しければ、b の連を消して c の連をつなげられる。

**(O1) F′ の文字の置き換え。** `claude_straddle` §3.1 の補題 F′ と系 C の証明を、a → b に置き換えて読み直し、次を確かめる。
- 仮定（b⁴ の出現、「b の個数 ≥ b の極大連の数 + 1」、v が b で始まらないこと）で十分か。
- 証明のどこかで、μ_a、SB、あるいは場合 I に固有の性質を使っていないか。

**(O2) b-融合による排除。** 場合 III で、a を含まない塊 F が次の三つを満たすとする。
- SB(F², 2d) が成り立つ。
- F が c を二つ以上含む。
- F が bb を含むか、F の両端がともに b である。このとき F² は bb を含み、a^s F² a^t で「b の個数 ≥ b の連の数 + 1」が成り立つ。

このとき F′ を繰り返して c の間の b の連を消すと、c が四つ以上続く語が L に入る。これは場合 III に矛盾する。
- 例：F = bcccb なら F² = bcccb·bcccb → bb ccc ccc b。前報 §8 が残した b…cc…b は、これで消える。
- 計算による裏付け：`check_claude_case3_bfusion_2026-11-04.py`。種は a⁵、bbbb、a^s F^j a^t（j ≤ 2、損失 1、離れた二塊は使わない）。この種から、bcccb、bccb、bcbcb で c⁴ を含む語が強制された（3, 3, 9 段）。
- 対照：c が一つの塊 bcb、bbcbb では、3巡で c⁴ は出なかった（観察）。

**(O3) 残る塊と共通の根。** (KL)、前報 §8、(O2) を合わせると、場合 III の分岐 (B) の低い内部の塊として残るのは次の二種類である。
- (bc)^j と (cb)^j
- c を一つだけ含む塊 b^i c b^j

分岐 (B) では鎖 F_X F_Y も塊である。c が一つの塊を二つつないだ鎖は c を二つ含む。
- 鎖が bb を含むか、両端がともに b なら、(O2) で消える（鎖の二乗の SB が要る）。
- 鎖が cc を含むか、両端がともに c なら、(KL) または前報 §8 で消える。
- 残るのは、両端が違い bb も cc も含まない鎖、すなわち (bc)² か (cb)² だけである。

特に X = Y の鎖 F_X F_X も使えるなら、b^i c b^j のうち bc と cb 以外は F_X² が bb と c 二つを持つので消える。このとき全ての低い内部の塊は**一つの根 u ∈ {bc, cb} の冪**になる。そうなれば、前報 §5・§6 の d_X = φ j_X と定理 II-B が、場合 III の分岐 (B) でもそのまま成り立つはずである。確かめること：
- 鎖を塊として使うとき、どの冪まで SB が要るか。前報 §4 の予算で足りるか。
- X = Y（同じラベル）の鎖も使ってよいか。
- 使えない場合、c が一つの塊 b^i c b^j（例えば bcb）が根として残りうる。そのときも全ての塊が一つの根の冪 u^j になり、§5 の議論が使えるか。
- (R) と一色型の数え方（前報 §6.2）が場合 III でも成り立つか。
