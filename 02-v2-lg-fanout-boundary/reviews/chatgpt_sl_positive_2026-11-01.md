## 1. 正確な設定と使う既知結果

`m=|Σ|≥1` を固定する。`c=c_Σ:Σ^+→\mathcal P_+(Σ)` は内容集合を与え、積は和集合。`L∈\mathcal C^{\mathrm{mcf}}_{2,c}`、`G` は `L∩Σ^+` の reduced good、fan-out ≤2、rank ≤`r=r_max` 表示である。`g=\lVert G\rVert`、`v=|V|≤g`、`θ=\bar\theta_G≥1` とする。`\Pi(w)=(|w|_a)_{a∈Σ}`、`\mathcal P=\Pi(L∩Σ^+)` と書く。

原稿 `lem:thickness-equivalence` の (i)、(ii)、(iv) により、各規則の直接の終端数は `≤θ`、各非終端 `B` は `\lVert\omega_B\rVert_1≤θ` の生成組を持ち、各 `A` に固定部分 `≤θ` の**許容**導出文脈 `E_A` が存在し `E_A[L_A(G)]⊆L` を満たす。ファンアウト2の二穴の間の区切りは非空である。

`lem:typed-homogeneity` および退避 `lem:app-u1-fillers` の証明は、型付けが `U₁` であることを用いない。従って任意の型付き非終端 `X=A_{\mathbf S}`（`\mathbf S=(S_1,\ldots,S_d)`、`d≤2`）について

\[
\boxed{\quad\tau_X=\min\{\lVert\mathbf z\rVert_1:\ c(z_i)=S_i\ (1≤i≤d),\ E_A[\mathbf z]∈L\}.\quad} \tag{1.1}
\]

理由：`L_X` の生成組と `E_A` を共有する同型の任意の組は、代入可能性によって分布を共有する。逆向きは `E_A` における受理から直ちに従う。**短い同値代表は文法 `G` の生成組とは限らない**点が重要である。

原稿 `cor:distribution-representatives` より、`τ=\max_X\tau_X` が抑えられれば、**同じ一つの**特徴標本 `K` が `\mathcal B^{≤r}_{2,c}` と `\mathcal B_{2,c}` の両方に使え、

\[
\lVert K\rVert_+≤N_{\rm typ}(1+2θ+rτ)+\mathbf 1_{\{\varepsilon∈L\}},\qquad
N_{\rm typ}≤|\mathcal P_+(Σ)^\sharp|^{2r}g=2^{2mr}g. \tag{1.2}
\]

この `\sharp` は空語を区別する fresh identity を加えるため、**二文字内容型では `|S^\sharp|=4` であり `U₁` の `3` ではない**。以下の上界は固定した `Σ` と `r_max` の下で一様で、`L`・`G` に依存する定数を隠さない。`\varepsilon` の寄与は最後の `+1` のみ。

## 2. 任意の有限アルファベットの浅い場合

### 定義（内容 `S` に相対的な深い挿入）

`\varnothing\ne S\subsetneq Σ`、整数 `h≥1` に対し、`L` が **`(S,h)`-深い挿入**を持つとは、ある受理語が因子 `xzy` を含み、`x,y∈S^h`、`z∈Σ^+`、`c(z)\not\subseteq S` となることをいう。`z` 自体が `S` の文字を含んでも構わない。`S={a}` では `a^h z a^h`、`z` に非 `a` 文字、という通常の形になる。

### 定理2.1（内容ごとの浅さに基づく短縮）【証明済み】

型付き非終端 `X=A_{(S_1,\ldots,S_d)}` を固定する。各 `S_i\subsetneq Σ` について `L` に `(S_i,h)`-深い挿入がなければ、

\[
\tau_X≤d(2h+m)(2^m-1)^2(r+1)vθ
≤2(2h+m)(2^m-1)^2(r+1)vθ. \tag{2.1}
\]

`S_i=Σ` に対しては仮定は不要である。従って、**あらゆる非空真部分集合** `S⊂Σ` について `(S,h)`-深い挿入がないなら、`τ(G,c)` に (2.1) の右辺が成り立つ。

**証明。** `X` からの型付き導出のうち節点数最小の木 `T` を取る。同じ型付き非終端が一つのパス上で反復すれば、上を下に差し替えると、型の結合則・線形非削除性により根型を保ったまま節点を減らせる。成分の型は非空内容集合であり、型付き非終端ラベルの総数は高々 `(2^m−1)^2v`。従ってパス上の節点は高々この数である。

根の成分 `u_i` で次の文字位置に印を付ける：(a) 先頭および末尾の `min(h,|u_i|)` 文字、(b) `S_i` の各文字種についてその出現を一箇所。印は全体で高々 `d(2h+m)` 個。印を書いた節点への根からのパスの和集合を `H` とすれば

\[|H|≤d(2h+m)(2^m-1)^2v.\]

`H` の外側へ伸びる部分木を、同じ**非終端記号** `B` の短い生成組 `\omega_B` に一つずつ差し替える。これは型付き木としては認められない場合があるが、型を消した文法 `G` では常に正しい導出であり、各中間生成組を `E_A` に挿した語は `L` に入る。

各根成分の `S_i` の文字種は、印によってすべて残る。仮に `S_i⊊Σ` の成分に新たに `Σ\setminus S_i` の文字が入ったとする。元の成分の長さが `≤2h` なら全位置を印したため、外側部分木に変更可能な正長ブロックは存在しない。元の長さが `>2h` なら、変更ブロックは保存された先頭 `h` 文字と末尾 `h` 文字の間にある。その中の `Σ\setminus S_i` の文字を含む因子は、受理語 `E_A[\mathbf u']` に `(S_i,h)`-深い挿入を作り、仮定に反する。`S_i=Σ` では新しい文字が増えても内容は変わらない。従って最終組の成分内容はすべて `S_i` であり、型付き根を代表する。

`H` の各節点が直接書く文字は `≤θ`、そこから省略した子は高々 `r` 個でそれぞれ `≤θ` 文字。よって最終組の総長は `(r+1)θ|H|` 以下となる。最終組は `L_X` にさえ属し、(1.1) の同値代表の候補にもなる。□

### 系2.2（二文字内容型の浅い場合）【証明済み】

`Σ={a,b}`、`h=6` とする。`L` が `a^6 z a^6`（`z` に `b`）も `b^6 z b^6`（`z` に `a`）も含まなければ、

\[
\tau(G,c_{\{a,b\}})≤252(r+1)vθ,\tag{2.2}
\]
\[
\lVert K\rVert_+≤4^{2r}g\{1+2θ+252r(r+1)gθ\}+\mathbf1_{\{\varepsilon∈L\}}.
\tag{2.3}
\]

これは `O_r(g^2θ)` である。原稿 `lem:app-u1-shallow` と比較すると、**純型 `{a}` だけでなく `{b}` にも両端の印と禁止挿入を適用し、混合型 `{a,b}` には両文字の存在印を加える**ことが変更点である。ここでは Parikh 飽和も交換則も使用していない。

**補足（局所的適用）**：`a`-深い挿入が存在しても、根の成分型に `{a}` が一つもなければ、その `X` については (2.1) が使える。`b` 側も対称である。さらに全成分の型が `Σ` なら仮定は一切不要である。

## 3. 二文字 Parikh 飽和の場合

ここで `Σ={a,b}` とし、`L` が **Parikh 飽和**、すなわち `\Pi(u)=\Pi(v)` なら `u∈L⇔v∈L` を満たすとする。以下では `L∈\mathcal C_{2,c}` の仮定も保持する。

### 補題3.1（全文字が要求される組の一般的な計数）【証明済み】

この補題は一般の `Σ` について述べる。`X=A_{(S_1,\ldots,S_d)}` で `S_1\cup\cdots\cup S_d=Σ` とする。各文字 `a∈Σ` が現れる成分数を `t_a=|\{i:a∈S_i\}|` とする。従って `1≤t_a≤d≤2`。`p_a=|E_A|_a` と置くと、Parikh 飽和性と (1.1) により

\[
\tau_X=\min\left\{\sum_a n_a:\ (p_a+n_a)_a∈\mathcal P,\quad n_a≥t_a\text{ for all }a\right\}.\tag{3.1}
\]

**実現可能性の理由**：`n_a≥t_a` なら各成分にその内容で要求される文字を一つずつ配り、余りを任意のその文字を要する成分に入れればよい。得られた `E_A[\mathbf z]` は元の受理 Parikh ベクトルを持つので受理される。

(3.1) を実現するベクトル `\mathbf n` を選び、`\mathbf p+\mathbf n` の任意の順序の語 `W` の**節点数最小**の `G` 導出木 `T` を選ぶ。Parikh 飽和なので `W∈L`。`c_a=n_a-t_a+1≥1`、`H_*=\sum_a(p_a+t_a)≤θ+2m` と置く。節点 `u` の出力の Parikh ベクトルを `\mathbf q_u`、総長を `\ell_u` と呼び、`\ell_u>θ` の節点を重いとする。

重い節点 `u` で全座標 `q_{u,a}<c_a` なら、その部分木を同じ非終端の `\omega_B`（総長 `≤θ`）に置き換える。語長は厳密に短くなり、各文字の新しい個数は `p_a+n_a-q_{u,a}+|\omega_B|_a≥p_a+t_a`。これにより (3.1) に反する。ゆえに**重い節点は少なくとも一座標 `q_{u,a}≥c_a` を持つ**。

さらに、同じ非終端を持つ祖先 `u` と真の子孫 `u'` の Parikh 差 `\mathbf q_u-\mathbf q_{u'}` が全座標で `0≤q_{u,a}-q_{u',a}<c_a` なら、上を下で置き換えて短い受理語を作れる。差が零のときには退避 `lem:app-u1-identity`（good・線形・非削除・非置換・非併合）により全規則が実質的な恒等鎖となり、同じ語をより少ない節点で導出できる。どちらも矛盾する。

根から葉への経路上で `\bigl(\lfloor q_{u,a}/c_a\rfloor\bigr)_{a∈Σ}` は座標ごとに非増加。同じ商ベクトル内に同じ非終端は反復しない。商ベクトルの異なる値の総数は高々

\[
1+\sum_a\left\lfloor{p_a+n_a\over c_a}\right\rfloor
≤1+\sum_a(p_a+t_a)≤H_*+1.
\]

従って経路長は `≤v(H_*+1)`。同一深さの重い節点の出力は互いに文字位置が交わらないので、その数は上記の「少なくとも一座標 `≥c_a`」により `≤H_*`。重い節点は祖先について閉じるので総数は `≤vH_*(H_*+1)`。語の各文字は重い節点に直接書かれたものか、その軽い子の出力に属するため、

\[
\boxed{\tau_X≤\max\{θ,(r+1)vθ(θ+2m)(θ+2m+1)\}.}\tag{3.2}
\]

これで補題を得た。□

**特に二文字の場合**、成分型の合併が `{a,b}` なら `t_a,t_b≥1` であり、`\tau_X≤30(r+1)vθ^3`。従って `{a},{b}`、`{a},{a,b}`、`{a,b},{a,b}` 等を、配置を問わず一括処理できる。これが退避 `lem:app-u1-parikh` の「mixed type」を内容型に拡張する箇所である。

### 補題3.2（すべての成分が `{a}`、またはすべて `{b}`）【証明済み：純型部分の再監査】

`X` の全成分型を `{a}` とする（`{b}` の場合は対称）。成分数を `h∈\{1,2\}`、`(p,q)=\Pi(E_A)`、`K=\min\{k≥h:(p+k,q)∈\mathcal P\}` と置く。このとき `τ_X=K`。**退避 `lem:app-u1-parikh` の「Type 1 only」の (P1)–(P6) は、`U₁` の粗い型の比較を使っていない。使う代入可能性は `a` と `a^{1+δ}` が同型であるという arity 1 の比較だけである。内容型でもともに `{a}` なので、以下の通り再利用できる。**

`K≤p+θ+2` なら `τ_X=O(θ)`。さもなくば `K>p+2` として、`W=b^q a^{p+K}∈L` の節点数最小導出を選ぶ。

1. **行剛性 (P1)**：同じ `b` 個数 `y` において、正の `a` 個数 `c_0,c_0+δ`（`1≤δ≤K-h`）の二受理 Parikh ベクトルは存在しない。そうなら共通文脈 `b^y a^{c_0-1}\square` により `\mathcal D_L(a)=\mathcal D_L(a^{1+δ})`。これを `b^q a^{p+K-δ-1}\square` に適用すると `K-δ≥h` のより短い (1.1) の代表を作る。
2. **高さ (P2)**：一パス上の同じ非終端を持つ祖先・子孫で `b` 個数が同じなら、その `a` 個数の差は少なくとも `K-h+1`。差0は `lem:app-u1-identity` で除外し、`1≤差≤K-h` は (P1) で除外する。`K>p+2` により、同じ非終端・同じ `b` 個数の出現は一パスで二回まで。従ってパス長 `≤2v(q+1)`。`b` を含む節点は `q` 個の `b` を書く節点へのパス上にあり、総数 `M≤2vq(q+1)≤4vθ^2`。
3. **重い純節点 (P3)**：`b` を含まず総長 `\ell_u>θ+1` の節点を重い純節点と呼び、`g_u=\ell_u-|\omega_{B_u}|_a≥2` とする。同じ非終端の重い純節点は祖先・子孫になれない（(P2) と `\ell_u≤p+K` に矛盾）。反鎖 `J` を一括短縮すると `a` は `σ(J)=\sum_{u∈J}g_u` だけ減り、`b` は `Y(J)=\sum_{u∈J}|\omega_{B_u}|_b` だけ増す。(P1) から、`σ(J),σ(J')≤K-h` かつ `Y(J)=Y(J')` なら `σ(J)=σ(J')`。
4. **反復ラベルと比率 (P4)**：同じ `B` の重い純節点が二個以上なら互いに非比較で、それぞれ `\ell_u≤K-2`、従って `g_u≤K-h`。上の反鎖比較で共通の `g_B,\ell_B` が定まり、`y_B=|\omega_B|_b≥1`（零なら一回短縮して `K` の最小性に反する）。出現数 `m_B>θ` のラベルを frequent と呼ぶ。二つの frequent な `B,C` について、`y_C` 個の `B` 節点と `y_B` 個の `C` 節点をそれぞれ短縮すると、`b` 増分が等しく、かつ `a` 減分は `≤K-h`。よって `y_Cg_B=y_Bg_C`、従って全 frequent ラベルで `g_B/y_B=α` が共通となる。
5. **比率の上界 (P5)**：`α_*=(r+1)(θ+1)(2θ+1)v≤6(r+1)vθ^2` とすると `α≤α_*`。`α≤θ` は直ちに成立。`α>θ` の場合、frequent ラベルの重い純節点 `u` 以下で、重い純節点の祖先鎖は同じ非終端を繰り返さないので長さ `≤v`。同じ深さの frequent 節点はそれぞれ長さ `≥α` で、`u` の長さは `\ell_B=|\omega_B|_a+α y_B≤(1+α)θ`、よって各層 `≤θ+1` 個。非 frequent な重い純節点は木全体で `≤vθ` 個。したがって `u` 以下の重い純節点は `≤v(2θ+1)` 個。直接書く文字と軽い子の文字を数え、`α≤g_B≤\ell_B≤(r+1)(θ+1)v(2θ+1)=α_*` を得る。
6. **総数 (P6)**：純節点で `\ell_u>(α_*+1)θ=:T_*≤7(r+1)vθ^3` のものを large とする。frequent ラベルは large に現れないので large は高々 `vθ` 個。`b` を含む節点 `≤M` 個と large 節点、それらの直下にある長さ `≤T_*` の純部分木で `W` を覆うと

\[
 p+K≤θM+(rM+rvθ+1)T_*+vθ^2
 ≤\bigl(42r(r+1)+5\bigr)v^2θ^5.\tag{3.3}
\]

`p≥0` なので `τ_X=K` も右辺以下である。この証明で「同じ `B` から生成した組を文法的に差し替える」操作に型一致を仮定していない点は重要：新しい語の**所属**は `G` の導出によって保証し、代入可能性を使うのは (P1) の純 `a` 交換だけである。`c_Σ` への移植に問題はない。□

### 定理3.3（二文字 Parikh 飽和の多項式特徴データ）【証明済み】

`r≥2` を固定する。`L∈\mathcal C_{2,c_{\{a,b\}}}` が Parikh 飽和なら、任意の指定された reduced good 表示 `G` に対して

\[
\boxed{\tau(G,c_{\{a,b\}})≤C_r v^2θ^5,\quad C_r:=42r(r+1)+50(r+1).}\tag{3.4}
\]

従って `\mathcal B^{≤r}_{2,c_{\{a,b\}}}` **と** `\mathcal B_{2,c_{\{a,b\}}}` の共通特徴標本があり、

\[
\boxed{\lVert K\rVert_+≤4^{2r}(3+rC_r)g^3θ^5+\mathbf1_{\{\varepsilon∈L\}}.}\tag{3.5}
\]

**証明。** 任意の `X` の根成分型の合併が `{a,b}` なら補題3.1より `τ_X≤30(r+1)vθ^3`。そうでなければすべての成分型が `{a}`、またはすべて `{b}` なので補題3.2により (3.3)。`v,θ≥1` と `r≥2` により (3.4) が両方を支配する。(1.2) と `v≤g` から (3.5)。`1+2θ≤3g^2θ^5` を用いた。□

**限界**：この定理は「Parikh 飽和なら二文字内容型の全表示に上界」を述べるが、「任意の `(2,c)` 言語が Parikh 飽和」とは述べない。`U₁` の全証明を完成したことにもならない。

### 補題4.1（単一異文字の橋がある場合の Parikh 飽和）【証明済み】

`L∈\mathcal C_{2,c_{\{a,b\}}}` とする。`a^6ba^6` または `b^6ab^6` がある受理語の因子なら `L` は Parikh 飽和である。

**証明。** `a^6ba^6` の場合、受理語に `a^6` がある。`lem:app-u1-transfer(i)` の証明で、同じ `a` の正長二組 `(a^i,a^j)` の内容が `{a},{a}` と一致することは、内容型でもそのまま成立する。`i+j=3` の二組 `(a^2,a)` と `(a,a^2)` の移送により、適切な両側文脈で `aaba` と `abaa` を作る（周囲の `a` の長い部分は固定する）。これらを `a·(ab)·a` と `a·(ba)·a` と見ると、一穴の共通文脈で同じ内容 `{a,b}` の `ab,ba` が受理される。よって `\mathcal D_L(ab)=\mathcal D_L(ba)`。すべての語の隣接 `ab↔ba` を交換でき、同一 Parikh の語が連結する。`b^6ab^6` は対称。□

### 定理4.2（深い挿入は Parikh 飽和を含意しない）【反例、証明済み】

`Σ={a,b}`、
\[
L_\bullet:=a^*bb a^*.
\]

この言語は正則なので `2`-MCFL であり、**あらゆる arity `d≥1` について** `c_Σ`-組代入可能である。一方 `a^6bb a^6∈L_\bullet` なので `a`-深い挿入を持ち、Parikh 飽和ではない（`bb a` と `b a b` は同じ Parikh ベクトルだが後者は属さない）。

**代入可能性の証明。** 許容 `d`-穴文脈 `E` と同じ成分内容の二組 `\mathbf x,\mathbf y` が `E[\mathbf x],E[\mathbf y]∈L_\bullet` を満たすとする。`E` の固定部分にある `b` の数を `j` とすると、`\mathbf x` および `\mathbf y` の全成分中の `b` の数はともに `2-j`。`j=0,1,2` に分ける。

- `j=2`：全穴成分は `a^+`。`b` が連続するかどうかは、穴に挿入した**正長**の `a` の有無・位置で決まり、その長さには依存しない。従ってどの別文脈 `F` でも `F[\mathbf x]` と `F[\mathbf y]` の所属は一致する。
- `j=1`：両組で `b` を含む穴成分はちょうど一つ、かつ同じ添字 `i`（成分ごとの内容が同じため）。その成分はそれぞれ `a^u b a^v` の形であり、残りは `a^+`。`E` の唯一の固定 `b` と連結できるよう、両者の `b` が固定 `b` 側の端に露出していなければならない。`S_i={b}` なら両者は語 `b`、`S_i={a,b}` なら両者は同じ側にしか `b` を露出しない（その反対側には必ず `a` がある）。従って任意の別文脈 `F` における二つの `b` の隣接可否は `\mathbf x,\mathbf y` で等しい。
- `j=0`：二つの `b` が別々の穴成分にあれば、その間には必ず非空の固定区切り（全て `a`）があり、`E` は受理できない。従って両組とも同じ一つの穴成分が `bb` を含む。`E` が受理する以上、どちらの成分も `a^u bb a^v` の形で、残りの穴成分は `a^+`。任意の `F` で新しい固定 `b` があれば全体の `b` が二個を超えて両方不受理、なければ二つの `b` が連続して両方受理する。

どの場合も `F[\mathbf x]∈L_\bullet⇔F[\mathbf y]∈L_\bullet`。従って任意の `d` で代入可能。□

**意味**：内容型が細かいことは `U₁` の深い挿入の交換論法を**易しくするのではなく、実際に禁止する**。もちろん本反例は短い代表を持つ正則言語であり、多項式上界への反例ではない。

## 5. 三文字以上：伸びる部分と伸びない部分

### 定理5.1（Parikh 飽和・全内容被覆型の一様上界）【証明済み】

`Σ` は任意の固定有限アルファベット、`L∈\mathcal C_{2,c_Σ}` は Parikh 飽和とする。成分型の合併が `Σ` となる任意の `X` に (3.2) が成立する。特に、**そのような `X` だけが実現する表示 `G`** については

\[
\tau(G,c_Σ)≤(r+1)vθ(θ+2m)(θ+2m+1),\tag{5.1}
\]
\[
\lVert K\rVert_+≤2^{2mr}g\bigl[1+2θ+r(r+1)gθ(θ+2m)(θ+2m+1)\bigr]
+\mathbf1_{\{\varepsilon∈L\}}.\tag{5.2}
\]

したがって `O_{Σ,r}(g^2θ^3)`。**注意**：全型付き非終端がこの条件を満たすという仮定は強く、一般の文法では字句規則などにより失敗する。特別な場合の条件付き定理であって、一般の Parikh 飽和な `Σ` への無条件拡張ではない。なお**全成分の内容が個別に `Σ`** なら、定理2.1の印の証明だけで Parikh 飽和仮定なしに `O_{Σ,r}(g^2θ)` の特徴標本を得る。

**証明。** (5.1) は補題3.1を全 `X` に適用したもの。(5.2) は (1.2) に代入したもの。□

### 多文字の純型の本質的差

`S={a,b}⊂{a,b,c}` を純型と見ると、`c_Σ` の型 `{a,b}` は必ず `a,b` の双方を含む語に限定される。`U₁` の三文字型付け `s(a)=s(b)=1,s(c)=ζ` では `a^N` も `ab` も同じ純型 `1` だった。この点は**内容型の方が易しい**：`a^N` を `{a,b}` 代表の候補とする必要はなく、`a,b` を一個ずつ印すだけで「要求文字の消失」は防げる。

しかし新たな問題もある。`ab...ab` のような `S`-純成分を任意に縮めたとき、短い非終端生成組が **`c` を内部へ挿入**すると、型 `{a,b}` から `{a,b,c}` へ移る。両端を `S` の文字で守っても、`(S,h)`-深い挿入のある対象では矛盾を得られない。逆に `c` 入りの成分では `{a,c}` と `{a,b,c}` を区別するため、粗い `U₁` 型の交換で許された二組は内容型では同型でなくなる。

従って Astra の「純成分の内部に入った `c` の修復」は、**要求文字の保持は容易になる一方、侵入した禁止文字を交換・削除する操作はより難しくなる**、という非対称な状態である。`S` が二文字以上のとき、同じ `S` 内での長い run がなくても純成分は長くなり得るので、`a^6` に依存する証明を文字の置換だけで拡張できない。

### 補題5.2（文字対ごとの交換の十分条件）【証明済み】

任意の `Σ`、`L∈\mathcal C_{2,c_Σ}`、相異なる文字 `a,b` について、`a^6ba^6` を因子に持つ受理語があれば、**どの文脈でも** `ab` と `ba` を交換して所属が変わらない。他の文字が周囲にあってもよい。従って、全ての異なる文字対にこのような橋が存在すれば、`L` は Parikh 飽和である。

**証明。** 補題4.1の移送は `a,b` に関する局所操作で、外側の固定語に別文字があっても成立する。`c_Σ(ab)=c_Σ(ba)={a,b}` は不変。すべての文字対について分布が等しければ、任意の隣接転置を繰り返して同じ Parikh ベクトルの全語を得る。□

これは**構造的な飽和の十分条件**であり、一般 `Σ` で Parikh 飽和から短い代表が得られるとの主張とは別である。

## 7. 反例族への設計仕様（もし肯定証明が失敗するなら）

P1 を否定する候補族 `L_n∈\mathcal C_{2,c_{\{a,b\}}}` と reduced good `G_n` が必要なら、次の**全条件**を同時に設計・証明する必要がある。

1. 固定 `Σ={a,b}`、固定 `r≥2`、`g_n,θ_n=n^{O(1)}` とする。実現内容型 `S_n∈\{\{a\},\{b\},\{a,b\}\}` に `\mu^\star(L_n,c) = n^{\omega(1)}` が必要（下界の**十分条件**。上界否定の必要条件だとは断定しない）。二文字の Parikh 飽和なら定理3.3と衝突する。
2. 浅さの定理を逃れるため、少なくとも一方の純型に対応する**長い両側純フランクを持つ深い挿入**がある。にもかかわらず、`a^6 b a^6` または `b^6 a b^6` のような**単独異文字の橋**を避ける（存在すれば Parikh 飽和になり (3.5)）。単純な `bb` の厚い塊は局所交換を避けられるが、それだけでは稀な型の下界にならない（定理4.2）。
3. 型 `\{a,b\}` の `ab` と `ba` は同型なので、共通文脈を持つなら**全**文脈で交換できる。その共通錨を作らずに長い稀型を保つか、交換閉包を受け入れても短い稀型へ漏れないよう、複数の Parikh 切片を調整する。
4. 同一語の異なる二穴切り直し、二穴間の非空区切り、混合側の異 Parikh 交換と純側への漏れ、`power-transfer` のすべてを生き延びること。`Σ` を `n` とともに増やす、標識文字を段数ごとに増やす設計は固定型付けの反例にならない。
5. 有限族を使う場合、先行の長さスペクトル定理から、指数的な稀型長を狙うなら異なる受理語長も指数個必要になる。少数の巨大な語だけからなる族では足りない。

[`README.md`](https://github.com/growupkuriyama-hub/Papers/blob/main/02-v2-lg-fanout-boundary/README.md) に記録された DeepSeek 中間報告の評価では、1296通りの浅い倍増構成が `n=3` で**複数語を含むものとして**残らず、失敗の多くが切り直しだったとされる。ただし指定の `reviews/deepseek_sl_fanout2_search_2026-11-01_interim.md` 本体は今回 GitHub の既定ブランチから **404 で取得できなかった**ので、本文の証人分類の独立照合はできていない。加えて同 README は「singleton language は任意 fan-out で代入可能」という中間報告内の主張を**誤り**と明記している。`n=3` の計算を一般定理として採用しない。

定理4.2 の代入可能性を **arity 1,2、受理語長 `≤12`** の範囲で独立に照合するための全スクリプトを示す。Python 3 の**標準ライブラリのみ**を用い、Windows の `py -3 script.py` で実行できる。コードは、この長さまでの受理語をすべて列挙し、共通の受理文脈に置かれる同内容の二組が、探索で現れた別の受理文脈において異なる所属を示すか検査する。`PASS` は有限範囲の観察であって、任意長の証明ではない。

```python
# script.py -- Python 3 standard library only
from collections import defaultdict

MAX_LENGTH = 12


def in_language(word):
    return word.count("b") == 2 and "bb" in word


def accepted_words():
    for length in range(2, MAX_LENGTH + 1):
        for left in range(length - 1):
            yield "a" * left + "bb" + "a" * (length - 2 - left)


def content(word):
    return "".join(sorted(set(word)))


def fill(context, pieces):
    return "".join(context[i] + pieces[i]
                   for i in range(len(pieces))) + context[-1]


def check():
    buckets = defaultdict(set)
    for word in accepted_words():
        n = len(word)
        for i in range(n):
            for j in range(i + 1, n + 1):
                pieces = (word[i:j],)
                context = (word[:i], word[j:])
                buckets[((1, (content(pieces[0]),)), context)].add(pieces)
        for i in range(n):
            for j in range(i + 1, n):
                for k in range(j + 1, n):
                    for ell in range(k + 1, n + 1):
                        pieces = (word[i:j], word[k:ell])
                        context = (word[:i], word[j:k], word[ell:])
                        key = (2, tuple(content(x) for x in pieces))
                        buckets[(key, context)].add(pieces)

    neighbors = defaultdict(set)
    accepted = defaultdict(set)
    for (key, context), alternatives in buckets.items():
        for pieces in alternatives:
            node = (key, pieces)
            neighbors[node].update((key, x) for x in alternatives)
            accepted[node].add(context)

    for (key, x), group in neighbors.items():
        for _, y in group:
            # Any discrepancy must have a context that accepts
            # at least one of the two tuples.
            contexts = accepted[(key, x)] | accepted[(key, y)]
            for context in contexts:
                a = fill(context, x)
                b = fill(context, y)
                if in_language(a) != in_language(b):
                    print("FAIL", key, x, y, context, a, b)
                    return False
    print("PASS: no witness among accepted words of length <=", MAX_LENGTH)
    print("Observed tuple/context buckets:", len(buckets))
    return True


if __name__ == "__main__":
    raise SystemExit(0 if check() else 1)
```

**検査の位置づけ**：無限の全 arity の主張は定理4.2の文章による証明に依存する。探索範囲内で見つからないことを一般の証明や未解決問題の解決と取り違えない。
