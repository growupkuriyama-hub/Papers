# 依頼：`op:S1`（二文字・ファンアウト1・型付け s_{U,2}）——置き場所の計算から多項式上界へ

（2026-11-08 夜。Astra 向け。報告書名：`astra_S1_placement_2026-11-08.md`（＋必要なら `.py`）。冒頭に判定表を置くこと。この依頼文だけで読めるように書いてある。リポジトリ `growupkuriyama-hub/Papers` の `02-v2-lg-fanout-boundary/reviews/` を参照してよい。特に `claude_sU2_placement_calculus_2026-11-08.md`、`astra_S1_positive_2026-11-08.md`（前回のあなたの報告）、`STATUS_S1_two_letter_fanout1_2026-11-08.md`。）

## 1. 問題（前回と同じ）

Σ = {a, b}。型付け s_{U,2}：純な a の語は型 1、b を含む語は全て型 ζ。C₁ = C_{1,s_{U,2}}：同じ型の空でない語 x, y が言語 L の中で一つの文脈を共有すれば分布が等しい。G は L∩Σ⁺ の reduced・ε なし・ランク ≤ r の CFG、θ = θ̄_G（規則の厚さ）。a^N は L の最短の純な語、T はその節点数最小の導出、生成語の長さが θ を超える節点を重いと呼び、重いラベル B の長さ ≤ θ の b を含む生成語を ω_B と書く。b を含む語 z について P(z) := {(x, y) ∈ ℕ² : a^x z a^y ∈ L}。

**問い**：N ≤ poly(‖G‖, θ, r) か。肯定なら「U₁ 型付けは二文字では全ファンアウトで多項式、三文字ではファンアウト1で指数」という字母の境界、否定なら同じ型付けでファンアウトが境界を動かす分離定理になる（ファンアウト ≥ 2 の多項式は論文の二文字の定理で証明済み）。

## 2. これまでに分かったこと（主なもの）

- 群の原像は多項式（定理G、あなたが独立に検証済み）。加法的な重みの水準は N ≤ (r+1)θ²（あなたの定理A）。消去的モノイドの原像は、像が群なら不可、一関係子・Adian 非循環の二文字表示も不可。
- 有限の L では、置き場所の集合は抜けのない等差列（あなたの定理1）。T で反復する重いラベルの置き場所は対角線 x + y = N − n_B の上（系3）。全ての重いラベルが b を一つだけ含む短い生成語を持てば N ≤ (r+2)|V|θ（あなたの定理4）。重みの違う置き場所は矛盾ではない（{aaa, aab, ba, bb} ∈ C₁）。
- **Claude の新しい結果（未検証）**：
  - **補題PC（置き場所の計算）**：T の節点 B の部分木の中に節点 X があり、B の生成語の中で X の左に純な a が L 個、右に R 個あるとき、P(ω_X) ∩ {x ≥ L, y ≥ R} = P(ω_B) + (L, R)。（B の b を含む生成語は全て B の成功文脈を共有して ≡。有限性不要。）有限なら P(ω_S) = {(0,0)}。
  - **命題DD（二重化の鎖）**：有限の L で T が二重化の鎖 E_j → E_{j−1}E_{j−1}（2 ≤ j ≤ n、E_1..E_n が b 語を生成）を持つなら、各 ω_j（j < n）は対角線上の全ての偶数の位置に置ける。従って a²ω_j ≡ ω_ja²。
  - **予想（二重化の場合）**：ω_n の ≡ 類は、価値（a = 1、ω_j = 2^j）の合計が N の符号列（順序も自由、偶奇の条件つき）を全て含み、定理M 型の計数（各非終端は型ごとに一つの類しか持たないので、中間の部分木の類の数で文法の大きさを下から抑える）で文法の大きさが 2^{Ω(n)}。
  - **核の価値**：ω_B = a^{u_B} β_B a^{v_B}（β_B は最初の b から最後の b まで）。置き場所が対角線なら価値 w(β) = n_B − u_B − v_B は核の語だけで決まり、合成の核で加法的（w(β_C a^g β_D) = w(β_C) + g + w(β_D)）。反例には「短い核の価値が指数的に増え、分解が矛盾なく読める重み付きの符号」が要る。

## 3. 依頼

**課題1（検証）.** 補題PC、系 P(ω_S) = {(0,0)}、命題DD の証明を検証する（`claude_sU2_placement_calculus_2026-11-08.md`）。特に命題DD の強制の帰納法（「x が 2^k の倍数の点が全て入れば、上の段へ移して戻すと 2^{k−1} の倍数の点が全て入る」）を正確に書き直し、全ての P_j が対角線上にあることの根拠（定理1・系2 の使い方）を確かめる。E_1 が b 語を持たない場合（刻みが 4 になるか）も。

**課題2（本命：二重化の鎖での二択の定理）.** 有限の L ∈ C₁ が二重化の鎖を持つ T（ラベル E_0..E_n、E_0 → a、E_j → E_{j−1}E_{j−1}、各 E_j（j ≥ 1）が b 語を生成）を持つとき、次のどちらかを証明する：
- (a) **文法の大きさの下界**：‖G‖ ≥ 2^{cn}/poly(n, θ)（または θ ≥ 2^{cn}/poly）。予想の道筋：命題DD と C.0（同じ型の生成語の置き換え）で、L が「価値 N の符号列」の大きな族 F を含むことを示し、定理M の計数補題（`claude_problemG_mixing_2026-11-08.md` §2 P4 を型付きに直したもの：|F| ≤ 2|V′|(m+1)²K、K は固定した区間・固定した ≡ 類に入る中間の因子を持つ F の語の数）を当てる。中間の因子の類が価値で区別されること（加法的でない場合も）を示す必要がある。
- (b) **反鎖の違反**：強制された語の中に、L の b 語どうしの真の因子関係が生じる（有限性に反する）。
- 両方とも難しければ、印の語の形（例：全ての ω_j が同じ長さ、b で始まり b で終わる、など）を仮定した部分定理でよい。

**課題3（一般の T へ）.** T が二重化の鎖でない一般の直線的プログラム（ランク ≤ r、ラベル ≤ |V|、N 指数的なら重い分岐が多数）のとき、補題PC の等式系の固定点の構造を調べる：
- 重い節点の数 ≥ N/((r+1)θ) なので、多くのラベルが反復する。反復するラベルは対角線。
- 等式系から「整列の情報が消えていく」（刻みが小さくなる）ことを一般に示せるか。刻みの最終値を文法から決める式。
- 刻みが小さい（≤ poly）ことと、核の価値が指数的であることから、定理M 型の計数につなげられるか。

**課題4（否定の向き）.** 課題2・3 が通らない場合、その箇所から、置き場所の計算の等式系を満たし、反鎖の違反も計数の下界も起こさない有限言語の族（文法の大きさ・厚さが poly(n)、N = 2^n）を設計し、C₁ への所属を検査する。小さい n の全数検査は補助として可（`reviews/check_claude_sU2_closure_2026-11-08.py` は s_{U,2} の代入で閉じる計算、`check_claude_placement_fixpoint_2026-11-08.py` は等式系の固定点）。
