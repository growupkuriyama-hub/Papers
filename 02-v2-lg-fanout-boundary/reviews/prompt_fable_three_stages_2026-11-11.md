## 1. 定義（`main.tex` に従う）

- **語と内容**：k = |Σ|。Ψ はパリク像、cont(w) は w に現れる文字の集合。内容型付け c_Σ は語に cont(w) を返し、組 x = (x₁,…,x_d) の型は (cont(x₁),…,cont(x_d))。
- **許容的な文脈** 𝓔_d：E = v₀□v₁⋯□v_d で、内側の v₁,…,v_{d−1} は空でない。D_L(x) = {E ∈ 𝓔_d : E[x] ∈ L}。
- **代入可能性**：(f, c_Σ)-代入可能とは、全ての 1 ≤ d ≤ f と x, y ∈ (Σ⁺)^d について、型が等しく D_L(x) ∩ D_L(y) ≠ ∅ なら D_L(x) = D_L(y) となること。C_{2,c_Σ} は SUB₁ と SUB₂ を満たす 2-MCFL のクラス。
- **文法**：
  - 既約 good な MCFG（ε-free、nondeleting、nonpermuting、nonmerging）。good な規則から誘導される子の文脈は許容的なので、分布同値は good なテンプレートへの代入で保たれる（`lem:witnessed-composition`）。
  - 厚さ θ̄_G は、各規則について「その規則を使う最短の文の長さ」を取った最大。θ = max(1, θ̄_G)、r はランク、v = |N|、f はファンアウト。
- **代表の長さ**：型付き非終端 X = A_(M₁,…,M_d) について τ_X = min{‖x‖₁ : x ∈ Cl_{L,c}(X)}、τ(G, c_Σ) = max_X τ_X。代表は分布同値な組なら何でもよく、X の生成組である必要はない。特徴データは N_typ(1 + 2θ̄_G + r_max·τ) 以下（`cor:distribution-representatives`）。
- **クラス 𝒦**：
  - Σ = Γ₁ ⊔ ⋯ ⊔ Γ_t（順序付きの段）。ND は段非減少な語の全体（全ての段を含む必要はない）。
  - L = ND ∩ Ψ⁻¹(Q)、Q = ⨆_M Q_M、Q_M = Π_M ∩ (q_M + N_M)（N_M ≤ ℤ^M は格子）。これは、値と部分群が内容ごとに変わる可換群の模型と同じものです。
  - 「有限指数」とは、全ての N_M が ℤ^M で有限指数であること（有限群の場合）。

## 2. 前回の結果（Fable、README (258)。Claude Opus が一行ずつ確認し、語の段階の検査でも違反 0）

### 2.1 所属の判定

型 T = (M₁,…,M_d)、J_T = ⋃M_i、b_T ∈ ℕ^k を (b_T)_a = #{i : a ∈ M_i} と置きます。

- **Comp(T)**：E[x] が ND になる文脈の全体。v_i の文字の段は [hi_i, lo_{i+1}] に入る（lo_i, hi_i は M_i の段の最小と最大）。このため、成分の「内側の段」（lo_i < s < hi_i）の文字は文脈に置けない。
- **Acc_T(n)**：総量 n について、文脈 E ∈ Comp(T) で Ψ(E) + n ∈ Q となるときの、受け入れる内容 supp(Ψ(E) + n) の集合。

**定理1**：L が arity d で代入可能 ⟺ (★)：全ての T, n と、全ての M, M′ ∈ Acc_T(n) について、N_M ∩ O_T(n) = N_{M′} ∩ O_T(n)（O_T(n) = {h ∈ ℤ^{J_T} : n + h ≥ b_T}）。

**系1b**：有限指数なら、(★) は「N_M ∩ ℤ^{J_T} = N_{M′} ∩ ℤ^{J_T}」と同値で、**有限の計算で厳密に判定できる**。

### 2.2 段の効果を示す例

- **Ex1**（段 a<b<c、SUB₁ だが SUB₂ でない）：L = {a^i c^l : i ≡ l (2)} ∪ {a^i b^j c^l : i, l 奇数}。証明書は x = (a,c)、y = (aa,cc)、E = □ac□、F = □b□。
- **Ex2**（段 a<b<c<d<e、SUB₁・SUB₂ だが SUB₃ でない）：L = {a^i c^j e^l : 全て奇数} ∪ {a^i b^p c^j d^q e^l : i ≡ j ≡ l (2)}。
  - N_{ace} = 2ℤ³、N_{abcde} ∩ ℤ^{ace} = 2ℤ³ + ℤ(1,1,1)。
  - arity ≤ 2 の型は、{a,c,e} と {a,b,c,d,e} を同時に受け入れられない。ある成分が b か d の段をまたぎ、その文字を文脈に置けないからである。

### 2.3 補題 M（移動）

z ≠ 0、S = supp z が m 個の段にまたがり、L が arity m で代入可能とする。q, q − z, α ∈ Q で、q と α が z⁺ + 2·𝟙_S 以上なら、α − z ∈ Q。

証明の要点：段ごとに ξ_i（パリク (z⁺ + 𝟙_S) の段 σ_i の部分）と ξ′_i（(z⁻ + 𝟙_S) の段 σ_i の部分）を作り、q の語の中で ξ と ξ′ が文脈を共有することを使う。

### 2.4 定理 A の証明の骨格

1. X の生成組の、節点が最小の導出木を取る（深さ ≤ D = v(2^k−1)^f）。
2. **詰め物**（補題 P）：仮想の葉 V を置き、文字を補う。
3. **良い節点** ω の規則差分 d_{R_ω} は一つの面 U の格子 N_U に入る。H′ = ⟨d_{R_ω}⟩。
4. **補題 O′**（しきい値つきの短縮）で、総量を H′ の短い元 z で順に減らす。
5. **戻し**：各 z について、深い点 q = Ψ(s_V) ∈ Q_U で q − z ∈ Q_U（飽和）。補題 M で α − z ∈ Q。
6. 結論：**t ≤ f なら τ ≤ τ_k = O_{k,f,r}(θ^{k²+2k} + vθ^{k²+k+1})**。全ての d ≤ max(f, t) で代入可能なら t は任意（定理 A′）。

**止まる箇所はただ一つ**：手順5 で z の支持が3つ以上の段にまたがると、補題 M が arity ≥ 3 の代入可能性を要求する。Ex2 では、U = {a,b,c,d,e} の中の z = (1,1,1)（a,c,e）は面 {a,c,e} に戻せない。

## 3. 課題

f = 2、t ≥ 3 の 𝒦 ∩ C_{2,c_Σ} を対象とします。目標は、どちらの方向かに決着をつけることです。

### 課題1（多項式データの方向）：移動を二つ以下の段に分解する

定理 A の手順4〜5 を、二つ以下の段にまたがる移動だけで行えるかを調べてください。候補は次のとおりです。

- (a) H′ の生成元 d_{R_ω} の中で「二つ以下の段にまたがるもの」が生成する部分格子 H″ が、手順4 の短縮に足りるか。足りない方向が、文法の側の理由（塊の内側の節点の詰め物が純粋であること、など）で現れないことを示せるか。
- (b) 三つ以上の段にまたがる z を、二つ以下の段にまたがる**実現された差**の列（途中の点が全て Q と Π の中にあるもの）に分解できるか。補題 M を、二穴の文脈を連鎖させる形に一般化できるか。
- (c) Ex2 の現象（面の格子が、二穴で比べられない方向にずれる）が、τ を実際に大きくすることがあるか。Ex2 そのもの、またはその族で τ を計算してください。Ex2 で τ が小さいなら、その理由が一般化できるかを述べてください。

成功したときの形：「𝒦 ∩ C_{2,c_Σ} の任意の既約 good な表示で τ ≤ poly_{k,r}(‖G‖, θ)（t は任意）」。条件付きの形（「段の構造が …… なら」）でも構いません。

### 課題2（下界の方向）：反例の族を作る

𝒦 ∩ C_{2,c_Σ} の中で、t ≥ 3、文法の大きさと厚さは poly(n)、τ（または特徴データ）は超多項式、という族を作ってください。

- 所属（SUB₁・SUB₂）は、系1b の厳密な判定条件で示してください（有限指数ならこれは有限の計算で、全ての arity・全ての長さについての証明になる）。無限指数なら、定理1 の (★) を手で示してください。
- 文法は明示し、L(G) = L を手で示してください（有界な照合は補助）。
- τ の下界は、分布の同値類（定理1 の系：総量が (n + N_M) ∩ (b_T + ℕ^{J_T}) に入る型 T の ND な組の全体）の最小ノルムとして、手で示してください。
- §2.5 の二つの障害（純粋な詰め物、窓の補題）をどう避けるかを明記してください。
- 失敗した場合は、壊れ方から新しい必要条件を取り出してください。

### 課題3（中間）：t ≥ 3 でも上界が成り立つ十分条件

課題1・2 が決着しない場合に取り組んでください。たとえば次の条件です。

- 「どの二つの内容の面の格子も、段の凸な部分集合の上で一致する」

これらの下で定理 A が延びるかを調べてください。どの条件も、系1b で判定できる形で述べてください。
