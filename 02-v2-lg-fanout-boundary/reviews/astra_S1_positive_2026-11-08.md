## 0. 記号と要点

Σ={a,b}、非空語の型は「b を含まない／含む」の二種類とする。

\[
D_L(x)=\{(l,r):lxr\in L\},\qquad x\equiv_L y\iff D_L(x)=D_L(y).
\]

同型の非空語が文脈を共有すれば分布が一致することを C₁ の条件と呼ぶ。空語が L に含まれていても、以下の非空因子の議論には影響しない。

重要な点は二つある。

1. 有限の置き場所は、単なる積順序の反鎖ではなく、**一つの方向に進む、途中の抜けのない等差列**である。その方向は一般には (d,−e)、d,e>0 であり、d=e は自動ではない。
2. 同じ非終端の短い代替語が、純な導出木の二か所に現れるなら、二か所の総パディング長は等しい。この場合に限って上の方向は (d,−d) となり、**その代替語の全ての純な置き場所が同じ対角線上にある**。

後者と、代替語中の b が一つという追加仮定を合わせると、全ての重い節点を同じ P(b) で比較でき、多項式上界になる。b が複数ある一般の場合、その比較はまだできていない。

## 1. (F1)–(F3) の検証

### 補題0（有限言語の分布クラスは因子反鎖）

L は有限とする。D_L(x)=D_L(y)≠∅ であり、y=uxv、|uv|>0 なら矛盾する。

**証明。** (l,r)∈D_L(x) を選ぶ。x≡y より l u x v r∈L。そこで新しい文脈 (lu,vr) にも x≡y を適用する。反復すると全ての k≥0 に対し

\[
l u^k x v^k r\in L.
\]

長さは狭義に増加し、有限性に反する。□

この補題自体は型付けを使わない。**非空の分布という条件は必要**である。L の因子でない語は全て空の分布を持つので、現れない語まで量化した (F1) はそのままでは偽。

### (F2)

L の b を含む語は全て型 ζ で文脈 (ε,ε) を共有する。従って分布が等しく、補題0により因子反鎖である。純な a の受理語も全て型1で文脈を共有する。二つの異なる a 冪は真の因子関係にあるため、有限 L では高々一つである。

reduced CFG の一つの非終端の生成語についても、固定した成功文脈を共有するので同じ議論が適用できる。特に、その非終端の純な a の生成語は存在すれば一つだけである。

### (F3)

ω が b を含むとする。P(ω)={(x,y)∈ℕ²:a^xωa^y∈L} に、異なる二点 (x,y)≤(x′,y′) があれば、前者の受理語は後者の真の因子になる。(F2) に反する。

従って P(ω) は積順序の反鎖であり、x は y を一意に決め、x が増えれば y は狭義に減る。次節はこれを強める。

## 2. 有限の置き場所の完全な形

固定した外側の文脈 U,V∈Σ* も許し、

\[
P_{U,V}(\omega)=\{(x,y)\in\mathbb N^2:U a^x\omega a^y V\in L\}
\]

と書く。P(ω)=P_{ε,ε}(ω)。ω は b を含む。

### 定理1（有限の置き場所は等差列）

L∈C₁ とし、P=P_{U,V}(ω) が有限であるとする。言語 L 自体の有限性は必要ない。

P は空集合、単集合、または次の形である：

\[
\boxed{P=\{(x_0+kd,\ y_0+(K-k)e):0\le k\le K\}},
\]

ここで K≥1、d,e≥1 は整数、0≤x₀<d、0≤y₀<e である。

**証明。**

**第1段：反鎖性。** 比較可能な二点があれば、対応する b を含む内側の語は文脈 (U,V) を共有する。C₁ と補題0の反復の議論を、この固定外側文脈のまま実行すると、P に無限個の点ができる。従って P の有限性だけで反鎖性が従う。

**第2段：一つの移動を全域で使えること。** |P|≥2 とする。P の異なる x 座標の差の最小値を d とし、その差を実現する二点を

\[
(x,y+e),\quad(x+d,y)\qquad(e>0)
\]

と書く。語 a^dω と ωa^e は、ともに b を含み、文脈 (Ua^x,a^yV) を共有する。従って

\[
a^d\omega\equiv_L\omega a^e. \tag{2.1}
\]

これを任意の出現に使うと、

\[
\begin{aligned}
(s,t)\in P, s\ge d&\Longrightarrow(s-d,t+e)\in P,\\
(s,t)\in P, t\ge e&\Longrightarrow(s+d,t-e)\in P.
\end{aligned} \tag{2.2}
\]

**第3段：軌道は一つ。** 任意の点から第1の移動を反復すると、x 座標が [0,d−1] にある点に到達する。d の最小性により、この帯に P の点は高々一つしかない。よって全ての点は一つの軌道に属する。

第2の移動も可能な限り強制されるので、その軌道に抜けはない。右端の y 座標は e 未満でなければならない。これで表示と端点条件が得られた。□

**注意。** これは置き場所の必要な形の分類である。「全ての ω の P がこの形なら L∈C₁」という十分条件は主張しない。b を含む外側文脈も含めた分布の条件が別途ある。

### 系2（対角線上の二点があれば全点が同じ対角線上）

定理1の仮定の下で、P が異なる二点 (x,y),(x′,y′) を持ち、x+y=x′+y′ なら、d=e であり、P 全体で s+t は一定である。

**証明。** 等差列上で二点の添字差を h≠0 とすると、総和の差は h(d−e)。これが0だから d=e。□

### 系3（純な導出木で反復するラベル）

有限 L∈C₁、a^N の最短・その中で節点数最小の導出木 T を考える。非終端 B が T の異なる二か所に現れ、その純な生成語の長さが n_B、b を含む生成語が ω_B であるとする。このとき

\[
P(\omega_B)\subseteq\{(x,y):x+y=N-n_B\}.
\]

**証明。** 最短かつ節点数最小の導出木では、同じラベルが祖先・子孫として現れない。そうなら祖先部分木を子孫部分木で置き換えて長さを短くするか、同じ長さで節点数を減らせるからである。

従って二つの B 出現は互いに素で、左端位置が異なる。それぞれを ω_B で置き換えると、P(ω_B) に異なる二点が得られ、いずれも座標和 N−n_B を持つ。系2を適用する。□

同じ主張は、固定成功文脈 (U,V) を持つ非終端 A の最短純語の導出について、P を P_{U,V} に替えて成立する。

## 3. (F4) のどこまでが正しいか

### 3.1 正しい部分

T の節点 B を ω_B で置き換えて得られる位置 (x,y) は、確かに x+y=N−n_B を満たす。この部分は代入可能性すら使わない。

さらに、同じ非終端 B の b を含む生成語 y,z は分布が等しいので、**P(y)=P(z)** である。定理1により、これらの集合が複数点を持てば共通の等差列になる。

系3は、同じ B が T で反復する場合に、その集合全体の傾きを −1 に固定する。

### 3.2 一般には言えない部分

以下は追加仮定なしには言えない。

- T から得た位置が一つだけでも、P(ω_B) の全体が x+y=N−n_B 上にある。
- 同じ b を含む語 z に、座標和の違う二つの置き場所があれば矛盾する。
- B→CD なら、C の短い代替語を置ける全ての位置に、B の短い代替語も同じパディングで置ける。

最後の点で C.0 が与えるのは、例えば a^{n_C}ω_D と ω_B がともに B の b を含む生成語なら、その二語の分布の一致である。**子の ω_D 単独との分布の一致ではない。** 純なパディングを付けたり取り除いたりする操作の条件を落としてはいけない。

### 命題3（非加法的な有限族）

p,q≥1 に対し

\[
L_{p,q}=\{a^{p+q},\ a^p b,\ b a^q,\ bb\}
\]

とする。すると L_{p,q}∈C₁ であり、

\[
P(b)=\{(p,0),(0,q)\}.
\]

p≠q なら二点の座標和は異なる。また、α≠0 として全受理語に共通の文字加法的重み α|w|_a+β|w|_b=α(p+q) を課すことはできない。

**所属の証明。** 非空の純な a 因子は a^k である。純な外側文脈では受理語 a^{p+q} が k を一意に決める。b を含む外側文脈では、b が因子の右にあれば a^pb、左にあれば ba^q しか候補がなく、やはり k は一意。従って異なる純な a 因子は文脈を共有しない。

b を含む因子は b、a^i b（1≤i≤p）、b a^j（1≤j≤q）、bb のみ。その分布は

\[
\begin{aligned}
D(b)&=\{(a^p,\varepsilon),(\varepsilon,a^q),(b,\varepsilon),(\varepsilon,b)\},\\
D(a^i b)&=\{(a^{p-i},\varepsilon)\}\quad(1\le i\le p),\\
D(b a^j)&=\{(\varepsilon,a^{q-j})\}\quad(1\le j\le q),\\
D(bb)&=\{(\varepsilon,\varepsilon)\}.
\end{aligned}
\]

異なる因子が文脈を共有するのは、受理語 a^pb,ba^q,bb の間だけであり、いずれも分布は {(ε,ε)}。従って C₁ の条件が成り立つ。

加法的重みについては、a^pb から β=αq、ba^q から β=αp が必要となるため、p≠q なら不可能。□

**文法と厚さ。**

\[
S\to BC,\quad B\to a^p\mid b,\quad C\to a^q\mid b.
\]

この文法は reduced、ε なし、ランク2で、

\[
|V|=3,\quad\|G\|=p+q+12,\quad\theta=\max(p,q)+1,\quad N=p+q\le2\theta-2.
\]

B→a^p を使う最短受理語は a^pb、C→a^q の場合は ba^q。残りの各規則は bb の導出で使えるので、θ の式は正確である。

T の左の B を b に替えると (0,q)、右の C を b に替えると (p,0)。したがって、同じ語 b に B と C から異なる「a 換算値」を与えても、代入可能性は壊れない。**語だけの関数 W(b) として両方の換算値を同時に定義すること自体ができない。**

最小の非対称な例は p=2,q=1：L={aaa,aab,ba,bb}。これは (F4) の一般的な衝突判定への反例であり、op:S1 への反例ではない。

### 3.3 二点だけの現象ではない

\[
L=\{a^8,\ ba^4,\ aba^2,\ a^2b\}
\]

も C₁ に属し、P(b)={(0,4),(1,2),(2,0)}。これは傾き −2 の三点等差列で、座標和は4,3,2と変わる。

所属は次のように直接確認できる。b を含む因子 a^i b a^j の文脈は純な a パディングだけであり、その集合は

\[
\{(a^u,a^v):2u+v=4-2i-j,\ u,v\ge0\}.
\]

共通文脈があれば右辺の値が等しく、分布が等しい。純な a 因子については、固定文脈中の b の左右位置が長さを一意に決め、純な外側文脈では a^8 が長さを一意に決める。

従って「非加法的なら座標和の衝突で排除」という方針(a)は、この形のままでは成立しない。

## 4. 条件付きの多項式上界

### 定理4（重い節点が一つの b で短く表せる場合）

L は有限で L∈C₁、G は依頼文の reduced・ε なし・ランク ≤r の CFG とする。a^N は最短純語、T はその中で節点数最小の導出木。

**追加仮定：** T に現れる全ての重いラベル B について、B は

\[
\omega_B=a^{u_B}b a^{v_B},\qquad |\omega_B|\le\theta
\]

という生成語を持つ。

このとき

\[
\boxed{N\le(r+2)|V|\theta.}
\]

より詳しくは、重いラベルの反復が無ければ N≤(r+1)|V|θ、反復があれば N≤(r+2)θ−1 である。

**証明。** N≤θ なら明らかなので根は重いとする。

**場合1：重いラベルが反復しない。** 重い節点数は高々 |V|。各規則が直接出力する端末数は θ 以下である。その規則を使う長さ θ 以下の成功導出が存在するからである。各重い節点には高々 r 個の軽い子があり、各子の純な生成語の長さは θ 以下。

根から重い部分木を展開し、軽い子で止めて長さを数えると、一つの重い節点への寄与は高々 (r+1)θ。よって N≤(r+1)|V|θ。

**場合2：ある重いラベル B が反復する。** 二つの出現を同じ ω_B=a^{u_B}ba^{v_B} で置き換える。P(b) に異なる二点が得られ、その座標和はいずれも

\[
N-n_B+u_B+v_B
\]

となる。系2より、P(b) 全体の座標和は一定 C である。

任意の重い節点 D についても、その短い一-b生成語を代入すると

\[
C=N-n_D+u_D+v_D.
\]

従って全ての重い節点で

\[
\delta:=N-C=n_D-u_D-v_D \tag{4.1}
\]

は共通である。

最も深い重い節点 D₀ を選ぶ。その子は全て軽いので

\[
n_{D_0}\le(r+1)\theta,\qquad
\delta=n_{D_0}-u_{D_0}-v_{D_0}\le(r+1)\theta.
\]

根 S も重い。一-b生成語の長さ制約から u_S+v_S≤θ−1 なので、(4.1)を根に適用すると

\[
N=\delta+u_S+v_S\le(r+2)\theta-1.
\]

二つの場合を合わせれば所望の上界。□

### 4.1 型付き非終端への適用

定理4は開始記号に固有ではない。非終端 A の最短純語を取り、固定した成功文脈 (U,V) を外に置き、P(b) を P_{U,V}(b) に替えれば証明はそのまま通る。

したがって、全ての a-重い非終端が長さ ≤θ の一-b生成語を持つなら、全ての型1の非終端について同じ上界が得られる。

型 ζ の最短生成語については、代入可能性なしでも O((r+1)|V|θ) の上界がある。b の端末出現を一つ標識し、その出現を含む導出の長さ・節点数を最小にする。標識への経路では非終端ラベルが反復できず、経路外の各子は長さ ≤θ の最短生成語で置き換えられる。経路長は |V| 以下なので同じ数え上げが適用できる。

よってこの追加仮定の下では、依頼文で求められた「型付き非終端ごとの短い代表語」の部分も満たせる。ただし、特徴データ全体の具体的な係数や r 依存性は、本報告では作用素の定義から再計算していない。

### 4.2 仮定を落とせない場所

一般の短い生成語は

\[
a^{t_0}b a^{t_1}b\cdots b a^{t_k},\qquad k\ge2
\]

かもしれない。反復するラベルについて P(ω_B) が一つの対角線に乗ることは系3で分かる。しかし、異なる ω_B の情報を**同一の P(b)** に移すには、b を含む外側文脈を固定しなければならず、その文脈が B ごと・b の出現位置ごとに変わる。

従って (4.1) の共通 δ はまだ定義できない。b を含む語を一つの b と同じように扱うことは、この未証明部分を飛ばすことになる。

## 5. 非加法的な二段構成を反復すると何が起きるか

### 命題5（三つの同じ代替語による剛性）

L は有限で L∈C₁。ω は b を含み、p,q,s≥1。ある固定 U,V について

\[
U\{a^p,\omega\}\{a^q,\omega\}\{a^s,\omega\}V\subseteq L
\]

なら p=q=s。

**証明。** 最初の二因子を変え、最後を a^s に固定すると、a^pω, ωω, ωa^q は文脈 (U,a^sV) を共有するので分布が等しい。最後の二因子を変え、最初を a^p に固定すると、a^qω, ωω, ωa^s も分布が等しい。

従って a^pω≡a^qω。p≠q ならどちらかが他方の真の因子であり、分布は非空なので補題0に反する。同様に ωa^q≡ωa^s から q=s。□

この命題は、命題3の非対称な二因子の族を同じ短い代替語のまま三因子以上へ増やせないことを示す。ただし、異なる代替語や因子間の異なる固定パディングを許した任意の導出木には、そのまま適用できない。

## 6. 無限標的と、計数方針について

### 6.1 定理1・定理4が残る範囲

定理1は P_{U,V}(ω) の有限性しか使わない。従って L が無限でも、P(b) が有限で、定理4の一-b生成語の仮定があれば、開始記号について同じ上界が成り立つ。各非終端については、その成功文脈に対応する P_{U,V}(b) の有限性が必要。

一般の無限標的では、P は積順序の反鎖ですらない。例えば L=Σ⁺ は C₁ に属し、P(b)=ℕ²。定理1を適用できない。これは上界への反例ではなく、有限置き場所の証明を無条件に流用できないことの例である。

定理Gは、依頼文で証明済みとされた特定の群原像クラスの結果として受け入れる。しかし「P が無限なら群原像のような計数構造を持つ」という含意は、ここでは証明できていない。

### 6.2 b の個数の種類を用いる既知型の評価

有限性の代わりに、b の個数のスペクトルが有限である場合は、既知の重い節点の反鎖の議論を使える。

\[
K=\bigl|\{|w|_b:w\in L\cap\Sigma^+\}\bigr|-1
\]

とする。開始記号が純な語を生成するので0はスペクトルに含まれる。互いに素な h 個の重い節点を左から順に短い b 含有語で置き換えると、0から始まる h+1 個の異なる b 個数が得られる。従って h≤K。

T の各根葉経路のラベルは反復しないので高さは |V| 以下。各深さの重い節点は反鎖だから、重い節点総数は |V|K 以下。よって

\[
N\le(r+1)|V|\theta\max(1,K).
\]

これは K が多項式で抑えられる場合の条件付き評価であり、一般の有限言語について K 自体を poly(‖G‖,θ,r) で抑えたものではない。先行報告の反鎖幅の方針を整理したもので、新しい一般解としては扱わない。

### 6.3 課題1(b)に残る障害

定理1によって、固定した一語の置き場所には任意の曲線の自由度はなくなった。しかし、等差列の長さ K、刻み d,e、異なる短い語に属する等差列の関係はまだ制御できない。短い語 ω が θ 文字以下であることから、その等差列の長さが多項式になるとは直ちには言えない。

従って「反鎖だから小さい」「短い代替語だから置き場所も少ない」という推論は不十分。文法が強制された全ての語を生成することを使う、別の計数補題が必要である。

## 8. 現時点で採用できる主張と残る問い

本報告で証明した主張は、有限の置き場所の等差列定理、同じラベルが反復する場合の対角線性、一-b代替語の仮定の下の上界 N≤(r+2)|V|θ、および三因子の剛性である。

一般の有限標的での op:S1 は未解決。特に、**複数の b を含む短い代替語どうしの関係を、文字ごとの共通重みなしに制御すること**が残る。定理1は各語について局所的な傾きを与えるが、それらを統一する定理ではない。

課題3では、非加法的な有限 C₁ 言語は実際に存在することを確定した。しかし、その族の厚さは N と同程度であり、超多項式分離を与えない。さらに、依頼文の「座標和が違う置き場所は矛盾」という条件そのものが一般には必要条件ではないため、その条件を反例探索の除外基準に使うと、正しい C₁ 言語まで除外してしまう。

無限の場合も、群原像の結果と今回の有限置き場所の結果を尽くす一般的な二択は未証明である。したがって、字母数の境界、あるいはファンアウトによる分離のどちらも、この報告からは結論しない。

## 付録：再実行コード

以下を `check_s1.py` として保存し、Python 3 で実行できる。

```python
from collections import defaultdict
from itertools import combinations, product

def distributions(L):
    D = defaultdict(set)
    for w in L:
        for i in range(len(w)):
            for j in range(i + 1, len(w) + 1):
                D[w[i:j]].add((w[:i], w[j:]))
    return D

def substitutable(L):
    D = distributions(L)
    first = {}
    for w, contexts in D.items():
        for c in contexts:
            v = first.setdefault(('b' in w, c), w)
            if D[v] != contexts:
                return False
    return True

def placement_shape(P):
    if len(P) <= 1:
        return True
    P = sorted(P)
    if any(y <= yy for (_, y), (_, yy) in zip(P, P[1:])):
        return False
    d = min(xx-x for (x, _), (xx, _) in zip(P, P[1:]))
    i = next(i for i in range(len(P)-1) if P[i+1][0]-P[i][0] == d)
    e = P[i][1]-P[i+1][1]
    x0, ymax = P[0]
    ymin = P[-1][1]
    return (x0 < d and ymin < e and
            P == [(x0+k*d, ymax-k*e) for k in range(len(P))])

def verify_placements(L):
    for w, contexts in distributions(L).items():
        if 'b' in w:
            P = {(len(l), len(r)) for l, r in contexts
                 if 'b' not in l+r}
            assert placement_shape(P), (L, w, P)

def main():
    for p in range(1, 9):
        for q in range(1, 9):
            L = {'a'*(p+q), 'a'*p+'b', 'b'+'a'*q, 'bb'}
            assert substitutable(L)
            verify_placements(L)
    print('Two-block family: 64/64 passed')
    total = accepted = 0
    bwords = [''.join(t) for n in range(1, 5)
              for t in product('ab', repeat=n) if 'b' in t]
    for N in range(1, 6):
        for k in range(4):
            for B in combinations(bwords, k):
                L = {'a'*N, *B}
                total += 1
                if substitutable(L):
                    accepted += 1
                    verify_placements(L)
    print(f'Finite languages checked: {total}; C1: {accepted}; placement failures: 0')
    total = accepted = 0
    for p, q, s in product(range(1, 6), repeat=3):
        L = {''.join(w) for w in product(('a'*p, 'b'),
                                        ('a'*q, 'b'), ('a'*s, 'b'))}
        ok = substitutable(L)
        assert ok == (p == q == s)
        total += 1
        accepted += ok
    print(f'Three-block family: {total}; C1: {accepted}; exactly p=q=s')
    L = {'a'*8} | {'a'*x+'b'+'a'*(4-2*x) for x in range(3)}
    assert substitutable(L)
    verify_placements(L)
    print('Nonunit slope, three placements: passed')

if __name__ == '__main__':
    main()
```
