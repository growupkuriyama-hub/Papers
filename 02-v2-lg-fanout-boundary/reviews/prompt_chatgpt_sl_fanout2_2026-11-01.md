## 1. 背景

- 型付け s: Σ⁺ ↠ S（S は有限半群）を固定し、空でない組の成分を s の値が等しいときだけ比べます。クラス C_{f,s} は、(f,s)-組代入可能なファンアウト f 以下の MCFL です。
- **一様な多項式データ**（`def:uniform-polydata`）：擬多様体 V がファンアウト f・ランク r_max でこれを持つとは、全ての有限アルファベット Σ と、像が V に入る全ての全射型付け s について、多項式 p_{f,r,s,Σ} があり、全ての L ∈ C_{f,s} と全ての reduced good 表示 G について、作用素 B^{≤r}_{f,s} の特徴標本で長さ ≤ p(‖G‖, θ̄) のものがあることです。
- **定理A(i)**：LG（局所群）は全てのファンアウトでこれを持つ。
- **定理B**：ファンアウト1・r_max ≥ 2 では、V がこれを持つ ⟺ V ⊆ LG。LG の外では、U₁ = {1, ζ} への型付け s_U と括弧付き倍増族 L_n（E_i → ⌊E_{i−1}E_{i−1}⌋ | ⌈E_{i−1}⌉）が指数のデータを必要とする。型1の語は W_n ただ一つで、長さは 3·2ⁿ−2。
- **定理C**：L_n は、n ≥ 2|S|+3 なら、どの固定型付けでもファンアウト2のクラスに入らない。理由は冪の移行（`lem:power-transfer`）です。L ∈ C_{f,s}（f ≥ 2）で、ある語が因子 u^{a+d+b+2}（a, b ≥ i₀、d は周期 q の正の倍数）を含むと、二つの穴の間で u の冪をやり取りしても所属が変わりません。W_n は ⌊ⁿ で始まるので、これに引っかかります。
- **未解決**（`op:fanout-two`）：ファンアウト2でも境界は LG か。

## 2. Claude の観察（今回の出発点。外部の検証はまだ）

**観察1（SL への帰着）**
- LG に入らない有限半群は U₁ の写しを含みます（`thm:lg-characterization`(ii)）。U₁ が生成する擬多様体は、有限半束全体 SL です。
- したがって、LG に含まれない擬多様体は全て SL を含みます。「一様な多項式データ」は V を大きくすると成り立ちにくくなる性質です（量化する型付けが増えるため）。
- 以上と定理A(i) から、次が言えるはずです。
  > ファンアウト f・r_max ≥ 2 で「V が一様な多項式データを持つ ⟺ V ⊆ LG」が成り立つ ⟺ SL がファンアウト f で一様な多項式データを持たない。

**観察2（内容型付けで十分）**
- 内容型付け c_Σ(w) = {w に現れる文字}（空でない部分集合の和集合の半束への全射）は、Σ 上の半束型付けの中で最も細かいものです。全ての半束型付け s は c_Σ を経由して書けます（s ⪯ c_Σ）。
- s ⪯ c_Σ なら C_{f,s} ⊆ C_{f,c_Σ} です。また、稀な型による下界は c_Σ にも移るはずです。s の型 m の最短の語の長さは、m に含まれるどの c_Σ の型の最短の長さよりも短くないからです。
- したがって、SL の失敗を示すには、**ある固定アルファベット上の内容型付けで、ファンアウト2の超多項式の族を作れば足りる**はずです。型付けが細かいほどクラスは大きいので、U₁ だけで探していたこれまでより、族を作りやすくなります。

**観察3（冪の移行の回避）**
- 半束では s(u)² = s(u) なので、i₀ = q = 1 です。冪の移行には、因子 u⁵（a = b = d = 1）が必要です。
- **Thue–Morse 語のように重なりのない語**（axaxa の形の因子を持たない）は、立方 u³ すら含みません。したがって冪の移行は最初から効きません。
- Thue–Morse 語 t_n（長さ 2ⁿ）は、A_0 → a、B_0 → b、A_i → A_{i−1}B_{i−1}、B_i → B_{i−1}A_{i−1} で、大きさ O(n) の文法で作れます。
- 稀な型の下界には、括弧付き倍増族と同じ仕組み、つまり「各段に短い別の枝（印の文字を使う）があり、印を使わない語がただ一つで長い」構造が使えるはずです。各段の規則が短い文で使われるので θ̄ = O(n) にできます。

## 3. 調べてほしいこと（優先順）

**T0（観察1・2の証明）**
観察1の同値と、観察2の帰着（内容型付けへ移せること、稀な型の下界が移ること）を、原稿の定義に沿って正確に証明してください。誤りがあれば、正しい形に直してください。論文に入れられる命題の形（主張と短い証明）で書いてください。

**T1（重なりのない倍増族の設計）**
固定アルファベット上の内容型付け c_Σ で、次を満たす族 (L_n, G_n) を設計してください。
- (i) L_n ∈ C_{2,c_Σ}。少なくともファンアウト1（Clark–Eyraud 型の条件）と、ファンアウト2の二穴の条件の両方。
- (ii) ‖G_n‖ と θ̄_{G_n} が n の多項式。
- (iii) ある内容型の最短の語の長さ μ が n について超多項式（理想は 2^{Ω(n)}）。
- (iv) 全ての語が u⁵（できれば u³）を因子に持たない。

括弧付き倍増族の背骨を Thue–Morse 型、または他の重なりのない・平方のない形態素（例えば Thue の三文字の平方のない語）に置き換えるのが第一案です。代入可能性の証明には、01 の付録 C の決定的スタック解析器の議論（および、閉じ記号が欠けた場合のあなたの以前の補強。`reviews/chatgpt_window_gap_2026-10-31.md` §3–§4）が参考になります。

**T2（障害が見つかった場合）**
T1 の族がファンアウト2で代入可能にならない場合は、その理由を**冪の移行より一般的な「二穴の移送」の補題**として定式化してください。例えば、同じ型で共通の二穴文脈を持つ二つの組の交換が、どんな構造を潰すか、という形です。その補題が「SL はファンアウト2で多項式データを持つ」方向の証明の部品になるかも検討してください。

**T3（逆向きの可能性）**
逆に、SL（あるいは内容型付け）がファンアウト2で一様な多項式データを持つ、と証明できる部分クラスがあれば述べてください。これが成り立てば、「境界がファンアウトで動く」ことになり、同じく論文の看板になります。
