## 1. 設定（閉包報告 §1・§3.6 のとおり）

- Σ = {a,b,c}。D は有向多重グラフで、各文字 σ がちょうど一本の辺 tail(σ) → head(σ) を持ちます。
- φ : Σ* → A は可換群への準同型で、ψ(w) = (π_D(w), φ(w), cont(w))、L = ψ⁻¹(P) です。P は経路の像の部分集合とします（零を受理する場合は扱いません）。
- 歩道の格子の記号：
  - C_x^M：x の上の閉じた歩道（空でない）で、内容が M に含まれるもののパリクが生成する格子。
  - D_{stM}：s → t で内容 M の歩道のパリクの差が生成する格子。
  - V_ab：辺 a, b の端点の集合。
- **(CW)**（端点の組 (s,t) についての条件）
  - (CW1) M ∈ {ab, abc} のうち s → t の歩道があるものについて、D_{stM} ⊆ C_s^M + C_t^M。
  - (CW2) ab と abc の歩道が両方あるとき：内容 ⊆ abc で c を含む閉じた歩道が s か t の上にあり、ある ab 歩道 w₂ と abc 歩道 w₃ について π(w₃) − π(w₂) ∈ C_s^{abc} + C_t^{abc}。
  - (CW3) 同じとき：ある r ∈ V_ab について D_{st,ab} ⊆ C_r^{ab}。
- 定理2.9：A が有限、L が SUB₁、(s,t) が (CW) を満たすなら、(K1) 受理値は一つの剰余類で、(K2) a, b を含む L ∩ Path(s,t) は (16) の形。そこから定理 H で μ_ab ≤ poly（系3.6(b)：max{16(r+1)vθ, 10 121 122·v³θ³}）。
- (CW) の現状：一文字一辺の有向グラフは同型を除いて 203 種。そのうち「長い ab 経路があり、c が内部に来うる」ものが 17 種で、その全ての端点の組 41 個で (CW) が成り立ちました。ただし**長さ ≤ 7 の歩道で生成した格子での観察**です。残りの 186 種は「補題3.8 か、ab 経路の長さ ≤ 2 で自明に片付く」とされています。

## 2. 課題

### 課題1：分類の点検

- (a) 一文字一辺の有向グラフ（3 本の辺、ループと平行辺を許す。孤立点は除く）が同型を除いて 203 種であることを確かめてください。数え方は自分で決め、明記してください。
- (b) 「長い ab 経路があり、c が内部に来うる」の定義を、報告書とスクリプト（§S9）から正確に読み取って書き直してください。17 種と 41 組を自分で列挙してください。
- (c) 残りの 186 種が本当に「補題3.8 か、ab 経路の長さ ≤ 2」で片付くかを、種類ごとに確かめてください。片付かないものがあれば、それを挙げてください。

### 課題2：(CW) の手による証明（主目標）

17 種・41 組の全てについて、(CW1)(CW2)(CW3) を**手で証明**してください。

- 鍵は、格子 C_x^M と D_{stM} を**有限個の短い閉じた歩道と経路**で生成することを示すことです。例えば「s → t の任意の歩道は、一本の単純な経路に s か t の上の閉じた歩道を足したもののパリクを持つ」といった分解の補題を、グラフの形ごとに示してください。強連結の 5 種（一頂点、二サイクル a: p→q, b: q→p に c のループか平行辺）と、残りの 12 種（a のループと b の辺など）を分けると見通しがよいはずです。
- 観察は長さ ≤ 7 の歩道で生成した格子によるものです。**本当の格子はもっと大きいかもしれません**。その場合、(CW1) の左辺 D_{stM} も右辺も大きくなるので、観察が正しくても証明が成り立つとは限りません。各組で、格子の生成元を有限個で尽くしたことを示してください。
- (CW) が成り立たない組があれば、それは重要な発見です。その組を挙げ、(CW) なしで定理2.9 の (K1)(K2) が成り立つか、成り立たない言語（SUB₁ を満たし (16) の形でないもの）を作れるかを調べてください。

### 課題3：定理2.9 と系3.6(b) の点検

- (a) 補題2.9a（詰め物）：「s の上の閉じた歩道の値と 0 は、有限群の中で連結について閉じた部分モノイドなので、Φ(C_s^M) と一致する」。有限群の部分モノイドは部分群であることの使い方と、生成する格子の像との一致を確かめてください。
- (b) 補題2.9b（挿入）：y^o の挿入で型が変わらないこと、分布の等しさの使い方。
- (c) 定理2.9 の (K1) と (K2) の (i)(ii)(iii)。特に (ii) で、ω が r を通ること（辺 a, b を使うので両端点を全て通る）、ω を r で分けたときに ω₁y^oω₂ が経路の語になること、S_r の定義、y と y′ の分布が等しくなる議論。
- (d) 系3.6(b) の定数 max{16(r+1)vθ, 10 121 122·v³θ³} の出どころ（定理3.2 の場合分けと、定理 H の定数への帰着）。
- (e) 定理2.9 は「(s,t) ごと」の主張です。L が複数の端点の組にまたがるとき、μ_ab の上界にどう組み合わせるかを確かめてください。
