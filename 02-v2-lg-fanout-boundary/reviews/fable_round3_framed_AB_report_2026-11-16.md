## 2. 設定と規約

`Σ={a,b,c}`、内容型 `alph`。L は内容型付き 1 穴・2 穴の組代入可能性を持つ：

> **(Rect)** `E₀[x], E₀[y], E₁[x] ∈ L` かつ x,y の各成分の実内容型が一致 ⟹ `E₁[y] ∈ L`。

穴に入る語はすべて非空、2 穴文脈 `(l,m,r)` の中央 m は非空（l,r は空でよい）。この規約は第十六段報告 §2 のものをそのまま使う。

`a^N` は L に属する最短の正の a 冪。`κ=pbcq`、`κ′=pcbq`、`p,q∈{b,c}⁺`。両者は単独 Rot 証人を持ち、外側 a 量 `λ=N−δ`、`λ′=N−δ′`、`δ,δ′≥1`。

- `s := δ−δ′ = λ′−λ`、`M := max(δ,δ′)`。よって `|s|≤M−1<N`。
- 実在宿主 `a^x κ a^y κ′ a^z ∈ L`、`t := x+y+z = N−δ−δ′ ≥ 3`。これより `λ=N−δ≥δ′+3≥4`、同様に `λ′≥4`、かつ `λ,λ′≤N−1`。

**既知の道具（第十六段 §3、再証明しない）**

- **R**：和が N−1 以下の正の a 連 2 本の再配分。
- **Rot**：`aκ≡κa`、`aκ′≡κ′a`（任意の 1 穴文脈で成立）。特に `a^{λ−i}κa^i∈L`（`0≤i≤λ`）、`κ′` も同様。宿主からは `κκ′a^t∈L`。
- **U_shift**：同じ P について `Pa^e, Pa^f∈L`、`e,f≥1`、`0<|e−f|<N` は不可能。

## 3. 二つの構造補題

### 補題F（枠補題・一般形）［PROVED］

`i≥1`、`i+s≥1`、`i≤λ` とする。任意の語 P,R と**任意の非空語 Q** について

- **F+**：`P·bc·Q·a^i·R ∈ L ⟹ P·cb·Q·a^{i+s}·R ∈ L`
- **F−**：`P·cb·Q·a^{i+s}·R ∈ L ⟹ P·bc·Q·a^i·R ∈ L`

| 項目 | 内容 |
|---|---|
| 比較タプル | `x=(bc, a^i)`、`y=(cb, a^{i+s})` |
| 実内容型 | 両者とも `({b,c},{a})` |
| 共通文脈 E₀ | `(a^{λ−i}p, q, ε)`、中央 q は非空 |
| E₀[x] | `a^{λ−i}·pbcq·a^i = a^{λ−i}κa^i ∈ L`（Rot） |
| E₀[y] | `a^{λ−i}·pcbq·a^{i+s}`、a 総数 `λ+s=λ′`、`∈L`（κ′ の Rot） |
| 試験文脈 E₁ | `(P, Q, R)`、中央 Q は非空 |

F− は x,y の役割を入れ替えた同じ Rect。

**要点。** 枠 p,q は E₀ の中にしか現れない。試験文脈は完全に任意なので、**受理語中のどの隣接 `bc`/`cb` も、その後方に非空の区切りと十分な a 連があれば、一定コスト ±s で交換できる。** 中間語が Rot 核であることは一度も要求しない。Q は a でもよい（末尾 2 文字の交換では a を 1 個 Q に回す）。

以下「i の標準選択」は F+ で `i=1+max(0,−s)`、F− でも同じ i（交換前の指数は `i+s=1+max(0,s)`）。いずれも `≤1+|s|≤M`。

### 補題S（スライド補題）［PROVED］

`x₁,m,y₂` を非空語、`alph(m)⊆alph(x₁)` かつ `alph(m)⊆alph(y₂)` とする。ある `P₀,R₀` について `P₀·x₁·m·m·y₂·R₀ ∈ L` ならば、任意の P,R と任意の非空 Q について

`P·x₁·Q·m·y₂·R ∈ L ⟺ P·x₁·m·Q·y₂·R ∈ L`。

| 項目 | 内容 |
|---|---|
| 比較タプル | `x=(x₁, m·y₂)`、`y=(x₁·m, y₂)` |
| 実内容型 | 第1成分 `alph(x₁)=alph(x₁m)`、第2成分 `alph(my₂)=alph(y₂)`（仮定より） |
| 共通文脈 E₀ | `(P₀, m, R₀)`、中央 m 非空 |
| E₀[x]=E₀[y] | `P₀·x₁·m·m·y₂·R₀`（**同じ語の二通りの切り方**） |
| 試験文脈 E₁ | `(P, Q, R)` |
| E₁[x], E₁[y] | `P·x₁·Q·m·y₂·R`、`P·x₁·m·Q·y₂·R` |

AB16 の「b 冪移送 `(b,bb)/(bb,b)`」は `x₁=m=y₂=b` の特殊例である。

### 矛盾の機構

m を 1 文字 `x∈{b,c}`、Q をもう一方の文字 y とすると、補題S は「x と y の隣接交換が **a コスト 0**」を与え、補題F は同じ交換が **a コスト ±s** であることを与える。同じ b/c 語に異なる末尾 a 指数が付くので、U_shift から `s=0`。

したがって必要なのは次の二つだけである。

- **(H1)** `X·xx·Y` を因子に持つ受理語（X,Y は x を含む）。a 指数は問わない。
- **(H2)** `X·xy·Y` または `X·yx·Y` を因子に持ち、後方に十分な a 連のある受理語。

### 補題X（順序交換）［PROVED］

`N≥2M+2` なら `κ′κa^t ∈ L`。

1 穴合同 **G**：`a^iκ ↔ a^{i+s}κ′`（共通文脈 `(ε,a^{λ−i})`、型は双方 `{a,b,c}`）、および `κa^j ↔ κ′a^{j+s}`（共通文脈 `(a^{λ−j},ε)`）。いずれも `i,i+s≥1`、E₀ の二語は単独 Rot 語。

`i=j=1+max(0,−s)` とする。Rot 合同で `a^iκκ′a^{t−i}∈L`。G を `E₁=(ε, κ′a^{t−i})` で使い `a^{i+s}κ′κ′a^{t−i}∈L`。次に第二の κ′ に G の逆向きを `E₁=(a^{i+s}κ′, a^{t−i−j−s})` で使い `a^{i+s}κ′κa^{t−i−s}∈L`。必要な室は `i+j+s=2+|s|≤t`、すなわち `N≥δ+δ′+2+|δ−δ′|=2M+2`。Rot 合同で a を右へ集めて `κ′κa^t∈L`。∎

## 4. 定理1：`bbccc / bcbcc`（問題A）［PROVED］

**定理1。** §2 の仮定の下、`κ=bbccc`、`κ′=bcbcc`（`p=b, q=cc`）とする。
`N ≥ 2max(δ,δ′)+1` ならば `δ=δ′`。（`C=2, C′=1`。最適性は主張しない。）

**証明。** `i=1+max(0,−s)`。`s≥0` なら i=1、`s<0` なら `i=1+δ′−δ` で、`t≥i ⟺ N≥2δ′+1`。よって仮定から `1≤i≤t`、`i≤λ`、`i≤λ′`。

**手順1（宿主）。** Rot 合同で `κκ′a^t = bbccc·bcbcc·a^t ∈ L`。

**手順2（F+ を 1 回）。** `E₁=(bbccc, bcc, a^{t−i})`。
`bbccc·bc·bcc·a^i·a^{t−i} ∈ L ⟹ bbccc·cb·bcc·a^{t+s} = bbccccbbcc·a^{t+s} ∈ L`。
これが (H1)：因子 `cccc`。`t+s≥i+s≥1`。

**手順3（スライド、`x₁=m=y₂=c`）。**

| 項目 | 内容 |
|---|---|
| 比較タプル | `x=(c, cc)`、`y=(cc, c)`、型 `({c},{c})` |
| E₀ | `(bb, c, bbcc·a^{t+s})` |
| E₀[x]=E₀[y] | `bb·cccc·bbcc·a^{t+s}`（手順2） |
| E₁ | `(b, b, a^{λ′})`、中央 b 非空 |
| E₁[x] | `b·c·b·cc·a^{λ′} = κ′a^{λ′} ∈ L`（Rot） |
| 導かれる第四語 | `E₁[y] = b·cc·b·c·a^{λ′} = bccbc·a^{λ′} ∈ L` |

**手順4（F+ をもう 1 回）。** `E₁=(bc, c, a^{λ′−i})`。
`bc·bc·c·a^{λ′} = κ′a^{λ′} ∈ L ⟹ bc·cb·c·a^{λ′+s} = bccbc·a^{λ′+s} ∈ L`。

**手順5。** `bccbc·a^{λ′}` と `bccbc·a^{λ′+s}` がともに L に属し、両指数は正。`s≠0` なら `0<|s|<N` で U_shift に反する。よって `s=0`。∎

**使った受理語の出所。** 単独 Rot 語（E₀ of F、手順3の E₁[x]、手順4）と、仮定された実在宿主（手順1）のみ。宿主は (H1) の `cccc` を作る一箇所でだけ使う。中間語 `bbccccbbcc`、`bccbc` が Rot 核であるとは仮定していない。

**最小数値例。** `N=5, δ=2, δ′=1` は `t=2<3` で仮定外。`N=7, δ=2, δ′=1`（`s=1, t=4, λ=5, λ′=6`）：手順2 で `bbccccbbcc a^5`、手順3 で `bccbc a^6`、手順4 で `bccbc a^7`、U_shift で `a^6∈L` となり `a^7` の最短性に反する。

## 5. 定理1′：`bbbcc / bbcbc`［PROVED］

**定理1′。** `κ=bbbcc`、`κ′=bbcbc`（`p=bb, q=c`）。`N ≥ 2max(δ,δ′)+2` ならば `δ=δ′`。

**証明。** 定理1 の鏡像。

1. 補題X で `κ′κa^t = bbcbc·bbbcc·a^t ∈ L`（ここで `+2` を使う）。
2. F+、`E₁=(bbc, bbbcc, a^{t−i})`：`bbc·bc·bbbcc·a^t ⟹ bbc·cb·bbbcc·a^{t+s} = bbccbbbbcc·a^{t+s} ∈ L`。因子 `bbbb`。
3. スライド：`x=(bb,b)`、`y=(b,bb)`、型 `({b},{b})`。`E₀=(bbcc, b, cc·a^{t+s})`、`E₀[x]=E₀[y]=bbcc·bbbb·cc·a^{t+s}`。`E₁=(ε, c, c·a^{λ′})`、`E₁[x]=bb·c·b·c·a^{λ′}=κ′a^{λ′}∈L`。よって `E₁[y]=b·c·bb·c·a^{λ′}=bcbbc·a^{λ′}∈L`。
4. F+、`E₁=(b, bc, a^{λ′−i})`：`b·bc·bc·a^{λ′} ⟹ b·cb·bc·a^{λ′+s} = bcbbc·a^{λ′+s} ∈ L`。
5. U_shift で `s=0`。∎

補題X を使わず `κκ′` から F− を 2 回使って `bbbb` を作ることもでき、その場合の室は `N≥3M`。

## 6. 定理2：一般の枠［PROVED、定数は枠長依存］

**定理2。** `p,q∈{b,c}⁺` を任意とし、`n=|κ|=|p|+|q|+2` とする。§2 の仮定の下、

`N ≥ (n²+2n)·max(δ,δ′)` ならば `δ=δ′`。

**証明。** `n≥4` なので、ある文字 `x∈{b,c}` が κ に 2 回以上現れる。もう一方を y とする（κ は b も c も含むので y も 1 回以上）。`w₀=κκ′` における x の個数を `m≥4`、y の個数を `l≥2` とする（`m+l=2n`）。

**(a) 並べ替えの不変量。** b/c 語 w の反転数を `inv(w)=#{(i<j): w_i=c, w_j=b}` とする。`wa^e∈L` に補題F を 1 回使うと、`bc→cb` で inv が +1、指数が +s、`cb→bc` で −1、−s。交換前の指数が `2+|s|` 以上なら（Q が空になる末尾交換では a を 1 個 Q に回すため +1）、常に適用できる。したがって、指数がその閾値を割らない限り、`w₀a^t` から隣接交換の列で到達する語 V は

`V·a^{e(V)} ∈ L、 e(V)=t+s·(inv(V)−inv(w₀))`

を満たす。

**(b) 三つの語。**
- `V₁=x^m y^l`
- `V₂=x·y·x^{m−1}·y^{l−1}`
- `V₃=x·x·y·x^{m−2}·y^{l−1}`

`w₀→V₁` は高々 `m·l≤n²` 回、`V₁→V₂` は `m−1≤2n−3` 回、`V₂→V₃` は 1 回（位置 2,3 の `yx→xy`、後続 Q は非空）。合計高々 `n²+2n−2` 回。

**(c) スライド。** `x₁=m=y₂=x`、型 `({x},{x})`：

| 項目 | 内容 |
|---|---|
| 比較タプル | `(x, xx)`、`(xx, x)` |
| E₀ | `(ε, x, x^{m−4}y^l·a^{e(V₁)})`、`E₀[·]=V₁a^{e(V₁)}` |
| E₁ | `(ε, y, x^{m−3}y^{l−1}·a^{e(V₂)})` |
| E₁[(x,xx)] | `x·y·xx·x^{m−3}y^{l−1}·a^{e(V₂)} = V₂a^{e(V₂)} ∈ L` |
| 第四語 | `xx·y·x·x^{m−3}y^{l−1}·a^{e(V₂)} = V₃·a^{e(V₂)} ∈ L` |

一方 (a) から `V₃·a^{e(V₂)±s}∈L`。U_shift で `s=0`。

**(d) 室。** 経路上の指数は `t−|s|(n²+2n−2)` 以上。各交換前に `2+|s|` 以上であるには `t ≥ |s|(n²+2n−1)+2` で足りる。`t=N−2M+|s|`、`|s|≤M−1` より `N ≥ 2M+(M−1)(n²+2n−2)+2` で十分で、これは `n≥4` のとき `(n²+2n)M` 以下。∎

これで第二目標の「室の定数が `|p|,|q|` に依存してよい版」は解決した。AB16 報告 §4.7 が挙げた障害（中間核の Rot 性、反復文字の宿主）は、補題F の試験文脈が任意であることと、宿主 `κκ′` を F で並べ替えて反復文字を自前で作ることで回避される。Σ が 3 文字で `p,q` に a がないため「通過できない文字」は存在しない。

## 7. 絶対定数に向けて：局所判定法と残る義務

### 命題3（局所判定法）［PROVED］

ある x∈{b,c}、y をもう一方とし、x を含む語 X,Y があって、

- (H1) `X·xx·Y` を因子に持つ語が、`{κ,κ′}` の 2 個以下の積（a は末尾）から F 交換 k₁ 回で得られ、
- (H2) `X·xy·Y` または `X·yx·Y` を因子に持つ語が、同様の積または単独核から F 交換 k₂ 回で得られる

とする。`k=k₁+k₂` として `N ≥ 2M+(k+1)|s|+2`（粗くは `N≥(k+3)M`）ならば `δ=δ′`。

証明は §3 の機構そのもの：(H2) の語に補題S を使った結果と、F を 1 回使った結果が同じ b/c 語・異なる指数になる。積の順序は補題X（`N≥2M+2`）で自由。∎

**定理1 は `k=1`（X=Y=c、(H2) は κ′ そのもの）。**

### 系4（AB16 の別証明と定数改善）［PROVED、要独立監査］

`B=bbcc`、`C=bcbc`、`N≥2M+2`。

1. `BCa^t` に F+：`bbcc·bc·bc → bbcc·cb·bc = bbcccbbc·a^{t+s}`。
2. スライド（`x₁=c, m=c, y₂=bbc`）：`x=(c, cbbc)`、`y=(cc, bbc)`、型 `({c},{b,c})`。`E₀=(bb, c, a^{t+s})`、`E₀[x]=E₀[y]=bbcccbbc·a^{t+s}`。
3. 補題X で `CBa^t=bcbcbbcc·a^t∈L`。`E₁=(b, b, c·a^t)`：`E₁[x]=b·c·b·cbbc·c·a^t=CBa^t`。よって `E₁[y]=b·cc·b·bbc·c·a^t=bccbbbcc·a^t∈L`。
4. `CBa^t` に F+：`bc·bc·bbcc → bc·cb·bbcc = bccbbbcc·a^{t+s}∈L`。
5. U_shift で `s=0`。

既監査の `C=6` を置き換える主張ではない。別経路の証明として独立監査を求める。

### 絶対定数が未解決である理由［OPEN］

命題3 の k が枠長によらず有界に取れるかが問題である。分かっていること：

- `κ=p′αbcβq′` と書くと、`α=b` なら κ に `bb`、`β=c` なら κ に `cc`、`α=c, β=b` なら κ′ に `cc` と `bb` がある。つまり平方 `xx` は常に枢軸の隣にある。
- 困難は (H1) と (H2) で**同じ側枠 X,Y** を要求する点。X,Y を短く取ると、(H1) は「x の連続する隙間列が `(i,0,j)`」、(H2) は「`(i+1,j)` または `(i,j+1)`」という条件になる。核の隙間がすべて大きい場合（例：x の連がどれも長く、孤立した y を持たない核）、一方を他方へ移すのに隙間長に比例した回数の交換が必要になる。
- X,Y を長く取ると核の周期構造に縛られ、`bb→bc` の 1 文字差が周期と両立しない。
- m を長い語（例：交互域の `bc`）に取るスライドは有効な場合がある（`(bc)⁴` を持つ受理語があれば `bc·b·bc·bc ↔ bc·bc·b·bc` がコスト 0）。これを全核に対して一様に組む場合分けは完成していない。

**失敗した試み。**
1. 核の冪 `κ³a^{N−3δ}`（1 穴合同 `κκ≡κa^δ` で得られる）からのスライド `(z, zMz)/(zMz, z)`、`zM` は κ の共役。コスト 0 の移動は得られるが、F 側の比較に `Θ(|κ|)` 回の交換が要り、定数が枠長に依存する。
2. 核の積から直接得られる 2 穴同値（`(bc,cb)~(cb,bc)` など）。すべて「可換モデル」と整合し、矛盾を生まない。矛盾には「同じ語の二通りの切り方」（補題S 型）が本質的に必要と思われる。

反例は探索していない。絶対定数版が偽である兆候も得ていない。

## 11. 次に残る最小数学義務

1. **独立監査**：補題F の「試験文脈は任意」という読みと、補題S の型条件。この二点が正しければ定理1・1′・2 は従う。
2. **絶対定数**：命題3 の k を枠長によらず抑える。最小の未解決切片は、x の連も y の連もすべて長さ 2 以上で、交互域を持たない核（例：`κ=b^r c^r·bc·b^r c^r` は 0 回で済むので該当しない。該当候補は枢軸の両隣が長い連に埋もれる `p=…c^r b^{r}`, `q=c^{r}b^r…` 型）。ここで有界回数のスライド配置があるか、あるいは室が本当に枠長に比例して必要かを決める。
