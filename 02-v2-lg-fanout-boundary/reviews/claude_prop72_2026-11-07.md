## 2. 文法の側：場合 (ii) は V ∩ Q₂ を強制する

**補題 1** [証明済み]。一頂点（Q は任意、SUB₁ も不要）、L = L(G)。場合 (ii) が起きれば π(W) ∈ V ∩ Q₂。

*証明。* t, t′ を比較不能な印のない重い節点とし、ω_t, ω_{t′} を長さ θ 以下の A_t, A_{t′} の生成とする（(T1)）。H 報告の補題 4.1（W の最短性だけを使う）から ω_t, ω_{t′} は c を含む。(S1) から W_t := W[t ← ω_t]、W_{t′}、W_{tt′} は L(G) = L の語で、印は t, t′ の外にあるので a, b を含み、c も含む。一頂点では所属がパリクで決まるので π(W_t), π(W_{t′}), π(W_{tt′}) ∈ Q₃。(S2) から π(W) = π(W_t) + π(W_{t′}) − π(W_{tt′}) ∈ q₃ + H₃、c 成分は 0 なので π(W) ∈ V。π(W) ∈ Q₂ は明らか。∎

**系 2** [証明済み]。一頂点、L = L(G) が SUB₁ とする。
(a) V ∩ Q₂ = ∅ なら μ_{ab} ≤ 9(r+1)vθ。
(b) V ∩ Q₂ ≠ ∅ なら μ_{ab} ≤ max{9(r+1)vθ, K((2F_L − 1)Θ, Θ₀ + 3(F_L − 1)Θ)}（Θ = (3v+1)θ、Θ₀ = 3vθ）。F_L = 1 なら右辺は max{9(r+1)vθ, K(Θ,Θ₀)} ≤ max{9(r+1)vθ, 226v³θ³}。

*証明。* (a) 補題 1 から場合 (ii) は起きない。場合 (i) では、重い節点の集合（祖先について閉じる）の葉のうち、印を含むものは ≤ 2 個、印を含まないものは互いに比較不能なので ≤ 1 個。根から葉への道の上で印の集合は {a,b} ⊇ … ⊇ ∅ と単調に減り（3 値以下）、同じ値の区間ではラベルが相異なる（H 報告の補題 3.1。短絡の結果は L(G) = L の ab 語で、T の最小性に反する）。重い節点は ≤ 3·3v、N = Σ_{z 重い}(|t_{R(z)}| + Σ_{軽い子} |y(j)|) ≤ 9v(θ + rθ)。
(b) 定理 3.7 そのもの（場合 (i) は (a) と同じ、場合 (ii) は定理 3.7 の証明の場合 (ii)）。K(Θ,Θ₀) ≤ 226v³θ³ は H 報告 §5.6。∎

**注意。** (a) は Q₃ の有限・無限によらない。閉包報告の T_n（例 2.8）は V ∩ Q₂ = ∅（スクリプト S1。手計算：H₃ = ⟨(−2,1,1), (−1,−1,2)⟩、V = (5,1) + ℤ(3,−3)、Q₂ = {(1+3n,1), (1,1+3n)} の点は V に乗らない）なので、補題 3.9 によらず μ_{ab} ≤ 9(r+1)vθ が出る。

**補題 3.9 の精密化** [証明済み]。場合 (ii) で |W_t|_a + |W_t|_b ≤ B_{ab} := max{|w|_a + |w|_b : w ∈ L は abc 語} から |y(t)| ≥ |W| − B_{ab}（W_t の a,b の個数は |W| − |y(t)| + |ω_t|_{ab} ≥ |W| − |y(t)|）。t′ も同様で、y(t), y(t′) は交わらず印を含まないので 2(|W| − B_{ab}) ≤ |W| − 2、|W| ≤ 2B_{ab} − 2。よって μ_{ab} ≤ max{9(r+1)vθ, 2B_{ab} − 2}（c の個数は関係しない）。

## 3. 言語の側：構造定理

### 3.1 道具

**補題 2.4′（補題 2.4 の抽象形）** [証明済み、閉包報告の補題 2.4 の証明そのまま]。X ⊆ P₂ は空でなく
(∗) 全ての d ∈ X − X と、α, α + d ∈ P₂ の α について α ∈ X ⟺ α + d ∈ X
を満たすとする。H_X := ⟨X − X⟩。このとき
(a) 任意の x ∈ X で X = (x + H_X) ∩ P₂。
(b) H_X の階数が 2 なら、X − X は両座標が正のベクトルを含む。
(c) X が有限で |X| ≥ 2 なら H_X = ℤe、e₁e₂ < 0 で、X = {x₀ + ie : 0 ≤ i ≤ m}（m ≥ 1）＝ (x₀ + ℤe) ∩ P₂。

*証明。* 補題 2.4 の証明は Q₂ について (∗) しか使っていない（階数 0・1 の区間の議論、階数 2 の (a) 反鎖の議論、(b) 正のベクトル、(c) 持ち上げ）。(a)(b) はその主張。(c)：階数 2 なら補題 2.4 の証明の (a) で X は無限なので階数は 1（|X| ≥ 2 なので 0 でない）。H_X = ℤe で e₁e₂ ≥ 0 なら符号を取り替えて e ≥ 0 とでき、(a) から x + ke ∈ X（k ≥ 0）で X は無限。よって e₁e₂ < 0。(a) の添字の集合は区間なので最後の形。∎

**補題 R（実現された平面の差）** [証明済み]。h ∈ ℤ³ が二つの同じ支持の Q の点の差で supp h ⊆ {a,b} とする（例えば h ∈ D₂ や h ∈ D₃ ∩ E）。q ∈ Q₂、q + h ∈ Π₂ なら q + h ∈ Q₂ で h ∈ D₂。特に h ∈ D₃ ∩ E で h ≥ 0（または h ≤ 0）なら h ∈ D₂ ⊆ H₂。

*証明。* supp h ⊆ {a,b} の上で q_σ ≥ 1、q_σ + h_σ ≥ 1（両方 Π₂ の点）なので h は q で有効、(M) から q + h ∈ Q、支持は {a,b} なので Q₂。h ≥ 0 なら q + h ∈ Π₂ は自動的、h ≤ 0 なら −h（やはり実現された差）を使う。∎

**F1** [証明済み]。d, d′ ∈ 𝒫 ⇒ d + d′ ∈ 𝒫。
*証明。* q ∈ Q₃ とすると q + d ∈ Π₃ なので (M3) で q + d ∈ Q₃、同様に q + d + d′ ∈ Q₃。差 d + d′ は非負で 0 でない。∎

**F2** [証明済み]。(P⁺) が成り立たないとき、d ∈ 𝒫 で d_c = 0 なら d_a = 0 か d_b = 0。
*証明。* d ∈ D₃ ∩ E、d ≥ 0 なので補題 R で d ∈ D₂。両座標が正なら二つの ab の点が両座標で狭義に増え、(P⁺)。∎

**F3** [証明済み]。Q₃ が無限なら 𝒫 ≠ ∅（Dickson の補題：ℕ³ の無限集合は q ≤ q′, q ≠ q′ の組を含む）。

以下 §3 全体で **一頂点、SUB₁、Q₂ ≠ ∅、Q₃ 無限、(P⁺) 不成立** を仮定する（(α) は (P⁺) 不成立を使わない）。

### 3.2 場合 (α)：𝒫 が狭義に正の元 u（三座標とも正）を持つ

**命題 α** [証明済み]。
(i) Q₃ = (q₃ + H₃) ∩ Π₃。
(ii) H₃⁰ ⊆ D₃ ∩ E（H₃⁰ の全ての元が同じ高さの二点の差として実現される）。
(iii) D₂ ⊆ H₃⁰。
(iv) K₂ := H₃⁰ は許容的。従って F_L = 1。

*証明。* (i) 閉包報告の補題 2.4 (c) と同じ。⊆ は明らか。t ∈ (q₃ + H₃) ∩ Π₃、t − q₃ = Σ_{i=1}^m d_i（d_i ∈ D₃、D₃ は対称で H₃ を生成）。N·min_σ u_σ ≥ Σ‖d_i‖_∞ の N を取る。q₃ + ju ∈ Π₃ なので (M3) で q₃ + Nu ∈ Q₃。部分和 q₃ + Nu + Σ_{i≤j} d_i は成分ごとに ≥ q₃ ≥ (1,1,1) なので全て Π₃ に入り、(M3) で順に Q₃ に入る。t + Nu ∈ Q₃、t + ju ∈ Π₃（0 ≤ j ≤ N）なので −u の移動で t ∈ Q₃。
(ii) h ∈ H₃⁰。N·min u_σ ≥ ‖h‖_∞ なら q₃ + Nu と q₃ + Nu + h はともに (q₃ + H₃) ∩ Π₃ = Q₃ に入る（(i)）。両者の c 座標は等しい。
(iii) h ∈ D₂。α := q₃ + Nu（N 大）∈ Q₃ で α + h ∈ Π₃。h は Q₂ の二点の差で supp h ⊆ {a,b}、α で有効なので (M) から α + h ∈ Q₃。よって h ∈ D₃ ⊆ H₃、c 成分 0 なので h ∈ H₃⁰。
(iv) q₂ ∈ Q₂ を固定する。Q₂ − q₂ ⊆ D₂ ⊆ H₃⁰ なので Q₂ ⊆ (q₂ + H₃⁰) ∩ Π₂。逆に t = q₂ + h ∈ Π₂（h ∈ H₃⁰）なら、(ii) と補題 R で t ∈ Q₂。よって H₃⁰ は許容的で、[H₃⁰ + H₃⁰ : H₃⁰] = 1。∎

### 3.3 場合 (β)：𝒫 ≠ ∅ で狭義に正の元がない

**B1** [証明済み]。「全ての d ∈ 𝒫 で d_b = 0」か「全ての d ∈ 𝒫 で d_a = 0」のどちらか。
*証明。* d ∈ 𝒫 は狭義に正でないので、ある座標が 0。d_c = 0 なら F2 で d_a = 0 か d_b = 0。よって全ての d ∈ 𝒫 で d_a = 0 または d_b = 0。d_a > 0 の d と d′_b > 0 の d′ があれば（d_b = 0、d′_a = 0）、F1 で d + d′ ∈ 𝒫 は a, b 座標が正。c 座標が正なら狭義に正で (β) に反し、0 なら F2 に反する。∎

設定は a ↔ b の入れ替えで対称（(P⁺)、Q₂、μ_{ab}、F_L、V はすべて入れ替えで保たれる）なので、以下 **全ての d ∈ 𝒫 で d_b = 0** とする。

**B2** [証明済み]。Q₃ の b 座標の値の集合は有限。
*証明。* 無限なら b 座標が狭義に増える Q₃ の点列が取れ、Dickson の補題で i < j、q_i ≤ q_j の組がある。q_j − q_i ∈ 𝒫 の b 座標は正で、仮定に反する。∎

**B3** [証明済み]。Q₃ の b 座標が二つ以上の値を取るなら、𝒫 ⊆ {(k,0,0) : k > 0} か 𝒫 ⊆ {(0,0,l) : l > 0}。
*証明。* d ∈ 𝒫 で d_a > 0 かつ d_c > 0 とする（d_b = 0）。p, p′ ∈ Q₃、p_b < p′_b を取る。(M3) で p′ + Nd ∈ Q₃ で、N が大きければ p′ + Nd ≥ p（a, c は N で、b は p′_b > p_b）。差 p′ + Nd − p ∈ 𝒫 の b 座標は正で、仮定に反する。(k,0,0) と (0,0,l) が両方 𝒫 にあれば F1 で (k,0,l) ∈ 𝒫 となり同じく矛盾。∎

従って (β) は次の三つに分かれる：**(β-I)** Q₃ の b 座標が一つの値；**(β-II)** 二つ以上の値で 𝒫 ⊆ ℕ_{>0}(1,0,0)；**(β-III)** 二つ以上の値で 𝒫 ⊆ ℕ_{>0}(0,0,1)。

### 3.4 (β-I)

**命題 β-I** [証明済み]。H₃⁰ ⊆ H₂。従って K₂ = H₂ で F_L = 1。

*証明。* Q₃ = {(x, y₀, z) : (x,z) ∈ X}、X ⊆ P₂（座標 a, c）は無限。d ∈ D₃ は b 成分 0 で、(M3) から X は (∗) を満たす（(x,y₀,z) と (x,y₀,z) + d はともに Π₃）。補題 2.4′(a) で X = (x₀ + H_X) ∩ P₂。H₃ = {(h₁,0,h₂) : (h₁,h₂) ∈ H_X} なので H₃⁰ = ℤ(j₀,0,0)（j₀ ≥ 0）。j₀ = 0 なら終わり。j₀ > 0 のとき (j₀,0,0) ∈ D₃ を示す。
- H_X の階数が 2：補題 2.4′(b) で両座標が正の u′ ∈ X − X がある。N が大きければ x₀ + Nu′ と x₀ + Nu′ + (j₀,0) はともに (x₀ + H_X) ∩ P₂ = X に入る。
- 階数が 1（H_X = ℤg）：X は無限なので補題 2.4′(a) の添字の区間は ≥ 2 点を含み、g ∈ X − X。j₀ > 0 なので g_c = 0、g = ±(j₀,0)。
どちらでも (j₀,0,0) ∈ D₃ ∩ E は非負で、補題 R から (j₀,0) ∈ D₂ ⊆ H₂。よって H₃⁰ ⊆ H₂、[H₂ + H₃⁰ : H₂] = 1。∎

### 3.5 (β-II)

**命題 β-II** [証明済み]。H₃⁰ ⊆ H₂。従って F_L = 1。

*証明。* (1) 𝒫 ∋ (k₀,0,0)（k₀ > 0）。補題 R で (k₀,0) ∈ D₂。Q₂ は (M) により (∗) を満たし、H₂ の階数が 2 なら補題 2.4′(b) で D₂ に両座標が正の元があり (P⁺)。よって H₂ = ℤ(k₂,0)（k₂ > 0）、補題 2.4′(a) から Q₂ = (q₂ + ℤ(k₂,0)) ∩ Π₂ は q₂ と q₂ + (k₂,0) を含み、(k₂,0,0) ∈ D₂。
(2) **繊維。** f = (y,z) ∈ P₂（座標 b, c）について X_f := {x : (x,y,z) ∈ Q₃}、F := {f : X_f ≠ ∅}。(M3) と (k₀,0,0) ∈ 𝒫 から X_f は ±k₀ の移動で閉じ（ℕ_{≥1} の中で）、空でなければ無限。同じ繊維の差 (x′ − x, 0, 0) は D₃ ∩ E の符号の定まった元なので補題 R で H₂ に入り、k₂ | x′ − x。Q₂ の差 (k₂,0,0)（支持 {a}）は α_a ≥ 1、α_a + k₂ ≥ 1 の任意の α で有効なので、X_f は ±k₂ で閉じる。よって **X_f = {x ≥ 1 : x ≡ r_f (mod k₂)}**。
(3) **F は反鎖**（ℕ² の成分ごとの順序で）。f ≤ f′、f ≠ f′ なら x′ ≥ x の x ∈ X_f、x′ ∈ X_{f′} が取れ（X_{f′} は無限）、(x′ − x, f′ − f) ∈ 𝒫 の (b,c) 成分は 0 でない。B3 の 𝒫 ⊆ ℕ(1,0,0) に反する。
(4) **F は (∗) を満たす。** d ∈ F − F、d = f′ − f、x ∈ X_f、x′ ∈ X_{f′} とすると d̃ := (x′ − x, d) ∈ D₃。g ∈ F、g + d ∈ P₂ なら ξ ∈ X_g を ξ ≥ 1 + |x′ − x| に取って (ξ, g)、(ξ + x′ − x, g + d) ∈ Π₃、(M3) で後者 ∈ Q₃、g + d ∈ F。逆向きも同様（ξ′ ∈ X_{g+d} を大きく取る）。F は反鎖なので有限、B3 の仮定から |F| ≥ 2。補題 2.4′(c) で **F = {f_i := f₀ + ie : 0 ≤ i ≤ m}**、e = (e_b, e_c)、e_b e_c < 0、m ≥ 1。
(5) **剰余は等差的。** 0 ≤ i, j, i′ ≤ m、i′ + j − i ∈ [0,m] とする。x ∈ X_{f_i}、x′ ∈ X_{f_j} の差 d̃ = (x′ − x, (j − i)e) は、ξ ∈ X_{f_{i′}}（ξ ≥ 1 + |x′ − x|）での (ξ, f_{i′}) で有効なので ξ + x′ − x ∈ X_{f_{i′+j−i}}。よって r_{i′+j−i} ≡ r_{i′} + r_j − r_i (mod k₂)。j = i + 1 とすると r_{i′+1} − r_{i′} ≡ r_{i+1} − r_i なので **r_i ≡ r₀ + iδ**（δ := r₁ − r₀）。
(6) D₃ の元は (x′ − x, (j − i)e)、x′ − x ≡ (j − i)δ (mod k₂) の形なので、群 Γ := {(νδ + μk₂, νe) : ν, μ ∈ ℤ}（a 座標と (b,c) 座標に分けて書いた）に入る。H₃ ⊆ Γ。Γ ∩ E では νe_c = 0（e_c ≠ 0）から ν = 0。よって H₃⁰ ⊆ ℤ(k₂,0,0) = H₂。∎

### 3.6 (β-III)：線分上の柱

**命題 β-III（構造）** [証明済み]。(β-III) では次が成り立つ。
(a) f ∈ P₂（座標 a, b）について Z_f := {z : (f,z) ∈ Q₃}、F := {f : Z_f ≠ ∅} とすると、F は反鎖で **F = {f_i := f₀ + ie : 0 ≤ i ≤ m} = (f₀ + ℤe) ∩ P₂**、e = (s, −t)、s, t ≥ 1、m ≥ 1。
(b) P_c := {l > 0 : (0,0,l) ∈ 𝒫}、g′ := gcd P_c とすると、各 Z_f は **(z_f + g′ℤ) ∩ ℕ_{≥1}**（剰余類の全体）。
(c) z_i := z_{f_i} について z_i ≡ z₀ + iδ (mod g′)（δ は定数）。
(d) **H₃ = ℤ(0,0,g′) + ℤ(s,−t,δ)**、**H₃⁰ = ℤ n₀(s,−t,0)**、n₀ := g′/gcd(g′,δ)。
(e) **V = {(f₀ + νe, 0) : z₀ + νδ ≡ 0 (mod g′)}**。特に V の (a,b) 成分は f₀ + ℤe に入る。
(f) λ(a) := t、λ(b) := s、λ(c) := 0 とすると、Q₃ の全ての点は λ = λ(f₀) の水準にある。

*証明。* (a) P_c ≠ ∅（F3 と B3）。(M3) で各 Z_f は l ∈ P_c の ±l の移動で閉じるので、空でなければ無限。(β-II) の (3)(4) と同じ議論（a と c の役を入れ替える）で F は反鎖・有限・(∗) を満たし、b 座標が二つ以上なので |F| ≥ 2。補題 2.4′(c) で主張の形、e の符号を e = (s,−t) に揃える。
(b) 同じ繊維の差 (0,0,z′ − z) は D₃ の符号の定まった元なので ±P_c ∪ {0} に入り、Z_f − Z_f ⊆ g′ℤ。逆に z ∈ Z_f、z′ ≥ 1、z′ ≡ z (mod g′) とする。z′ − z = Σ c_i l_i（l_i ∈ P_c、c_i ∈ ℤ）と書き、正の c_i の移動（上向き、常に有効）を先に、負の c_i の移動を後に行うと、途中の値は全て ≥ min(z, z′) ≥ 1 で、(M3) から z′ ∈ Z_f。
(c) z ∈ Z_i、z′ ∈ Z_j の差 d = ((j − i)e, z′ − z) ∈ D₃。i′ + j − i ∈ [0,m] なら、ζ ∈ Z_{i′}（ζ ≥ 1 + |z′ − z|）で (f_{i′}, ζ) と (f_{i′+j−i}, ζ + z′ − z) はともに Π₃、(M3) で後者 ∈ Q₃。よって z_{i′+j−i} ≡ z_{i′} + z_j − z_i、j = i + 1 として δ は i によらない。
(d) (c) から D₃ ⊆ Γ := {(νe, νδ + μg′) : ν, μ ∈ ℤ} = ℤ(e,δ) + ℤ(0,0,g′)（群）。逆に (0,0,l) ∈ D₃（l ∈ P_c）なので (0,0,g′) ∈ H₃、(e, z′ − z) ∈ D₃（z ∈ Z₀、z′ ∈ Z₁、z′ − z ≡ δ）なので (e,δ) ∈ H₃。よって H₃ = Γ。Γ ∩ E = {(νe,0) : νδ ≡ 0 (mod g′)} = ℤn₀(e,0)。
(e) q₃ = (f₀, z₀′)（z₀′ ∈ Z₀）として q₃ + Γ の c 成分 z₀′ + νδ + μg′ が 0 になる条件。
(f) λ(e) = ts − st = 0。∎

**定理 S(β-III)** [証明済み]。(β-III) で V ∩ Q₂ ≠ ∅ なら F_L = 1。さらに Q₂ ⊆ x + ℤn₀e（x ∈ V ∩ Q₂）で、a と b を含む全ての L の語は (f) の λ の同じ水準にある。

*証明。* x ∈ V ∩ Q₂。(e) から x = f₀ + i*e ∈ ℕ²_{≥1} なので (a) で 0 ≤ i* ≤ m、すなわち x ∈ F。
**(K)** k ∈ ℤ、i* + kn₀ ∈ [0,m] なら x + kn₀e ∈ Q₂。実際、kn₀δ ≡ 0 (mod g′) なので (c)(b) から Z_{i*} = Z_{i*+kn₀}、共通の高さ z で (x,z), (f_{i*+kn₀}, z) ∈ Q₃、(kn₀e, 0) ∈ D₃ ∩ E。x と x + kn₀e = f_{i*+kn₀} はともに Π₂ なので補題 R。
- **|Q₂| = 1**：(K) から i* + kn₀ ∈ [0,m] の k ≠ 0 はない。K₂ := H₃⁰ = ℤn₀e について (x + K₂) ∩ Π₂ = {f_{i*+kn₀} : i* + kn₀ ∈ [0,m]} = {x} = Q₂（(a) の F = (f₀ + ℤe) ∩ P₂ を使う）。許容的で [K₂ + H₃⁰ : K₂] = 1。
- **|Q₂| ≥ 2**：補題 2.4′(b) と (P⁺) 不成立から H₂ = ℤh（階数 1）、Q₂ = (x + ℤh) ∩ Π₂ で、h の符号を選べば x + h ∈ Q₂。h は Q₂ の差（支持 ⊆ {a,b}）で、z ∈ Z_{i*} の (x,z) で有効、(M) で (x + h, z) ∈ Q₃。よって x + h ∈ F、h = je（j ≠ 0、i* + j ∈ [0,m]）、z ∈ Z_{i*+j} から z_{i*} ≡ z_{i*+j}、jδ ≡ 0 (mod g′)、n₀ | j。|n₀| ≤ |j| なので i* + sgn(j)n₀ は i* と i* + j の間にあり [0,m] に入る。(K) で x + sgn(j)n₀e ∈ Q₂、n₀e ∈ D₂ ⊆ ℤje、j | n₀。よって |j| = n₀、H₂ = ℤn₀e = H₃⁰、K₂ = H₂（補題 2.4 で許容的）で指数 1。
最後の主張：どちらの場合も Q₂ ⊆ x + ℤn₀e ⊆ f₀ + ℤe で λ(e) = 0、(f) と合わせて Q₂ ∪ Q₃ は λ の一つの水準にある。∎

### 3.7 構造定理

**定理 S** [証明済み]。一頂点、L が SUB₁、Q₂ ≠ ∅、Q₃ が無限、(P⁺) が成り立たないとする。
1. (α)・(β-I)・(β-II) では F_L = 1。
2. (β-III)（Q₃ の a,b 成分が負の傾きの線分上の有限集合 F で、Q₃ の非負の差は全て (0,0,l)）では、V ∩ Q₂ ≠ ∅ ⇒ F_L = 1。
3. 従って常に **V ∩ Q₂ ≠ ∅ ⇒ F_L = 1**。

*証明。* F3 で 𝒫 ≠ ∅。(α) なら命題 α。そうでなければ B1（必要なら a ↔ b を入れ替える）、B3 で (β-I)〜(β-III) のどれかになり、命題 β-I・β-II と定理 S(β-III)。∎

**依頼文 §2 課題1 の (S) との対応。** (S) の「(P⁺) が成り立つか、F_L が簡単な量で抑えられる」は、そのままの形では**偽**（例 4.1 の E_N は F_L = ⌈N/2⌉ で、Q₃ の極小元は (1,2,1), (2,1,2) と N によらない）。正しい形は「V ∩ Q₂ ≠ ∅ なら F_L = 1、V ∩ Q₂ = ∅ なら文法の側で場合 (ii) が起きない」であり、二つ合わせて (S′) が出る。

## 5. 補題 W：一つの重みの水準（比によらない上界）

**補題 W** [証明済み]。G は既約・線形・非削除、ランク ≤ r（r ≥ 1）、v 個の非終端、θ = θ_loc。λ(a) = α ≥ λ(b) = β ≥ 1、λ(c) = 0（整数。α < β なら a と b を入れ替える）とし、**L(G) の a と b を両方含む全ての語が同じ λ の値 C を持つ**とする。L(G) が ab 語を持てば
μ_{ab}(L(G)) ≤ max{3vθ², 7(r+1)v²θ²} = 7(r+1)v²θ²。
代入可能性・一頂点・ファンアウトは使わない。

*証明。* W を最短の ab 語、T をその導出で (|W|, 節点数) について辞書式に最小のものとする。
