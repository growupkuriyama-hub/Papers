## 1. 背景（要点）

- 型付け s: Σ⁺ ↠ S を固定し、空でない組の成分を型が等しいときだけ比べます。C_{f,s} は (f,s)-組代入可能なファンアウト f 以下の MCFL のクラスです。(2,s)-組代入可能とは、d = 1, 2 について、成分ごとに同じ型の d 組 x, y が共通の許容文脈（内部の区切りは空でない）で E[x], E[y] ∈ L なら、全ての許容文脈 F で F[x] ∈ L ⟺ F[y] ∈ L となることです。
- `cor:distribution-representatives` により、各型付き非終端の代表の長さ τ が ‖G‖ と θ̄ の多項式なら、作用素 B_{2,s} の特徴データは多項式です。
- `prop:sl-reduction` により、「ファンアウト2で境界が LG から動くか」は「内容型付け c_Σ が全ての Σ で多項式データを持つか」と同値です。二文字 Σ = {a, b} はその最初の段です。

## 2. 前回までに分かったこと（二文字の内容型付け c、ファンアウト2）

- **補題2.1（a 塊の再配分）**：ある語に a⁴ が現れれば、所属は a 骨格（a の塊を一文字に潰した語）と |w|_a だけで決まる。
- 浅い場合・Parikh 飽和・場合 I（a⁴ と b⁴ がともに現れ、飽和でない）は多項式（場合 I は t_typ ≤ 117(r+1)|V|θ̄）。四つの場合で全てを覆う。
- **場合 II**（a の深い挿入があり、b⁴ が無く、飽和でない）では、問題は型 ({a})、({a},{a})、({a},{b})、({b},{a}) の型付き非終端だけで、それは一穴の量
  P_a(C) = min{ k ≥ 1 : C[aᵏ] ∈ L }（C は固定部分の長さ ≤ θ̄+3 の一穴文脈）
  に帰着する。上界は P_a(C) ≤ δ_L（同じ骨格で a の個数が違う二語の差の最小値。差が一つも無ければ「a 剛」）と、P_a(C) ≤ (θ+4)(θ+5)v(θ + r·max{θ, Π_G})（Π_G は文法が作る純な a の組の最短の長さ）。
- **止まった場所**：a 剛（または δ_L が超多項式）で、Π_G と塊の数が超多項式の場合。純な a の穴の最短の k を、文法の短縮（短い組 ω_B は b を含む）と、内容 {a,b} の組の交換（純な側と内容が違うので直接は比べられない）の二つだけで抑える議論が無い。

## 3. 問い

> **場合 II で、P_a(C) は ‖G‖ と θ̄ の多項式で抑えられるか。**

- **(肯定・推奨)** 抑えられることの証明。これで「Σ = {a, b} の内容型付けはファンアウト2で多項式データを持つ」が完結します。最後に、全体の定理を一つの文として述べ、定数（Σ = {a,b}、r_max への依存）と作用素（B^{≤r}_{2,c} と B_{2,c}）を明記してください。
- **(否定)** 前回の §6.2 の条件 1–7 を満たす族 (L_n, G_n)（‖G_n‖・θ̄ が n の多項式、ある P_a(C) が超多項式）。L_n ∈ C_{2,c} の証明（d = 1 と 2 の両方）を必ず付けてください。

## 4. 手がかり（使う前に自分で確かめてください）

1. **場合 II の言語の正規形**：b⁴ が無いので b の塊の長さは 1, 2, 3。補題2.1 により、L は「骨格 σ（b の塊の長さの列と端の形）と a の個数 N の組 (σ, N) の集合」として書けるはずです。骨格ごとの a の個数の集合 N_σ = { |w|_a : w ∈ L、骨格 σ } を定義し、a 剛 ⟺ 全ての N_σ が一点、と言い換えてください。P_a(C) は「ある骨格のもとでの N_σ の最小値」と結びつくはずです。
2. **内容 {a,b} の組で骨格をまたぐ**：純な a の組とは比べられませんが、(aⁱ b, aʲ) と (a^{i'} b, a^{j'}) のように、内容 {a,b} の成分を持つ組なら比べられます。b の塊の境界をまたぐ組の交換で、**異なる骨格の N_σ どうしの関係**（例えば差が骨格の局所的な変化だけで決まる、という加法的な形）が強制されないか調べてください。強制されるなら、N_σ は骨格の「重み」の和として書け、最小値を短い骨格で達成できる可能性があります。
3. **a 剛の場合の構造**：a 剛なら N は骨格の関数 N(σ) です。補題6.1（b の塊を2から3に伸ばす障害）と同種の交換を使って、N(σ) が骨格の局所的な書き換え（塊の長さの変更、塊の挿入・削除）でどう変わるかを制限してください。N(σ) が「各塊の長さごとの定数の和 + 定数」の形に強制されるなら、純な a の部分の長さは塊の数で抑えられ、塊の数には前回の系3.2 の議論が使えるかもしれません。
4. **文法の側**：Π_G が超多項式とは、ある非終端の純な a の組が全て長いことです。純な a の組を作る非終端の部分文法は一文字の MCFG で、その生成する長さの集合は半線形です。文法の大きさに対して、最短の元や周期の大きさがどう抑えられるか（一文字の場合の既知の結果。文献は未確認なら未確認と書く）と、場合 II の代入可能性を組み合わせられないか。
5. **長さの種類の定理**：有限の標的で語の長さが k 種類なら、全ての語の長さは θ̄ + k(k−1)|V|(‖G‖ + rθ̄) 以下。a 剛の言語で骨格の種類が少ないなら、これが直接効く可能性があります。
6. **否定の向きの仕様**：前回の §6.2 の 1–7。特に、純な a の非終端を倍増（A_i → A_{i−1} A_{i−1}）で作り、b を含む短い枝で θ̄ を小さく保つ設計が、内容 {a,b} の組の交換（手がかり2）を生き延びられるかが要点です。過去の反例の候補（括弧付き倍増族、Thue–Morse、単一の繊維、並べ替えに閉じた繊維）は全て二穴の交換で潰れています。同じ失敗をしていないか確かめてください。
