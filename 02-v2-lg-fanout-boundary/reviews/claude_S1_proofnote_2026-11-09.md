## 0. 主張

**記号.**
- Σ = {a, b}。**内容型付け** c は語をその文字の集合に写す。空でない語の型は {a}（純な a）、{b}（純な b、b⁺ と書く）、{a,b}（混合）。
- L ⊆ Σ⁺ について、D_L(x) := {(l, r) ∈ Σ\*×Σ\* : lxr ∈ L} を x の**分布**と呼ぶ。x ≡ y :⇔ D_L(x) = D_L(y)。≡ は Σ\* 上の合同関係である。分布が空の語どうしも ≡ になる。
- **C₁（ファンアウト1の型つき代入可能性）**：L ∈ C_{1,c} :⇔ 同じ型の空でない語 x, y が L の中で一つの文脈を共有すれば（D_L(x) ∩ D_L(y) ≠ ∅）x ≡ y。
- G は L の reduced・ε なしの CFG。
- **G の大きさ** ‖G‖ := |V| + Σ_{X→γ}(1+|γ|)。
- **厚さ** θ = θ̄_G：各規則 ρ について「ρ を使う導出で開始記号から導ける語の最短の長さ」を取り、その最大。
- **代表元の長さ**：非終端 A と型 t について、L_{A,t} を A の型 t の生成語の集合とする。L ∈ C_{1,c} なら L_{A,t} の語は全て ≡ である（A の一つの導出的文脈を共有するので）。
  - τ(A, t) := min{|v| : v は型 t で、L_{A,t} の語と ≡}。
  - これは論文 `main.tex` の `cor:distribution-representatives` の τ で、≡_{L,s}-類 Cl_{L,s}(A_t) の最短の元の長さにあたる。

**定理T′.** L ∈ C_{1,c}（無限でもよい）、G は L の reduced・ε なしの CFG とし、G′ を §1.2 の二分化、K := |V′| ≤ ‖G‖ + 2 とする。G′ の非終端 A が純な a の生成語を持てば

  τ(A, {a}) ≤ Ψ(K, θ)

が成り立つ。ここで Ψ(K, θ) は §7 で明示する K, θ の多項式で、ランク r によらない（粗い評価で Ψ ≤ C·K^{76}θ^{21}、C は絶対定数）。b と a を入れ替えても同じ。

**系1（最短の純な語、定理P∞-c）.** A = 開始記号とする。τ(S, {a}) は L の最短の純な a の語の長さ N（純な語が L にあれば）に等しい。従って N ≤ Ψ。s_{U,2}（純な a / b を含む）は c より粗いので C_{1,s_{U,2}} ⊆ C_{1,c} で、そこにもそのまま使える。

**系2（系 2L）.** 二文字の像が半束である型付け s（c、s_{U,2} を含む）について、L ∈ C_{1,s} は B^{≤r_max}_{1,s} と B_{1,s} の両方に対して特徴標本を持ち、その長さは ≤ poly(‖G‖, θ̄_G) で、ランクによらない（§8）。

**注意（t_typ では抑えられない）.** 論文の `prop:typed-thickness-exponential` の文法で c を b に読み替えると、次の文法 G_n ができる。

  S → SS | a | b | A₀ | ⋯ | A_n、 A₀ → a、 A_i → A_{i−1}A_{i−1} | b

L = Σ⁺、θ = 2 で、A_n の最短の純な生成語は a^{2ⁿ} なので t_typ ≥ 2ⁿ。一方 a ≡ a^{2ⁿ} なので τ = 1。定理T′ が抑えるのは τ であって、A の最短の純な生成語そのものではない。

## 1. 準備

### 1.1 消去と C.0

**補題1.1（消去）.** L ∈ C_{1,c}、x, y は同じ型、z ∈ Σ\*。zx の分布が空でなく zx ≡ zy なら x ≡ y。右からも同様。

*証明.* (l, r) ∈ D(zx) とする。zx ≡ zy なので lzyr ∈ L。従って x, y は文脈 (lz, r) を共有し、同じ型なので C₁ から x ≡ y。□

**補題1.2（C.0）.** 非終端 X に導出的文脈 (l, r)（S ⇒\* lXr）があり、u, u′ が X の同じ型の生成語なら u ≡ u′。

*証明.* lur, lu′r ∈ L なので、u, u′ は文脈 (l, r) を共有する。□

### 1.2 二分化

G の各規則 X → Y₁⋯Y_t（t ≥ 3）を補助非終端の鎖 X → Y₁Z₁、Z₁ → Y₂Z₂、…で置き換える。終端は前終端 T_a → a、T_b → b を経由させる。得られる文法を G′ とする。

- G′ の規則は X → YZ、X → Y、X → a の形。
- L(G′) = L(G)。
- G′ は reduced・ε なし。
- K := |V′| ≤ |V| + Σ(|γ| − 2)⁺ + 2 ≤ ‖G‖ + 2。
- **θ(G′) ≤ θ(G)**：補助規則を使う導出は、元の規則を使う導出と対応する。T_a → a を使う導出は、a を含む元の規則を使う導出に対応する。最短の語は元の規則の値以下。

以下 θ は θ(G′) ≤ θ̄_G と読む。

**事実1.3.** G′ のどの非終端 X も長さ ≤ θ の生成語を持つ。X を左辺とする規則を使う長さ ≤ θ の成功語の中の、その X の節点の生成語を取ればよい。X が他の規則の右辺に現れる非終端であれば、その規則を使う長さ ≤ θ の成功語から、X の導出的文脈で長さ ≤ θ のものも得られる。

### 1.3 木 T_A

以下の記号を固定する。

- A は G′ の非終端で、純な a の生成語を持つ。
- n を A の最短の純な a の生成語の長さとする。
- T_A を、生成語 a^n の A からの導出木のうち節点数が最小のものとする。
- (l, r) を A の導出的文脈で |l| + |r| ≤ θ のもの（事実1.3。A = S なら (ε, ε)）とする。

T_A の部分木を同じラベルの別の導出木に差し替えて得る語は全て A の生成語なので、l·(その語)·r ∈ L。

- 節点の生成語の長さが > θ なら**重い**、≤ θ なら**軽い**。
- 重い子を持たない重い節点を**種**と呼ぶ。

**補題1.4.**
- (a) T_A の根から葉への道でラベルは反復しない。従って道の節点は ≤ K 個。
- (b) T_A の同じラベル Y の節点は全て同じ長さ n_Y の生成語 a^{n_Y} を持つ。
- (c) 重いラベル Y（T_A に重い節点として現れるもの）は、b を含む長さ ≤ θ の生成語 ω_Y を持つ。
- (d) 種の生成語は ≤ 2θ。
- (e) 種を s 個含む部分木の生成語は ≤ s(K+2)θ。
- (f) T_A の左から右に隣り合う二つの種について、左端の位置の差は ≤ 2Kθ。
- (g) 種どうしは互いに素（一方が他方の子孫にならない）。

*証明.*
- (a) 祖先 x と子孫 y が同じラベルなら、x の部分木を y の部分木に替える。生成語が真に短くなれば、A のより短い純な生成語ができる。同じ長さなら、節点の少ない導出ができる。どちらも T_A の選び方に反する。
- (b) 二つの節点の生成語の長さが違えば、長い方を短い方に替えて A のより短い純な生成語ができる。(a) からこの二節点は祖先と子孫の関係にない。
- (c) 重い節点で使う規則 ρ について、ρ を使う長さ ≤ θ の成功語の中のその左辺 Y の節点の生成語 y は |y| ≤ θ < n_Y。y が純な a なら、T_A の Y の部分木に y の導出を差し込んで A のより短い純な生成語ができる。従って y は b を含む（b⁺ でも混合でもよい）。
- (d) 種は単位規則の節点ではない（その子は同じ生成語で重い）。G′ は二分なので、二つの軽い子の和で ≤ 2θ。
- (e) 重い節点は全て、どこかの種への道の上にある（重い子をたどれば種に着く）。従って ≤ sK 個。種でない重い節点の子は、重い子が少なくとも一つなので、軽い子は高々一つで長さ ≤ θ。全ての葉は、種の下か、種でない重い節点の軽い子の下にある。従って長さ ≤ sKθ + s·2θ。
- (f) 隣り合う種 u, v の最小共通祖先 w から u, v への二本の道（各 ≤ K 節点）を考える。u, v の間の文字は、これらの道にぶら下がる子の生成語からなる。そうした子は ≤ 2(K−1) 個である。どれかが重ければその中に u, v の間の種があることになり、隣り合うことに反する。従って間の文字は ≤ 2(K−1)θ で、u の生成語は ≤ 2θ。
- (g) 種 v が種 u の真の子孫なら、u の子のうち v を含む方は生成語が v より長いので重い。これは u が種であることに反する。□

**重い道.** X₀ := T_A の根とし、X_{i+1} := X_i の子のうち生成語の長い方（単位規則なら唯一の子）とする。X_i が種でない限り X_{i+1} は重い。

(★₀) n_{X_i} ≤ 2 n_{X_{i+1}}。

**小さい場合.**
- 根の部分木の種が ≤ K 個なら、(e) から n ≤ K(K+2)θ で定理T′ は成り立つ（τ ≤ n）。
- 以下、種は > K 個とする。i\* を「X_i の部分木が種を ≥ K+1 個含む」最大の i とする。X_{i\*} は種でない（種を ≥ 2 個含む）。X_{i\*+1} の部分木の種は ≤ K 個なので、(e) と (★₀) から
  - B₀ := n_{X_{i\*}} ≤ 2K(K+2)θ。
- n_{X_{i\*}} = n なら n ≤ 2K(K+2)θ で成り立つ。以下 n_{X_{i\*}} < n とする。
- K = 1 なら (a) から T_A は一節点で、重い節点がない。以下 K ≥ 2。

**二つの種.**
- X_{i\*} の部分木の種は、T_A の種の左から右の順序で連続した区間をなし、≥ K+1 個ある。
- その中の連続した K+1 個に鳩の巣原理を使う。(f) から、同じラベル Y の二つの種 u₁, u₂ が位置 x₁ < x₂ にあり、d := x₂ − x₁ ≤ 2K²θ。
- (g) から g₀ := d − n_Y ≥ 0（n_Y ≥ 1）。
- y₁ := n − x₁ − n_Y（u₁ の右の文字数）とおくと y₁ ≥ d。

## 2. 基底（補題R^c）

ω := ω_Y、x := x₁、y := n − x₂ − n_Y とおき、次の三語を考える。

  W₁ := a^x ω a^{g₀} ω a^y、 W₂ := a^x ω a^{d+y}、 W₃ := a^{x+d} ω a^y

それぞれ u₁ と u₂ の両方、u₁ だけ、u₂ だけを ω に替えた A の生成語で、l W_i r ∈ L。

**補題2.1（補題R^c）.**
- **(通常の場合) g₀ ≥ 1 または ω が混合**：z₀ := ωa^{g₀}、c := d とおくと a^d z₀ ≡ z₀ a^d、z₀z₀ ≡ a^c z₀。
- **(悪い場合) g₀ = 0 かつ ω ∈ b⁺**：z₀ := ωa^d、c := 2d とおくと同じ二式が成り立つ。

どちらでも z₀ は混合で、分布は空でない。また d | c。

*証明.*
- **W₁ は混合**：W₁ が b⁺ なのは x = g₀ = y = 0 かつ ω ∈ b⁺ のときだけである。そのとき a^n は u₁, u₂ の生成語の連接で、(g) から T_A の種はちょうど二つ。これは種が ≥ K+1 ≥ 3 個であることに反する。W₂, W₃ は a^d（d ≥ 1）と b を含むので混合。三語は文脈 (l, r) を共有し、同じ型なので W₁ ≡ W₂ ≡ W₃。
- **(ii) a^dω ≡ ωa^d（両方の場合）**：
  - W₂ ≡ W₃ を a^x·[ωa^{d+y}] ≡ a^x·[a^dωa^y] と読み、補題1.1 で a^x を消す（括弧の中はどちらも混合、W₂ の分布は空でない）。
  - 次に [ωa^d]a^y ≡ [a^dω]a^y の右の a^y を消す（どちらも混合、ωa^{d+y} は W₂ の因子なので分布は空でない）。
- **通常の場合**：
  - W₁ ≡ W₂ から同様に a^x と a^y を消す（残りの ωa^{g₀}ω と ωa^d は、仮定からどちらも混合）。結果は ωa^{g₀}ω ≡ ωa^d。
  - z₀z₀ = (ωa^{g₀}ω)a^{g₀} ≡ ωa^{d+g₀} = z₀a^d。
  - a^dz₀ = (a^dω)a^{g₀} ≡ ωa^da^{g₀} = z₀a^d。
  - z₀ は W₁ の因子（文脈 (la^x, ωa^y r)）なので分布は空でない。z₀ は混合（g₀ ≥ 1 か ω が混合）。
- **悪い場合**：n_Y = d。z₀ = ωa^d は W₂ の因子で、混合。前段から x ≥ 1 または y ≥ 1。
  - **y ≥ 1**：W₁ ≡ W₂ から a^x と a^{y−1} を消して ωωa ≡ ωa^{d+1}（どちらも混合、ωωa^y は W₁ の因子）。すると z₀z₀ = ωa^dωa^d ≡ ωωa^{2d}（(ii)）= (ωωa)a^{2d−1} ≡ ωa^{3d} = z₀a^{2d}。
  - **y = 0, x ≥ 1**：a^{x−1} だけ消して aωω ≡ aωa^d（どちらも混合）。すると z₀z₀ ≡ a^{2d}ωω（(ii) を使って a^d を左へ）= a^{2d−1}(aωω) ≡ a^{2d}ωa^d = a^{2d}z₀。
  - どちらの場合も (ii) から z₀a^{2d} ≡ a^{2d}z₀ と a^dz₀ ≡ z₀a^d。□

（悪い場合に素朴な ωω ≡ ωa^d は一般に偽で、付属スクリプトに多数の例がある。）

**崩壊.** 次の三つを定める。
- 語 z が**崩壊する** :⇔ z ≡ a^e z₀（e ≥ 0、d | e）。z の**価値**は v(z) := e + c。
- d の倍数の純な塊 a^R の価値は R とする。
- u がそれらの積なら val(u) := 価値の和とする。

**補題2.2（崩壊の計算）.** u が崩壊する語と d の倍数の純な塊の積で、崩壊する語を少なくとも一つ含めば u ≡ a^{val(u)−c} z₀。

*証明.* 各崩壊する語を a^{e}z₀ に替え、a^dz₀ ≡ z₀a^d を使って全ての純な塊を左へ集めると、a^E z₀^t（t ≥ 1）になる。z₀^t ≡ a^{(t−1)c}z₀ は帰納法で示せる：z₀^{t} = z₀^{t−2}(z₀z₀) ≡ z₀^{t−2}a^cz₀ ≡ a^cz₀^{t−1}（d | c）。val(u) = E + tc なので a^{E+(t−1)c}z₀ = a^{val(u)−c}z₀。□

## 3. 符号（補題C.0^c と詰め物）

**添字の範囲.** i₀ を n_{X_i} < n となる最初の添字とする。X₀ は根で n_{X₀} = n なので i₀ ≥ 1。n_{X_{i\*}} < n なので i₀ ≤ i\*。符号は i₀ ≤ i ≤ i\* についてだけ作る（単位規則のため、重い道の上部に n_{X_i} = n の節点が複数ありうる）。

i₀ ≤ i ≤ i\* について、次を定める。
- T_A の中での X_i の純な文脈を (a^{p_i}, a^{q_i}) とする。p_i + q_i = n − n_{X_i} ≥ 1。
- X_i の部分木は u₁, u₂ を含む。u₁ の X_i の部分木の中での左右の純な長さを L_i, R_i とする（L_i + R_i = n_{X_i} − n_Y ≥ n_Y ≥ 1）。
- Ω_i := a^{L_i}ω_Ya^{R_i}（X_i の部分木で u₁ を ω_Y に替えた生成語、混合）。

**補題3.1（補題C.0^c）.**
- ω_{X_i} が混合なら ω_{X_i} ≡ Ω_i。
- ω_{X_i} ∈ b⁺ で p_i ≥ 1 なら aω_{X_i} ≡ aΩ_i。
- ω_{X_i} ∈ b⁺ で p_i = 0 なら（q_i ≥ 1）ω_{X_i}a ≡ Ω_ia。

*証明.* X_i の導出的文脈 (l a^{p_i}, a^{q_i} r) から、l a^{p_i}ω_{X_i}a^{q_i}r と l a^{p_i}Ω_ia^{q_i}r は L に入る。
- 混合なら、同じ型で文脈を共有する。
- b⁺ で p_i ≥ 1 なら、aω_{X_i} と aΩ_i はどちらも混合で、文脈 (l a^{p_i−1}, a^{q_i} r) を共有する。右も同様。□

**詰め物.** s′_i, s_i ∈ [0, d] を次のように取る。
- d | L_i + s′_i。左から a を借りる場合（ω_{X_i} ∈ b⁺、p_i ≥ 1）は s′_i ≥ 1。
- 通常の場合は R_i + s_i ≡ g₀ (mod d)、悪い場合は R_i + s_i ≡ 0 (mod d) かつ R_i + s_i ≥ d。右から借りる場合（ω_{X_i} ∈ b⁺、p_i = 0）は s_i ≥ 1。

どの条件も長さ d+1 の区間 [0, d] の中で満たせる。そこで

  ẑ_i := a^{s′_i} ω_{X_i} a^{s_i}

とおく。

**補題3.2.** ẑ_i は崩壊する。ẑ_i ≡ a^{e_i}z₀ で d | e_i、価値 v_i = n_{X_i} + s_i + s′_i、|ẑ_i| ≤ θ + 2d。

*証明.* 補題3.1 と合同性から ẑ_i ≡ a^{s′_i}Ω_ia^{s_i}（借りた a は詰め物の中に含まれる）= a^{s′_i+L_i}ω_Ya^{R_i+s_i}。
- 通常の場合：R_i + s_i ≥ 0、≡ g₀ (mod d)、0 ≤ g₀ < d なので R_i + s_i = g₀ + κd（κ ≥ 0）。従って a^{s′_i+L_i}z₀a^{κd} ≡ a^{e_i}z₀、e_i := s′_i + L_i + κd。v_i = e_i + d = s′_i + L_i + R_i + s_i − g₀ + d = n_{X_i} + s_i + s′_i（d − g₀ = n_Y）。
- 悪い場合：R_i + s_i = d + κd（κ ≥ 0）なので a^{s′_i+L_i}z₀a^{κd} ≡ a^{e_i}z₀。v_i = e_i + 2d = n_{X_i} − n_Y + s_i + s′_i + d = n_{X_i} + s_i + s′_i（n_Y = d）。□

**形式的な値.** i < i₀ について v_i := n とおく（符号は作らない）。すると全ての i ≤ i\* で

  (★) v_i ≤ 2v_{i+1} + 2d、 v_i ≥ n_{X_i}

が成り立つ。i ≥ i₀ では v_i ≤ n_{X_i} + 2d ≤ 2n_{X_{i+1}} + 2d ≤ 2v_{i+1} + 2d。i = i₀ − 1 では n = n_{X_{i₀−1}} ≤ 2n_{X_{i₀}} ≤ 2v_{i₀}。i < i₀ − 1 では v_i = v_{i+1} = n。

また v_{i\*} ≤ B₀ + 2d ≤ 2K(K+2)θ + 4K²θ ≤ 10K²θ で、v_{i\*} ≥ n_{X_{i\*}} ≥ d + n_Y > d。

**目標.** u₁ だけを ω_Y に替えた語 l a^{x₁}ω_Ya^{y₁} r ∈ L を使う。
- 通常の場合：a^{x₁}ω_Ya^{y₁} = a^{x₁}z₀a^{y₁−g₀}（y₁ ≥ d > g₀）。
- 悪い場合：a^{x₁}ω_Ya^{y₁} = a^{x₁}z₀a^{y₁−d}（y₁ ≥ d）。

右の指数を qd + ρ（0 ≤ ρ < d）、x₁ + qd = e\* + ρ′（d | e\*、0 ≤ ρ′ < d）と書く。a^{qd} を左へ移して

  l_ctx a^{e\*} z₀ r_ctx ∈ L、 l_ctx := l a^{ρ′}、 r_ctx := a^{ρ} r、

V\* := e\* + c とおくと、**V\* = n − ρ − ρ′**（両方の場合に x₁ + n_Y + y₁ = n から計算できる）。

## 4. 周期と所属の判定

**補題4.1（補題Π）.** P₀ := {p ≥ 0 : a^pz₀ ≡ z₀} とおく。
- (a) P₀ = {0} か、ある p₀ ≥ 1 について P₀ = p₀ℕ。
- (b) l′ a^{f}z₀ r′ ∈ L となる f ≥ 0 があれば、F(l′, r′) := {f ≥ 0 : l′a^fz₀r′ ∈ L} について次が成り立つ。
  - P₀ = {0} なら F は一点。
  - そうでなければ F = {f ≥ 0 : f ≡ f_min (mod p₀)}。

*証明.* a^fz₀（f ≥ 0）は全て混合（z₀ が混合）。
- (a) 加法で閉じることは合同性から。差で閉じること：p < q ∈ P₀ なら a^p z₀ ≡ z₀ ≡ a^p(a^{q−p}z₀)。a^pz₀ の分布は空でない（≡ z₀）ので、補題1.1 で a^p を消して a^{q−p}z₀ ≡ z₀。
- (b) f < f′ ∈ F なら、a^fz₀ と a^{f′}z₀ は文脈 (l′, r′) を共有するので ≡。a^fz₀ の分布は空でないので、補題1.1 で a^f を消して f′ − f ∈ P₀。逆に f ∈ F、p ∈ P₀ なら f + p ∈ F。また f ≥ p₀ なら a^fz₀ = a^{f−p₀}(a^{p₀}z₀) ≡ a^{f−p₀}z₀ なので f − p₀ ∈ F。□

D := lcm(d, p₀) とおく（P₀ = {0} なら D := ∞）。

**補題4.2（mod D での所属）.** u が補題2.2 の形の語（崩壊する語を少なくとも一つ含む）なら

  l_ctx u r_ctx ∈ L ⇔ val(u) ≡ V\* (mod D)

（D = ∞ なら等号）。

*証明.* 補題2.2 から u ≡ a^{val(u)−c}z₀ で、val(u) − c ≥ 0。従って左辺 ⇔ val(u) − c ∈ F(l_ctx, r_ctx)。e\* ∈ F なので、補題4.1 (b) からこれは val(u) − c ≡ e\* (mod p₀) と同値（P₀ = {0} なら等号）。val(u) と V\* = e\* + c はどちらも d の倍数なので、mod p₀ と mod d の同時の合同、すなわち mod D と同値。□

**補題4.3（補題S′₀）.** P₀ ≠ {0} なら a ≡ a^{1+p₀}。従って、全ての k ≥ 1 について a^k ≡ a^{k′} となる 1 ≤ k′ ≤ p₀ がある。

*証明.* (l′, r′) を z₀ の文脈とする。a^{p₀}z₀ ≡ z₀ と a^{2p₀}z₀ ≡ z₀ から l′a^{p₀}z₀r′, l′a^{2p₀}z₀r′ ∈ L。a と a^{1+p₀} を文脈 (l′a^{p₀−1}, z₀r′) に入れると、この二語になる。二語はどちらも型 {a} なので C₁ から a ≡ a^{1+p₀}。後半は合同性から、a^{1+p₀} を a に替える操作を繰り返す。□

（A = S の場合、これと最短性から「N ≤ p₀」が出る：a^N の中の a^{1+p₀} を a に替える。）

## 5. 計数（定理C\* の mod D 版）

**命題5.1.** 次を仮定する。
- 崩壊する語 z_1, …, z_M（M ≥ 6）があり、|z_j| ≤ λ。その価値 w_1, …, w_M の部分和は全て相異なり、総和 Σ := Σ_j w_j < D。
- 崩壊する語と d の倍数の純な塊の固定の積 Q があり、Σ + val(Q) = V\*。

このとき全ての置換 π について w_π := l_ctx z_{π(1)}⋯z_{π(M)} Q r_ctx ∈ L で、m := |w_π| とおくと

  C(M+1, j) ≤ (M+1)·K·(m+1)²·(Mλ+1)²

を満たす j ∈ (M/3 − 1, 2M/3] がある。特に 3^{M/3−1} ≤ (M+1)K(m+1)²(Mλ+1)²。

*証明.*
- **所属**：w_π ∈ L は補題4.2 から（val = V\*）。
- **中間節点**：
  - w_π の G′ での導出木を一つ取り、単位規則の節点を縮めて二分木と見る。
  - 節点の**重み**を「その生成語の区間の中に最初の文字がある符号 z_{π(k)} の個数」とする。葉の重みは ≤ 1、根の重みは M。
  - 根から重い方の子をたどり、初めて重み ≤ 2M/3 となる節点 u を取る。その重み κ は親（重み > 2M/3）の半分以上なので κ > M/3。u のラベルを X、生成語の区間を [p, q) とする。
- **内側の集合**：
  - I(π) を、[p, q) に完全に含まれる符号の添字 j の集合とする。添字は符号 z_j の番号で、π での位置ではない。
  - 区間の中に最初の文字がある符号は、I(π) の符号と、右端をまたぐ高々一つの符号だけである。従って M/3 − 1 < κ − 1 ≤ |I(π)| ≤ κ ≤ 2M/3。
- **記録**：
  - 記録は、X、p、q、「左端をまたぐ符号の (番号 j, ずれ o)」または「なし」、「右端をまたぐ符号の (番号 j′, ずれ o′)」または「なし」の組。
  - 端が l_ctx の中、Q r_ctx の中、符号の境目にあるときは「なし」とする。
  - 記録の数は ≤ K(m+1)²(Mλ+1)²。
- **同じ記録なら内側が同じ**：
  - π, π′ が同じ記録を持つとする。π の木の u の部分木を、π′ の木の対応する節点 u′（同じラベル X、同じ区間）の部分木に替えると、G′ の導出木になる。その語 w_π[0,p)·w_{π′}[p,q)·w_π[q,m) は L に入る。
  - またぎの番号とずれが一致するので、この語は l_ctx·u″·Q r_ctx と書ける。ここで u″ =（π の左の外側の符号）z_j（π′ の内側の符号）z_{j′}（π の右の外側の符号）で、端が l_ctx や Q r_ctx の中にある場合も同様に読める。
  - 区間の端が両方 Q r_ctx の中にあることはない（κ ≥ 2）。
  - u″ は符号の積（重複・欠落を許す）で、符号を含む。補題4.2 から val(u″) + val(Q) ≡ V\* = Σ + val(Q) (mod D)、すなわち Σ_{j∈I(π′)} w_j ≡ Σ_{j∈I(π)} w_j (mod D)。
  - 両辺は [0, Σ) ⊂ [0, D) にあるので整数として等しい。部分和が相異なることから I(π′) = I(π)。
- **数え上げ**：
  - 記録と I が決まると、π は I の符号の並べ方（|I|! 通り）と、残りの符号（またぎを除く）を左右に分けて並べる方法（≤ (M − |I| + 1)! 通り）で決まる。
  - 従って M! ≤ #記録 · max_j j!(M−j+1)!、すなわち C(M+1, j)/(M+1) ≤ K(m+1)²(Mλ+1)² となる j = |I| がある。
- **二項係数**：
  - n′ := M+1、j′ := min(j, n′−j) とおく。n′ − j ≥ M/3 + 1 なので j′ > M/3 − 1、また j′ ≤ n′/2。
  - j′ ≤ n′/3 なら C(n′, j′) ≥ (n′/j′)^{j′} ≥ 3^{j′} ≥ 3^{M/3−1}。
  - n′/3 < j′ ≤ n′/2 なら、単峰性から C(n′, j′) ≥ C(n′, ⌊n′/3⌋) ≥ 3^{⌊n′/3⌋} ≥ 3^{M/3−1}（⌊(M+1)/3⌋ ≥ M/3 − 1/3）。□

（記録の論証は導出木の差し替えだけを使い、C.0 も L の有限性も使わない。L の性質を使うのは補題4.2 だけである。）

## 6. 符号の選択と埋め草

λ := 5K²θ、B₁ := 14K²θ とおく。2θ + 2d ≤ λ、v_{i\*} ≤ B₁ である。

**(S) 超増加の選択.** Λ := min(V\*, D) とおく。
- v_{i\*} > Λ/2 なら M := 0 とし、Λ < 2v_{i\*} ≤ 2B₁。
- そうでなければ i\* を取り、以後「現在の添字より小さい添字で、値が 2 × 現在の値を初めて超えるもの」を次の候補とする。候補が Λ/2 を超えるか、候補がなければ止める。

性質は次のとおり。
- **候補は現在の値の 6 倍以下**：候補を i とすると、i+1 の値は ≤ 2 × 現在の値（i+1 は現在の添字そのものか、飛ばした添字）。(★) から v_i ≤ 2v_{i+1} + 2d ≤ 4·現在 + 2d ≤ 6·現在（現在 ≥ v_{i\*} > d）。
- **取る値は全て実の符号**：形式的な値 n は > Λ/2（Λ ≤ V\* ≤ n）なので取られない。従って取る添字は ≥ i₀。
- **止まったときの最後の値**：候補が Λ/2 を超えて止まれば、最後の値 > Λ/12。候補がなければ v₀ = n ≤ 2 × 最後の値なので、最後の値 ≥ n/2 ≥ Λ/2。
- 取った M 個の値は超増加なので、部分和は相異なり、総和 Σ < 2 × 最後の値 ≤ Λ ≤ D。
- 最後の値 ≤ B₁ 6^{M−1} なので **Λ < 12 B₁ 6^{M−1}**（M ≥ 1）。

**(Q) 貪欲な埋め草.** M ≥ 1 とし、X := V\* − Σ とおく。X ≥ 0 で d の倍数である。
- i = i₀, …, i\* の順に q_i := ⌊X/v_i⌋ 個の ẑ_i を Q に加え、X を減らす。
- q_{i₀} ≤ 1：X < V\* ≤ n ≤ 2v_{i₀} から。
- i > i₀ では、直前に X < v_{i−1} ≤ 2v_i + 2d なので q_i < 2 + 2d/v_i ≤ 2 + 4K²（v_i ≥ n_{X_i} > θ、d ≤ 2K²θ）。
- 最後の余り X < v_{i\*} ≤ B₁ は d の倍数なので、純な塊 a^X として Q に加える。
- i\* − i₀ + 1 ≤ K なので |Q| ≤ (1 + (K−1)(2+4K²))λ + B₁ ≤ (5K³ + 3)λ。val(Q) + Σ = V\*。

**長さ.** m = |l_ctx| + |r_ctx| + Σ|z_j| + |Q| ≤ (θ + 2d) + Mλ + (5K³+3)λ ≤ (5K³ + M + 4)λ。

## 7. 定理T′ の証明の結び

M\*(K, θ) を、3^{M/3−1} ≤ (M+1)K((5K³+M+4)λ+1)²(Mλ+1)² を満たす最大の整数 M ≥ 6 とする（なければ 5）。右辺は M の多項式なので M\* = O(log(Kθ)) である。

  Φ(K, θ) := 12 B₁ 6^{max(M\*, 5)}、 Ψ(K, θ) := max{2K(K+2)θ, Φ(K, θ) + 4K²θ}

とおく。

- §6 の M について、M ≥ 6 なら命題5.1 から M ≤ M\*。M ≤ 5 または M = 0 でも、Λ < 12B₁6^{max(M,1)−1} ≤ Φ。
- **Λ = V\* の場合**：n = V\* + ρ + ρ′ < Φ + 2d ≤ Φ + 4K²θ。τ(A, {a}) ≤ n。
- **Λ = D < V\* の場合**：D は有限なので P₀ ≠ {0}。補題4.3 から a^n ≡ a^{n′}、1 ≤ n′ ≤ p₀ ≤ D < Φ。a^{n′} は型 {a} で A の純な生成語 a^n と ≡ なので、τ(A, {a}) ≤ n′。
- §1.3 の小さい場合と合わせて τ(A, {a}) ≤ Ψ(K, θ)。∎

**次数.** 6^{M\*} = (3^{M\*/3})^{3 log₃ 6} で、3 log₃ 6 ≈ 4.89。不等式の右辺の K の次数は 1 + 2·5 + 2·2 = 15、θ の次数は 4 なので、Ψ ≲ K^{2+15·4.89}θ^{1+4·4.89}·(log)^{O(1)} ≈ K^{75.4}θ^{20.6}。指数は最適化していない。

## 8. 系の証明

**系1.** A = S、(l, r) = (ε, ε) とする。S の純な生成語は L の純な語で、τ(S, {a}) は a^N と ≡ な純な語の最短の長さである。そうした語は L に入る（(ε, ε) ∈ D(a^N)）ので、長さは ≥ N。従って τ = N ≤ Ψ。s_{U,2} について：c で同じ型なら s_{U,2} でも同じ型なので、s_{U,2} の C₁ の条件は c の条件を含み、C_{1,s_{U,2}} ⊆ C_{1,c}。□

**補題8.1（混合の型、代入可能性不要）.** G′ の非終端 A が混合の生成語を持てば、長さ ≤ 3Kθ + 2 の混合の生成語を持つ。

*証明.*
- 混合の生成語の A からの導出木のうち、節点数最小のものを取る。a の葉と b の葉を一つずつ印し、根からの二本の道の和集合（骨格）を考える。骨格は、根から分岐点 w への道と、w から二つの葉への道からなる。
- 各区間でラベルが反復すれば、祖先の部分木を子孫の部分木に替える。根から w への区間なら両方の印が残る。w から a の葉への区間なら b の葉は外側にあるので残る。どちらも混合の生成語のまま節点が減り、矛盾する。従って骨格は ≤ 3K 節点。
- 骨格からぶら下がる部分木（二分なので ≤ 3K 個）を、それぞれの根の長さ ≤ θ の生成語（事実1.3）に替えると、長さ ≤ 3Kθ + 2 の混合の生成語が得られる。□

**系2の証明.**
- s を二文字の像が半束である型付けとする。半束は可換かつ冪等なので、s(w) は w の文字の集合だけで決まる。従って c で同じ型なら s でも同じ型で、C_{1,s} ⊆ C_{1,c}、また ≡_{L,c} ⊆ ≡_{L,s}（「同じ型かつ ≡」）。
- s の型つき非終端 A_t について、A の s-型 t の生成語の c-型 t′ を一つ取ると τ_s(A_t) ≤ τ_c(A_{t′})。
- τ_c(A_{t′}) ≤ Ψ（t′ が純、定理T′ とその a↔b 版）か ≤ 3Kθ + 2（t′ が混合、補題8.1）。
- 論文の `cor:distribution-representatives` を G′ に使う。G′ はランク 2 ≤ r_max、reduced・ε なし、L(G′) = L(G)。型つき非終端は ≤ 3K 個、型つき規則は G′ の規則一つあたり ≤ 9 個なので、N_typ(G′, s) ≤ 3K + 9|P′| = O(‖G‖)。θ̄_{G′} ≤ θ̄_G。
- 以上から ‖K‖₊ ≤ N_typ(G′,s)(1 + 2θ̄_{G′} + 2τ(G′,s)) + 1 = poly(‖G‖, θ̄_G) で、ランクによらない。□

（**要確認**：論文の系の仮定「reduced good な表示」の good が、二分化 G′ で保たれること。）
