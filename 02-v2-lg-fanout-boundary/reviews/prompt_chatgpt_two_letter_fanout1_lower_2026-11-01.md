## 1. 目標

Σ = {a,b}、内容型付け c = c_{a,b}（型は {a}、{b}、{a,b}）、ファンアウト1、ランク2。次を満たす族 (L_n, G_n) を作ってください。
- (i) L_n ∈ C_{1,c}（一穴の代入可能性を、内容が同じ因子どうしに限ったもの）。有限言語でも無限言語でもよい。
- (ii) G_n は L_n ∩ Σ⁺ の reduced good な文脈自由文法で、‖G_n‖ と θ̄_{G_n} が n の多項式。
- (iii) ある内容型（前回の補題1により {a} か {b}）の最短の語の長さ μ が、n について超多項式。

これができれば、`prop:rare-type` により B^{≤r}_{1,c}、B_{1,c}、および C_{1,c} 全体に特徴標本を持つ任意の集合駆動作用素で、特徴データが超多項式になります。`thm:two-letter-content`（ファンアウト2では多項式）と合わせて、**同じ型付けで、ファンアウト1は超多項式、ファンアウト2は多項式**という分離が二文字で成り立ちます。さらに L_n ∈ C_{1,s_{U,2}} も言えれば、`op:S1` が否定で解決します。

## 2. 族が満たすべき必要条件（前回までに証明済み。使う前に確かめてください）

a だけの語 a^N を稀な型とする場合（b の場合は文字を入れ替える）：
1. **混合の型は短い**（前回の補題1）：長くできるのは純な型だけ。
2. **純な語は一つ**（補題2）：有限の標的なら a だけの語は a^N ただ一つ。無限の標的でも、a^p と a^q が両方あれば a^{p+k(q−p)} が全て入る。
3. **b の個数の種類が多い**（定理3）：N > θ̄ なら、L の語の b の個数（正の値）が N/((r+1)|V|θ̄) 種類以上必要。
4. **重みが一定でない**（`prop:u1-weight-all-fanout`）：ある λ で |w|_a + λ|w|_b が一定なら μ ≤ ⌊(θ̄+1)²/4⌋。重みの値が k 種類でも、λ が多項式なら（前回の定理5）多項式で抑えられる。
5. **語の長さの種類が多い**（Astra §3.6）：有限の標的で語の長さが h 種類なら、全ての語の長さは h·θ̄ 以下。従って h ≥ N/θ̄。
6. **二穴の交換では崩れてよい**：ファンアウト2では `thm:two-letter-content` によりこの族は存在しないので、族は (2,c)-代入可能であってはならない。実際、a⁴ が現れて a の塊を再配分できないことが、族の本質的な性質になるはずです（前回 §5.2：{aa,b}⁴ では aabaaaa ∈ L、aaabaaa ∉ L）。
7. **過去の失敗**：素朴な倍増 A_i → A_{i−1}A_{i−1} | b（n = 2 で b と bb が共存）、三文字の K_n の符号化 A ↦ a, B ↦ aa, C ↦ b（n = 3 で混合の因子が衝突）。

## 3. 調べてほしいこと（優先順）

**D1（前回の §7 (ii)：符号化の一般化）**
三文字の倍増族 K_n（K_0 = {A}、K_i = B K_{i−1} K_{i−1} B ∪ C K_{i−1} C）を、A ↦ a^p、B ↦ a^q、C ↦ u（u は b を含む語）で二文字に符号化する。p, q, u を（n に依存してよい形で）選んで、全ての n で (1,c)-代入可能になるようにできるか。できないなら、どの p, q, u でも深さ有限で違反することの証明（違反の組の一般形）を示してください。特に、u を b の長い塊や、b と a の特定の並び（例：b a^j b）にして、混合の因子の偶然の一致を避けられるかを調べてください。

**D2（前回の §7 (iii)：長い純な語と、b の個数の多数の値）**
条件2〜5を同時に満たす設計の候補を、いくつかの型（例：L_{m,n} の積の構造を入れ子にしたもの、「a の塊の長さを二進数で書く」型の符号、b の個数で段数を数える型）で試し、それぞれ (1,c)-代入可能性がどの交換で崩れるか、または崩れないかを調べてください。崩れる場合は、違反の組と文脈を一般の n で示してください。

**D3（前回の §7 (i)：一穴の文脈による位置の同定）**
有限の C_{1,c} の標的で、a^N と同居する混合の語について、「b の個数が違う語の中で、同じ内容の因子が共通の文脈を持つと、何が強制されるか」を補題として定式化してください。例えば「a^N の中の位置 i で切った文脈 (a^i, a^{N−i−k}) と、混合の語の文脈が交わると、混合の語の a の塊の長さの集合に強い制約が出る」のような形。これが成り立てば、否定の向きの障害（条件8）として、あるいは肯定の向き（多項式上界）の部品として使えます。

**D4（障害が強い場合）**
D1〜D3 の結果から、条件1〜7に加えて新しい必要条件が出れば、それを証明付きでまとめてください。条件が十分に強ければ、「二文字の内容型付けはファンアウト1でも多項式データを持つ」の証明を試みてください（その場合、分離は二文字では起きず、三文字 c_{a,b,c} のファンアウト2が残る唯一の道になります）。

## 4. 計算での確認

- 小さい n で、候補の族の (1,c)-代入可能性と (1,s_{U,2})-代入可能性を全数検査してください。有限言語では分布は観察された文脈の集合に等しいので、この検査は正確です（前回のスクリプトを使ってよい）。
- D1 の符号化では、p, q と u の小さい範囲（例：p, q ≤ 4、u は長さ ≤ 4 の b を含む語）を全て試し、n = 3, 4 で通るものがあるかを表にしてください。
- 通った候補は「観察」として扱い、一般の n の証明を別に付けてください。
