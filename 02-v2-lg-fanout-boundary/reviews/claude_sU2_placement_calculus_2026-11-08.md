## 1. 補題PC（置き場所の計算）

**補題PC.** T の節点 u（ラベル B）の部分木の中に節点 v（ラベル X）があり、u の生成語の中で v の左に純な a が L 個、右に R 個あるとする。X が b を含む生成語 ω_X を持てば、B も b を含む生成語を持ち、B の任意の b を含む生成語 ω_B について

  P(ω_B) = {(x, y) : (x + L, y + R) ∈ P(ω_X)}、すなわち P(ω_X) ∩ {x ≥ L, y ≥ R} = P(ω_B) + (L, R)。

*証明.* u の部分木の中で v の部分木を X の生成語 ω_X に替えると、B の生成語 a^L ω_X a^R（b を含む）が得られる。B の b を含む生成語どうしは B の成功文脈を共有するので分布が等しい（C.0。s_{U,2} では b を含む語は全て同じ型）。従って P(ω_B) = P(a^L ω_X a^R)。右辺は定義から右の式。□

L の有限性は使わない。型付け c では ω_B と a^Lω_Xa^R の内容が違う場合（ω_B が純な b など）に比べられないので、そのままでは成り立たない。

**系PC′.** L が有限なら P(ω_S) = {(0,0)}（S は開始記号、ω_S ∈ L）。*証明.* (x,y) ≠ (0,0) なら a^xω_Sa^y と ω_S はともに L の b 語で、L の b 語は全て文脈 (ε, ε) を共有して ≡、後者は前者の真の因子になり、有限性に反する（Astra 補題0）。□

## 2. 命題DD（二重化の鎖）

**命題DD.** L は有限で L ∈ C₁、T は開始記号 E_n から始まり、各 E_j（2 ≤ j ≤ n）の節点が二つの E_{j−1} の子を持つ（E_j → E_{j−1}E_{j−1}）とし、E_1, …, E_n はどれも b を含む生成語 ω_j を持つとする（E_1 の子 E_0 は純な a だけでよい）。純な長さは n_j = 2^j（一般の葉 a^p でも同様）。このとき 1 ≤ j ≤ n−1 について

  P(ω_j) ⊇ {(x, N − 2^j − x) : 0 ≤ x ≤ N − 2^j、x は偶数}。

*証明.* 補題PC を E_j の左の子（L = 0, R = 2^{j−1}）と右の子（L = 2^{j−1}, R = 0）に当てると、2 ≤ j ≤ n で

  (E1) P_{j−1} ∩ {y ≥ 2^{j−1}} = P_j + (0, 2^{j−1})、 (E2) P_{j−1} ∩ {x ≥ 2^{j−1}} = P_j + (2^{j−1}, 0)

（P_j := P(ω_j)）。全ての P_j は対角線 x + y = N − 2^j の上にある（系PC′ と (E1)(E2) から帰納的に）。Q_j := {偶数の x の対角線の点} とおく。(i) Q_j が (E1)(E2) を満たすことは直接確かめられる（2^{j−1} は j ≥ 2 で偶数）。(ii) 強制：系PC′ の (0,0) ∈ P_n から始め、(E1)(E2) を両方向に使うと、P_{n−1} ∋ (0, 2^{n−1}), (2^{n−1}, 0)、P_{n−2} ∋ (2^{n−2}, 2^{n−1})、これを (E1) で戻すと (2^{n−2}, 2^{n−2}) ∈ P_{n−1}。一般に、j 段で x が 2^k の倍数の点が全て入れば、(E2) で上の段へ移して (E1) で戻すと 2^{k−1} の倍数の点が全て入る（k ≥ 2）。従って k = 1 まで下がり、偶数の位置が全て入る。□

**計算.** `check_claude_placement_fixpoint_2026-11-08.py`：(E1)(E2) の両方向の強制の固定点を n = 5, 6 で計算すると、各段でちょうど偶数の位置の全体（n = 5 で段 1..5 に 16, 15, 13, 9, 1 点）になる。

**意味.** これは `claude_two_letter_fanout1_2026-11-01.md` 命題C.1（一段ずれた位置への強制）を、任意の印の語について、全ての段で、全ての偶数の位置まで広げたもの。Theorem 1（Astra、有限の置き場所は等差列）と合わせると、各 ω_j は a² と可換（a²ω_j ≡ ω_j a²）。

## 3. 二択の筋書き（予想）

命題DD の後、強制は単独の置き換え語にとどまらない。B の b を含む生成語は全て ≡ なので、二重化では ω_j ≡ a^{2^{j−1}}ω_{j−1} ≡ ω_{j−1}a^{2^{j−1}} ≡ ω_{j−1}ω_{j−1}、および a²ω_j ≡ ω_ja²。≡ は合同関係なので、L は L の語の中のこれらの因子の置き換えで閉じている。

**予想（二重化の場合）.** ω_n の ≡ 類（L の b 語全体を含む）は、「価値」（a = 1、ω_j = 2^j）が N で、偶奇の条件を満たす**全ての符号列**（符号語の順序も自由）を含む。符号語の長さがそろっていれば、定理M の計数補題（非終端ごとに型が二つ、b を含む因子の類は価値で決まる）を、符号語の部分集合を左右に並べ替えた 2^{n−1} 語の族に当てて、文法の大きさ 2^{Ω(n)} が出る。

**筋書き（一般）.** a^N の最小の導出 T は a^N の直線的プログラムで、N が指数的なら重い規則の鎖に二重化型の分岐が並ぶ。補題PC は T の全ての親子で置き場所を等式で結び、整列の情報を消していく。最後に (a) 有限性・反鎖に反する（強制された語が L の b 語の真の因子を含む）か、(b) 強制された類が価値の値を指数的に多く持ち、計数で文法が大きくなる、の二択になる——というのが道P の目標。群の原像（定理G）は (b) の極端な場合、加法的な重み（Astra 定理A）は類が少ない場合にあたる。

**未解決**：一般の T での補題PC の系の解法（固定点の構造）、類が価値で区別されること（加法的でない場合を含む）、計数の族の選び方。b を二つ以上含む核（STATUS (12)）とも同じ問題。
