## 1. 設定

- Σ = {a, b, c}、型付けは内容型付け c（語 ↦ 現れる文字の集合）。L ∈ C_{2,c}（arity 1 と 2 で (2,c)-タプル代入可能な 2-MCFL）。G は L∩Σ⁺ の既約な良い表示（ファンアウト ≤ 2、ランク ≤ r）、v = |V|、θ = θ̄_G。
- k := μ_a(L) = min{j : a^j ∈ L} ≥ 5。T は a^k の節点数最小の導出。
- **場合の分け方**：場合 I は b⁴ と c⁴ がともに L の語に現れる（定理 I で多項式、閉じている）。場合 II はどちらも現れない。**場合 III は b⁴ だけが現れる**（c⁴ だけの場合は対称）。
- **分岐 (B)**：前報 §4 の「鎖」の分岐。両文字型（短い生成が b と c の両方を含む）の低い内部の塊 F_X について、SB(F, d)（s, t ≥ 1、s+t = k−d の全てで a^s F a^t ∈ L）と、鎖 F_X F_Y の SB、離れた二塊の所属が成り立つ場合。分岐 (S)（入れ子）は今回扱わない。

## 2. 確かめて証明すること（Claude の観察、未検証）

**(O1) 補題 F′ の文字の置き換え。** `claude_straddle` §3.1 の補題 F′ と系 C を、a を b に置き換えて読み直し、次を確かめる。
- 仮定（b⁴ の出現、「b の個数 ≥ b の極大連の数 + 1」、置き換える部分が b で始まらないこと）で十分か。
- 証明が μ_a、SB、場合 I に固有の性質を使っていないか。

**(O2) b-融合による排除。** 場合 III で、a を含まない塊 F が
- SB(F², 2d) を満たし、
- c を二つ以上含み、
- bb を含むか、両端がともに b である

とする。このとき F′ を繰り返して c の間の b の連を消すと、c⁴ を含む語が L に入り、場合 III に矛盾する（例：bcccb·bcccb → bb ccc ccc b）。**一般の長さの塊について証明する。** F′ による直接の証明でも、抽象的な文字の基礎の証明書と準同型による持ち上げでもよい。

**(O3) 共通の根。** (KL)、前報 §8、(O2) を合わせると、場合 III の分岐 (B) で残る低い内部の塊は (bc)^j、(cb)^j と、c を一つだけ含む b^i c b^j になる。c が一つの塊を二つつないだ鎖は、(O2) か (KL) で消え、(bc)² か (cb)² だけが残るはずである。確かめること：
- 鎖を塊として使うとき、どの冪まで SB が要り、前報 §4 の予算で足りるか。
- 同じラベルの鎖 F_X F_X も使えるか。使えるなら、b^i c b^j のうち bc と cb 以外は消え、全ての低い内部の塊が**一つの根 u ∈ {bc, cb} の冪**になる。
- 使えないなら、c が一つの塊（例 bcb）が根として残る。そのときも全ての塊が一つの根の冪 u^j になり、前報 §5 の損失の線形化が使えるか。
- 前報 §6.2 の一色型の数え方（二文字の影の飽和／非飽和）が場合 III でも成り立つか。b⁴ が現れることで変わる点はないか。
