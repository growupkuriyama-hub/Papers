# Fable 第2回：P2+ の混合支持 `(b^p c^q, b^r c^s)` への拡張 — 数学報告

## 1. 結論

**CONDITIONAL（一般形は OPEN、反証なし）。**

- **PROVED（追加仮定なし）**：補題MS（語列加法性）。混合支持でも、連結宿主なしに二成分 Transport と多重集合帰納がそのまま通る。
- **PROVED（連長室の仮定 RR の下）**：定理MX。欠損和は成分別 Parikh で決まる。実際には総 Parikh だけで決まる。
- **OPEN**：RR なしの目標命題。最初に破綻する交換は `c b^t → b^t c` の一穴交換で、共通受理文脈が存在しない（§4）。

## 2. 設定と記号

単位 J は `u_J=b^{p}c^{q}`, `v_J=b^{r}c^{s}`（p,q,r,s≥1）、欠損 `d_J`。前提は P2 と同形である。

- (Single) `a^l u_J a^g v_J a^{r'}∈L`、l,g,r'≥1、a総数 `N−d_J≥4`。種 B,C も同様。
- (Seed) 交錯 `u_B u_C v_B v_C`、または入れ子 `u_B u_C v_C v_B` の間と両外側に a を置いた実在受理語。a総数 `N−d_B−d_C≥2`（木では両外側が正なので自動）。
- 許容単位は `d_J≤(N−1)/2`（依頼の `(N−1)/(24θ²)` を含む）。種には窓を課さない。N≥7。

(Single) の `g≥1` は Astra §5.6 と同じ good/nonmerging の議論に依拠しており、今回は再監査していない。

## 3. 新しい補題

### 3.1 a と単位成分の可換（Comm）

R で `a²u a v a^{A−3}` と `a u a² v a^{A−3}` を得る（A=N−d_J）。

- 比較片：`x=a·u_J`, `y=u_J·a`。実型はともに `{a,b,c}`。
- 共通文脈：`E₀=(a, a v_J a^{A−3})`。
- 帰結：任意の一穴文脈で `a u_J ≡ u_J a`。`v_J` も `E₀=(a^{A−3}u_J a, a)` で同様。

P2 との違いは、型が `{a,b}`/`{a,c}` から `{a,b,c}` になる点だけである。これは**ブロック `b^pc^q` 全体**との可換であり、`b a c` のような内部への a 挿入は主張しない。

### 3.2 補題MS（語列加法性）［PROVED］

許容単位の任意の非空多重集合 m（`d_m≤N−4`）と任意の並べ方 σ について

- 交錯種のとき：`u_{σ1}⋯u_{σn} v_{σ1}⋯v_{σn} a^{N−d_m}∈L`
- 入れ子種のとき：`u_{σ1}⋯u_{σn} v_{σn}⋯v_{σ1} a^{N−d_m}∈L`

**交錯の Transport**（B を保持し C→J）。`i=N−d_B−d_C`, `i'=N−d_B−d_J`（ともに≥1）。

- `x=(u_C, v_C a^{i})`, `y=(u_J, v_J a^{i'})`。実型はともに `({b,c},{a,b,c})`。
- `E₀=(a^{d_B−1}, a, ε)`：`E₀[x]`, `E₀[y]` は a総数 `N−d_C`, `N−d_J` の単独語で、(Single) から Comm で実際に得られる。
- `E₁=(u_B, v_B, ε)`：`E₁[x]=u_B u_C v_B v_C a^{i}` は種。
- 第四語：`E₁[y]=u_B u_J v_B v_J a^{i'}∈L`。
- 中央は `a`, `v_B` で非空。

続いて J を保持し B→J' とする。Comm で a を `v_J` の左へ移し、`x=(u_B,v_B a^{i'})`, `E₁=(ε,u_J,v_J)`, `E₀=(a^{d_J−1},a,ε)`。

**入れ子の Transport（P2 との第一の差分）。** P2 では `c^{q_B}c^{q_C}` が文字列として可換だったので入れ子を交錯と同一視できた。混合支持では `u_C` と `v_C` が隣接し、二穴の中央が空になる。そこで a を1個だけ中央に置く。

- `x=(u_C, v_C a^{i−1})`, `y=(u_J, v_J a^{i'−1})`。実型 `({b,c},{a,b,c})`。
- `E₀=(a^{d_B}, a, ε)`、`E₁=(u_B, a, v_B)`。
- `E₁[x]=u_B u_C a v_C a^{i−1} v_B` は種から Comm で得る。
- 必要条件：`i,i'≥2`。これが (Seed) の「≥2」の理由である。

外側の単位を替えるときは `E₁=(ε, u_C v_C, ε)` で、中央は自動的に非空。

**多重集合帰納**は Astra §5.5 と同じ。m=M+K とし、合成 `(u_M,v_M)` は単位の連接なので Comm を継承する。`W_{JK}` の中で K を保持し J→M とする。`x=(u_J,v_J a^{·})`, `y=(u_M,v_M a^{·})`, `E₀=(a^{d_K−1},a,ε)`, `E₁=(ε,u_K,v_K)`（入れ子は上の a 区切り版）。∎

**MS の射程。** 証明は `u_J,v_J` の形 `b^pc^q` を使っていない。全単位の成分型が共通なら、任意の語で成立する。ただし `b^pc^q b^{p'}c^{q'}` は列 `((p,q),(p',q'))` を一意に復元するので、MS 単独で U_shift にかけられるのは「同じ語列」だけである。つまり `d_J` が `(p,q,r,s)` の関数であること以上は出ない。P2 では `b^pb^{p'}=b^{p+p'}` が文字列の等式だったが、ここでは違う。これが破綻の正体である。

系：固定語 u,v に対する単位族 `(u^k, v^l)` では語が自動的に合流するので、**P2 が追加仮定なしで拡張される**（AB16-block の二成分版にあたる）。

### 3.3 補題Rc（c連再配分）［PROVED］

`l c^m r∈L` なる語があるとする。`i+j=k+l'≤m−1`（各≥1）のとき

- `x=(c^i,c^j)`, `y=(c^k,c^{l'})`。型 `({c},{c})`。
- `E₀=(l, c^{m−i−j}, r)`。中央は非空。`E₀[x]=E₀[y]=l c^m r`。

よって中央が非空の任意の二穴文脈で x と y は交換でき、**a 数は変わらない**。これは R の c 版で、`a^N` の役を「長い c 連を持つ受理語」が担う。

### 3.4 補題CC（c と b ブロックの可換）［PROVED］

`w=P c^α b^t c^β Q∈L` とする。

1. α+β≥3 かつ m≥α+β+1 のとき。h=α+β−1≥2 とおき、Rc（`E₁=(P,b^t,Q)`）で `w₁=P c^h b^t c Q` と `w₂=P c^{h−1} b^t c² Q` を得る。
   - 比較片：`x=c b^t`, `y=b^t c`。実型はともに `{b,c}`。
   - `E₀=(P c^{h−1}, cQ)`：`E₀[x]=w₁`, `E₀[y]=w₂`。
   - 帰結：**`c b^t ≡ b^t c`**（全一穴文脈、コスト0）。
2. α=β=1 のとき。w の別の極大 c 連 `c^γ`（γ≥2, m≥γ+2）と Rc で `(c,c^γ)→(c²,c^{γ−1})` としてから 1 に帰着する。

これは Astra の ON 補題の順序（正の連のまま合同を証明し、その後で0個の隙間を許す）を c に移したものである。空の連は一度も比較していない。

### 3.5 定理MX［RR の下で PROVED］

**(RR)** 許容単位の c 指数の最大値を χ とする。χ≥2 で、L のある語が長さ `m≥2χ+1` の c 連を因子に持つ。

このとき `d_m≤N−4` の任意の m について

`b^{P}c^{Q}b^{R}c^{S}a^{N−d_m}∈L`、(P,Q)=Σ(p_J,q_J)、(R,S)=Σ(r_J,s_J)。

したがって成分別 Parikh が一致する二つの多重集合は、U_shift により欠損和が一致する。

*証明。* 各 J について、c 指数≥2 を持つ J'（J 自身でもよい）を取る。MS の二単位語 `W_{J'J}` では `b^{p_J}`, `b^{r_J}` がともに両側を c 連に挟まれる。連の和は ≤2χ≤m−1 なので、CC から `c b^{p_J}≡b^{p_J}c`, `c b^{r_J}≡b^{r_J}c` が出る。MS の語にこれを適用し、各相で b ブロックを左へ集める。∎

**注。** 接合部の `b^{r_J}` も c と可換なので、さらに `b^{P+R}c^{Q+S}a^{N−d_m}∈L` まで進む。つまり RR の下では**総 Parikh の一致だけで欠損和が一致**する。総 Parikh から成分別一致を仮定したのではなく、正規形が合流することによる。b と c の役を入れ替えた対称版（長い b 連、`b c^t≡c^t b`）も同じ証明で成立する。

## 4. RR なしで最初に破綻する交換

最小の関係は単位数が変わる `2·(bc,bc)` 対 `(bbcc,bbcc)`、または単位数を保つ `(p,q)+(p',q')=(p,q+1)+(p',q'−1)` である。どちらも必要なのは

`P c^{α}[c b^{t}]c^{β−1}Q` と `P c^{α}[b^{t} c]c^{β−1}Q` の同時受理

で、片 `c b^t`, `b^t c` の型は一致する。しかし後者の語は「c を1個ずらした単位対」の語であり、a 数が一致することが示したい欠損等式そのものなので**循環する**。a を成分に吸収する二穴比較 `x=(c^q b^{p'}, v v' a^i)`, `y=(b^{p'}c^q, v'' a^{i'})`, `E₀=(b^p,c^{q'},ε)` は合法だが、得られる語はどれも加法的モデルと整合し、欠損の情報を生まない。

つまり欠けているのは**「c 1個を b ブロック越しにコスト0で移す証人対」**だけである。RR はそれを長い c 連から供給する。AB16 は同じものを連結宿主と `N≥6maxδ+1` から供給していた。木の短い組は長さ≤θ で、L に長い連がある保証はないので、一般の木版は未解決のまま残る。「Parikh が等しいから並べ替える」はどこでも使っていない。

## 5. P2/P2+ との差分

| 項目 | P2/P2+ | 今回 |
|---|---|---|
| Comm の型 | `{a,b}`, `{a,c}` | `{a,b,c}`（ブロック全体） |
| Transport の型 | `({b},{a,c})` | `({b,c},{a,b,c})` |
| 入れ子 | c 冪の文字列可換で交錯に帰着 | 中央に a を1個置く。a 室≥2 が必要 |
| 多重集合の合流 | 文字列の等式で自動 | 不成立。Rc+CC（RR）で回復 |
| 結論 | 成分別 Parikh ⇒ 欠損和 | RR 下で総 Parikh ⇒ 欠損和 |
| 連結宿主・IH・AB | 不使用 | 不使用 |

## 6. 次に残る最小の課題（1件）

**二成分AB の最小例。** 単位 `J=(bc,bc)`（欠損 δ）と `K=(bbcc,bbcc)`（欠損 D）、交錯種。L の b 連・c 連の最大長は 2（RR は m≥4 を要するので不成立）。このとき `D=2δ` は強制されるか。

MS により `(bc)^4 a^{N−2δ}`, `(bbcc)^2 a^{N−D}`, `bc·bbcc·bc·bbcc a^{N−δ−D}` などは既に L にある。連結核 `a^* bbcc a^*` は無いので AB16 は直接には適用できない。この一点が証明されれば、単位数を変える関係が RR なしで通る。反証されれば、P_tree には連長室か宿主の仮定が本質的に必要と確定する。
