## 1. ここまでの到達点

Σ = {a, b, c}、内容型付け c、L ∈ C_{2,c}、G は L∩Σ⁺ の reduced good な表示（ファンアウト ≤ 2、ランク ≤ r）、v = |V|、θ = θ̄_G。k := μ_a(L) ≥ 5、T を a^k の節点数最小の導出。

**補題M（証明済み）**：重い非終端 B ごとに β_x(B)（B の生成組で {a,x}⁺ に入り x を含むものの最短の長さ）を取り、β* := max_B min{β_b(B), β_c(B)} とすると、μ_a ≤ 9000(r+1)³v³·max{1, θ, β*}⁶。

したがって、超多項式の μ_a を持つ族（中心の問いの否定）には、次の性質を持つ重い非終端 B が必要：
- **(★)** B の長さ θ 以下の生成組は**全て b と c の両方を含み**、B の二文字の逃げ道（{a,b}⁺ だけ、または {a,c}⁺ だけで、a 以外を含むもの）は超多項式に長いか、存在しない。

## 2. 問い

> **(★) を満たす重い非終端は、代入可能性と両立するか。**
> - **肯定側（中心の問いの肯定に近づく）**：(★) のもとで、代入可能性から B の短い二文字の逃げ道を作る（影の抽出）、または (★) のもとで直接 μ_a ≤ poly(‖G‖, θ) を示す。
> - **否定側（中心の問いの否定）**：(★) を満たし、L_n ∈ C_{2,c}、‖G_n‖ と θ̄_{G_n} が n の多項式、μ_a(L_n) が超多項式となる族を作る。

## 3. 考えるための手がかり

- **挿入の補題は有限の言語にしか効かない**：これまでの候補 A_i → A_{i−1}A_{i−1} | bc は、bc と bcbc が有限の言語の中で比べられて壊れた。逃げ道を無限の族（例：(bc)⁺）にすれば、この壊れ方は起きない。
- **ただし a の個数の漏れで壊れる例**（Claude の検査、所属は正確な判定器なので違反は本物）：
  - 候補 A_0 → a | D、A_i → A_{i−1}A_{i−1} | D、D → bc | bc D（開始 A_n）。
  - n = 2：(a) と (aa) が文脈 (a, bcbc) を共有するが、文脈 (a, abc) では aaabc ∈ L、aaaabc ∉ L。
  - n = 3 でも arity 1 と 2 の両方で同様の違反。
  - 原因：a の塊の長さが二進の区切りに縛られ、定理S（同じ a 骨格の語の a の個数の差は 0 か k 以上）に反する。
- **交換の補題**：L のある語が因子 a a y a（y は一文字）を持てば、文脈 (U a, a V) が a y と y a を受理し、内容 {a, y} が等しいので D(ay) = D(ya)。b, c についても同様の交換が起きうる（三文字の報告 §6.2）。(★) の逃げ道を T に入れた語は、保護された aa と、b と c の両方を含む隙間を持つ。
- **影の抽出の発想**：B の短い生成組 ρ（b と c の両方を含む）から、代入可能性を使って c だけを消す、または b だけを消す操作が作れるか。例えば、ρ の中の c を含む因子 z と、c を含まない因子 z′ が、同じ内容（成分ごと）で共通の文脈を持つ場面を作る。
- **否定側で守るべき条件**（これまでの検証済みの結果）：
  - 同じ a 骨格の語の a の個数の差は 0 か k 以上（定理S）。
  - 倍増節点とその重い子孫は、同じ逃げ道の符号を持てない（`reviews/chatgpt_escape_branches_2026-11-03.md` の補題4.1）。
  - 二つの二文字の影のどちらでも、a だけの語の長さが補題L1 で抑えられないこと。

## 4. してほしいこと（優先順）

1. **肯定側**：(★) のもとで影の抽出か μ_a の多項式上界を証明する。一般に無理なら、示せる特別な場合を切り出す（例：b⁴ と c⁴ の両方が L に現れる場合、逃げ道が一成分の場合、B の短い生成組が bc を因子に持つ場合）。
2. **否定側**：(★) を満たし、定理S と §3 の条件を守る族を設計する。候補を作ったら、まず小さい n で、正確な所属判定器を使った検査（違反が見つかればそれは本物の証明書）を行い、通れば全ての n について arity 1 と 2 の代入可能性を省略せずに証明する。さらに G_n が reduced good でファンアウト ≤ 2・ランク ≤ 2、‖G_n‖ と θ̄_{G_n}（n の多項式）、μ_a(L_n)（超多項式）を全て証明する。
3. どちらも完了しない場合は、証明できたこと、止まった場所、次に絞るべき一点を書いて終える。
