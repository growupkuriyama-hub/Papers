## 1. 背景（なぜこの計算が重要か）

- Σ = {a,b}。準同型 φ: Σ* → H（H は有限群）について、L := φ⁻¹(1) ∩ Σ⁺ は、**どの型付けについても**一穴の組代入可能性を満たします（共通の文脈があれば φ(x) = φ(y) となるから）。L の中で a だけの最短の語は a^N（N は φ(a) の位数）で、そのため二文字の内容型付け c（および s_{U,2}：a ↦ 1、b ↦ ζ）のファンアウト1の特徴データは N+1 以上必要です。
- **問題G**：r ≥ 2 を固定する。有限群 H と全射 φ、および L の reduced good なランク ≤ r の文脈自由文法 G の全てについて、ord(φ(a)) ≤ p(‖G‖, θ̄_G) となる多項式 p はあるか。
  - 問題G が**否定**（位数が大きいのに、小さく薄い文法がある群の族がある）なら、論文の未解決問題 `op:S1` が否定で解け、s_{U,2} について「ファンアウト1では超多項式、ファンアウト2では多項式」という分離が二文字で成り立ちます（論文の看板になる結果）。
  - 問題G が肯定なら、その証明が二文字・ファンアウト1の肯定の証明の一部になります。
- **候補の群**：n ≥ 2、N_n := 2ⁿ − 1、H_n := Z/N_n ⋊ Z/n（アフィン写像 x ↦ mx + c、m は 2 の冪）。a ↦ (x ↦ x+1)、b ↦ (x ↦ 2x)、語は左から順に作用させる。b^n = 1、φ(a) の位数は N_n。そして a^{2^j} = b^{n−j} a b^j（長さ n+1）が成り立つ。|H_n| = n(2ⁿ − 1)。
- 「全ての元 g について、値 g の語を生成する非終端 X_g」を置く素朴な文法は |H_n| 個の非終端を持ち、大きさが指数になります。**多項式個の非終端で済むか**が問題です。

## 2. 計算してほしいこと（Python 3 標準ライブラリのみ）

### C1：値付きの文法の族（主課題）

非終端を群の元の部分集合 V ⊆ H で添字付けた文法 G_V を考えます：開始記号 S = X_1、規則は
- X_g → x（x ∈ Σ、φ(x) = g のとき）
- X_g → X_{h_1} ⋯ X_{h_k}（2 ≤ k ≤ r、h_i ∈ V、h_1 ⋯ h_k = g）
- （必要なら終端と非終端を混ぜた右辺 X_g → x X_h など。ランク ≤ r の範囲で）

G_V の生成する語は全て L の元（値 1）です。**L(G_V) = L（完全性）となる最小の V**を、n = 2, 3, 4, 5（できれば 6）とランク r = 2, 3, 4 について求めてください。
- 完全性の判定：語の長さ ℓ ≤ ℓ_max の全ての w ∈ L が G_V で導出できるかを、CYK 型の動的計画法で確かめる（ℓ_max は計算が許す限り大きく。長さの上限を明記）。これは観察です。可能なら、完全性の**十分条件**（例えば「V の元 g と文字 x について、ある分割規則で g·φ(x) の値の語が必ず構文解析できる」などの閉包条件）を考えて、証明として確かめてください。
- 最小の |V| を、全探索（小さい n）または貪欲法・局所探索（大きい n）で求め、どの方法かを明記してください。
- 各 n、r について、|V|、‖G_V‖、θ̄_{G_V}（各規則を使う最短の文の長さを、文法から計算：各非終端の最短の生成物の長さと、各非終端を含む最短の文脈の長さを、最短路の計算で求める）、N_n = ord(φ(a)) を表にしてください。
- **知りたいのは増え方**：|V|、‖G_V‖、θ̄ が n について多項式か指数か。N_n = 2ⁿ − 1 と比べて、N_n ≤ (‖G_V‖ θ̄)^c のような関係が保たれそうか、崩れそうか。

### C2：一般の文法の下界の手がかり

値付きの文法に限らない一般の文脈自由文法でも、各非終端の生成物は全て同じ値を持ちます（全ての生成物が同じ文脈を共有するため）。従って一般の文法も「V で値付けされた文法」の一種です（ただし一つの値に複数の非終端があってよい）。この観察を使って、C1 の最小の |V| が一般の文法の非終端の数の下界になるかを考えてください（証明できれば証明を、できなければ反例の可能性を）。

### C3：比較のための可換群

H = Z/N（可換）、a ↦ 1、b ↦ λ について、同じ計算をしてください（N を 7, 15, 31, 63 など、λ を色々）。報告 §2.3 の予想では、可換の場合は位数が θ̄ のおよそ二乗で抑えられるはずです。C1 の非可換の候補と、増え方を比べてください。

### C4（余力があれば）：別の候補の群

H_n 以外にも、φ(a) の位数が大きく、全ての元が短い語で書ける（直径が小さい）群の族を試してください。例：Z/(2ⁿ−1) ⋊ ⟨×2⟩ の他の生成元の選び方、ランプライター型の群 Z/2 ≀ Z/n、Z/p ⋊ Z/(p−1)（アフィン群）。各族について、直径、ord(φ(a))、C1 の最小の |V| の増え方を表にしてください。
