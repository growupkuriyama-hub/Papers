## 2. E1：普遍正則篩いの正確な判定条件

### 2.1 普遍性と篩い自身の代入可能性は同値

**定理 2.1（全ファンアウトで成立）。** 固定 `f≥1`、固定有限半群型付け `s`、正則言語 `R⊆Σ*` に対して、

`(∀ L∈C_{f,s})[L∩R∈C_{f,s}]` **iff** `R` が `(f,s)`-tuple-substitutable。

**証明。** `Σ*` は正則で、全ての非空 `d`-タプルの分布が全許容文脈集合 `E_d` に等しいから `Σ*∈C_{f,s}`。左辺に `L=Σ*` を代入すれば `R∈C_{f,s}`、したがって代入可能。逆方向では、`R` は正則ゆえ `f`-MCFL、`L∩R` も MCFG の正則言語交差閉性から `f`-MCFL。原稿 `prop:abelian-coset-filter(i)` の**代入可能言語の交差閉性**により `L∩R` は全 `d≤f` で代入可能。□

これは一般の有限モノイドの構造による簡単な閉形式分類ではないが、**普遍篩いを正則な `(f,s)`-tuple-substitutable 言語と同定する必要十分条件**である。特に、全言語に対する普遍性を検査するために全 `L` を列挙する必要はない。

### 2.2 有限認識モノイドでの完全な有限表検査

`ψ:Σ*→M` が `R=ψ⁻¹(F)` を認識するとする（`M` は有限、`F⊆M`）。`T={(s(w),ψ(w)):w∈Σ⁺}` は有限。文脈の前後端に使う像は `M₀=ψ(Σ*)`、穴間の非空セパレータの像は `M₊=ψ(Σ⁺)` である。

各 `d=1,2`、成分別型が同じ `x=(m_i)` と `y=(n_i)`（値は `T` に属する）について、全 `q=(q₀,…,q_d)∈M₀×M₊^{d−1}×M₀` を調べ、

`P_q(x) :⇔ q₀ m₁ q₁···m_d q_d∈F`

を定める。このとき**「ある `q` で `P_q(x)` と `P_q(y)` が真なら、全 `q'` で真偽が一致」**が全組で成立することと `R∈C_{2,s}` は同値である。証明は、文脈の受理が認識モノイドの積だけで決まり、非空条件が `M₊` の採用に正確に対応することによる。`T` と各像は `Σ` の生成元から有限閉包として計算できる。元のモノイド `M` が認識準同型の全像でなくてもこの方法は正しい。

これにより E1 の分類について、**有限表による厳密かつ決定可能な特徴付け**を得る。ただし、許される `M` の擬多様体の簡潔な恒等式分類までは行っていない。

## 3. E1 の反例：非可換・非 Parikh の普遍篩いと短語上界

### 3.1 交互言語は全 arity で代入可能

`R=(ab)^+`（`c` を含まない）。

**命題 3.1.** 任意の有限半群型付け `s`、任意の `d≥1` について、`R` は `(d,s)`-tuple-substitutable。従って `R` は `C_{2,s_U}` の普遍正則篩いである。

**証明（arity を省略しない）。** `E[x],E[y]∈R` であるとする。`R` の語は始点が `a`、終点が `b`、文字が厳密に交互である。ある穴について、その直前に固定文字があればその文字が直後の先頭文字を一意に決め、そうでなければ穴は文頭から始まるので先頭文字は `a`。同様に、穴の直後に固定文字があればその文字が穴の末尾を一意に決め、なければ穴は文末まで続くので末尾文字は `b`。各穴は正の語で、穴どうしの間の固定区切りは必ず非空だから、各穴の直前・直後の「固定文字または文境界」の情報が得られる。従って `x_i,y_i` はともに交互語で、**同じ先頭文字と同じ末尾文字**を持つ。

特に `d=1` で `E=□` の場合も、`x,y∈R` なのでともに先頭 `a`・末尾 `b`。`d=2` では中間区切り `v₁≠ε` の最終・先頭文字が両穴の境界を固定し、両端の穴にも文頭／文末境界がある。`d>2` も同じ議論が各穴に独立に適用できる。

任意の許容文脈 `F` で `F[x]` を `F[y]` に置換したとき、各穴内部の交互性、各穴の両端の文字、固定部と穴の隣接関係、語全体の先頭・末尾は不変である。よって `F[x]∈R ⇔ F[y]∈R`。型の同一性は一度も使わなかったので任意の `s` に成立する。□

### 3.2 原予想の反証

型の集合 `s_U⁻¹(Acc)`、可換群準同型 `φ` の剰余類 `φ⁻¹(γ+H)` およびこれらの有限**交わり・和・補集合**は、全て `ab` と `ba` を区別できない。実際 `s_U(ab)=s_U(ba)=1` であり、任意の可換群では `φ(ab)=φ(a)+φ(b)=φ(ba)`。ところが `ab∈R`、`ba∉R`。従って **`R` は提案された有限和・交差の族に属さない**。

最小 DFA において `a`、`b` が誘導する状態変換は交換不能である（初期状態から `ab` は受理状態へ行き、`ba` は死状態へ行く）。これは順序に本質的に依存した非可換的普遍篩いである。ただし「正則篩いは全て可換群＋型で尽きない」という反証であり、「非可換な**群**の剰余類が普遍である」ことを意味しない。

### 3.3 端点指定の短い生成組

以下 `G` は reduced good、`fanout≤f`、`rank≤r`、`v=|V|`、`θ=θ̄_G≥1` とする。

**補題 3.2（端点短縮）。** 非終端 `A` の第 `j` 成分の**先頭**（または**末尾**）が文字 `x` となる生成組が一つでもあれば、そうした生成組で全成分長の和が

`B := 2 f v (r+1) θ`

以下のものがある。

**証明。** 指定端点を実現する `A` の導出木のうち、まず全成分長が最小、次に節点数が最小のものを選ぶ。根の規則テンプレートの指定成分の先頭／末尾は、規則に直接書かれた終端か、ある子のある成分の先頭／末尾から生じる。`λ`-free と生成成分の非空性により、指定側の最初／最後の atom は必ず同じ境界文字を担う。この依存を子へ追うと**一本の経路**を得る。

経路上で `(非終端名,成分番号,先頭/末尾)` が二度現れれば、下位の同名非終端の導出で上位を置換しても指定端点 `x` が保存される。nondeleting だから他の成分の長さが問題にならず、長さは増えず、節点数は減る。選択の最小性に反する。よって経路節点数は高々 `2fv`（実際には先頭・末尾は伝播中に切り替わらないのでさらに強くできる）。

経路外の各兄弟非終端には、原稿 `lem:thickness-equivalence(ii)` から全成分長 `≤θ` の最短生成組を代入できる。指定端点は経路側で実現するので保持される。各経路節点において、直接終端は原稿の同補題 (i) により高々 `θ`、経路外の子は高々 `r` 個で総長高々 `rθ`。従って導出組の全長は経路節点数×`(r+1)θ` 以下、すなわち `≤B`。□

### 3.4 禁止隣接対の短い成功語

**補題 3.3（2文字局所違反）。** `L(G)` のある語が隣接因子 `xy`（`x,y∈Σ`）を含むなら、同じ因子を持つ成功語が長さ

`≤ 2θ+rB = [2+2fr(r+1)v]θ`

で存在する。

**証明。** 隣接する2文字の起源を、ある成功導出木の下から上へ追い、同一の子成分内に残る間は下へ降りる。最初に両文字が同一子成分には属さなくなる規則 `R:A→ρ(B₁,…,B_k)`（`k≤r`）を取る。その規則の一つの出力成分中で、両文字は隣接する2つの atom（終端または子成分変数）の端点から供給される。同一子の2つの成分変数が直接隣接する場合は、nonpermuting と nonmerging により禁止される。よって制約される子は**高々2つで、別々の子**である。

制約された子には補題 3.2 の該当成分の左／右端点文字を保つ全長 `≤B` の生成組を与える。残る子には全長 `≤θ` の組を与える。規則が書く終端は `≤θ` 個であり、規則の合成は線形・非削除だから、新しい `A`-組の全長は `≤θ+rB`。この `A`-組はなお隣接因子 `xy` を含む。`lem:thickness-equivalence(iv)` の成功文脈 `E_A` は固定部長 `≤θ` で、当該組を埋め込める。従って長さ `≤2θ+rB` の成功語を得る。もとの2文字が同一の直接終端部分から来る場合も、残りを最短生成組へ替えれば同じ結論。□

**補題 3.4（端点・単文字違反）。** `L(G)` に先頭が `b` の語、または末尾が `a` の語があれば、そのような語の一つは長さ `≤B`。`L(G)` に `c` を含む語があれば、その一つは長さ `≤(r+2)θ`。

**証明。** 先頭／末尾は根 `S`（一成分）の補題 3.2 を使う。`c` は規則のどこかの明示終端に由来する。その規則の全子を最短生成組にし、`E_A` に挿入する。文脈と直接終端が各 `≤θ`、子が高々 `r` 個でそれぞれ `≤θ` なので `≤(r+2)θ`。□

### 3.5 非可換篩いの**多項式短語定理**

**定理 3.5.** `G` が上記の reduced good MCFG で `L=L(G)` とする。`L\(ab)^+` が非空なら、

`min{|w|: w∈L\(ab)^+} ≤ [2+2fr(r+1)|V|] θ̄_G.`

**証明。** 空語が `L` にあれば長さ0で結論。非空の語が `(ab)^+` に入らない必要十分条件は、(i) `c` を含む、(ii) `b` で始まる、(iii) `a` で終わる、(iv) `aa` または `bb` を因子に持つ、のいずれかである。補題3.3–3.4でそれぞれ同じ種類の違反を持つ短い成功語が得られる。`B≥θ` なので、これらの上界は全て表示した上界以下。□

**帰結。** `f=2`、`r` 固定なら `≤[2+4r(r+1)|V|]θ̄_G`。`r=2` では `≤(2+24|V|)θ̄_G`。`‖G‖≥|V|` なので `O_r(‖G‖θ̄_G)`。しかも代入可能性を仮定せず成立する。したがって新しい普遍篩い `(ab)^+` は、区別の補題による超多項式下界には使えない。**これは任意の普遍正則篩いに対する多項式上界ではない。** 局所的な隣接禁止という特殊構造を利用した。

## 4. 型と可換群の組合せを正確に分ける

### 4.1 一つの型集合と一つの剰余類の**交わり**

`L∈C_{f,s}`、`G` は reduced good、`Acc⊆S`、`C=φ⁻¹(γ+H)`（可換群の剰余類）として `L'=L∩s⁻¹(Acc)∩C` を取る。有限群ならこの `L'` は原稿の交差閉性と可換群篩いによって `C_{f,s}` に属する。

`M_L=s(L∩Σ⁺)`、`μ*(L,s)=max_{m∈M_L}μ_m(L)` とする（原稿の定義）。差 `D=L\L'` が非空の場合：

- `M_L\Acc≠∅` なら、ある除外型の最短語は**剰余類条件の成否を問わず** `D` に入る。従って `d(L,L')≤min_{m∈M_L\Acc} μ_m(L)≤μ*(L,s)`。
- 除外された実現型が一つもなければ、`L'=L∩C`（空語があるときは空語の型も扱う）なので原稿 `prop:abelian-filter-short` により `d(L,L')≤θ̄_G`。

よって非空語の範囲で `d(L,L')≤max{μ*(L,s),θ̄_G}`。**交差だけでは、型の削除の道より強い長さ下界を得られない。** `L∩s⁻¹(m)` に可換群篩いの短語定理を適用しようとすると、その限定文法の厚さが高くなり得る、という警告は正しいが、ここではもっと直接に「他の型を削除してしまう」ことが先に効く。

空語がある場合は `s^♯` の空語型を追加して同様に論じるか、`L∩Σ⁺` に限定する（原稿の厚さ節の取り決め）。

### 4.2 **和**による型別篩いは危険

`R=s⁻¹(1)∩{ |w|≡0,1 (mod 3) }` のように、同じ型の内部で剰余類を**和**にして受理する場合を考える。`x=a³`、`y=a⁴` はどちらも `R` に属し、`s_U(x)=s_U(y)=1`、共通文脈 `E=□` を持つ。しかし `F=□a` では `a⁴∈R`、`a⁵∉R`。従って `(1,s_U)`-代入可能性が失敗する。これは「可換群の各剰余類は安全」から「剰余類の任意の有限和も安全」への推論が誤りであることを示す。

さらに `R=(s⁻¹(m)∩C)∪s⁻¹(S\{m})` として、指定型だけに群篩いを作用させる場合も、共通文脈 `E` の出力型が `m` でないときには群差が `H` に入る保証がなく、一般には普遍性を証明できない。そうした `R` が**特定の `L`** に対してのみ使える可能性はなお残り、E2 の本題である。この「型ごとの和」を §4.1 の交差と混同してはいけない。

## 5. E2：位置・並び方に依存する非普遍な部分標的

### 5.1 2穴条件が実際に発動する、厳密な有限例

`L={aab,baa}`、`L'={aab}`、`R=aΣ*` と置くと `L'=L∩R`、`L\L'={baa}`。`aab` と `baa` は同じ `s_U` 型1・同じ Parikh ベクトル `(2,1,0)` なので、**`L'` は `L` と型集合・可換群剰余類の交わりでは分離できない**。一方 `R` は普遍篩いではない：`x=a,y=b,E=a□` では `aa,ab∈R` だが `F=□` では `a∈R,b∉R`。

**`L` の arity 1 の完全証明。** 共通受理文脈 `E` で `E[x],E[y]∈L` とする。両語が同じなら固定した一穴文脈で自由モノイドの消去が成り立つので `x=y`。両語が異なるなら `aab` と `baa` であり、異なる位置は1文字目と3文字目。共通の**一つの連続穴**が両方の相違位置を覆うためには、穴は語全体で `E=□`、`{x,y}={aab,baa}`。この2語の1穴分布はともに `{□}`（他の文脈は語長3より長くなる）。従って一致する。

**`L` の arity 2 の完全証明。** 受理文の長さが3で、穴2つと非空区切りの長さはそれぞれ1以上なので、前後端は空、中間は1文字、穴はそれぞれ長さ1に限られる。`aab`,`baa` の第2文字は両方 `a` だから唯一の受理可能な文脈は `E=□₁a□₂`。対応する受理タプルはそれぞれ `(a,b)` と `(b,a)` で、成分型はいずれも `(1,1)`。両者が共通受理文脈 `E` を持つだけでなく、その2穴分布はいずれも正確に `{E}` である。従って条件を満たす。ここでは2穴条件は**空虚ではない**。

**`L'` の arity 1 の完全証明。** `E[x]=E[y]=aab` なら一穴で `x=y`。arity 2 では上記の長さ制約で、唯一の受理文脈 `□₁a□₂` に受理タプル `(a,b)` のみ存在する。従って同型で共通受理文脈を持つ異なるタプル対はなく、条件を満たす。ゆえに **`L,L'∈C_{2,s_U}`**。

真のファンアウト2を使用する表示は

```text
S -> (ξ_1^1 a ξ_1^2)(A)
A -> (a,b) | (b,a)
```

である。`fan(S)=1,fan(A)=2`、最大ファンアウト**2**、最大ランク**1（よって cap r≥2 に適合）**、`|V|=2`、規則費用 `5+3+3=11`、`‖G‖=13`、`θ_G(R)=3` は3規則全てについて成立するので `θ̄_G=3`。全成分非空、各変数が一度だけ使われ、`ξ_1^1` と `ξ_1^2` は間に端末 `a` があるので nonmerging、順序は保存される。両非終端は到達可能・生産可能で、reduced good。`L'` は `S'→aab` の good なファンアウト1・ランク0文法を持つ（サイズ4、厚さ3）。最短差語長は正確に `3`。

**注意**：この例は下界族ではない。`L'` が自動的に代入可能になるという仮定は使わず、両 arity を独立に証明した点が目的である。`G` は rank cap 2 以下だが最大規則ランクちょうど2ではない。上界問題の定式化では cap なので合法。

### 5.2 既存の倍増近接例が下界族にならない理由

原稿 `thm:doubling-no-lift` は、三文字倍増族（および文字を互いに素な語へ置換した族）が `n≥2|S|+2` で**arity 2 の代入可能性を失う**ことを証明する。途中の `lem:power-transfer` は、非空の穴間区切りによる同じ受理語の2分割から、冪のブロック間輸送を要求する。唯一純語の位置パターンを壊すため、`L'` の設計以前に `L` の所属が失敗する。

前報のショートカット文法 `A₀→a|c`, `A_i→A_{i−1}A_{i−1}|c` は `‖G_n‖=8n+5`, `θ̄=n+1`、唯一純語 `a^{2^n}` という数値条件を持つが、`n=1` から **arity 1** で失敗する（`x=c,y=ac,E=□,F=□a`）。ブロック言語 `{a^k,bc}^m` は `k≥2,m≥3` で **arity 2** で失敗する（前報の `E=a^{k−1}□₁a□₂`, `F=□₁bc□₂` の証人）。これらを後から位置篩いで切っても、母標的の所属失敗は修復されない。

### 5.3 型削除とは異なる難しさ

§5.1 の `L\L'={baa}` は、**唯一の型1語を残し忘れた**事象ではない（型1の語 `aab` が `L'` に残る）。従って `lem:unique-word-rigid`、`prop:unique-two-letter-shapes`、`lem:unique-word-gap` の「唯一の希少型語」に固有の仮定は適用されない。将来 `n^{ω(1)}` の族でこれと同様に型の全代表を短く保ちながら、長い**位置的な**差語だけを削除できれば、型削除の障害を避けられる。しかし §5.1 を大きい `n` へ反復・倍増するだけでは、母言語の1穴／2穴の代入可能性が保たれる保証がなく、現時点ではそのような族は構成できていない。

## 6. E2(b)：部分文法で削除する場合の厚さ

### 6.1 曖昧でない文法の場合

**命題 6.1.** reduced good な `G''` が**非曖昧**で、規則の非空集合 `Q` を削除した部分文法 `G''\Q` が真部分言語 `L'⊊L(G'')` を与えるとする。すると `d(L(G''),L')≤θ̄_{G''}`。

**証明。** 真に削除された語は必ずある削除規則を使って導出されていた。そのうち実際に使われる削除規則 `R∈Q` を取る。`θ_{G''}(R)` を達成する成功導出は `R` を使用し、その生成語には**他の成功導出が存在しない**。従って `G''\Q` でこの語を生成できない。差語長はその語長 `θ_{G''}(R)≤θ̄_{G''}` 以下。□

従って `G''` 非曖昧で超多項式差語を目指すなら、必ず `θ̄_{G''}` が超多項式でなければならない。ただし**多項式のサイズ・厚さを要求するのは最初の `G` だけ**であり、`G''` が厚くなることは禁止されていない。加えて `L'` が代入可能であることは、規則削除から自動的には出ない。

### 6.2 曖昧性が作る指数的なずれ：正確な反例（クラス外）

`n≥1` について次の reduced good CFG を取る。

```text
S  -> A_n | a
A_0 -> a                  (削除する規則 R)
A_i -> A_{i-1} A_{i-1} | a    (1 <= i <= n)
```

`A_i` の語長集合は帰納法で `[1,2^i]∩ℤ`。`R=A₀→a` を削除すると `A₀` が空になり、`A_i (i≥1)` の語長集合は `[1,2^{i−1}]∩ℤ`。従って

`L(G''_n)={a^j:1≤j≤2^n}`、
`L(G''_n\{R})={a^j:1≤j≤2^{n−1}}`、
`d(L,L')=2^{n−1}+1`。

費用：非終端数 `n+2`、`S` の規則費用 `3+2`、`A₀` 費用2、各 `A_i` 費用 `5+2=7`。従って `‖G''_n‖=(n+2)+5+2+7n=8n+9`。`R` を成功導出で使うには根への各レベルで二項規則を通り、兄弟に少なくとも1文字を置く必要があり、最短文は `n+1`。他の全規則の厚さは高々 `n+1`、ゆえに `θ̄_{G''_n}=n+1`。fan-out 1、最大ランク2、reduced good。

**これは曖昧な一般文法では、規則厚さだけから部分文法との差語長を抑えられないという反例**。たとえば短い `a` は `R` を使う導出と使わない導出を持つので、`R` の短い成功証人は削除差語にならない。

ただし `L(G''_n)` は `n≥1` で `a` と `aa` を含む**有限**言語であり、`s_U(a)=s_U(aa)=1`、共通受理文脈 `□` を持つため原稿 `lem:no-insertion` に反する。従って **`C_{2,s_U}` に属さず、主問題の反例ではない**。この限定を外して使ってはいけない。

## 7. E3：一般の部分標的が満たす厳密な構造

### 7.1 生き残る共通文脈に関する飽和：必要十分条件

`L∈C_{2,s_U}`、`D⊆L`、`L'=L\D` とし、`L'` はファンアウト2 MCFG であると仮定する。次は **`L'` の代入可能性の必要十分条件**である：

> 全 `d=1,2`、同じ成分型の非空タプル `x,y`、および許容文脈 `E` について `E[x],E[y]∈L'` なら、全許容 `F` で `F[x]∈D ⇔ F[y]∈D`。

**証明。** `E[x],E[y]∈L'⊆L` より `L` の代入可能性から `D_L^(d)(x)=D_L^(d)(y)` が成立する。`L'=L\D` なので、`F[x]` と `F[y]` はともに `L` に入るかともに入らず、`L'` に入るかどうかが一致するための必要十分条件は `D` に入るかどうかが一致することである。全 `F` についてこの条件が成り立つことは `D_{L'}^(d)(x)=D_{L'}^(d)(y)` と同値。従って必要十分。□

- **d=1**：`E=u□v` において `uxv,uyv` が**ともに生存**すれば、任意の `p□q` による削除判定が `pxq,pyq` で同じになる。
- **d=2**：`E=u□₁t□₂v` の `t∈Σ⁺`（非空）について両組が生存すれば、任意の `F=p□₁h□₂q`（`h∈Σ⁺`）で削除判定が一致する。**区切りが空の文脈にはこの含意はない。**

この飽和は `D` に関する、`L'` の受理文脈に依存する条件であり、一般に「`L` で共通文脈があるだけで D は閉じる」と強化できない。§5.1では `aab` と `baa` は `L` の共通文脈 `□` を持つが、`L'` 内では両方が生き残っていない。よってこの縁に沿った伝播は起こらない。

### 7.2 短い規則証人から全導出への伝播が停止する場所

原稿の可換群篩いでは、個々の規則 `R` の短い二証人の Parikh 差 `δ_R` を全受理語へ**導出木の総和として**持ち上げられる。一般の `L'` では、短い語がすべて生き残っても、長い導出中のある置換を比較するために必要な**二つの語が生存する共通文脈**は保証されない。候補となる長い語は `L\L'` に入るかもしれず、その時点で §7.1 の必要十分条件を適用できない。これが「規則を一つずつ差し替える」証明の厳密な循環点である。

ただし、追加仮定として原稿の分布代表長 `τ(G,s_U)` が `p(‖G‖,θ̄_G)` 以下なら、`cor:distribution-representatives` と `N_typ≤|S^♯|^{fr}‖G‖` により、両 canonical operators の特徴標本の**総符号長**が

`≤ |S^♯|^{2r} ‖G‖ [1+2θ̄_G+r p(‖G‖,θ̄_G)] + 1`

となる（`f=2`、型付け固定、空語分の+1）。区別の補題から任意の真の `L'∈C_{2,s_U}` への差には、この上界以下の語がある。これは**既存定理からの条件付き帰結**であり、肝心の `τ(G,s_U)` 自体の無条件多項式評価は未解決。`L'` が大きな文法で表されてもよいことと矛盾しない。

### 7.3 ファンアウト1との違い

ファンアウト1の原稿 `prop:three-letter-family` は、`‖G_n‖=13n+7`、`θ̄_G=4n`、唯一の型1語の長さ `3·2^n−2` という厳密な指数下界族を持つ。`L'=L\{W_n}` は `lem:type-deletion` でクラス内にある。しかし `f≥2` では `lem:power-transfer` と `thm:doubling-no-lift` が同じ母言語の**arity 2** を破る。`lem:unique-word-rigid`、`prop:unique-two-letter-shapes` はさらに長い唯一純語の可能な形を5形へ制限する。これらの議論は、**型ごとに唯一の語を削除する方針**への障害であって、§5.1のように同じ型を一部残す非 Parikh 部分標的を禁じる定理ではない。

def ut(w):

    return 'z' if 'c' in w else '1'

def occurrences(w, d):
    n=len(w)
    if d==1:
        for i in range(n):
            for j in range(i+1,n+1):
                yield ((w[i:j],),(w[:i],w[j:]))
    else:
        for i in range(n):
            for j in range(i+1,n):
                for k in range(j+1,n):
                    for ell in range(k+1,n+1):
                        yield ((w[i:j],w[k:ell]),(w[:i],w[j:k],w[ell:]))

def plug(ctx,words):
    return ''.join(s+w for s,w in zip(ctx,words))+ctx[-1]

def check_finite(words, d):
    words=set(words)
    buckets=defaultdict(lambda:defaultdict(set))
    for word in sorted(words):
        for tup,ctx in occurrences(word,d):
            buckets[tuple(map(ut,tup))][tup].add(ctx)
    for typ,group in buckets.items():
        tuples=list(group)
        for i,x in enumerate(tuples):
            for y in tuples[i+1:]:
                shared=group[x] & group[y]
                if shared and group[x]!=group[y]:
                    sep=next(iter(shared))
                    distinguish=next(iter(group[x]^group[y]))
                    assert plug(sep,x) in words and plug(sep,y) in words
                    assert (plug(distinguish,x) in words)!=(plug(distinguish,y) in words)
                    return ('FAIL',d,x,y,sep,distinguish)
    return ('PASS',d,len(buckets),sum(map(len,buckets.values())))

# DFA for (ab)+ over {a,b,c}: states 0 start, 1 expect b, 2 accept expect a, 3 sink
TRANS={
 'a':(1,3,1,3),
 'b':(3,2,3,3),
 'c':(3,3,3,3),
}
Q=4
I=tuple(range(Q))

def compose(f,g):
    return tuple(g[f[q]] for q in range(Q))

def monoid():
    # Attainable elements remember positive s_U type (1/z), plus epsilon (e).
    start=(I,'e')
    todo=deque([start]); rep={start:''}
    while todo:
        elt=todo.popleft(); f,t=elt
        for c in ALPHABET:
            nxt=(compose(f,TRANS[c]), 'z' if t=='z' or c=='c' else '1')
            if nxt not in rep:
                rep[nxt]=rep[elt]+c;todo.append(nxt)
    return rep

def check_regular(d):
    rep=monoid()
    allmaps={f for f,t in rep}
    posmaps={f for f,t in rep if t!='e'}
    poselts=[(f,t,w) for (f,t),w in rep.items() if t!='e']
    contexts=list(product(sorted(allmaps),repeat=2)) if d==1 else [
        (u,v,w) for u in sorted(allmaps) for v in sorted(posmaps) for w in sorted(allmaps)]
    def accept(C,xx):
        st=0
        for k,xf in enumerate(xx):
            st=C[k][st]
            st=xf[st]
        st=C[-1][st]
        return st==2
    buckets=defaultdict(list)
    for tup in product(poselts,repeat=d):
        typed=tuple(t for f,t,w in tup)
        funcs=tuple(f for f,t,w in tup)
        profile=0
        for i,C in enumerate(contexts):
            if accept(C,funcs):profile|=1<<i
        buckets[typed].append((tup,profile))
    for typ,rows in buckets.items():
        for i,(x,p) in enumerate(rows):
            for y,q in rows[i+1:]:
                if p&q and p!=q:
                    return ('FAIL',d,typ,tuple(z[2] for z in x),tuple(z[2] for z in y),
                            len(contexts),i)
    return ('PASS',d,len(contexts),len(poselts),sum(len(v) for v in buckets.values()))

if __name__=='__main__':
    print('Finite:')

    print('Regular (ab)+:')

    block={''.join(p) for p in product(('aa','bc'),repeat=3)}

## 付録 B：再現手順と検査の論理的限界

`py -3 script.py` を実行する。正則篩いのモノイド・型の7元は `('',e), (a,1), (b,1), (c,ζ), (aa,1), (ab,1), (ba,1)` で代表される。文脈変換の像は6種類で、正のセパレータの変換像は5種類。ゆえに d=1 文脈像数 `6²=36`、d=2 文脈像数 `6·5·6=180`、正の成分シグネチャ6個と d=2 成分組36個の全場合が覆われる。`ψ(x)` と `s_U(x)` が同じ語は任意の DFA 文脈に対して区別不能なので、無限の語列挙を有限化した判断は**完全**である。有限言語の検査も、受理可能な語を一つずつ切り抜いた全出現を用いるため、共通受理文脈を一つでも持つタプルは必ず列挙される。

**限界**：既存倍増族の `n≤2` の失敗は確認できるが、一般 `n` の所属否定は計算からではなく原稿・前報の一様証明に依拠する。一般の任意正則篩いが `O(‖G‖θ̄_G)` で検出されるとの主張もしていない。
