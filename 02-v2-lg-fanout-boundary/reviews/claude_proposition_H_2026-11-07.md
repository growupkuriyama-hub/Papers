## 1. 設定と規約

### 1.1 文法

G = (N, Σ, R, S) は MCFG。各規則 R : A → f_R(B_1, …, B_k) について、f_R は**線形かつ非削除**（右辺の各変数がちょうど一回現れる）。これが、この文書が「good」の内容として使う唯一の性質である（(G1)）。**既約**：全ての非終端が S から到達可能で、生成的。ランク r = 規則の右辺の非終端の数の最大、v = |N|。ファンアウトに制限はない（証明はファンアウトを一度も使わない）。

- t_R：f_R が直接書く終端の列（全成分をつないだもの）。
- 組 u = (u_1, …, u_m) の長さ |u| = Σ|u_i|、パリクベクトル π(u) = Σ π(u_i) ∈ ℤ³（座標 a, b, c）。
- **(P1) パリクの加法性。** (G1) から、π(f_R(u_1, …, u_k)) = π(t_R) + Σ_j π(u_j)。

### 1.2 厚さ

- τ(B) = min{|u| : u は B の生成}（非終端の厚さ）。
- ρ(R) = |t_R| + Σ_j τ(B_j)（規則 R を根に使う生成の最短の長さ。(P1) から）。
- **θ = θ̄_G = max_R ρ(R)**（規則の厚さ）。

使うのは次の三つだけ：(T1) τ(B) ≤ θ（B は既約なので左辺に持つ規則がある）、(T2) |t_R| ≤ θ、(T3) |t_R| + Σ_{j∈J} τ(B_j) ≤ θ（任意の子の部分集合 J）。L ⊆ Σ⁺ なので θ ≥ 1。

### 1.3 言語

D は有向多重グラフで、**各文字がちょうど一本の辺**（文字 σ の辺を tail(σ) → head(σ) と書く）。Path_D(s,t) は s から t への歩道の辺の列としての語。φ : Σ* → A は可換群（有限とは限らない）への準同型、H ≤ A。φ は π を経由する：φ(w) = Φ(π(w))、Φ(m) = Σ_σ m_σ φ(σ) は ℤ³ → A の線形写像。

L = { w ∈ Path_D(s,t) ∩ Σ⁺ : cont(w) ∈ 𝓜, φ(w) ∈ g_{cont(w)} + H }  (16)

μ_{ab}(L) = 内容がちょうど {a,b} の L の語の最短の長さ。「ab 語」「abc 語」は内容がちょうど {a,b}、{a,b,c} の語。

境界写像 ∂ : ℤ³ → ℤ^{V(D)}、∂m = Σ_σ m_σ (𝟙_{head(σ)} − 𝟙_{tail(σ)})。s から t への歩道 w について ∂π(w) = 𝟙_t − 𝟙_s。

### 1.4 導出木の操作

導出木 T の節点 z のラベルを A_z、使う規則を R(z)、生成（成分の組）を y(z) と書く。

- **(S1) 置き換え。** z の部分木を、同じラベルを根に持つ別の導出木に置き換えると、正しい導出木になる。比較不能な（祖先・子孫の関係にない）節点の集合は、同時に置き換えられる（部分木が交わらない）。
- **(S2) 置き換えの効果。** z の部分木を生成 u の木に置き換えた語を W[z ← u] と書くと、π(W[z ← u]) = π(W) − π(y(z)) + π(u)。複数の比較不能な節点でも同様に足し合わせる。ファンアウト2以上でも、成分の和で数えるので成り立つ。
- **(S3) 包含。** z′ が z の子孫なら、y(z′) の各成分は y(z) の成分の（互いに重ならない）部分語で、|y(z′)| ≤ |y(z)|。z が重い（後述）ならその祖先も全て重い。

**印。** W の中の a の出現と b の出現を一つずつ選び「印」と呼ぶ。印の出現はそれを書いた節点（その t_R に属する）を持つ。節点 z の**印の集合** M_z ⊆ {a,b} は、z の部分木の中にある印の文字の集合。

### 1.5 規約の換算

報告書の θ̄ が「非終端の厚さと |t_R| の最大」（τ_G = max(max_B τ(B), max_R |t_R|)）なら、ρ(R) ≤ (r+1)τ_G なので、以下の θ を (r+1)τ_G に置き換えればよい。報告書の定理1.2 の上界 12θ̄³ に r が現れないことは、報告書が規則の厚さ（またはそれ以上の量）を θ̄ としていることを示唆する。

**補題 3.2（代表の長さ）** [証明済み]。B ∈ N、F ⊆ {a,b} とし、B が F の文字を全て含む生成を持つとする。F の文字を全て含む B の生成の最短の長さを ℓ(B,F) とすると

ℓ(B,∅) ≤ θ、 ℓ(B,{σ}) ≤ vθ、 ℓ(B,{a,b}) ≤ 3vθ。

*証明。* F の文字を全て含む B の生成の導出木 D を取り、F の各文字の出現を一つずつ印とする。「背骨」を印を含む部分木の根の集合とする。

（各項は (T3) で θ 以下）。F = ∅ なら (T1)。∎

## 4. 場合 A の証明

W を L の最短の ab 語（N = |W| = μ_{ab}）、T を、最短の ab 語の導出木のうち節点数が最小のものとする（(|W|, 節点数) の辞書式最小）。節点 z は |y(z)| > θ のとき**重い**。根が重くなければ N ≤ θ で終わり。

**補題 4.1（印のない重い節点は c-強制）** [証明済み]。印を固定する。M_z = ∅ の重い節点 z について、長さ θ 以下の A_z の生成は全て c を含む。

*証明。* 長さ θ 以下の生成 ω が c を含まなければ、W[z ← ω] ∈ L(G) = L は印を全て含み（z の外にある）、内容は {a,b}、長さは N − |y(z)| + |ω| < N。最短性に反する。∎

**補題 4.2（四語の比較）** [証明済み]。場合 A では、印を含まない重い節点の比較不能な組 t, t′ は存在しない。{a,b,c} ∉ 𝓜 なら、印を含まない重い節点は一つも存在しない。

*証明。* (T1) から長さ θ 以下の生成 ω_t、ω_{t′} がある。補題4.1 から両方とも c を含む。(S1) から W_t = W[t ← ω_t]、W_{t′}、W_{tt′} は L(G) = L の語。印は t, t′ の外にあるので残り、c が加わるので内容は全て {a,b,c}。

- {a,b,c} ∉ 𝓜 なら W_t ∉ L で矛盾（一つの節点 t で足りる）。
- そうでなければ、(S2) と Φ の線形性から
  Φ(π(W_t)) − Φ(π(W)) = Φ(π(ω_t) − π(y(t))) = Φ(π(W_{tt′})) − Φ(π(W_{t′}))。
  左辺は (g_{abc} + H) − (g_{ab} + H) = g_{abc} − g_{ab} + H に入り、右辺は (g_{abc}+H) − (g_{abc}+H) = H に入る。従って g_{abc} − g_{ab} ∈ H。場合 A の仮定に反する。∎

**場合 A の結論** [証明済み]。印を任意に固定する。重い節点の集合は祖先について閉じている（(S3)）。その葉（重い子を持たない重い節点）を数える。

- 印を含む葉は互いに比較不能で、それぞれ印を含むので高々2個。
- 印を含まない葉は互いに比較不能なので、補題4.2 から高々1個（{a,b,c} ∉ 𝓜 なら0個）。

よって葉は高々3個（2個）。根から一つの葉への道の上で、M_z は単調に減り（{a,b} ⊇ … ⊇ ∅）、高々3つの値を取る。補題3.1 と T の最小性から、同じ値の区間の中でラベルは相異なる。従って道の長さは高々 3v、重い節点は高々 3v·3 = 9v 個（6v 個）。最後に

N = Σ_{z 重い} ( |t_{R(z)}| + Σ_{z の軽い子 j} |y(j)| ) ≤ (θ + rθ)·(重い節点の数) ≤ 9(r+1)vθ

（(T2) と、軽い子の生成の長さ ≤ θ）。{a,b,c} ∉ 𝓜 なら 6(r+1)vθ。∎

**(153) の補題1 との関係。** 上の数え方は、q′ を印を含まない c-強制の重い節点の最大反鎖の幅として N ≤ 3(r+1)vθ(q′ + 2) を与える（葉 ≤ q′ + 2）。(153) の補題1（q は c-強制の重い節点全体の最大反鎖）はこれより弱い形で、場合 A では q ≤ 3 から 15(r+1)vθ。依頼文の復元の N ≤ 15(r+1)vθ は正しいが、直接数えると 9 になる。

## 5. 場合 B の証明

仮定（場合 B）から次が成り立つ：

**(★)** a と b をともに含む L の語 w は、全て φ(w) ∈ g_{ab} + H。

（実際、cont(w) ∈ 𝓜 ∩ {{a,b},{a,b,c}} で、{a,b,c} ∉ 𝓜 か g_{abc}+H = g_{ab}+H。）

W を L の任意の ab 語（最短でなくてよい）、T をその任意の導出とし、印を固定する。

### 5.1 印型の代表と恒等式

各 (B, M)（M ⊆ {a,b}、B が M の文字を全て含む生成を持つ）に、**代表** rep(B,M) を一つ固定する：M の文字を全て含む B の最短の生成（とその導出木）。c や M の外の文字を含んでもよい。

T の節点 z に対して、p_z = rep(A_z, M_z)、p′_z = f_{R(z)}(rep(B_1, M_{z_1}), …, rep(B_k, M_{z_k}))（z_j は z の子）、δ_z = π(p′_z) − π(p_z)、p₀ = π(rep(S, {a,b})) とおく。M_z は、z の子孫として T に現れる組なので、代表は存在する（y(z) が M_z を含む）。

**補題 5.1（恒等式）** [証明済み]。π(W) = p₀ + Σ_{z ∈ T} δ_z。

*証明。* (P1) から Σ_z π(t_{R(z)}) = π(W)。また Σ_z Σ_j π(rep(B_j, M_{z_j})) は根以外の各節点 z′ について π(rep(A_{z′}, M_{z′})) をちょうど一回数える（z′ はその親の子としてちょうど一回現れ、そのとき使う代表は z′ 自身の (A_{z′}, M_{z′}) で決まる）。従って Σ_z δ_z = π(W) + Σ_{z≠根} π(p_z) − Σ_z π(p_z) = π(W) − p₀（根の印集合は {a,b}）。∎

恒等式は代表の選び方によらない単なる打ち消しで、代表が節点の型の関数であることだけを使う。

**印集合と規則の関係。** 各印は z の t_R にあるか、ちょうど一つの子の部分木にあるので、M_z = M(t_{R(z)}) ⊔ ⨆_j M_{z_j}（交わらない合併。M(t_R) は t_R に属する印の文字）。

### 5.2 証人と Φ(δ_z) ∈ H

**補題 5.2** [証明済み]。各 z について Φ(δ_z) ∈ H かつ ∂δ_z = 0。また Φ(p₀) ∈ g_{ab} + H、∂p₀ = 𝟙_t − 𝟙_s。

*証明。* 証人として w_z = W[z ← p_z]、w′_z = W[z ← p′_z] を取る。(S1) から両方とも L(G) = L の語。

- p_z は M_z の文字を含む（代表の定義）。p′_z は M(t_{R(z)}) ∪ ⋃_j M_{z_j} = M_z の文字を含む（上の関係と代表の定義）。
- z の外には、M_z に入らない印がある。従って w_z、w′_z はどちらも a と b を含む。
- (★) から Φ(π(w_z)), Φ(π(w′_z)) ∈ g_{ab} + H。(S2) から差は Φ(π(p′_z) − π(p_z)) = Φ(δ_z) なので、Φ(δ_z) ∈ H。
- 両者とも s から t への歩道なので ∂ の値は等しく、∂δ_z = 0。
- rep(S,{a,b}) は a, b を含む L の語なので、(★) から Φ(p₀) ∈ g_{ab} + H。∎

文脈（W の z の外の部分）は差で消えるので、**証人の語の長さはどこにも使わない。**

### 5.3 生成元と基点の大きさ

**補題 5.3** [証明済み]。‖p₀‖₁ ≤ 3vθ、|p_z| ≤ 3vθ、|p′_z| ≤ (3v+1)θ、従って ‖δ_z‖_∞ ≤ (3v+1)θ。

*証明。* ‖p₀‖₁ = |rep(S,{a,b})| ≤ 3vθ と |p_z| ≤ 3vθ は補題3.2。p′_z について、M_{z_j} = ∅ の子は代表の長さが τ(B_j) なので、(T3) から |t_R| + Σ_{M_{z_j}=∅} τ(B_j) ≤ θ。M_{z_j} ≠ ∅ の子は、印の割り振りから「{a,b} の子が一つ」「一文字の子が高々二つ」のどちらかで、補題3.2 から代表の長さの和は max{3vθ, 2vθ} = 3vθ 以下。合わせて (3v+1)θ。δ_z の各座標は [−|p_z|, |p′_z|] に入る。∎

（復元のように型を F_z = cont(y(z)) で取ると、非消去の文法では全ての子が F ≠ ∅ になり、|p′_z| ≤ θ + r·3vθ。r が入るのはこのため。）

### 5.4 格子補題

**補題 5.4（補題5.2 の自前の版）** [証明済み]。Γ ⊆ ℤ³ を ‖γ‖_∞ ≤ Θ（Θ ≥ 1）の有限集合、Λ = ⟨Γ⟩_ℤ、p₀ ∈ ℤ³、Θ₀ = ‖p₀‖₁ とする。P = (p₀ + Λ) ∩ (ℤ² × {0}) が x, y ≥ 1 の点を含むなら、P は x, y ≥ 1 かつ

x + y ≤ K(Θ, Θ₀) := 2Θ²Θ₀ + 8Θ² + 2

の点を含む。特に Θ₀ ≤ Θ なら K ≤ 12Θ³。

*証明。* w = (x,y,0) ∈ P（x,y ≥ 1）とする。座標を (x,y,z) と書き、z は c の座標。二つの事実を使う。

- (F1) γ, γ′ ∈ Γ なら u(γ,γ′) := γ_z γ′ − γ′_z γ ∈ Λ ∩ {z=0}、‖u‖_∞ ≤ 2Θ²。γ, γ′ が一次独立で γ_z, γ′_z の一方が 0 でなければ u ≠ 0。
- (F2) n = γ × γ′（外積）は整数ベクトルで ‖n‖_∞ ≤ 2Θ²。|n · p₀| ≤ ‖n‖_∞ ‖p₀‖₁ ≤ 2Θ²Θ₀。

Λ の階数で分ける。

**(i) 階数3。** Γ は一次独立な γ₁, γ₂, γ₃ を含み、少なくとも一つ（γ₁ とする）は γ₁z ≠ 0（三つとも平面 z=0 には入らない）。u₂ = u(γ₁,γ₂)、u₃ = u(γ₁,γ₃) は Λ ∩ {z=0} の一次独立なベクトル（a u₂ + b u₃ = 0 なら γ₁, γ₂, γ₃ の係数比較で a γ₁z = b γ₁z = 0）。M = ℤu₂ + ℤu₃ の基本平行四辺形 Π = {s u₂ + t u₃ : s,t ∈ [0,1)} は、ℝ² の任意の平行移動 b + Π が w + M（⊆ P）の点をちょうど一つ含む。Π の x 座標の幅は |u₂x| + |u₃x| ≤ 4Θ²、y も同様。b を、b + Π の x, y 座標の下限が 1 になるように取れば、その点は 1 ≤ x, y ≤ 1 + 4Θ²。x + y ≤ 2 + 8Θ²。

**(ii) 階数2、Λ ⊆ {z=0}。** 一次独立な二つの生成元で (i) と同じ議論をすると x + y ≤ 2 + 4Θ。

**(iii) 階数2、Λ ⊄ {z=0}。** 一次独立な γ₁, γ₂ ∈ Γ を取る。n = γ₁ × γ₂ について p₀ + Λ ⊆ {X : n·X = c}、c = n·p₀、|c| ≤ 2Θ²Θ₀。Λ ⊄ {z=0} なので (n_x, n_y) ≠ (0,0)、P は平面 z=0 の直線 ℓ : n_x x + n_y y = c の上にある。Λ₀ = Λ ∩ {z=0} は ℓ の方向の一次元の格子で、(F1) の u(γ₁,γ₂) ≠ 0 を含むので、その生成元 u は ‖u‖_∞ ≤ 2Θ²。P = w + ℤu。

- (a) n_x n_y > 0：正としてよい。ℓ 上で x, y ≥ 1 の点は x + y ≤ n_x x + n_y y = c ≤ 2Θ²Θ₀。w 自身が条件を満たす。
- (b) n_x = 0：ℓ 上で y = c/n_y、|y| ≤ 2Θ²Θ₀。u = (u_x, 0) なので x を [1, |u_x|] に動かせる。x + y ≤ 2Θ² + 2Θ²Θ₀。n_y = 0 も同様。

### 5.5 語に戻す（オイラー路）

**補題 5.5** [証明済み]。m = (x′, y′, 0)、x′, y′ ≥ 1、∂m = 𝟙_t − 𝟙_s とし、D の辺 a, b を含む弱連結な部分グラフに s が乗っているとする。このとき、辺 a を x′ 回、辺 b を y′ 回使う s から t への歩道がある。

*証明。* 辺 a の x′ 本の複製と辺 b の y′ 本の複製からなる多重グラフは、辺の台が {a, b} で、仮定から弱連結。s ≠ t なら t → s の辺を一本足すと入次数と出次数が全ての頂点で釣り合い、弱連結なので強連結で、オイラー閉路がある。足した辺を除けば s から t へのオイラー路。s = t なら釣り合っていて、s が辺に接するのでオイラー閉路を s から始める。∎

W は a と b を両方使う s から t への歩道なので、辺 a, b を含む部分グラフは弱連結で s が乗っている。

**1. 場合1：同時の置き換え、印、加法性。** 正しい [証明済み]。

## 8. 残る問題

## 10. `op:fanout-two` に対して意味すること・しないこと

**意味すること** [証明済み]。(16) の形の言語は、どの既約・線形・非削除の MCFG 表示（任意のファンアウト、代入可能性を問わない）でも μ_{ab} ≤ max{9(r+1)vθ̄, 226v³θ̄³}。従って、μ_{ab} が超多項式になる反例の族を (16) の中に探しても見つからない。「内容ごとに受理剰余類を変える」ことは、可換群の不変量で区別できる限り、μ_{ab} を長くする手段にならない。

**意味しないこと。**
- 一般の代入可能な言語での、c-強制の重い節点の反鎖の幅 q の上界ではない。場合 B は q を全く抑えずに μ_{ab} を抑えている（大域の可換な不変量 Φ を使う）。(153) の帰着 N ≤ 3(r+1)vθ(q+2) を一般に使う道は開いたままである。
- τ（全ての型付き非終端の代表の長さ）や μ_{a} など、他の量の上界ではない。
- 証明は、言語が大域の可換な不変量 Φ で切り出され、内容ごとの剰余類が一つの部分群 H を共有することを使っている（A/H が有限なら (16) は正規言語。A/H が無限なら正規とは限らない。例：φ(a) = 1, φ(b) = −1 ∈ ℤ, H = 0）。H が内容ごとに違う場合（言語 J の読み2）や非可換の不変量は、この結果の外にある。
