## 1. 問いと、ここまでで分かったこと

Σ = {a, b, c}、内容型付け c、L ∈ C_{2,c}（arity 1 と 2、arity 2 の区切りは空でない）、G は L∩Σ⁺ の reduced good な表示（ファンアウト ≤ 2、ランク ≤ r）、v = |V|、θ = θ̄_G。

> **Q：μ_a(L) := min{k : a^k ∈ L} は poly(‖G‖, θ) で抑えられるか。**

否定の族があれば `prop:rare-type` により `op:fanout-two` が否定で解ける。

k := μ_a ≥ 5、T を a^k の節点数最小の導出とする。これまでに証明されたこと：
- 個数の漏れ：同じ a 骨格の二語の a の個数の差は 0 か k 以上（1〜k−1 の差は a^{k'}、k' < k を強制）。
- 各重い節点 h（非終端 B）の短い生成組 ω_B は b か c を含む（逃げ道）。その符号 κ(B) := σ_a(a ω_{B,1} a ⋯ a) が同じなら、失う a の数 w_h は同じ。
- 倍増節点と、その清浄で重い子孫は、同じ符号を持てない。したがって μ_a が超多項式なら、一本の道の上に ω(log n) 個の倍増節点があり、それらの符号は全て異なる。
- k ≤ 4vθ[1 + r(1 + r(v−1))·r^M]（M は符号の種類数）。θ が定数なら μ_a = O(v²)。

**止まった場所**：倍増節点で a だけの生成組と逃げ道を混ぜても、矛盾は自動的には出ない。比べられるのは成分ごとの内容が一致するときだけで、個数の漏れを起こすには a 骨格まで同じでなければならない。

## 2. 問い（骨格衝突の補題）

> **補題C（予想）**：清浄で重い倍増節点が一本の道の上に m 個並び、それぞれ異なる逃げ道の符号 κ_1, …, κ_m を持つとする。m が十分大きければ（例えば m > C·log(‖G‖ + θ)、または m > poly(θ)）、逃げ道の差し替えの組合せ（同時に差し替える反鎖 J、J′）と、再配分・隙間の合流・共役移送・冪の移行・境界の交換を使って、**同じ a 骨格を持ち、a の個数の差が 1 以上 k−1 以下の二つの L の語**が作れる。

補題C が成り立てば、定理5.1 と合わせて μ_a ≤ poly(‖G‖, θ) となり、Q が肯定で解ける。

## 3. 考えるための手がかり（使う前に確かめること）

- **符号の数の制約**：符号は長さ θ+3 以下の {a,b,c} の語なので、種類は高々 3^{θ+4}。一方、ω(log n) 個が要る。つまり反例は θ が少なくとも ω(log log n) 程度に大きいことを要する。
- **反鎖の骨格**：互いに祖先と子孫の関係にない清浄な重い節点の集合 J を同時に差し替えた語の骨格は、J の各節点の符号を穴の中に左から並べたもので決まる（位置の順序だけが効く）。二つの反鎖で「並べた符号の列」が同じなら、失う a の総数が同じ（不足の加法性）。
- **鳩の巣**：一本の道の上の倍増節点 h_1（上）, …, h_m（下）で、各 h_i の「道から外れる重い子」y_i は互いに比べられない（反鎖）。y_i の符号の列から、同じ並びを二通りに作れれば、加法性から重みの関係式が出る。符号が全て異なっても、隙間の合流（隣り合う逃げ道の間の a の塊を消してつなぐ）を経ると、つないだ後の語の骨格が一致することがある。
- **重みの関係**：倍増節点では、上の節点の長さは下の重い子二つの長さの和以上になるので、重み（失う a の数）は道を上るごとに増える。重みが一つ違う二つの組合せが同じ骨格になれば矛盾。
- **二文字ではこの補題が成り立つ**（`thm:two-letter-content`）：隙間が b の塊だけなので、合流で b⁴ ができて再配分が効く。三文字では隙間に b と c の両方が入る。

## 4. してほしいこと（優先順）

1. **補題C を証明する**（肯定側）。一般に示せない場合は、示せる場合を切り出して証明する。例：
   - 逃げ道が全て一成分（fan-out 1 の非終端）の場合。
   - 符号の中の b, c の並びが互いに「順序づけられる」場合（例えば全て b*c* の形）。
   - b⁴ か c⁴ のどちらかが L に現れる場合（その文字について再配分が効く）。
2. **否定側**：補題C を満たさない（同じ骨格の衝突を起こさない）符号の系を、L ∈ C_{2,c} の中で実現する族を作る。作れたら、L_n ∈ C_{2,c}（arity 1 と 2 を省略せずに）、G_n が reduced good でファンアウト ≤ 2・ランク ≤ 2、‖G_n‖ と θ̄_{G_n}（n の多項式）、μ_a(L_n)（超多項式）を全て証明する。
   - 前回までに壊れた候補（倍増の型 E_i → E E | d_i は d_i によらず壊れる、接頭符号 bc^i b と (bc)^i bb、逃げ道 bc の倍増、K_n、Thue–Morse 型、ブロックの族）は使わない。
3. どちらも完了しない場合は、証明できたこと、止まった場所、補題C の反例になりそうな符号の系の具体的な形を書いて終える。

## 5. 計算について

否定側では、抽象的な模型（一本の道の上の倍増節点、各節点の逃げ道の符号と重み、反鎖の差し替えで生じる骨格と a の個数）を作り、小さい場合に補題C の反例（衝突の起きない符号の系）が存在するかを全数で探すことを勧める。見つかれば、それを具体的な言語に落として有限言語の (1,c)・(2,c)-代入可能性の全数検査をする。Python 3 の標準ライブラリだけで書き、全文を載せる（Windows の `py -3 script.py` で動く形）。有限の検査の結果から無限の族の代入可能性を推定しない。
