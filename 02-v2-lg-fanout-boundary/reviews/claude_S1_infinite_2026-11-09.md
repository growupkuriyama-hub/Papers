## 1. 課題1：定理P の検査

### 1.1 補題R：正しい（有限性は不要）

- W₁ ≡ W₂ ≡ W₃：L の b 語どうしは文脈 (ε, ε) を共有。

- z₀z₀ = (ωa^gω)a^g ≡ ωa^{d+g} = z₀a^d、a^dz₀ ≡ ωa^da^g = z₀a^d。正しい。
- 補題2.1 の証明（zx の文脈 (l, r) から x, y が文脈 (lz, r) を共有）も正しい。

**T への適用（依頼の確認点）.**
- 種どうしは互いに素：u₂ が u₁ の子孫なら、u₁ の子のうち u₂ を含む方は生成語が u₂ より長く重い。これは「種は重い子を持たない」に反する。従って g₀ = x₂ − x₁ − n_Y ≥ 0。
- W₂（u₁ だけ替える）と W₃（u₂ だけ替える）が補題R の形になるには、**二つの種の純な長さが等しい（n₁ = n₂）** ことが要る。n₁ < n₂ なら u₂ の部分木を u₁ の部分木に替えて、より短い純な語ができる（有限なら補題0 による一意性からも出る）。原文は n_Y を「X の唯一の純な生成語の長さ」と定義しているので暗黙に正しいが、無限の場合に備えて明記すべき（**補足1**）。
- 部分木の差し替えは G′ の導出木を与えるので、W₁, W₂, W₃ ∈ L。C.0 は要らない。

### 1.2 補題P1：正しい

- (b) X の節点で使う規則 ρ について、ρ を使う長さ ≤ θ の成功語の中の X の生成語 y。y = a^p（p ≤ θ < n_X）なら、有限では補題0 に反する（無限でも、T の X の部分木を替えて a^{N−n_X+p} ∈ L となり最短性に反する）。
- (c) 子は軽く二分なので ≤ 2θ。単位規則なら種自身が軽くなるので起きない。
- (d) 重い節点は全て、どこかの種への道の上にある。重い子をたどれば種に着くからである。従って重い節点は ≤ sK 個。種でない重い節点の軽い子は ≤ 1 個で長さ ≤ θ、種は ≤ 2θ。合計 ≤ s(K+2)θ。
- (e) 隣り合う種 u, v の最小共通祖先 w からの二本の道（節点 ≤ K 個ずつ）にぶら下がる兄弟は ≤ 2(K−1) 個。どれかが重ければ間に種があることになり、隣り合うことに反する。従って間の文字は ≤ 2(K−1)θ、u 自身は ≤ 2θ、左端の差は ≤ 2Kθ。K+1 個の連続した種から鳩の巣で d ≤ K·2Kθ。正しい。

### 1.4 定理C\*：正しい（記録の論証の端の場合）

w_{π′} の区間を w_π に移した語 w_π[0,p)·w_{π′}[p,q)·w_π[q,m) を場合ごとに見る。

## 2. 課題2：無限の標的（定理P∞）

以下、L ∈ C₁（s_{U,2}）は**無限でもよい**。L は純な語を持ち、a^N が最短の純な語。G、G′、T、K、θ、重い、種は §1 と同じ。

### 2.1 無限でもそのまま残るもの

- **補題P1 (a)–(e)**：(a) は §1.2 のとおり、最短性と節点数最小から。(b) も最短性から（§1.2）。(c)–(e) は木の組合せ論だけ。
- **n_X は T の中で well-defined**：T の同じラベルの二節点の生成語の長さが違えば、長い方を短い方に替えて短い純な語ができる。**補足1 の n₁ = n₂ はこれで出る。**
- **補題R、C.0、補題2.1、補題2.2′**（合同性だけ）。従って (P1) の z₀ := ω_Ya^{g₀} と (C1′)（g = c = d）、(P2) の符号 ẑ_i ≡ a^{e_i}z₀（d | e_i）、(★)、(P3) の l = a^{ρ′}, r = a^ρ, e\* と l a^{e\*}z₀ r ∈ L は全て成り立つ。
- **定理C\* の記録の論証**（§1.4 の注意のとおり、使うのは差し替えと補題2.3′ だけ）。

崩れるのは補題2.3′ だけ（依頼文の見通しどおり）。

### 2.2 周期の構造（見通しの訂正）

**補題Π.** P₀ := {p ≥ 0 : a^p z₀ ≡ z₀} とおく。
- (a) P₀ = {0} か、ある p₀ ≥ 1 について P₀ = p₀ℕ。
- (b) 語 l, r が l a^{e} z₀ r ∈ L（ある e ≥ 0）を満たすとき、F(l, r) := {f ≥ 0 : l a^f z₀ r ∈ L} は e_min + P₀ に等しい。

*証明.* z₀ = ω_Ya^{g₀} は W₁ の因子なので分布は空でない。
- (a) P₀ は加法で閉じる：a^{p+q}z₀ = a^p(a^qz₀) ≡ a^pz₀ ≡ z₀。差でも閉じる：p < q ∈ P₀ なら a^pz₀ ≡ z₀ ≡ a^p(a^{q−p}z₀)。z₀ と a^{q−p}z₀ は b 語、a^pz₀ ≡ z₀ の分布は空でないので、補題2.1 で左の a^p を消して q − p ∈ P₀。
- (b) f, f′ ∈ F(l, r) なら、a^fz₀ と a^{f′}z₀ は b 語で文脈 (l, r) を共有するので C₁ から ≡。f < f′ なら補題2.1 で a^f を消して f′ − f ∈ P₀。逆に f ∈ F、p ∈ P₀ なら a^{f+p}z₀ = a^f(a^pz₀) ≡ a^fz₀ なので f + p ∈ F。従って F = min F + P₀。□

依頼文の「類は f ≥ f₀ で周期 p」は、**f₀ = 0**（純粋に周期的）に強められる。以下 D := lcm(d, p₀)（P₀ = {0} なら D := ∞）とおく。

### 2.3 補題S（周期が小さければ短い純な語）

**補題S.** P₀ ≠ {0} なら N ≤ 2D + d。

*証明.* D の取り方から、a^Dz₀ ≡ z₀（p₀ | D）と z₀a^D ≡ a^Dz₀ ≡ z₀（d | D、(C1′)）が成り立つ。

u₁ を ω_Y に替えた語 W := a^{x₁}ω_Ya^{y₁} = a^{x₁}z₀a^{y₁−g₀} ∈ L を使う。ここで y₁ = d + y₂ ≥ g₀、x₁ + n_Y + y₁ = N。

- **左**：x₁ > D とする。W = a^{x₁−D}(a^Dz₀)a^{y₁−g₀} ≡ a^{x₁−D}ω_Ya^{y₁} なので、後者も L に入る。従って空でない純な語 a^{x₁} と a^{x₁−D} は、b を含む文脈 (ε, ω_Ya^{y₁}) を共有する。C₁ から D_L(a^{x₁}) = D_L(a^{x₁−D})。a^{x₁} は純な文脈 (ε, a^{N−x₁}) を持つ（x₁ < N）ので、a^{N−D} ∈ L∩Σ⁺（N − D ≥ x₁ − D ≥ 1）。これは a^N の最短性に反する。よって x₁ ≤ D。
- **右**：y₁ − g₀ > D とする。W ≡ a^{x₁}z₀a^{y₁−g₀−D} = a^{x₁}ω_Ya^{y₁−D}（y₁ − D > g₀ ≥ 0 なので右の塊は空でない）。a^{y₁} と a^{y₁−D} は文脈 (a^{x₁}ω_Y, ε) を共有するので ≡。a^{y₁} の純な文脈 (a^{N−y₁}, ε) から a^{N−D} ∈ L で、矛盾。よって y₁ ≤ g₀ + D。
- N = x₁ + n_Y + y₁ ≤ D + (n_Y + g₀) + D = 2D + d。□

**依頼文の困難（型の違い）について**：補題S は b 語と純な語を比べない。比べるのは**二つの純な語**で、両者が共有する文脈 (ε, ω_Ya^{y₁}) の方が b を含むだけである。依頼文 §3 の既知の制約「純な語どうしが b 語の中で文脈を共有すると分布の一致が強制される」を、周期 a^Dz₀ ≡ z₀ で実際に起こしたのが補題S。

### 2.4 補題2.3‴（mod D での所属の判定）

**補題2.3‴.** u を崩壊する語（≡ a^ez₀、d | e）と d の倍数の純な塊の積とし、崩壊する語を少なくとも一つ含むとする。このとき

  l u r ∈ L ⇔ val(u) ≡ V\* (mod D)

（D = ∞ のときは val(u) = V\*。V\* は (P3) のとおり）。

*証明.* 補題2.2′ から u ≡ a^{val(u)−d}z₀ で、val(u) − d ≥ 0。従って l u r ∈ L ⇔ val(u) − d ∈ F(l, r) = e\*_min + P₀。e\* ∈ F(l, r) なので、これは val(u) − d ≡ e\* (mod p₀) と同じ（P₀ = {0} なら等号）。val(u) と V\* = e\* + d は d の倍数なので、mod lcm(d, p₀) と同値。□

### 2.5 定理P∞

**定理P∞.** L ∈ C₁（s_{U,2}、無限でもよい）が純な語を持ち、a^N を最短の純な語とする。G を L∩Σ⁺ の reduced・ε なしの CFG、厚さ θ、K := |V′| ≤ ‖G‖+2、λ := 5K²θ、B₁ := 14K²θ とする。Φ(K, θ) を、

  12B₁·6⁵ と、3^{M/3−1} ≤ K(M+1)(m+1)²(Mλ+1)²（m := (5K³+M+4)λ）を満たす全ての M ≥ 6 についての 12B₁·6^{M−1}

の最大とする。このとき

  N ≤ max{ K(K+2)θ, 2Φ(K, θ) + 2d } ≤ C(‖G‖+2)^{76}θ^{21}

（d ≤ 2K²θ。C は絶対定数。ランク r は現れない）。

*証明.*
- 根が種を ≤ K 個しか含まなければ、P1 (d) から N ≤ K(K+2)θ。以下そうでないとし、§2.1 の (P1)–(P3) を行う。
- Λ := min(V\*, D) とおく。
- **(P4′)** (P4) を「Λ/2 以下の値だけを取る」に替えて行う。§1.3 の論証は V\* を Λ に替えてそのまま通る。道が尽きたときは v₀ ≥ N ≥ Λ なので、最後の値 ≥ Λ/2。取った値は超増加で和 < Λ ≤ D なので、**部分和は mod D でも相異なる**。最後の値 > Λ/12 と最後の値 ≤ B₁6^{M−1} から、Λ < 12B₁6^{M−1}（M = 0 なら Λ < 2B₁）。
- **(P5)** はそのまま（目標は正確に V\*。等号なら合同も成り立つ）。
- **(P6′)** 定理C\* を、補題2.3′ を補題2.3‴ に替えて使う。記録の論証（§1.4）では、l u″ Q r ∈ L から val(u″) + val(Q) ≡ V\* ≡ Σv + val(Q)（mod D）が出る。従って Σ_{I(π′)} ≡ Σ_{I(π)}（mod D）で、部分和が mod D で相異なることから I(π′) = I(π)。残りは定理C\* と同じなので、M ≥ 6 なら計数の不等式が成り立つ。いずれにせよ **Λ ≤ Φ(K, θ)**。
- **場合分け.**
  - Λ = V\*：N < V\* + 2d ≤ Φ + 2d。
  - Λ = D < V\*：D は有限なので P₀ ≠ {0}。補題S から N ≤ 2D + d ≤ 2Φ + d。
- 最後の評価は定理P と同じ（Φ ≤ C′K^{75.4}θ^{20.6}(log)^{O(1)}、2d ≤ 4K²θ）。∎

**注意.**
- 有限の L では P₀ = {0}（a^pz₀ ≡ z₀、p ≥ 1 は補題0 に反する）で、定理P∞ は定理P に一致する。
- **群の原像** φ⁻¹(1)∩Σ⁺ では a^pz₀ ≡ z₀ ⇔ φ(a)^p = 1 なので、p₀ = ord φ(a) = N で D ≥ N。このとき定理P∞ は (P4′)(P6′) だけで N ≤ poly を与える。これは定理G の帰結のうち **ord φ(a) ≤ poly(‖G‖, θ)** の部分の、混合時間も Breuillard–Tointon も使わない別証明になる（|H| の評価は与えない）。定理G（独立検証済み）と同じ向きの結論なので矛盾はない。ただし**誤りを探す試金石**として、検証者には H_n = Z/(2ⁿ−1) ⋊ Z/n などの既知の例で、ord φ(a) と ‖G‖, θ の関係が定理P∞ と両立することを確かめてほしい。
