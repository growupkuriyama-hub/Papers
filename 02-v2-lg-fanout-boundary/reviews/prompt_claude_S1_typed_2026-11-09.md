- C₁：同じ型の空でない x, y が L の中で一つの文脈を共有すれば D_L(x) = D_L(y)。≡ は分布の同値（Σ\* 上の合同、分布が空の語どうしも ≡）。

  - 従って **t_typ ≤ poly(‖G‖, θ̄, r) なら、ファンアウト1・二文字・c で多項式の特徴データ**。

## 2. 依頼

**課題1（検査、最優先）.** 定理P∞-c の新しい部分を、反例を探すつもりで検査する。
- **補題S′**：a^pz ≡ z（z の分布は空でない）なら N ≤ p。
  - 証明の骨子：a と a^{1+p} が文脈 (la^{p−1}, zr) を共有するので a ≡ a^{1+p}。a^N の中の a^{1+p} を a に替える。
  - これは補題S を不要にする強い主張なので、特に慎重に読むこと。
- **補題R^c**：悪い場合（ω_Y ∈ b⁺、g₀ = 0）で基底を z₀ = ω_Ya^d、c = 2d に替える。確かめる点は次のとおり。
  - x ≥ 1 または y ≥ 1 であること（種 > K 個から）。
  - 消去の各段で残りの二語が同じ型（混合）であること。
  - z₀z₀ ≡ a^{2d}z₀ の計算。
- **補題C.0^c**：ω_{X_i} ∈ b⁺ のとき、純な文脈から a を一文字借りて aω_{X_i} ≡ aΩ_i を出す。確かめる点は次のとおり。
  - 借りた a が詰め物（s′_i ∈ [1, d] など）に収まること。
  - 悪い場合の価値 v_i = n_{X_i} + s_i + s′_i と κ ≥ 0。
- **根の符号が (P4′)(P5) で使われないこと。**
- 可能なら、小さな有限・正則の C_{1,c} 言語で定理P∞-c の構成を実際に計算して、等式を検査するスクリプト（補助）。

**課題2（本命：t_typ への拡張）.** 次の形の定理を証明するか、反例の族を作る。

> **予想T.** L ∈ C_{1,c}（Σ = {a,b}、無限でもよい）、G は L∩Σ⁺ の reduced・ε なしの CFG。(X, {a}) がトリムされた細分に現れるなら n_X^\* ≤ poly(‖G‖, θ̄)（b も対称）。従って t_typ(G, c) ≤ poly で、二文字・ファンアウト1・c の特徴データは多項式。

方針の候補を挙げる。
- (a) 定理P∞-c の論証を「根の代わりに X」で行う。T を、X の節点の生成語が純で、その純な長さが最小になる成功導出とする（さらに節点数最小）。X の部分木 T_X は純な語 a^{n} の導出で、外側の文脈 (l, r) は固定。
  - 確かめること：補題P1 (a)(b) の最短性の議論（X の部分木の中の道でラベルが反復すれば、縮めても成功導出のままか）。
  - 補題R（W₁, W₂, W₃ は l·…·r の形になる。W の内側の消去は、外側の l, r を文脈に含めて行えるか）。
  - 補題S′（a と a^{1+p} が文脈を共有すれば a ≡ a^{1+p}。そこから X の生成語 a^{n} の中の a^{1+p} を a に替えると、**同じ X の**より短い純な生成語が同じ文脈で L に入るか。≡ は L の分布の同値なので、l a^{n} r ∈ L ⇒ l a^{n−p} r ∈ L は出るが、a^{n−p} が X の生成語であることは出ない。ここが要点）。
  - 定理C\* の計数（X の部分木の符号を並べ替えた語が L に入ることは、X の部分木の差し替えから）。
- (b) (a) の要点の困難（「L の語として短い」と「X の生成語として短い」の違い）を、トリムされた細分の定義で回避できるか。t_typ の定義は「X の型 {a} の語のうち最短」であり、成功導出であることは (X, {a}) がトリムされていることだけを要求するのか、それとも最短の語そのものが成功導出に使えることまで要求するのか。`main.tex` の Definition `def:output-refinement` と `subsec:typed-thickness` を読んで確定すること。前者なら、X の純な生成語で成功導出に使えるものが一つあれば、最短の純な生成語そのものは任意に取れる。従って問いは「X の任意の純な生成語の最短の長さ」になり、L に依らない文法だけの問いに近づく。
- (c) 反例の族を作るなら、純な語を作る部分の文法が直線的プログラム（指数的に長い純な語を小さな文法で）で、その上の非終端 X の純な生成語が成功導出の中で使われ、しかも L ∈ C_{1,c} を保つもの。開始記号の純な語は定理P∞-c で多項式なので、**X の純な語が L の中で必ず b を含む文脈に置かれる**ことが必要。その場合に C₁ が何を強制するかを調べる。

**課題3（帰結の整理）.** 予想T が正しい場合の論文 #2 への帰結を、定理の形で一つにまとめる。候補は「二文字の内容型付け c（従って二文字の半束型付け全て）はファンアウト1で多項式の特徴データを持つ。三文字では U₁ 型付けがファンアウト1で指数的（論文の Theorem C）」。
