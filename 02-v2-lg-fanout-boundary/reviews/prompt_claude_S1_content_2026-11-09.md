## 1. 設定（自己完結）

- Σ = {a, b}。
- C₁ の定義：型付け τ（語から有限半群への射）について、同じ型の空でない x, y が L の中で一つの文脈を共有すれば D_L(x) = D_L(y)。≡ は分布の同値（Σ\* 上の合同関係。分布が空の語どうしも ≡）。
- G は L∩Σ⁺ の reduced・ε なしの CFG。‖G‖、厚さ θ、二分化 G′ の非終端数 K ≤ ‖G‖+2。a^N は L の最短の純な a の語。T は G′ での a^N の最短・節点数最小の導出。生成語の長さ > θ の節点が重い。重い子を持たない重い節点が種。
- **op:S1**：N ≤ poly(‖G‖, θ, r) か。
- **二つの型付け**
  - **s_{U,2}**：純な a の語は型 1、b を含む語は全て型 ζ。
  - **内容型付け c**：語をその文字の集合へ。型は {a}（純な a）、{b}（純な b）、{a,b}（混合）。c の方が細かいので C_{1,s_{U,2}} ⊆ C_{1,c} で、c での肯定の方が難しい。
- **(S1-c)**：c で N ≤ poly か。否定なら、この型付けでファンアウト1と高いファンアウトが分離される（論文 #2 の動機）。

## 2. s_{U,2} での結果（定理P∞、未検証）

- **補題R**：W₁ = a^xωa^gωa^y、W₂ = a^xωa^{d+y}、W₃ = a^{x+d}ωa^y ∈ L（d = g+n、n ≥ 1）なら、z₀ := ωa^g、c := d で a^cz₀ ≡ z₀a^c ≡ z₀z₀。
  - 証明：三語は L の b 語なので ≡。純な塊 a^x, a^y を補題2.1（同じ型の x, y について zx の分布が空でなく zx ≡ zy なら x ≡ y）で消す。
- **補題Π**：P₀ := {p : a^pz₀ ≡ z₀} は {0} か p₀ℕ。l a^ez₀ r ∈ L なら {f : l a^fz₀ r ∈ L} = f_min + P₀。
- **補題S**：P₀ ≠ {0}、D := lcm(d, p₀) なら N ≤ 2D + d。
  - 証明：W = a^{x₁}ω_Ya^{y₁} ∈ L で x₁ > D なら a^{x₁−D}ω_Ya^{y₁} ∈ L。二つの純な語 a^{x₁}, a^{x₁−D} が文脈 (ε, ω_Ya^{y₁}) を共有するので ≡。a^{x₁} の文脈 (ε, a^{N−x₁}) から a^{N−D} ∈ L で矛盾。右も同様。
- **補題2.3‴**：崩壊する語と純な塊の積 u について、l u r ∈ L ⇔ val(u) ≡ V\* (mod D)。
- **定理P∞**：L ∈ C_{1,s_{U,2}}（無限でもよい）なら N ≤ C(‖G‖+2)^{76}θ^{21}。
  - 証明：(P1) 種の鳩の巣で同じラベル Y の種を差 d ≤ 2K²θ で取り、補題R で基底を作る。(P2) 重い道の符号 ẑ_i = a^{s′}ω_{X_i}a^{s} ≡ a^{e_i}z₀。(P3) 目標 V\*。(P4′) 超増加で Λ = min(V\*, D) の半分まで取る。(P5) 貪欲な埋め草 Q。(P6′) 定理C\* の計数を mod D で行う。最後に Λ = V\* か Λ = D（補題S）で場合分けする。

## 3. 依頼

**課題1（検査、最優先）.** 定理P∞ の新しい部分（補題Π、補題S、補題2.3‴、(P4′)、(P6′) の mod D の計数、最後の場合分け）を、反例を探すつもりで検査する。特に以下を確かめる。
- 補題Π (a) の差での閉包で、消去に使う語の分布が空でないこと。
- 補題S で x₁ − D ≥ 1 の扱い（x₁ = D + 1 の境界）と、a^{x₁} が L の因子であること。
- (P6′) で、入れ替えた語から得た「部分和の mod D の一致」から I(π′) = I(π) を出す箇所（全ての部分和が D 未満か）。
- **群の原像での試金石**：φ: Σ\* → H（有限群）、L = φ⁻¹(1)∩Σ⁺ では p₀ = ord φ(a) = N。定理P∞ はこのとき ord φ(a) ≤ poly(‖G‖, θ) を、混合時間も Breuillard–Tointon も使わずに与える。既知の例（巡回群、二面体群、H_n = Z/(2ⁿ−1) ⋊ Z/n、対称群の n-サイクルと互換など）で ‖G‖, θ の既知の下界と矛盾しないかを確かめる。矛盾すれば定理P∞ のどこかが誤り。
- 可能なら、無限の正則な C₁ 言語で D < N となる例を探して補題S を空振りでなく検査する（付属スクリプトの (C-iii) は D < N の例を一つも持たなかった）。

**課題2（本命：S1-c）.** 定理P∞ の論証を内容型付け c に移す。こちらの見通し（**未検証**）は次のとおり。
- c では L の混合の語どうし、b⁺ の語どうしはそれぞれ ≡ だが、混合と b⁺ は C₁ から直接には比べられない。
- 補題R：W₂, W₃ は a^d を含むので混合。W₁ は x = g = y = 0 かつ ω ∈ b⁺ のときだけ b⁺。補題2.1 の消去は「同じ型」を要するので、ωa^gωa^y と ωa^{d+y} の型が一致するかを場合ごとに見る必要がある。危ないのは **ω_Y ∈ b⁺ で g₀ = 0**（隣り合う双子）と y = 0 の組合せ。種の取り方を工夫して避けられるか（例えば y₁ > 0 になる種の対を選ぶ、詰め物で全てを混合に寄せる）。
- 補題S は二つの純な語を比べるだけなので、c でもそのまま通るはず（文脈 (ε, ω_Ya^{y₁}) が混合でも b⁺ でも、比べる二語は型 {a}）。
- 補題Π：a^fz₀（f ≥ 1）は混合。z₀ 自身が b⁺ のときだけ f = 0 が型の違う語になる。
- (P2) の C.0 は、ω_{X_i} と a^{L_i}ω_Ya^{R_i} の型が一致する必要がある。ω_{X_i} が b⁺ で a^{L_i}ω_Ya^{R_i} が混合なら C.0 から ≡ は出ない。**ここが本当の障害になりうる**：重いラベル X の短い b 語が b⁺ しかなく、T の中の X の b 語は全て混合、という状況。その場合に (a) 別の短い混合の語を見つける、(b) 符号を b⁺ の側で組み直す、(c) 型 b⁺ の類と混合の類の二つの基底を持つ計数（定理C\* の二基底版）にする、のどれかで閉じられるか。
- 結論を (i) c でも肯定（定理の形で）、(ii) 否定の候補（上の障害を実際に起こす族）、(iii) 部分結果、のいずれかで報告する。

**課題3（否定の向き、課題2 が閉じない場合）.** 障害「重いラベルの短い b 語が b⁺ で、T の中の b 語は混合」を各段で起こす族を設計する。例えば各 X_i の短い語が b^{k_i} という形。長さを打ち切った c の強制閉包（同じ c の型で文脈を共有する因子を同じ類にまとめ、類の全ての文脈に全ての因子を入れる操作の繰り返し）で、C_{1,c} と両立するか、小さな CFG を持つかを検査する。
