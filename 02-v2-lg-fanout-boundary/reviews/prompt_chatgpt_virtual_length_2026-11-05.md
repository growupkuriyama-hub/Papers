## 1. 前報の主張（独立に検証すること）

Σ = {a,b,c}、内容型付け c、L ∈ C_{2,c}、G は reduced good、ファンアウト ≤ 2、ランク ≤ r、v = |V|、θ = θ̄_G。W は内容がちょうど {a,b} の最短の語、T はその節点数が最小の導出。

1. **補題1（帰着）。**
   - 重い節点は、「c で強制される」（生成の長さより短い生成が全て c を含む）か、「a か b の全ての出現を含む（保持者）」かのどちらかである。
   - μ_{ab} ≤ 3(r+1)vθ(q+2)。q は c で強制される重い節点の反鎖の最大の大きさ。
2. **補題2。** 比較不能で、保持者でなく、非終端が同じ重い節点は、生成の総長が等しい。
3. **補題3。** 近道の証明書の最後の段は必ず次の形である。c を含みうる共通の枠が、内容の同じ二つの c を含まない埋め草を受け入れ、長い方が W の因子になっている。
4. **命題5（トークンの障壁）。**
   - 逃げ道の近傍の種（W の互いに素な重い節点を、別の生成で置き換えた語）を、生成ごとに一つの抽象的な文字（トークン）として扱う。トークンの重みは、置き換えた節点の総長とする。
   - すると種は全て、一つの加法的な重みの水準集合に入る。この集合は全ての arity・全ての型付けで代入可能である。
   - よって、トークンの段階の証明書から近道は出ない。
5. **補題7・7′（逃げ道の因子の一致による近道）。**
   - 親の逃げ道が e_C = s·β（β は子の非終端の生成、s は c を含まない）なら、1段（内容がそろう場合）か2段で近道が出る。
   - (150) はその特別な場合である。
6. **計算。** 倍増族 A_i → A_{i−1}A_{i−1} | e_i で、m = 3 の短い逃げ道の網羅探索（2525 通り）を行った。
   - 閉包が閉じたのは 17 通りで、全て退化した場合（e_2 = e_1e_1 = cc）である。
   - 近道は 1349 通り、打ち切りは 1159 通り。

## 2. してほしいこと（優先順）

1. **独立の検証。** §1 の 1〜5 を自分で証明し直す。
   - 補題1(iii)（一本の道の節点は 3v 個以下：保持者の状態 σ が道の上で単調に変わること）と、補題7の前提が実際に L に入ることを特に確かめる。
   - 命題5 については、適用の仕方を確かめる。トークンの重みが矛盾なく決まること（補題2と、同じ非終端が入れ子で現れないこと）が要る。
   - 計算は、前報のスクリプトを使わず、自分で書いた閉包と再生で、少なくとも Part A・E と、m = 3 の七つの名前付きの設計を再現する。
2. **仮想の長さの定式化。** 前報 §6 の (D1) を、次のような形で定式化する。
   - L の各語 w に「仮想の長さ」ν(w) を割り当てる。c を含まない語では ν(w) = |w| とする。
   - 健全な規則の各段で ν の差が保たれる：E[x], E[y], F[x] ∈ L なら ν(F[y]) = ν(F[x]) − ν(E[x]) + ν(E[y])。
   - このような ν があれば近道は出ない（帰納法）。逆向き、つまり近道が出ないことから ν の存在が言えるか、言えるならどの範囲でかも調べる。
   - 定式化は他の形でもよい。目的に合う最も扱いやすい形を選ぶこと。
3. **肯定の向き：剛性は深い倍増で破れるか。**
   - 前報 §6 は、ν が文字の上で加法的なら倍増の深さ m ≤ log₂θ + 1 になることを示した（動機の段階）。
   - (100) 定理3.1 の ab 語版（言語全体が非負の加法的な重みの一つの水準に入るなら μ_{ab} ≤ poly）を証明する。
   - さらに、加法的でない ν について、逃げ道の長さが θ 以下という条件から、深い倍増では ν の整合性が必ず破れる（したがって補題3の形の近道が出る）ことを示せるか試みる。
4. **否定の向き：剛性を保つ逃げ道の族はあるか。**
   - m = 4（|W| = 32）以上で閉包を計算できる速い方法を作る。例えば、二穴の出現を、逃げ道の位置の周りや種の差分に制限する。制限が健全な規則の部分集合であることを明記すること（強制された語は正しいが、「強制されない」は観察にすぎない）。
   - 前報で打ち切りになった 1159 通りのうち、e_1 ≠ c、または e_2 ≠ e_1e_1 のものを優先して判定する。
   - 閉包が閉じ、近道のない非退化の設計が m = 4 で見つかれば、その文法の族について所属の証明に進む。
5. どれも完了しない場合は、次の三つを書いて終える。
   - 証明できたこと
   - 止まった場所
   - 次に絞るべき一点

## 4. 守ってほしいこと

- 冒頭に、主張ごとの判定の表を置く。検証した主張には「独立に確認」「誤り」「確認できず」のいずれかを、新しい主張には「証明済み／反証／観察／未解決」のいずれかを書く。
- 「自明に成り立つが目的には足りない」主張と、既に知られた補題の特別な場合にすぎない主張は、その旨を表に書く。
- まだ所属を示していない言語に、その所属を前提にした補題を使わない。
- 証明した範囲を超えて書かない。開始の型 {a,b} の結果を、他の欠けた型や τ に広げて書かない。
- 反例を主張するのは、所属・下界・文法の大きさの全てを証明した場合だけ。
- 「最大の特徴標本」と書かない。
- 「境界がファンアウトで動く」は、三文字の全ての内容型・全ての場合を証明した場合にだけ書く。
- 新しい結果が文献で既知かどうか、分かる範囲で書く。分からなければ「未確認」と書く。
