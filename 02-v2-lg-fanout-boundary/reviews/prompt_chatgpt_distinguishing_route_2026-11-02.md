## 1. 背景：唯一語の道は狭くなった

この論文の下界は全て、区別の補題（`lem:distinguishing`）から出ています。
> L' ⊊ L がともに C_{f,s} に入るなら、L のどの特徴標本も L∖L' の語を含む。

したがって、次の量は全ての特徴標本の長さの下界になります。
> **μ^dist(L) := max { min{ |w| : w ∈ L∖L' } : L' ⊊ L、L' ∈ C_{f,s} }**

今までは、L' として次の二つだけを使ってきました。
- **型の削除** L' = L∖s⁻¹(m)（`prop:rare-type`）。
- **一語の削除**（`prop:linear-factor-all-fanout`。全ての部分集合がクラスに入る族）。

ファンアウト2では、型の削除の道（唯一語の道）に強い制約が分かっています。
- 唯一語は5形に限られる。
- 唯一語と同じくらい長い他の語が要る。
- ζ 型の文字を超多項式個含む語が要る。

しかし、L' の取り方はほかにもあります。原稿の `prop:abelian-coset-filter` により、**任意の可換群への準同型 φ と剰余類 γ+H による篩い L ∩ φ⁻¹(γ+H) は、型付けによらず代入可能性を保ちます**。ほかに、型付けの像の受理集合 s⁻¹(Acc) との交わりもあります。これらで作る L' では、L∖L' は**多数の語、多数の型**にまたがってよく、唯一語の制約を受けません。

**注意**：LG の型付けでは、データの上界（定理A(i)）から μ^dist は自動的に多項式です。したがってこの問いが意味を持つのは、LG の外（U₁ への型付けや半束の内容型付け）だけです。

## 2. 問い

型付け s_U : {a, b, c}⁺ → U₁、a, b ↦ 1、c ↦ ζ を第一候補とします（半束の内容型付け c_Σ でも構いません）。ファンアウト f = 2、ランク r ≥ 2 です。

> **ファンアウト2で、C_{2,s} の標的の族 L_n、その reduced good な表示 G_n（‖G_n‖, θ̄_{G_n} が n の多項式）、および L'_n ⊊ L_n で L'_n ∈ C_{2,s} となるものがあって、L_n∖L'_n の最短の語の長さが n について超多項式になるか。**

**意味**：あれば、区別の補題により全ての特徴標本が超多項式に長くなり、`op:fanout-two` は否定で解決します（U₁ と内容型付けは半束の型付けなので、`prop:sl-reduction` により LG がファンアウト2でも境界になる）。

## 3. 調べてほしいこと（優先順）

**D1（可換群の篩いの道：本題）**
- L'_n = L_n ∩ φ⁻¹(γ+H) の形で、上の問いに答える族を作ってください。
  - φ は文字の個数の可換群への写像です。例えば |w|_a mod p、|w|_b − |w|_c など。
  - L_n∖L'_n は「篩いに通らない語」全体です。それらが全て長い、すなわち短い語は全て篩いを通るように設計します。
- 候補の考え方（使う前に確かめてください）：
  - (a) **群の語問題**：ファンアウト1での帰着（問題G）を、ファンアウト2の二穴の成分に移す。L を「型付けの像と可換群の値の組」で決まる言語にし、短い語では値が単位元に偏る。
  - (b) **Parikh 像の剰余**：短い語の Parikh ベクトルは全て格子 Λ に入り、Λ に入らない語は長い。そのような言語を、小さく薄い文法と代入可能性を両立させて作れるか。
  - (c) 前回までの失敗例（c で近道する倍増族、ブロックの族）を、篩いの道から見直す。型の削除では使えなかった族でも、篩いの削除なら区別の補題が使えるかもしれません。
- 必ず確かめてほしいこと：
  - L_n と L'_n の両方が C_{2,s} に入ること。全ての arity について代入可能性を証明してください。L'_n は `prop:abelian-coset-filter` から自動的に入りますが、L_n 自身の証明が必要です。
  - reduced good、ファンアウト、ランク、‖G_n‖ と θ̄_{G_n} の正確な値。
  - L_n∖L'_n の最短の語の長さ。
- 計算による探索を強く勧めます。小さい n での (1,s)・(2,s)-代入可能性の全数検査を、Python 3 の標準ライブラリだけで書き、全文を載せてください（Windows の `py -3 script.py` で動く形）。前回までの報告の `exhaustive` 関数を再利用して構いません。

**D2（一般の区別の道の限界：D1 が失敗する場合）**
- 次の形の上界を証明できるか調べてください。
  > ファンアウト2、s_U。L ∈ C_{2,s_U}、L' ⊊ L、L' ∈ C_{2,s_U} なら、L∖L' に長さ poly(‖G‖, θ̄_G) 以下の語がある。
- まず L' が可換群の篩いの場合に限って示し、次に一般の L' を調べてください。
- 唯一語の道での補題（高さの補題、重い節点の層、隙間の補題、密度の定理）のうち、どれが「多数の語」の場合に一般化できるかを明示してください。
- ファンアウト1との違いを明示してください。ファンアウト1では、型の削除の道で指数の下界が出ます（三文字の倍増族）。

**D3（整理）**
- 型の削除、一語の削除、可換群の篩い、s⁻¹(Acc) との交わりなど、L' の作り方ごとに、ファンアウト1とファンアウト2で μ^dist がどうなるかの表を作ってください。各欄は「指数（族あり）」「多項式（証明）」「未解決」のどれかです。
- 結果が `op:S1`、`op:fanout-two`、`prop:unique-word-route` にどう効くかも書いてください。
