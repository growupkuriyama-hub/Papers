## 1. 設定

- **族 F_n**：E_0 → a、E_i → l E_{i−1}E_{i−1} | c E_{i−1} r（1 ≤ i ≤ n）、開始 E_n。Σ = {a, l, c, r}。L_i = L(E_i)。
- 全ての n で Clark–Eyraud 代入可能（あなたの1回目の定理 4.1）なので、どの型付けでもクラスに入ります。‖G_n‖ = 12n+3、θ̄ = 4n−1。
- 記号：C_i = c^i a r^i、D_i^c = C_i、D_i^l = l C_{i−1} C_{i−1}、U_0 = a、U_i = l C_{i−1} U_{i−1}（|U_i| = i(i+1)+1）。∂w は w の先頭1文字を除いた語。
- **型付け s_{1,1}**：長さ2以上の語に（先頭の文字, 末尾の文字）、1文字の語にはその語自身。
- **作用素 B_{1,s}**：観測した因子 x ごとに [x]。Const、Comp（観測した z を、端末の隙間と空でない子に分ける）、Link（同じ型で、標本の中に共通の文脈を持つ）、Start。ファンアウト1では、上限なしの版とランク2の版は同じ言語を作ります（2回目の定理 2.1）。
- **健全性**：[x] から導出される y は、x と型付き合同です。特に s(x) = s(y)。**Comp の子が生成する語も、その子の型を保ちます。**
- **特徴標本**：L ⊆ L(B(F)) を満たせば足ります（単調性と健全性）。cs は最短の特徴標本の長さ Σ(|w|+1) です。

## 2. これまでに分かっていること

- s_{0,1}（末尾）では cs = Θ(n²)（Astra 第3次）。
  - 鍵は、右に一文字ずらした断片 {wb}、{∂w b} を補助記号にすることです。その型は次の文字 b で決まります。
  - 末尾が a の背骨は、U_n 一本の接尾辞を Comp で ∂U_i = (C_{i−1} l)·∂U_{i−1} と切るだけで扱えました。
- **s_{1,1} では、n²+7n+4 ≤ cs ≤ O(n³) で未解決**です（Astra 第5次）。
  - 内部の補助記号を先頭の文字で細分すると、どの細分にも長さ O(i) の代表と O(n) の文脈があります。これで、末尾が r の語は全部、長さ O(n²) の標本から作れます。
  - **背骨が止まります。** 子 [C_{i−1} l] は型 (c, l) なので、l で始まる u からの ul（型 (l, l)）は生成できません。
  - 背骨の断片 H_i^q = {∂w : w ∈ L_i が a で終わり、∂w が q で始まる} の最短長は、q = c で i²+i、q = l で i²+3i−4 です。段ごとに別々に観測すると Θ(n³) になります。
  - ただし、これは下界ではありません。B は別の切り方・別の Link を使えるからです。
- 計算（DeepSeek）：s_{1,1} で cs は n = 1, 2 でそれぞれ 8, 44（全数検査。n=2 では全語が必要）。n = 3 は上界 144（局所探索）、下界 34（稀な型）。n = 4 は上界 336。

## 3. 調べてほしいこと

### 理論（S1）：背骨の「乗り換え」

末尾が a の語では、右の背骨の各段 i で、左の子が c で始まるか l で始まるかを選べます。二次で済ませるには、全ての段の全ての選び方の組み合わせを、少数の長い語でまかなう必要があります。

- **観察**：長い背骨を4本（左の子が全部 c、全部 l、交互が2通り）用意すれば、隣り合う段の組み合わせ（c→c、c→l、l→c、l→l）は全て、どれかの語に現れます。
- **問題**：導出の途中で、ある語の背骨の断片から別の語の背骨の断片へ乗り換えるには、二つの断片が**同じ型で、標本の中に共通の文脈を持つ**必要があります（Link の条件）。二本の長い語は前半が違うので、そのままでは共通の文脈を持ちません。

次のどちらかを証明してください。
- **(A) 二次の上界**：乗り換えを短い証拠で可能にする構成。例：背骨の断片を、短い内部の文脈 (c^{n−i} l, r^{n−i}) に入れた語を少数加え、Link の橋にする。乗り換え用の証拠の総長が O(n²) になることを示し、s_{1,1} で長さ O(n²) の特徴標本を完成させてください。
- **(B) 三次の下界**：B_{1,s_{1,1}} について cs = Ω(n³)。2回目の報告で、型付き合同類をスタック変換で分類しました（定理 3.1）。これを使って、「段 i で、先頭が q の背骨の断片の類」に属する yield を持つ節点が、B の導出のどこかに必ず現れること、そしてその類の成員が全て長さ Ω(i²) で、異なる段どうしで共有できないことを示す、という道筋が考えられます。

どちらも完結しない場合は、止まった場所と、それを確かめる小さい n の中間命題を書いてください。

### 計算（S2）：小さい n の厳密値と構造

Python 3（標準ライブラリのみ）で次を行ってください。
1. B_{1,s}^{≤2} を正確に実装する。2回目の報告の `complete` 関数を土台にしてよいです。ただし、型を s_{1,1} に変えること（Link の連結成分のキーを「文脈と、先頭と末尾の文字の組」にする）。
2. **n = 3、s_{1,1} で、最短の特徴標本の長さ cs を厳密に求める。** L_3 は 42 語で、全部の部分集合を試すのは無理です。次の工夫を使ってください。
   - 単調性：特徴標本の上位集合は特徴標本です。
   - 必須の語：除くと失敗する語は必ず含まれます。
   - 稀な型の下界。
   - 長さの小さい順の分枝限定法。
   厳密値が出なければ、上界と下界を分けて書いてください。
3. 最短（または最良）の標本について、**末尾が a の長い語を何本含むか**、その左の子の先頭の文字の並び（背骨の各段の c／l）がどうなっているかを報告してください。
4. 余力があれば、n = 4、s_{1,1} の上界を改善してください。Astra 第5次の内部の標本（末尾が r の語を全部作れる）に、背骨用の長い語を何本足せば足りるかを調べるのが効率的です。
   - n = 4 では、作用素 B の判定が重くなります（L_4 は 1806 語）。DeepSeek は、Comp の隙間を 0 に制限した部分作用素で上界を検証しました。部分作用素で通る標本は、本来の B でも特徴標本です。

計算の結果は「観察」として扱い、S1 の証明と区別してください。
