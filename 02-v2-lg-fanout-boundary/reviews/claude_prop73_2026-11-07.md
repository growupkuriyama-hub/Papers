## 2. 課題1：有限の閉じた Q₃ は rank ≤ 2 のときだけ正の水準に乗る

### 2.1 平面の二つの補題

以下 A ⊆ ℝ³ は平面、Λ := A ∩ ℤ³、F ⊆ Λ ∩ Π₃ は有限で閉じているとする。A の上のアフィン関数 u, v（線形部分が一次独立）を座標に使う。

**補題2（楔、切り落としがあってもよい）** [証明済み]。ある実数 α, β > 0、κ₀ ∈ ℝ ∪ {−∞} について、Λ の点 x が Π₃ に入る ⟺ u(x) ≥ 0、v(x) ≥ 0、κ(x) := αu(x) + βv(x) ≥ κ₀、とする。このとき F は一直線上にある。

*証明。* κ の線形部分も κ と書く。
(1) **反鎖。** p ≠ q ∈ F で u(q) ≥ u(p)、v(q) ≥ v(p) なら d := q − p について u, v, κ は d の向きに減らないので q + kd ∈ Π₃（k ≥ 0）、閉包から帰納的に q + kd ∈ F（q + (k−1)d に q − p を使う）。F の有限性に反する。よって u の値は相異なり、u で並べると s_1, …, s_n で u は狭義増加、v は狭義減少。n ≤ 2 なら終わり。d_j := s_{j+1} − s_j（Δu_j > 0 > Δv_j）。
(2) **κ(d_j) ≥ 0 なら d_{j−1} = d_j（j ≥ 2）。** x := s_{j−1} + d_j とする。u(x) ≥ 0、v(x) = v_{j−1} + Δv_j > v_j + Δv_j = v_{j+1} ≥ 0、κ(x) ≥ κ(s_{j−1}) ≥ κ₀。よって x ∈ Π₃、閉包で x ∈ F。u(x) = u_{j−1} + Δu_j で、Δu_j < Δu_{j−1} なら u(x) ∈ (u_{j−1}, u_j)、Δu_j > Δu_{j−1} なら u(x) ∈ (u_j, u_{j+1}) で、どちらもその範囲に F の点はない。よって Δu_j = Δu_{j−1}、x = s_j、d_j = d_{j−1}。
(3) **κ(d_j) ≤ 0 なら d_{j+1} = d_j（j ≤ n−2）。** x := s_{j+2} − d_j。u(x) = u_{j+2} − Δu_j > u_{j+1} − Δu_j = u_j ≥ 0、v(x) = v_{j+2} + |Δv_j| ≥ 0、κ(x) ≥ κ(s_{j+2}) ≥ κ₀。x ∈ F で、(2) と同じはさみうちで d_{j+1} = d_j。
(4) (2)(3) から J⁺ := {j : κ(d_j) ≥ 0} は始切片 [1, m] で、d_1 = … = d_m =: d（κ(d) ≥ 0）、d_{m+1} = … = d_{n−1} =: d′（κ(d′) < 0）。m = 0 か m = n − 1 なら一直線。以下 1 ≤ m ≤ n − 2 とし、頂点 s* := s_{m+1} を考える。
(5) y := s* + d：u(y) ≥ 0、κ(y) ≥ κ₀。v(y) ≥ 0 なら y ∈ F で u(y) > u(s*) なので y = s* + i d′（i ≥ 1）、d = i d′、κ(d) < 0 となり矛盾。よって v(s*) < |Δv|。同様に y′ := s* − d′：v(y′) ≥ 0、κ(y′) > κ(s*)。u(y′) ≥ 0 なら y′ = s* − i d、d′ = i d、κ(d′) ≥ 0 で矛盾。よって u(s*) < Δu′。
(6) s_1 = s* − m d ∈ Π₃ から Δu ≤ mΔu ≤ u(s*) < Δu′。s_n = s* + (n−1−m) d′ ∈ Π₃ から |Δv′| ≤ (n−1−m)|Δv′| ≤ v(s*) < |Δv|。よって κ(d) = αΔu − β|Δv| < αΔu′ − β|Δv′| = κ(d′) < 0 ≤ κ(d)。矛盾。∎

**補題3（半帯）** [証明済み]。ある U について、Λ の点 x が Π₃ に入る ⟺ 0 ≤ u(x) ≤ U、v(x) ≥ 0、とする。このとき F は一直線上にある。

*証明。* (1) 同じ u を持つ二点 p, q（v(q) > v(p)）があれば q + k(q − p) ∈ Π₃（k ≥ 0）で無限。よって u で並べて s_1, …, s_n（u 狭義増加）、d_j = s_{j+1} − s_j。
(2) Δv_j ≥ 0 なら d_{j−1} = d_j：x := s_{j−1} + d_j は u(x) < u_{j+1} ≤ U、u(x) ≥ 0、v(x) ≥ 0 で F に入り、はさみうち。
(3) Δv_j ≤ 0 なら d_{j+1} = d_j：x := s_{j+2} − d_j は u_j < u(x) < u_{j+2}、v(x) ≥ 0。
(4) 補題2 と同じく d（Δv ≥ 0）の始切片と d′（Δv′ < 0）の終切片に分かれ、両方が空でない場合を考える。s* := s_{m+1}。y = s* + d は v ≥ 0、u ≥ 0 で、u(y) ≤ U なら y = s* + i d′、Δv = iΔv′ < 0 で矛盾。よって u(s*) + Δu > U。y′ = s* − d′ は v ≥ 0、u ≤ U で、u(y′) ≥ 0 なら d′ = i d、Δv′ ≥ 0 で矛盾。よって u(s*) < Δu′。
(5) s_1 = s* − m d から Δu ≤ u(s*) < Δu′。s_n = s* + (n−1−m) d′ から Δu′ ≤ U − u(s*) < Δu。矛盾。∎

### 2.2 定理4

**定理4** [証明済み]。F ⊆ Π₃ を有限で閉じた集合とし、H := ⟨F − F⟩ とする。F が正の水準に乗る ⟺ rank H ≤ 2。特に、L が SUB₁ で Q₃ が有限なら、Q₃ が正の水準に乗る ⟺ rank H₃ ≤ 2。

*証明。* (⇒) λ ⊥ H、λ ≠ 0 なので rank ≤ 2。
(⇐) **rank 0**：一点。**rank 1**：H = ℤd。d ≥ 0 か d ≤ 0 なら F ∋ p, p + kd（k ≠ 0）から閉包で p + jkd ∈ F（j ≥ 0 か ≤ 0 の全て、Π₃ に入るので）、無限。よって d は正の座標と負の座標を持ち、d^⊥ は正の象限の内部と交わる（d の正の座標の集合を I、負を J として、I の上で λ_σ := Σ_{j∈J}|d_j|、J の上で λ_σ := Σ_{i∈I} d_i、零の座標で λ_σ := 1 と置けば λ·d = 0）。
**rank 2**：A := aff F、n を A の法線（整数、原始的）とする。n の三座標が全て正（または全て負）なら A ∩ Π₃ は有界な三角形で、λ = n（または −n）が求める重み。それ以外の場合に矛盾を導く。座標の置換と n の符号を除いて次のどれか：
- (a) n = (n₁, 0, 0)：A は x_a = 一定。u = x_b − 1、v = x_c − 1 で補題2（κ₀ = −∞）。
- (b) n = (n_a, −n_b, 0)、n_a, n_b > 0：A の上で x_b = (n_a x_a − C)/n_b は x_a の増加関数なので、x_a ≥ 1 と x_b ≥ 1 は x_a ≥ a₀ := max{1, (C + n_b)/n_a} と同値。u = x_a − a₀、v = x_c − 1 で補題2。
- (c) n = (n_a, n_b, 0)、n_a, n_b > 0：x_b ≥ 1 ⟺ x_a ≤ (C − n_b)/n_a。u = x_a − 1、U = (C − n_b)/n_a − 1、v = x_c − 1 で補題3。
- (d) 三座標が 0 でなく符号が混ざる：符号と置換で n = (n_a, n_b, −n_c)（n_a, n_b, n_c > 0）。x_c = (n_a x_a + n_b x_b − C)/n_c なので x_c ≥ 1 ⟺ n_a x_a + n_b x_b ≥ C + n_c。u = x_a − 1、v = x_b − 1、α = n_a、β = n_b、κ₀ = C + n_c − n_a − n_b で補題2。

いずれの場合も (u, v) は A の座標（n の 0 でない座標の方向に A が射影で単射）で、補題2・3 から F は一直線上、rank ≤ 1 に矛盾。∎

**注意（Stiemke の形）。** 「rank ≤ 2 ⟹ H が非零の非負ベクトルを含まない」が依頼文の Stiemke の形にあたる。依頼文が示唆した「H が非負のベクトルを含めば移動で無限」は rank 3 では偽（例1 の H₃ は ℤ³ の指数 59 の部分格子で、(59,0,0) を含むが F₄ は有限）。移動の途中で Π₃ を出るため、格子の元が実現されない。

### 2.3 rank 3 の例

**例1（F₄）** [証明済み]。F₄ = {(1,3,12), (4,8,1), (6,4,4), (12,1,3)}。
(a) 閉じている：p + q − r（q ≠ r、p = q も含む）の 36 通りのうち Π₃ に入るのは p = r の自明なものだけ（スクリプト E2 の厳密な全数。手でも 36 個の座標の符号を見るだけ）。
(b) (4,8,1) からの差 (−3,−5,11), (2,−4,3), (8,−7,2) の行列式は 59 ≠ 0 なので rank 3。
(c) c の値 12, 1, 4, 3 が相異なるので D₃ ∩ 平面 = ∅、D₂ = ∅（Q₂ を一点にする）。従って任意の P ∈ Π₂ について Q = {P} ∪ F₄ は条件 (T) を満たし（Q₃ 内の移動は (a)、他の支持への作用はない）、定理2.1・系2.2 で全ての arity で代入可能。
(d) V は H₃⁰（rank 2）の剰余類で、例えば (10,5) = (4,8,1) + (12,1,3) − (6,4,4) ∈ V。P ∈ V を取れば命題7.3 の仮定（SUB₁、¬(P⁺)、Q₃ 有限で空でない、V ∩ Q₂ ≠ ∅）が全て成り立ち、Q₃ は正の水準に乗らない。F_L = ∞（§4.1）。

## 3. 文法の側

### 3.1 短い生成

**補題5** [証明済み]。B ∈ N と空でない F ⊆ {a,b,c} について、B が F の文字を全て含む生成を持てば、その最短の長さは (2|F| − 1)vθ 以下。特に L(G) が abc 語を持てば長さ ≤ 5vθ の abc 語がある。c を含む生成の最短は ≤ vθ。

*証明。* H 報告の補題3.2 と同じ。F の各文字の出現を一つずつ印にし、背骨（印を含む節点）の外の子を最短の生成に置き換え、同じラベル・同じ印集合の祖先・子孫を短絡する（印を保つので F の文字を全て含む生成のまま、節点が減る）。止まったとき、背骨の印集合は |F| 点の集合の層状の族で、空でない元は ≤ 2|F| − 1 個。同じ印集合の節点は互いに比較可能（比較不能なら部分木が交わらず印集合も交わらない）で、ラベルが相異なるので ≤ v 個。背骨の各節点の寄与（直接書く文字と背骨外の子の最短の生成）は (T3) で ≤ θ。∎

### 3.2 水準定理

**定理6（水準定理）** [証明済み]。G は既約・線形・非削除（ファンアウト任意）、ランク ≤ r（r ≥ 1）、v 個の非終端、θ = θ_loc。L(G) が ab 語を持ち μ := μ_{ab}(L(G)) とする。λ = (α, β, γ) ∈ ℝ³_{>0} と C があって、**長さ < μ の全ての abc 語 w ∈ L(G) で λ(w) = C** とする。このとき
**μ ≤ max{9(r+1)vθ, 11(r+1)v²θ⁴}** ≤ max{9(r+1)vθ̄_G, 11(r+1)v²θ̄_G⁴}。

*証明。* 設定は a ↔ b で対称なので α ≥ β とする。§1 の枠（W, T, 印）を取る。場合 (i) なら μ ≤ 9(r+1)vθ。以下場合 (ii) とし、t, t′ を比較不能な印のない重い節点とする。

**(0) 使う事実。** 節点 z の部分木に印がなく、u が A_z の生成なら、W[z ← u] ∈ L(G)（(S1)）は印を含むので a と b を含む。
- (F1) u が c を含まなければ W[z ← u] は ab 語なので |W[z ← u]| ≥ |W|、すなわち |u| ≥ |y(z)|。
- (F2) A_z の**最短の**生成 u が |u| < |y(z)| なら、(F1) から u は c を含み、W[z ← u] は長さ < μ の abc 語、仮定から λ(W[z ← u]) = C。

**(1) λ(W) = C。** W_t, W_{t′}, W_{tt′} は長さ < μ の abc 語（§1 の (★)）で λ = C。(★) と λ の線形性から λ(W) = C + C − C = C。

**(2) γ ≤ θα。** y(t) は c を含まない（W は ab 語）。ω_t は c を含み長さ < |y(t)| の生成なので、(S2) と (1) から λ(y(t)) = λ(ω_t) ≥ γ。t の部分木で λ(y(z*)) ≥ γ を満たす最も深い節点 z* を取る。z* の子 z′ は λ(y(z′)) < γ。A_{z′} の最短の生成 u′ が |u′| < |y(z′)| なら (F2) で λ(u′) = λ(y(z′)) < γ だが u′ は c を含むので λ(u′) ≥ γ、矛盾。よって τ(A_{z′}) ≥ |y(z′)|、θ ≥ ρ(R(z*)) ≥ |t_{R(z*)}| + Σ_{z′}|y(z′)| = |y(z*)|（(P1)）。γ ≤ λ(y(z*)) ≤ α|y(z*)| ≤ αθ。

**(3) |W|_a ≤ 5vθ²。** μ ≤ 5vθ なら終わり。そうでなければ補題5 の abc 語 u₀（|u₀| ≤ 5vθ < μ）は λ(u₀) = C。C ≤ max(α, β, γ)|u₀| ≤ αθ·5vθ（(2) と θ ≥ 1）。λ(W) = α|W|_a + β|W|_b = C から |W|_a ≤ C/α ≤ 5vθ²。

**(4) 新しい印と背骨。** 同じ T で、W の**全ての a の出現**と b の出現一つを印にする（k := |W|_a + 1 ≤ 5vθ² + 1 個）。y が y′ の真の祖先で同じラベル・同じ印集合なら、短絡で除かれる文字は印のない文字、すなわち b だけで、結果は全ての a と印の b を含む L(G) の ab 語、長さ ≤ |W|、節点は減る。T の最小性に反する。従って補題5 の証明と同じく背骨は ≤ (2k − 1)v ≤ (10vθ² + 1)v ≤ 11v²θ² 節点。背骨外の子 j の部分木の節点 z は印を含まないので y(z) は b だけからなり、k_z := |y(z)|。(P1) から |W| = Σ_{z 背骨}(|t_{R(z)}| + Σ_{j は z の背骨外の子} k_j)。背骨外の部分木の節点 z について、(F2) の生成 u は λ(u) = λ(y(z)) = βk_z を満たす。

**(5) 場合分け。**
- **A：全ての背骨外の子で k_j ≤ θ。** |W| ≤ 11v²θ²·(θ + rθ) = 11(r+1)v²θ³。
- **B：ある背骨外の子 j₀ で k_{j₀} > θ。**

  - (B2) ある背骨外の子 j で βk_j > α のとき：j の部分木で βk_{z*} > α の最も深い z* を取る。子 z′ は βk_{z′} ≤ α なので (B1) で τ(A_{z′}) ≥ k_{z′}/θ、θ ≥ ρ(R(z*)) ≥ (|t_{R(z*)}| + Σ k_{z′})/θ = k_{z*}/θ。よって α < βk_{z*} ≤ βθ²。このとき |W| ≤ λ(W)/β = C/β（α ≥ β）で、C ≤ max(α,β,γ)·5vθ（(3)）、max(α,γ)/β ≤ max(θ², θ) = θ² から |W| ≤ 5vθ³。
  - (B3) 全ての背骨外の子で βk_j ≤ α のとき：(B1) と (T1) から k_j ≤ θτ(A_j) ≤ θ²。|W| ≤ 11v²θ²·(θ + rθ²) ≤ 11(r+1)v²θ⁴。

全ての場合で μ = |W| ≤ max{9(r+1)vθ, 5vθ, 11(r+1)v²θ⁴}。∎

**注意。**
1. 仮定は「μ 未満の abc 語」だけに関わる。証明で水準を使うのは (1)・(2)・(3)・(F2) の四か所で、どれも長さ < μ の abc 語（W の一つの節点の生成を短いものに置き換えた語か、補題5 の u₀）である。
