## 1. 背景（要点）

- 型付け s: Σ⁺ ↠ S（S は有限半群）を固定し、空でない組の成分を s の値が等しいときだけ比べます。C_{f,s} は (f,s)-組代入可能なファンアウト f 以下の MCFL のクラスです。(2,s)-組代入可能とは、d = 1, 2 について、空でない成分の d 組 x, y が成分ごとに同じ型を持ち、共通の許容文脈（d 穴文脈で、内部の区切りは空でない）で E[x], E[y] ∈ L となるなら、全ての許容文脈 F で F[x] ∈ L ⟺ F[y] ∈ L となることです。
- 作用素 B_{f,s}（Const/Comp/Link/Start）の特徴標本の長さを、表示 G の大きさ ‖G‖ と規則の厚さ θ̄ で測ります。`cor:distribution-representatives` により、**各型付き非終端の同値類に長さが多項式の代表がある（τ が多項式）ことを示せば、特徴データは多項式**です。
- 型付き非終端 X = A_{(S₁,…,S_d)} の代表の長さは、τ_X = min{ ‖z‖₁ : 各 z_i の内容が S_i、E_A[z] ∈ L } です（E_A は A の短い導出文脈、長さ ≤ θ̄）。
- **論文の位置づけ**：ファンアウト1では「多項式データを許す擬多様体はちょうど局所群 LG」（定理B）。ファンアウト2で同じかは未解決です。`prop:sl-reduction` により、これは「**半束 SL がファンアウト2で多項式データを持つか**」と同値で、さらに**内容型付け c_Σ（語に現れる文字の集合）だけで判定できます**。
  - 肯定なら、境界がファンアウトで動く（論文の看板になる）。
  - 否定なら、ファンアウト2でも境界は LG。

## 2. 二文字の内容型付けで分かっていること（ChatGPT の報告、別のスレッドの Claude が検証済み）

Σ = {a, b}、c = c_Σ（型は {a}、{b}、{a,b}）、ファンアウト2、ランク r ≥ 2。
- **(A) 浅い場合**：真部分集合 S（ここでは {a} と {b}）について、「(S,h)-深い挿入」（ある語が因子 x z y を持ち、x, y ∈ Sʰ、z が S の外の文字を含む）が無ければ、τ = O(|V|θ̄)。
- **(B) Parikh 飽和の場合**：L が Parikh 飽和（同じ Parikh ベクトルの語は所属が同じ）なら、τ = O(|V|²θ̄⁵)。
- **(C) 一文字の橋**：ある語が因子 a⁶ba⁶ または b⁶ab⁶ を持てば、L は Parikh 飽和。
- **(D) 深い挿入は Parikh 飽和を導かない**：L = a*bba* は全ての d で (d,c)-代入可能で、a⁶bba⁶ を持つが、Parikh 飽和ではない（bba と bab は同じ Parikh ベクトル）。この例自体は短い代表を持つので、多項式の上界の反例ではありません。

## 3. 問い（残った核心）

> **Σ = {a, b}、内容型付け、ファンアウト2で、次の場合に τ が多項式（‖G‖ と θ̄ について）か。**
> L は深い挿入を持つ（a⁶ z a⁶ で z が b を含む、または b⁶ z b⁶ で z が a を含む）。しかし一文字の橋（a⁶ba⁶、b⁶ab⁶）は持たず、Parikh 飽和でもない。

どちらかを示してください。
- **(肯定)** この場合も τ が多項式であることの証明。これと (A)(B)(C) を合わせると、「二文字の内容型付けはファンアウト2で多項式データを持つ」が言えます（二文字では全ての場合を覆うかも確かめてください）。
- **(否定)** この場合に入る族 (L_n, G_n) で、‖G_n‖・θ̄ が n の多項式なのに、ある内容型の最短の語の長さ（またはある τ_X）が超多項式になるもの。L_n ∈ C_{2,c} の証明（d = 1 と 2 の両方）を必ず付けてください。

## 4. 手がかり（使う前に自分で確かめてください）

- 一文字の橋が無いので、挿入される部分 z の中の b は、2個以上の塊でしか a の塊と接しない、という構造があるはずです（a⁶ の直後の b の塊、など）。**語を a の塊と b の塊の交互の並びとして書き、塊の長さの列で言語を記述する**と、二穴の交換が何を強制するかを整理しやすいかもしれません。
- 例えば、「塊の長さの多重集合を保つ並べ替え」に閉じる、という弱い飽和が強制されないか。強制されるなら、その弱い飽和のもとで (B) の数え上げを塊の単位でやり直せないか。
- 退避した二文字の U₁ の証明（`lem:app-u1-deep` の e ≥ 2）が内容型付けで崩れる理由は、(a, b^{e−1}a) と (aa, b^{e−1}) の二つ目の成分の内容が {a,b} と {b} で異なることでした。成分を b の塊の境界で切る別の組（例えば (a, b^{e}a) と (aa, b^{e})）を探すと、内容がそろう比較が作れないか。
- 既知の「強制」の道具：冪の移行（`lem:power-transfer`、u⁵ が必要）、同じ語の切り直し（`chatgpt_sl_fanout2` の補題5・定理7）、Parikh のずれの漏れ（`chatgpt_parikh_closed_family` の定理3.1）、長さの種類の定理（有限の標的で語の長さが k 種類なら、全ての語の長さは θ̄ + k(k−1)|V|(‖G‖ + rθ̄) 以下）。
- 否定の向きの設計仕様は `chatgpt_sl_positive_2026-11-01.md` の §7 にまとまっています。
