## 1. 記号と出典の読み方

`Σ={a,b,c}`、`c(w)` は非空語の**内容集合**、`L∈𝒞_{2,c}`、`G` は `L∩Σ⁺` の reduced good な fan-out `≤2`、rank `≤r` の表示とする。`v=|V|`、`θ=\bar θ_G≥1`、`k=μ_a(L)≥5`。`T` は `a^k` の成功導出のうち節点数最小で、§2により一様にしておく。重い節点は総生成長 `ℓ_u>θ`。根からの深さは節点の個数で数え、最長は `v` 以下。

原稿 `lem:thickness-equivalence` の必要部分は次である。(i) 各規則の直接書込みは高々 `θ` 文字、(ii) 各非終端 `B` に総長 `≤θ` の生成組がある。各重いラベルについてそのような組を一つ選ぶ。純粋な `a` の短い代表があれば `a^k` の対応節点をそれで置換し `k` を小さくできるため、不可能である。

よって各重いラベル `B` に、一方の `x∈{b,c}` のみを非 `a` 文字として含む短い代表 `ω_B∈{a,x}^+`（組なら全成分の文字がその集合に入り、`x` を少なくとも一度含む）があれば、**一色型**として一つの色 `x` を固定する。そうでなければ、**両文字型**であり、どの短い代表も `b,c` の両方を含む。これら後者の重い節点全体を `F`、その個数を `N_bc` とする。

**注意**：ラベルの色は選んだ短い代表を基準に固定する。ひとつのラベルに `b` 型と `c` 型の双方の短い代表があっても、二重計数しない。以下の数え方にこの選択の任意性は影響しない。

`h` は **`S` を含め**、根葉経路上にある `F` 節点の最大個数とする。`S∈F` の場合に `S` を除外した深さ `h'` を使いたければ、以下の全ての `h` を `h'+1` で置き換える必要がある。`S∉F` なら `h=h'`。

## 2. 一様化 (U) の検証

`T` 中の同名ラベル `B` の出現 `u,u'` が異なる総長を持つと、長い方を短い方の部分導出に交換した成功導出は、線形・非削除性により `a^{k-d}`（`0<d<k`）を生成して矛盾する。したがってラベル `B` ごとの総長 `ℓ_B` は一定。同総長で節点数が異なれば、節点数の多い方を少ない方に交換して `T` の最小性に反する。ゆえに部分木の節点数 `s_B` も一定である。

`B` の採用規則に子ラベル `C` があれば、真の子部分木なので `s_B>s_C`。これは異なる枝の全出現を統合したラベル依存グラフでも厳密であり、グラフは非巡回。各ラベルについて選んだ一つの規則を `s_B` の昇順で再展開すると、同名の全出現を同じ部分導出にできる。そのとき根語 `a^k` と総節点数は保存される。**成分別長さの保存は不要**で、各子成分がすべて純粋 `a`、各変数が一度ずつ使われることから総長の保存が従う。

以後、同名ラベルは一つの部分木形を持ち、同名の出現は反鎖である（自己祖先は `s_B` の厳密減少に反する）。深さも `≤v`。以上は第九報の (U) をそのまま引用するのではなく、交換に必要な二つの最小性を明示して確認した。

## 3. (K) の数え方に必要な一色型の補題を再確認

### 3.1 非飽和な二文字影は `18v` 個以下

`x∈{b,c}` を固定し、`L_x=L∩{a,x}^+` と置く。`L_x` は arity 1,2 の内容代入可能性を継承する。共有文脈が二文字上にあるなら三文字上にもあるので、三文字の代入可能性を適用し、二文字の文脈に制限すればよい。**切り出した文法の厚さが `θ` 以下とは仮定しない。**

`a^k` があるから `a^4` は因子として現れる。原稿 `lem:app-two-runs` の再配分操作は `(a,aa)` と `(aa,a)` の共有二穴文脈から作れる。`L_x` が Parikh 非飽和なら、`aa` を持ち、相互に離れた二つの**内部 `x` ラン**を持つ受理語は存在しない：`x^4` が現れなければ `lem:app-two-runs(iv)`、現れれば `lem:app-two-alternate` と `aa` が矛盾する。どちらの証明も二文字の `L_x` の中で完結する。

いま `T` の同じ深さに、色 `x` の一色型重い節点が10個あるとする。この10個は反鎖。`a^k` の最初・最後各2個、計4個の `a` を保護すると、保護文字を所有する反鎖節点は高々4個で、少なくとも6個が残る。各節点の生成組は fan-out `≤2` なので根語の中で高々2区間を占める。区間同士が接する節点を隣接とするグラフの最大次数は4以下、6頂点に独立な2頂点がある。その二節点を各々 `ω_B∈{a,x}^+` に置換する。他は全て純粋 `a` のままなので、得られた語は**必ず `L_x`** に入る。境界の `aa` が残り、二つの非隣接ブロックの内部に二つの隔離した `x` ランができる。矛盾。

よって非飽和色の重い節点は一深さあたり高々9。深さは高々 `v` なので二色合計

\[
N_{\mathrm{ns}}\le18v. \tag{3.1}
\]

これは `F` の節点を一つも交換していない。途中に多くの両文字型節点があっても、元の `T` の出力は純粋 `a` なので証明は変わらない。

### 3.2 飽和色の損失比は `F` に依存しない

`L_x` が Parikh 飽和である場合、`(p,q)` と `(p+δ,q)` がともにその Parikh 像に入り `p≥1`、`0<δ<k` なら、`x^q a^p` と `x^q a^{p+δ}` が受理される。共通一穴文脈 `x^q a^{p-1}□` は `a` と `a^{1+δ}` を受理するため、両者の分布が等しい。`a^k` の末尾を縮めて `a^{k-δ}` を受理させる矛盾になる。したがってこのような二つの Parikh 点は存在しない（第七報の式 (3.3)）。

色 `x` を割り当てた一色型ラベル `B` が重く出現する回数を `q(B)` とし、`q(B)>θ` なら**頻出**とする。短い一色代表の `a,x` 個数を `p_B,q_B`（`q_B≥1`）とする。`T` 中の `B` の総長は `ℓ_B` に一定だから、損失 `d_B=ℓ_B-p_B≥1` も一定。`B,C` が同色の頻出ラベルなら、別々の成功語において `q_C` 個の `B` を、または `q_B` 個の `C` をそれぞれの代表で交換する。`q_B,q_C≤θ`、かつ同名出現は `>θ` なので、どちらの場合も未交換の純粋 `a` 部分木が残る。両語の `x` 個数は `q_Bq_C` で一致し、`a` 個数は正かつ `k` 未満。先の剛性から

\[
q_Cd_B=q_Bd_C,
\quad\alpha_x:=\frac{d_B}{q_B}=\frac{d_C}{q_C}>0.
\]

よって各頻出出現 `u` は

\[
\frac1\theta\le\alpha_x\le\ell_u
=p_B+\alpha_xq_B\le\theta(1+\alpha_x). \tag{3.2}
\]

一色型の非頻出ラベルの出現数は一ラベル `≤θ`、全ラベルで高々 `vθ`。式 (3.1) を合わせて、両文字型を含まない**例外**の総数は

\[
E_0:=18v+v\theta. \tag{3.3}
\]

この計算でも `F` は数えず、交換もしない。とくに頻出比の等式は**多くの両文字型節点の存在に影響されない**。

### 3.3 頻出節点の局所幅：小さい比の層で使えることの証明

**補題3.1（比を下から制限した領域の幅）。** 頻出節点 `u` の比を `α_*` とする。`u` の下の連結した領域で、数える頻出節点すべての比が `≥α_*` とする（途中に例外節点があってもよく、`F` は境界で切ってよい）。この領域にある頻出節点の総数は

\[
M:=v(\theta+\theta^2) \tag{3.4}
\]

以下である。

**証明。** 式 (3.2) により `ℓ_u≤θ(1+α_*)`、領域内の各頻出節点 `z` は `ℓ_z≥α_*`。同じ深さの節点は互いに素な出力区間を持つから、その総生成長は `ℓ_u` 以下。従って各深さの頻出節点数は

\[
\le\frac{\theta(1+\alpha_*)}{\alpha_*}
=\theta+\frac\theta{\alpha_*}
\le\theta+\theta^2.
\]

`T` の最大深さは `v` なので総数は `M` 以下。例外節点や `F` 節点の**個数をこの幅評価で抑えたわけではない**。□

比が二種類 `α_1≤α_2` のとき、`α_1` 節点を根とする領域では、両色の頻出節点がすべて `≥α_1` なのでこの補題を**両色合算して**使える。`α_2` 節点を根とする領域では、最初の `α_1` 節点で切れば、残りは `α_2` 節点のみなので再び使える。これが後の三層の順序の正当化であり、実際の木で `α_1` 節点が `α_2` 節点の祖先になることを禁止していない。

## 4. (K) の明示定数付き定理

以下を定める。

\[
\begin{aligned}
c_0&:=E_0+1=18v+v\theta+1,\\
H_0&:=c_0+M=v(19+2\theta+\theta^2)+1,\\
q_0&:=1+(r-1)c_0,\\
q_1&:=1+(r-1)H_0,\\
\boxed{P&:=q_0q_1^2.}
\end{aligned} \tag{4.1}
\]

**定理4.1（重い両文字型の入れ子深さによる上界）。** §1 の全条件の下で

\[
\boxed{N_{bc}\le P+P^2+\cdots+P^h.} \tag{K}
\]

`h=0` の場合の右辺は0とする。`r≥2` を固定すれば `P` は `v,θ` の明示多項式である。

**証明。** まず木の基本計数を示す。各節点の子は最大 `r` 個で、単なる一本道の節点を縮約した有限根付き木において、分岐節点（子が2個以上）の数が `H` なら葉の数は `≤1+(r-1)H` である。実際、葉数 `l` と内節点の次数 `d_u` について `l=1+∑_u(d_u-1)`。

`F` 節点 `w` を一つ固定し、その下にある**最初の真の `F` 子孫**（他の `F` を途中に持たないもの）をすべて末端として残す。`S∉F` の場合は `S` を始点にして最初の `F` 子孫を末端にする。`F` の子孫を持つ道しか残さないので、これらが末端であり、途中の分岐節点は `F` でない（ただし始点 `w∈F` のとき `w` 自身だけは例外として許す）。

`ℓ_u≤θ` の節点の下には `ℓ_z>θ` の節点を置けない：線形・非削除性により子孫の総生成長は祖先の総生成長以下だからである。従って残した木の途中の**分岐節点は必ず重い**。`F` でないものは、一色型の非頻出例外か頻出節点のどちらかである。

ここで末端までの経路を三段に切る。

1. **上段**：まだどの頻出節点にも入っていない領域。分岐節点は一色型の例外（大域的に `≤E_0` 個）および始点 `w∈F` の場合の `w` 自身（高々1個）しかない。だから分岐数は `≤c_0`、この段の末端数は `≤q_0`。末端は最初の頻出節点か最初の `F` 節点である。
2. **中段**：初めて頻出節点に達した際の比が `α_2` なら、最初の `α_1` 節点または `F` 節点で切る。この段は `α_2` の頻出節点 `≤M` 個と一色型例外 `≤E_0` 個から成る。分岐数は `≤H_0`、末端数は `≤q_1`。`α_1` 節点から始まる道は中段を**省略**する。
3. **下段**：`α_1` 節点からは、後に `α_2` が再び現れても区別せず、最初の `F` 節点までを一つの領域とする。この領域内の頻出節点はどれも比 `≥α_1` なので補題3.1により `≤M` 個。一色型例外を加えて分岐数 `≤H_0`、末端数 `≤q_1`。

比が片方しか定義されない場合は中・下段の不要な段を省略する。頻出節点が全くなければ上段だけでよい。元の根から葉への経路で比の大小が交互になっても、**一度 `α_1` に達した後はすべて下段へ吸収**するので、段の数が増えることはない。

分岐数による葉数上界を段ごとに適用すると、一つの始点から最初の（真の）`F` 節点まで到達する末端は高々 `q_0q_1^2=P` 個である。上段・中段・下段のそれぞれに現れる例外節点を `E_0` で数えたのは過大評価だが、上界として正しい。

そこで `F` 節点を頂点とし、`w` からその最初の真の `F` 子孫へ辺を張る（全体の根が `F` でないなら仮想根を加える）。この「`F`-骨格木」の各頂点の子は高々 `P` 個である。根自身が `F` なら第一世代は1頂点（`1≤P`）、そうでなければ第一世代は高々 `P` 頂点。第 `j` 世代は高々 `P^j` 頂点で、最大世代は `h`。全頂点を足して (K) を得る。□

### 4.2 根 `S` の例外を明確にする

`S∈F` なら上段で `S` 自身を高々一つの分岐として数えたため、式 (4.1) の `+1` が必要になる。`S` を `F` 個数に含めない定義のまま `h=0` と置くと、`N_bc=1` でも右辺が0になり誤りである。正確には `h` に根 `S` を含めるか、`h'` を使って `∑_{j=1}^{h'+1}P^j` と書く。

### 4.3 `μ_a` に戻す

第八報の局所スペクトル証明では、両文字型の各ラベルについて保護した一つの `a` を所有しない出現を順に短縮し、正の損失 `d_B` の相異なる倍数を得る。この出現は同名反鎖なので、ラベル別スペクトル数 `h_T` は `≤N_bc`。その定理3.2の証明を改めて必要な範囲で展開する。まず `F` を含む例外総数を

\[
E:=E_0+N_{bc},\qquad H:=v\theta+E
\]

と置く。頻出比がある場合、小さい方を `α_1` として

\[
A_1:=(r+1)\theta H,\quad Q_1:=\theta(1+A_1)
\]

とする。`α_1≤θ` なら `α_1≤A_1` は直ちに成り立つ。`α_1>θ` なら、`α_1` 節点 `u` 以下では、どの頻出節点も長さ `≥α_1` である。式 (3.2) と各深さの長さの分割から、各深さの頻出節点は `≤θ`、全体で `≤vθ`。例外を加えれば、`u` の下の重い節点数は高々 `H`。各重い節点が書く終端は `≤θ`、その軽い子は高々 `r` 個で各長さは `≤θ`。重い節点以外で止める刈込みを行うと `ℓ_u≤(r+1)θ H=A_1`。従って小さい比の**どの**頻出節点も長さは `≤Q_1`。

大きい比 `α_2` があるとき

\[
A_2:=H(\theta+rQ_1),\quad Q_2:=\theta(1+A_2)
\]

と置く。`α_2≤Q_1` ならそれでよい。`α_2>Q_1≥θ` なら、大きい比の節点 `u` の下で小さい比の頻出節点（長さ `≤Q_1`）と軽い節点（長さ `≤θ≤Q_1`）を停止し、残る大きい比の頻出節点と例外だけを core とする。大きい比の頻出節点は一深さ `≤θ`、従って `≤vθ` 個、例外を加えると core は `≤H` 個。core は一節点あたり高々 `θ` 文字を書き、高々 `r` 個の長さ `≤Q_1` の停止した子を持つから `ℓ_u≤H(θ+rQ_1)=A_2`。よって**すべての頻出節点の長さは `≤Q_2`**。頻出比が一種類以下でも同じ上界を上から採用できる。

長さ `>Q_2` の節点は例外節点で `≤E` 個。根から、それらの大きい節点の直書きと大きくない子で切ると、前者の総長は `≤Eθ`、後者の境界部分木は高々 `1+rE` 個で各長さ `≤Q_2`。したがって

\[
k\le E\theta+(1+rE)Q_2. \tag{4.2a}
\]

`q:=θ+N_bc+20` と置けば `E≤vq`、`H≤2vq`、`Q_1≤3(r+1)vθ²q`、`Q_2≤9r(r+1)v²θ³q²` が成り立つ。従って `r≥2` で `1+rE≤2rvq` を使うと

\[
\boxed{k\le19(r+1)^3v^3\theta^3(\theta+N_{bc}+20)^3}. \tag{4.2}
\]

を得る。この再点検では、両文字型節点を「短い」と仮定せず、その個数を `E` に計上しただけである。式 (3.3) と局所スペクトルの `h_T≤N_bc` は計数の別々の経路を示しているが、ここでは `N_bc` を直接使った。したがって

\[
\boxed{\displaystyle
k\le19(r+1)^3v^3\theta^3
\left(\theta+20+\sum_{j=1}^{h}P^j\right)^3.} \tag{4.3}
\]

`h≥1` なら `∑_{j=1}^hP^j≤hP^h`。`P` は `poly_r(v,θ)` なので、これは `k≤poly_r(v,θ)^{O(h)}` を意味する。`h=0` なら直接 `k≤19(r+1)^3v^3θ^3(θ+20)^3`。

### 4.4 帰結と「`h≤poly`」の限界

一様なDAGでは同じラベルが根葉経路に二度出現できない。よって

\[
 h\le\#\{\text{両文字型ラベル}\}\le v. \tag{4.4}
\]

**異なる両文字型ラベルが高々 `d` 個**なら `h≤d`、式 (4.3) は固定 `r,d` の多項式上界。特に `d=1` では `N_bc≤P`。従って `v,θ` が問題の族に沿って多項式で抑えられるのに `k` が超多項式となるなら、必ず `h→∞`、異なる両文字型ラベルの真に入れ子の鎖が必要である。

ただし、質問中の「`h≤poly(v,θ)` を示す」は式 (4.4) で**既に自明に成立する**。それだけでは右辺の指数 `h` が変数のままで、中心問題の肯定解にはならない。今回の証明は `h=O(1)` を得ていないし、`F` 段あたりの子孫倍率を1にできていない。

## 5. 段の交換 (L)：正しい部分と残るギャップ

### 5.1 正しい条件付き分布等式

`w_1∈F`（ラベル `B_1`）の内部に、ラベル `B_2` の `t≥1` 個の出現があるとする。一様な `T` では `t=t_{B_1,B_2}` は `B_1` の出現によらない。`B_2` は `B_1` の真の子孫なので、同名 `B_2` の出現同士は反鎖である。

`w_1` の外側を切り出した**許容**文脈を `E` とする。文法の代入規則により、`B_1` 全体を短い代表 `ρ_1` にした組 `X` と、`B_1` の内部の `t` 個の `B_2` を全て `ρ_2` にした組 `Y` はいずれも `E` によって `L` に受理される。従って `E∈D_L(X)∩D_L(Y)`。`c^{(d)}(X)=c^{(d)}(Y)` が**成分ごとに**成立すれば、`L∈𝒞_{2,c}` により `D_L(X)=D_L(Y)`。これが (L) の正しい主張である。

特に **外側の文脈 `E` にある `a` は `X` の内容に入らない**。`E[X]` と `E[Y]` がともに全内容 `{a,b,c}` でも、`X` と `Y` 自体の内容が異なる場合には代入可能性を使えない。fan-out 2 では総内容が同じだけでも不足し、二成分のそれぞれの内容が等しい必要がある。

### 5.2 定理Sを使うための必要条件

`d_i:=ℓ_{B_i}-|ρ_i|_a>0`、`β_i:=|ρ_i|_b≥1`、`γ_i:=|ρ_i|_c≥1` とする。`E[X]` と `E[Y]` は成功語であり、置換されない部分はもともと純粋 `a` なので

\[
\begin{array}{c|ccc}
&|\cdot|_a&|\cdot|_b&|\cdot|_c\\\hline
E[X]&k-d_1&\beta_1&\gamma_1\\
E[Y]&k-t d_2&t\beta_2&t\gamma_2
\end{array}. \tag{5.1}
\]

過去の定理Sは、`0<|E[X]|_a,|E[Y]|_a<k`、かつ **`σ_a(E[X])=σ_a(E[Y])`** のときにのみ、`d_1=t d_2` を強制する。分布同値だけではこの骨格一致を含意しない。骨格が一致するなら、当然

\[
\beta_1=t\beta_2,\qquad\gamma_1=t\gamma_2 \tag{5.2}
\]

が**必要**である（骨格は `b,c` の個数と並びを保存する）。したがって異なる段の短縮が受理されるという事実だけから、`a` の個数の漏れは出ない。

### 5.3 両文字代表が `b,c` 一個ずつの場合の明確な障害

**補題5.1（「各一文字」の交換対には骨格衝突が生じにくい）。** `β_1=γ_1=β_2=γ_2=1` とする。(i) `t≥2` なら `E[X]` と `E[Y]` は `a` 骨格が異なる。(ii) `t=1` で `B_1` の部分木が、`B_2` を含む枝と**別の重い子枝**とに分岐するなら、`L∈𝒞_{2,c}` の下でこの二つの成功語は同じ `a` 骨格を持てない。

**証明。** (i) 非 `a` 文字数は `E[X]` で `(1,1)`、`E[Y]` で `(t,t)` なので、骨格一致に必要な (5.2) が崩れる。(ii) 別の重い子から少なくとも `θ+1` 文字が `B_1` の出力に加わるため、`ℓ_{B_1}>ℓ_{B_2}+θ`。`|ρ_i|_a≤θ` より

\[
 d_1-d_2=(\ell_{B_1}-\ell_{B_2})-(|\rho_1|_a-|\rho_2|_a)>0.
\]

式 (5.1) で `a` 個数が異なる。もし一方の語に `a` がなく他方にあれば骨格は自動的に異なる。双方に `a` があればどちらも `k` より小さいので、骨格一致は定理Sにより禁じられる。□

これは**分岐不能の証明ではない**。むしろこの具体的な交換対は、`t≥2` では非 `a` 文字の個数から、`t=1` の重い別枝がある場合には定理Sから、同骨格での矛盾を作る手段にならないことを示す。

第九報の `L_k={a^k,abc,acab}` では、混合した二語の内容は同じ全内容でも `a` 個数が異なり、しかも代入可能性が保たれる。つまり「(L)で全内容因子が同じ分布になる」だけから、同骨格の矛盾を強制する一般定理はない。この有限例は `θ=k` であり、厚さが小さい場合の反例にはならない。

## 6. 肯定側で達成できた範囲と未達の部分

定理4.1は、各 `F`-段の**最大分岐数**を明示的多項式 `P` で抑える。しかし `P` を1にできない。上段では稀な一色型節点、中段・下段では頻出の一色型節点が分岐し得る。現在の二文字影の補題は、それらの総数・局所幅を抑えるだけで、`F` をそれぞれ二つの枝に持つことを禁止していない。

`h` の一様定数上界も導いていない。`h≤v` は非巡回性の帰結であって解決ではない。fan-out 1への限定、入れ子二段への限定、各 `ρ_i` の `b,c` 個数を1ずつにする限定についても、**入れ子の存在そのものを否定する証明には至らなかった**。

`lem:app-two-runs` や定理Sの適用を受けるのは二文字影や同じ `a` 骨格の受理語である。一般の `F` の段交換では `b,c` が複数の位置へ同時に入るため、`σ_a` が一致することを制御できない。この点が肯定解の本質的な未解決箇所である。

## 7. 否定側、下界の量化、計算で確認したこと

### 7.1 以前の無限候補は arity 1 で失敗

候補

```text
A_0 -> a | D
A_i -> A_(i-1) A_(i-1) | D     (i>=1)
D   -> bc | bc D
start A_n
```

の言語は無限だが、各入力語への所属は付録の再帰分割判定器で**正確**に決定できる。`n=2` で

\[
X=bcbc,\quad Y=bc,\quad c(X)=c(Y)=\{b,c\}
\]

は `E=□` を共有する。一方 `F=□a` では `bcbca∈L(G_2)`、`bca∉L(G_2)`。後者は `A_2→D` の形ではなく、`A_2→A_1A_1` ではそれぞれの子の最小長が2で長さ3を出せない。したがって `D_L(X)≠D_L(Y)`、**arity 1違反の厳密な証明書**となる。

注意：この具体的な `□a` 証明書を**全ての `n≥2` にそのまま転用することはできない**。付録の正確な判定では `n=3` に `bcbca` は所属しない。系列として `𝒞_{2,c}` であるとの主張は `n=2` の一点だけで既に破綻する。

### 7.2 新しい反例族は提出しない

今回、`h→∞` と小さな表示・厚さに加えて、arity 1,2 の代入可能性まで証明した `G_n` は得られなかった。従って「有限長のテストで違反が見つからなかった」ことから無限族の所属を推論することも、反例族の文法サイズ・厚さ・`μ_a` の超多項式性を主張することもしない。

**将来の下界の量化を先に固定する。** `Σ={a,b,c}`、内容型付け `c_Σ`、fan-out `≤2`、rank `≤r`（特に `r=2`）を明記し、`L_n∈𝒞_{2,c_Σ}` と reduced good な表示 `G_n` を直接証明すること。`a^{k_n}` を内容 `{a}` の唯一の受理語として `μ_a(L_n)=k_n` を実現でき、型 `{a}` の語が他にないとき、原稿 `prop:rare-type` は `\mathcal B^{\le r}_{2,c_Σ}`、`\mathcal B_{2,c_Σ}`、および**クラス全体に特徴標本を持つ任意の集合駆動作用素**の特徴標本に長さ `k_n` の正例が必要であることを与える。最後の普遍量化には、同じクラスに属する型削除先への特徴標本の存在が必要であり、原稿の型削除補題がそれを保証する。Gold学習器一般の収束時点や実行時間の下界ではない。

### 7.3 有限例の独立した完全判定

`L_k={a^k,abc,acab}`（`5≤k≤9`）について、**有限言語の全ての受理文脈を、各受理語の全ての許容1穴・2穴分割から構成**した。全ての同型の組について、分布に共通文脈があれば分布集合が一致するかを厳密に検査した。arity 1,2 の違反は見つからなかった。この判定は、言語全体の語が列挙されているため「有限長打切りによる観察」ではなく**その `k` の有限言語に対する完全判定**である。ただし `k≥10` への計算的帰納は行わない。

一般 `k≥5` の数学的確認は次のように行える。`a^k` と混合語をまたぐ共通文脈で同内容の二組が現れることはない。純粋 `a` の1穴因子の総長が異なれば、`a^k` を完成する固定部の長さが違う。2穴では純粋組 `(a^p,a^q)` が `a^k` を完成させる条件は固定部と `p+q` の合計が `k` であることだけなので、**同じ合計長の純粋組は外側の純粋文脈に対して同じ真理値を持つ**。混合語 `abc` に2つの純粋 `a` 穴は置けず、`acab` に置けるのは唯一の `(a,a)` とその唯一の二穴位置だけで、別の組との共通受理を作らない。異なる混合語 `abc,acab` は2穴の固定中央語の位置が一致せず共通受理文脈を持たない。1穴で両混合語を完成する同内容因子の組は `□` の下の `(abc,acab)` に限られ、それぞれ他の受理語の因子として現れないため分布はともに `{□}`。この**直接の場合分け**で代入可能性を確認できる。ここでは、まだ言語の所属を確立する前に `𝒞_{2,c}` 専用補題を適用していない。

## 8. 残された一点：どの条件を追加すれば深さに依存しないか

(K) は構文的増殖を一色型の例外・頻出比に押し込み、`F` の間を**定数個の層**に分解した。しかし段を重ねるごとに `P` を掛けることを回避する情報が足りない。

次に絞るべき一点は、**異なる `F` ラベルの祖先・子孫において、文法が保証する複数の置換語から、同じ非 `a` 骨格を持つが `a` 損失の異なる二語を強制できるか**、あるいはその強制不能性を利用して本当に代入可能な反例を構成できるかである。そのためには単なる `B_1` と `B_2` の二通りの置換だけでなく、同じ内容型のまま非 `a` 部分列をそろえる**第三の局所交換**が必要であろう。ただしその存在は現時点で未証明である。

とくに `β_i=γ_i=1` なら、(L) の二語は `t≥2` では非 `a` 文字数すら違う。これは「各代表に `b,c` が一回だから簡単になる」とは限らないことを示す厳密な障害である。

## 9. 文献との関係と新規性

基礎の代入可能性と正例学習の枠組みは Clark–Eyraud, *JMLR* **8** (2007), 1725–1745（https://jmlr.org/papers/v8/clark07a.html）および Yoshinaka, *Theoretical Computer Science* **412** (2011), 1821–1831, DOI: [10.1016/j.tcs.2010.12.058](https://doi.org/10.1016/j.tcs.2010.12.058) と比較した。後者は多次元代入可能性によるMCFG学習の先行研究である。原稿中の有限型付けと厚さ、`prop:rare-type` の量化を混同しない。

**今回の `F`-鎖深さをパラメータとした明示上界 (K) が先行文献に既に現れているかは未確認**。確認した文献の書誌・抄録や手元原稿・既報からは同一の定式化を特定できなかったが、網羅的な既知結果調査はしていない。原稿への組込み・「新定理」としての公表には、著者による再検証と先行調査が必要である。

## 10. 結了時の三点

1. **証明できたこと**：一色型の例外 `≤18v+vθ`、頻出比の局所幅 `≤v(θ+θ²)` を `F` の存在下で再確認し、明示的 `P` による `(K)` と `k≤poly_r(v,θ)^{O(h)}` を証明した。根 `S∈F` も正しく処理した。(L) の条件付き分布同値と、「各 `b,c` 一個」交換対の骨格不一致条件も明確化した。
2. **止まった場所**：`h=O(1)`、`F` 分岐の禁止、または新しい完全な反例族は得られなかった。(L) の二語の内容・分布の一致から `a` 骨格の一致は出ない。
3. **次に絞るべき一点**：入れ子の二段 `B_1⊃B_2` で、**非 `a` 部分列を固定したまま別の `a` 損失を実現する交換閉路**を強制するか、逆にそのような閉路が一切生じない代入可能な文法を厳密に設計すること。

## 付録A. Python 3 標準ライブラリによる再現コード（全文）

このコードは、有限言語 `L_k` の **全ての**受理文脈の比較と、無限候補 `A_i,D` の**入力語ごとの正確な**所属判定を行う。`P` の計算チェックは単なる算術的な有限検算であり、(K) の証明の代用ではない。Windows ではコード部分を `nested_bc_verify.py` に保存して `py -3 nested_bc_verify.py` を実行する。

```python
"""Exact finite-language arity 1/2 audit and exact CFG membership checks.
Windows: py -3 nested_bc_verify.py
Python 3 standard library only.
"""
from collections import defaultdict
from functools import lru_cache


def content(word):
    return frozenset(word)


def tuple_occurrences(word, arity):
    """All admissible context/tuple pairs in a concrete accepted word."""
    n = len(word)
    if arity == 1:
        for i in range(n):
            for j in range(i + 1, n + 1):
                yield ((word[i:j],), (word[:i], word[j:]))
    elif arity == 2:
        for i in range(n):
            for j in range(i + 1, n):
                for p in range(j + 1, n):  # nonempty separator
                    for q in range(p + 1, n + 1):
                        yield ((word[i:j], word[p:q]),
                               (word[:i], word[j:p], word[q:]))
    else:
        raise ValueError('only arities 1 and 2')


def finite_substitutability_failure(words, arity):
    """Exact decision, not length-bounded: words is the entire finite L."""
    distributions = defaultdict(set)
    for w in words:
        for tup, ctx in tuple_occurrences(w, arity):
            distributions[tup].add(ctx)
    by_type = defaultdict(list)
    for tup in distributions:
        by_type[tuple(map(content, tup))].append(tup)
    for tuples in by_type.values():
        for i, x in enumerate(tuples):
            for y in tuples[i + 1:]:
                dx, dy = distributions[x], distributions[y]
                common = dx & dy
                if common and dx != dy:
                    distinguishing = sorted(dx ^ dy)[0]
                    return (x, y, sorted(common)[0], distinguishing,
                            distinguishing in dx)
    return None


def near_candidate_member(depth, word):
    """Exact membership for infinite A_0 -> a|D, A_i -> A_(i-1)^2|D,
       D -> bc|bcD. Each query terminates via strictly shorter substrings.
    """
    @lru_cache(None)
    def member(i, w):
        if len(w) >= 2 and len(w) % 2 == 0 and w == 'bc' * (len(w)//2):
            return True
        if i == 0:
            return w == 'a'
        return any(member(i-1, w[:cut]) and member(i-1, w[cut:])
                   for cut in range(1, len(w)))
    return member(depth, word)


def check_arithmetic():
    # No claim about language membership here; only sanity checks of K constants.
    for r in (2, 3, 4):
        for v in range(1, 6):
            for theta in range(1, 7):
                e0 = 18*v + v*theta
                c0 = e0 + 1
                h0 = c0 + v*(theta + theta*theta)
                p = (1 + (r-1)*c0) * (1 + (r-1)*h0)**2
                assert p >= 1 and p >= 1 + (r-1)*h0
    print('Arithmetic P checks: PASS (finite sanity check only)')


def main():
    for k in range(5, 10):
        finite = {'a'*k, 'abc', 'acab'}
        for arity in (1, 2):
            failure = finite_substitutability_failure(finite, arity)
            print('L_k', k, 'arity', arity, 'failure:', failure)
            assert failure is None
    print('These finite L_k decisions are exact because every accepted word is listed.')
    for n in (0, 1, 2, 3):
        entries = {w: near_candidate_member(n, w)
                   for w in ('bc', 'bcbc', 'bca', 'bcbca')}
        print('Near candidate A_'+str(n), entries)
        if n == 2:
            assert entries == {'bc': True, 'bcbc': True,
                               'bca': False, 'bcbca': True}
    check_arithmetic()


if __name__ == '__main__':
    main()
```
