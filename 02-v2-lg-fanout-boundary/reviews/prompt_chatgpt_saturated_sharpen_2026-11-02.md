## 1. 背景

`thm:two-letter-content`（2026-11-02 に全てのファンアウト f ≥ 2 に拡張）：Σ = {a,b}、内容型付け c、f ≥ 2、r ≥ 2。
- L が **Parikh 飽和でない**とき：t_typ ≤ D_f(r+1)|V|θ̄（D_f = (6f+1)3^f）、特徴標本の長さ O_{f,r}(‖G‖²θ̄)。これは定理A(i) の局所群の上界と同じ形です。
- L が **Parikh 飽和**のとき：τ ≤ C_{f,r}|V|²θ̄⁵、特徴標本の長さ O_{f,r}(‖G‖³θ̄⁵)。
  - 成分の内容の和が Σ の型は τ_X ≤ (2f+1)(2f+2)(r+1)|V|θ̄³。
  - 全ての成分が一文字 {a}（または {b}）の型が θ̄⁵ の原因で、(P1)–(P6)（行の剛性、高さ、重い純な節点、頻出する非終端の比 α、比の上界、数え上げ）を通しています。

**もし飽和の場合も O_{f,r}(‖G‖²θ̄)（または少なくとも O(‖G‖^2 θ̄^{O(1)}) で ‖G‖ の指数を2に）に詰められれば**、「二文字の半束型付けは、ファンアウト ≥ 2 で局所群と同じ形の上界を持つ」と言えます。これは論文の主張を大きくきれいにします。

## 2. 調べてほしいこと（優先順）

**S0（検証、最初に短く）**：付録 H の `lem:app-two-saturated` の一文字の場合（f 版。K > θ̄ + 2(f−1) の仮定、(P2) の K > p + 2h − 2、重い純な節点の閾値 θ̄ + f − 1、(P4)–(P6) の定数）を一行ずつ確かめ、誤りがあれば指摘してください。

**S1（本題：上界の改良）**：飽和の場合の τ（特に全ての成分が {a} の型）を、できるだけ小さい多項式で抑えてください。狙いは次の順です。
- (a) τ_X = O_{f,r}(|V| θ̄)（または O(|V| θ̄^k) で k を小さく）。そうなれば特徴標本は O_{f,r}(‖G‖²θ̄^k)。
- (b) 少なくとも |V|² を |V| に下げる、または θ̄⁵ を下げる。

手がかり（使う前に確かめてください）：
- 飽和なら所属は Parikh ベクトルだけで決まるので、L ∩ Σ⁺ は Parikh 像 𝒫 ⊆ ℕ² で決まります。文法の Parikh 像は半線形で、MCFG でも同様です。𝒫 の「行」{k : (k, y) ∈ 𝒫} は (P1) により、差が K − h 以下の二点を持てません（行の剛性）。
- 純な型の最短の代表は K = min{k ≥ h : (p+k, q) ∈ 𝒫} です。これは「𝒫 の中で b の個数が q の行の、p+h 以上の最小の点」です。文法の Parikh 像の構造（各非終端の Parikh 像も半線形で、短い生成組 ω_B を持つ）から、行の最小の点を直接抑えられないか。
- 二文字・ファンアウト1の重み一定の場合の鋭い評価 μ ≤ ⌊(θ̄+1)²/4⌋（退避 `parked/parked_u1_typing_level.tex` の `prop:u1-weight-all-fanout`）、および可換群の語問題の評価 |H| ≤ (r+2)θ̄²（`reviews/chatgpt_problemG_2026-11-01.md` の定理1。各非終端の短い代表の Parikh ベクトルと、規則の「ずれ」が格子に入ることを使う行列式の議論）は、飽和の場合に似た構造を持ちます。特に後者の**行列式の議論**は、Parikh 像だけで所属が決まる言語にそのまま適用できる可能性があります。
- 原稿の (P4)–(P5) の頻出する非終端の比 α は、θ̄² の要因です。比が共通であることから、Parikh 像の中の一本の直線に沿った構造が見えるはずです。

**S2（下界）**：S1 で O(‖G‖²θ̄) に届かなかった場合、飽和の二文字の言語の族で、τ（または `prop:rare-type` の下界）が θ̄ について超線形（例えば θ̄²）になり、‖G‖ が小さいものを作ってください。ファンアウト ≥ 2 の (2,c)-代入可能性（arity 1 と 2）を必ず証明してください。飽和の言語では所属が Parikh ベクトルで決まるので、代入可能性の確認は Parikh 像の上の条件になるはずです。

**S3（余力があれば）**：二文字の場合に、線形の因子 ‖G‖θ̄ の下界（原稿の定理A(ii) は 4f+1 文字以上が条件）が成り立つか。成り立てば、二文字の上界の鋭さが分かります。
