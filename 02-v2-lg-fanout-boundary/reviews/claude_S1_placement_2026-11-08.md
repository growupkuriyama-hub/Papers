## 1. 課題1：補題PC・系PC′・命題DD の検証

### 1.1 補題PC と系PC′：原文どおり正しい

- **PC**：v の部分木を X の b を含む生成語 ω_X に差し替えると、B の生成語 a^L ω_X a^R（b を含む）が得られる。C.0 から ω_B ≡ a^L ω_X a^R なので、P(ω_B) = {(x, y) : (x+L, y+R) ∈ P(ω_X)}。量化に問題はない。ω_B の選び方によらないこと（P は B の ≡ 類だけで決まる）も同じ理由で成り立つ。有限性は使わない。
- **PC′**：(x, y) ≠ (0,0) なら a^xω_Sa^y と ω_S はともに L の b 語で、文脈 (ε, ε) を共有するので ≡。前者は後者の真の因子を含むので補題0 に反する。正しい。実際にはもっと強く D_L(ω_S) = {(ε, ε)}（b を含む文脈でも同じ議論が通る）。

### 1.2 命題DD：対角線にあることの根拠

原文は「全ての P_j が対角線の上にあるのは、系PC′ と (E1)(E2) から帰納的に分かる」としている。**これだけでは足りない。** (E1) が決めるのは P_{j−1} ∩ {y ≥ h} だけ、(E2) が決めるのは P_{j−1} ∩ {x ≥ h} だけ（h = 2^{j−1}）なので、角 {x < h, y < h} の点については何も言えない。

正しい根拠は次のとおり。P_j ≠ ∅（P_n = {(0,0)} から帰納的に）の点 (x, y) を一つ取ると、(E1)(E2) から P_{j−1} ∋ (x, y+h), (x+h, y)。この二点は異なり、座標和はどちらも N − 2^{j−1}。L は有限なので P_{j−1} は有限で、**系2**（定理1 の系）により P_{j−1} の全体が対角線 x + y = N − 2^{j−1} に乗る。もう一つの根拠として、j−1 ≤ n−1 なら E_{j−1} は T に二回以上現れるので、**系3** からも同じ結論が出る。どちらも Astra の定理1 を使う。

### 1.3 命題DD の強制：正確な形と解の全体

P_j = {(x, N − 2^j − x) : x ∈ X_j}、M_j := N − 2^j と書く（1 ≤ j ≤ n）。対角線上では y ≥ h ⇔ x ≤ M_j なので、(E1)(E2) は次と同値になる：

  (E1′) X_j = X_{j−1} ∩ [0, M_j]、 (E2′) X_{j−1} ∩ [2^{j−1}, M_{j−1}] = X_j + 2^{j−1}。

**補題1.1.** X_j = X_1 ∩ [0, M_j]（1 ≤ j ≤ n）。特に X_n = {0} から 0 ∈ X_1。
*証明.* (E1′) を繰り返す。□

**補題1.2.** 2 ≤ j ≤ n について、(E2′) は「x ∈ [0, M_j] で x ∈ X_1 ⇔ x + 2^{j−1} ∈ X_1」と同値（X_1 は [0, M_{j−1}] の上で 2^{j−1} 周期）。
*証明.* 補題1.1 を (E2′) に代入する。□

**命題DD′（解の全体）.** 系 (E1)(E2)、P_n = {(0,0)}、および定理1（隙間のない等差列で、端の条件 x₀ < d、M_1 − max < d）を満たす X_1 は、ちょうど次の二つ：

  X_1 = {偶数} ∩ [0, N−2]、または X_1 = [0, N−2] ∩ ℤ。

*証明.* j = 2 の補題1.2 で X_1 は [0, N−2] の上で 2 周期。0 ∈ X_1 なので偶数は全て入る。奇数が一つでも入れば奇数も全て入る。どちらの集合も全ての j の周期条件と定理1 を満たす。□

従って原文の結論「X_j ⊇ 偶数（j ≤ n−1）」は正しい。原文の帰納法「2^k の倍数が全て入れば 2^{k−1} の倍数が全て入る」は、正確には**段 k の周期条件（補題1.2、j = k）**のことであり、段の間を往復する必要はない。原文の (i)「Q_j が (E1)(E2) を満たす」も正しい。ただし**最小の固定点が偶数全体だというだけで、方程式から刻み 2 が決まるわけではない**（刻み 1 の解も残る）。付属スクリプトの全数検査（n = 3, 4）で、解はちょうどこの二つになった。

注：j = 1 の主張（ω_1 を偶数の位置に置ける）は T の E_1 節点の位置そのものなので自明。命題DD の中身は j ≥ 2 の部分にある。

### 1.4 E_1 が b 語を持たない場合

b 語を持つ最下段を E_k（k ≥ 1）とする。同じ議論で X_j = X_k ∩ [0, M_j]（j ≥ k）、X_k は 2^k 周期（段 k+1 の周期条件）、0 ∈ X_k。従って

  X_k ⊇ 2^k ℤ ∩ [0, N − 2^k]、 刻み d_k は 2^k の約数。

**方程式は約数のどれも許す。** 全数検査では n = 4, k = 2 で刻み {1, 2, 4}、n = 5, k = 4 で {1, 2, 4, 8, 16} の解が全て存在した。k = 2 なら「強制されるのは 4 の倍数で、刻みは 4, 2, 1 のどれか」であり、刻みが 4 になるとは言えない。

### 1.5 帰結 a²ω_j ≡ ω_ja²

(0, M_j) と (2, M_j − 2) ∈ P_j（j ≤ n−1、M_j ≥ 2）から、a²ω_j と ω_ja² は文脈 (ε, a^{M_j−2}) を共有する。正しい。ただし §2 ではこれより直接の関係（E_{j+1} の生成語どうしの ≡）だけを使う。

## 2. 課題2：二重化の鎖では文法が指数的に大きい（定理D）

### 2.1 道具

**補題2.1（右の消去）.** L ∈ C₁、x, y が同じ型、xz が L の因子で xz ≡ yz なら x ≡ y。左についても同じ。
*証明.* xz の文脈 (l, r) から x は文脈 (l, zr) を持ち、yz ≡ xz から y も (l, zr) を持つ。同じ型なので C₁ から x ≡ y。□

**抽象的な設定（崩壊する符号）.** b 語 z_0, z_1, …, z_M、整数 c ≥ 1 について次を仮定する。

- **(C1)** a^c z_0 ≡ z_0 a^c ≡ z_0 z_0。
- **(C2)** 各 i について z_i ≡ a^{e_i} z_0（e_i ≥ 0、c | e_i）。v_i := e_i + c とおく（z_i の**価値**）。a^c の価値は c。
- **(C3)** v_1, …, v_M の部分和は全て異なる（例えば各 v_i が自分より小さい v の和を超える）。
- **(C4)** 語 l, r と、c の倍数 P ≥ 0 があって、e* := Σv_i + P − c について l a^{e*} z_0 r ∈ L。

**補題2.2（崩壊）.** u を {z_1, …, z_M, a^c} の語の連接で、z を少なくとも一つ含むものとすると、u ≡ a^{val(u) − c} z_0（val は価値の和）。
*証明.* (C2) で各 z_i を a^{e_i} z_0 に替える（≡ は合同）。(C1) から a^c は z_0 と可換で、e_i は c の倍数なので、a を全て左へ集めて u ≡ a^E z_0^t（t ≥ 1 は z の個数）。(C1) から z_0^t ≡ a^{(t−1)c} z_0（t についての帰納法：z_0^t = z_0^{t−2}(z_0z_0) ≡ z_0^{t−2}a^cz_0 ≡ a^cz_0^{t−1}）。指数を数えると val(u) − c。□

**補題2.3（価値による所属の判定）.** 補題2.2 の u について、l u a^P r ∈ L ⇔ val(u) = Σv_i。
*証明.* 補題2.2 と (C1) から l u a^P r ≡ l a^{val(u) − c + P} z_0 r。f := val(u) − c + P ≠ e* で l a^f z_0 r ∈ L とすると、a^f z_0 と a^{e*} z_0 は b 語で文脈 (l, r) を共有するので ≡ で、分布は空でなく、一方は他方の真の接尾辞になる。補題0 に反する。逆向きは (C4)。□

**定理C（計数）.** L は有限、L ∈ C₁、G は L∩Σ⁺ の reduced・ε なしの CFG、(C1)–(C4) が成り立ち M ≥ 6 とする。λ := max_i |z_i|、m := |l| + |r| + P + Σ_i|z_i| とおくと

  ‖G‖ + 2 ≥ 3^{M/3 − 1} / ( (M+1) (m+1)² (Mλ+1)² )。

*証明.* G を `claude_problemG_mixing` (P2) のように二分化した G′ を取る（|V′| ≤ ‖G‖+2）。G′ の各非終端の b を含む生成語は C.0 により全て ≡（補助非終端も成功文脈を持つ）。単位節点を縮めた導出木は二分木。

M 個の符号の並べ方 π ごとに w_π := l z_{π(1)} ⋯ z_{π(M)} a^P r とおく。補題2.3 から w_π ∈ L、|w_π| = m。w_π の導出木を一つ選び、各符号の最初の文字に重み 1、他の葉に重み 0 を置く（全体の重み M）。

*重み付きの中間節点.* 根から重い方の子をたどり、重みが初めて 2M/3 以下になった節点 u を取る。親の重みは 2M/3 を超え、u はその重い方の子なので、u の重み κ は M/3 < κ ≤ 2M/3（葉の重みは 1 < 2M/3 なので、親は葉でない）。u のラベル X、区間 [p, q)、y := w_π[p, q) とする。

*記録.* I(π) を [p, q) に完全に含まれる符号の集合、O(π) を区間と交わらない符号の集合とする。区間の左端・右端をまたぐ符号は高々一つずつで、その（番号, 符号内のずれ）を記録する（l, a^P, r の位置は固定なので、そこでまたぐ場合は p, q だけで決まる）。記録 ρ(π) := (X, p, q, 左のまたぎ, 右のまたぎ) は高々 |V′|(m+1)²(Mλ+1)² 通り。|I(π)| ≥ κ − 1 > M/3 − 1 ≥ 1 なので y は b を含む。

*同じ記録なら内側の集合が同じ.* ρ(π) = ρ(π′) とする。y, y′ := w_{π′}[p, q) はどちらも X の b を含む生成語なので y ≡ y′。従って w_π[0, p) · y′ · w_π[q, m) ∈ L。またぐ符号の番号とずれが一致するので、この語は l u″ a^P r の形で、u″ は（π の左の外側の符号）（左のまたぎ）（π′ の内側の符号）（右のまたぎ）（π の右の外側の符号）の連接。補題2.3 から val(u″) = Σv_i = val(w_π の符号列)、従って Σ_{i∈I(π′)} v_i = Σ_{i∈I(π)} v_i。(C3) から I(π′) = I(π)。

*数える.* 一つの記録に属する π は、内側の並べ方と、外側の集合 O の並べ方と左右への分け方で決まるので、高々 |I|!·(|O|+1)! ≤ |I|!(M − |I| + 1)! 個。従って

  M! ≤ |V′|(m+1)²(Mλ+1)² · max_I |I|!(M−|I|+1)!、

すなわち |V′| ≥ C(M+1, |I|)/((M+1)(m+1)²(Mλ+1)²)（|I| は最大を与えるもの）。ここで M/3 − 1 < |I| ≤ 2M/3 なので、j := min(|I|, M−|I|) は M/3 − 1 < j ≤ M/2 を満たす。j ≤ M/3 なら C(M, j) ≥ (M/j)^j ≥ 3^j ≥ 3^{M/3−1}。M/3 < j ≤ M/2 なら二項係数の単調性から C(M, j) ≥ C(M, ⌊M/3⌋) ≥ 3^{⌊M/3⌋} ≥ 3^{M/3−1}。C(M+1, |I|) ≥ C(M, |I|) = C(M, j) と合わせて主張が出る。∎

### 2.2 定理D（二重化の鎖）

**定理D.** L は有限、L ∈ C₁、G は L∩Σ⁺ の reduced・ε なし・厚さ θ の CFG とする。G が非終端 E_k, …, E_n と規則 E_j → E_{j−1}E_{j−1}（k < j ≤ n）を持ち、E_k は純な生成語 a^c（c > θ）を持つとする。M := n − k ≥ 6 なら

  ‖G‖ + 2 ≥ 3^{M/3 − 1} / ( (M+1) ((M+1)θ + c + 1)² (Mθ+1)² )。

特に依頼文の鎖（E_0 → a、E_j → E_{j−1}E_{j−1}、1 ≤ j ≤ n）では、k を 2^k > θ となる最小の k とすると c = 2^k ≤ 2θ で

  ‖G‖ + 2 ≥ 3^{(n−k)/3 − 1} / ( (n−k+1) ((n−k+3)θ+1)² ((n−k)θ+1)² ) ≥ 2^{0.528 n} / ( 3·(2θ)^{0.53}·(n+1)·((n+3)θ+1)⁴ )。

*証明.* E_j の純な生成語は a^{2^{j−k}c}（倍化から。補題0 からそれが唯一）。

*短い符号.* k ≤ j ≤ n とする。E_j の規則を使う長さ ≤ θ の成功語の導出で、E_j の生成語 y は |y| ≤ θ < 2^{j−k}c。y が純なら E_j が二つの異なる純な生成語を持ち、両者は成功文脈を共有するので ≡ で、一方が他方の因子になって補題0 に反する。従って y は b を含む。これを ω_j とする（|ω_j| ≤ θ）。同じ導出から、E_n は長さ ≤ θ − 1 の成功文脈 (l, r) を持つ。

*(C1).* E_{k+1} → E_kE_k から、ω_k a^c、a^c ω_k、ω_k ω_k はいずれも E_{k+1} の b を含む生成語なので、C.0 から ≡。z_0 := ω_k。

*(C2).* E_j → E_{j−1}E_{j−1} から ω_j ≡ a^{2^{j−1−k}c} ω_{j−1}（同じく C.0）。帰納法で ω_j ≡ a^{(2^{j−k}−1)c} ω_k。z_i := ω_{k+i−1}（i = 1, …, M）、e_i = (2^{i−1} − 1)c、v_i = 2^{i−1}c。

*(C3).* v_i は c の相異なる 2 冪倍なので、部分和は全て異なる。

*(C4).* P := c とすると e* = Σv_i + P − c = (2^M − 1)c。a^{(2^M−1)c} ω_k は E_n の b を含む生成語（一番右の E_k を ω_k に替える）なので、l a^{e*} ω_k r ∈ L。

λ ≤ θ、m ≤ (θ−1) + c + Mθ。定理C から主張が出る。依頼文の鎖では c = 2^k ≤ 2θ。最後の不等式は 3^{(n−k)/3} = 3^{n/3}·3^{−k/3}、3^{k/3} = 2^{k·log₂3/3} ≤ (2θ)^{0.53} から。∎

**系D（二重化の鎖での上界）.** 依頼文の設定で E_n = S、N = 2^n、M = n − k とすると

  N ≤ 2θ · [ 3(M+1)((M+3)θ+1)⁴(‖G‖+2) ]^{3/log₂3}（3/log₂3 ≈ 1.893）、M < 6 なら N < 128θ。

M ≤ log₂N なので、これは N ≤ poly(‖G‖, θ)（多重対数の因子を吸収して、例えば N = O((‖G‖θ⁴)^{1.9+ε})）。

### 2.3 注意と限界

- **使っていないもの**：T、命題DD、E_n が開始記号であること、ランク。使ったのは「規則 E_j → E_{j−1}E_{j−1} があること」「E_k が重いこと」「L が有限で C₁ に入ること」だけ。従って定理D は**文法のどこにあっても、重いラベルの二重化の鎖は O(log(‖G‖θ)) 段まで**という形で使える。
- 依頼文の予想「ω_n の類は価値 N の符号列を全て含む」は、補題2.2・2.3 の形で証明された：符号 ω_k, …, ω_n と a^{2^k} の塊の連接は、価値が N のときに限り L に入る（順序は自由）。a の塊が 2^k の倍数でないもの（偶奇の条件の外）は扱っていない。

## 3. 課題3：一般の T

### 3.1 刻みの剛性

**命題S.** L は有限、L ∈ C₁。T の節点 u（ラベル B）の部分木の中に節点 v（ラベル X、b を含む生成語を持つ）があり、ずれが (L, R) とする。|P(ω_B)| ≥ 2 なら、P(ω_X) と P(ω_B) は定理1 の意味で同じ刻み (d, e) を持つ。
*証明.* 補題PC から P(ω_X) ∩ {x ≥ L, y ≥ R} = P(ω_B) + (L, R)。定理1 から P(ω_X) は x が増えると y が減る隙間のない等差列で、象限との共通部分は添字の連続した区間、従って同じ刻みの部分列。それが二点以上の等差列 P(ω_B) + (L, R) に等しいので刻みは一致する。□

**系S1.** T に M_Y ≥ 2 回現れるラベル Y について、P(ω_Y) は対角線上にあり（系3）、刻み d_Y = e_Y は全ての出現位置の差を割る。特に d_Y ≤ (N − n_Y)/(M_Y − 1)。

**系S2.** |P(ω_X)| ≥ 2 なら、X のどの出現の下にある b 語つきのラベルも全て刻み d_X を持つ。刻みは「二点以上の置き場所を持つ節点」から下へそのまま伝わり、**辺を下るごとに細かくなることはない**。依頼文の「整列の情報が消えていく」は、命題S の形では「反復するラベルの出現位置の差が刻みを割る」ことによって起こる。

**系S3（刻みは小さい）.** T の重い節点の集合（祖先で閉じた部分木）の葉（最小の重い節点）の数を ℓ とする。T の根から葉への道でラベルは反復しないので、一本の枝分かれのない区間の長さは < |V|、重い節点の数は ≤ (2ℓ−1)|V|。重い節点は ≥ N/((r+1)θ) 個なので ℓ ≥ N/(2(r+1)θ|V|)。従ってあるラベル Y が最小の重い節点として M_Y ≥ N/(2(r+1)θ|V|²) 回現れ、M_Y ≥ 2 なら

  d_Y ≤ 4(r+1)θ|V|²、

かつ系S2 により、Y の出現の祖先で二点以上の置き場所を持つ全てのラベルが同じ刻みを持つ。

**刻みの最終値は等式系からは決まらない**：§1.3–1.4 のとおり、二重化の鎖ですら PC の等式系は 2^k の約数の全てを許す。最終値を文法から決める式は得ていない。

### 3.2 一般の T で計数に必要なもの

定理C は (C1)(C2) さえあれば T の形によらない。二重化では (C1) が双子の節点 E_{k+1} → E_kE_k から、(C2) が鎖に沿った C.0 から自動的に出た。一般の T で欠けているのは次の一点である。

**問題C.** 有限の L ∈ C₁ で N が ‖G‖, θ, r の多項式を超えるとき、T の重いラベルの中から、ある基底 z_0 と c について (C1)(C2) を満たし、価値が (C3) を満たす符号を ω(log(‖G‖θr)) 個取り出せるか。

肯定なら定理C から矛盾し、op:S1 は肯定（N ≤ poly）。分かっていること：

- 双子の節点 B → C C（C は重い）があれば、z_0 = ω_C、c = n_C で (C1) が成り立つ。B の上の重いラベル D は C.0 から ω_D ≡ a^{L_D} ω_C a^{R_D}。(C2) には右の埋め草 a^{R_D} を左へ移す必要があり、n_C | R_D なら (C1) で移せる。一般には、刻み d_C（系S1 から d_C | n_C）を使って R_D を d_C 未満の剰余まで減らせるだけで、剰余が残ると、二つの符号の積の間の ω_C a^s ω_C（s ≢ 0 mod d_C）が潰れない。
- 双子のない T（加法鎖、例えば Fibonacci 型 F_k → F_{k−1}F_{k−2}）では、C.0 から ω_k ≡ ω_{k−1}a^{f_{k−2}} ≡ a^{f_{k−1}}ω_{k−2} ≡ ω_{k−1}ω_{k−2} が出る。補題2.1 による消去は型の違う語の間ではできない（ω_{k−1}ω_{k−2} ≡ ω_{k−1}a^{f_{k−2}} から ω_{k−2} ≡ a^{f_{k−2}} は出ない）ので、(C1) が出るかどうかは分からない。**ここが一般の場合の核心。**

### 3.3 小さい刻みと指数的な価値から計数へ

刻みが小さい（系S3）と、a^d ω_Y ≡ ω_Y a^d（d ≤ 4(r+1)θ|V|²）が成り立つ。これは (C1) の前半の「a^c との可換性」を c = d で与えるが、後半の z_0 z_0 ≡ a^c z_0（自分との積が潰れること）は与えない。後半は二重化では双子から出た。一般の T で「ω_Y ω_Y が Y と同じ類の生成語の a-ずらしになる」ことを示せれば、(C2) の剰余の問題と合わせて問題C に近づく。未着手。
