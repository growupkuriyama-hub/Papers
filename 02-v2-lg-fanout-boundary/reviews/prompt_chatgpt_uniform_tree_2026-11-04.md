## 2. Claude の観察（確かめること）

**(U) 一様な最小導出。** T は次の性質を持つものに取り直せる。

> 同じラベルの節点の部分木は全て同一である。

理由は次のとおり。

1. 補題2.1 により、同名の部分木は生成の総長が等しい。
2. 節点数も等しい。違えば、大きい方を小さい方に差し替えると、同じ語 a^k で節点が減る。
3. あるラベル B の全出現（反鎖）を、一つの部分木 t_B に同時に差し替える。
4. これをラベルごとに順に行う。後の差し替えは全出現に一様に効くので、先に揃えたラベルの部分木は同一のままである。

この結果、T は v 個以下の頂点を持つ DAG を展開したものになる。各ラベル X には規則が一つずつ決まる。

- 長さ：ℓ_X = c_X + Σ_{子} ℓ_子（c_X は規則が直接書く終端の数で、θ 以下）
- 出現数：N_X = Σ_{親 P} N_P · (P の規則に X が現れる回数)

つまり a^k は、v 個以下の規則からなる「直線的プログラム」で与えられる。反例には、ある両文字型ラベル B の上に倍増の鎖があって、N_B が超多項式になることが要る。

**(X) 違うラベルとの交差。** B の祖先のラベル P（重い）は、短い代表 ω_P を持つ。P の一出現が B の出現を t 個含むとき、次の二つの語を比べる。

- P を ω_P に差し替えた語：Parikh ベクトルは (k − d_P, |ω_P|_b, |ω_P|_c)
- その t 個の B を ρ_B に差し替えた語：Parikh ベクトルは (k − t·d_B, tβ_B, tγ_B)

複数のラベルの差し替えを整数で組み合わせると、b と c の個数が等しく a の個数が違う二語が作れる場合がある。例は、一色型ラベル C（b のみ）と C'（c のみ）を B と組み合わせる場合である。そのような二語を作れても、**同じ a 骨格**に揃えなければ定理S は使えない。

二文字の影では「Parikh 飽和かどうか」の二分法がこの揃えの役を果たしていた。三文字の全内容語に、これに当たる二分法はあるか。
