## 1. 問い

原稿の定理A は、型付けの像が局所群（窓の型付けを含む）なら、特徴データの長さが O(‖G‖²θ̄) であることを示しています。下界は Ω(‖G‖θ̄)（4f+1 文字以上）で、自明な型付けでは Θ(‖G‖θ̄) です。

**窓の型付けで、最短の特徴標本の長さは Θ(‖G‖θ̄) と Θ(‖G‖²θ̄) のどちらに近いか。** これを、小さな n で厳密に計算して調べてください。

## 2. 定義（ファンアウト1の場合。原稿の §2〜§3 と同じ）

- **窓の型付け** s_{k,ℓ}：m₀ = max{1, k+ℓ} として、|w| < m₀ なら w 自身、|w| ≥ m₀ なら（長さ k の接頭辞, 長さ ℓ の接尾辞）。自明な型付け s_triv は全ての語に同じ値を与える。
- **作用素** B_{1,s}^{≤2}(K)（ランク上限2）：
  - 非終端：K の語の空でない因子 x ごとに [x]。
  - Start：Ŝ → [w]（w ∈ K）。
  - Const：[x] → x。
  - Comp：x = α₀ u₁ α₁ … u_q α_q（端末の隙間 α は空でもよい、u は空でない、1 ≤ q ≤ 2）と分解できるとき、[x] → α₀[u₁]α₁…[u_q]α_q。ファンアウト1では、隣り合う子の間の隙間 α₁ は空でもかまいません（非併合の条件は、同じ子の連続する成分にだけかかるからです。E_i → l E_{i-1}E_{i-1} はこの形です）。
  - Link：s(x) = s(y) で、K の中に共通の文脈 (u, v) を持つ（uxv ∈ K かつ uyv ∈ K）とき、[x] → [y]。
- **特徴標本** F ⊆ L：F ⊆ K ⊆ L を満たす全ての有限集合 K について L(B(K)) = L となるもの。長さは ‖F‖₊ = Σ_{w∈F}(|w|+1)。
  - **確かめてから使ってほしい補題**：B(K) の規則の集合は K について単調に増え、L が (1,s)-代入可能なら L(B(K)) ⊆ L（健全性、原稿 `prop:reconstruction-soundness`）。したがって、F が特徴標本かどうかは「L ⊆ L(B(F))」だけを調べればよい。単調性を自分で確認してから使ってください。
- **最短の特徴標本の長さ** cs(L, s) = min ‖F‖₊。特徴標本に語を足しても特徴標本のままなので、意味があるのは最短の長さだけです。

## 3. 主な対象：族 F_n

```
E_0 → a,    E_i → l E_{i-1} E_{i-1}  |  c E_{i-1} r    (1 ≤ i ≤ n),   開始 E_n
```
L_n = L(F_n) は有限です（語数 2, 6, 42, 1806, …）。n ≤ 4 で Clark–Eyraud 代入可能（全数検査済み）なので、どの型付けでもクラスに入ります。s_{0,1}（末尾の文字）では、末尾が a の最短の語の長さは n(n+1)+1 です。

## 4. やってほしいこと

**T1（基盤）**
B_{1,s}^{≤2} を正確に実装してください。有限の L では、健全性により L(B(F)) ⊆ L なので、各 w ∈ L が B(F) で導出できるかを CYK 風の動的計画法で判定すれば足ります。
既知の例で検算してください：
- 原稿の標識族 `prop:linear-factor-all-fanout`（f=1、q, k が小さいもの）で、特徴標本は L 全体だけであること。
- 括弧付き倍増族（E_i → ⌊E E⌋ | ⌈E⌉）で、型が1の語 W_n が s_U の下で必ず要ること。

**T2（F_n の厳密な値）**
n = 1, 2, 3（できれば 4）、型付け s_triv, s_{0,1}, s_{1,0}, s_{1,1} について、次を求めてください。
(a) ‖G_n‖（原稿 `def:standard-mcfg` の数え方）、θ̄、各型の μ_m。
(b) **最短の特徴標本の長さ cs(L_n, s)**。n ≤ 3 では厳密に求めてください（分枝限定法、または長さ順の探索。L_3 は 42 語）。n = 4 で厳密が無理なら、上界（貪欲法で包含極小な標本を作る）と下界（稀な型の議論、および「この語を抜くと失敗する」語の集まり）を分けて書いてください。
(c) 原稿の証拠集合 Wit（各型付き非終端・型付き規則に、最短の代表と短い文脈を使ったもの）の長さ。
(d) **償却の構成**：「短い証拠 ＋ 稀な型ごとに長い語を1本」のような標本が特徴標本になるかを確かめ、その長さを求めてください。

**T3（増え方の判定）**
cs(L_n, s) が n² 型か n³ 型かを、表と比で示してください（‖G_n‖ = Θ(n)、θ̄ = Θ(n) なので、n² は ‖G‖θ̄、n³ は ‖G‖²θ̄ に当たります）。n が小さいので、推測には「観察」と明記してください。

**T4（Ω(‖G‖²θ̄) を狙う族の探索）**
F_n では長い語1本が全ての段の代表を同時に含むので、償却が効く可能性があります。償却が効かないように、**互いに共有できない長い代表を ‖G‖ 本程度必要とする族**を設計し、計算してください。例：
- 末尾の型ではなく、文の途中の窓の型を区別させる族（ファンアウト1で s_{1,1} など）。
- 段ごとに別の「背骨」を持ち、一本の語では二つの背骨を同時に通れない族。

各候補について、必ず次を確かめてください。
① クラスに入ること（有限の言語なら全数検査）
② ‖G‖・θ̄・cs の値
③ 増え方
逆に、どう設計しても償却されてしまうなら、その理由（どの規則がどの長い語で同時に賄われるか）を構造として述べてください。それは O(‖G‖θ̄) の証明の手がかりになります。

**T5（証明できるところ）**
計算で見えた規則性のうち、証明できるものは証明してください。特に次の二つです。
(i) F_n が全ての n で Clark–Eyraud 代入可能であること（01 の論文 arXiv:1409.6247v5 の付録 C にある、決定的構文解析器による議論の改変）。
(ii) F_n の cs の上界または下界。
