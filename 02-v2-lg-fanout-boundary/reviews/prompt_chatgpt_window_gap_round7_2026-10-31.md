## 1. 設定

- s = s_{0,1}（末尾の1文字。1文字の語はその語自身）。ファンアウト1、ランク r_max は固定。
- L ∈ C_{1,s}、G は L∖{ε} の reduced good な CFG 表示。‖G‖ は記号単位の大きさ、θ̄ は「各規則を使う最短の文の長さ」の最大値。
- 作用素 B_{1,s}：観測した因子 x ごとに [x]。Const、Comp（観測した z を、端末の隙間と空でない子に分ける）、Link（同じ型で、標本の中に共通の文脈を持つ）、Start。
- 健全性：[x] から導出される y は x と型付き合同です。Comp の子が生成する語も、その子の型を保ちます。
- 目標：全ての L と G について、最短の特徴標本の長さ cs ≤ c_{r_max, Σ}·‖G‖θ̄ を示すこと。原稿の上界は O(‖G‖²θ̄) です。

## 2. F_n で効いた仕組み（Astra 第3次、検証済み）

1. **右にずらした断片**：X_A^b = {u b : u ∈ L_A}、T_A^{p,b} = {∂u b : u ∈ L_A、u は p で始まる}。断片の型は次の文字 b で決まるので、共通の文脈に入れた代表どうしは自動的に同じ型になり、Link が張れます。
2. **局所証明書補題**：補助記号 X ごとに代表 h_X と文脈 e_X を決め、各補助規則の代入語 z_R も同じ文脈に入れて観測すれば、B は補助文法の導出を全て再現できます。
3. **背骨**：文末で終わる節点には次の文字が無いので、1 が使えません。F_n では、末尾が a の背骨を、一本の長い語 U_n の接尾辞を Comp で ∂U_i = (C_{i−1} l)·∂U_{i−1} と切ることでまかないました。Link は使いません。

## 3. Claude からの手がかり（証明はまだ）

- **B の非終端は文字列で決まります。** 同じ文字列 h が、標本の別々の語に因子として現れれば、それは同じ非終端 [h] です。そこから得られる Comp 規則は全部合わさります。したがって、**長い文字列を一度決めて、複数の観測語に共通の部品として入れれば、Link なしで共有できます**。
- **Comp の観測は、文中のどの位置でも構いません。** 背骨の断片の分割 [h_A] → [x][h_C] は、h_A が標本のどこかの語に因子として現れれば使えます。文末にある必要はありません（Astra 第4次で、右端での観測が不要なことが示されています）。
- **残る障害（Astra 第4次 §4、§5）**：背骨の非終端 A に、末尾の型を保つ規則が複数あると、規則ごとに「左側の断片 ＋ 長い背骨の続き h_C」を観測する必要があります。h_C の長さは最大で t_typ = O(‖G‖θ̄) なので、素朴に足すと ‖G‖·t_typ = O(‖G‖²θ̄) に戻ります。
- **見込み**：背骨の続きの「標準の文字列」を、最短導出の木に沿って矛盾なく選びます（各 h_A = 断片·h_C の形で、互いの接尾辞になるように）。そうすれば、長い部分は木の枝ごとに一度ずつしか現れず、総和を「木の大きさ × θ̄」程度に抑えられるかもしれません。ただし、規則ごとの観測語にはそれぞれ h_C 全体を含める必要があるので、ここが本当の山です。

## 4. 調べてほしいこと

**T1（一般の上界）**
s_{0,1}、ファンアウト1で、cs = O(‖G‖θ̄) を証明してください。完全な一般形が無理なら、次の順に弱めた形で構いません。
- (a) 条件付き：各非終端 A と、実現される各先頭 p について、「先頭が p の A の最短 yield」が O(θ̄) であるとき（先頭が安い文法）。
- (b) 背骨の費用を明示した形：cs ≤ c·(‖G‖θ̄ + Λ(G))。Λ(G) は背骨の証拠の最小の総長として正確に定義し、Λ(G) の上界と下界を与えてください。

いずれの場合も、補助文法の作り方（記号と規則の一覧）、その大きさが O(‖G‖) であること、各代表と文脈の長さ、標本の総長を、具体的に書いてください。

**T2（障害が本物なら、下界の族）**
T1 の途中で、背骨の使い回しの費用が本当に避けられないと分かったら、それを使って、s_{0,1}、ファンアウト1で cs = ω(‖G‖θ̄)（理想は Ω(‖G‖²θ̄)）となる族を作ってください。必要なことは次の三つです。
- ①クラスに入ることの証明（Clark–Eyraud 代入可能性が望ましい）
- ②‖G‖・θ̄ の計算
- ③下界がどの作用素について成り立つかの明示

これまでの報告で、三次の下界への道が三つ閉じています。境界をまたぐ Link、文中で確立した非終端の文末への持ち込み、文字列が同じなら同じ非終端になること、の三つの逃げ道を全て排除できるか確かめてください。

**T3（小さい例での確認）**
T1 か T2 の構成を、小さい n で、あなたの以前の B の実装（2回目の `complete`、または6回目の `Grammar`）を使って確認してください。結果は「観察」として扱ってください。
