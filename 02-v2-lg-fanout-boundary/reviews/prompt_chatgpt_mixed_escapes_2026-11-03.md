## 1. 設定と前回の結果

Σ = {a, b, c}、内容型付け c、L ∈ C_{2,c}、G は L∩Σ⁺ の reduced good な表示（ファンアウト ≤ 2、ランク ≤ r）、v = |V|、θ = θ̄_G。k := μ_a(L) ≥ 5、T を a^k の節点数最小の導出（同じ非終端は一本の道に二度現れない）。

各非終端 B と x ∈ {b, c} について
  β_x(B) := min{ ‖z‖₁ : z ∈ L_B(G)、z の全成分が {a,x}⁺ に入り、x を含む }（なければ ∞）、
  β_x := max_{B は T の重い節点に現れる} β_x(B)。

**定理L1（証明済み）**：x = b, c のそれぞれについて μ_a ≤ 10(r+1)²v²·max{1, θ, β_x}⁴。

**弱点**：L1 は全ての重い節点で同じ影 x を使う。三文字の本当の難しさは、節点ごとに安い逃げ道が b のこともあれば c のこともある場合にある。

## 2. 問い

> **混ざった逃げ道の補題（M）**：β* := max_{B は T の重い節点に現れる} min{ β_b(B), β_c(B) } とおく。μ_a ≤ poly_r(v, θ, β*) が成り立つか。

成り立てば、反例には「短い逃げ道が全て b と c の両方を含む」重い節点が必要になる（その節点では β_b(B) と β_c(B) の両方が大きい）。これは問題を一つの形に絞る。

## 3. してほしいこと（優先順）

1. **補題M を証明する**。L1 の証明の二つの場合（非飽和の反鎖の議論、飽和の Parikh の議論）は、どちらも「一つの二文字の言語 L ∩ {a,x}⁺ の中」で行われていた。三文字の言語 L の中で、b の逃げ道を入れた節点と c の逃げ道を入れた節点が混ざった語を扱う必要がある。手がかり：
   - 二文字の走りの補題のうち、三文字でも成り立つもの：a の再配分（a⁴ があるので常に使える）、個数の漏れ、「a a y a（y は b か c の一文字）があれば ay と ya の分布が一致する」（`lem:app-two-runs`(ii) の証明は、文脈の内容が {a, y} であれば三文字でも通る。確かめること）。
   - 鳩の巣：重い節点の反鎖が大きければ、その半分以上は同じ側（b の逃げ道が安い、または c の逃げ道が安い）に属する。同じ側の節点だけを差し替えれば二文字の影の中の語になる。L1 の非飽和の議論はそのまま使えるか（使えるなら、反鎖の大きさは 2×9 程度で抑えられる）。
   - 飽和の場合：L ∩ {a,x}⁺ が飽和かどうかは x ごとに違いうる。b 側が飽和で c 側が非飽和、などの組合せを全て扱う。b 側の節点の重みと c 側の節点の重みを比べる必要が出たら、その段を特定する。
2. **補題M が成り立つ場合**：反例に必要な「両方の文字を必ず含む逃げ道」の節点について、何が言えるかを調べる（例：その逃げ道の中の b と c の位置関係、倍増節点での交差置換、共役移送）。
3. **補題M が一般には言えない場合**：通らない段を特定し、b 側と c 側が混ざることで本当に新しい現象が起きる例（有限の小さな例でよい）を示す。
4. どれも完了しない場合は、証明できたこと、止まった場所、次に絞るべき一点を書いて終える。

## 4. 計算について

必要なら、有限言語の (1,c)・(2,c)-代入可能性の全数検査を使う（前回までの付録を再利用してよい）。Python 3 の標準ライブラリだけで書き、全文を載せる（Windows の `py -3 script.py` で動く形）。有限の検査の結果から無限の族の代入可能性を推定しない。

## 5. 守ってほしいこと

- 冒頭に、主張ごとの判定（証明済み／反証／観察／未解決）と根拠の節を書いた表を置く。
- 下界には、作用素（B^{≤r}_{2,c}、B_{2,c}、クラス全体に特徴標本を持つ集合駆動作用素）、ファンアウト、ランク、アルファベットの条件を明記する。
- 証明した範囲を超えて書かない。「最大の特徴標本」と書かない。「境界がファンアウトで動く」は、三文字の全ての内容型を証明した場合以外は書かない。
- 新しい結果が文献で既知かどうか、分かる範囲で書く。分からなければ「未確認」と書く。
