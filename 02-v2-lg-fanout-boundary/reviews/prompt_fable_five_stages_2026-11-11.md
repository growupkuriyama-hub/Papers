## 1. 定義（`main.tex` に従う）

- **語と内容**：k = |Σ|。Ψ はパリク像、cont(w) は w に現れる文字の集合。内容型付け c_Σ は語に cont(w) を返し、組 x = (x₁,…,x_d) の型は (cont(x₁),…,cont(x_d))。
- **許容的な文脈** 𝓔_d：E = v₀□v₁⋯□v_d で、内側の v₁,…,v_{d−1} は空でない。D_L(x) = {E ∈ 𝓔_d : E[x] ∈ L}。
- **代入可能性**：(f, c_Σ)-代入可能とは、全ての d ≤ f と、型が等しい x, y について、D_L(x) ∩ D_L(y) ≠ ∅ ⇒ D_L(x) = D_L(y) となること。C_{2,c_Σ} は SUB₁ と SUB₂ を満たす 2-MCFL のクラス。
- **文法**：
  - 既約 good な MCFG（ε-free、nondeleting、nonpermuting、nonmerging）。分布同値は good なテンプレートへの代入で保たれる（`lem:witnessed-composition`）。
  - 厚さ θ̄_G は、各規則について「その規則を使う最短の文の長さ」を取った最大。θ = max(1, θ̄_G)、r はランク、v = |N|、f はファンアウト。
- **代表の長さ**：型付き非終端 X = A_(M₁,…,M_d) について τ_X = min{‖x‖₁ : x ∈ Cl_{L,c}(X)}、τ = max_X τ_X。代表は分布同値な組なら何でもよい。特徴データは N_typ(1 + 2θ̄_G + r_max·τ) 以下。
- **クラス 𝒦**：
  - Σ = Γ₁ ⊔ ⋯ ⊔ Γ_t（順序付きの段）。ND は段非減少な語の全体。
  - L = ND ∩ Ψ⁻¹(Q)、Q = ⨆_M Q_M、Q_M = Π_M ∩ (q_M + N_M)（N_M ≤ ℤ^M は格子。値と部分群が内容ごとに変わる可換群の模型と同じ）。𝓜* は Q_M が空でない内容の全体。

- **段の記法**：
  - st(S) = {s(a) : a ∈ S}（s(a) は文字 a の段）。
  - **隣接対**は {u, u+1} の形の段の集合。π(S) は、st(S) を「一つの段か隣接対」の互いに交わらない区間で覆うのに要る最小の個数。
  - **三方型**：移動の支持 S と、違いのある段 p < p′ について、st(S) が s < p < s′ < p′ < s″ を満たす段 s, s′, s″ を含むこと。

## 2. 既知の結果（Fable の二本の報告。Claude Opus が一行ずつ確認し、自前の検査でも違反 0。別系統のモデルの確認はまだ）

### 2.1 所属

- **Comp(T)**：型 T の文脈で E[x] が ND になるものの全体。v_i の段は [hi_i, lo_{i+1}] に入るので、成分の「内側の段」の文字は文脈に置けない。
- **Acc_T(n)**：総量 n について、文脈 E ∈ Comp(T) で Ψ(E) + n ∈ Q となるときの、受け入れる内容 supp(Ψ(E) + n) の集合。
- **定理1**：arity d で代入可能 ⟺ 全ての型 T、総量 n、M, M′ ∈ Acc_T(n) について、N_M ∩ O_T(n) = N_{M′} ∩ O_T(n)（O_T(n) = {h ∈ ℤ^{J_T} : n + h ≥ b_T}）。
- **系1b**：有限指数なら N_M ∩ ℤ^{J_T} = N_{M′} ∩ ℤ^{J_T} と同値で、有限の計算で厳密に判定できる。
- **定理1 の系（同値類の形）**：X の同値類は、総量が (n + N_M) ∩ (b_T + ℕ^{J_T}) に入る型 T の ND な組の全体。

### 2.2 移動の補題

- **補題 M\***：q, q − z, α ∈ Q で、q と α が z⁺ + 2·𝟙_S 以上（S = supp z）、L が arity π(S) で代入可能なら、α − z ∈ Q。隣り合う二つの段は一つの成分に入れてよい。
- **補題 M2**：L が arity 2 で代入可能で、st(S) = {s₁ < ⋯ < s_r}、Int_j = (s₁, s_j) ∪ (s_{j+1}, s_r) とする。q と α が Int_j の段の全ての文字で等しいなら、α − z ∈ Q。違いのある段が二つ {p, p′} のとき、どの j でも使えないのはちょうど三方型のときで、それには段が5つ要る。
- **系 M\***：有限指数で SUB_{≤d} なら、π(S) ≤ d の全ての S で N_M ∩ ℤ^S = N_{M′} ∩ ℤ^S。t ≤ 2d なら全ての arity で代入可能。

### 2.3 定理 A・A⁺ の証明の骨格と、止まる箇所

1. X の生成組の、節点が最小の導出木を取る（深さ ≤ D = v(2^k−1)^f）。
2. **詰め物**（補題 P）：仮想の葉 V（|V| ≤ k、帰納法で短い代表 ỹ_κ に置き換える）。
3. **良い節点** ω の規則差分 d_{R_ω}（‖·‖₁ ≤ (r+2)θ）は一つの面の格子 N_U に入る。H′ = ⟨d_{R_ω}⟩。
4. **補題 O′** で、総量を H′ の短い元 z で順に減らす。
5. **戻し**：深い点 q = Ψ(s_V) ∈ Q_U で q − z ∈ Q_U（飽和）。補題 M* で α − z ∈ Q。
6. **結論**：t ≤ 2f なら τ ≤ τ_k = O_{k,f,r}(θ^{k²+2k} + vθ^{k²+k+1})（定理 A⁺）。全ての d ≤ max(f, t) で代入可能なら t は任意（定理 A′）。

止まる箇所は手順5 だけです。f = 2 で止まるのは、次の全てが同時に起きるときに限られます（前回 §5.3(c)）。
- t ≥ 5。
- 仮想の葉 κ がファンアウト 2 で、その二つの成分の段 p < p′ の両方で u_κ と ỹ_κ の個数が違う（または κ が骨格の節点）。
- 移動 z の支持が三方型。

### 2.4 各段一文字と、反例の必要条件

- **補題 S（骨格）**：成分のある塊の内側にある節点を「内側」と呼ぶ。
  - 内側でない節点は 2ftD′ 個以下。
  - 内側の節点の任意の生成組は、その塊の段の文字だけからなる（純粋な詰め物）。
  - 内側の節点の規則差分は f 個以下の段にまたがる。
- **定理 B**：各段が一文字なら、𝒦 も代入可能性も使わずに、任意の good な文法で全ての型付き非終端が長さ 2fkD(1+r)θ 以下の生成組を持つ。
- **反例の必要条件**（𝒦 ∩ C_{f,c_Σ} で τ が超多項式の族）：
  - N1：同じ段に二文字以上ある。
  - N2：t ≥ 2f + 1。
  - N3：ある arity f < d ≤ t で代入可能でない。
  - N4：ある a ∈ J_T で p_a(M) が 0 か超多項式。全ての a ∈ J_T で p_a(M) > 0 なら τ_X ≤ k(f − 1 + max_a p_a(M))。
- **窓の補題**：2^i = λ·m（‖m‖₁ ≤ θ）と書ける i は k(⌊log₂(kθ)⌋ + 1) 個以下。

### 2.5 前回の失敗した設計（観察、§6.2）

段 1〜5、文字 a | c, ψ | e | g, χ | i で、段2・4 をまたぐファンアウト2の非終端（短い生成組は (ψ, χ)）を使った設計です。壊れ方は三つありました。
1. ψ, χ がまたぐ節点からしか出ないと、移動は二段の純粋な部分に分かれて戻せる。
2. 他の節点からも出ると、中間の面が生じて段ごとに戻せる。
3. 固い個数（N4）は、塊の内側の純粋な詰め物と窓の補題に阻まれる。

排除できていない設計は、「三つ以上の詰め物の文字が段2と4にあり、中間の面の比較が全て内側の段の個数の不一致で妨げられる」ものです。

## 3. 課題

f = 2 とし、対象は 𝒦 ∩ C_{2,c_Σ} の、段 ≥ 5 で同じ段に二文字以上ある言語です。目標は、どちらの方向かに決着をつけることです。

### 課題1（多項式データの方向、第一候補）：固い個数を文法の側から排除する

N4 から、次を示せば t によらない上界が出ます。

> **(R)** 厚さ θ の既約 good な文法 G で L(G) ∈ 𝒦 ∩ C_{2,c_Σ} のとき、τ_X が大きい型付き非終端 X と、その面 M ∈ Acc_T(n) の全ての a ∈ J_T について、p_a(M) > 0 かつ p_a(M) ≤ poly(θ)、または、p_a(M) = 0 の文字があっても同値類の中で n_a を poly(θ) まで減らせる。

- (a) **p_a(M) > 0 の上界**：補題 S から、a の長い塊の内側の節点の詰め物は a と同じ段の文字（純粋とは限らない）です。二段以下の移動（補題 M*）だけを使って「同じ段の別の文字の詰め物」を戻し、a だけの短い差を作ってください。窓の補題を任意の可換群の商に延ばす形（短い関係の格子の階数で場合分けする）が前回の見込みです。
- (b) **p_a(M) = 0 の扱い**：a だけの方向の移動がないとき、同値類の中で a の個数を他の文字と組で動かせるか（N_M の中の短い、a を含むベクトル）。それが三方型にならないことを示せるか。
- (c) 示せない場合は、(R) が破れる具体的な状況（文法と言語、所属の証明付き）を挙げてください。それは課題3 の候補になります。

### 課題2（多項式データの方向、第二候補）：t = 5 の三方型を直接閉じる

- §2.5 の壊れ方1 の議論（またぐ節点の規則差分は二つの段に閉じる）を、骨格の節点と複数の詰め物の文字を含めて証明にしてください。
- 得たい形：「三方型の移動 z は、二段以下の移動の和に分解でき、その各々は補題 M* か M2 で戻せる」。または、定理 A の手順4 の短縮で三方型の z を使わずに済む（三方型でない生成元だけで H′ の必要な部分が張れる）。
- t ≥ 6 で、三方型が二重・三重に重なる場合に延びるかも述べてください。

### 課題3（下界の方向）：機械的な探索

前回の §11 の2(ii) です。
- 無限指数の言語（T_n の型、すなわち一部の面の格子が満階数でない）で、中間の面の比較が全て「内側の段の個数の不一致」で妨げられるものを、定理1 の (★) を小さな箱の中で全数検査して探してください。
- 候補が見つかったら、族に延ばして |G|、θ、τ の表を作ってください。所属は (★) の手の証明で、τ の下界は同値類の最小ノルムとして手で示します。
- 見つからなければ、探索した範囲（段の数、文字の数、格子の生成元の大きさ、箱）と、壊れ方の分類を報告してください。
