## 1. 設定（前回と同じ）

- Σ = {a, b, c}、内容型付け c = c_Σ、L ∈ C_{2,c}（arity 1 と 2 の両方で代入可能、arity 2 の穴の間の区切りは空でない）。
- G は L∩Σ⁺ の reduced good な表示（ファンアウト ≤ 2、ランク ≤ r、r ≥ 2）。v = |V|、g = ‖G‖、θ = θ̄_G。
- 一穴文脈 C について P_a(C) = min{k ≥ 1 : C[a^k] ∈ L}、μ_a(L) = P_a(□)。
- k = P_a(C) ≥ 5 とし、T を C[a^k] の節点数最小の導出、印は C の固定部分の全ての文字と穴の最初と最後の2文字。
- 各非終端 B に、短い生成組 ω_B ∈ L_B(G)（‖ω_B‖₁ ≤ θ）を一つ選ぶ。**符号** κ(B) := σ_a(a ω_{B,1} a ⋯ a ω_{B,d} a)（σ_a は a の極大な塊を一文字にする骨格）。
- M = M(T)：T の印の無い重い節点（総長 > θ）に現れる、相異なる κ(B) の個数。

## 2. 分かっていること（前回の報告、検証済み）

- **定理3.1**：印の無い重い節点 h, h′ で κ(B_h) = κ(B_{h′}) なら、失う a の数 w_h := ℓ_h − |ω_{B_h}|_a は等しい（比較可能でも、非終端が違ってもよい）。
- **定理4.2**：P_a(C) ≤ m·v(m+1)²·θ·[1 + r(v+1)·r^M]、m = |C|_fix + 4。M ≤ v なので、これは θ と |C|_fix について多項式、v についてだけ指数の無条件の上界。
- **系4.4**：P_a(C) が超多項式の族には M = ω(log n) が要る。
- 二つの重い節点の反鎖 J を同時に差し替えた語の骨格は、J の各節点の符号を穴の中に並べたもので決まり、骨格が同じ二つの反鎖は失う a の総数が等しい（Claude の補題6.3(ii) と同じ議論）。つまり符号の上の**重み** w(κ) は、「骨格として同じ並びになる符号の多重集合」に対して加法的に一致しなければならない（k 未満の誤差なし）。

## 3. 問い

> **骨格の多様性の問題**：ω_B を適切に選び直せば、M(T) = O_r(log(g + θ)) にできるか。あるいは、M を数えるのをやめて、定理4.2 の r^M を多項式に置き換える別の数え方があるか。

肯定なら、定理4.2 により P_a(C)（|C|_fix ≤ θ）が多項式、とくに μ_a(L) が多項式になる。これは内容 {a} の型付き非終端の代表長 τ_X の多項式上界であり、三文字の肯定（`op:fanout-two` の肯定側）への大きな一歩になる。

## 4. 調べてほしいこと（優先順）

**S1（肯定の証明）**：次のどれかの道で r^M を除く。
- (a) **符号の同一視**：隙間の合流（補題3.4）と共役移送（補題3.5）で、異なる符号 κ, κ′ を持つ二つの差し替えを同じ骨格に揃え、系3.2(iii) で「重みが等しいか、差が k 以上」を導く。そこから、重みの異なる符号の種類が O(log) しかないことを示す。
- (b) **重みの加法性**：§2 の加法性から、重みは符号の上の「一意に復号できる重み付き符号」でなければならない。三文字では隙間に b, c の両方が入るので、この符号は一般には作れる。しかし合流で長い隙間ができたとき、その隙間の語からも重みが読めなければならない。この追加の条件で、重みの比が有界（例えば最大の重み ≤ poly × 最小の重み）になることを示す。
- (c) **補題4.1 の改良**：パスで初めて現れる符号ごとに r 倍する代わりに、「重い子の重みは親の重みの真の一部で、加法性から重みの大きさが階層で多項式に抑えられる」と示す。
- どの道でも、arity 1 と arity 2 の代入可能性のどれを、どこで使うかを明示してください。

**S2（否定の側：S1 が失敗する場合）**：
- 重みが倍々に増える符号の系（例えば、重み 2^i を持つ i 番目の符号）を、L ∈ C_{2,c} の中で実現する族を作れるか。
- 実現できたら、L_n、G_n を明示し、L_n ∈ C_{2,c}（arity 1 と 2 を省略せずに）、reduced good、ファンアウト、ランク、‖G_n‖、θ̄_{G_n}、μ_a(L_n) を全て証明する。
- 実現できない場合、どの代入可能性の条件（合流、共役移送、冪の移行）が符号の系を壊すかを、具体的な違反の組で示す。

**S3（どちらも完了しない場合）**：証明できたこと、止まった場所、重み付き符号について分かった新しい制約を書いて終える。
