### 未解決問題 `op:fanout-two` と、否定の十分条件
三文字 Σ = {a,b,c} の内容型付け c_Σ(w) = cont(w) で、ファンアウト ≤ 2 の代入可能な言語（C_{2,c_Σ}：arity 1 と 2 の内容型付き代入可能性 SUB₁・SUB₂）の、内容 {a,b} の最短語の長さ μ_{ab} が、文法の大きさ v = |V| と厚さ θ̄ の多項式で抑えられるか。‖G_n‖, θ̄(G_n) = poly(n) で μ_{ab} が超多項式の C_{2,c_Σ} の族があれば否定される（`prop:rare-type`）。

SUB_d の規約：文脈 E = v₀□₁v₁…□_d v_d（両端は空でもよい、d = 2 の内部 v₁ は非空）、穴の成分は非空。cont(x_i) = cont(y_i) かつ E[x], E[y], F[x] ∈ L なら F[y] ∈ L。

### 閉包報告で分かったこと（証明は Claude が二回確認、別のモデルの検証は依頼中）
**一頂点のクラス** = パリク飽和な言語 L = π⁻¹(Q)（Q ⊆ ℕ³∖{0}、π はパリクベクトル）。Q₂ = Q の支持 {a,b} の部分、Q₃ = 支持 {a,b,c} の部分、Π₂, Π₃ は対応する格子点の集合、D₂ = Q₂ − Q₂、D₃ = Q₃ − Q₃、H₂ = ⟨D₂⟩、H₃ = ⟨D₃⟩、H₃⁰ = H₃ ∩ 平面（c = 0）。
- **定理2.1**：L が SUB₁ ⟺ 条件 (T)：同じ支持の q, q′ ∈ Q、h = q′ − q ≠ 0、S = supp h、全ての γ ∈ ℕ³ について h⁻ + 𝟙_S + γ ∈ Q ⟺ h⁺ + 𝟙_S + γ ∈ Q。
- **系2.2**：一頂点では SUB₁ ⇒ 全ての SUB_d（既知、README (57)）。
- **補題2.3（移動）**：q, q′ ∈ Q（同じ支持）、h = q′ − q。α ∈ ℕ³ が supp h の上で α_σ ≥ 1 かつ α_σ + h_σ ≥ 1 なら、α ∈ Q ⟺ α + h ∈ Q（c 座標などその他は任意）。
- **補題2.4**：Q₂ = (q + H₂) ∩ Π₂。
- **定理2.7**：(P⁺)（両方の座標が狭義に大きい二つの ab の点がある）なら、a,b を含む部分は (16) の形で、定理 H により μ_{ab} ≤ max{9(r+1)vθ, 226v³θ³}。有限群でも同じ（系3.6(a)）。
- **例2.8**：T_n（Q₂ = {(1+3n,1,0), (1,1+3n,0)}、Q₃ = 三角形 {(3,2,1),(1,3,2),(2,1,3)}）は代入可能だが (16) の形でない。ただし abc 語が有界なので、補題3.9（abc 語の長さが全て ≤ B なら μ_{ab} ≤ max{2B, 9(r+1)vθ}）で片付く。
- **定理3.7**：F_L := min_{K₂ 許容的} [K₂ + H₃⁰ : K₂]（K₂ が許容的 ⟺ (q₂ + K₂) ∩ Π₂ = Q₂）とすると、μ_{ab} ≤ max{9(r+1)vθ, 2050F_L³v³θ³}。
- (P⁺) が成り立たないとき、Q₂ は「負の傾きの線分上の有限集合」か「一つの座標が一定の半直線」か「一点」（補題2.4 と、ℤ² の階数2の部分格子は狭義に正の元を持つこと）。

## 1. 依頼：命題7.2

> **命題7.2。** L = π⁻¹(Q) が C_{2,c_Σ} に入り（一頂点なので SUB₁ と同値）、(P⁺) が成り立たず、Q₃ が無限（abc 語の長さが有界でない）とする。このとき、L の任意の既約 good な表示 G で μ_{ab}(L) ≤ poly_r(v, θ̄_G) か？

閉包報告の見立て：無限の Q₃ は Dickson の補題により非負の差 w ∈ D₃ を持ち、補題2.3 で Q₃ は w の方向に周期的になる。この周期の移動と、三角形型の差の移動が「同じ高さ（同じ c の個数）の abc の点」を作り、それが (P⁺) か F_L = 1 を強制する。手計算の試行三つでそうなったが、網羅的ではない。

**この命題が解ければ、パリク飽和な（文字の並び順によらない）代入可能な言語は、完全に閉じます。** 否定的に解ければ、それはこのクラスでの唯一の反例の候補になり、`op:fanout-two` の否定につながります。

## 2. 課題

### 課題1（構造の定理、主目標）
次のどちらかを証明すること。
- **(S)** SUB₁ を満たす一頂点の L で Q₃ が無限なら、(P⁺) が成り立つか、F_L が言語の簡単な量（例えば Q₃ の極小元の大きさ）で抑えられる。
- **(S′)** もっと直接に、命題7.2 の仮定の下で μ_{ab} ≤ poly_r(v, θ̄)。文法の厚さと、Q₃ の周期構造を組み合わせてよい。

方針の候補（使わなくてよい）：
- Q₃ の非負の周期 w の支持で場合分けする。
  - supp w ⊆ {a,b} なら、w の移動は Q₂ の点でも有効なので Q₂ + w ⊆ Q₂。両座標が正なら (P⁺)、軸に平行なら Q₂ は半直線。
  - c ∈ supp w なら、Q₃ は c の方向にも周期的。
- 二つの周期（または周期と三角形型の差）の整数結合で、c 成分が 0 の差を作る。それが補題2.3 の意味で Q₂ の点で有効な移動になるか（定理2.7 の (2) と同じ論法）を調べる。
- Q₂ が「一つの座標が一定の半直線」（例：b の個数がちょうど N）の場合は、μ_{ab} が大きくなりうる唯一の形に見える。この形で Q₃ がどう縛られるかを集中的に調べる。

### 課題2（反例の探索、課題1が閉じない場合）
命題7.2 の仮定を満たし、μ_{ab} が大きい代入可能な Q の族を探すこと。
- 補題2.3 の移動による閉包（一頂点、ℤ³）を計算機で求め、種（三角形型の点、半直線型の Q₂、無限の方向）を変えて、(P⁺) と F_L の振る舞いを見る。閉包の計算は有限の箱で行い、箱の端の影響を明示すること。
- 見つかった族について、小さな文法（‖G_n‖, θ̄ = poly(n)）が作れるかを調べること。パリク飽和な言語の文法は、内容ごとに長さが一つの層言語のように、厚さで失格しやすい（README (177) の定理B2：長さに空白があれば θ̄ ≥ M）。この点も確かめること。

条件 (CW)（閉包報告 §3.6。一般のグラフ D で有限群の場合を閉じるための条件。関係する 17 種のグラフ全てで計算上成り立つ）を、手で証明すること。これができれば系3.6(b) が無条件になる。
