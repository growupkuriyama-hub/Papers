## 1. 到達点（検証済み）

Σ = {a,b,c}、内容型付け c、L ∈ C_{2,c}。W は内容がちょうど {a,b} の最短の語で、N = |W|。

**近道。** W より短い ab 語が、健全な規則（共通の許容文脈を持つ、成分ごとの内容が同じ組は分布が等しい）で強制されることを近道と呼ぶ。近道が出れば、その設計は反例にならない。

**分かっていること。**
- **トークンの障壁（(153) 命題5、(155) で適用範囲を限定して確認）：** 逃げ道を中身の見えない記号として扱う議論では、近道は出ない。近道は文字の並びの一致から生じる。
- **近道の最後の段の形（(153) 補題3、(155) §2.3 で精密化）：** 最初に長さ N 未満に達する段では、次が成り立つ。
  - 埋め草 x, y は c を含まず、‖x‖ > ‖y‖。
  - 共通の枠 E は c を含んでよい。
  - 第三前提 F[x] は ab 語だが、元の W とは限らない。
- **因子の一致（(153) 補題7・7′）：** 全ての前提が揃えば近道を生む。ただし e_C = s·β という一致だけでは足りない（(155) §4.3 の例 K = {abab, abc, cab, cc, ac} は C_{2,c} に属し、近道がない）。
- **仮想の長さ（(155) §5）：**
  - Claude の定式化は、種の正規化を欠いていた（通常の長さが常に解になる）。
  - 正規化すると、「閉包の c を含まない語が全て長さ N」と同値になる。
  - **長い ab 語が強制されるだけでは近道にならない**（長さが 4 の倍数の語全体の例）。長い ab 語は μ_{ab} を下げないので、反例にとって無害である。
  - したがって、目標は不整合ではなく、**近道そのもの**である。
- **加法的な場合の上界（(155) 定理6.1）：** λ(a) = λ(b) > 0、λ(c) ≥ 0 の一つの加法的な水準に言語全体が入るなら、μ_{ab} ≤ (r+1)θ²。代入可能性は使わない。
- **倍増族 A_0 → ab、A_i → A_{i−1}A_{i−1} | e_i（e_i は c を含む）：**
  - m = 3 の名前付きの7つの設計は全て近道を持つ。
  - 7つの設計は m = 4 でも近道を持つ（m = 3 の証明書を文脈の中へ移した特別な場合）。
  - (153) で打ち切りになった設計のうち3つは、(155) で近道ありと判定された（5〜7段）。
  - 閉包が閉じたのは、退化した設計（e_2 = e_1e_1 = cc）だけである。

## 2. 問い

**近道は、どのような文字の一致から生じるのか。その一致を全て避ける、c を含む短い逃げ道の設計はあるか。**

- 全ての一致の型が深い倍増で避けられないと示せれば、倍増型の μ_{ab} は多項式になる（肯定の向き）。
- 避ける設計が見つかれば、それが反例の候補になる（否定の向き）。

## 3. してほしいこと（優先順）

1. **(155) の新しい主張の確認。** 次の四つを確かめる。
   - 定理6.1 の証明（特に、閾値を交差する節点の選び方）

   - §4.3 の例 K が C_{2,c} に属すること
   - 打ち切りだった3設計の近道の証明書（6, 7, 5段）
2. **近道の証明書の分類。**
   - m = 3 の倍増族の探索を、時間ではなく段数・語数の決まった上限で再実行し、近道の証明書を全て集める。(155) の付録のような、時間に依存しない閉包を使うこと。
   - 各証明書を、使っている文字の一致の型で分類する。型の候補は次のとおり。
     - 逃げ道どうしの接頭・接尾の一致（補題7の型）
     - c の連の重なり（cc と c の比較）
     - 逃げ道の a, b の部分と、W の ab の並びの位相のずれ（a で始まるか b で始まるか）
     - その他
   - 型ごとの件数を表にし、各型の最短の代表的な証明書を、抽象的な文字の基礎の証明書として書き直す。
3. **抽象化と持ち上げ。**
   - 各型について、どの条件で近道が出るかを補題の形で書き、証明する。
   - 基礎の証明書を非消去準同型で持ち上げ、具体例で再生して検査する。持ち上げの健全性の条件は次のとおり。
     - 成分ごとの内容が保たれること
     - 二穴の中央が空でないこと
     - 種の像が仮定に含まれること
4. **全ての型を避ける設計の探索。**
   - 分類で得た型を全て避ける逃げ道の族を設計する。例えば、逃げ道の両端の文字、c の連の長さ、a, b の位相をそろえる、などの条件で絞る。
   - m = 3, 4 で閉包を計算し、近道が出るかを見る。
   - 出なければ、閉包を総当たりで閉じているか確かめ、所属の証明に進む。
   - 出れば、その証明書が新しい型かどうかを見て、分類を更新する。
5. **肯定の向きの試み。**
   - 逃げ道の長さが θ 以下という条件の下で、深い倍増（m が θ の多項式より大きい）では、分類した型のどれかが必ず起きることを示せるか。
   - 起きるなら、倍増型の μ_{ab} の多項式の上界を、定数付きで書く。
6. どれも完了しない場合は、次の三つを書いて終える。
   - 証明できたこと
   - 止まった場所
   - 次に絞るべき一点

## 4. 計算について

Python 3 の標準ライブラリだけで書き、全文を載せる（Windows の `py -3 script.py` で動く形）。コードを実行できる環境なら実際に動かし、出力をそのまま載せる。実行できない場合は「未実行」と明記し、出力を推測で書かない。

- 閉包は時間で打ち切らず、段数・語数・長さの上限を決めて、結果が機械の速さに依存しないようにする。
- 強制した語ごとに、種から再生できる証明書（各段の E, x, y, F）を残す。再生は別の関数で独立に行う。
- 「近道が強制された」は上限で切っても正しい。「強制されない」は、上限なしの総当たりで閉性を確かめた場合を除き、観察にすぎない。この区別を明記する。
- 所属を文法で判定するときは、長さで切った集合ではなく、文法から厳密に判定する。
- 有限の検査の結果から、無限の族の代入可能性を推定しない。

## 5. 守ってほしいこと

- 冒頭に、主張ごとの判定の表を置く。検証した主張には「独立に確認」「誤り」「確認できず」のいずれかを、新しい主張には「証明済み／反証／観察／未解決」のいずれかを書く。
- 「自明に成り立つが目的には足りない」主張と、既に知られた補題の特別な場合にすぎない主張は、その旨を表に書く。
- まだ所属を示していない言語に、その所属を前提にした補題を使わない。
- 証明した範囲を超えて書かない。
  - 倍増族の結果を一般の文法に広げて書かない。
  - 開始の型 {a,b} の結果を、他の欠けた型や τ に広げて書かない。
- 反例を主張するのは、所属・下界・文法の大きさの全てを証明した場合だけ。
- 「最大の特徴標本」と書かない。
- 「境界がファンアウトで動く」は、三文字の全ての内容型・全ての場合を証明した場合にだけ書く。
- 新しい結果が文献で既知かどうか、分かる範囲で書く。分からなければ「未確認」と書く。
