## 1. 到達点

Σ = {a, b, c}、内容型付け c、L ∈ C_{2,c}、G は L∩Σ⁺ の reduced good な表示（ファンアウト ≤ 2、ランク ≤ r）、v = |V|、θ = θ̄_G。k := μ_a(L) ≥ 5、T を a^k の節点数最小の導出。

**定理3.1（証明済み）**：μ_a ≤ 19(r+1)³v³θ³(θ+m+20)³。ここで m は、内容がちょうど {a,b,c} で a の個数が 1〜k−1 の L の語に現れる、a の個数の種類数。

したがって中心の問いの否定には m が超多項式であることが要り、肯定には m ≤ poly(‖G‖, θ) を示せばよい（ただし命題5.1 により、言語の性質だけからは m を抑えられない。文法の小ささと薄さを使う必要がある）。

## 2. 局所化と、使えそうな構造（Claude のメモ、確かめること）

- **m の局所化**：定理3.1 の証明で m を使うのは補題2.1 だけで、そこで使う語は、T の重い節点の反鎖を長さ θ 以下の生成組に差し替えた語だけである。したがって m の代わりに
  m_T := T の重い節点の反鎖を、それぞれの非終端の長さ θ 以下の生成組に差し替えて得られる、内容 {a,b,c} の語の a の個数の種類数（1〜k−1 の範囲）
  を使っても定理3.1 は成り立つはず。正確に確かめて、局所版として述べ直してほしい。
- **b と c の両方を含む非終端 B の出現**：B の重い出現は互いに比べられず、剛性（同じ符号なら同じ損失）により全て同じ長さ ℓ と同じ損失 d を持つ。最初の j 個を ρ_B に差し替えた語 W_j の a の個数は k − jd。
- **交差の置換**：B の二つの出現 u₁, u₂（ファンアウト1、互いに隣接しない）について、u₁ だけを差し替えた語 W₁ = P ρ R a^ℓ S と、両方を差し替えた語 W₂ = P ρ R ρ S はともに L に入る。ρRρ と ρRa^ℓ はどちらも内容 {a,b,c}（R は a を含む）で、文脈 (P, S) を共有するので、**D(ρRρ) = D(ρRa^ℓ)**。ファンアウト2の B では二穴の組で同様。これと a の再配分、定理S（同じ a 骨格の語の a の個数の差は 0 か k 以上）を組み合わせて、a の個数の差が 1〜k−1 の、同じ a 骨格の二語を作れないか。
- **反例が満たすべき条件**：超多項式個の a の個数を、それぞれ別の a 骨格で、しかも文法の短い差し替えから実現する必要がある。T の高さは v 以下。

## 3. してほしいこと（優先順）

1. **局所版の定理3.1（m_T 版）を確かめて述べる。**
2. **m_T ≤ poly(v, θ) を証明する**（中心の問いのうち、a だけの語についての肯定）。交差の置換、再配分、定理S、倍増節点の構造（補題D、補題4.1）などを使う。一般に無理なら、示せる特別な場合を切り出す（例：b と c の両方を含む非終端が一種類だけの場合、その非終端がファンアウト1の場合、b⁴ と c⁴ が現れる場合）。
3. **否定側**：m_T が超多項式になり、しかも L ∈ C_{2,c}、‖G_n‖ と θ̄_{G_n} が n の多項式、μ_a(L_n) が超多項式となる族を作る。作れたら arity 1 と 2 の代入可能性を省略せずに証明し、G_n が reduced good でファンアウト ≤ 2・ランク ≤ 2 であること、‖G_n‖、θ̄_{G_n}、μ_a(L_n) を全て証明する。小さい n では正確な所属判定器で検査する（違反は証明書）。
4. どれも完了しない場合は、証明できたこと、止まった場所、次に絞るべき一点を書いて終える。
