## 1. 背景

- Σ = {a,b}、内容型付け c（語に現れる文字の集合。型は {a}、{b}、{a,b}）。`thm:two-letter-content` は、**ファンアウト2**・ランク r ≥ 2 の全ての L ∈ C_{2,c} と全ての reduced good な表示 G について、τ(G,c) ≤ C_r|V|²θ̄⁵、特徴標本の長さ O_r(‖G‖³θ̄⁵)（Parikh 飽和でなければ t_typ ≤ 117(r+1)|V|θ̄ と O_r(‖G‖²θ̄)）を示しています。
- **ファンアウト f ≥ 3** については何も述べていません。C_{f,c} は d ≤ f の全ての d で (d,c)-代入可能性を要求するので、d = 2 の条件（付録 H の塊の再配分などが使う条件）は f ≥ 3 でも成り立ちます。一方、文法の非終端は f 個までの成分を持つので、挿入補題・数え上げの定数が変わります。
- f ≥ 3 に広がれば、「二文字の半束型付けは、**全てのファンアウト f ≥ 2** で多項式データを持つ（ファンアウト1は未解決）」と言え、`op:fanout-two` の二文字の段が全ファンアウトで閉じます。

## 2. 調べてほしいこと

**T1（本題）**：付録 H の各補題と命題を、ファンアウト f ≥ 2（固定）に広げてください。補題ごとに表で、(i) そのまま成り立つか、(ii) 修正が要るなら何をどう直すか、(iii) 定数が f にどう依存するか、を示してください。特に次を確かめてください。
- `lem:app-two-basic`：(i) は f によらない。(ii)（恒等の経路）も f によらないか。
- `lem:app-two-runs`、`lem:app-two-alternate`：使うのは arity 1 と 2 の代入可能性だけで、f ≥ 2 なら成り立つはず。確かめてください。
- `lem:app-two-insertion`：成分が f 個になると、印の数（各成分で ≤ 4 個 → ≤ 4f 個）、独立集合の最大次数（各節点のブロックは ≤ f 個 → 次数 ≤ 2f）、|I| ≥ |Q_0|/(2f+1) が変わります。「|Q| ≥ 14」の閾値を f の式で置き直し、結論 (a)(b) がそのまま出るかを確かめてください。
- `prop:app-two-nonsaturated`：型付きラベルの数 ≤ 3^f |V|、反鎖の大きさの上界を f の式にして、t_typ ≤ (定数)·(r+1)|V|θ̄ の定数を f の式で書いてください。
- `lem:app-two-saturated`：
  - 成分の内容の和が Σ の場合：t_a, t_b ≤ f となり、不等式 ⌊(p+n)/(n−t+1)⌋ ≤ p+t、値の個数（≤ θ̄ + 2f + 1）、同じ深さの重い節点の数などが変わる。
  - 全ての成分が {a} の場合の (P1)–(P6)：h = d ≤ f になり、(P2) の「同じ非終端・同じ b の個数の節点は一つのパスに二回まで」の議論（K > p + 2 と h ≤ 2 を使っている）が h ≤ f でどう変わるか。必要なら K の仮定を K > θ̄ + f などに変えて、定数を直してください。
- 定理の証明：N_typ ≤ |S♯|^{f r}‖G‖ = 4^{fr}‖G‖ になること、最終的な特徴標本の長さの式。

**T2（定理の形）**：T1 が通れば、次の形の定理を、定数を明示して LaTeX で書いてください（原稿の `thm:two-letter-content` を置き換えられる形）。
> Σ = {a,b}、c = c_Σ、f ≥ 2、r ≥ 2。全ての L ∈ C_{f,c} と全ての reduced good なファンアウト ≤ f・ランク ≤ r の表示 G について、τ(G,c) ≤ C_{f,r}|V|²θ̄⁵、B^{≤r}_{f,c} と B_{f,c} に共通の特徴標本で長さ ≤ 4^{fr}(3 + rC_{f,r})‖G‖³θ̄⁵ + 1 のもの。非飽和なら t_typ ≤ D_f (r+1)|V|θ̄。

系（二文字の全ての半束型付け、s_{U,2} を含む）も同じ形で。

**T3（止まった場合）**：どこかで f ≥ 3 に本質的な障害があれば、その場所を正確に書き、f ≥ 3 で成り立たない可能性（反例の候補）を示してください。
