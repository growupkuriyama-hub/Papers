## 1. 問いの意味

- `thm:two-letter-content`：Σ = {a,b} の内容型付け c = c_{a,b} は、ファンアウト2・ランク r ≥ 2 で一様な多項式データを持つ。`cor:two-letter-semilattice` により、二文字の全ての半束型付け（s_{U,2} を含む）も同じ。
- ファンアウト1では、二文字の場合は**未解決**です（`op:S1` は s_{U,2} についての問い）。
- もし c_{a,b}（または s_{U,2}）がファンアウト1で超多項式のデータを要するなら、**一つの型付けについて「ファンアウト1では超多項式、ファンアウト2では多項式」**が成り立ち、ファンアウトを上げると学習が真に安くなることが示せます。論文の看板になる結果です。
- `lem:typing-monotone` により、s_{U,2} が超多項式なら c_{a,b} も超多項式です（c の特徴標本は s の特徴標本だから）。逆は言えません。**c_{a,b} のほうが細かい型付けでクラス C_{1,c} が大きいので、反例の族は c_{a,b} について探すほうが易しい**はずです。まずこの推論を自分で確かめてください。

## 2. 問い

> **Σ = {a,b}、内容型付け c（型は {a}、{b}、{a,b}）、ファンアウト1、ランク r ≥ 2 で、全ての L ∈ C_{1,c} と全ての reduced good な表示 G について、特徴データの長さ（作用素 B^{≤r}_{1,c}）は ‖G‖ と θ̄ の多項式で抑えられるか。**

次の優先順で調べてください。

**T1（否定：本題）**
族 (L_n, G_n) で、L_n ∈ C_{1,c}（ファンアウト1、つまり Clark–Eyraud 型の一穴の代入可能性を、内容が同じ因子どうしに限ったもの）、‖G_n‖ と θ̄_{G_n} が n の多項式、ある内容型の最短の語の長さ μ（または `prop:rare-type` の下界）が超多項式のものを作ってください。L_n ∈ C_{1,c} の証明を必ず付けてください。下界がどの作用素について成り立つか（B に限るか、クラス全体に特徴標本を持つ任意の集合駆動作用素か）も明記してください。s_{U,2} についても同じ族が使えるか（L_n ∈ C_{1,s_{U,2}} か）も調べてください。

**T2（障害）**
T1 が通らない場合、その障害を一般的な補題として定式化してください。例えば「有限の標的では純な語（内容 {a} または {b}）は各一つ」「重み一定なら二次」のような既知の制約に加え、二文字のファンアウト1で稀な型の長さを抑える新しい制約。そこから条件付きの多項式上界（例：重みの値が k 種類なら O(k·poly)）が出るかも調べてください。

**T3（肯定）**
障害が強ければ、肯定の証明（または強い部分結果）を狙ってください。付録 H の証明は二穴の文脈（a 塊の再配分）を本質的に使っています。ファンアウト1でその代わりになる道具があるか、無いならどこで本質的に二穴が要るかを、補題ごとに示してください。

## 3. 手がかり（使う前に自分で確かめてください）

1. **既知の制約**：有限の標的で a^p と a^q（p < q）が両方あれば、文脈 (ε, ε) を共有するので a^{p+k(q−p)} が全て入り、有限でなくなる。従って有限の標的では内容 {a} の語は高々一つ（b も同様）。
2. **重み一定の壁**：ψ_λ(w) = |w|_a + λ|w|_b が一定なら μ* ≤ ⌊(θ̄+1)²/4⌋（`prop:binary-u1-weight-slice`(i)、`prop:u1-weight-all-fanout`）。従って超多項式の族は**重みが一定でない**必要があります。{aa, ab, bbb} のように重み一定でない代入可能な有限言語はあります。
3. **二次の族の構造**：L_{m,n}（2ⁿ 個の a^{2^m} と b の並び）は、純な語 a^{2^{m+n}} の長さが「塊の長さ × 塊の数」、θ̄ が「その和」になることで二次を出しています。積の構造を何段も重ねて（例えば塊の長さ自体を同じ仕組みで作る）超多項式にできないか。そのとき、どの交換で崩れるかを調べてください。
4. **内容型付けの利点**：c では {b} と {a,b} が別の型なので、b だけの語と a, b を含む語は比べられません。s_{U,2} より交換の制約が弱く、三文字の倍増族 K_n（E_i → b E E b | c E c）の「印の文字 c」の役割を、二文字でどこまで再現できるかが要点です。例えば「印」を b の長い塊や特定の因子で表す設計。
5. **ファンアウト2との違い**：ファンアウト2で効いた道具（`lem:app-two-runs` の a 塊の再配分、冪の移行 `lem:power-transfer`、切り直し）は二穴の組を使います。ファンアウト1の反例の族は、二穴の交換では崩れてよい（ファンアウト2では崩れるはず）ことに注意してください。実際、L_{m,n} は m ≥ 3, n ≥ 2 でファンアウト2の代入可能性を満たしません。
6. **計算での確認**：小さい n で、有限言語の (1,c)-代入可能性を全数検査してください（有限言語では分布は観察された文脈の集合なので、検査は証明になります）。
