## 1. 正確な量化と型の範囲

`Σ={a,b,c}`、`c(w)=supp(w)`、`L∈C_{2,c}`。`G` は `L∩Σ⁺` の reduced good な MCFG、fan-out≤2、rank≤r、`v=|V|`、`θ=\bar θ_G≥1` とする。原稿の trimmed full yield-type refinement `\widetilde G_0` の非開始ラベルを `X=A_{(t_1,…,t_d)}`（`d=fan(A)∈{1,2}`）とする。good で非空成分なので各 `t_i` は七つの非空集合 `a,b,c,ab,ac,bc,abc` のいずれか。fan-out 1 には7型、fan-out 2 には49型あり、実現するものだけが残る。したがって型付きラベル数は高々 `49v`。

`Cl(X)` は同じ成分ごとの内容ベクトルをもち、同一の arity-d 分布をもつ**全ての非空組**からなる。同一の `L_X` の組は原稿 `lem:typed-homogeneity` により `Cl(X)` に属する。`τ_X=min{||z||_1:z∈Cl(X)}`、`τ(G,c)=max_Xτ_X`、`t_X=min{||z||_1:z∈L_X}` である。開始型 `S_(m)` の arity は1だから `τ_{S_(m)}≤μ_m(L)`、一方原稿の全体不等式は `μ*≤τ(G,c)≤t_typ` である（開始型は `Cl` の代表の中で長さが短くなりうるが、開始文脈 `□` により実際には `τ_{S_(m)}=μ_m(L)`）。

原稿 `cor:distribution-representatives` と `|S^#|=8` により

`||K||_+ ≤ N_typ(1+2θ+rτ(G,c))+1_{ε∈L}`,  `N_typ≤8^(2r)||G||`。

したがって**全 X の τ に対する多項式評価**は、この既存の構成で多項式特徴データを得るための十分条件である。ただし、別構成の特徴データがありうる以上、論理的な必要条件ではない。定理 I の `μ_a` 上界と文字交換による `μ_b,μ_c` 上界は開始型三つだけを制御し、残りの開始型三つと開始型以外の最大49v個を制御しない。今回も場合 II・III に結果を延ばさない。

## 2. (T1) 型付きラベルなら一様化できるが、同名の無型ラベルではできない

**補題 2.1（型付き最小導出の局所最短性）。** 型付き X の最短の組を導く T を、節点数も最小に選ぶ。T の任意の節点 u が型付きラベル Y を持つとき、その節点の組の全長は `t_Y` に等しい。また T の一経路に同じ型付き Y は二度現れない。

**証明。** u を Y の最短導出に置換すると型付き文法の導出のままである。現状が `t_Y` より長ければ根も短くなり矛盾する。次に u≻u' が同じ型付き Y なら、u を u' の導出で置換できる。非削除・非空成分により長さは増えない。短くなれば最短性、同長なら良い規則の経路は末端を書かない rank-one 恒等写像に限られる（原稿 `lem:app-two-basic(ii)` の証明を直接適用）ので節点数最小性に矛盾する。∎

これは型付きラベルに限定した原稿既存の刈込みであり、証明の本質的な新規性はない。**型を忘れた A だけ**を合わせる交換は正当化できない。例えば `A→a|c`、`S→A A` で `ac` の左 A を右の `c` に替えると `cc` となり、根の内容 `{a,c}` から `{c}` へ下がる。文法は good である。この現象は「型を保つ交換ができること」だけから「型を変える交換の例外個数が小さい」ことが出ない理由である。なおこの小文法自体を場合 I の反例とは呼ばない。

## 3. 全成分が最大内容の X は、導出の長さ自体が線形に抑えられる

**定理 3.1（全内容成分のマーク上界）。** 字母数 `m=|Σ|`、fan-out≤f の reduced good grammar G で `θ≥1` とする。型付き X の d 個の成分の内容がすべて Σ なら

` t_X ≤ m d (2^m−1)^f (r+1)vθ `、従って `τ_X` も同じ上界を満たす。

**証明。** `t_X` を実現する節点数最小導出 T を取る。各根成分に各文字の出現を一つずつマークする。マークは全体で高々 md 個。長さ `>θ` の節点を heavy と呼ぶ。ある heavy 節点の部分木にマークが一つもなければ、その無型非終端 B の最短導出 `ω_B`（全長≤θ、原稿 `lem:thickness-equivalence(ii)`）に置換できる。いずれの根成分にも全 m 文字のマークが残るため、置換後も根の各内容は Σ、すなわち X の元の型のままである。型付けの一意な持ち上げ（原稿 `prop:output-invariants`）により新しい組は `L_X` に属し、長さは厳密に減る。矛盾。ゆえに全 heavy 節点が少なくとも一つのマークを含む。

heavy 節点は祖先閉包で、同一深さの節点は非交叉である。各深さの heavy は高々 md 個。補題2.1と最大型数 `(2^m−1)^f v` により経路長はその数以下、従って heavy 節点総数 H は `md(2^m−1)^fv` 以下。根が heavy でなければ長さ≤θ。根が heavy なら、各文字は heavy 節点の規則が書いた文字（規則当たり≤θ）か、heavy 節点の子で non-heavy な部分木（節点当たり高々 r 個、各長さ≤θ）のどちらかに属する。ゆえに `t_X≤(r+1)θH`。両場合とも表示した評価が成立する。∎

**系 3.2（場合 I の混合開始型）。** 三文字、f=2 なら `(2^3−1)^2=49`。よって全成分 `{a,b,c}` の型付き X には

`τ_X≤t_X≤147d(r+1)vθ`。

特に開始型 `S_({a,b,c})` は d=1 であり、実現されていれば

`μ_{abc}(L)=t_{S_(abc)}≤147(r+1)vθ`。

**重要**：この定理は (2,c) 代入可能性、`a⁴,b⁴,c⁴` の出現、定理 I を全く使わない。case I の一部を解くが、既知の「マーク保存」の方法の直接的な一般化である。

## 4. Parikh 飽和という追加仮定の下では「合併が abc」まで拡張できる

**定理 4.1。** 上記に加えて L が Parikh-saturated（Parikh ベクトルが等しい語は所属も等しい）であるとする。型付き X が d≤2 成分で、その内容の合併が Σ なら

`τ_X ≤ (r+1)vθ (θ+3d)(θ+3d+1) ≤ (r+1)vθ(θ+6)(θ+7)`。

**証明。** 原稿の canonical な無型文脈 `E_A` をとる。固定部分の Parikh ベクトルを `p=(p_a,p_b,p_c)` とすると `|p|≤θ`。`E_A` は `L_X` の全組を受理する。内容型が同じ組 z について、`E_A[z]∈L` なら z と `L_X` の組は許容文脈 `E_A` を共有し、代入可能性によって分布が等しい。従って `τ_X` は「E_A に入れて受理される内容型 t の組」の最短全長に等しい（原稿 `lem:app-two-basic(i)` の証明を再構成した）。

`q_x` を文字 x を含む成分の数とする。合併が Σ なので `1≤q_x≤d`。最短の z の総文字数ベクトルを `n=(n_a,n_b,n_c)` とすれば `n_x≥q_x`。Parikh 飽和より、任意の `n'_x≥q_x` について `p+n'` の語が L に入るなら、同じ数を成分へ配分した型 t の組 z' を作れて `E_A[z']∈L` となる。したがって n はこの座標下界を満たす L の Parikh ベクトルのうち総和最小のもの。

`W=E_A[z]` の G 導出 T を節点数最小に取り、`c_x:=n_x−q_x+1≥1` と置く。heavy 節点 u が全ての x について `|u|_x<c_x` なら、無型最短 `ω_B` に替えると受理語 W' は短くなり、その各文字数は `p_x+n_x−|u|_x+|ω_B|_x≥p_x+q_x` である。先の配分によってより短い z' が受理され、矛盾。よって全 heavy 節点は少なくとも一色で `|u|_x≥c_x`。

同じ深さの heavy 節点は互いに非交叉なので、その数は高々 `∑_x⌊(p_x+n_x)/c_x⌋`。`n_x≥q_x≥1` より、直接展開すれば

`⌊(p_x+n_x)/(n_x−q_x+1)⌋≤p_x+q_x`。

従って各深さの heavy 幅は `H_0:=|p|+∑q_x≤θ+3d`。次に一経路の節点 u について `h(u)=(⌊|u|_a/c_a⌋,⌊|u|_b/c_b⌋,⌊|u|_c/c_c⌋)` は下方へ非増加で、値が変わるのは高々 H_0 回。もし同じ h の区間に無型非終端 B が再出現したなら、祖先から子孫への差 `δ_x` は各 x について `<c_x` である。祖先を子孫で置換した受理語は、正の損失があれば上記と同じ配分により n の最短性に反し、損失ゼロなら nondeleting good の恒等経路を刈り込んで節点数最小性に反する。したがって各 h 値につき高々 v 節点、経路長は `v(H_0+1)` 以下。

heavy 節点総数は高々 `vH_0(H_0+1)`。定理3.1と同じ重い節点の規則・軽い子の分解により `|W|≤(r+1)θvH_0(H_0+1)`（根が軽ければ |W|≤θ）。`τ_X=|z|≤|W|` として所望の上界を得る。∎

これは二文字付録 `lem:app-two-saturated` の「成分内容の合併が全文字」の部分を、座標数3で読み替えたもの。**Parikh 飽和を外す議論にはならない。** 特に純粋 a のように欠ける文字があると、無型の短い置換によって c などが増え、z' に元の内容型を配分できない。

## 5. (T3) μ_a は固定された純粋 a 穴の長さを制御しない

**補題 5.1（Parikh 繊維を内容ごとに一つ選ぶ構成）。** 有限な Parikh ベクトル集合 P において異なるベクトルの support が必ず異なるとする。`L_P={w∈Σ⁺:Ψ(w)∈P}` は、全ての arity f≥1 について `(f,c)`-tuple-substitutable である。有限言語なので任意の f に対し f-MCFL でもある。

**証明。** ある許容 E が同じ成分内容の組 x,y をともに受理するとき、`supp(E[x])=supp(E[y])`。P の選び方から両語の Parikh ベクトルは同じであり、固定部分を引くと `∑Ψ(x_i)=∑Ψ(y_i)`。任意の他の許容 F で `Ψ(F[x])=Ψ(F[y])` なので、L_P の所属は一致する。これが分布等式である。∎

**具体例。** `N≥4` に対し

`P_N={(4,0,0),(0,4,0),(0,0,4),(N,1,1)}`、`L_N={w:Ψ(w)∈P_N}`。

各 support は `{a},{b},{c},{a,b,c}` で異なる。従って `L_N∈C_{2,c}`（実際には全 f）。`a⁴,b⁴,c⁴∈L_N` なので場合 I。しかも

`μ_a(L_N)=μ_b(L_N)=μ_c(L_N)=4`、`μ_{abc}(L_N)=N+2`、`min{k≥1:a^kbc∈L_N}=N`。

固定の一穴文脈 `E=□bc` は `a^N` を受理するが、**他の正の純粋 a 語を受理しない**。よって「定理 I で μ_a が小さい→固定文脈に必要な純粋 a の穴も小さい」という *μ_a だけをパラメータとする* 推論は成り立たない。この構成は全ての n に対する言語所属を上の補題で証明しており、有限実験だけに依存しない。

ただし `μ_{abc}=N+2` に定理3.1を適用すれば、どの reduced good 表示 G についても `N+2≤147(r+1)vθ` となる。この L_N は **θ と v を含む多項式上界への反例ではない**。また、E が G の短い canonical 文脈であることも無条件ではない。

**限定的に使える純粋穴の帰着。** X の全成分が `{a}`、その canonical 文脈 E_A の固定部分が a のみ、長さ p≤θ であり、`k:=μ_a(L)≥p+d` なら、`k−p` 個の a を d 個の非空成分に配り `E_A[z]=a^k∈L` とすることで `τ_X≤k−p≤k` が成立する。これは原稿の分布補題の直接の特別な場合である。`k<p+d`、または E_A に b,c が含まれると、この論証は止まる。

## 6. 未解決の残差：型欠損への置換と例外の計数

必要な全 X は7型（arity 1）・49型（arity 2）のうち実現したもの。今回の定理3.1で「各成分が abc」の型、定理4.1で Parikh 飽和という追加仮定の下の「各成分の合併が abc」の型を解いた。開始型 abc は追加仮定なしに解けた。定理 I で開始型 a,b,c の μ は既に有界である。

残る最大の障害は、**根成分に欠けた文字を無型短縮が新しく挿入する**こと。例えば `{a,b}` 成分への c の侵入は、a,b の witness を全て固定しても防げない。逆に「同じ型付き非終端に限定した一様化」は補題2.1で完全に処理できており、主たる不足ではない。純粋成分に対して損失を一変数で測る定理 I の補題 F′・(R) を直接移すには、固定部分 b,c の位置と他成分の長さ・内容を守る必要がある。定理 I の証明が使った純粋開始語の再配分を、任意の canonical 文脈について保証する補題は現時点ではない。

**次に絞る一点**：`X` の一成分の内容が `{a,b}`、もう一成分がある場合も含め、重い無型短縮が c を持ち込む節点を「型欠損の証人」に結び付け、同じ無型ラベルについてそのような侵入節点の反鎖を O(poly(v,θ)) に抑えられるか。できなければ、文脈つき短縮の反例を `θ=O(poly(v))` で作る必要がある。

## 7. Python 3 標準ライブラリによる有限独立検査

次のコードを実行した。全ての語を列挙し、arity 1,2 の**全ての非空穴と、二穴の場合は非空の中央固定部分**を走査する。共通文脈を持つ同内容の組は分布集合そのものを比較した。`PASS` は列挙された**有限言語**についての完全な判定であるが、全 N の定理は補題5.1の数学的証明による。スクリプトは `py -3 check_case1.py` で動く。


```python
#!/usr/bin/env python3
"""Exhaustive finite (1,c)/(2,c) checks; Python 3 standard library only."""
from collections import defaultdict


def occurrences(w, d):
    n = len(w)
    if d == 1:
        for i in range(n):
            for j in range(i + 1, n + 1):
                yield (w[i:j],), (w[:i], w[j:])
    else:
        for i in range(n):
            for j in range(i + 1, n):
                for p in range(j + 1, n):
                    for q in range(p + 1, n + 1):
                        yield (w[i:j], w[p:q]), (w[:i], w[j:p], w[q:])


def check_exact(L):
    for d in (1, 2):
        distributions = defaultdict(set)
        shared = defaultdict(set)
        for w in sorted(L):
            for x, E in occurrences(w, d):
                distributions[x].add(E)
                ty = tuple(''.join(sorted(set(t))) for t in x)
                shared[(ty, E)].add(x)
        for candidates in shared.values():
            if len(candidates) < 2:
                continue
            x = min(candidates)
            for y in candidates:
                if distributions[x] != distributions[y]:
                    return False, (d, x, y)
    return True, None


def make_language(N):
    out = {'a' * 4, 'b' * 4, 'c' * 4}
    for i in range(N + 2):
        for j in range(N + 2):
            if i == j:
                continue
            letters = ['a'] * (N + 2)
            letters[i], letters[j] = 'b', 'c'
            out.add(''.join(letters))
    return out


def main():
    for N in range(4, 10):
        L = make_language(N)
        ok, counterexample = check_exact(L)
        assert ok, counterexample
        mu_abc = min(len(w) for w in L if set(w) == {'a', 'b', 'c'})
        hole = min(k for k in range(1, N + 3) if 'a' * k + 'bc' in L)
        assert mu_abc == N + 2 and hole == N
        assert all(x * 4 in L for x in 'abc')
        print('N=%d |L|=%d exact(1,2)=PASS mu_a=4 mu_abc=%d P_a([]bc)=%d'
              % (N, len(L), mu_abc, hole))


if __name__ == '__main__':
    main()
```

## 8. 文献・最終判断

参照した原稿は、型付き同値類と標本代表について `lem:typed-homogeneity`、`cor:distribution-representatives`、二文字の `lem:app-two-basic`・`lem:app-two-saturated` を既に含む。系列十三・十四報の **定理 I**（`μ_a` に対する `max{4θ+12,K_I^313 R^312 θ}`）は開始型の単一文字問題として参照した。本報はその巨大な定数を τ_X に流用していない。一般の正例学習・MCFG 代入可能性について Yoshinaka (2011, *Theoretical Computer Science* 412:1821–1831) および Clark–Eyraud (2007, *JMLR* 8:1725–1745) が先行する。今回の最大内容マーク補題・三座標 Parikh 論法と同一の定式化が既刊文献にあるかは **未確認**。今回の新しい下界は主張していない。従って、作用素を `B^{≤r}_{2,c}`・`B_{2,c}`・クラス全体に標本を持つ集合駆動作用素のどれに取るかという下界の議論には進まない。

**証明できたこと**：全成分最大内容の τ_X に線形上界、開始内容 abc の μ に線形上界、Parikh 飽和の全合併内容型の τ_X に多項式上界、および `μ_a` と文脈つき純粋穴の間の明示的な非含意。

**止まった場所**：一般の非飽和 L で、欠損文字がある根成分への無型置換が新文字を導入する節点の数・損失を制御できない。

**次の一点**：成分内容 `{a,b}` への c 侵入を起こす重い節点の反鎖上界を導くこと。**場合 I の全 τ 多項式上界も `op:fanout-two` も未解決である。**
