## 1. 背景：‖G‖ 一つ分の差

- 定理A(i)：局所群の型付けで、特徴データの長さは O(‖G‖²θ̄_G)（全ファンアウト）。
- 定理A(ii)(iii)：線形因子 Ω(‖G‖θ̄_G) は必要で、自明な型付けではちょうど Θ(‖G‖θ̄_G)。
- 二つの ‖G‖ の出どころ：証人の語の数 N_typ と、`lem:heavy-node-count` のパスの長さ |V|（t_typ の中）。後者は証人の構成では本物だが（§9 の例）、データそのものについては分かっていない。
- 下界の道具の限界：
  - 区別の補題・希少な型の議論は、固定の型付けでは高々 |S|(t_typ + 1) しか出ない。
  - 有限の標的で二次の下界を出すには、長さ Ω(‖G‖θ̄) の語が要る（README (64) の定理2）。
  - したがって **Ω(‖G‖²θ̄) の下界は、特定の作用素 B の働き方を使って示すしかない**（区別の補題では出ない）。

## 2. 最有力の候補：F_n と窓の型付け s_{1,1}

- 族：E_0 → a、E_i → l E_{i−1} E_{i−1} | c E_{i−1} r（1 ≤ i ≤ n）、開始 E_n、F_n := L(E_n)。ファンアウト1、ランク2。
- 分かっていること（検証済み）：
  - F_n は Clark–Eyraud 代入可能（全ての n）。‖G_n‖ = 12n+3、θ̄ = 4n−1。
  - s_{0,1}（末尾1文字の窓）では cs = Θ(n²) = Θ(‖G‖θ̄)（Astra 第3回、明示的な標本）。
  - **s_{1,1}（先頭1文字と末尾1文字）では n² + 7n + 4 ≤ cs ≤ O(n³)、未決着**（README (26)）。
    - 末尾 r の語は全て O(n²) の標本から生成できる。
    - 末尾 a の背骨（spine）を先頭の文字で細分すると、長さ i² + i と i² + 3i − 4 の断片が要り、段ごとに観測すると Θ(n³) かかる。ただし、他の Comp の分け方や Link を排除していないので、Ω(n³) の下界は出ていない。
  - n = 3 で 56 ≤ cs ≤ 144。最良の標本は、末尾 a の背骨を2本使う（README (28)）。
- **意味**：s_{1,1} は窓の型付けで LG に入る。cs(F_n) = Θ(n³) = Θ(‖G‖²θ̄) が B について示せれば、**定理A(i) の上界が B について鋭い**ことになり、主定理を Θ で書ける（B について、ファンアウト1、この型付けで）。O(n²) の標本が作れれば、この最有力の候補が消え、線形の上界の側に傾く。

## 3. 問い（優先順）

**Q1（本題）：s_{1,1}、作用素 B_{1,s}（とランク2版 B^{≤2}_{1,s}）で、cs(F_n) は Θ(n³) か Θ(n²) か。**
- (a) **下界 Ω(n³)**：B の文法の健全性（`prop:reconstruction-soundness`：B(K) の各非終端は、K の中の観測から決まる型付きの類に収まる）を使い、「末尾 a の語を生成するには、各段 i で長さ Ω(i²) の断片を、互いに共有できない形で観測しなければならない」ことを示す。
  - 鍵になりそうな点：s_{1,1} の Link は先頭と末尾の両方の文字が一致することを要求する。[C_{i−1} l]（型 (c, l)）は、l で始まる u について u l を導出できない（README (26) の Claude の誤りの訂正）。どの Link と Comp の組合せなら背骨を短く橋渡しできるかを、全て列挙して排除する。
  - 下界の主張は B_{1,s} と B^{≤2}_{1,s} に限ってよい（全ての集合駆動作用素についての主張は不要。区別の補題では出ないため）。
- (b) **上界 O(n²)**：背骨を先頭の文字で細分せずに済む、短い Link の橋を見つけ、長さ O(n²) の標本を明示して、特徴標本であることを証明する。
- n = 3, 4 の最短の特徴標本の長さを計算で絞れれば、(a) と (b) のどちらに向かうかの判断材料になる（`check_astra_sample_with_B.py` の実装を使ってよい。n = 4 は重い）。

**Q2（Q1 が決着しない場合、または余力があれば）：一般の上界の改良。**
- 窓の型付け（群が自明）でファンアウト1なら、特徴データは O(‖G‖θ̄ + Λ) と書ける。ここで Λ は「長い型の証明書」の費用で、今は O(‖G‖²θ̄) しか分かっていない（README (30) の (c)）。Λ = O(‖G‖θ̄) を示すか、Λ が本当に大きくなる族を示す。

**Q3（どちらも完了しない場合）**：証明できたこと、止まった場所、B の働き方について分かった制約を書いて終える。
