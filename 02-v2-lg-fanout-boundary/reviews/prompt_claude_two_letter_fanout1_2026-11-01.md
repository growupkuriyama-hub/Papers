## 1. 問いとその意味

> **Σ = {a,b}、内容型付け c（型は {a}、{b}、{a,b}）、ファンアウト1、ランク r ≥ 2。全ての L ∈ C_{1,c} と全ての reduced good な文脈自由文法の表示 G について、特徴データ（作用素 B^{≤r}_{1,c}）の長さは ‖G‖ と θ̄ の多項式で抑えられるか。**

- **否定なら**：`thm:two-letter-content` と合わせて、同じ型付けがファンアウト1では超多項式、ファンアウト2では多項式になり、**ファンアウトを上げると学習が真に安くなる**ことが二文字で示せます（論文の看板）。族が s_{U,2}（a ↦ 1、b ↦ ζ）でも代入可能なら `op:S1` も否定で解決。
- **肯定なら**：分離は二文字では起きないことが分かり、残る道は三文字（c_{a,b,c} のファンアウト2）だけになります。これも論文に入れる価値のある結果です（`op:S1` の内容型付け版の解決）。
- 現状：下界は二次（θ̄²/4、L_{m,n}）。重み一定なら二次で鋭い。一般は未解決。

## 2. 既に分かっていること（証明済み。使う前に自分で確かめてください）

1. **混合の型は短い**：a と b の両方を含む語を作る非終端は、長さ 3(r+1)|V|θ̄ 以下の語を作る（代入可能性を使わない）。従って長くなりうるのは純な型 {a}, {b} だけ。
2. **出現数の種類による上界**：b の個数の正の値が h_b 種類、a の個数が h_a 種類なら t_typ ≤ (r+1)|V|θ̄ max{3, h_a, h_b}（代入可能性を使わない）。長さ N の a だけの最短の語があれば h_b ≥ N/((r+1)|V|θ̄)。
3. **重みの種類**：ψ_λ = |w|_a + λ|w|_b の値が k 種類なら、max{1, λ, 1/λ} を掛けた同様の上界。重み一定（k = 1）なら μ* ≤ ⌊(θ̄+1)²/4⌋。
4. **純な語は一つ**：有限の標的では a だけの語は一つ（b も）。同じ文脈 (P,Q) に入る a だけの塊の長さも一つ（無限の標的なら等差数列が全て入る）。
5. **反鎖**：有限の標的で、同じ型の二つの因子が共通の文脈を持てば、一方が他方の真の因子にはなれない。特に同じ型の受理語どうしは因子の順序について反鎖。
6. **塊の並びの一か所だけの違いは無い**：b の個数が同じ語の a の塊の長さの並びは、正の座標を一か所だけ変えた形で二つ現れない（a と b を入れ替えても同じ）。
7. **層の端**：混合の因子 x, y が共通の文脈を持ち、b の個数の差が δ > 0 なら、全ての文脈で交換でき、x は b の個数が最大の語に、y は最小の語に現れない。
8. **失敗した族**：素朴な倍増、三文字の K_n のあらゆる単項の符号化（A ↦ a^p、B ↦ a^q、C ↦ u）、段ごとの印 b a^i b、塊の数を数える印。いずれも n = 3 までに崩れる。
9. **ファンアウト2の道具は使えない**：a の塊の再配分は一穴では成り立たない（{aa,b}⁴）。

## 3. 調べてほしいこと

推奨は**肯定の向きを先に**試すことです（下界の族の設計は2回失敗し、必要条件が積み上がっているため）。

**P1（肯定：本題）**
長さ N の a だけの最短の語 a^N（型付き非終端 A_{({a})} の最短の生成物、または言語の唯一の a だけの語）について、N を ‖G‖ と θ̄ の多項式で抑えてください。道具の候補：
- (a) a^N の節点数最小の導出で、重い節点を短い生成物 ω に差し替えると必ず b が入る（§2 の 2）。差し替えた語 E_A[…] は全て L に入り、b の個数が互いに違う。これらの語の間で、§2 の 4〜7 の制約（同じ文脈の純な塊の一意性、反鎖、一か所だけの違いの禁止、層の端）が何を強制するかを調べる。特に、**二つの重い節点 h, h′ を別々に差し替えた語と、同時に差し替えた語の三つ**が、どの文脈を共有するかを追うと、二穴を使わずに一穴だけで交換が作れる可能性があります。
- (b) 有限の標的に限ってよければ、まず有限の標的で示す（無限の標的は、等差数列が全て入るという強い性質を使う）。
- (c) 重み ψ_λ の値の種類 k を、λ を文法から自然に選ぶ（例：短い生成物 ω_B の a と b の比）ことで多項式に抑えられないか。
- (d) 部分的な結果でよい：例えば「L が有限で、各非終端の生成物の b の個数が有界なら多項式」「ランク r の文法で、純な非終端の部分文法が線形なら多項式」など、証明できる最も強い条件付きの定理。

**P2（否定：P1 で本質的に止まった場合）**
止まった場所を、反例の族が満たすべき追加の条件として書き出し、§2 の 1〜9 を全て満たす族を試してください。L_n ∈ C_{1,c} の証明を必ず付けてください。積の構造（L_{m,n}：a^N の長さ = 塊の長さ × 塊の数、θ̄ ≈ その和）を何段も重ねる設計が、どの制約で崩れるかを一般の形で示すことも価値があります。

**P3（s_{U,2} との関係）**
肯定の結果が s_{U,2} にも移るか（`lem:typing-monotone` の向きに注意：c で多項式なら s_{U,2} でも多項式）。否定の族が見つかった場合は、L_n ∈ C_{1,s_{U,2}} かどうか。
