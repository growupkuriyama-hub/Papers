## 1. 問い

型付けを s_U : {a, b, c}⁺ → U₁ = {1, ζ}、a, b ↦ 1、c ↦ ζ とします。ランク r ≥ 2 を固定します。

> **定理（目標）**：ある多項式 p があって、全ての L ∈ C_{2,s_U}、全ての reduced good でファンアウト ≤ 2・ランク ≤ r の L∩Σ⁺ の表示 G について、L の型1の語がただ一つ W なら、|W| ≤ p(‖G‖, θ̄_G)。

**意味**：
- これは「(2, s_U) は短い唯一語を持つ」（`prop:unique-word-route` の用語）です。
- 証明できれば、ファンアウト2では、この論文の下界の方法（唯一語を全ての特徴標本に強制する）は多項式止まりになります。`op:fanout-two` を否定するには、別の方法（同じ型の多数の語など）が要ることが確定します。
- ファンアウト1では、同じ型付けで唯一語が指数に長くなります（`prop:three-letter-family`）。したがって目標の定理は、ファンアウト1と2の違いを方法の水準で示すことになります。

**既に分かっていること**：
- W は5形のどれか（|W| ≥ 7、`prop:unique-two-letter-shapes`）：aᴺ、aᴺ⁻¹b、baᴺ⁻¹、baᴺ⁻²b、交互の語。a ↔ b の入れ替えを含みます。
- 隙間の補題：型 ζ の語の長さが M 以下なら |W| ≤ θ̄ + (r+1)M。したがって反例があるなら、型 ζ の語も超多項式に長いはずです。
- 冪の移行：a⁴ が L に現れれば、L の全ての語で a の連続の間の a の再配分が自由になります（付録H の `lem:app-two-runs`(i) と同じ）。b の冪、(ab) の冪でも同様です。
- 二文字 {a, c} だけなら、`thm:two-letter-content` で多項式です。
- 有限の標的では、同じ型の語が真の部分語の関係を持ちません（`lem:no-insertion`）。

## 2. 調べてほしいこと（優先順）

**U1（W = aᴺ の場合：本題の第一段）**
- W = aᴺ のときに |W| ≤ poly(‖G‖, θ̄) を証明してください。
- 方針の候補（使う前に確かめてください）：
  - (a) **付録H の (P1)–(P6) の三文字版**。W = aᴺ の導出木で、純な（a だけの）yield を持つ重い節点を数える。行の剛性 (P1) に当たるものとして、「aᴺ と同じ文脈で、長さの違う a の冪は受理されない」（一穴の代入可能性と唯一性）を使う。
  - (b) **隙間の補題の強化**。M を「型 ζ の語の最大長」ではなく、「W の導出に使う規則の、型 ζ の短い文」の長さで置き換えられないか。θ̄ の定義により、各規則には長さ θ̄ 以下の文があります。W の導出に使う規則が型1の文しか持たなければ、その文は W 自身で、厚さが |W| になるからです。
  - (c) **二穴の輸送**。W の導出の重い節点 v（純な yield aᵗ）について、v の規則を使う短い型 ζ の文（長さ ≤ θ̄）の中で、v の yield を含む二穴の組と、W の中の組を比べる。冪の移行や分布の貼り合わせ（`chatgpt_power_rare_words` の §2–3）で、aᵗ の長さを短くできることを示す。
- ファンアウト2の二穴の条件がどこで本質的に効くかを明示してください。ファンアウト1では aᴺ が指数に長くなる例は今のところ知られていません。`prop:binary-u1-quadratic` は θ̄ の二次まで、三文字の倍増族は W が5形でない例です。したがって、ファンアウト1との違いがどの補題に現れるかを書いてください。

**U2（他の4形への拡張）**
- aᴺ⁻¹b、baᴺ⁻²b、交互の語 (ab)^k についても同じ上界を示してください。
- 交互の語では、冪の移行を (ab) に使えます。

**U3（部分結果）**：U1 が一般には無理なら、証明できる最も強い部分結果を。例えば次のような場合です。
- 標的が有限の場合。
- ランク r = 2 の場合。
- 型 ζ の語の c の個数が有界な場合。
- 証明が止まった場合は、止まった場所と、反例の族が満たすべき仕様（隙間の補題、5形、冪の移行、`lem:no-insertion` を全て満たす形）を正確に書いてください。

**U4（一般化）**：U1・U2 が成功した場合、次の一般化がどこまで言えるかも調べてください。
- 任意の U₁ への型付けで、型1の文字が二つ以上の場合。
- ファンアウト f ≥ 3 の場合。
