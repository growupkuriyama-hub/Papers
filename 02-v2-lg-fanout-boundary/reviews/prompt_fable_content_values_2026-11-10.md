## 1. 定義（正本 `main.tex` に従う）

- **語と内容**
  - Σ は有限の字母で、k = |Σ| とする。Ψ(w) ∈ ℕ^k はパリク像、cont(w) は w に現れる文字の集合。
  - **内容型付け** c_Σ は、空でない語に cont(w) を返す。組 x = (x₁,…,x_d) の型は (cont(x₁),…,cont(x_d))。
- **許容的な文脈**
  - 𝓔_d は E = v₀□₁v₁⋯□_d v_d の形の文脈で、v₀, v_d ∈ Σ*、内側の v₁,…,v_{d−1} ∈ Σ⁺（空でない）。
  - D_L(x) = {E ∈ 𝓔_d : E[x] ∈ L}。
- **代入可能性**
  - L が **(f, c_Σ)-代入可能**とは、全ての 1 ≤ d ≤ f と x, y ∈ (Σ⁺)^d について、型が等しく D_L(x) ∩ D_L(y) ≠ ∅ なら D_L(x) = D_L(y) となること。
  - 空の成分は比べない。
  - C_{f,c_Σ} は (f, c_Σ)-代入可能な f-MCFL のクラス。以下では f = 2 を主に考え、SUB₁・SUB₂ と書く。
- **文法**
  - **good** な MCFG は、ε-free、nondeleting、nonpermuting、nonmerging（同じ子の隣り合う変数が一つの成分の中で連続しない）。**既約** は全ての非終端が到達可能かつ生産的であること。
  - good な規則から誘導される子の文脈は、再び許容的になる（`lem:filling-identity`）。そのため分布同値は good なテンプレートへの代入で保たれる（`lem:witnessed-composition`）。
  - 厚さ θ̄_G は、各規則について「その規則を使う最短の文の長さ」を取った最大。以下 θ = max(1, θ̄_G)、r はランク、v = |N|。
- **型付き非終端と代表の長さ**
  - **型付き非終端** X = A_(M₁,…,M_d) は、非終端 A と、その生成組の成分の内容の組の対。L_X が空でないものだけを考える。
  - L ∈ C_{f,c_Σ} なら L_X は一つの同値類 Cl_{L,c}(X) に入る。
  - **代表の長さ**：τ_X = min{‖x‖₁ : x ∈ Cl_{L,c}(X)}、τ(G, c_Σ) = max_X τ_X。代表は X の生成組である必要はなく、分布同値な組なら何でもよい。
  - `cor:distribution-representatives`：特徴データは N_typ(1 + 2θ̄_G + r_max·τ(G, c_Σ)) 以下。
- **問いの位置**
  - `op:fanout-two` の YES は「ファンアウト f ≥ 2 でも LG が境界のまま」（下界の方向）。
  - `prop:sl-reduction` により、多項式データの方向を示すには、**全ての固定した Σ** で c_Σ が一様な多項式データを持つことが要る。
  - 二文字は解決済み（多項式）。三文字以上は未解決。

## 2. 既知の結果（使ってよい）

### 2.1 Astra の報告 `reviews/astra_fanout2_map_2026-11-10.md`

- **補題 S1**：Σ = Γ₁ ⊔ ⋯ ⊔ Γ_t（順序付きの文字群）、R = Γ₁⁺⋯Γ_t⁺、Φ : ℤ^k → A（可換群、無限でもよい）とする。L = {w ∈ R : Φ(Ψ(w)) = g} は全ての arity で内容型付きの代入可能。

- **補題 S2（短い規則差分）**：L = L(G) とし、各非終端 A に長さ ≤ θ の許容的な文脈 E_A と、長さ ≤ θ の生成組 u_A を固定する。p_A = Ψ(u_A) とし、規則 R : A → ρ(B₁,…,B_s) に d_R = Ψ(t_R) + Σ_j p_{B_j} − p_A と置く（t_R は規則の終端記号）。
  - (a) ‖d_R‖₁ ≤ (r+2)θ。
  - (b) H := ⟨d_R⟩ ⊆ ker Φ。E_A[u] ∈ L なら Φ(u) は u によらないので、Φ(p_A) = Φ(t_R) + Σ Φ(p_{B_j})。
  - (c) 全ての w ∈ L で Ψ(w) − p_S ∈ H。導出木の上で d_R を足し合わせると、内部の p が打ち消し合う。
- **補題 O（直交象限の中での短縮）**

  - 証明：大きい座標の集合 I 上で動ける格子ベクトルで一つずつ座標を下げ、最後は Cramer の公式で評価する。

- **定理 F**：有限群なら τ ≤ k(f + ((r+2)θ)^k − 1)。
- **定理 G1**：有限群 Γ に全射する φ で L = φ⁻¹(P) ∩ Σ⁺ とする。内容型付きの SUB₁ と SUB₂ を満たす ⟺ P = pN（N ⊴ Γ、Γ/N 可換）、すなわち L は有限可換群の一つの値の原像。

## 3. 対象：クラス 𝒦

Σ = Γ₁ ⊔ ⋯ ⊔ Γ_t を順序付きの空でない文字群とし、w が**段非減少**であるとは、文字の段番号が非減少であることとします。全ての段を含む必要はありません。

A を可換群（無限でもよい）、Φ : ℤ^k → A とします。内容の族 𝓜 の各 M に部分群 H_M ≤ A と g_M ∈ A を与え、

  L = { w ∈ Σ⁺ : w は段非減少、cont(w) ∈ 𝓜、Φ(Ψ(w)) ∈ g_{cont(w)} + H_{cont(w)} }

とします。

- t = 1 は一頂点で、受理するパリクの集合は「内容ごとの剰余類の和」になる。
- H_M が全て同じなら、定理 H の (16) の一頂点版。

## 4. 課題

### 課題1：𝒦 の所属の特徴づけ

L ∈ C_{2,c_Σ} となる (𝓜, (g_M, H_M)) の条件を、必要十分の形で求めてください。
- 閉包報告の定理2.5（有限群の場合）が手がかりになります。
- 無限群で何が変わるか（T_n の現象）、段（t ≥ 2）が内容の違う語どうしの移動をどう制限するかも述べてください。
- 所属は全ての arity について**手で**証明してください。有界な長さの検査で代用しないこと。

### 課題2（主）：全ての型の τ

𝒦 ∩ C_{2,c_Σ} の言語と、その任意の既約 good な表示 G（ファンアウト ≤ f、ランク ≤ r）について、

  τ(G, c_Σ) ≤ poly_{k,f,r}(θ)

を示してください（v によらない形が望ましく、poly(‖G‖, θ) でもよい）。示せなければ、どこで失敗するかを示してください。

定理 S が「一つの値」を使うのは次の二か所です。
1. 補題 S2(b)：A の全ての生成組は、E_A の中で同じ値を持つ。
2. 戻し：同じ剰余類の短い点は受理される。

内容ごとに値が変わると、A の生成組の内容が違えば値も違いえます。次の方向を検討してください。
- 型付き非終端 X ごとに、内容を保つ短い規則差分だけから格子 H_X を作る。
- 同じ内容の面の中の差分が θ で有界な生成系を持つか。SUB₁・SUB₂ を使ってよい。
- 内容の面の間の整合条件（課題1 の答え）で、戻しを保証する。

**罠**：
- 型付きの積の文法の厚さに頼らないこと。型付き非終端の最短の**生成**は指数的に長くなりうる（`main.tex` の該当命題：‖G_n‖ = O(n)、θ ≤ 2、t_typ ≥ 2ⁿ）。必要なのは分布の代表です。
- 型付き非終端の短い文脈が、元の文法の短い文脈から作れるかを明記してください。

### 課題3（副）：一頂点の命題7.4 への応用

t = 1 で Q が (T) を満たす任意の集合のとき、補題 S2(c) の格子と (T) を組み合わせて、μ_ab（または τ）を抑えられるかを調べてください。

- 例：F₄ ∪ {P}、E₁ ∪ {(6,5)}、F_n。
- 狙いの形：Q₂ の点は p_S + H に入る。(T) の移動で、p_S + H の中の短い ab の点が Q₂ に入ることを導けるか。
- 部分結果でも、「この方法では届かない」ことを示す具体例でも構いません。

### 課題4：失敗した場合の否定の向き

𝒦 の中で、次を全て満たす族を構成してください。
- C_{2,c_Σ} に入る（手の証明）。
- 文法の大きさと厚さは poly(n)。
- τ（または特徴データ）は超多項式。
