## 1. 到達点（検証済み、ただし (KL) の完成は Claude だけが確かめた）

Σ = {a, b, c}、内容型付け c、L ∈ C_{2,c}、a^k ∈ L（k = μ_a(L) ≥ 5）、場合 II。a を含まない語 F（b と c を含む）が損失 d の SB を持つとは、s, t ≥ 1、s+t = k−d の全てで a^s F a^t ∈ L であること。

**鍵の補題 (KL)。** k ≥ 6d とし、SB(F, d)、SB(F², 2d)、SB(F³, 3d) と、全ての正の配分の離れた二塊 a^p F a^q F a^r が L に入るとする。F が bb か cc を含むなら、b⁴ か c⁴ が L の語に強制される。

その証明（場合分け）は次のとおり。x を二重になっている文字、y を他方の文字とする。
1. F = x x U（U は y を含む）：十八本目 定理3.1(2)。基礎は bbc。
2. F = U x x：定理3.1(1)。基礎は bcc。
3. F の先頭と末尾が同じ文字：定理3.1(3)。基礎は bcb。
4. それ以外。両端の文字が違うので、どちらかの端は x である。
   - F が x で始まり y で終わるとき：先頭が xx でないので F[1] = y である。xx の出現は位置 2 以降にあり、末尾は y なので、F = x P x x Q（P, Q は空でない）と書ける。
   - F が y で始まり x で終わるとき：同様に F = P x x Q x（P, Q は空でない）と書ける。
   - **Claude の補完**：抽象的な四文字 {a, p, x, q} 上の塊 xpxxq と pxxqx について、k = 6、損失 1 の種から、4段で x⁴ が強制される証明書を得た（十六本目の閉包のコードで発見）。準同型 h(a) = a^d、h(x) = x、h(p) = P、h(q) = Q で持ち上げる。補題2.2 が使うのは「内容が等しい組の像は内容が等しい」ことだけなので、元の文字が四種類でもよい。これで任意の F = xPxxQ、PxxQx が覆われる。
   - Claude は二つの証明書を自作の検査器で種から再生した。さらに6種類の具体的な塊と4種類の (k, d) に持ち上げて検査した。
   - 対照：p, q, x が全て違う抽象的な塊 pxxq では、閉包は 42 語で閉じて x⁴ は出ない。両端の一方が x であることが本質的に効いている。

**(KL) からの帰結（分岐 (B)）。** 分岐 (B) では、低い内部の両文字型ラベルの塊の任意の鎖が SB を持ち、分離もできる。十八本目 §4 の予算（d ≤ k/(50θ³)）で (KL) の仮定を満たす。したがって次が成り立つ。
- 全ての低い内部の塊は、bb も cc も含まず、両端が違う。すなわち (bc)^j か (cb)^j である。
- 根が混ざると、鎖 (bc)^i(cb)^j の両端が同じ文字になる。系3.3 で消える。
- よって全ての塊は一つの根 u の冪 u^{j_X} である。
