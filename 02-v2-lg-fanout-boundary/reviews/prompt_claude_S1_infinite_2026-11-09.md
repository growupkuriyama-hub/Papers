## 1. 設定（自己完結）

- Σ = {a, b}。型付け s_{U,2}：純な a の語は型 1、b を含む語（b 語）は型 ζ。
- **C₁**：同じ型の空でない x, y が L の中で一つの文脈を共有すれば D_L(x) = D_L(y)。≡ は分布の同値（合同関係）。
- G は L∩Σ⁺ の reduced・ε なし・ランク ≤ r の CFG。‖G‖、厚さ θ（各規則について、その規則を使う成功導出の最短の語の長さ、の最大）。二分化した G′ の非終端数 K ≤ ‖G‖ + 2。
- a^N は L の最短の純な語。T は G′ での a^N の最短・節点数最小の導出。生成語の長さ > θ の節点が**重い**。
- **問い（`op:S1`）**：N ≤ poly(‖G‖, θ, r) か。
- 道具：
  - **C.0**：一つの非終端の同じ型の生成語は ≡。
  - **補題2.1（消去）**：同じ型の x, y について、zx の分布が空でなく zx ≡ zy なら x ≡ y（右も）。
  - **補題0**（有限のときだけ）：分布が空でない ≡ 類は因子の反鎖。
  - 注意：L の b 語は全て文脈 (ε, ε) を共有するので、**無限でも L の b 語は全て ≡**。

## 2. 既にあること（定理P、未検証）

- **補題R**（有限性不要）：b 語 ω、x, g, y ≥ 0、n ≥ 1、d = g + n。a^xωa^gωa^y、a^xωa^{d+y}、a^{x+d}ωa^y ∈ L なら ωa^gω ≡ ωa^d、a^dω ≡ ωa^d。従って z₀ := ωa^g、c := d で a^c z₀ ≡ z₀ a^c ≡ z₀z₀。
- **定理C\***（有限）：(C1′) a^g z₀ ≡ z₀a^g、z₀z₀ ≡ a^c z₀（g | c）。z ≡ a^e z₀（g | e）を「崩壊する」、価値 e + c。l a^{V\*−c} z₀ r ∈ L なら、崩壊する語と g の倍数の純な塊の積 u について l u r ∈ L ⇔ val(u) = V\*（**補題2.3′**、補題0 を使う）。M 個の符号の部分和が相異なり、固定の積 Q で Σ + val(Q) = V\* なら ‖G‖+2 ≥ 3^{M/3−1}/((M+1)(m+1)²(Mλ+1)²)。
- **定理P**（有限）：N ≤ C(‖G‖+2)^{76}θ^{21}。
  - (P1) 重い道 X₀ = 根, X_{i+1} = 長い方の子。種（重い子を持たない重い節点）の鳩の巣で、同じラベル Y の種二つを差 d ≤ 2K²θ で取り、補題R で z₀ = ω_Ya^{g₀}、c = g = d。
  - (P2) 符号 ẑ_i = a^{s′_i}ω_{X_i}a^{s_i}（s, s′ < d）≡ a^{e_i}z₀、価値 v_i = n_{X_i} + s_i + s′_i、v_i ≤ 2v_{i+1} + 2d。
  - (P3) 目標 V\* = N − ρ − ρ′。
  - (P4) 超増加に M ≥ 1 + log₆(N/(15B₁)) 個。
  - (P5) 貪欲な埋め草 Q。
  - (P6) 定理C\*。
- **有限性を使う箇所は補題0 だけ**と原文は主張している。

## 3. 依頼

**課題1（検査、最優先）.** 定理P とその部品（補題R、定理C\*、補題P1 (a)–(e)、(P1)–(P6)、θ(G′) ≤ θ(G)、K ≤ ‖G‖+2、最後の指数の評価）を、反例を探すつもりで検査する。特に以下を確かめる。
- 補題R を T に当てる際、W₁, W₂, W₃ が本当に L に入るか（二つの種が互いに素であること、g₀ ≥ 0）。
- (P2) の C.0 の使い方（ω_{X_i} と、u₁ を ω_Y に替えた X_i の生成語が同じ非終端の b 語であること）。
- 定理C\* の記録の論証で、区間の端が Q や l, r の中にある場合。
- 符号 ẑ_i が L の因子でなくてもよいか（≡ の合同性だけで済むか）。
- (P4) の止め方と「最後の値 > V\*/12」。
- (P5) の q₀ ≤ 1 と q_i ≤ 2 + 4K²。
- **小さな有限の C₁ 言語で、定理P の構成（T、種、d、z₀、符号、Q）を実際に計算して等式を検査するスクリプト**があれば望ましい（補助として）。

**課題2（本命：無限の標的）.** 無限の L ∈ C₁ で定理P の論証のどこが残り、どこが崩れるかを確定し、残りを閉じる。こちらの見通し（**未検証**）は次のとおり。
- 補題P1 (a) は最短性から（道でラベルが反復すれば縮めて短い純な語）。(b) も最短性から（重い X の長さ ≤ θ の生成語が純な a^p なら、T で置き換えて短い純な語）。補題R・C.0・補題2.1 は無限でも成り立つ。従って (P1)(P2)(P3) は無限でもそのまま。
- 崩れるのは補題2.3′ だけ。S := {f ≡ e\* (mod d) : a^f z₀ ≡ a^{e\*}z₀} とおくと、S = {e\*} なら補題2.3′ は (l, r) について成り立ち、定理P の計数がそのまま通るはず。S が二点以上なら a^f z₀ ≡ a^{f+p}z₀（d | p）で、類は f ≥ f₀ で周期 p。
- 二択の候補：
  - (i) **周期が大きい（p ≥ N^{Ω(1)}）**：価値を mod p で読む定理C\* の変形（部分和が mod p で相異なる符号を Θ(log p) 個）。
  - (ii) **周期が小さい**：周期性を純な語の側へ移して、より短い純な語を作る。**困難**：b 語と純な語は型が違い、直接は比べられない。手がかりは T の節点の文脈を純な生成語と b 語が共有すること（C.0）、および補題R の三語の a の塊を伸縮させること。
- 見通し自体の誤りの指摘も歓迎。

**課題3（否定の向き）.** 課題2 の (ii) が閉じない場合、周期的な b 語の構造を持ち、最短の純な語が指数的に長い無限の L ∈ C₁ と、小さく薄い CFG を探す。
- 既知の制約：
  - 有限群の原像は定理G で多項式。
  - 加法的な重みの一つの水準は定理A で二次。
  - 消去的モノイドの像では Ĝ の可換化が有限でなければならない（STATUS (8)(9)）。
  - L ∈ C₁ なので、純な語どうしが b 語の中で文脈を共有すると分布の一致が強制される。
- 候補を挙げたら、長さを打ち切った s_{U,2} の強制閉包で C₁ との両立を検査すること（同じ型で文脈を共有する因子を同じ類にまとめ、類の全ての文脈に全ての因子を入れる操作の繰り返し）。

**課題4（任意）.** 定理P の指数の改良（例えば (P5) の Q を短くする、(P1) の d の評価を良くする）。
