## 1. 到達点（検証による整理）

Σ = {a, b, c}、内容型付け c、L ∈ C_{2,c} とする。G は L∩Σ⁺ の reduced good な表示で、ファンアウト ≤ 2、ランク ≤ r。v = |V|、θ = θ̄_G とおく。k := μ_a(L) ≥ 5 とし、T を a^k の節点数最小で一様な導出とする。X ⊆ {b, c} は、x⁴ が L の語に現れる文字の集合である。語 u の核は κ(u) := σ_X(a u a) とする。

- **(R)（証明済み）**：σ_X が等しく、b と c の個数が等しく、a の個数が (0, k) にある二語は、a の個数も等しい。
- **補題A（証明済み）**：同じ核 κ を持つ頻出の両文字型ラベル（出現 N₀ = 504θ²+4 以上）の損失は、d_X = ⟨φ_κ, (e_X, β_X, γ_X)⟩ と線形になる。
- **定理B（証明済み）**：μ_a ≤ K^{3D+1}R^{3D}θ。ここで K = (2v+E)(2r+1)、R = θ+2v+2、E = v(504θ²+θ+22)。D は区分の次元の和で、場合 I では D = 2 + 3m_u + m_n（m_u は核の類の数、m_n は非一様な頻出ラベルの数）。
  - **核の種類が有界なら多項式**（系4.1）。F 分岐の段数・入れ子の深さ・ラベルの数には依らない。
- **反例に要るもの（系6.1）。** 群の値が比 R 以上で上がる鎖（疎な鎖）は、一つの区分の中では 3·dim 段未満しか作れない。したがって超多項式の反例には、**Ω(n/log n) 個の相異なる核**（ファンアウト2では非一様なラベルも数える）が要る。それらは、長さが幾何級数的に増える尺度に一つずつ並ぶ。
- **自明に成り立つが足りないもの**：D ≤ 2 + 3v。全ての核が相異なると、ラベルの数が指数に入る上界に戻る。

## 2. 観察（確かめること）

以下は、この系列の検証を担当している別のスレッドの Claude の観察で、まだ証明されていません。同じモデルの観察なので、同じ見落としを共有している恐れがあります。**鵜呑みにせず、反例を探すつもりで確かめてください。**

**(O) 順序をそろえた配置による、核をまたぐ関係。** ファンアウト1で考える。核 κ ≠ κ' の類の頻出ラベルについて、次の二つの語を作る。

- W₁：核 κ のラベル X₁ の出現 x₁ を左に、核 κ' のラベル Y₁ の出現 y₁ を右に置いた語。二つの出現は隣り合わず、互いに素とする。
- W₂：同じく、核 κ のラベル X₂ の出現 x₂ を左に、核 κ' のラベル Y₂ の出現 y₂ を右に置いた語。

補題1.2 により、σ_X(W₁) = κ∘κ' = σ_X(W₂) である。β_{X₁}+β_{Y₁} = β_{X₂}+β_{Y₂} かつ γ も同様なら、(R) により d_{X₁}+d_{Y₁} = d_{X₂}+d_{Y₂} となる。補題A を代入すると、(β, γ) の差 Δ = w_{X₁} − w_{X₂} = −(w_{Y₁} − w_{Y₂}) について ⟨φ_κ − φ_{κ'}, Δ⟩ = 0 が出る（e の座標は両方とも 1）。

- ここで Δ は、**両方の類の差の集合に共通に現れる**ものに限られる。
- 一般には、複数の塊の配置と整数の関係を組み合わせて使う。
- 期待：φ_κ の (β, γ) 部分が類によらず共通（μ, ν）になり、核ごとに定数項 λ_κ だけが残る。そうなれば、区分の次元は「類ごとに 1」まで下がる。ただしこれだけでは、核の数が指数に入ることは変わらない。

確かめる点は次のとおり。
- 左右の順序を実現できるか。頻出の出現は多いので、片方の向きなら取れると思われる。
- ファンアウト2での成分の入り組み方。
- 差の集合が共通に交わらない場合に何が残るか。

**(M) 合流による核どうしの関係。** 核 κ の塊を二つ隣り合わせて置くと、合流した塊の核は κ∘κ とは別の核になる（例：bc と bc を隣り合わせると σ(a bcbc a) = abcbca。一方 κ∘κ = abcabca）。その合流した核が、別の類 κ'' の核に一致する場合には、二つの類の定数項 λ の間に関係が生じるか。前回の §9 の 3 の提案を、具体的な関係式の形で確かめること。

**(N) 入れ子の類の尺度。** 疎な鎖では、上の尺度の類 κ_{i+1} の節点 u の下に、下の尺度の類 κ_i の節点が多数ある。u を ρ_u に差し替えた組と、u の下の κ_i の節点を差し替えた組は、同じ文脈で受理される（段の交換 (L)）。成分ごとの内容が一致すれば、二つの組の分布は等しい。この分布の等式を、**u とは別の出現の文脈**や、**配置語の中**に運ぶと、核の異なる塊を同じ骨格にそろえられるか。そろえられれば、κ_{i+1} の尺度を κ_i の尺度で抑えられる。

## 3. してほしいこと（優先順）

1. **(O) を厳密に確かめて述べる。** 正しければ、定理B の D を「2 + 2 + m_u + m_n」程度に改良した形で述べる。誤り・ずれがあれば反例か正しい形を示す。
2. **肯定側：核の数への依存を消す。** 目標は、疎な鎖の長さを、核の種類によらない poly(v, θ) の対数で抑えること。そうすれば μ_a ≤ poly(v, θ) となる。手がかりは (O)・(M)・(N)、補題1.2、(R)、段の交換 (L)。次の場合を目標にしてよい。
   - ファンアウト1・ランク2
   - 場合 I（b⁴, c⁴ が現れる）
   - 鎖の隣り合う二段（κ_i ⊂ κ_{i+1}）だけ。二段の尺度の比を poly(v, θ) で抑えられれば、それだけで新しい結果になる。
3. **否定側。** 次を全て満たす G_n を作る。
   - Ω(n/log n) 個の相異なる核の類が、幾何級数的な尺度に並ぶ
   - L_n ∈ C_{2,c}
   - ‖G_n‖ と θ̄_{G_n} が n の多項式
   - μ_a(L_n) が超多項式

   新しい候補では、次をどう避けるかを先に説明すること。
   - □ と □a による a の個数の漏れ
   - 偶数の塊の障害（定理3.2）
   - (R)・補題A・(O)

   作れたら、次を全て証明する。
   - arity 1 と 2 の代入可能性（省略しない）
   - reduced good であること
   - ファンアウト ≤ 2、ランク ≤ 2
   - ‖G_n‖、θ̄_{G_n}、μ_a(L_n)

   小さい n では正確な所属判定器で検査する。そこで見つかった違反は証明書になる。

## 5. 守ってほしいこと

- 冒頭に、主張ごとの判定（証明済み／反証／観察／未解決）と根拠の節を書いた表を置く。
- 「自明に成り立つが目的には足りない」主張は、その旨を表に書く（前回の D ≤ 2+3v の書き方がよい例）。
- 言い換えると中身が弱くなる主張（例：新しい量の上界が、実は既知の量で抑えているだけ）は、そう分かる形で書く。
- まだ所属を示していない言語に、その所属を前提にした補題を使わない。
- 下界には次の条件を明記する。
  - 作用素：B^{≤r}_{2,c}、B_{2,c}、クラス全体に特徴標本を持つ集合駆動作用素
  - ファンアウト、ランク、アルファベット
- 証明した範囲を超えて書かない。
- 「最大の特徴標本」と書かない。
- 「境界がファンアウトで動く」は、三文字の全ての内容型を証明した場合にだけ書く。
- 新しい結果が文献で既知かどうか、分かる範囲で書く。分からなければ「未確認」と書く。
