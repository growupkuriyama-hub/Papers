## 1. 到達点（Claude の検証による整理）

Σ = {a, b, c}、内容型付け c、L ∈ C_{2,c} とする。G は L∩Σ⁺ の reduced good な表示で、ファンアウト ≤ 2、ランク ≤ r。v = |V|、θ = θ̄_G とおく。k := μ_a(L) ≥ 5 とし、T を a^k の節点数最小の導出とする。

- **(U) は証明済み**（前回の定理2.3）。T は一様に取り直せる。つまり、同名ラベルの部分木は全て同一で、T はラベル数 v 以下の非巡回 DAG を展開したものである。節点数最小のままなので、これまでの補題は全てこの T に使える。
- **成分ごとの長さは同名でも違ってよい**（前回 §3 の例）。差し替えに必要なのは総長だけである。
- 両文字型ラベル：長さ θ 以下の生成組が全て b と c の両方を含むラベル。一色型ラベル：{a, x}⁺ の中に x を含む長さ θ 以下の生成組を持つラベル（x ∈ {b, c}）。重いラベルはどちらかに当たる（重いラベルの長さ θ 以下の生成組は純粋な a ではない）。
- 前回 §7：全内容語について、Parikh 飽和かどうかの素朴な二分法は成り立たない（L_k = {a^k, abc, acab}）。ただし θ = k なので、Q とは関係しない。

## 2. Claude の観察（確かめること）

**(K) 両文字型の入れ子の深さへの帰着。**

h を、一様な T の根から葉への一本の道に並ぶ、重い両文字型節点の最大個数とする。このとき、ある多項式 P = poly_r(v, θ) について次が成り立つ（と Claude は読んでいる）。

> N_bc ≤ P + P² + … + P^h。したがって定理3.2 により k ≤ poly_r(v, θ)^{O(h)}。

特に、両文字型ラベルが一つだけの場合（h ≤ 1、根 S を除く）や、両文字型ラベルの数が定数の場合は、μ_a ≤ poly_r(v, θ) となる。

証明の筋は次のとおり。各段を確かめ、正しければ定数を付けて述べてください。

1. **数え方の骨組み。** F を重い両文字型節点の集合とする。根（または F の節点 w）から下で、F の節点を子孫に持つ節点だけを残した木を考え、各道は最初の F の節点で切る。この木で子が二つ以上ある節点を「分岐節点」と呼ぶ。分岐節点の数が H 以下なら、葉（切った F の節点）は (r−1)H + 1 個以下である。分岐節点は F に属さない重い節点、つまり一色型であり、根 w 自身を加えてもよい。
2. **一色型の重い節点のうち、B と関係なく抑えられるもの**（`chatgpt_bc_escapes` §3.1・§3.2）。
   - 非飽和色の重い節点は、各深さに 9 個以下で、深さは v 以下である。したがって二色合わせて 18v 個以下。
   - 飽和色で頻出でない（重い出現が θ 回以下の）ラベルの節点は、合わせて vθ 個以下。
   - これらの議論は、一色型の節点を {a, x}⁺ の短い代表に差し替えるだけで、両文字型の節点には触れない。だから F がいくつあっても成り立つ。ここを確かめること。
3. **頻出の節点。** 色 x の頻出の節点 u は α_x ≤ ℓ_u ≤ θ(1+α_x) を満たし、α_x ≥ 1/θ である。二色の比を α₁ ≤ α₂ とする。
   - 比 α₁ の頻出の節点 u の下では、どちらの色の頻出の節点も長さが α₁ 以上である。だから各深さに θ(1+α₁)/α₁ ≤ θ + θ² 個以下で、全体で v(θ+θ²) 個以下。
   - 比 α₂ の頻出の節点の下では、比 α₁ の頻出の節点で切る。すると残りの頻出の節点（比 α₂）は、同じ理由で v(θ+θ²) 個以下。
4. **三層の組み合わせ。** 一段（F の一つの節点 w から、その下の最初の F の節点まで）を、次の三つの層に分ける。
   - 頻出の祖先を持たない上の層
   - 比 α₂ の領域
   - 比 α₁ の領域

   各層の分岐節点の数は、c₀ := 18v + vθ + 1 と H₀ := c₀ + v(θ+θ²) で抑えられる。したがって一段で F の節点が増える倍率は、P := [(r−1)c₀+1]·[(r−1)H₀+1]² 以下になる。
5. **段を重ねる。** F の節点 w の下でも、同じ議論がそのまま使える（2 の数は大域的に抑えられている）。深さ h まで重ねると、N_bc ≤ Σ_{j≤h} P^j。

**帰結（確かめること）。** 超多項式の反例には、重い両文字型ラベルが入れ子になって、h → ∞ となる鎖 B₁ ⊃ B₂ ⊃ … が要る（各 B_j は別のラベル）。

既報の近い候補 A_i → A_{i−1}A_{i−1} | D（D → bc | bc D）では、A_i は全て両文字型で、h = n である。これは (K) と合っている。この候補は、a の個数の漏れで壊れた（bcbc と bc が □ を共有し、□a で分かれる）。

**(L) 段の交換（確かめること）。** 入れ子の二つの両文字型の重い節点 w₁ ⊃ w₂ を考える。w₁ のラベルを B₁、w₂ のラベルを B₂ とし、w₁ の下にある B₂ の出現を t 個とする（一様なので t = t_{B₁,B₂}）。次の二つの組は、どちらも同じ文脈 E（T から w₁ を抜いたもの）で受理される。

- w₁ を ρ_{B₁} に差し替えた組
- w₁ の下の t 個の B₂ を全て ρ_{B₂} に差し替えた組

成分ごとの内容が一致すれば、二つの組の分布は等しい。ファンアウト1では、両方が b と c を含み、a も含むなら内容は {a, b, c} で一致する。これは、近い候補で漏れを起こした「段の間の交換」そのものである。これと定理S（同じ a 骨格では a の個数が一致する）を組み合わせて、矛盾が出るか。
