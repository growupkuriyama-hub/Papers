## 問い：片側の窓 s_{0,1}、ファンアウト1で、費用を「内部」と「右端」に分ける

前回のあなたの分析では、右にずらした断片（型が次の文字で決まる）は内部の構成素を安く扱えます。いっぽう、**文の右端で終わる節点**は次の文字が無いので、ずらす方法が使えません。F_n では、その費用が U_n 一本に入れ子で収まりました。

**T1（条件付きの上界を、きれいな形で証明する）**
s = s_{0,1}、ファンアウト1、ランク r_max 固定、L ∈ C_{1,s}、G は reduced good とします。次の三つの量を正確に定義してください。
- **P(G)**：先頭の条件の費用。各非終端 A と、実現される先頭の文字 p について、「先頭が p の A の最短 yield の長さ」。
- **Q(G)**：ずらした断片に必要な文脈の費用。各 (A, p, b)（A の yield の先頭が p で、直後の文字が b となる出現）について、その最短の文脈の長さ。
- **R(G)**：右端の費用。右端で終わる節点が実現する「（非終端, 末尾の型）」と、それを使う規則の全てを証拠として含む語の集合の、最短の総長。

そのうえで、次を証明してください。
> cs ≤ c_{r_max}·(‖G‖θ̄ + P(G) + Q(G) + R(G))

前回の (6.1) の「子の代表の使い回し」の費用は、P と Q が θ̄ の定数倍で抑えられる場合に ‖G‖θ̄ に吸収されるはずです。そうならないなら、その理由を示してください。

**T2（右端の費用は本物か：ここが本題）**
次のどちらかを示してください。
- **(a) R(G) = O(‖G‖θ̄) が常に成り立つ。** 右端の証拠は、F_n の U_n のように、少数の語の接尾辞に入れ子で収まる、という主張です。
- **(b) R(G) = Θ(‖G‖²θ̄) となる族がある。** 右端の状態が「一本の語の接尾辞の鎖には同時に乗らない」ように枝分かれする族です。この場合はさらに、**作用素 B についての下界 cs = Ω(‖G‖²θ̄)** が言えるかを調べてください。右端には次の文字が無いので、境界をまたぐ Link による逃げ道が無いはずです。ただし、前回の報告にあるとおり、Comp で接尾辞を切ったり、別の語の接尾辞の断片を Link でつないだりする逃げ道は残ります。それも含めて排除できるかを確かめてください。

(b) の族の候補を作るときは、必ず次を添えてください。①クラスに入ること（できれば Clark–Eyraud 代入可能）、②‖G‖・θ̄ の値、③どの作用素についての下界か。
