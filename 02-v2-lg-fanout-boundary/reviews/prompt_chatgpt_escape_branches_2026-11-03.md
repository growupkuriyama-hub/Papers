## 1. 問い（これまでと同じ）

Σ = {a, b, c}、内容型付け c、L ∈ C_{2,c}（arity 1 と 2、arity 2 の区切りは空でない）、G は L∩Σ⁺ の reduced good な表示（ファンアウト ≤ 2、ランク ≤ r）。

> **Q：μ_a(L) := min{k : a^k ∈ L} は poly(‖G‖, θ̄_G) で抑えられるか。**

否定の族があれば `prop:rare-type` により `op:fanout-two` が否定で解ける。

## 2. これまでの試みから見えた核心（Claude のまとめ）

- **逃げ道がなければ反例は作れるが、θ̄ が大きい**：(a^N)^+ は C_{2,c} に入り（全ての組が a だけなので、比べられる組は a の個数 mod N で決まる）、文法の大きさは O(log N)、μ_a = N。しかし θ̄ も Θ(N)。
- **θ̄ を小さくするには「安い逃げ道」が要る**：a^k の導出で使う全ての規則 R に、R を使う長さ θ̄ 以下の文がなければならない。とくに重い節点の非終端 B には、b か c を含む短い生成組 ω_B（‖ω_B‖₁ ≤ θ̄）がある（a だけの短い生成組があると、より短い a だけの語ができる）。
- **これまでの候補は全て、逃げ道が「比べられる二語」を作るところで壊れた**：
  - A_i → A A | bc：bc と bcbc が同じ内容で文脈 □ を共有し、有限の言語なので `lem:no-insertion` に反する。
  - A_i → A A | d_i（d_i ∈ {b,c}⁺）：a の塊が全て偶数長になり、再配分と矛盾（`reviews/chatgpt_skeleton_diversity_2026-11-02.md` の定理3.2）。
  - 接頭符号 bc^i b、(bc)^i bb の重み付きの連結：c の再配分や境界の交換で壊れる。
  - 倍増族 K_n、Thue–Morse 型、ブロックの族、c で近道する族：冪の移行や共役移送で壊れる。

## 3. 準備の補題（証明してから使うこと）

k := μ_a ≥ 5、T を a^k の節点数最小の導出とする（高さは |V| 以下）。節点 h の総長を ℓ_h とし、ℓ_h > θ̄ のとき重いと呼ぶ。

**補題D（倍増の深さ）**：重い子を二つ以上持つ節点を「倍増節点」と呼ぶ。T の根から、各段で最も長い子へ下る道の上の倍増節点の数を D とすると、
  k ≤ (r+1)·|V|·θ̄ · r^D
程度が成り立つ（重い子が一つの節点では ℓ_parent ≤ rθ̄ + ℓ_child にしかならないため）。したがって μ_a が超多項式なら、**一本の道の上に ω(log n) 個の倍増節点がある**。正確な定数で示してください。

倍増節点 h（規則 R_h : B → ρ(C_1, …, C_m)、重い子 C_i, C_j を持つ）では、次の二種類の材料が同時に存在する。
- T の中の a だけの長い生成組（各子の部分木の yield）。
- 各重い子の、b か c を含む短い生成組 ω_{C_i}（逃げ道）。

R_h はこれらを混ぜて適用できる（子ごとにどちらを入れても B の生成組になる）。混ぜ方を変えた生成組どうしは、成分ごとの内容が一致することがあり、そのとき文脈 E_B（`lem:thickness-equivalence`(iv)、固定部分 θ̄ 以下）や T の外側の文脈で比べられる。

## 4. してほしいこと（優先順）

1. **補題D を証明する。**
2. **肯定側（逃げ道の補題）**：ω(log n) 個の倍増節点が一本の道に並ぶとき、それらの逃げ道の混ぜ方から、成分ごとの内容が等しく共通の受理文脈を持つ二つの組で、分布が異なるもの（または a^{k'}、k' < k を強制するもの）が必ず見つかることを示す。使える道具：個数の漏れ（同じ a 骨格で a の個数が 1〜k−1 違えば矛盾）、再配分、隙間の合流、共役移送、`lem:no-insertion`、不足の加法性。
   - 示せれば μ_a ≤ poly(‖G‖, θ̄_G) となり、Q が肯定で解ける。
   - 一般に示せない場合は、示せる部分（例：倍増節点の子の逃げ道の符号が O(log) 種類しかない場合、ランク2で fan-out 1 の倍増節点だけの場合、など）を切り出して証明する。
3. **否定側**：比べられる二語を作らない逃げ道の付け方を、多項式の大きさの文法で実現する族を作る。作れたら、L_n ∈ C_{2,c}（arity 1 と 2 を省略せずに）、G_n が reduced good でファンアウト ≤ 2・ランク ≤ 2、‖G_n‖ と θ̄_{G_n}（n の多項式）、μ_a(L_n)（超多項式）を全て証明する。
4. どちらも完了しない場合は、証明できたこと、止まった場所（どの混ぜ方で比べられる二語が作れなかったか）、次に絞るべき一点を書いて終える。

## 5. 計算について

否定側の候補の検査に、有限言語の (1,c)・(2,c)-代入可能性の全数検査を勧める（前回の付録を再利用してよい）。肯定側では、小さい文法を列挙して「倍増節点の逃げ道の混ぜ方」で違反が必ず出るかを観察するのも有効。Python 3 の標準ライブラリだけで書き、全文を載せる（Windows の `py -3 script.py` で動く形）。有限の検査の結果から無限の族の代入可能性を推定しない。
