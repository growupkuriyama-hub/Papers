## 4. 新しい文法側の補題：低い c の不足

**定義。** L ⊆ {a,b,c}⁺、P を L の最短の ab 語のパリク、θ ≥ 1 とする。

Δ_L(P, θ) := max(0, max{‖P‖ − |f|_{ab} : f は L の abc 語のパリクで、f_c ≤ θ})

（そのような f がなければ 0。一頂点では f は Q₃ を動く。）

**補題 C** [証明済み]。G を既約・線形・非削除の表示（ファンアウト・言語の形は任意）、r をランク、v = |N|、θ = θ_loc、μ = μ_{ab}(L(G)) とする。L の最短の ab 語の全てのパリク P について

**μ ≤ 3vθ + 3rv(θ + Δ_L(P, θ)) ≤ 3(r+1)vθ + 3rv·Δ_L(P, θ)。**

*証明。* 7.3 報告 §1 の枠（W は最短の ab 語で π(W) = P、T は最小の導出、a と b の出現に一つずつ印）を取る。
- 印のある節点は、印集合 {a,b}, {a}, {b} の三本の鎖をなし、各鎖のラベルは相異なるので、高々 3v 個（H 報告の補題3.1。7.3 報告の補題7 の証明と同じ）。
- 全ての節点は、印のある節点か、印のある節点の印のない子 j の部分木にある。
- (P1) から |W| = Σ_{z は印あり} (|t_{R(z)}| + Σ_{j は z の印のない子} |y(j)|) ≤ 3v(θ + r·U)。ここで U は印のない子 j の |y(j)| の最大。

U を抑える。u を A_j の最短の生成とすると、|u| = τ(A_j) ≤ θ（(T1)）。W[j ← u] ∈ L（(S1)）は両方の印を含むので、a と b を含む。
- u が c を含まない場合：W[j ← u] は ab 語なので |W[j ← u]| ≥ |W|。従って |y(j)| ≤ |u| ≤ θ。
- u が c を含む場合：W[j ← u] は abc 語で、そのパリク f = P − π(y(j)) + π(u) は f_c = |u|_c ≤ θ を満たす。ab 成分の長さを比べると |y(j)| = ‖P‖ − |f|_{ab} + |u|_{ab} ≤ Δ_L(P, θ) + θ。

よって U ≤ θ + Δ_L(P, θ)。∎

**注意。**
1. 補題 C は場合 (ii) も、代入可能性も、一頂点も使わない。Q₃ に c ≤ θ の点がなければ μ ≤ 3(r+1)vθ（H 報告の (A′) 6(r+1)vθ と同種の改良）。
2. 7.3 報告の補題7（c の個数の種類 K_c）と相補的である。補題7 は「c 可能な節点」の数を K_c で数える。補題 C は「印のない子の大きさ」を、低い c の abc の点の a,b の不足で抑える。
3. Δ は Q と θ だけで決まる量で、文法によらない。

**系4** [証明済み]。命題3 の Q_n = {P} ∪ F_n について、任意の既約・線形・非削除の表示で
μ_{ab} = 10n + 1 ≤ 3vθ + 3rv(θ + max(8, 3.5θ)) ≤ 3v(1 + 4.5r)θ + 24rv。
従って F_n は命題7.4 の反例ではない。

*証明。* 命題3(f) から Δ(θ) ≤ max(8, 3.5θ)。補題 C。∎

## 6. 課題3：場合 (ii) を起こす文法について

文法は**作れなかった**。理由と、反例の文法に必要なものを記す。

**(1) 見つかった Q はどれも反例にならない。**
- E₁、E₂ は固定された有限の例。
- F_n は補題 C で落ちる（系4）。
- 構造化された探索では、反例の必要条件である「K_c が大きい（補題7）」「Δ(θ)/θ が大きい（補題 C）」「‖P‖/θ が大きい」の**三つを同時に**満たす Q は見つからなかった。三つの最小値は最大 4.0 だった（§10 の C6、seed 2, 3 の各 600 秒）。θ ≤ 6 に限ると Δ の最大は 12（θ = 6、‖P‖ = 67）。

従って、どの補題を避けたかを問う段階に進む Q がない。前の候補は補題8・9・7 で落ち、今回の候補は 7.5 の意味の反例ではあるが、命題7.4 の上界は補題 C か補題7 で落ちる。

**(2) 反例の文法に必要なもの** [証明済みの部分を含む]。

**命題5** [証明済み]。L(G) が有限なら μ_{ab} ≤ θ·(r^v − 1)/(r − 1)（r ≥ 2）、r = 1 なら μ_{ab} ≤ vθ。

*証明。* T の根から葉への道で、z とその子孫 z′ が同じラベルを持つとする。(S1) で z′ の部分木を z の部分木に繰り返し置き換えると、(P1) から長さが |y(z)| − |y(z′)| ずつ増える語が L に入る。L は有限なので差は 0。そのとき z を z′ の部分木で置き換えると、同じ語で節点が減り、T の最小性に反する。従って深さは v 以下で、節点は Σ_{i<v} r^i 個以下。各節点の寄与は |t_R| ≤ θ。∎

Q₂ = {P} の族（命題3 の形）では L が有限なので、命題7.4 の反例には v ≳ log_r(μ/θ) で、しかも θ が μ より桁違いに小さい表示、すなわち**厚さの小さい指数的に簡潔な文法**が要る。

さらに次が要る。
- θ ≥ τ(S) なので、Q は長さ θ 以下の点（他の支持でよい）を持たなければならない（§1(4)）。
- W の木の全ての重い節点の短い生成の置換が、L の語（abc の点か他の支持の点）に落ちる必要がある。
- 補題 C から、Q₃ は「c ≤ θ で、a,b の不足が μ/(3rv) 程度の点」を持たなければならない。
- 補題7 から、K_c ≳ μ/(vθ)。

**(3) θ_loc について。** 命題3 の F_n では、(N) を許す θ は [7, 5n−2]。小さい θ で場合 (ii) を起こすには、他の支持の短い点を Q に足す必要がある（(T) は保たれる）。具体的な表示の θ_loc は計算していない（文法を作っていないので）。
