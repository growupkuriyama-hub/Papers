## 1. 中心の問いと、この依頼の位置

- 中心の問い：ファンアウト2で、内容型付け c_Σ（語 ↦ 現れる文字の集合）は特徴データが多項式で済むか。二文字では肯定（`thm:two-letter-content`）。三文字 Σ = {a, b, c} が未解決。否定なら LG がファンアウト2でも境界、肯定なら境界がファンアウトで動く。
- 今回の対象（三文字の最も鋭い特別な場合）：
  > **Q：L ∈ C_{2,c}（Σ = {a,b,c}）、G は L∩Σ⁺ の reduced good な表示（ファンアウト ≤ 2、ランク ≤ r）。μ_a(L) := min{k : a^k ∈ L} は poly(‖G‖, θ̄_G) で抑えられるか。**
  否定の族があれば `prop:rare-type` により中心の問いが否定で解ける。
- 分かっていること（検証済み）：
  - a^k（k = μ_a ≥ 5）の節点数最小の導出の、印の無い重い節点 h について、短い代わりの生成組 ω_B を入れた語の a 骨格は、符号 κ(B) だけで決まり、失う a の数（重み）w_h は符号で決まる（前々回の定理3.1）。
  - P_a(C) ≤ poly(|V|, θ̄, |C|_fix)·r^M、M は符号の種類数（前々回の定理4.2）。したがって否定の族には、重みが指数的に離れた超対数個の符号が要る。
  - **個数の漏れ**：x⁴ が現れ、同じ x 骨格の二語の x の数が δ だけ違えば D(x) = D(x^{1+δ})。したがって a については、**どの骨格でも、L の語の a の数は互いに 0 か k 以上離れている**（a^{k−δ} ∈ L になって矛盾するため）。
  - 倍増の型 E_i → E_{i−1}E_{i−1} | d_i は d_i によらず壊れる。重み 2^i の接頭符号 bc^i b は抽象的には復号できるが、重み N の全ての連結からなる言語では c の再配分で重みがアフィンになる（前回の定理3.2、4.1）。

## 2. 新しい切り口：b, c の4乗の有無で分ける

再配分の補題3.1 は「x⁴ がどこかに現れる文字 x」についてだけ使える。そこで次の三つに分ける。

**場合I：b⁴ と c⁴ の両方が現れる。**
- このとき、a⁴ も現れるので、全ての文字について再配分が効き、w ∈ L かどうかは（全文字の骨格 σ(w), Parikh ベクトル Ψ(w)）だけで決まるはずである（確かめてください）。
- すると、重い節点の符号の重みは、符号の骨格と Parikh ベクトルで決まる関数になり、隙間の合流（補題3.4）で符号をつなぐと重みが足し算になる。前回の定理4.1 の「アフィン化」を、一般の文法の中で起こせるかが鍵。
- **目標**：場合I では μ_a(L) ≤ poly(‖G‖, θ̄_G) を証明する。

**場合II：b⁴ と c⁴ のどちらも現れない。**
- このとき L の全ての語で b と c の走りの長さは3以下。符号は「走りが3以下の {b,c} の語」（a で区切られた並び）で、二進数のような符号を作る余地がある。**反例があるなら、ここにある可能性が高い。**
- 一方、共役移送（補題3.5）は、L のある語に x v t′ y（t = pq、t′ = qp、v = (pq)^k p、c(t) ⊆ c(x)∩c(y)）の形の因子があれば移送を強制する。k = 0 なら因子 x p q p y で足りるので、重なり（pqp の形）が多い語ほど縛られる。
- **目標**：場合II で、(a) 重みが指数的に離れた符号の系を、arity 1 と 2 の代入可能性（再配分、合流、共役移送、冪の移行を全て含む）と両立させる族を作る（否定の解決）か、(b) 共役移送などで、そのような符号の系が作れないことを示す（場合II の肯定）。

**場合III：片方だけが4乗を持つ（例：c⁴ はあり、b⁴ はない）。**
- 場合I と II の議論の組合せで扱えるかを調べる。

## 3. してほしいこと（優先順）

1. **場合I の証明**（最優先）。骨格と Parikh ベクトルによる正規形を確かめ、それを使って重みの関数が多項式で抑えられることを示す。証明できれば、Q の場合I が肯定で解ける。
2. **場合II の探索**。まず抽象的な模型（符号の集合、重み、骨格を保つ移動、合流、共役移送）を立て、小さい場合を計算で探索してから、具体的な言語 L_n と文法 G_n に落とす。否定の族が得られたら、次を全て証明する：
   - L_n ∈ C_{2,c}（arity 1 と 2 を省略せずに）。
   - G_n は reduced good、ファンアウト ≤ 2、ランク ≤ 2、‖G_n‖ と θ̄_{G_n} の値（n の多項式）。
   - μ_a(L_n)（超多項式）。
   作れない場合は、どの条件が符号の系を壊すかを、具体的な違反の組で示す。
3. **場合III** は余力があれば。
4. **どれも完了しない場合**：証明できたこと、止まった場所、次に絞るべき一点を書いて終える。

## 4. 計算について
