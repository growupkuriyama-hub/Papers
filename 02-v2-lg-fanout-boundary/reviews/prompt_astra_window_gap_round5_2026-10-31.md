- F_n：E_0 → a、E_i → l E_{i−1}E_{i−1} | c E_{i−1} r、開始 E_n。Clark–Eyraud 代入可能（全ての n で証明済み）。‖G_n‖ = 12n+3、θ̄ = 4n−1。

## 問い

**Q（本題）：s_{1,1}、作用素 B_{1,s}（とランク2版）で、F_n の最短の特徴標本の長さは Θ(n²) か。**

Claude の見立て（証明はまだ）：
- Comp は型を見ません。型が効くのは Link だけです。
- 第3次の補助記号を、**断片の先頭の文字でも細分**すれば、Link の型の一致を保てそうです。X_i^b = {wb} は w の先頭 p ∈ {c, l} で分け、T_i^{p,b} = {∂w b} は w の2文字目で分けます。
- どの細分にも、長さ O(i) の代表がありそうです（C_i と l C_{i−1}C_{i−1} を組み合わせる）。文脈 (3.4) は先頭の文字によらないので、そのまま使えます。
- 末尾が a の背骨は、第3次と同じく U_n 一本の接尾辞を Comp で切るだけです。Link を使わないので、型の問題は起きません。

どちらかを示してください。
- **(a)** 細分した補助記号で、長さ O(n²) の特徴標本を具体的に構成し、特徴標本であることを証明する。各細分に短い代表と共通の文脈があることを、表の形で確かめてください。
- **(b)** 細分のどこかで短い代表または共通の文脈が作れず、構成が止まる。その場合は止まる場所を特定し、そこから Ω(n³) の下界が出るかどうかを述べてください。

余力があれば、一段落で構いません。(a) が通る場合、同じ方法が任意の固定窓 s_{k,ℓ} で F_n に通るか（細分の数が定数で、各代表が O(n) か）を述べてください。
