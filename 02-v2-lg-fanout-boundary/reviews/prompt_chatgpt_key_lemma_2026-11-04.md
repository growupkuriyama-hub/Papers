## 1. 到達点（検証済み）

Σ = {a, b, c}、内容型付け c、L ∈ C_{2,c}、a^k ∈ L（k = μ_a(L) ≥ 5）。場合 II は、b⁴ も c⁴ も L の語の因子に現れない場合である。a を含まない語 F（b と c を含む）が**損失 d の単一塊の性質** SB(F, d) を持つとは、s, t ≥ 1、s+t = k−d の全てで a^s F a^t ∈ L であること。

- 十六本目の証明書（三つのモデル・実装で再生済み）：k = 9、損失 2 で、次の種を全て含む場合 II の言語はない。種の範囲は u = bcc, bbc, bcb の三つである。
  - a^9
  - a^s u^j a^t（j = 1, 2, 3、全ての正の配分）
  - a^p u a^q u a^r（全ての正の配分）

  a → a^m で写した種（k = 9m、損失 2m）も同じである。
- u = bc、bcbc では矛盾が出ない（有限の閉包が閉じる。証明ではない）。
- Parikh 飽和という追加の仮定があれば、F³ が現れる塊は bc か cb に限られる（十六本目 系2.2）。

## 2. 帰着（Claude の観察。確かめること）

**鍵の補題 (KL)。** 場合 II で、a を含まない語 F（b と c を含む）が次を満たすとする。
- SB(F, d)、SB(F², 2d)、SB(F³, 3d) を持つ。
- 離れた二塊の語 a^p F a^q F a^r が、全ての正の配分（p+q+r = k−2d）で L に入る。
- 3d ≤ k/2。

このとき、F が因子 bb または cc を含むなら、b⁴ か c⁴ を含む語が L に入ることが強制される。

**(KL) から (ALT) が出る理由。** 場合 II の分岐 (B) では、関係のある低い塊の**任意の鎖**（異なるラベルの塊を並べたものも含む）が SB を持ち、分離もできる。したがって、関係のある塊の鎖 C で損失が k/6 以下のものは、全て (KL) の仮定を満たす。
1. 関係のある塊 F が xx を含むなら、(KL) で矛盾する。
2. F の先頭と末尾が同じ文字 x なら、鎖 F·F が xx を含むので、F·F に (KL) を使って矛盾する（十六本目の bcb の例がこれ）。
3. よって全ての関係のある塊は、先頭と末尾が違う交代語、すなわち (bc)^j か (cb)^j である。
4. **根の統一**：(bc)^i の塊と (cb)^j の塊が両方あれば、鎖 (bc)^i(cb)^j は cc を含むので、その鎖に (KL) を使って矛盾する。十六本目 §4(2) は「bccb に 4 乗はないので直ちには矛盾しない」と書いたが、鎖そのものに (KL) を当てれば矛盾が出る。
   - **実験による裏付け**（`reviews/check_claude_mixed_roots_2026-11-04.py`、十六本目の閉包のコードをそのまま使った）：鎖 u = bccb と u = cbbc を一つの塊として同じ種（k = 9、損失 2）を置くと、それぞれ11段・10段の証明書で c⁴・b⁴ が強制された。Claude が自作の検査器で全段を再生した。
5. 全ての塊が一つの根 u の冪 u^j になると、u^i u^j = u^{i+j} と (R) により、損失は指数 j の線形関数になる。区分は1次元一つで、定理 I と同じ例外の数え方と補題3.1・3.2 から μ_a ≤ poly_r(v, θ) が出る（場合 II の分岐 (B)）。
