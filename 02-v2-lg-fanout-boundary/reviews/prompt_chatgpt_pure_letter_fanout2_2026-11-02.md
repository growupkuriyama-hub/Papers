## 設定

- Σ = {a, b, c}、型付けは内容型付け c_Σ（語 ↦ 現れる文字の集合）。ファンアウト f = 2、ランク r ≥ 2。
- L ∈ C_{2,c_Σ}：L は 2-MCFL で、arity 1 と 2 の両方で (2,c_Σ)-組代入可能（成分ごとの内容が等しく、共通の許容文脈を持つ組は、全ての許容文脈で同時に受理される。arity 2 の文脈の穴の間の区切りは空でない）。
- G は L∩Σ⁺ の reduced good な表示（ファンアウト ≤ 2、ランク ≤ r）。
- **量**：μ_a(L) := min{ k ≥ 1 : a^k ∈ L }（無ければ ∞）。

## 問い

> **Q：L ∈ C_{2,c_Σ} で a^+ ∩ L ≠ ∅ なら、μ_a(L) ≤ poly(‖G‖, θ̄_G) か。**（多項式は r にだけ依存してよい。）

**意味**（どちらの答えも決定的）：
- **否定**（‖G_n‖, θ̄_{G_n} が多項式で μ_a(L_n) が超多項式の族）：`prop:rare-type` により内容 {a} の語が全ての特徴標本に要るので、`op:fanout-two` が否定で解け、LG がファンアウト2でも擬多様体の境界になる（`prop:sl-reduction`）。
- **肯定**：唯一語の道（`prop:unique-word-route`）のうち冪の形 x^n が閉じる。さらに、証明が一穴文脈 C での P_a(C) := min{k : C[a^k] ∈ L}（|C|_fix ≤ θ̄_G）にも通れば、内容 {a} の型付き非終端の代表長 τ_X（= P_a(E_A)、報告の (1.1)）が多項式になり（二穴の ({a},{a}) は同じ議論の二穴版が要る）、三文字の肯定（境界がファンアウトで動く）への大きな一歩になる。

## 分かっていること（使ってよい、ただし確かめること）

1. **二文字では肯定**（`thm:two-letter-content`）。三文字で壊れるのは「第三の文字が隙間に入る」ことだけ。
2. **再配分**（補題3.1）：a^4 がどこかの語に現れれば、w ∈ L は（a 骨格, |w|_a）だけで決まる。したがって μ_a(L) が大きいとき、a の塊の長さは自由に配り直せる。
3. **剛性**（補題6.3）：μ_a = k ≥ 5 のとき、a^k の節点数最小の導出の印の無い重い節点 h（非終端 B）では、ω_B（長さ ≤ θ̄ の生成組）が a 以外の文字を含み、重み ℓ_h − |ω_B|_a は差し替えた後の a 骨格だけから k 未満の誤差なしに決まる。つまり否定の族には「隙間の語の上の、指数的な重みを持つ一意に復号できる重み付き符号」が要る。二文字ではこの符号が作れない（隙間が b の塊だけなので合流で b^4 ができる）。
4. **否定の族が満たすべき条件**：
   - L は無限（`lem:no-insertion`：有限なら同じ型の語は互いの因子にならない）。
   - 長い仲間：|W| > θ̄ なら、a 以外の文字を |W|/((r+1)|V|θ̄) 個以上含む語がある（`lem:unique-word-gap`(ii)、Γ = {a}）。
   - 共役移送（補題3.5）と冪の移行（`lem:power-transfer`）で壊れないこと。
   - 隙間の合流（補題3.4）で生じる長い隙間の語からも重みが読めること。
5. **閉じた道**：三文字の倍増族 K_n（n ≥ 3 で脱落）、Thue–Morse 型、c で近道する倍増族、ブロックの族、可換群の篩い、型の集合、(ab)⁺ のような局所篩い。

## してほしいこと（どちらか一つ）

- **(a) 肯定の証明**：μ_a(L) ≤ poly(‖G‖, θ̄_G) を証明する。鍵は、第三の文字を含む隙間でも「重み付き符号」が作れないことを示すこと（例：隙間の合流と共役移送で、重みの異なる二つの差し替えを同じ骨格に揃え、系3.2(iii) で矛盾させる）。余力があれば P_a(C) に広げる。
- **(b) 否定の族**：L_n、G_n を明示し、次を全て証明する。
  - L_n ∈ C_{2,c_Σ}：arity 1 と arity 2 の代入可能性を、省略せずに。
  - G_n は reduced good、ファンアウト ≤ 2、ランク ≤ 2、‖G_n‖ と θ̄_{G_n} の値。
  - μ_a(L_n) の値（超多項式）。
- **どちらも完了しない場合**：証明できたこと、止まった場所（どの補題のどの場合か）、重み付き符号について分かった制約を書いて終える。
