## 1. 背景と、この問いの意味

- 型付け s: Σ⁺ ↠ S を固定し、空でない組の成分を型が等しいときだけ比べます。C_{f,s} は (f,s)-組代入可能なファンアウト f 以下の MCFL のクラス、B_{f,s} はその学習作用素です。`cor:distribution-representatives` により、各型付き非終端の代表の長さ τ が ‖G‖ と θ̄ の多項式なら、特徴データは多項式です。
- **二文字は解決済み**：Σ = {a,b} の内容型付け c はファンアウト2で多項式データを持つ（`claude_binary_case2` の定理E。飽和でない場合 O_r(‖G‖²θ̄)、飽和の場合 O_r(‖G‖³θ̄⁵)）。
- **三文字が持つ意味**：
  - ファンアウト1では、三文字の倍増族 K_n（`prop:three-letter-family`：E_0 → a、E_i → b E_{i−1} E_{i−1} b | c E_{i−1} c）は Clark–Eyraud 代入可能で、c を含まない語は V_n ただ一つ（長さ 3·2ⁿ − 2）。内容型付け c_{a,b,c} では、内容 {a,b} の語は V_n だけなので、`prop:rare-type` により、c_{a,b,c} はファンアウト1で多項式データを持ちません（下界は B^{≤r}_{1,c}、B_{1,c}、および C_{1,c} 全体に特徴標本を持つ任意の集合駆動作用素について。まずこの推論を自分で確かめてください）。
  - したがって **c_{a,b,c} がファンアウト2で多項式データを持てば、一つの型付けについて「ファンアウト1では指数、ファンアウト2では多項式」が成り立ち**、境界がファンアウトに依存する具体例になります。逆に反例の族が見つかれば、`prop:sl-reduction` により、ファンアウト2でも擬多様体の境界は LG と確定します。どちらでも論文の看板になる結果です。

## 2. 問い

> **Σ = {a, b, c}、内容型付け c_Σ（型は空でない部分集合 7 種類）、ファンアウト2、ランク r ≥ 2 で、全ての L ∈ C_{2,c_Σ} と全ての reduced good な表示 G について、τ(G, c_Σ) は ‖G‖ と θ̄ の多項式か。**

完全な解決が難しいことを前提に、次の順で段階的な結果を狙ってください。

**Q0（すぐに確かめること）**
K_n はファンアウト2の (2, c_Σ)-代入可能性を満たすか。満たさないなら、具体的な二穴の組・共通の文脈・食い違う文脈を挙げてください（`thm:doubling-no-lift` の冪の移行と同じ機構か、別の機構か）。満たすなら、それだけで否定の答えになります（その場合は全力で証明を確かめてください）。

**Q1（一文字の純な型）**
純な型が一文字（{a}, {b}, {c}）の型付き非終端について、二文字の場合の道具（再配分の補題2.1、境界の交換の補題A、内部の塊の補題B、挿入補題3.1）がどこまで移るかを、補題ごとの表で示してください。特に補題B の最後の矛盾（二つの b の塊の合流で b⁴ ができる）が、塊の間に第三の文字が挟まる場合にどう変わるかを調べてください。

**Q2（二文字の純な型：本当の山）**
内容 {a,b} の長い成分（Σ = {a,b,c} の中では純）の短縮で c が入る場合の修復が、これまで止まっていた場所です。次のどれかを狙ってください。
- (a) 「内容 {a,b} の成分の中では、二文字の場合の定理E の議論がそのまま動く」ことを、成分の中を二文字の言語として扱う帰着で示す。例えば、x^4（x ∈ {a,b}）の再配分や、Parikh 飽和に当たる機構が、c を含む文脈の中で成り立つか。
- (b) 二文字の場合の「飽和／四乗の有無」による場合分けを、三文字では「各二文字の組 {x,y} について、内容 {x,y} の因子の上で何が強制されるか」の場合分けに広げる。
- (c) 条件付きの定理（例：「c を含む語の中で、内容 {a,b} の因子の長さが有界なら多項式」「Parikh 飽和なら多項式」「どの二文字の組についても深い挿入が無ければ多項式」など）を、証明できる最も強い形で。

**Q3（否定の向き）**
Q2 で本質的に止まった場合は、止まった場所を反例の族の設計仕様として書き出し、族 (L_n, G_n)（‖G_n‖・θ̄ が n の多項式、ある内容型の代表が超多項式）を試してください。L_n ∈ C_{2,c_Σ} の証明（d = 1 と 2 の両方）を必ず付けてください。過去の候補（括弧付き倍増族、Thue–Morse、単一の繊維、並べ替えに閉じた繊維、二文字の場合 II の倍増）が全て二穴の交換で潰れていることを踏まえ、同じ失敗をしていないか確かめてください。

## 3. 手がかり（使う前に自分で確かめてください）

1. **二文字の成功の構造**：二文字の証明は「言語側の構造の補題（補題B：内部の b の塊は一つ）」と「文法側の挿入補題（同時の差し替えで、純な成分の内部に別の塊が複数できる）」の組み合わせでした。三文字でも、まず「長い純な成分を持つ語では、その内部に入れられる他の文字の塊の数が有界」という言語側の補題を探すのが近道かもしれません。
2. **一文字ずつの再配分**：x⁴ が現れれば x の塊の再配分が成り立つ（比べる組の内容は ({x},{x})）。三文字では、a の塊の再配分と b の塊の再配分が同時に使える場合、内容 {a,b} の因子の内部の構造がかなり縛られるはずです。
3. **内容 {a,b} の成分どうしの交換**：内容 {a,b} の組 (ab, ba) が共通の文脈を持てば、c を含む文脈でも隣接交換ができ、内容 {a,b} の因子の中で Parikh 飽和に近い性質が出ます。どんな条件で共通の文脈が強制されるか。
4. **型付けの単調性**：`lem:typing-monotone` により、c_{a,b,c} で多項式が言えれば、三文字の U₁ 型付け S2（a, b ↦ 1、c ↦ ζ）も解けます。S2 は過去3回の挑戦で未解決でした。逆に、S2 の部分結果（`archive-v1/revision/` の Astra と ChatGPT の報告）のうち、内容型付けのほうが細かいために易しくなる部分があるかを確かめてください。
5. **長さの種類の定理**（`chatgpt_sl_fanout2_2026-11-01.md` の定理10）、**Parikh のずれの法則と漏れ**（`chatgpt_parikh_closed_family_2026-11-01.md`）、**冪の移行**（`lem:power-transfer`、u⁵ が必要）も道具として使えます。
