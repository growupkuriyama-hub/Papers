## 2. 論文定義との照合

`main.tex` の `def:tuple-substitutable` は比較対象の各穴の語を `Σ⁺` とし、二穴中央の隔ては非空。一穴の左右外部は空でもよい。内容型は文字集合 `alph` を成分ごとに比較する。今回の比較片 `JJ a^k` / `KK a^{k−(D−δ)}`、`(bbcc,c)` / `(bcb,cc)`、`(cc,c)` / `(c,cc)`、`cb` / `bc` はすべてこの要件を満たす。古いX1/CAは使用していない。

## 3. 主証明の独立再構成

`J=bc`, `K=bbcc`、`M=N−δ−D`。MSより次の**具体的な受理語**を得る：

```
W_J   = JJ a^(N−δ)
W_K   = KK a^(N−D)
W_JJ  = JJJJ a^(N−2δ)
W_JK  = JKJK a^M
W_KK  = KKKK a^(N−2D)
```

これらは単なるParikh一致から得た語ではなく、Singleと実在交錯Seedからの先行MSに依存する。室(H)で末尾a指数は4以上（単独も正）。

### (A) 一穴のa吸収

`Δ=D−δ, k=max(1,1+Δ)` とすると `k≥1`, `k−Δ≥1`, `N−2δ−k≥0`。比較片 `x=JJ a^k`, `y=KK a^(k−Δ)` はともに内容 `{a,b,c}`。共有E₀=`(ε,a^(N−δ−k))` の二語は W_J、W_K、試験E₁=`(JJ,a^(N−2δ−k))` のx側は W_JJ。ゆえに `JJKK a^M∈L`。

### (C) 二穴の新しい合同

`x=(K,c)=(bbcc,c)`, `y=(bcb,cc)` は成分型 `({b,c},{c})`。共有E₀=`(J,b,K a^M)` を使うと `E₀[x]=JKJK a^M`、`E₀[y]=JJKK a^M`。両方が上で証明済み。中央bは非空。これにより任意の適法試験2穴文脈へ交換できる。

### (N,R) 長いc連を前提から導出

`E₁=(ε,bbc,a^(N−D))` に C を適用して `bcbbbccc a^(N−D)∈L` を得る。従って極大b/c連長≤2という障害仮定は前提と両立しない。

Cを W_KK に適用すると、

```
V1 = bbccbbccbcbbbccc a^(N−2D)
V2 = bbccbcbbcbbbcccc a^(N−2D)
```

となる。2手のE₁は順に `(bbccbbcc,bbc,a^(N−2D))` と `(bbcc,bcbbb,cc a^(N−2D))`。どちらも比較片・中央・受理先行語が適法。

### (Rc,CC) コスト0の `cb≡bc`

`V2=l₀ c⁴ a^(N−2D)`, `l₀=bbccbcbbcbbb`。`x=(cc,c)`, `y=(c,cc)` は `E₀=(l₀,c,a^(N−2D))` で**同じ**V2を与え、型が `({c},{c})`。試験E₁=`(bcbb,b,bbcc a^M)` のx側はW_JK、y側は `w2=bcbbcbccbbcc a^M`。両方受理。

次に一穴比較片 `cb`, `bc` は内容 `{b,c}` が等しい。共有E₀=`(bcbbc,cbbcc a^M)` の両語はそれぞれW_JKとw2。よって `cb≡bc` が**全適法一穴文脈で成立**。可換性を事前仮定したものではない。

### 終結

1穴合同で W_JJ と W_K を隣接`cb→bc`で整列し、

```
bbbbcccc a^(N−2δ)∈L,
bbbbcccc a^(N−D)∈L.
```

同じ1穴文脈 `(bbbbcccc,ε)` で比較片 `a^(N−2δ)` と `a^(N−D)` を共有する。両方正なので型 `{a}`。指数が異なるなら、長い方を短い方で `a^N` の内部で置換し、長さ `N−|2δ−D|` の**より短い正のa冪**を受理させて最短性に反する。従って `D=2δ`。

### Mの独立補足

Fableの加重Dyck言語は、深さ `0,1,2` の部分可逆歩行：`b:q→q+1`, `c:q→q−1`、`a:0→0`（重み1）、下降cには出発深さ1で重みe₁、2で重みe₂、総コストN、初終状態0で記述できる。

`gcd(e₁,e₂)=1, e₁e₂>N` より、受理語における深さ1/2下降回数 `u₁,u₂` は同じ非a費用であれば一意（`u₁<e₂,u₂<e₁`）。共通一穴文脈でx,yが受理されたときは入口と出口状態が等しい。aを含む比較片ならa出現で入口状態が一意に定まり、別の有効試験文脈でも一致する。a-freeな比較片では、他の試験入口深さへ移れる場合、境界側への到達条件が下降数の片方が0であることで決まり、共有宿主から得た同じ下降数を持つyにも同様に成立する。従って1穴代入可能性は成り立つ。これは元報告の「重みが一意」の一言を補うための論証であり、形式化・全パラメータ網羅実験ではない。

小さな検査例として `(e₁,e₂,N)=(3,4,11)` は53語、(3,5,14)は161語で、各受理語の全非空因子と共通文脈の厳密列挙を独立に行い、どちらも一穴内容型代入可能性の違反0（前者655対照比較、後者4098比較）。ただしこれらはHやJ/Kの両Singleを満たす大きなモデルではなく、1穴言語クラスの仕組みの局所チェックである。

**二穴の違反を明示するには、共通受理文脈も必要。** 比較組 `x=(bbcc,c)`, `y=(bcb,cc)`、`E₀=(a^r,b,a^s)` とし `r+s=N−(2e₁+e₂)≥0`。`E₀[x]` の非a語は `bbccbc`、`E₀[y]` は `bcbbcc` で、双方のコスト `2e₁+e₂` が等しく、両方受理。一方 E₁=`(ε,ab,ε)` は `E₁[x]=bbccabc`（深さ0にa）が許されるのに `E₁[y]=bcbabcc` は深さ1にaを含むので拒否。元報告の結論「二穴は破れる」に対応する合法な明示証人になっている（例 e₁=20,e₂=21,N=400）。
