## 1. 問題

### 1.1 設定（命題7.3 の報告 §1 のとおり）

Σ = {a,b,c}、π はパリクベクトル、Π₂ = {(x,y,0) : x, y ≥ 1}、Π₃ = ℤ³_{≥1}、L = π⁻¹(Q)、Q₂ = Q ∩ Π₂、Q₃ = Q ∩ Π₃。μ = μ_ab は Q₂ の点の長さの最小で、P はそれを与える Q₂ の点です。

有限の F ⊆ Π₃ が**閉じている**とは、全ての p, q, r ∈ F（p = q も含む）について、p + q − r ∈ Π₃ なら p + q − r ∈ F となることです。L が SUB₁ なら Q₃ は閉じています。

### 1.2 分かっていること

一頂点・SUB₁・Q₃ 有限の場合の地図です。

| 場合 | 上界の出どころ |
|---|---|
| rank H₃ ≤ 2 | 定理4 ＋ 定理6（系10） |
| Q₃^{<μ} が狭義に正の水準に乗る | 定理6 |
| P が Q₃^{<μ} の三点の頂点 p₁ + p₂ − p₁₂ でない | 補題8（場合 (ii) が起きない） |
| 支配の条件（補題9）が破れる | 補題9 |
| K_c が小さい | 補題7：μ ≤ (K_c+3)vθ |

その外の (P⁺)、Q₃ 無限、V ∩ Q₂ = ∅ の場合は、系3.6・定理 A・系2(a) で閉じています。

### 1.3 残る穴

**命題7.4**：rank H₃ = 3 で、Q₃^{<μ} が正の水準に乗らず、P が短い点の頂点で、支配の条件も満たすとき、任意の既約 good な表示で μ_ab ≤ poly_r(v, θ̄) か。補題7 から、反例には K_c ≥ μ/(vθ) − 3 も要ります。

**予想7.5**：Q = {P} ∪ Q₃（P ∈ Π₂、Q₃ ⊆ Π₃ 有限）が (T) を満たすとします。さらに、ある θ と p₁, p₂, p₁₂ ∈ Q₃、Y₁, Y₂ ∈ ℕ²、r₁, r₂ ∈ ℕ³ が次を満たすとします。

- (N1) p₁ + p₂ − p₁₂ = P。
- (N2) ‖p_i‖ < ‖P‖。p₁₂ も短い点です（報告 §7.2 の文脈）。
- (N3) Y_i = (P − p_i + r_i)_{ab} ≥ 0、(r_i)_c = (p_i)_c、|r_i| ≤ θ < |Y_i|。
- (N4) Y₁ + Y₂ ≤ P − (1,1)。
- (N5′) i = 1, 2 について、q ∈ Q₃ と M ≤ Y_i（|M| ≤ θ）で (P − q)⁺_{ab} ≤ M となるものがある。

このとき Q₃^{<‖P‖} は狭義に正の水準に乗る。

まず、(N1)〜(N5′) が補題8・9 と (★) を言語の言葉に**正しく**書き直したものかを確かめてください。不足や過剰があれば、正しい形に直してから攻めてください。p₁₂ が短いことは (★) から出ますが、予想の文面に明記されていません。

## 追記（2026-11-07 夕、README (194)）：予想7.5 の対象を広げること

Astra による命題7.3 の報告の独立検証（`reviews/astra_check_prop73_2026-11-07.md` §5 S6）で、次の穴が指摘されました。予想7.5 は Q = {P} ∪ Q₃ に限っていますが、命題7.3・7.4 の Q は一般の Q₂ を持てます。そして、**最短点 P だけを残すと (T) が壊れることがあります**。

- 例：Q₃ = F_{5,4} = {(1,5,1), (6,1,1), (2,2,2), (1,1,4)}、Q₂ = {(1,15,0), (6,11,0), (11,7,0), (16,3,0)}。
- Q 全体は (T) を満たし、P = (1,15,0) は最短の ab 点で、P ∈ V です。
- ところが {P} ∪ Q₃ は、h = (5,−4,0)、γ = (0,10,0) で (T) に反します。

この例は予想7.5 の反例ではありません（場合 (ii) は起きない）。しかし「予想7.5 ⟹ 命題7.4」の帰着が成り立たないことを示しています。

従って、課題2 では次の**一般形の予想**を対象にしてください。

> **予想7.5′**：Q ⊆ ℕ³ が (T) を満たし、Q₃ が有限、P が Q₂ の最短の点で、(N1)〜(N5′) が成り立つ。このとき Q₃^{<‖P‖} は狭義に正の水準に乗る。

- 反例を探すときも、Q₂ が複数の点を持つ場合を含めてください。
