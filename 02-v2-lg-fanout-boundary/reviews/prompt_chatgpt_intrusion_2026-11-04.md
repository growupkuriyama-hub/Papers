## 1. 到達点（検証済み）

Σ = {a, b, c}、内容型付け c、L ∈ C_{2,c}。G は L∩Σ⁺ の reduced good な表示で、ファンアウト ≤ 2、ランク ≤ r。v = |V|、θ = θ̄_G とおく。**場合 I** は、a⁴、b⁴、c⁴ が全て L の語に現れる場合とする。型付き非終端 X は、非終端 A と、その出力の成分ごとの内容 (t_1, …, t_d)（d ≤ 2、各 t_i は {a,b,c} の空でない部分集合）の組である。

- **定理3.1（十七本目、代入可能性を使わない）**：全成分の内容が {a,b,c} の X は τ_X ≤ t_X ≤ 147d(r+1)vθ。特に μ_{abc} ≤ 147(r+1)vθ。
  - 理由：根の各成分の各文字に印を一つずつ付ける。印を含まない重い節点は短い代表に替えても型が変わらないので、全ての重い節点が印を含む。
- **定理 I**：開始記号の型 {a}, {b}, {c} の μ は多項式。
- **定理4.1**：Parikh 飽和という追加の仮定があれば、成分の合併が {a,b,c} の X も多項式。
- **残り**：成分に欠けた文字がある X（例：成分の内容が {a,b}、{a}、{b,c} など。もう一つの成分の内容は任意）。
  - 印の議論が止まる理由：印を含まない重い節点を短い代表 ω に替えると、欠けた文字（例えば c）が**侵入**して型が変わることがある。
  - 十七本目 §5 の例が示すとおり、「μ_a が小さいから文脈の中の a の穴も短い」とは言えない。θ を使う議論が要る。

## 2. 観察（確かめること）

この系列の検証を担当している Claude の観察で、まだ証明されていません。

**(I1) 侵入しない代表を持つ節点は印で処理できる。** X の型が成分 i で文字 z を欠くとする。根の各成分の各文字に印を付けたうえで、印を含まない重い節点 u のラベル B が「z を含まず、u が置かれた成分の型を壊さない短い代表」（長さ ≤ θ、あるいは ≤ poly(θ)）を持てば、u を替えても型は変わらない。よって最小性から、そのような節点は存在しない。残るのは「**短い代表が全て、欠けた文字を含む**」ラベルの節点だけである。

これは純粋 a 語の場合の「両文字型の節点」（短い代表が全て b と c を含む）とちょうど同じ状況である。系列は、その場合を次の道具で処理した。
- 一色型の数え方（(K)、補題M）
- 塊の融合と交換（補題 F′、補題E）
- (R) による損失の線形化と、補題3.1・3.2

これらを、「欠けた文字を持ち込む節点」に移せるか。

**(I2) 印のある文字を文脈の固定部分として扱う。** X の型が成分の内容 {a,b} なら、根の b の印は固定された位置にあり、その間の部分は a だけ、または a と b の語である。純粋 a 語の議論の「a の連」を「印と印の間の a の連」に置き換えれば、補題 F′（a の連の除去）や a の再配分（a⁴ による）はそのまま使えるか。十七本目 §5 の例は、印の位置が固定されると μ_a が効かないことを示した。しかし θ を使う議論（重い節点の数え方）なら止まらないかもしれない。

**(I3) 侵入の重み付き計数。** 侵入する節点 u を短い代表に替えると、型は変わるが、L の語であることは保たれる。その語を、場合 I の全文字の骨格と Parikh ベクトルによる正規形（`chatgpt_weighted_codes_2026-11-02.md` の系2.2：場合 I では所属は全文字の連の骨格と Parikh ベクトルだけで決まる）で比べられないか。侵入した c の連を、型を保ったまま元の位置から外へ押し出すことはできないか。
