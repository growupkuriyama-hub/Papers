## 1. 到達点（検証済み）

Σ = {a, b, c}、内容型付け c、L ∈ C_{2,c}。G は reduced good、ファンアウト ≤ 2、ランク ≤ r。v = |V|、θ = θ̄_G とおく。**場合 I**：a⁴、b⁴、c⁴ が全て L の語に現れる。型付き非終端 X の最短の組の、節点数最小の導出を T とする。

- 根の各成分の各文字に印を一つずつ付ける（3d 個以下）。
- 印を含まない重い節点 u は、必ず θ-侵入配置になる。つまり、u のラベル B と配置 π について、根の型を壊さない長さ θ 以下の B の代表がない（定理2.1）。
- 侵入する節点の反鎖の大きさを q とすると、τ_X ≤ 49(r+1)vθ(3d + q)。
- 同じ (B, π) の侵入節点の反鎖が h 以下なら、q ≤ 4vh。
- **残る問い**：場合 I で h ≤ poly(v, θ) か。

## 2. 観察（確かめること）

この系列の検証を担当している Claude の観察で、まだ証明されていません。

**(J1) 侵入節点は、定理 I の「両文字型の節点」と同じ役割をする。** 定理 I は、純粋な a 語の導出で、短い代表が全て b と c を含む節点を、次の道具で処理した。
- a の連の除去と塊の融合（補題 F′）
- 塊の交換（補題E・E₂）
- 型板と入れ子（補題 T・N）
- (R) による損失の線形化（補題 P・Q）

型が成分 {a, b} の X では、侵入節点の短い代表は c を含む。場合 I には c⁴ も現れるので、**c の連にも補題 F′ の類似が使える**（c の連の再配分は二穴の組 (c, cc) と (cc, c) の共通文脈から出る。十八本目の補題2.2 と同じ形の持ち上げも使える）。そうすると、侵入した c の連を融合して一つにまとめられる。これは定理 I で b, c を含む塊を一つにまとめたのと同じ操作である。

**(J2) 背景の文字。** 定理 I の背景は a だけの語だった。型 {a, b} の X では、背景は a と b の語で、根の b の印は動かせない。場合 I では b の連も再配分できるので、(R) の形「同じ全文字の骨格・同じ b, c の個数なら a の個数も同じ」は、背景に b があってもそのまま使えるか。使えない場合、何が壊れるか。

**(J3) 抽象的な文字での実験。** 十八本目の手法にならい、抽象的な文字で「背景 + 侵入する塊」の小さな種を作り、強制閉包で短い型 X の語（または矛盾）が出るかを調べる。出れば、準同型で持ち上げて一般の場合の証明書にできる。
