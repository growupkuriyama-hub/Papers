## 1. 設定（自己完結）

- Σ = {a, b}。型付け s_{U,2}：純な a の語は型 1、b を含む語（b 語）は全て型 ζ。
- **C₁**：同じ型の空でない語 x, y が言語 L の中で一つの文脈 (l, r)（lxr, lyr ∈ L）を共有すれば、x と y の分布 D_L(x) = {(l, r) : lxr ∈ L} は等しい。≡ は分布の同値（統語合同なので合同関係）。
- G は L∩Σ⁺ の reduced・ε なし・ランク ≤ r の CFG。‖G‖ = |V| + Σ_{X→γ}(1+|γ|)。**規則の厚さ** θ = θ̄_G：各規則について、その規則を使う開始記号からの導出が生成する最短の語の長さ、の最大値。
- a^N は L の最短の純な語。**問い（`op:S1`）**：N ≤ poly(‖G‖, θ, r) か。まず L が**有限**の場合に限る。
- 既知の道具：
  - **C.0**：一つの非終端の同じ型の生成語は、その非終端の成功文脈を共有するので ≡。
  - **補題0**：L が有限なら、分布が空でない ≡ 類は因子の反鎖（一方が他方の真の因子にならない）。
  - **補題2.1（消去）**：同じ型の x, y で、xz が L の因子として現れ xz ≡ yz なら x ≡ y（左右とも）。
  - **定理1**：有限の置き場所 P(z) = {(x, y) : a^x z a^y ∈ L}（z は b 語）は、空・一点・または抜けのない等差列 {(x₀+kd, y₀+(K−k)e)}。

## 2. 既に得られたこと（検査の対象を含む）

- **定理C（抽象的な計数）**：b 語 z_0, …, z_M と c ≥ 1 について
  (C1) a^c z_0 ≡ z_0 a^c ≡ z_0 z_0、(C2) z_i ≡ a^{e_i} z_0（c | e_i）、価値 v_i := e_i + c、(C3) v_i の部分和は全て異なる、(C4) l a^{Σv_i + P − c} z_0 r ∈ L（c | P）
  が成り立ち、L が有限で M ≥ 6 なら ‖G‖+2 ≥ 3^{M/3−1}/((M+1)(m+1)²(Mλ+1)²)（λ = max|z_i|、m = |l|+|r|+P+Σ|z_i|）。
  証明の骨子：補題2.2（崩壊：符号と a^c の連接 u は u ≡ a^{val(u)−c}z_0）、補題2.3（l u a^P r ∈ L ⇔ val(u) = Σv_i、補題0 を使う）、M 個の符号の並べ方 w_π に重み付きの中間節点を取り、記録（ラベル、区間、端をまたぐ符号の番号とずれ）が同じなら内側の符号の集合が同じ（内側を入れ替えた語が L に入り、補題2.3 で価値が保存され (C3) から集合が一致）。
- **定理D（二重化の鎖）**：G が E_j → E_{j−1}E_{j−1}（k < j ≤ n）を持ち E_k が重い（純な生成語 a^c、c > θ）なら、z_0 = ω_{E_k}、z_i = ω_{E_{k+i−1}} で (C1)–(C4) が成り立ち、定理C から M = n−k = O(log(‖G‖θ))。
- **命題S（刻みの剛性）**：T の節点 B の部分木の中の X について、|P(ω_B)| ≥ 2 なら P(ω_X) と P(ω_B) は同じ刻み。あるラベルの刻みは ≤ 4(r+1)θ|V|²。
- **問題C（残る核）**：有限の L ∈ C₁ で N が多項式を超えるとき、T の重いラベルから、ある基底に (C1)(C2) で潰れ (C3) を満たす符号を ω(log(‖G‖θr)) 個取り出せるか。肯定なら定理C で op:S1（有限）は肯定。困難は**双子の節点（B → C C）のない T**：例えば Fibonacci 型 F_k → F_{k−1}F_{k−2} では C.0 から ω_k ≡ ω_{k−1}a^{f_{k−2}} ≡ a^{f_{k−1}}ω_{k−2} ≡ ω_{k−1}ω_{k−2}（f_k は F_k の純な長さ）が出るが、型の違う語の間では消去できないので (C1) が直接は出ない。

## 3. 依頼

**課題1（検査、最優先）.** 定理C と定理D の証明を、反例を探すつもりで検査する。特に：
- 補題2.2：≡ が合同関係であることの使い方、a^c を z_0 の間で動かすときに e_i が c の倍数であることが必要な箇所、z_0^t ≡ a^{(t−1)c}z_0 の帰納法。
- 補題2.3：l u a^P r ≡ l a^{f} z_0 r の導出（a^P を z_0 の左へ移す段階）、f ≠ e* のとき補題0 に当てる二語が本当に同じ文脈を共有し、一方が他方の真の因子になるか。
- 定理C：重み付きの中間節点の存在（単位節点を縮めた二分木、葉の重み ≤ 1）、記録の数え方（端をまたぐ符号の「番号とずれ」で十分か。l, a^P, r の中に端がある場合）、「同じ記録なら内側を入れ替えた語が L に入る」の論証（y, y′ が同じ非終端 X の b を含む生成語であること、|I(π)| ≥ 1）、一つの記録に属する並べ方の数の上界、二項係数の評価。
- 定理D：E_j の純な生成語の一意性、短い b 語 ω_j の存在（厚さの定義から、長さ ≤ θ の成功語の中の E_j の生成語が b を含むこと）、(C4) の語が実際に E_n の生成語であること、m の評価。
- 誤りが見つかれば、直せるか、直した後の主張を示す。

**課題2（本命：問題C）.** 双子のない T で符号を潰す方法を探す。候補：
- (a) **Fibonacci 型を直接扱う**：F_k → F_{k−1}F_{k−2} の鎖で、C.0 の関係 ω_k ≡ ω_{k−1}a^{f_{k−2}} ≡ a^{f_{k−1}}ω_{k−2} ≡ ω_{k−1}ω_{k−2}、補題2.1、命題S（刻み）、定理1 から、ある基底への崩壊（(C1)(C2) の形でなくてもよい）を導く。例えば二段先の関係を組み合わせて ω_kω_k や ω_{k}a^{c} の形の関係を作れるか。
- (b) **定理C の一般化**：崩壊が一つの基底でなく、有界個の基底 z_0^{(1)}, …, z_0^{(t)} への崩壊で足りるように定理C を強める（補題2.3 の類似が成り立てば計数はそのまま通るはず）。
- (c) **加法鎖の一般論**：重い部分 T が直線的プログラムなら、ラベルの数が |V| で N が指数的なので、どこかに「同じラベルの二つの出現の間の差が小さい」構造（命題S の刻み）がある。刻み d の小ささと a^d ω ≡ ω a^d から (C1) の前半は出る。後半（ω ω ≡ a^c ω）を、反復するラベルの二つの出現を同時に置き換えた語と補題0 から導けるか。
- 部分結果でよい：例えば「Fibonacci 型の鎖では定理D と同じ下界」「双子が O(1) 段ごとに現れる T では多項式」。

**課題3（一般化、任意）.** E_j → E_{j−1}^{t_j}（2 ≤ t_j ≤ r）の鎖で定理D の書き下し（報告の §2.3 で未了とされた部分）。

**課題4（否定の向き）.** 課題2 が通らない箇所から、Fibonacci 型の鎖で各段の ω_{k−1}ω_{k−2} の類が a のずらしで潰れないような印（例えば二つの基底を交互に使う）を設計し、s_{U,2} の強制閉包（長さ打ち切り）で反鎖の違反が出るかを検査する。閉包の計算は、同じ型で文脈を共有する因子を同じ類にまとめ、類の全ての文脈に全ての因子を入れる操作の繰り返し（打ち切りより長い語は捨てる。部分閉包は全ての C₁ の上位言語に含まれるので、そこで b 語どうしの真の因子関係が出れば有限の上位言語は存在しない）。
