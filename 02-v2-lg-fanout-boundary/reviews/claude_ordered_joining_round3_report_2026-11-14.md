## 2. W1・W2 の独立な確認

**補題W1** [独立に証明]。$w$ を歩道とし、$S(w)$ を $w$ が使う辺の台グラフとする。$S(w)$ の異なる強連結成分を結ぶ辺は、$w$ にちょうど1回現れる。さらに、$w$ は $S(w)$ の強連結成分を一本の線形順序で、それぞれ連続したブロックとして訪れる。

*証明。* 辺 $e:K\to K'$（$K\ne K'$）が2回現れるとする。2回の間で、歩道は $K'$ から $K$ に戻る。その戻り道は $S(w)$ の中にあるので、$K$ と $K'$ は互いに到達でき、矛盾する。後半は、凝縮グラフを歩道が一度ずつ通ることから従う。∎

量化の点検：Opus の記述どおりで正しい。ただし定理Pで使うのは W1 そのものではなく、W2 の成分版（下の系）である。

**補題W2（頻度の隙間）** [独立に証明]。
- **設定**：$w$ を歩道とし、$n_a:=|w|_a$ とおく。$1=c_1<c_2<\cdots<c_{k+2}$ を $c_{i+1}\ge kc_i$ を満たす数列とする。
- **ギャップの選択**：$k+1$ 個の区間 $[c_g,c_{g+1})$（$g=1..k+1$）の中に、どの $n_a>0$ も入らない $g$ が存在する。
- **分類**：$n_a\ge c_{g+1}$ の文字を頻出、$0<n_a<c_g$ の文字を稀と呼ぶ。この $g$ のもとで、すべての文字は頻出か稀のどちらかである。
- **主張**：頻出辺の部分グラフの各弱連結成分 $J$ は強連結である。

*証明。*
1. 頻出辺 $b:p\to q$ について、$q$ から頻出辺で到達できる頂点の集合を $Z$ とし、$p\notin Z$ と仮定する。
2. $w$ は $b$ を通るたびに $Z$ に入るので、入る回数は $\ge c_{g+1}$。出る回数は入る回数から1を引いた数以上である。
3. $Z$ から出る辺は頻出ではない（頻出なら行き先も $Z$ に入る）ので稀である。稀な文字は $\le k-1$ 個なので、出る回数は $\le(k-1)(c_g-1)$。
4. ところが $(k-1)(c_g-1)<kc_g-1\le c_{g+1}-1$ なので矛盾する。
5. したがって頻出辺はすべて頻出閉路に載り、弱連結成分は強連結である。∎

量化の点検：
- Opus の $c_{i+1}=kc_i+1$ でも W2 は成り立つ。
- 定理Pでは、余剰の写しを確保するために間隔を広げた $c_{i+1}=kc_i+f+\lambda+1$ を使う（§4.1）。W2 には $c_{i+1}\ge kc_i$ があれば足りる。
- **W2 を適用する語の選び方が重要**である。
  - 語全体 $w=E_A[x]$ に適用すると、頻出成分 $J$ の辺が成分 $x_i$ にほとんど現れないことがあり、穴の内容 $E(J)\subseteq\mathrm{alph}(x_i)$ が保証されない。
  - 定理Pでは、**各根成分 $x_i$ に別々に**適用する（§5の候補6）。

**系W2'（成分ごとの稀骨格）** [独立に証明]。各 $x_i$ に W2 を適用して $g_i$ を選び、印を「各 $x_i$・各文字の最初の $c_*\ge c_{k+2}$ 個の出現」とする。このとき次が成り立つ。
- (a) **稀な文字は全部印になる。** $n_a<c_{g_i}\le c_{k+1}\le c_*$ だからである。
- (b) **印のない出現を持つ文字は頻出である。** $n_a>c_*\ge c_{g_i}$ で、ギャップに入らないので $n_a\ge c_{g_i+1}$。
- (c) **頻出文字は $\ge c_{g_i+1}$ 個の印を持つ。**
- (d) **自由因子は一つの J-区間に収まる。** $x_i$ を稀な文字の出現で区切ると $x_i=F_0r_1F_1\cdots r_NF_N$ となる。$F_l$ を区間と呼ぶ。空でない区間は頻出辺だけの歩道なので、一つの $J$ に入る。印を含まない因子（自由因子）は、稀な文字を含まないので一つの区間に入り、その区間の $J$ の中にある。
- (e) **区間の数**：$N+1\le(k-1)(c_{g_i}-1)+1$。

## 3. 順序付き接合：最も強い真な形と、明示反例

依頼文 §3.1 の 5 項目に順に答える。

### 3.1 鍵となる観察（補題P0）

**補題P0** [独立に証明]。$L\cap\Sigma^+=\mathrm{Path}_D(s,t)\cap\Psi^{-1}(Q)$ とする。$y,y'\in(\Sigma^+)^d$ について、次の三つが成り立つとする。
- 各成分 $y_i,y'_i$ は歩道で、始点・終点が等しい。
- $\mathrm{alph}(y_i)=\mathrm{alph}(y'_i)$。
- $\sigma(y)=\sigma(y')$。

このとき $y\equiv_{L,c}y'$。（代入可能性は使わない。）

*証明。* 内容型は等しい。$E\in\mathcal E_d$ について、$E[y]$ が $s\to t$ の歩道かどうかは、$E$ の各片の内部と、継ぎ目（$y_i$ の始点・終点）だけで決まる。また $\Psi(E[y])=\Psi(E)+\sigma(y)$。したがって $E[y]\in L\iff E[y']\in L$。∎

**Euler の定理**（標準）：
- $N\in\mathbb N^\Sigma$ の台が弱連結で $u,u'$ を含み、各頂点で（入次数−出次数）$=[\,\cdot=u']-[\,\cdot=u]$ ならば、Parikh が $N$ の歩道 $u\to u'$ がある。
- $N=0$ のときは $u=u'$ に限り、空の歩道でよい。

この二つから、**y 側でも F 側でも並べ替えは自由**であり、問題は「どの切れ目に穴を開けるか」だけになる。

### 3.2 局所 circulation 補題（依頼文の問1）

**補題P1** [独立に証明]。
**設定**：
- 極大自由節点 $\eta$ の成分を $\varphi_1,\dots,\varphi_g$（$g\le f$）とする。
- $T_j$ は、$I_j$ の各節点を $u_{B_\nu}$（$\|u_{B_\nu}\|_1\le\theta$）の導出に置き換えた木とする。$T_j$ における $\eta$ の第 $\kappa$ 成分を $\psi^{(j)}_\kappa$ と書く。
- **成分ごとの色**を次で定める。
$$\mathrm{col}_\kappa(j):=\sum_{\nu\in I_j}\ \sum_{m:\ \nu\text{ の第 }m\text{ 成分が }\varphi_\kappa\text{ に入る}}\Psi\bigl((u_{B_\nu})_m\bigr),\qquad \mathrm{col}(j):=(\mathrm{col}_\kappa(j))_{\kappa\le g}.$$
- 色の種類は $\le(1+rH\theta)^{kf}$。

**主張**：$\mathrm{col}(j)=\mathrm{col}(j')$（$j<j'$）、$R=U_{j'}\setminus U_j$ ならば、各 $\kappa$ について
$$z_\kappa:=\Psi(R\cap\varphi_\kappa)=\Psi(\psi^{(j)}_\kappa)-\Psi(\psi^{(j')}_\kappa)\ \ge0$$
であり、$z_\kappa$ は circulation である。

*証明。*
1. **等式。** $\Psi(\psi^{(j)}_\kappa)=\Psi(\varphi_\kappa)-\Psi(U_j\cap\varphi_\kappa)+\mathrm{col}_\kappa(j)$ が成り立つ。$\nu\in I_j$ の各成分は $\eta$ のある一成分の連続因子だからである。色が等しいので、引き算から等式が出る。
2. **端点の一致。**
   - $\eta$ より上の木は変わらず、テンプレートは線形である。よって $W_j:=E_A[x^{(j)}]$ は、$w=E_A[x]$ の各 $\varphi_\kappa$ をその場で $\psi^{(j)}_\kappa$ に置き換えた語である。
   - good な文法では、同じ節点の相異なる成分は根の語の中で、その節点の外の空でない文字列で隔てられる。親のテンプレートは nonmerging で、ε-free なので、上へ帰納法で示せる。
   - したがって $\psi^{(j)}_\kappa$ の直前・直後の文字（または語の端）は $w$ と同じである。$W_j\in L(G)\subseteq L$ は歩道なので、$\psi^{(j)}_\kappa$ と $\psi^{(j')}_\kappa$ は同じ端点を持つ歩道である。
3. **結論。** 同じ端点を持つ二つの歩道の Parikh の差なので、各頂点で釣り合う。∎

**注。**
- Opus の「端点型の短い代表 $\beta$」は不要である。$W_j\in L$ が自動的に歩道であることで足りる。
- 端点の一致には、上の「成分の分離」が必要である。

**大域色では偽** [明示反例・有界検査]。
**文法**：頂点 $0,1$、$a:0\to1$、$b:1\to0$、ループ $c$（頂点0）と $e$（頂点1）。good な規則は次のとおり。
$$P\to(a,b)\mid(c\,\xi^1e,\ \xi^2)\,(P)\mid(\xi_1^1\xi_2^1\xi_1^2,\ \xi_2^2)\,(B,P)\mid(\xi_1^1\,e\,\xi_1^2\,c\,\xi_2^1,\ \xi_2^2)\,(P,P),\qquad B\to(c,e).$$
（$S\to(\xi^1e\,\xi^2c)(P)$ を加えると $L(G)\subseteq\mathrm{Path}(0,0)\cap\{|w|_c=|w|_e\}$ となる。）

**木**：$\eta=P_6(P_1(P_5(B_0,P_0)),\,P_6(P_0,P_0))$ とする。
- $\varphi_1=\mathtt{ccaeeebcaebca}$、$\varphi_2=\mathtt b$。
- $j=2$、$j'=4$ で、大域色はどちらも $a+b$ である。成分ごとの色は $(a{+}b\mid0)$ と $(a\mid b)$ で異なる。
- $\Psi(R\cap\varphi_1)=\{a{:}2,b{:}1,c{:}2,e{:}2\}$ となり、頂点0で出次数が入次数を1上回るので circulation ではない。

### 3.3 anchored Eulerian exposure（依頼文の問2）

**補題E（露出）** [独立に証明]。
**仮定**：
- $P$ は歩道 $u\to u'$。
- $J$ は強連結な部分グラフで、$P$ が $J$ の頂点を訪れる。
- $g$ は台が $E(J)$ の閉歩道。
- $\Psi(P)\ge\Psi(g)+\mathbb 1_{\mathrm{supp}P}$。

**主張**：$\Psi(P^*)=\Psi(P)$ を満たす歩道 $P^*=\alpha g'\beta$（$u\to u'$）がある。$g'$ は $g$ の回転である。

*証明。* $\Psi(P)-\Psi(g)$ の台は $\mathrm{supp}P$ のまま連結で、釣り合いも同じである。よって Euler 歩道 $\alpha\beta$ がある。それは $J$ の頂点を通るので、そこで $g$ を回転させて差し込む。∎

**限界。** 補題Eは $g'$ の**位置を制御しない**。複数の穴の順序を守るには、次の §3.4 の固定が必要である。

### 3.4 順序付き接合の不変量（依頼文の問3）

**不変量** [独立に証明。§4 の補題Y・補題Fで使う]：
- 各根成分 $x_i$ の**稀骨格**（稀な文字の全出現の列。系W2'(a) により全部印）を、y 側でも F 側でも**文字どおり固定**する。
- 再配線は「同じ $J$ の区間どうしの間」でのみ行う。具体的には、主区間でない区間は最短路にし、主区間は Euler 歩道で再実現する。
- 穴 $(i,J)$ は「$x_i$ の最初の $J$-区間の先頭」という骨格上の切れ目に置く。

すると次の二点が自動的に成り立つ。
- 穴の順序は、両側とも（成分番号、区間の位置）の辞書式順になる。
- 区切りは空でない。同じ成分の中の異なる穴の間には稀な文字が少なくとも一つあり、成分をまたぐ穴の間には文脈の内側の片（admissible なので空でない）がある。

**順序を自由に選ぶ方法は失敗する** [明示反例]。
- 頂点 $0,1,2$、辺 $p:0\to1$、$q:1\to2$、$\rho:2\to0$、各頂点にループ $\ell_0,\ell_1,\ell_2$ を置く。
- $W=\ell_0^n\,p\,\ell_1^n\,q\,\ell_2^n\,\rho\,\ell_0^n$ を考える。
- Parikh が $\Psi(W)$ である $0\to0$ の歩道はどれも、$p,q,\rho$ を1回ずつ、この順に通る。頂点1を訪れるのは $p$ と $q$ の間だけ、頂点2を訪れるのは $q$ と $\rho$ の間だけである。
- したがって「$\{\ell_2\}$ 上の閉歩道を $\{\ell_1\}$ 上の閉歩道より前に露出する」並べ替えは存在しない。
- 穴の順序を y 側と F 側で独立に決めると、一般には一致させられない。骨格による固定がこれを解消する（y 側と $W_{j'}$ は同じ稀骨格を持つ）。

### 3.5 任意の Q（依頼文の問4）

- $F[t']=W'$ と $F[t]$ が $L$ に入ることは、**Parikh ベクトルの完全一致**だけから示す。
  - $\Psi(W')=\Psi(W_{j'})$。
  - $\Psi(F[t])=\Psi(W_{j'})+\sum z=\Psi(W_j)$。
- どちらも $s\to t$ の歩道なので、$\Psi(W_{j'}),\Psi(W_j)\in Q$ から $L$ に入る。
- mod や群値やほぼ等しいことは一度も使わない。

### 3.6 型付けと区切り（依頼文の問5）

- 穴の中身は $t'=h_J$ と $t=$（$\Psi(h_J)+z$ の Euler 閉歩道）である。どちらも内容は $E(J)$ で一致する。
- 区切りは §3.4 のとおり空でない。$F\in\mathcal E_e$（$e\le f$）であり、y 側の文脈 $F_E$ も $\mathcal E_e$ に入る。

## 4. 定理P：主張と完全な証明

### 4.1 定数と設定

- $\lambda:=k(2k-1)$。
  - 強連結な $J$（頂点・辺 $\le k$）について、$E(J)$ のすべての辺を通る基点 $u$ の閉歩道 $h_J$ を、辺ごとに「$u\to\mathrm{tl}(a)$ の最短路、$a$、$\mathrm{hd}(a)\to u$ の最短路」を連結して作る。
  - $|h_J|\le\lambda$ である。
- $c_1:=1$、$c_{i+1}:=kc_i+f+\lambda+1$、$c_*:=c_{k+2}$。
- 型付き非終端 $X=A_{\mathbf T}$（arity $d$）と、$x\in L_X$ で節点数最小の導出木の組を固定する。
  - 補題A により、根から葉への道の型付きラベル $(B,\mathrm{alph}(\cdot)\dots)$ はすべて異なり、高さは $\le H$。
  - $w=E_A[x]\in L$。$x_i$ は歩道 $p_i\to q_i$ で、$T_i:=\mathrm{alph}(x_i)$。
- 印は「各 $x_i$・各文字の最初の $c_*$ 個の出現」。数は $\le c_*kf$ 個で、骨格節点は $N_{\rm sk}\le c_*kfH$ 個。
- 自由節点・極大自由節点 $\eta$（$\le rN_{\rm sk}$ 個）・$I_j$・$U_j$ は Opus 報告 §2.2 補題B のとおり。$|I_j|\le rH$、$|U_{j+1}\setminus U_j|\le H\theta$。
- 色は §3.2 の成分ごとの色を使う。

### 4.2 状態と不変量

各成分の**現在の Parikh** $m_i$ を持つ。初期値は $m_i=\Psi(x_i)$。

**不変量 (Inv)**：$m_i$ は「$\Psi(x_i)$ から、これまでの段で削った circulation を引いたもの」であり、印は一つも削っていない。端点 $(p_i,q_i)$・内容 $T_i$・成分ごとの Parikh $m_i$ を持つ組は存在し、それらはすべて $x$ と $\equiv_{L,c}$ である。

- 初期状態では成り立つ。存在は $x$ 自身で示せる。全部が同値であることは補題P0から従う。
- 各段で保たれることを示す。

### 4.3 一段の削除

貪欲法で選んだ $j<j'$（同色）と $R=U_{j'}\setminus U_j$ を考える。$R$ はそれまでの段の領域と互いに素で、印を含まない。

**穴。**
- $R\cap\varphi_\kappa\ne\varnothing$ となる各 $\kappa$ について、$\varphi_\kappa\subseteq x_i$ は系W2'(d) により $x_i$ の一つの区間に収まり、その区間の頻出成分 $J_\kappa$ が決まる。
- 穴の集合は $\mathcal H:=\{(i,J_\kappa)\}$ で、$e:=|\mathcal H|\le g\le f$。
- 各穴の削除量は $z_{(i,J)}:=\sum_{\kappa\to(i,J)}z_\kappa$ である。補題P1により circulation で、台は $E(J)$ に含まれる。
- 穴の基点 $u_{(i,J)}$ は、$x_i$ の最初の $J$-区間の始点とする。
- $h:=h_J$（基点 $u$）、$t:=\Psi(h)+z_{(i,J)}$ の Euler 閉歩道（基点 $u$。台は $E(J)$ で強連結）。
- $t'=h$ で、$\mathrm{alph}(t)=\mathrm{alph}(h)=E(J)$。

**補題Y（y 側）** [独立に証明]。各 $i$ について、次の性質を持つ歩道 $y^\pi_i:p_i\to q_i$ がある。
- Parikh は $m_i$、内容は $T_i$。
- $x_i$ の稀骨格を同じ順に含む。
- 各穴 $(i,J)$ について、最初の $J$-区間の先頭（骨格上の切れ目）に $t_{(i,J)}$ を因子として持つ。

*構成。*
1. 頻出成分 $J$ ごとに、$x_i$ の $J$-区間を $F_{l_1},\dots,F_{l_s}$ とする。
2. $l_2..l_s$ は、端点が同じ $J$ 内の最短路 $\pi_l$ に置き換える。
3. $l_1$ は、$t_{(i,J)}$（穴があれば）のあとに、次の $N$ の Euler 歩道（$F_{l_1}$ の端点間）を置く。
   $$N:=m_i|_{E(J)}-\sum_{l\ne l_1}\Psi(\pi_l)-\Psi(t_{(i,J)})$$
4. 稀な文字は元の位置に置く。

*正当性。*
- 釣り合い：$m_i|_{E(J)}$ の釣り合いは元の $J$-区間の端点の和である（削った量は circulation）。最短路と閉歩道を引くと、$F_{l_1}$ の端点の釣り合いだけが残る。
- $N\ge\mathbb 1_{E(J)}$：$a\in E(J)$ について $m_i(a)\ge(\text{印の数})+z(a)\ge c_{g_i+1}+z(a)$ である（今回の $R$ はまだ削っていない）。最短路は単純路なので、各辺を $\le s-1\le(k-1)(c_{g_i}-1)$ 回しか使わない。$t$ の分は $\le\lambda+z(a)$。よって
  $$N(a)\ge c_{g_i+1}-(k-1)(c_{g_i}-1)-\lambda\ge1.$$
- 以上から、台は強連結な $E(J)$ で、Euler 歩道がある。
- 内容：稀な文字はそのまま、頻出文字は各 $J$ の主区間に全部ある。よって内容は $T_i$。Parikh は構成から $m_i$。∎

**補題F（F 側）** [独立に証明]。$\Psi(W')=\Psi(W_{j'})$ を満たす歩道 $W':s\to t$ がある。さらに、各穴 $(i,J)$ について、$W_{j'}$ の中の $x_i$ の領域で、最初の $J$-区間の先頭の切れ目に $h_J$ を因子として持つ。

*構成。*
1. $W_{j'}$ の $x_i$ 領域は、$x_i$ の中の今の $\eta$ の成分を $\psi^{(j')}_\kappa$ に置き換えたものである。各 $\psi$ ブロックは**固定**し、稀な文字も固定する。
2. 残りの元の頻出文字の極大な連（**$J$-片**）は $x_i$ の因子なので、一つの $J$ に入る。片の数は $\le s+f$。
3. 補題Y と同じく、主片以外を最短路にし、主片を $\sum\Psi(\text{片})-\sum\Psi(\pi)-\Psi(h_J)$ の Euler 歩道にする。
4. 穴の切れ目に $h_J$ を差し込む。その切れ目は直前が稀な文字・文脈・語頭のいずれかで変わらないので、頂点 $u$ にある。最初の要素が $\psi$ ブロックでも、$\mathrm{start}(\psi)=\mathrm{start}(\varphi)=u$ である。

*正当性。*
- 印はすべて片の中にある（自由節点の外）ので、$J$ の各辺は片の中に $\ge c_{g_i+1}$ 個ある。
- 最短路は $\le s+f-1$ 個、$h$ の分は $\le\lambda$。$c_{g_i+1}\ge kc_{g_i}+f+\lambda+1$ なので、主片の Parikh は $\ge\mathbb 1_{E(J)}$ である。
- 変わるのは各片の中身だけで、端点は保たれる。よって $W'$ は $s\to t$ の歩道で、Parikh は保存される。$W_{j'}\in L$ なので $W'\in L$。∎

**一段の結論。**
1. $F:=W'$ の各 $h_J$ を穴に替えた文脈とする。$F\in\mathcal E_e$（§3.4）、$F[t']=W'\in L$、$F[t]\in L$（§3.5）。
2. $t,t'$ は穴ごとに内容が等しい。arity $e\le f$ の代入可能性から $\mathcal D(t)=\mathcal D(t')$。
3. 補題Y の $y^\pi$ について、$y'$ を各 $t$ を $h$ に替えた組とする。
   - 任意の $E\in\mathcal E_d$ について、$E[y^\pi]=F_E[t]$、$E[y']=F_E[t']$ である。
   - $F_E\in\mathcal E_e$ で、穴の順序は $F$ と同じである（§3.4）。
   - 内容は保存される。
   - 以上から $y^\pi\equiv y'$。
4. (Inv) から $y^\pi\equiv x$。よって $y'\equiv x$。
5. $y'$ の Parikh は $m_i-z_{(i,\cdot)}$ である。補題P0から、この Parikh を持つすべての組が $x$ と同値になる。
6. $m_i\leftarrow m_i-z_{(i,\cdot)}$ と更新すれば、(Inv) が保たれる。∎

### 4.4 長さの評価

- 貪欲法で残る位置は次の二種類である。
  - 骨格節点が明示する終端：$\le N_{\rm sk}\theta$。
  - 各極大自由節点で残す段：色ごとに高々一段、一段あたり $\le H\theta$。
- 最終の $m_i$ は (Inv) により歩道として実現できる。印が残るので内容は $T_i$、空の成分はない。
- よって
$$\tau_X\le N_{\rm sk}\theta+rN_{\rm sk}(1+rH\theta)^{kf}H\theta\le c_*kfH\theta\bigl(1+rH(1+rH\theta)^{kf}\bigr).$$
- $N_{\rm typ}\le2^{kfr}\|G\|$ と `cor:distribution-representatives` から、特徴標本の評価が出る。
- **型付き積文法の厚さは一度も使っていない**（使うのは元の $\theta$ と $|I_j|\le rH$ だけ）。∎

### 4.5 小さなグラフでの意味（依頼文 §3.2）

依頼文の 5 種類のグラフは、すべて定理Pに含まれる。
- 一頂点＋ループ、2-閉路、2-閉路＋ループ、3-閉路＋ループ、figure-eight、稀な橋で結んだ二つの強連結成分。
- 証明が区別するのは、各根成分の頻出成分 $J$（強連結）と稀骨格だけである。
- 「稀な橋」は稀骨格に入り、figure-eight の共有頂点は一つの $J$ にまとまる（両方の閉路が頻出の場合）。

### 4.6 適用範囲の注意

- 始点・終点の集合 $\mathrm{Path}_D(S_0,T_0)$ にもそのまま通る。補題P0は端点の集合への所属だけを使う。
- **仮定 $L\in\mathcal C^{\rm mcf}_{f,c}$ は自動的には成り立たない**（Q が任意なので MCFL でないこともある）。定理Pはこの仮定のもとでの主張である。
- 定理Pの使い道は、`op:fanout-two` の YES 族の候補を除外することである。下界は与えない。

## 6. 次に攻める補題（最大3つ）

1. **正則な基底への一般化** [予想]。$L\cap\Sigma^+=R\cap\Psi^{-1}(Q)$ で、$R$ が strictly $\ell$-testable（de Bruijn グラフの歩道で、ラベルが単射でない）である場合。
   - 同値類は、各成分の $(\ell-1)$-接頭・接尾と内容と $\sigma$ で決まる（補題P0の類似）。
   - 頻度解析を de Bruijn の辺（$\ell$-因子、$\le k^{\ell}$ 種類）で行い、色を $\ell$-因子の Parikh に細分すれば、定理Pの証明がそのまま通る見込みである。
   - 新しく点検が要るのは、境界をまたぐ $\ell$-因子の扱い（P1の類似）と、長さ $<\ell-1$ の短い成分である。
   - さらに locally testable（$\ell$-因子の集合の条件）へ進む。再配線は台を保つので、内容型を $\ell$-因子に持ち上げれば済むと予想する。
   - 成立すれば、定理Sの主な例（ND$_P\cap$ Parikh）と定理Pを、一つの「正則基底 × 任意 Parikh」定理にまとめる足場になる。
2. **抽象的な転送原理** [予想]。次の (T1)(T2) を仮定する。
   - (T1) $\equiv_{L,c}$ の類が「各成分の有界な局所型 $\rho(y_i)$ と $\sigma$」で決まる。
   - (T2) 局所型を固定したとき、Parikh の実現が Euler 型に柔軟である。すなわち、稀骨格を固定し、各頻出成分で閾値以上あれば任意の Parikh を実現でき、閉歩道の露出もできる。

   このとき $\tau$ は多項式である。定理Sは (T1) を独立交換の版に、定理Pは端点の版に置き換えたものとみなせる。これを証明すれば、YES 族は (T1) か (T2) を破らなければならない、という明確な必要条件になる。
3. **YES 側の候補を絞る**（下界の設計）[未解決]。
   - (T1) を破る最も単純な候補は、局所型が有界でない基底である。例えば Dyck 型（成分の正味の高さと最小の高さ）に Parikh 条件を課したもの。
   - ただし高さの情報も、置き換えた短い部分では $\le rH\theta$ に収まるので、色に入れても多項式にとどまる可能性が高い。
   - まずこの Dyck 型で局所鳩の巣法が通るか（通れば NO の証拠が強まる）、通らない固定小例があるかを判定する。
   - YES の証明には、引き続き次のすべてが要る：固定の内容型付け、fan-out 2・rank 2 での MCFL 性と代入可能性、$\|G_n\|$ と元の $\theta_{G_n}$ が多項式、**特徴標本の総長**の超多項式下界（$\tau$ の下界だけでは不足）。
