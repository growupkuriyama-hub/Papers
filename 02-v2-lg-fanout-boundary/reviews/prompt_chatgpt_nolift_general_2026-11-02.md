## 1. 背景と狙い

**ファンアウト1**：希少な型の語（`prop:rare-type`）を指数に長くすることで、LG の外は指数のデータが要る（定理B）。
- 族は L_n。ただ一つの型1の語 W_n = b W_{n−1} W_{n−1} b は bⁿa で始まる。

**ファンアウト2**：定理C（`thm:doubling-no-lift`）で、この族はクラスから外れます。
- 仕組みは冪の移行です。語が u^{a+d+b+2} を含むと、二穴の組 (u^a, u^{d+b}) と (u^{a+d}, u^b) が同じ型で文脈を共有するので、離れた二つの u の連続の間で u を d 個移せる。
- W_n の先頭の bⁿ と、二つ目の W_{n−1} の先頭の b の連続の間で b を移すと、c を含まない別の語ができ、W_n の一意性に反する。

**中心の問い（`op:fanout-two`）**：ファンアウト2でも LG が境界か。
- `prop:sl-reduction` により、これは半束の内容型付け c_Σ が多項式のデータを持つかと同値です。
- U₁ は半束なので、**ファンアウト2で、U₁ への型付け（例えば a, b ↦ 1、c ↦ ζ）一つに超多項式の下界が出れば、`op:fanout-two` は否定で解決します**（LG が全てのファンアウトの境界になる）。
- `lem:typing-monotone` により、これは内容型付けにも移ります。
- 二文字の内容型付けは全ての f ≥ 2 で多項式なので（`thm:two-letter-content`）、反例には三文字以上が要ります。

**新しい角度**：冪の移行が効くのは、希少な語が**長い冪 u^k** を含むからです。
- 一方、大きさ O(n) の文法で長さ 2ⁿ の語を作っても、長い冪を含まないことがあります。例えば Thue–Morse 語は overlap-free（特に立方を含まない）で、A_i = A_{i−1}B_{i−1}、B_i = B_{i−1}A_{i−1} という小さな文法で生成されます。
- 冪を含まない倍増族は、冪の移行をすり抜けるかもしれません。逆に、すり抜けられないことを示す一般定理は、「ファンアウト ≥ 2 では希少な型による下界は多項式止まり」という方法の限界の定理になります。

## 2. 調べてほしいこと（優先順）

**N1（冪を含まない倍増族：本題）**
- ファンアウト2（できれば全ての f ≥ 2）で C_{f,s} に入り、型付け s（U₁ への型付けが第一候補）について、ただ一つの希少な型の語が 2^{Ω(n)} の長さを持ち、大きさと厚さが O(n)（または多項式）の reduced good な表示を持つ有限の族を作ってください。
- 候補（使う前に確かめてください）：
  - 文字 c を「天井」として使う三文字の族で、c を含まない語を Thue–Morse 語（または立方を含まない別の語）にするもの。例えば次の規則に c の分岐を加えて、厚さを O(n) に保つ。
    - A_i → A_{i−1} B_{i−1}、B_i → B_{i−1} A_{i−1}。
    - A_i → c A_{i−1} c、B_i → c B_{i−1} c など。
  - 型を分ける文字を増やす（文字を共有しない語への像、`cor:typing-level-obstruction`）。
- 必ず確かめてほしいこと：
  - (1,s) と (2,s) の両方の代入可能性。arity 2 の条件が本質で、許容文脈の穴の間が空でないことを使ってください。
  - 冪の移行以外の二穴の交換（同じ型の二つの組が文脈を共有する全ての場合）で、希少な語の一意性が崩れないか。
  - `lem:no-insertion`（同じ型の語が真の部分語にならない）と矛盾しないか。
- **計算による探索を強く勧めます。**
  - 小さい n（n ≤ 4 程度）で、候補の有限言語の (1,s)・(2,s)-代入可能性を全数検査する Python 3（標準ライブラリのみ）のプログラムを書き、全文を載せてください（Windows の `py -3 script.py` で動く形）。
  - 2-tuple の全ての出現と許容 2-文脈を列挙し、同じ型の組で文脈を共有するものの分布を比べます。
  - 有限の検査は「観察」として扱い、一般の n の証明と区別してください。

**N2（一般の非持ち上げ定理：N1 が失敗する場合の本題）**
- N1 の失敗の理由を一般化して、例えば次の形の定理を証明できるか調べてください。
  > f ≥ 2、s 固定。有限の L ∈ C_{f,s} の、ある型 m のただ一つの語 W は、L の reduced good な表示 G について |W| ≤ poly(‖G‖, θ̄_G)。
- または、より弱い形として「W は長さ ℓ の因子を二か所に持てない」「W の因子の複雑さは低い」など、冪の移行を一般化した組合せ論的な制約。
- 方針の候補：
  - 冪 u^k の代わりに、W の中で二回現れる因子 z と、その周りの文脈を使う二穴の交換。
  - 文法が小さく語が長いと、W には長い繰り返し（同じ因子の二回の出現）が必ずある（compressibility）。
  - 二つの出現の間の語を移す交換が、型の等しさ（有限半群の周期性）の下で強制されるか。
- 一般には偽なら、反例の構造（N1 の候補）を示してください。

**N3（整理）**
- N1・N2 の結果が、`op:fanout-two`、`prop:sl-reduction`、定理C とどう関係するかを表にしてください。
