## 1. 背景：差がどこから来るか

定理A は、型付け s の正の像が局所群（LG）なら、固定した f, r_max, s, Σ について、
- 上界：全ての L ∈ C_{f,s} と全ての reduced good な表示 G に、正準作用素 B^{≤r}_{f,s} と B_{f,s} の共通の特徴標本があり、長さは O(‖G‖² θ̄_G)。
- 下界：|Σ| ≥ 4f+1 なら、全ての型付けについて、ある有限の標的族では、特徴標本の長さが全て Ω(‖G‖ θ̄_G)。
- 自明な型付けでは O(‖G‖ θ̄_G) で、下界と一致します（`cor:trivial-exact`）。

上界の形は `cor:distribution-representatives` の
> ‖K‖_+ ≤ N_typ (1 + 2θ̄ + r τ(G,s)) + 1、N_typ = O(‖G‖)

から来ています。窓・群や局所群の型付けでは、τ ≤ t_typ = O(|V| θ̄) です（重い節点の反鎖を群の同時置換で抑え、経路の長さが型付きの非終端の数 |V||M|^f で抑えられる）。つまり ‖G‖ が二回、「型付き非終端の数 N_typ」と「代表の長さ τ の中の |V|」として入っています。

下界の側には、今のところ二つの仕組みしかありません。
- (a) 希少な型（`prop:rare-type`）：‖F‖_+ ≥ Σ_{m∈M_L}(μ_m(L)+1)。型の数は |S| 以下で固定なので、各 μ_m ≤ O(‖G‖θ̄) では、この仕組みからは Ω(‖G‖θ̄) より上は出ません。
- (b) 全ての語が必要な有限言語（`prop:linear-factor-all-fanout`）：語数 ≍ ‖G‖、各語の長さ ≍ θ̄。

‖G‖²θ̄ の下界には、**長さ ≍ ‖G‖θ̄ の語が ≍ ‖G‖ 個、どれも省けない**という新しい仕組みが要るはずです。逆に、それが不可能だと示せれば、上界が O(‖G‖θ̄) に下がります。

注意（`prop:typed-thickness-exponential`）：t_typ が大きくても、データが大きいとは限りません（τ は t_typ より指数的に小さくなりうる）。したがって**下界は、t_typ や τ ではなく、特徴標本そのものについて証明してください**。

## 2. 問い

固定した f, r_max（≥ 2）, Σ, s（正の像が LG、特に有限群、または窓・群）について：

> 最短の特徴標本の長さの最悪値は、‖G‖ と θ̄_G の関数として Θ(‖G‖θ̄) か、Θ(‖G‖²θ̄) か、その間か。

## 3. 調べてほしいこと（優先順）

**Q0（差の所在、最初に短く）**
- 上界の証明で ‖G‖ が二回入る場所（N_typ と τ）を、補題の番号で特定してください。
- 片方が実際には不要になる場合（例えば「長い代表が要る型付き非終端は高々 O(1) 個」）があるかを見てください。

**Q1（下界：本題）**
- 固定した群の型付けで、特徴標本が全て ω(‖G‖θ̄) の長さを持つ族を作ってください。理想は Ω(‖G‖²θ̄) です。
- 候補：
  - Z_2 で文字 a の個数の偶奇を記録する型付け。
  - S_3 の型付け（成分が交錯して、順序が効く）。
  - 窓型付け s_{k,ℓ}。
  - ファンアウト1（CFG）で既に出るなら、それでも価値があります。f と |Σ| は明記してください。
- 設計の要点（使う前に確かめてください）：
  - 型 t を持つ最短の yield が |V|θ̄ 程度になる型付き非終端を ≍ ‖G‖ 個作る。
  - それぞれの代表が、全ての特徴標本に（部分語として）現れることを、区別する標的（L と、L からその部分を除いた言語の両方がクラスに入る）で強制する。
- 下界がどの作用素について成り立つかを分けてください。
  - (L1) 正準作用素 B^{≤r}_{f,s}・B_{f,s} の最短の特徴標本：これだけでも「上界の解析は鋭い」と言えます。
  - (L2) クラス全体に特徴標本を持つ任意の集合駆動作用素：`prop:rare-type` と同じ強さ。
- 表示 G が、その標的の reduced good な最小の表示の定数倍以内であること（水増しでないこと）を示してください。少なくとも ‖G‖ の下界は示してください。
- 代入可能性（(d,s)-tuple-substitutable、d ≤ f）を、全ての arity について必ず証明してください。

**Q2（上界の改良）**
- Q1 がうまくいかない場合、または一部の型付けについては、上界を O(‖G‖θ̄)（または O(‖G‖θ̄ polylog)）に下げてください。
- 候補：
  - 窓型付け s_{k,ℓ}（群が自明）。
  - 可換群の型付け。可換群の語問題では、位数が (r+2)θ̄² 以下になる議論があります：`reviews/chatgpt_problemG_2026-11-01.md` の定理1。
- 道筋の例（使う前に確かめてください）：
  - 代表 τ_X が全ての X で O(θ̄) になる。
  - または、長い代表が要る X の数が O(1)。
  - または、一つの長い語が多くの X の代表を同時に含む（特徴標本は語の集合なので、代表を共有できれば和が小さくなる）。

**Q3（整理）**：型付けごとに、どちらの側にあるかの表を作ってください。
- 自明、窓、可換群、非可換群、局所群の別に、「O(‖G‖θ̄) を証明」「ω(‖G‖θ̄) を証明」「未解決」のどれかを書く。
- それぞれの根拠と、アルファベットの条件を添える。
