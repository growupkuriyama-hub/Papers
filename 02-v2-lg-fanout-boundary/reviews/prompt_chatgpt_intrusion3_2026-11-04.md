## 1. 到達点（検証済み）

Σ = {a, b, c}、内容型付け c、L ∈ C_{2,c}、G は reduced good、fan-out ≤ 2、rank ≤ r、v = |V|、θ = θ̄_G。場合 I（a⁴, b⁴, c⁴ が全て現れる）。

- 型付きラベル X の最短の導出組で、節点数が最小の導出を T とする。
- 根の各成分で、内容の各文字の出現を一つずつ印にする。
- 印を持たない重い節点 u（ラベル B、配置 π）は θ-侵入である。すなわち、成分の内容が根の型に収まる長さ θ 以下の代表を、B は持たない。
- 同じ (B, π) の侵入節点の反鎖の幅が h 以下なら、τ_X ≤ 49(r+1)vθ(3d+4vh)。**h の上界は未解決。**
- 一段の SUB_t は、完成した語全体の支持集合を変えない（前報 補題2.1）。したがって c を含む語の中で c の連をいくら動かしても、c を含まない語は直接には出てこない。c を含まない短縮には、c を含まない穴の組と、それを受理する別の文脈が要る。

## 2. Claude の観察（確かめること）

**(K1) 同じ写しへのそろえ。** 同じ (B, π) の、印のない侵入節点 u_1, …, u_h が T で反鎖をなすとする。生成をそれぞれ y_1, …, y_h とする。
- u_i の部分木を u_j の部分木に取り替えても、導出は正しい（同じラベル、互いに素な部分木）。
- 配置 π が同じなので、y_j の各成分の文字は根の同じ成分の型に収まる。印は u_i の外にあるので残る。よって根の型は変わらない。
- 型付き最短性から |y_i| = |y_j| が従う。さらに、節点数が最小の y を一つ選び、全ての u_i をその写しに取り替えてよい（長さも節点数も増えない）。

**よって、一般性を失わずに全ての u_i の生成は同じ組 y である。**

**(K2) 2^h 語の族。** β を B の長さ θ 以下の代表とする（侵入なので c を含む成分を持ちうる）。上のそろえの後、根の文脈を C とすると、次が成り立つ。
- w_i ∈ {y, β} のどの選び方でも、語 C[w_1, …, w_h] は L に入る（文法の部分木の取り替え）。
- このうち c を含まないのは全て y の場合だけで、残りの 2^h − 1 語は c を含む。

問い：この族と SUB_t から、根と同じ型で、c を含まないより短い語を導けるか。
- 支持集合の不変性から、導くには「c を含まない語 H[X]（例えば C[y, …, y]）」と「同じ内容のより短い組 Y」と「X, Y がともに受理される文脈 E」が要る。
- E は c を含んでよい。E として C[β, …, ·, …] のような c を含む文脈が使えるか、考えてほしい。
- y と β は内容が違うので、そのままでは SUB の対にならない。対になるのは、y の成分の部分語どうし、あるいは y の写しを複数まとめた組どうしである。
