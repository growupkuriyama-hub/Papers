## 1. 課題1：定理C・定理D の検査

### 1.1 補題2.2（崩壊）：正しい

- ≡ が合同関係なので (C2) の置き換え z_i ↦ a^{e_i}z₀ は語のどの位置でもできる。
- a を左へ集める段階で使うのは a^c z₀ ≡ z₀ a^c だけで、動かす塊が c の倍数であることが要る。それが c | e_i を使う唯一の箇所（u の中の a^c の塊は自明に c の倍数）。
- z₀^t ≡ a^{(t−1)c}z₀ の帰納法：t = 1 は自明、t = 2 は (C1)、t ≥ 3 では z₀^{t−2}(z₀z₀) ≡ z₀^{t−2}a^c z₀ ≡ a^c z₀^{t−1}（a^c を z₀^{t−2} の左へ）≡ a^c·a^{(t−2)c}z₀。正しい。
- 指数の勘定：a の総数 E = Σ(a^c の塊) + Σ_{z_i∈u} e_i、val(u) = E + tc、結果は a^{E+(t−1)c}z₀ = a^{val(u)−c}z₀。正しい。

### 1.2 補題2.3：正しい

- l u a^P r ≡ l a^{val(u)−c} z₀ a^P r ≡ l a^{f} z₀ r（c | P で a^P を z₀ の左へ）。≡ は分布の一致なので所属が保存される。

## 2. 双子なしの (C1)、および定理C の使える形

### 2.1 補題R（反復するラベルからの崩壊）

**補題R.** L ∈ C₁（有限性は不要）、ω は b を含む語、x, g, y ≥ 0、n ≥ 1、d := g + n とする。三語

  W₁ = a^x ω a^g ω a^y、 W₂ = a^x ω a^{d+y}、 W₃ = a^{x+d} ω a^y

が全て L に入るなら（より一般に、三語が同じ ≡ 類に入り、その分布が空でないなら）

  (i) ω a^g ω ≡ ω a^d、 (ii) a^d ω ≡ ω a^d、

従って **z₀ := ω a^g、c := d は (C1) を満たす**：a^c z₀ ≡ z₀ a^c ≡ z₀ z₀。

*証明.* W₁ ≡ W₂（b 語で文脈 (ε, ε) を共有）。左の a^x を補題2.1 で消し、さらに右の a^y を消して (i)。W₂ ≡ W₃ から同様に ω a^d ≡ a^d ω で (ii)。z₀z₀ = (ωa^gω)a^g ≡ ωa^d a^g = z₀a^d、a^d z₀ = a^dωa^g ≡ ωa^da^g = z₀a^d。□

**使い方.** T（a^N の最短・節点数最小の導出）で、ラベル Y の互いに素な二つの出現が位置 x₁ < x₂ にあり、ω_Y が Y の b 語なら、二つとも ω_Y に替えた語が W₁、左だけ替えた語が W₂、右だけ替えた語が W₃（n = n_Y、g = x₂ − x₁ − n_Y、d = x₂ − x₁）。**双子（B → C C）は g = 0 の特別な場合にすぎない。** Fibonacci 型 F_{k+1} → F_k F_{k−1}, F_k → F_{k−1}F_{k−2} では F_{k−1} が位置 0 と f_k に現れ、z₀ = ω_{k−1}a^{f_{k−2}} ≡ ω_k、c = f_k：

  **ω_k ω_k ≡ ω_k a^{f_k} ≡ a^{f_k} ω_k。**

依頼文 §2 の「型の違う語の間では消去できない」という困難は、**消去を純な語の側（a^x, a^y）だけで行う**ことで避けられる。

### 2.2 定理C\*（定理C を使う形に書き直す）

L は有限、L ∈ C₁、G は L∩Σ⁺ の reduced・ε なしの CFG。b 語 z₀ と整数 g, c ≥ 1（g | c）について

- **(C1′)** a^g z₀ ≡ z₀ a^g、 z₀ z₀ ≡ a^c z₀。

b 語 z が **崩壊する**とは z ≡ a^{e} z₀（e ≥ 0、g | e）であること。価値 v(z) := e + c。純な塊 a^R（g | R）の価値は R。

**補題2.2′.** 崩壊する語と g の倍数の純な塊の積 u が崩壊する語を少なくとも一つ含めば u ≡ a^{val(u)−c} z₀。（証明は補題2.2 と同じ。a^c の代わりに a^g を動かす。）

**補題2.3′.** 語 l, r と V\* について l a^{V\*−c} z₀ r ∈ L とする。上の u について l u r ∈ L ⇔ val(u) = V\*。（証明は補題2.3 と同じ。）

**定理C\*.** さらに、崩壊する語 z_1, …, z_M（価値の部分和が全て異なる）と、崩壊する語と純な塊の固定の積 Q があって Σ v(z_i) + val(Q) = V\* とする。M ≥ 6、λ := max|z_i|、m := |l| + |r| + |Q| + Σ|z_i| なら

  ‖G‖ + 2 ≥ 3^{M/3−1} / ((M+1)(m+1)²(Mλ+1)²)。

*証明.* 定理C の証明で a^P r を Q r に替え、補題2.3 を補題2.3′ に替える。w_π := l z_{π(1)}⋯z_{π(M)} Q r は補題2.3′ から L に入る。入れ替えた語 l u″ Q r も L に入るので val(u″) + val(Q) = V\*。残りは同じ。□

**注意.** (C4) は「上の形の語が一つ L に入る」ことだけを要求し、**符号の価値の和が目標に一致するように Q を後から選べる**。原文の a^P は Q の特別な場合。

## 3. 課題2：定理P（有限の場合の多項式上界）

### 3.1 準備

G を二分化した G′（規則 X → YZ、X → Y、X → a）を取る。K := |V′| ≤ ‖G‖ + 2。

**厚さは増えない：θ(G′) ≤ θ.** G′ の補助規則（ある規則 X → Y₁⋯Y_t の分解の一部）を使う導出は元の規則を使う導出に対応し、前終端の規則 T_a → a を使う導出は a を含む元の規則を使う導出に対応するので、最短の語の長さは元の規則のどれかの値以下。以下 θ は θ(G′) ≤ θ(G) と読む（上界はそのまま θ(G) で成り立つ）。

T を G′ での a^N の最短・節点数最小の導出とする。節点は生成語の長さが > θ なら**重い**。n_X は X の唯一の純な生成語の長さ。重い節点で重い子を持たないものを**種**と呼ぶ。

**補題P1.**
- (a) T の根から葉への道でラベルは反復しない（祖先の部分木を子孫の部分木に替えると、より短い純な語か、節点の少ない導出ができる）。従って道の節点は ≤ K 個。
- (b) 重いラベル X は長さ ≤ θ の b 語 ω_X を持つ（定理D の短い符号の議論：X の節点で使う規則の長さ ≤ θ の成功語の中の X の生成語は、純なら X の二つ目の純な生成語になり補題0 に反する）。
- (c) 種の生成語は ≤ 2θ（二つの子はどちらも軽い）。
- (d) 種を s 個含む部分木の生成語は ≤ s(K+2)θ。（重い節点は全て種への道の上にあり ≤ sK 個。種でない重い節点の軽い子は高々一つで ≤ θ。種は ≤ 2θ。）
- (e) 左から右に隣り合う種の左端の差は ≤ 2Kθ。（二つの種の間の文字は、最小共通祖先から両者への道にぶら下がる子の生成語で、重い子があればその中に間の種がある。従って全て軽く、各道の節点は ≤ K−1 個。）従って隣り合う K+1 個の種の中に、**同じラベルで左端の差が d ≤ 2K²θ の二つ**がある。

### 3.2 定理P

**定理P.** L は有限、L ∈ C₁、G は L∩Σ⁺ の reduced・ε なしの CFG で厚さ θ、K = |V′| ≤ ‖G‖ + 2 とする。λ := 5K²θ、B₁ := 14K²θ とおく。このとき

- N ≤ K(K+2)θ、または
- M ≥ 1 + log₆(N/(15B₁)) を満たす整数 M ≥ 6 について 3^{M/3−1} ≤ K(M+1)(m+1)²(Mλ+1)²、m := (5K³ + M + 4)λ、
- または N < 15B₁·6^5。

従って（6^M = (3^{M/3})^{3 log₃ 6}、3 log₃ 6 ≈ 4.89、M ≤ log₂N を吸収して）**N ≤ C·(‖G‖+2)^{76} θ^{21}**（C は絶対定数、指数は最適化していない）。**ランク r は現れない。**

*証明.* T の根が種を ≤ K 個しか含まなければ (d) から N ≤ K(K+2)θ。以下そうでないとする。

**(P1) 重い道と基底.** X₀ := 根、X_{i+1} := X_i の子のうち生成語の長い方（X_i が種でない限り重い）。n_{X_i} ≤ 2 n_{X_{i+1}}。i\* を「X_i の部分木が種を ≥ K+1 個含む」最大の i とする。X_{i\*+1} の部分木の種は ≤ K 個なので (d) から n_{X_{i\*+1}} ≤ K(K+2)θ、B₀ := n_{X_{i\*}} ≤ 2K(K+2)θ。X_{i\*} の部分木の種は T の種の順序で連続した区間なので、(e) から同じラベル Y の種 u₁, u₂ が位置 x₁ < x₂（d := x₂ − x₁ ≤ 2K²θ）にある。種どうしは互いに素なので g₀ := d − n_Y ≥ 0。補題R（W₁, W₂, W₃ は T から得られる L の語）から

  z₀ := ω_Y a^{g₀}、 c := d、 g := d は (C1′) を満たす。

**(P2) 詰め物つきの符号.** 0 ≤ i ≤ i\* について u₁ は X_i の部分木の中にある。その中での u₁ の左右の純な長さを (L_i, R_i) とすると、C.0 から ω_{X_i} ≡ a^{L_i} ω_Y a^{R_i}。s′_i, s_i ∈ [0, d) を d | L_i + s′_i、R_i + s_i ≡ g₀ (mod d) となるように取り

  ẑ_i := a^{s′_i} ω_{X_i} a^{s_i}

とおく。R_i + s_i ≥ 0 > g₀ − d なので R_i + s_i = g₀ + κd（κ ≥ 0）で、z₀ a^{κd} ≡ a^{κd} z₀ から

  ẑ_i ≡ a^{L_i + s′_i + κd} z₀、 e_i := L_i + s′_i + κd（d の倍数、≥ 0）。

ẑ_i は崩壊し、価値は v_i = e_i + d = n_{X_i} + s_i + s′_i（L_i + R_i = n_{X_i} − n_Y、d − g₀ = n_Y を使う）。|ẑ_i| ≤ θ + 2d ≤ λ。また

  v_i ≤ n_{X_i} + 2d ≤ 2 n_{X_{i+1}} + 2d ≤ 2 v_{i+1} + 2d。 (★)

**(P3) 目標.** a^{x₁} ω_Y a^{y₁} ∈ L（u₁ を ω_Y に替えた語）で y₁ = g₀ + n_Y + y₂ ≥ g₀。y₁ − g₀ = qd + ρ（0 ≤ ρ < d）、x₁ + qd = e\* + ρ′（d | e\*、0 ≤ ρ′ < d）とすると a^{x₁}ω_Ya^{y₁} = a^{x₁} z₀ a^{qd} a^ρ ≡ a^{ρ′} a^{e\*} z₀ a^ρ。従って l := a^{ρ′}、r := a^ρ、**V\* := e\* + c = N − ρ − ρ′** で補題2.3′ の仮定が成り立つ（|l|, |r| < d）。

**(P4) 並べ替える符号（超増加）.** 道を上へたどり、v_i ≥ d となる最初の添字から始める（その値は (★) から ≤ max(B₀ + 2d, 4d) ≤ B₀ + 4d ≤ B₁）。以後、現在の値の 2 倍を初めて超える値を次に取る。(★) と現在の値 ≥ d から、次の値は ≤ 6 × 現在の値。V\*/2 以下の値だけを取る。どの値も前の値の 2 倍を超えるので部分和は全て異なり、和は最後の値の 2 倍未満で ≤ V\*。止まったとき最後の値は > V\*/12 なので、取った個数 M は B₁ 6^{M−1} > V\*/12 を満たす。V\* ≥ N − 2d から M ≥ 1 + log₆(N/(15B₁))（N ≥ 15B₁ のとき。そうでなければ結論の三番目）。

**(P5) 埋め草 Q（貪欲）.** X := V\* − Σ(取った価値) ≥ 0 は d の倍数。i = 0, 1, …, i\* の順に q_i := ⌊X/v_i⌋ 個の ẑ_i を Q に加え X を減らす。X ≤ V\* ≤ N ≤ v₀ から q₀ ≤ 1。i ≥ 1 では直前に X < v_{i−1} なので (★) と v_i > θ から q_i ≤ 2 + 2d/θ ≤ 2 + 4K²。最後の余り X < v_{i\*} ≤ B₀ + 2d は d の倍数なので純な塊 a^X として Q に加える。i\* ≤ K − 1 なので |Q| ≤ (1 + (K−1)(2+4K²))λ + B₁ ≤ 5K³λ + 3λ。val(Q) + Σ = V\*。

**(P6) 計数.** 定理C\* を z_1, …, z_M（P4 で取った ẑ）、Q、l, r に使う。m ≤ 2d + |Q| + Mλ ≤ (5K³ + M + 4)λ。M ≥ 6 なら主張の不等式。最後の評価は M ≤ 3 + 3 log₃(K(M+1)(m+1)²(Mλ+1)²) と N ≤ 15B₁·6^M から。∎

### 3.3 定理P について

- **問題C への答え**：肯定。ただし符号は T の重いラベルの b 語そのものではなく、**長さ < 2d の純な詰め物をつけた語**で、基底は ω_Y a^{g₀}。取れる個数は Θ(log N)。
- **有限性を使う箇所**：補題0 だけ（純な生成語の一意性、短い b 語、補題2.3′）。補題R・補題2.1 は有限性を使わない。
- **型付けの使い方**：s_{U,2} の C₁ は、消去（純な塊の消去は b 語どうし）と C.0 でだけ使う。純な語と b 語を比べる場面はない。
- **命題S（刻み）も定理1（等差列）も使わない。** 刻みの代わりに二つの出現の差 d そのものを可換性の単位にし、d が小さい（≤ 2K²θ）ことは種の鳩の巣から得る。
- 二重化の鎖・Fibonacci 型・t_j 鎖は全て特別な場合。下の系はより良い定数を与える。

### 3.4 系F（Fibonacci 型の鎖、課題2 (a)）

**系F.** L 有限、L ∈ C₁、G は厚さ θ。非終端 F_k, …, F_n と規則 F_j → F_{j−1} F_{j−2}（k+2 ≤ j ≤ n）があり、純な長さ f_k, f_{k+1} > θ とする（f_j = f_{j−1} + f_{j−2}）。b := k+2、M := ⌊(n − b)/2⌋ ≥ 6 なら

  ‖G‖ + 2 ≥ 3^{M/3−1} / ((M+1)((M+2)θ)²(Mθ+1)²)。

従って Fibonacci 型の鎖も O(log(‖G‖θ)) 段まで。

*証明.* g := gcd(f_k, f_{k+1}) は全ての f_j を割る。ω_j を F_j の短い b 語とする（補題P1 (b) と同じ議論、k ≤ j ≤ n）。C.0 から

  (R1) ω_j ≡ ω_{j−1} a^{f_{j−2}} ≡ a^{f_{j−1}} ω_{j−2}（k+2 ≤ j ≤ n）。

*a^g との可換性.* F_{b+2} → F_{b+1}F_b、F_{b+1} → F_bF_{b−1} で F_b は位置 0 と f_{b+1} にあるので a^{f_{b+1}}ω_b ≡ ω_b a^{f_{b+1}}。F_{b+3} では F_b が位置 0 と f_{b+2} にあり、ω_b a^{2f_{b+1}} ≡ a^{f_{b+2}} ω_b a^{f_{b−1}}（2f_{b+1} = f_{b+2} + f_{b−1}）。右の a^{f_{b−1}} を消して a^{f_{b+2}}ω_b ≡ ω_b a^{f_{b+2}}。**互除法（補題E）**：b 語 ω が a^p, a^q と可換で a^{max(p,q)}ω の分布が空でなければ a^{gcd(p,q)} とも可換（p < q なら a^p(a^{q−p}ω) = a^qω ≡ ωa^q ≡ a^p(ωa^{q−p}) から左の a^p を消す。a^{q−p}ω は a^qω の接尾辞なので分布は空でない）。gcd(f_{b+1}, f_{b+2}) = g なので a^g ω_b ≡ ω_b a^g。
*(C1′).* z₀ := ω_b、c := f_b（g | c）。補題R（Y = F_{b−1}、F_{b+1} の中の二つの出現）から ω_bω_b ≡ ω_b a^{f_b}、これに a^g の可換性を合わせる。
*崩壊.* ω_{b+1} ≡ ω_b a^{f_{b−1}} ≡ a^{f_{b−1}} ω_b、(R1) の右の形を繰り返して ω_{b+2i−1} ≡ a^{f_{b+2i−1} − f_b} ω_b（f_{b+2}+f_{b+4}+⋯+f_{b+2i−2} = f_{b+2i−1} − f_{b+1}）。同様に ω_{b+2M} ≡ a^{f_{b+2M} − f_b} ω_b。
*符号と目標.* z_i := ω_{b+2i−1}（i = 1..M）、価値 f_{b+2i−1}（超増加：前の和は f_{b+2i−2} − f_b）。Σv_i = f_{b+2M} − f_b。Q := ω_b（価値 f_b）。(l, r) は F_{b+2M} の長さ ≤ θ−1 の成功文脈で、V\* = f_{b+2M}。定理C\* から（λ ≤ θ、m ≤ (M+2)θ − 1）。□

## 4. 課題3：系D′（E_j → E_{j−1}^{t_j}）

**系D′.** 規則 E_j → E_{j−1}^{t_j}（2 ≤ t_j ≤ r、k < j ≤ n）、E_k は純な a^c（c > θ）を持つとする。M := n − k ≥ 6 なら

  ‖G‖ + 2 ≥ 3^{M/3−1} / ((M+1)((r−1)M+2)²θ²(Mθ+1)²)。

*証明.* f_j := c Π_{i ≤ j} t_i。E_{k+1} の生成語で二つの E_k を ω_k にした語と一つだけにした語から ω_kω_k a^{(t−2)c} ≡ ω_k a^{(t−1)c}、右の a^{(t−2)c} を消して ω_kω_k ≡ ω_k a^c。同様に a^cω_k ≡ ω_ka^c（補題R の t ≥ 3 版。t = 2 なら消去は不要）。g := c。ω_j ≡ ω_{j−1}a^{(t_j−1)f_{j−1}} から ω_j ≡ a^{f_j − c} ω_k。z_i := ω_{k+i−1}（i = 1..M）、価値 f_{k+i−1}。t ≥ 2 なので超増加。f_n = f_k + Σ_{i=k}^{n−1}(t_{i+1} − 1)f_i なので、Q := ω_k Π_i ω_i^{t_{i+1}−2}（符号 ≤ 1 + (r−2)M 個）で Σv + val(Q) = f_n = V\*。m ≤ (θ − 1) + (1 + (r−1)M)θ。定理C\* から。□
