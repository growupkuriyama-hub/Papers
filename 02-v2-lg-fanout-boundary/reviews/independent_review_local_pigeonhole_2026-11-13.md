# 独立検証メモ（2026-11-13）：局所鳩の巣法の補題2(a)に対する反例

対象：`claude_fanout2_local_pigeonhole_2026-11-13.md`、§3.2（補題2）およびその依存先 §3.3–3.4。

## 判定

**補題2(a)「最小の型付き生成組の導出木で、自由節点の同一路上では非終端ラベルがすべて異なる」は現行の reduced good MCFG の定義の下で偽。** これを用いた補題2(b)、補題3(a)(b)、定理1の上界は、**提示された証明のままでは未確立**である。ただし、この反例は定理1自体の否定ではない。定理1を修復できる可能性は残る。

### 反例文法（fan-out 2、rank 1、reduced good）

終端アルファベットは `Σ={p,x,b,y}`。`S` の fan-out は1、`A,B` の fan-out は2とする。規則：

```text
A -> (x, y)
A -> (p, ξ1^1 b ξ1^2)(A)
B -> (p ξ1^1 p, x b y ξ1^2 x b y)(A)
S -> (a ξ1^1)(S)         (各 a∈Σ)
S -> (a)                 (各 a∈Σ)
S -> (ξ1^1 b ξ1^2)(B)
```

いずれも ε-free、nondeleting、nonpermuting、nonmerging（同一子の隣接成分は `b` で分離）である。全非終端は reachable、productive。

`S -> aS | a` だけで `Σ+` の全語が生成できるので、`L(G)=Σ+`。従って段数 `t=1`、`Q=N^Σ \ {0}` とすれば `L∈𝒩_st`。また `L` は内容型付け（実際にはどの型付けでも）fan-out 2 のタプル代入可能性を満たす。したがって報告の補題の言語・文法仮定を満たす。

`A` の再帰をちょうど `n` 回使った生成組を `A(n)` と書くと：

```text
A(0) = (x, y)
A(1) = (p, xby)
A(2) = (p, pbxby)
```

対応する `B(n)` は：

```text
B(0) = (pxp, xbyyxby)          成分内容=({p,x},{x,b,y})
B(1) = (ppp, xbyxbyxby)        成分内容=({p},{x,b,y})
B(2) = (ppp, xbypbxbyxby)     成分内容=({p},{x,b,y,p})
```

`n>=2` では第2成分に必ず `p` が現れる。

型 `T=({p},{x,b,y})` の `B_T` を考える。`B(1)` のみがこの型を持つので、**`B(1)` の導出は `L_{B_T}` の中で節点数最小**である。この導出木には `B -> A -> A` という路がある。

`B(1)=(ppp,xbyxbyxby)` における最初・最後の文字の印は、0起点で

```text
第1成分: p の位置 0,2
第2成分: x の位置 0,6、b の位置 1,7、y の位置 2,8
```

一方、外側 `A` の生成組の位置は第1成分の `p` 位置1、第2成分の `xby` 位置3,4,5だけ。内側 `A` は第2成分の位置3と5だけ。どちらの `A` も印を含まないから **自由節点**である。

したがって、最小導出の一本の道に**同じラベル `A` の自由な節点が2個**あり、補題2(a)に反する。

### 証明上の誤りの所在

報告§3.2の「同じラベルの先祖節点を子孫で置換した生成組 `x°` は、元の `x` から殻 `pos(ν)\pos(ν')` を消したもの」という主張が、good MCFG では一般に成り立たない。

`A -> (p, ξ1^1 b ξ1^2)(A)` は **good** だが、子の第1成分を親の第2成分に埋め込む。先祖を子孫で置換すると、元々親の第2成分に置かれていた子の `x` が新しい第1成分へ移る。単純な文字削除にはならない。

実際、最小導出 `B(1)` の外側 `A` を子孫 `A(0)` に置換すると `B(0)` となり、第1成分に `x` が新たに入り、型が変わる。したがって最小性に矛盾しない。

nonpermuting は同じ子の変数が **全成分を連結した順序**で並ぶことしか要求せず、各変数が親の同じ番号の成分に留まることは要求しない。nonmerging もこの成分移動を禁じない。

### 結論と修復案

- 補題2(a)はこのままでは引用できない。補題2(b)の骨格サイズ上界 `2kf(kf+1)v` は、この証明から導出できない。
- したがって接頭反鎖のサイズ上界 `|I_j|<=rv` と定理1の `τ` の上界も、示された連鎖では保証されない。
- 定理1自体はなお真かもしれない。各非終端のラベルだけでなく、**子孫の各成分が根のどの成分に置かれるかという配置状態**や、内容型に関する有限状態を含めて反復を数える補修が候補。ただし指数・厚さ・置換可能性を再証明する必要がある。
- 添付の `check_local_pigeonhole_2026-11-13.py` は `build/evaluate` が対応する成分ごとの連結だけを使うので、今回のような子成分の移動をテストしていない。さらにT2の段付きケースでは `member()` が入力をソートするため、非ND入力を排除するテストにもならない。

## 独立検査

`check_free_node_counterexample_2026-11-13.py` では `A(n),B(n)` と内容型を計算し、`B(1)` の印の位置と二つの `A` がともに自由であること、祖先置換で型が変わることを `assert` で検査している。結果は全て成功。無限言語 `Σ+` の代入可能性と規則のgood性は上記の手計算による。
