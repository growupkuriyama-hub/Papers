## 1. `Comm` の直接確認

`A=N−d_J≥4`, `u=u_J`, `v=v_J` とすると、正のa連再配分により

- `a²u a v a^{A−3}∈L`,
- `a u a²v a^{A−3}∈L`

が得られる。`x=au`, `y=ua`, `E₀=(a, a v a^{A−3})` とすれば、`E₀[x]` と `E₀[y]` がこの二語となり、両方の実内容型は`{a,b,c}`で等しい。従って一穴合同`au≡ua`が成立。`v`の場合も`E₀=(a^{A−3}u a, a)`で成立する。`u,v`内部のaを変形しているわけではない。

## 2. `MS` の交錯・入れ子の確認

交錯Seedの外側a量を`i=N−d_B−d_C≥2`、置換先Jのそれを`i'=N−d_B−d_J`とする。元のBを保持した交換では

```
x  = (u_C, v_C a^i)
y  = (u_J, v_J a^i')
E₀ = (a^(d_B−1), a, ε)
E₁ = (u_B, v_B, ε)
```

と置ける。実型は成分ごとに`({b,c},{a,b,c})`。E₀の二語は各(Single)から`Comm`で構成でき、`E₁[x]=u_B u_C v_B v_C a^i`はSeedからaを末尾へ運んだ語。従って`E₁[y]=u_B u_J v_B v_J a^i'∈L`。

入れ子Seedでは**中央が空になる問題をaで修復**する：

```
x  = (u_C, v_C a^(i−1))
y  = (u_J, v_J a^(i'−1))
E₀ = (a^d_B, a, ε)
E₁ = (u_B, a, v_B)
```

`E₁[x]=u_B u_C a v_C a^(i−1) v_B`は、入れ子Seedから`Comm`により得られ、E₀側の二語も(Single)から得られる。**i,i'≥2**が必要。外側Bの置換には中央`u_Cv_C≠ε`を使える。すべての比較片は非空で、二穴中央も非空。

数値条件の補足：`d_B+d_C≤N−2`から**小さい方の種欠損**を`d_min`とすれば`d_min≤⌊(N−2)/2⌋`。各許容Jの`d_J≤⌊(N−1)/2⌋`と合わせると**`d_min+d_J≤N−2`**。従って最初の交換は入れ子でもa室≥2。**小さい方が入れ子の内側Cであれば、内側Cを保持して先に外側Bを交換する**（`E₁=(ε,u_Cv_C,ε)`）。小さい方が外側Bなら上のE₁を用いて内側Cを先に交換する。この場合分けを元報告は省略気味だが、室条件の正当化には必要。目標2単位で`d_J+d_K≤N−4`なら次の交換はa室≥4。3単位以上の帰納では、全ての中間部分和が最終総欠損以下だからa室≥4。この量化・室の区別を明文化するとMSの帰納は閉じる。

なお、`MS`末尾の「共通成分型なら**任意の語**でも同じ証明」は**過大な射程**。成分内部にaがあれば、外側指数`N−d_B−d_C`は、実際の(Single)/(Seed)の外側a量とは一般に一致しない。`h=δ+内部a数`等を導入して再定式化しなければ、今回の証明は移せない。**aを含まない任意の成分語で、適切な共通型が成り立つ場合**なら同じ構成を使える。

## 3. `Rc` と `CC` の直接確認

ある`l c^m r∈L`があれば、正の指数で`i+j=k+l'≤m−1`のもと、`x=(c^i,c^j)`,`y=(c^k,c^{l'})`, `E₀=(l,c^{m−i−j},r)`が合法。両方の共有語は同じ`l c^m r`だから、任意の非空中央を持つ試験文脈でc連分配を移せる。

受理済み`w=P c^α b^t c^β Q`があり、`α+β≥3`,`m≥α+β+1`なら、Rcで以下を得る（`h=α+β−1`）：

```
w₁=P c^h     b^t c Q
w₂=P c^(h−1) b^t c² Q
x=cb^t, y=b^tc, E₀=(P c^(h−1), c Q)
```

まさに`E₀[x]=w₁`,`E₀[y]=w₂`で、x,yの実型は`{b,c}`。ゆえに**一穴合同**`cb^t≡b^tc`が得られる。`α=β=1`のときは同じ受理語内の別の極大c連`c^γ(γ≥2)`から一文字を移し、`α+β`を3に増やせばよい。これには`m≥γ+2`と相異なるc連の間の非空隔てが必要。

## 4. `RR⇒MX` の構成可能性

許容単位集合からc指数χ≥2を達成する**一つのJ\***を固定する。各許容Jに対し、MSが作る二単位受理語`W_{J*J}`を使う。

- `u_J`側の`b^{p_J}`は、先行する`u_{J*}`末尾の正c連と、自分の`u_J`末尾の正c連に挟まれる。
- `v_J`側の`b^{r_J}`も、交錯では`v_{J*}`/`v_J`のc連、入れ子では`u_J`/`v_J`のc連に挟まれる。
- どちらも両c連が1なら、J*のc指数≥2の**別のc連**が同じ二単位語内にあるので、前節の一文字借用を使える。

周囲の正c連はそれぞれχ以下なので合計≤2χ≤m−1。別のc連から借用する場合もγ≤χ、`m≥2χ+1≥γ+2`が成り立つ。従って全Jについて必要な二種類の`cb^{p_J}≡b^{p_J}c`と`cb^{r_J}≡b^{r_J}c`が成立する。これらは**全一穴文脈で使える**ため、MSで得た任意の二成分語列から、各bブロックを左に寄せ、最終的に

`b^{Σ_J m_J(p_J+r_J)} c^{Σ_J m_J(q_J+s_J)} a^{N−d_m}∈L`

を導ける。二多重集合で同じ**非a総Parikh**なら接頭語が一致。双方`1≤d_m≤N−4`のため末尾a指数は`[4,N−1]`で、異なる欠損では一穴単項剛性`U_shift`に矛盾する。よって**RRと今回のMS前提の範囲ではMXは有効な数学的手証明**と判定する。

注意：単に「Lのどこかに長いc連がある」だけで何でも交換可能になるのではない。**MSが先に生成する実在の挟み込み受理語**が必要である。Fableの報告ではこの役割が§3.5に書かれている。

## 5. 報告書への修正提案と今後

1. **MSの任意語拡張を限定**：少なくともa-free成分と、共通の実型、正の外側budgetを維持する。内部aを認めるなら`δ`と`h`を分けて一般化を別証明する。
2. **OPENの意味を正確化**：「RRなしでは共通受理文脈が存在しない」ではなく、「今回の仮定と方法からは必要な共通宿主を構成できていない」。非存在の全称命題は示されていない。
3. **RRの最小例の定数**：単位`(bc,bc),(bbcc,bbcc)`ではχ=2なので、報告§6の「RRはm≥4」は正確には**m≥5**。ただし最大c連長2の例はRR外という判定に影響しない。
4. **次の最小課題**：RRなし、J=`(bc,bc)`、K=`(bbcc,bbcc)`、交錯実在種、既存の正a室の下で`d_K=2d_J`を直接導くか、厳密なreduced good文法からの反例を構成する。今回の報告はどちらにも未到達。反例があれば単なる有限言語レベルでなく木由来性・型・厚さ・小窓・加法的Seedを示す必要がある。

## 6. 独立の有限構造検査

`audit_fable_round2_local_checks.py`（Python 3標準ライブラリのみ）を新規作成して実行した。**40,840件**の交錯・入れ子2穴Transportテンプレートの文字列一致・型・a指数境界、**3,190件**のCC一穴宿主テンプレートをPASS。さらにa入り任意成分への外側budgetの無条件移植が成り立たないことを会計で確認。これらは**数値上の文脈構造検査**であり、全言語・全MCFGに対する形式証明や一般の代入閉包の検査ではない。Fable自身はPythonを実行していない。

**結論：Fableの今回の核心であるMSおよびRR付きMXは、明示したa-free成分・正欠損・実在Single/Seed・室の下では、独立再構成した手証明として有効と判断する。ただし内部aまでの「任意の語」拡張、RRなしの一般形、正式LG境界は未証明のままである。** GitHubや論文本文は変更していない。
