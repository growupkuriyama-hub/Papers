## 0. 前回確定したこと（再掲）

- 族 F_n：E_0 → a、E_i → l E_{i-1} E_{i-1} | c E_{i-1} r（1 ≤ i ≤ n）、開始 E_n。全ての n で Clark–Eyraud 代入可能（あなたの定理 4.1。スタック解析器と不変量 H による）。
- ‖G_n‖ = 12n+3、θ̄ = 4n−1。末尾の文字による窓の型付け s_{0,1} で τ = t_typ = μ* = n(n+1)+1。
- 記号：C_i = c^i a r^i（L_i の最短語）。U_0 = a、U_i = l C_{i−1} U_{i−1}（末尾が a の L_i の最短語、長さ i(i+1)+1）。
- 補題 2.3：u, v ∈ L_i なら u と v は F_n の構文的合同で等しい。
- s_{0,1} について：n²+3n+4 ≤ cs ≤ (8n−3)(2n²+2n+4)。cs は B_{1,s} の最短の特徴標本の長さ。

作用素 B_{1,s}(K) の定義は原稿の `def:reconstruction` です（観測した因子 x ごとに [x]。Const、Comp（観測した z を、端末の隙間と空でない子に分ける。ファンアウト1では隣り合う子の間の隙間は空でもよい）、Link（同じ型で、K の中に共通の文脈を持つ）、Start）。健全性（`prop:reconstruction-soundness`）により、[x] から導出される y はすべて x と型付き合同です（同じ型で、分布が等しい）。

## 1. Claude の観察（今回の出発点）

各段 j（2 ≤ j ≤ n）について、「左の子が a で終わる L_{j−1} の語である l の節点」を、**文法 G_n の構造どおりに**含む語の集まりを考えます。こうした語の集まりは、全長が必ず Ω(n³) になります。理由は次のとおりです。

- 段 j の出現は、a で終わる L_{j−1} の語を左の子に持つので、長さ (j−1)j+1 以上の部分を含みます。
- 異なる段の出現が文字を共有できるのは、入れ子の鎖になる場合だけです。
- 鎖一本でも、各段で新しい a で終わる語が要るので、Σ_j j² ≈ n³/3 かかります。

したがって残る問いは次の一点です。**B_{1,s} は、このような「文法どおりの出現」を本当に必要とするか。** B は文法と違う切り方（Comp の分解や Link の組み方）で同じ語を導出できるかもしれません。

## 2. 調べてほしいこと

**R1（本題：どちらかを証明する）**
s = s_{0,1}、作用素 B_{1,s}（と B_{1,s}^{≤2}）について、次のどちらかを証明してください。

**(a) 下界 cs = Ω(n³)。** 提案する道筋は次のとおりです。必要ならもっと良い道を探してください。
1. F_n の因子の**型付き合同類**を、スタック解析器の部分変換で分類する。前回の定理 4.1 の強い主張から、合同類は「同じスタック変換を行う」ことで決まるはずです。この同値性（必要十分か）をまず確かめてください。
2. 型 A（末尾 a）で、「E_{j−1} を完全に読み切る」変換を含む合同類について、その全ての成員が長さ Ω(j²) であることを示す。
3. 段 j で左の子が a で終わる語 w を B(K) が導出するとき、導出のどこかに、そのような合同類に属する yield を持つ節点が必ずあることを示す。Comp の分解は文法の切り方と一致しなくてよい点に注意してください。
4. その節点を支える観測 x（K の語の因子）が段 j ごとに要り、異なる j の x が全長で Σ j² を共有できないことを示す。

**(b) 上界 cs = O(n²)。** 文法と違う切り方を使い、長さ O(n²) の特徴標本を具体的に構成し、特徴標本であることを証明してください。

どちらも完結しない場合は、どこで止まったかを正確に書き、小さい n（n ≤ 4）で手計算か短いスクリプトで確かめられる中間命題を提示してください（重い全数探索は DeepSeek が別に行っているので不要です）。

**R2（作用素の範囲）**
(a) が証明できた場合、その下界が「クラス C_{1,s} 全体に特徴標本を持つ集合駆動作用素」にも伸びるかを調べてください。伸びないなら、B_{1,s} に限る理由を書いてください（例：型を削除した言語はクラスに入るが、「段 j の出現を持つ語を削除した言語」はクラスに入らない、など）。

**R3（一般化の見通し）**
(a) が成り立つ場合、次を調べてください。
- これが原稿の定理A の上界 O(‖G‖²θ̄) が窓の型付けで鋭いことを示すか。‖G_n‖ = Θ(n)、θ̄ = Θ(n) なので、n³ = Θ(‖G‖²θ̄) です。
- 自明な型付けでは Θ(‖G‖θ̄)（原稿 `cor:trivial-exact`）なので、「自明でない窓の型付けは、自明な型付けより一段高くつく」という分離の形で述べられるか。
- ファンアウト f ≥ 2 へ持ち上げられるか（例えば、各成分に F_n を置く族）。

**R4（前回の小さな補足）**
前回の補題 3.1 は「E_i 一個から始めた解析」の形で書かれ、補題 3.2 では下に ψ があるスタックに使っています。H を η の部分だけで計算すれば済むことを、一段落で明記してください。
