## 1. 背景：区別の補題で残っている道

区別の補題（`lem:distinguishing`）：
> L' ⊊ L がともに C_{f,s} に入るなら、L の特徴標本（B^{≤r}_{f,s}、B_{f,s}、および L と L' の両方に特徴標本を持つ集合駆動作用素について）は L∖L' の語を含む。

部分標的 L' の作り方と、今わかっていることは次のとおりです。

| L' の作り方 | L∖L' の最短の語 | 根拠 |
|---|---|---|
| 可換群の篩い L ∩ φ⁻¹(γ+H) | ≤ θ̄_G（全ファンアウト、全型付け） | `prop:abelian-filter-short` |
| 型の集合 L ∩ s⁻¹(Acc) | 一つの型の削除と同じ値（下の注） | `lem:type-deletion` |
| 一つの型の削除 L∖s⁻¹(m) | ファンアウト1で指数（族あり）、ファンアウト2で未解決 | `prop:three-letter-family`、`prop:unique-word-route` |

**注（Claude による確認、使う前に確かめてください）**：L∖(L ∩ s⁻¹(Acc)) = ∪_{m∉Acc} (L ∩ s⁻¹(m)) なので、その最短の語の長さは m ∉ Acc での型 m の最短の語の長さの最小値です。Acc = 𝖲∖{m} と選べば一つの型の削除になります。よって s⁻¹(Acc) の道で得られる値の最大は、一つの型の削除で得られる値の最大と一致します。

型の削除の道には、ファンアウト2で強い制約があります（5形、長い他の語、ζ 型の文字の多い語、冪の移行、挿入なし）。したがって、型の削除を使わずに否定の答えを出すには、**可換群の篩いでも型の集合でも書けない部分標的 L'** が要ります。今回はこの道を調べてください。

次の二点に注意してください。
- **L' 自身は小さい文法を持たなくてよい。** 区別の補題で要るのは L' ∈ C_{f,s} だけです（`lem:distinguishing` の証明は `prop:reconstruction-soundness` を L' に適用するだけ）。‖·‖ と θ̄ が多項式であるべきなのは L の表示 G だけです。
- LG の型付けでは定理A(i) により全てが多項式なので、意味があるのは LG の外です。二文字の内容型付けではファンアウト ≥ 2 で多項式です（`cor:two-letter-semilattice`）。したがって三文字以上が要ります。

## 2. 問い

型付け s_U : {a, b, c}⁺ → U₁、a, b ↦ 1、c ↦ ζ を第一候補とします（三文字の内容型付け c_Σ でも構いません）。ファンアウト f = 2、ランク r ≥ 2 です。

> **C_{2,s} の標的の族 L_n、その reduced good な表示 G_n（‖G_n‖, θ̄_{G_n} が n の多項式）、および L'_n ⊊ L_n で L'_n ∈ C_{2,s} となるものがあって、L_n∖L'_n の最短の語の長さが n について超多項式になるか。ただし L'_n は可換群の篩いでも、型の集合との交わりでもないものとする。**

**意味**：あれば、全ての特徴標本が超多項式に長くなり、`op:fanout-two` は否定で解決します（`prop:sl-reduction` により、LG がファンアウト2でも境界になる）。

## 3. 調べてほしいこと（優先順）

**E1（どの篩いが代入可能性を保つか：分類）**
- 正則な篩い R（有限モノイド M への準同型 ψ : Σ* → M と受理集合 F ⊆ M で R = ψ⁻¹(F)）で、次の性質を持つものを分類してください。
  > 全ての L ∈ C_{2,s_U} について L ∩ R ∈ C_{2,s_U}（「普遍な篩い」と呼ぶ）。
- `prop:abelian-coset-filter` の証明で可換性が効く理由は、φ(E[x]) が φ(E) と Σφ(x_i) だけで決まることです。可換でない群や、群でないモノイドでは、二穴の文脈で値が穴の位置と並び方に依存します。
- 予想（未確認）：普遍な篩いは、型の集合 s⁻¹(Acc) と可換群の剰余類の、交わりと有限の和で作れるものに限る。これを証明または反証してください。
  - 反証なら、新しい普遍な篩いを明示し、その篩いで L∖L' の最短の語が θ̄_G で抑えられるかを調べてください。
  - 証明なら、普遍な篩いの道は「型の削除」と「可換群」の組合せに帰着します。
- **組合せの場合に注意**：L ∩ s⁻¹(m) ∩ φ⁻¹(γ+H) の差集合には「型 m の語で篩いを通らないもの」が入ります。これは `prop:abelian-filter-short` を L ∩ s⁻¹(m) の文法に適用すれば抑えられますが、その文法の厚さは希少な型のために大きくなりえます。この組合せの道が、型の削除の道より強い下界を出せるかどうかを明示してください。

**E2（標的に依存する部分標的：本題）**
- 普遍でない篩い、すなわち特定の L に対してだけ代入可能性を保つ L' を作ってください。候補の考え方（使う前に確かめてください）：
  - (a) **c の位置や並び方**：「c がどのブロックにあるか」「a と b の並びに対して c が左か右か」など、Parikh 像でも型でも見えない条件で L を分ける。
  - (b) **部分文法の言語**：L の別の good な文法 G''（小さくなくてよい）の規則を一部削った文法の言語を L' とする。
    - 注意：G'' から規則 R を削ったとき、L∖L' の語は「全ての導出が削った規則を使う語」です。G'' が曖昧なら、R を使う最短の語が他の導出を持つことがあり、L∖L' の最短の語は θ_{G''}(R) で抑えられるとは限りません。
    - G'' が曖昧でない場合、および L' = L(G'' の部分文法) の一般の場合に、最短の語の長さを θ̄_{G''} などで抑えられるかを調べてください。抑えられるなら、この道では G'' が厚い（θ̄_{G''} が超多項式）ことが必要条件になります。
  - (c) **前回までの族の見直し**：三文字の倍増族、c で近道する倍増族、ブロックの族 {aᵏ, bc}^m。これらで L 自身の代入可能性が壊れた理由（`thm:doubling-no-lift`、前回の報告 §4）を確かめ、L を「壊れない部分」に縮めた族と、その中の部分標的を考える。
- 必ず確かめてほしいこと：
  - L_n と L'_n の両方が C_{2,s} に入ること。全ての arity d ∈ {1, 2} について、代入可能性を省略せずに証明してください。L'_n は普遍な篩いではないので、自動的には入りません。
  - L_n の reduced good な表示 G_n の、ファンアウト、ランク、‖G_n‖、θ̄_{G_n} の正確な値。
  - L_n∖L'_n の最短の語の長さ。
  - 型の削除の道の制約（`lem:unique-word-rigid`、`prop:unique-two-letter-shapes`、`lem:unique-word-gap`）を受けない理由。
- 計算による探索を強く勧めます。小さい n での (1,s)・(2,s)-代入可能性の全数検査を、Python 3 の標準ライブラリだけで書き、全文を載せてください（Windows の `py -3 script.py` で動く形）。前回の報告の `exhaustive` 関数を再利用して構いません。有限の検査の結果から、無限の族の代入可能性を推定しないでください。

**E3（必要条件：E2 が失敗する場合）**
- ファンアウト2、s_U で、L' ⊊ L がともに C_{2,s_U} に入るときに L∖L' が満たすべき構造を調べてください。例えば：
  - L' の代入可能性から、L∖L' は「同じ型の組を共通の文脈で入れ替える操作」についてどう閉じるか。
  - L の短い語（長さ ≤ θ̄_G）がすべて L' に入るとき、L の導出で規則の適用を一つずつ置き換えて、長い語も L' に入ることを示せるか。示せない場合、どの置き換えで止まるか。
- 次の形の上界を、条件付きでよいので証明できるか調べてください。
  > ファンアウト2、s_U。L ∈ C_{2,s_U}、L' ⊊ L、L' ∈ C_{2,s_U} なら、L∖L' に長さ poly(‖G‖, θ̄_G) 以下の語がある。
- ファンアウト1との違いを明示してください。ファンアウト1では、型の削除の道で指数の下界が出ます（三文字の倍増族）。どの議論がファンアウト1で壊れ、ファンアウト2で生き残るかを書いてください。

**E4（整理）**
- 部分標的の作り方ごとに、ファンアウト1とファンアウト2で、L∖L' の最短の語の長さがどうなるかの表を作ってください。行は少なくとも「可換群の篩い」「型の削除」「型と可換群の組合せ」「E1 の新しい普遍な篩い（あれば）」「部分文法」「位置や並び方による部分標的」「一般の L'」。各欄は「指数（族あり）」「多項式（証明）」「未解決」のどれかです。
- 結果が `op:S1`、`op:fanout-two`、`prop:unique-word-route`、`prop:abelian-filter-short` の後の段落にどう効くかも書いてください。

## 4. 守ってほしいこと

- 冒頭に、主張ごとに判定（証明済み／反証／観察／未解決）と根拠の節を書いた表を置いてください。
- 下界には、どの作用素について成り立つか（B^{≤r}_{2,s}、B_{2,s}、L と L' の両方に特徴標本を持つ集合駆動作用素）、ファンアウト、ランク、アルファベットの条件を明記してください。
- 代入可能性は全ての arity d ≤ f について、省略せずに証明してください。計算だけで済ませないでください。arity 2 では、穴の間の区切りが空でない文脈だけを考えることに注意してください（`def:tuple-substitutable`）。
- 主張は、証明した範囲を超えないでください。「最大の特徴標本」という言い方はしないでください。「境界がファンアウトで動く」とは、証明できた場合以外は書かないでください。
