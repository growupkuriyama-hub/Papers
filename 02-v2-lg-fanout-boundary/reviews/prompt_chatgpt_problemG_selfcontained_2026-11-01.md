## 1. 定義

- Σ = {a, b}。H は有限群、φ: Σ* → H は全射な準同型（φ(a), φ(b) が H を生成する）。L := {w ∈ Σ⁺ : φ(w) = 1}（空でない語で、値が単位元のもの）。
- 文脈自由文法 G = (V, Σ, P, S) は次を満たすとする（「reduced good」）：全ての非終端が開始記号から到達でき、かつ終端の語を生成する。空語を生成する規則は無い。規則の右辺の非終端の数（ランク）は r 以下（r ≥ 2 は固定）。L(G) = L。
- **大きさ** ‖G‖ := |V| + Σ_{規則 A → α} (1 + |α|)（右辺の記号の数を数える）。
- **規則の厚さ** θ_G(R) := 規則 R を少なくとも一度使う、G の成功した導出（開始記号から終端の語まで）で得られる語の、最短の長さ。θ̄_G := max{1, max_R θ_G(R)}。
- 事実（自分で確かめてよい）：各非終端 X の生成する語は、全て同じ値 φ(·) を持つ。理由：X を使う成功した導出から X の部分木を一つ取り除いた文脈を u□v とすると、X の生成する任意の語 y について φ(u)φ(y)φ(v) = 1 なので φ(y) は一つに決まる。

## 2. 問題G

> **多項式 p（r だけに依存）があって、全ての有限群 H、全射 φ、L の全ての文法 G について、φ(a) の位数 ord(φ(a)) ≤ p(‖G‖, θ̄_G) となるか。**

**意味**：L の中で a だけの最短の語は a^N（N = ord(φ(a))）です。文法の大きさだけなら、倍増（A_i → A_{i−1}A_{i−1}）で O(log N) にできますが、そのとき a^N を作る規則の厚さは N 以上になります。b を含む短い語で全ての規則を「使える」ようにしつつ、文法を小さく保てるか、が問題です。

- 問題G が**否定**なら（位数 N が超多項式なのに ‖G‖ と θ̄_G が多項式の族がある）、ある学習理論の未解決問題が否定で解けます（ファンアウト1の特徴データの超多項式の下界）。
- 問題G が肯定なら、その未解決問題の肯定の証明の一部になります。

## 3. 既に分かっていること（使う前に確かめてください）

1. **値付き文法への帰着（模擬定理）**：V_H ⊆ H、1, φ(a), φ(b) ∈ V_H とし、非終端 X_g（g ∈ V_H）、開始記号 X_1、規則 X_g → x（φ(x) = g）と X_g → X_{h_1}⋯X_{h_k}（2 ≤ k ≤ r、h_i ∈ V_H、h_1⋯h_k = g）を全て持つ文法を G_{V_H} とする。任意の文法 G（上の条件）から、各規則の右辺を左から読んだ「接頭辞の値」を全て集めると、|V_H| ≤ ‖G‖ + 2 で L(G_{V_H}) = L となる V_H が作れる。従って **‖G‖ ≥ min{|V_H| : L(G_{V_H}) = L} − 2**。
2. **計算の観察**：H_n := Z/(2ⁿ − 1) ⋊ Z/n（アフィン写像 x ↦ 2^j x + c、語は左から作用）、φ(a) = (x ↦ x+1)、φ(b) = (x ↦ 2x) では、N = 2ⁿ − 1、a^{2^j} = b^{n−j} a b^j（長さ n+1）。ランク2で、L(G_{V_H}) = L となる最小の |V_H| は n = 2, 3 で 5, 13（厳密）、n = 4, 5, 6 で 37, 87, 212 以下（貪欲法）、つまり |H_n| の約 0.56〜0.62 倍。厚さは 7〜50 と小さい。
3. **可換群**：H = Z/N、φ(a) = 1、φ(b) = λ では、|V_H| は小さい（λ = 1 で 5, 7, 8, 13）が、厚さが N/3 以上（観察）。

## 4. 調べてほしいこと（優先順）

**Q1（可換の場合の証明）**：H が可換なら、ord(φ(a)) ≤ p(θ̄_G)（大きさによらず、厚さだけの多項式）が成り立つことを証明してください。目安は ord(φ(a)) = O(θ̄_G²) か O(θ̄_G)。ヒント：可換なら値は Parikh ベクトル (|w|_a, |w|_b) で決まる。a^N の節点数最小の導出で、重い節点（生成する語の長さ > θ̄）を同じ非終端の短い語に差し替えると、値は同じで、b の個数が増え a の個数が減る。値が一致することから、短い語の Parikh ベクトルの差が格子 {(x, y) : x + λ y ≡ 0 mod N} に入る。短い語の Parikh ベクトルは (θ̄+1)² 通りしかない。

**Q2（H_n の下界）**：H_n について、min{|V_H| : L(G_{V_H}) = L} ≥ c|H_n|（c > 0 は n によらない）、あるいは少なくとも ≥ 2^{εn} を証明してください。これができれば、模擬定理により ‖G‖ ≥ 2^{εn} − 2 となり、H_n では問題G が肯定（N ≤ ‖G‖^{1/ε} 程度）になります。ヒント：ランク2では、値 g の語 w が「分割できない」（どの分割 w = w_1 w_2 でも φ(w_1) ∉ V_H か φ(w_2) ∉ V_H）ことは、Cayley グラフ（辺 x → x·φ(a)、x → x·φ(b)）の、集合 H ∖ (V_H ∩ g V_H⁻¹) の中を通る路の存在と同値です。V_H が小さければ、そのような路（＝分割できない語）が作れることを示せばよい。

**Q3（一般の場合）**：問題G そのものに肯定・否定の手がかりがあれば。例えば、全ての元が短い語で書ける（直径が小さい）群では、厚さは小さくできるが大きさが |H| 程度要る、という二択が一般に成り立つか（ord(φ(a)) ≤ poly(‖G‖) か ≤ poly(θ̄_G) のどちらか）。
