## 1. 課題1：定理P∞-c の検査

反例を探すつもりで、`claude_S1_content` §2 を一行ずつ読んだ。

### 1.1 補題S′：正しい

主張：z の分布が空でなく、p ≥ 1 で a^pz ≡ z なら N ≤ p。

- (l, r) を z の文脈とする。D(a^pz) = D(z) から la^pzr ∈ L。a^{2p}z = a^p(a^pz) ≡ a^pz ≡ z から la^{2p}zr ∈ L。
- 文脈 (la^{p−1}, zr) に a を入れると la^pzr、a^{1+p} を入れると la^{2p}zr。どちらも L に入る。
- a, a^{1+p} はどちらも空でなく型 {a}。C_{1,c}（s_{U,2} でも同じ）から D(a) = D(a^{1+p})。
- N ≥ p+1 なら、a^N の中の a^{1+p} は文脈 (a^{N−1−p}, ε) を持つ。従って a^{N−1−p}·a = a^{N−p} ∈ L∩Σ⁺ となり、最短性に反する。

「強すぎる」ように見えるが、要るのは「純な語どうしが一つの文脈を共有すれば同値」だけで、正しい。z が b を含むことも使わない。

**課題2 で使う形（補題S′₀）**：上の前半だけで **a ≡_{L,c} a^{1+p}** が出る（最短性は使わない）。従って、分布が空でない全ての純な語 a^k について、k ≡ k′ (mod p)、1 ≤ k′ ≤ p となる k′ で a^k ≡_{L,c} a^{k′}。

### 1.2 補題R^c：正しい

記号：W₁ = a^xωa^{g₀}ωa^y、W₂ = a^xωa^{d+y}、W₃ = a^{x+d}ωa^y。悪い場合は g₀ = 0、ω ∈ b⁺、d = n_Y、z₀ := ωa^d、c := 2d。

- **x ≥ 1 または y ≥ 1**：x = y = g₀ = 0 なら、a^N は二つの種 u₁, u₂ の生成語の連接になる。種は互いに素なので、根の種はちょうど二つ。前提は「根の種 > K」。
  - K ≥ 2 なら矛盾する。
  - **補足**：K = 1 なら、P1 (a)（道でラベルが反復しない）から木は一節点で、重い節点がない。従って第一の場合（N ≤ K(K+2)θ）に入る。原文の「> K ≥ 2」はこの一行で正当化される。
- **W₁ が混合**：x + y ≥ 1 から。W₂, W₃ は a^d（d ≥ 1）と ω を含むので混合。三語は文脈 (ε, ε) を共有し ≡。
- **(ii) a^dω ≡ ωa^d**：
  - W₂ ≡ W₃ から左の a^x を消す。残りは ωa^{d+y} と a^dωa^y で、どちらも混合。zx = W₂ ∈ L。
  - 次に右の a^y を消す。残りは ωa^d と a^dω で、どちらも混合。ωa^{d+y} は W₂ の因子なので分布は空でない。
- **y ≥ 1 の場合**：
  - W₁ ≡ W₂ から a^x を消し（ωωa^y、ωa^{d+y}、どちらも混合）、右の a^{y−1} を消す（ωωa、ωa^{d+1}、どちらも混合。ωωa^y は W₁ の因子）。結果は ωωa ≡ ωa^{d+1}。
  - z₀z₀ = (ωa^d)(ωa^d) ≡ ω(ωa^d)a^d = ωωa^{2d}（(ii) で a^dω を ωa^d に）。
  - ωωa^{2d} = (ωωa)a^{2d−1} ≡ ωa^{3d} = z₀a^{2d}。
  - a^{2d}z₀ = a^{2d}ωa^d ≡ ωa^{3d}（(ii) を二回）。
- **y = 0、x ≥ 1 の場合**：
  - a^{x−1} を消して aωω ≡ aωa^d（どちらも混合。zx = W₁）。
  - z₀z₀ ≡ (a^dω)(a^dω) ≡ a^{2d}ωω = a^{2d−1}(aωω) ≡ a^{2d}ωa^d = a^{2d}z₀。
- **a^dz₀ ≡ z₀a^d**：a^dωa^d ≡ ωa^{2d}（(ii)）。
- **(C1′)**：g = d、c = 2d、g | c。z₀ = ωa^d は W₂ の因子なので分布は空でない。
- **(P3)**：
  - u₂ が u₁ の右にあるので y₁ ≥ d。
  - a^{x₁}ωa^{y₁} = a^{x₁}z₀a^{y₁−d} とおき、x₁ + qd = e\* + ρ′、y₁ − d = qd + ρ とする。
  - N = x₁ + d + y₁ = e\* + ρ′ + 2d + ρ なので、V\* = e\* + c = N − ρ − ρ′。正しい。

通常の場合（g₀ ≥ 1 または ω が混合）の消去も、残りの二語は全て混合で正しい。

### 1.3 補題C.0^c：修正が要る（軽微）

**誤りの箇所.** 「X_i は T の根でないので p_i + q_i = N − n_{X_i} ≥ 1」。

二分化した G′ は単位規則 X → Y を持つ。T の根で S → Y を使えば、X₁ = Y で n_{X₁} = N、p₁ = q₁ = 0 となる。節点数最小でも、根と子のラベルが違えばこれは消えない。このとき ω_{X₁} ∈ b⁺ なら、借りる a がない。

**直し方.** 符号 ẑ_i を作るのは **n_{X_i} < N の添字だけ**とする。そのとき p_i + q_i = N − n_{X_i} ≥ 1 で、原文の証明がそのまま通る。それ以外の添字の符号を使わないことは §1.4 で示す。

**残りの検査（正しい）.**
- a^{p_i}ω_{X_i}a^{q_i} と a^{p_i}Ω_ia^{q_i} は、T の X_i の部分木を差し替えた導出の語なので L に入る。
- b⁺ の場合、aω_{X_i} と aΩ_i はどちらも混合で、文脈 (a^{p_i−1}, a^{q_i}) を共有する。
- Ω_i は混合。X_i（i ≤ i\*）の部分木は u₁ と u₂ を含むので、n_{X_i} ≥ 2n_Y > n_Y。
- **借りた a が詰め物に収まること**：
  - 左から借りる場合：s′_i ∈ [1, d] なので ẑ_i = a^{s′_i−1}(aω_{X_i})a^{s_i} ≡ a^{s′_i}Ω_ia^{s_i}。
  - 右から借りる場合：s_i ∈ [1, d] で同様。
- **κ ≥ 0**：
  - 通常の場合：R_i + s_i ≥ 0、≡ g₀ (mod d)、0 ≤ g₀ < d なので R_i + s_i ≥ g₀。
  - 悪い場合：R_i + s_i ≥ s_i ≥ 1 で d の倍数なので ≥ d。z₀ = ω_Ya^d を取り出せる。
- **価値**：
  - 通常の場合：v_i = e_i + d = s′ + L_i + (R_i + s − g₀) + d = n_{X_i} + s + s′（d − g₀ = n_Y）。
  - 悪い場合：v_i = e_i + 2d = s′ + L_i + (R_i + s − d) + 2d = n_{X_i} + s + s′（n_Y = d）。
- s, s′ ≤ d なので v_i ≤ n_{X_i} + 2d、|ẑ_i| ≤ θ + 2d。(★) と λ, B₁ は変わらない。

### 1.4 n_{X_i} = N の節点の符号は使わない

- **(P4′)**：取る値は ≤ Λ/2 ≤ V\*/2 < N ≤ v_i。従って n_{X_i} = N の節点の値は取られない。
- **(P5)**：M ≥ 1 なら、埋め草の残り X は < V\* ≤ N ≤ v_i なので q_i = 0。M = 0 なら Λ < 2B₁ で計数を使わない。
  - **補足**：n_{X_i} < N となる最初の添字 i₀ での q_{i₀} の評価に「直前の v_{i₀−1}」を使う。その値は形式的な数 n_{X_{i₀−1}} + s + s′ ≥ N で足り、符号は要らない（X < V\* ≤ N ≤ 2n_{X_{i₀}} から q_{i₀} ≤ 2）。
- **(β) 道が尽きた場合**：形式的な値で「最後の値 ≥ Λ/2」が出る。符号は要らない。

従って依頼の点（根の符号が (P4′)(P5) で使われないこと）は正しい。ただし主張は「n_{X_i} = N の全ての節点」に拡げて書くべきで、それが 1c の修正と対になる。

### 1.5 課題1 の結論

定理P∞-c は、1c の修正（符号を n_{X_i} < N の添字に限る）をすれば正しい。結論の定数は変わらない。

## 2. 課題2：t_typ への拡張

### 2.1 (b) の確定：t_typ は文法だけの量

`main.tex` の定義（`def:output-refinement`、`prop:output-invariants`、`subsec:typed-thickness`）から、次が出る。

- **L_X は型 t の全ての生成語**：`prop:output-invariants`(iv) から、型つき非終端 X = A_t について L_X = {u : A_t ⇒\* u in G^ŝ} = {u ∈ L_A(G) : ŝ(u) = t}。
- **トリムされる条件**：G が reduced なら、**A が型 t の生成語を一つでも持てば A_t は G̃₀ に残る**。A の任意の文脈 S ⇒\* lAr と型 t の生成語 u を合わせた導出が、`prop:output-invariants`(ii) で G^ŝ に一意に持ち上がり、成功導出になる。
- 従って **t_typ の (A, {a}) の成分は「A の最短の純な a の生成語の長さ」**で、L に関する性質（C₁ など）が入る余地はない。依頼文 (b) の「前者」が正しい。

### 2.2 予想T の反例

`prop:typed-thickness-exponential` の文法で、c を b に読み替える：

  S → SS | a | b | A₀ | ⋯ | A_n、 A₀ → a、 A_i → A_{i−1}A_{i−1} | b（1 ≤ i ≤ n）。

- L(G_n) = {a,b}⁺ ∈ C_{1,c}（どの型付けでも代入可能）。
- G_n は reduced・ε なし・ランク 2。‖G_n‖ = 8n+13（|V| + Σ(1+|γ|)）、θ = 2。
- A_n の純な a の生成語は a^{2ⁿ} だけ（b を一つでも使えば型が変わる）。(A_n, {a}) はトリムされた細分にある（S → A_n）。
- 従って **t_typ(G_n, c) ≥ 2ⁿ**。依頼文 (c) が求めた形（直線的プログラム、成功導出で使われる、C_{1,c}）を全て満たす。
- スクリプト (A) で n ≤ 12 について、‖G_n‖、θ = 2、reduced、最短の純な生成語 = 2ⁿ を計算した。

**依頼文 (c) の見通しの訂正**：「X の純な語が L の中で必ず b を含む文脈に置かれることが必要」は誤り。この反例では a^{2ⁿ} は空の文脈に置かれる。L の最短の純な語は別の道（S → a）で短い。定理P∞-c は L の最短の純な語を抑えるだけで、個々の非終端の純な生成語は抑えない。

### 2.3 正しい量：代表元の長さ τ

`cor:distribution-representatives`：特徴標本の長さ ≤ N_typ(1 + 2θ̄_G + r_max·τ(G, s)) + 1。ここで

- τ_X := min{|v| : v ∈ Cl_{L,s}(X)}。
- Cl_{L,s}(X) は L_X を含む ≡_{L,s} 類（`lem:typed-homogeneity`）。

純な型の X = A_{{a}} では、Cl は a^n（a^n ∈ L_X）と ≡_{L,c} な語、すなわち a^n と同じ分布を持つ純な a の語の集合になる。従って

  **τ_X = min{m ≥ 1 : a^m ≡ a^n}**。

上の反例では a ≡ a^{2ⁿ} なので τ = 1（論文の本文にも書いてある）。

### 2.4 定理T′

**定理T′.** Σ = {a, b}、L ∈ C_{1,c}（無限でもよい）、G は L∩Σ⁺ の reduced・ε なしの CFG で厚さ θ とする。G′、K := |V′| ≤ ‖G‖+2、λ := 5K²θ、B₁ := 14K²θ は定理P∞-c のとおりとする。Φ′(K, θ) を、定理P∞ の Φ で m を m′ := (5K³ + M + 5)λ に替えたものとする。

このとき、G′ の非終端 A が純な a の生成語 a^n を持てば

  τ_{A_{{a}}} ≤ max{ K(K+2)θ, Φ′(K, θ) + 2d } ≤ C(‖G‖+2)^{76}θ^{21}

（d ≤ 2K²θ、C は絶対定数、r は現れない）。b⁺ についても対称。

Φ′ の K の次数は Φ と同じ（m′ の K の次数は 5 のまま）なので、指数 76, 21 は変わらない。G の非終端は G′ の非終端でもあり、生成語も同じなので、主張は G の型つき非終端にもそのまま成り立つ（τ は L と生成語一つで決まる）。

### 2.5 定理T′ の証明

**設定.**
- (l, r) を A の導出的な文脈とする（`lem:thickness-equivalence`(iv) を G′ に使う。|l| + |r| ≤ θ(G′) ≤ θ）。
- n を A の最短の純な生成語の長さとする。
- T_A を、生成語 a^n の A からの導出木で節点数最小のものとする。外側の (l, r) を導出する木と合わせると、la^nr の成功導出になる。
- 以下、T_A の部分木の差し替えで得る語は全て **A の生成語**で、文脈 (l, r) に入れると L に入る。

定理P∞-c の証明の各段を、T を T_A に、「L の最短の純な語」を「A の最短の純な生成語」に、文脈 (ε, ε) を (l, r) に替えて読む。

| 定理C\* の計数 | w_π ∈ L の G′ での任意の導出木の差し替え | w_π := l_ctx z_{π(1)}⋯z_{π(M)} Q r_ctx ∈ L。記録の論証は A を使わず、L の語の導出木だけを使う。語の長さは m + |l| + |r| ≤ m′ | 通る（m → m′） |
| (P4′)(P5)(P6′) | 算術、根の符号を使わない | 同じ（n_{X_i} = n の節点の符号は使わない、§1.4） | 通る |
| **最後の一歩（補題S′）** | a ≡ a^{1+p₀} から a^{N−p₀} ∈ L で最短性に反する | **A の生成語にはならないので使えない（依頼文の要点）**。代わりに補題S′₀ | **替える** |

**最後の一歩.** 計数から Λ := min(V\*, D) ≤ Φ′（D := lcm(d, p₀)、P₀ = {0} なら D = ∞）。
- Λ = V\* なら、n < V\* + 2d ≤ Φ′ + 2d。τ ≤ n。
- Λ = D < V\* なら P₀ ≠ {0}、すなわち a^{p₀}z₀ ≡ z₀ で、z₀ の分布は空でない（W₁ または W₂ の因子で、文脈 (l, r) の中にある）。補題S′₀ から a ≡_{L,c} a^{1+p₀}。合同性から a^n ≡ a^{n′}（n′ ≡ n (mod p₀)、1 ≤ n′ ≤ p₀）。どちらも型 {a} なので a^{n′} ∈ Cl_{L,c}(A_{{a}})、従って **τ ≤ p₀ ≤ D ≤ Φ′**。

いずれにせよ主張の評価が成り立つ。∎

**注意.**
- **A = S のとき**：文脈は (ε, ε) で、Cl の元は L の語（分布が (ε, ε) を含む）。τ = μ_{a}(L) なので、定理T′ は定理P∞-c を含む。補題S′ の最短性の議論は、この形では補題S′₀ に吸収される。
- **依頼文 (a) の三つの確認点への答え**：
  - P1 (a)(b) の最短性：A の部分木の中で縮めるので、A の生成語のまま。
  - 補題R の外側の文脈：(l, r) を文脈に含めて消去できる。補題2.1 は「zx の分布が空でない」だけを要求する。
  - 補題S′：A の生成語としては短くならない。しかし τ には ≡ だけで足りる。
- **定理C\* の計数**：A の部分木の符号を並べ替えた語が L に入ることは、A の部分木の差し替えではなく、補題2.3‴（≡ の計算）から出る。原文と同じ。

## 3. 課題3：帰結

**系 2L（定理T′ が正しければ）.** Σ = {a, b}、s を像が半束である型付けとする（例：内容型付け c、s_{U,2}）。L ∈ C_{1,s}、r_max ≥ 2、G を L∩Σ⁺ の reduced good でランク ≤ r_max の CFG とする。このとき L は、B^{≤r_max}_{1,s} と B_{1,s} の両方に対して特徴標本 K を持ち、

  ‖K‖₊ ≤ N_typ(G′, s)·(1 + 2θ̄_G + 2τ(G′, s)) + 1 ≤ C·(‖G‖+2)^{77}·θ̄_G^{21}

となる。C は絶対定数で、**ランク r にも s にも依らない**。

*証明.*
1. **s は c を経由する**。半束は可換かつ冪等なので、s(w) は w の文字の集合だけで決まる。従って s ⪯ c で、C_{1,s} ⊆ C_{1,c}（`def:class-cmcf` (a)）。L ∈ C_{1,c} なので定理T′ が使える。
2. **τ_s ≤ τ_c**。s の型つき非終端 A_t について、A の生成語で s-型が t のものの c-型 t′ を一つ取る。≡_{L,c} は ≡_{L,s} より細かいので、Cl_{L,c}(A_{t′}) ⊆ Cl_{L,s}(A_t)。従って τ_s(A_t) ≤ τ_c(A_{t′}) ≤ max{定理T′, 9Kθ̄}。
3. **二分化した G′ に系を使う**。G′ はランク 2 ≤ r_max、reduced・good で、L(G′) = L∩Σ⁺。θ̄_{G′} ≤ θ̄_G、|P′| ≤ ‖G‖ + 2。
   - 型つき非終端は ≤ |S|·K。型つき規則は G′ の規則一つあたり ≤ |S|² 個。|S| ≤ 3 なので N_typ(G′, s) ≤ 3K + 9|P′| = O(‖G‖)。
   - `cor:distribution-representatives` を G′ と r_max = 2 で使う（B^{≤r_max} の主張には G′ のランク ≤ r_max だけが要る）。
4. 定理T′ と混合の評価を入れて、主張の評価を得る。∎

**次数**：τ の (‖G‖+2)^{76}θ^{21} と N_typ の ‖G‖ で、全体は (‖G‖+2)^{77}θ̄^{21} 程度。指数は最適化していない（`claude_S1_infinite` §5 の改良候補がそのまま効く）。

**G そのものに系を使うと**、N_typ(G) は 3^r 程度になりうる（一つの規則の子の型の組合せ）。ランクに依らない形にするには G′ を経由する必要がある。
