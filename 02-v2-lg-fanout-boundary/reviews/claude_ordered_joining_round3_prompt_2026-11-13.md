## 1. 元の問題を間違えないこと

固定 `f≥2`, `r_max≥2` で、局所群 `LG` は 「一様多項式特徴データ長」 の正確な擬多様体境界か（`op:fanout-two`）。ここでは **f=2, r_max=2を第一対象** とする。

- **YES**：LGが境界のまま。LG外の任意の擬多様体に失敗する型付けが存在する。
- **NO**：LGより広い擬多様体（特にSL）が一様多項式データ長を持つ。
- 退避された `prop:sl-reduction` により、元の境界問題は半束擬多様体SLの成功／失敗に帰着する。
- Theorem AはLG十分性を**任意の固定fan-out・rank**で示すが、必要性を示したTheorem Cは**fan-out 1のみ**。
- 反例は固定有限アルファベット、固定型付け、文法サイズ `||G_n||` と**元の**規則厚さ `θ̄_{G_n}` が多項式で、特徴標本**総長**が超多項式になる必要がある。
- `μ`（最短の実現型語）・`τ`（分布同値代表長）・特徴標本の下界を混同しない。
- `τ`の多項式上界は `cor:distribution-representatives` により特徴標本上界を与えるが、`τ`の超多項式下界だけでは特徴標本下界にならない。
- 一部の有限アルファベット・一部の言語クラスの上界だけではNOにならない。

## 2. 2026-11-13までに得られたこと

### 2.1 局所鳩の巣法（基礎）

`k=|Σ|`, `v=|V|`, `θ=θ̄_G`, `r=rank cap`, `c=c_Σ`、
`H=v(2^k−1)^f` とおく。

節点数最小の**content-typed** 導出木では型付き非終端が根葉の道で重複しないため高さ ≤H。最初・最後の文字に印を付けると、骨格数が多項式。最大自由部分木のDFS接頭反鎖を短い生成組の色で分類し、同じ色の切り口間の領域を削る。

### 2.2 定理S（非交互言語）

`I_L={(a,b):a≠b, ∀u,v [uabv∈L ⇔ ubav∈L]}` とし、相異なる依存対 `a,b`（`(a,b)∉I_L`）について、Lのどの語にも散在する `aba` / `bab` が現れないことを「非交互」と呼ぶ。

Opus報告およびChatGPTの独立監査では、`L∈C^{mcf}_{f,c}` かつ非交互であれば

\[
\tau(G,c)\le4kf^2H\theta\{1+rH\cdot3^{\binom{k}{2}}(1+rH\theta)^k\}
=O_{k,f,r}(v^{k+2}\theta^{k+1})
\]

が成立すると判断した。証明の核心は、自由因子の文字が互いに可換なので、**DFS接頭領域が多数の断片に分かれても、独立交換によって高々f個の穴へ集約できる**こと。各文字の最初・最後の `2f` 出現を保護印として残し、W_jとW_j'のParikh和＋依存対の向きが一致すると、局所削除が可能になる。

**ただし** この手法は、互いに交換できない文字が繰り返し交互に現れる経路言語一般には直接使えない。ユーザーの主目的は、この次の壁を越えること。

### 2.3 経路言語（Opus §4）

有限有向グラフDの各字母aが**ちょうど一本の有向辺**に対応する場合、`Path_D(s,t)` をsからtへの歩道ラベル言語とする。まず

\[
L=\operatorname{Path}_D(s,t)\cap\Psi^{-1}(Q),\quad Q\subseteq\mathbb N^{\Sigma}\ \text{任意},
\]

で、**さらに** `L∈C^{mcf}_{2,c_Σ}` と仮定する。Qが任意なら自動的にMCFL・代入可能となるわけではないことに注意。

Opusは次を報告：

- **W1**：語wで使う辺の支持グラフの異なる強連結成分を結ぶ辺は一回しか出現しない。従って最初・最後の印のない長い因子は同じ強連結成分の内部にある。
- **W2**：文字数k、頻度しきい値 `c_{i+1}=kc_i+1` の中から、実際の頻度のない隙間を選ぶ。頻出辺によるグラフは弱連結成分ごとに強連結。特に頻出辺がすべて頻出辺だけの閉路に載る。
- ただしW1/W2の報告全体を無条件に信用せず、量化・証明を今回独立点検すること。
- そこで止まったのは **「順序付き接合」**：W_{j'}の頻出辺の写しを有限個のチェックポイント（高々fのη成分）へ、指定された**順序**で集めたいが、非可換な文字を任意に並べ替えられない。DFS接頭領域は一成分の中で深さに比例した数の断片に分かれ得る。

## 3. 第一優先：順序付き接合補題を正確に定式化して攻める

次のような明示的な問題から始める。

- 元の受理歩道 `W_{j'}, W_j∈L` は、短い反鎖の異なる代替生成組で得られる。
- 各々のParikh色、各η成分の端点型、境界のパス状態を色に追加することを検討する。
- 削除領域Rはηの高々f成分に分布していても、一つの成分内では多数の**非連続断片**に分かれる。
- 希望するものは、高々f個の穴のタプル `t,t'` と admissible な共有文脈 `F∈E_e`（穴間の固定区切りが非空）であり、`t,t'`は**成分ごとの内容型が同一**、`F[t],F[t']∈L`、かつ全削除が各成分の分布同値を保つこと。
- **元の文法の厚さθ** と `||G||` の多項式で必要な短い証人を構成する。積文法の厚さが巨大になる方法は不可。

### 3.1 Eulerian再配置を活用できるか（新しい具体的な着想）

強連結有限有向グラフK（辺数m≤k）の頂点qで、**全辺を一度以上通る短い閉歩道 h_q** がある。各辺を訪ねる経路を連結すれば `|h_q|=O(k²)` の構成ができる。

非負整数ベクトルzがK上の**circulation（各頂点の入次数＝出次数）**であれば、`h_q+z` もEulerianな連結有向多重グラフの辺多重集合である。従って

- qを基点とする閉歩道t'で Parikh(t')=Ψ(h_q)、
- qを基点とする閉歩道tで Parikh(t)=Ψ(h_q)+z、
- `alph(t)=alph(t')=E(K)`、

という**二つの同型付き閉歩道**を作れる。これは標準的なEuler閉路の考え方による**補助候補**であり、これだけで順序付き接合が解けたわけではない。

問題は、受理証人W_{j'}の指定位置から **h_q の辺多重集合を取り出し、残りの歩道を元の端点・順序で再構成できるか** である。必要な頻度の備蓄がチェックポイントごとに存在するとは限らない。また zが各η成分ごとにcirculationになるとは限らない。

次を真偽判定せよ。

1. **局所circulation補題**：切り口色を「各η成分の端点・短い生成組のParikh和」などへ精密化すれば、各成分の削除差 z_κ が circulation になるか。偽なら小さなgood MCFGの具体反例を出せ。
2. **anchored Eulerian exposure**：頻出強連結成分の歩道Wの所定のチェックポイントで、各辺を使う長さO(k²)の閉歩道を露出させても、残余が同じ端点の歩道になる十分条件は何か。
3. **ordered joining**：複数のチェックポイントを左から右へ処理し、露出した閉歩道が別のチェックポイントの必要な辺を奪わないようにする不変量は何か。
4. **任意Qへの対応**：`F[t']` と `F[t]` の両方が L に属するのは、W_j,W_{j'}の**Parikhベクトルに厳密に一致**することから示す。一般のQについて「同じmod」「同じ群値」「ほぼ同じ」では不十分。
5. **型付けと穴間区切り**：タプル各成分の内容を保存し、穴間に非空の固定文字列を持つadmissible contextを作れるか。

**まず固定Dかつ固定kでの部分定理を歓迎する**。ただしその部分定理が「もともとLGで得られる場合」または定理Sの単なる言い換えでないか精査する。

### 3.2 最初に試す有限グラフ（小さい順）

- 一頂点＋自己ループ数個（Parikh飽和に退化。正の基準例）。
- 二頂点二辺の2-cycle（`b:0→1`,`d:1→0`）。交互 `bdb` が必然的に現れ、定理Sの範囲外。
- 二頂点の2-cycle＋各頂点の自己ループ。閉路とループの混合が「順序付き接合」を阻むか。
- 三頂点の有向3-cycle＋一部の自己ループ。
- figure-eight（共有頂点を持つ2閉路）と、二つの強連結成分を稀な橋で結んだグラフ。

各グラフについて、任意Qの交差で（代入可能性を仮定した上で）何を証明できるか記述する。状態端点だけでなく、**多重辺の循環分解とチェックポイントの順序**を重視する。

## 4. 別方向も許可：より強い障壁・反例

もし順序付き接合が一般に偽なら、「何を増やしても短い閉路を露出できないか」を明示する **固定小グラフDと歩道族** を構成すること。

ただし局所接合の反例は、即座には `op:fanout-two` の YES 証明ではない。YESには、固定内容型付け・fan-out 2/rank 2でのMCFL性・代入可能性、文法サイズと厚さ、特徴標本総長の下界がすべて必要。

障壁候補：

- 稀な辺で区切られた順序の固定（独立交換ができない）。
- 端点を持つ部分流量のbalanceの破れ（zがcirculationでない）。
- 各チェックポイントの前に必要な全辺が存在せず、パス中の遠い循環を動かせない。
- DFS接頭領域が根の一つの成分の中で Ω(H) 個の断片に分割される。
- 既存の倍増族は `thm:doubling-no-lift` によって直接の持ち上げが不可。
