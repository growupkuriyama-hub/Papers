## 1. 設定（要点）

- **型付け**：全射な半群準同型 s: Σ⁺ ↠ S（S は有限）。学習者は、空でない組の成分を s の値が一致するときだけ比べる。
- **窓の型付け** s_{k,ℓ}：m₀ = max{1, k+ℓ} として、|w| < m₀ なら w 自身、|w| ≥ m₀ なら ⟨長さ k の接頭辞, 長さ ℓ の接尾辞⟩。s ⪯ s_{k,ℓ} なら窓の型付け。**片側の窓**とは s ⪯ s_{0,ℓ}（末尾だけを見る）または s ⪯ s_{k,0}（先頭だけを見る）のこと。
- **クラス** C_{f,s}：ファンアウト f 以下の MCFL で、(f,s)-組代入可能なもの。f = 1 では「同じ型の空でない因子 x, y が文脈を一つ共有すれば、分布が等しい」。
- **表示**：reduced good（λ-free・非削除・非置換・非併合）な MCFG G、ランクは r_max 以下（固定）。‖G‖ は記号単位の大きさ。θ̄_G は「各規則を使う最短の文の長さ」の最大値（1 以上）。
- **作用素** B_{f,s}(K)：観測した組 x ごとに [x]。
  - Const：[x] → x。
  - Comp：観測した z を、端末の隙間と空でない子に分ける。
  - Link：同じ型で、K の中に共通の文脈を持つとき [x] → [y]。
  - Start。
  - 健全性：L がクラスに入るなら、[x] から導出される y はすべて x と型付き合同（同じ型で、分布が等しい）。
- **特徴標本** F：F ⊆ K ⊆ L の全ての有限 K で L(B(K)) = L となるもの。B(K) は K について単調で健全なので、L ⊆ L(B(F)) を確かめれば足ります。意味があるのは**最短の**特徴標本の長さ cs だけです（語を足しても特徴標本のまま）。

## 2. 既知の結果

**原稿**
- 上界：局所群（窓の型付けを含む）で、どのファンアウトでも O(‖G‖²θ̄)。
- 下界：4f+1 文字以上で、どの型付けでも Ω(‖G‖θ̄)。
- 自明な型付け：Θ(‖G‖θ̄)。
- 上界の余分な ‖G‖ は、証拠を作る段階で「印を含む背骨」の長さを |V||N|^f で抑えている部分から来ています。

**族 F_n**（ChatGPT 1回目・2回目、検証済み）
- 定義：E_0 → a、E_i → l E_{i−1} E_{i−1} | c E_{i−1} r、開始 E_n。Σ = {a, l, c, r}。
- 全ての n で Clark–Eyraud 代入可能。決定的スタック解析器と、合流する二つの解析が同じ部分変換を行うという不変量で示されています。
- ‖G_n‖ = 12n+3、θ̄ = 4n−1。
- 記号：C_i = c^i a r^i、U_0 = a、U_i = l C_{i−1} U_{i−1}（末尾が a の最短の L_i の語、長さ i(i+1)+1）。
- s_{0,1}（末尾の文字）で、τ = t_typ = μ* = n(n+1)+1。よって **τ = O(θ̄) は窓の型付けでも偽**です。
- s_{0,1} での範囲：n²+3n+4 ≤ cs ≤ O(n³)。どちらが正しいかは未解決。
- ファンアウト1では、B の上限なし版とランク2版が同じ言語を作る。
- F_n の構文的合同は、到達可能なスタック上の部分変換の一致で決まる。
- **鍵の補題**：u, v ∈ L_i、b ∈ {c, l} なら、ub と vb は s_{0,1} の下で型付き合同。
- その結果、n ≥ 3 では、最上段の「左の子が a で終わる l の節点」を一つも含まない特徴標本が存在する（境界をまたぐ Link、例：`carc` → `laac`）。したがって「文法どおりの出現が必要」という Ω(n³) への道は閉じています。

## 3. Claude の見立て（今回の出発点。証明はまだ）

鍵の補題は、次の一般的な仕組みの現れだと考えています。

- **右にずらした切り方**：導出木の各節点 v の yield が文の区間 [s_v, e_v) を占めるとき、v の断片を [s_v+ℓ, e_v+ℓ) とする。子の区間が親の区間を隙間なく分割するなら、ずらした区間も同じように分割します。したがって Comp の分解として使えます。
- s_{0,ℓ} では、断片の型は末尾 ℓ 文字、つまり v の**直後の ℓ 文字**で、文脈によって決まります。共通の文脈を持つ断片は自動的に同じ型になるので、**型の制約は事実上消え、自明な型付けと同じ形で証拠を集められる**はずです。
- **例外 1（右の背骨）**：文の右端で終わる節点は、ずらすと文の外にはみ出します。これらは右の背骨に並び、本物の稀な型の費用（F_n では U_n）がかかります。ただし全てが一本の語に入れ子で収まるので、合計は O(‖G‖θ̄) で済むと期待しています。
- **例外 2（先頭の条件）**：断片は、v の**先頭 ℓ 文字** p を落とします。この p は文脈の側に入るので、同じ非終端の断片でも、p が違えば共通の文脈を持ちません。したがって証拠は、非終端と p の組ごとに要り、**「先頭が p の短い yield」が必要**になります。
  - F_n では、どの段の生成物も c か l で始まり、どちらも短い（C_i と l C_{i−1} C_{i−1}）。そのため **F_n は O(n²)** になると予想しています。
  - 一般には「末尾の稀さ」を「先頭の稀さ」に移すだけです。

## 4. 調べてほしいこと（優先順）

**Q1（F_n の決着）**
s_{0,1}、B_{1,s} について、長さ O(n²) の特徴標本を具体的に構成し、特徴標本であることを証明してください。3節の右にずらした切り方が手がかりです。
- これで F_n について cs = Θ(n²) = Θ(‖G‖θ̄) が確定します。
- 構成が通らない場合は、どこで止まるかを正確に示してください。

**Q2（片側の窓の一般定理）**
s ⪯ s_{0,ℓ}、ファンアウト1、ランク r_max の固定のもとで、次の形の上界を証明してください。
- 全ての L ∈ C_{1,s} と、全ての reduced good な表示 G について、cs ≤ c_s·(‖G‖θ̄ + P(G))。
- ここで P(G) は「先頭の条件」の費用で、例えば各非終端 A と、実現される各先頭 p について「先頭が p の A の最短 yield の長さ」を足したもの。より良い量があればそれを使ってください。
- さらに、P(G) = O(‖G‖θ̄) となる条件（例えば、全ての非終端で、実現される先頭ごとに長さ O(θ̄) の yield があること）を述べてください。
- s ⪯ s_{k,0}（先頭だけを見る）は、左右を反転した同じ議論で扱えるはずです。
- 注意：原稿の型付き精密化（型付き非終端・型付き規則）とは別の、「ずらした精密化」の文法を作ることになるかもしれません。その大きさ・厚さが ‖G‖・θ̄ の定数倍で抑えられることも示してください。

**Q3（下界の候補：先頭も末尾も稀な族）**
ずらす方法は、片側の稀さをもう片側に移すだけです。そこで次を調べてください。
- (a) **先頭の稀さが本当に費用になる族**を、片側の窓 s_{0,1} で作れるか。例えば F_n の鏡像を、F_n と組み合わせる。作れたら、cs = Ω(‖G‖²θ̄) を B_{1,s} について証明できるか。
- (b) 両側の窓 s_{1,1} で、先頭と末尾の両方を稀にする族。
- いずれも、①クラスに入ることの証明、②‖G‖・θ̄ の計算、③下界がどの作用素について成り立つか、を必ず添えてください。2回目の報告にあるとおり、「特定の構造を持つ語を消してもクラスに残る」とは限らない点に注意してください。

**Q4（余力があれば）**
Q2 の上界が、ファンアウト f ≥ 2 に伸びるか。各成分を右に ℓ ずらすと、成分の間の区切りが ℓ 文字より短い場合に、ずらした区間が隣の成分と重なる問題が起きます。ℓ = 1 なら区切りは空でないので重なりません。
