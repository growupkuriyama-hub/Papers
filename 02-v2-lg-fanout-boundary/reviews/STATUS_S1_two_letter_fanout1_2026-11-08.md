# 期限付き研究：二文字・ファンアウト1の超多項式下界（`op:S1`）と、ファンアウトの分離（2026-11-08 開始）

（著者の決定 2026-11-08：「期限付きの研究（1〜2週間程度）：s_{U,2} で f=1 に超多項式の下界を出す」。期限 **2026-11-21**。成功しなければ投稿は A＋A+案（定理A を主役にし、退避した非CFLの分離 `prop:lg-needed-target`、`prop:nonabelian-needed-target` を戻す）で進める。）

## 0. 目標と、成功したときの定理

Σ = {a, b}、r_max ≥ 2。次のどちらかを示す族 L_n（reduced good な CFG G_n、‖G_n‖, θ̄_{G_n} ≤ poly(n)）を作る。

- **(S1-c)** L_n ∈ C^{mcf}_{1,c}（内容型付け）で、特徴標本の長さが超多項式。
- **(S1-U)** 同じことを s_{U,2}（a ↦ 1, b ↦ ζ）で。

C_{1,s_{U,2}} ⊊ C_{1,c} なので（README (48)(a)）、**(S1-U) ⇒ (S1-c)**。分離定理には **(S1-c) で足りる**（`thm:two-letter-content` は c 自身について f ≥ 2 で多項式）。従って**まず c を狙う**（クラスが広いぶん作りやすい）。s_{U,2} は c が出たら次に試す。

成功時の定理（案）：「二文字の内容型付け c は、ファンアウト ≥ 2 では一様な多項式特徴データを持ち、ファンアウト1では持たない。」

## 1. 出発点（既にあること）

- **「定理C の U₁ 指数族を二文字に落とす」確認は 2026-11-01 に済んでいて、否定**：三文字族 K_n の全ての符号化 A ↦ a^p, B ↦ a^q, C ↦ u（u は b を含む）は、(1,c) でも (1,s_{U,2}) でも代入可能でない（`chatgpt_two_letter_fanout1_lower_2026-11-01.md` 定理2.1、n ≥ 3 への拡張は README (49) の訂正つき）。素朴な二文字の倍増、段付きの印の族、型板探索も n = 2, 3 で壊れる。**従って分離には新しい族、つまり `op:S1` の否定そのものが要る。**
- 希少な型は純な語（a^N か b^N）でなければならない（混合の型は代入可能性なしで 3(r+1)|V|θ̄ 以下、README (48)(b)）。
- 必要条件：超多項式の純な語と同時に、もう一方の文字の個数が**超多項式個の異なる値**を取ること（t_typ ≤ (r+1)|V|θ̄·max{3,h_a,h_b}、README (48)(c)）。有限の標的では型1の語は高々一つ（`lem:no-insertion`）、同じ型の語は因子順序の反鎖（README (49)(a)）、一つの文脈に二つの純な塊の長さがあると等差数列が強制される（README (49)(d)）。
- s_{U,2} の既知の下界は二次だけ（`prop:binary-u1-quadratic`、退避中）：θ̄²/4 を超えるデータ、‖G‖ = O(log θ̄)。
- **群の道（問題G）**：準同型 φ: {a,b}* → H（有限群）の原像 φ⁻¹(1) は全ての型付けで一穴代入可能で、純な語の最短の長さは ord φ(a)。従って「ord φ(a) が文法の大きさと厚さの多項式で抑えられない群の族」があれば (S1-U) が成り立つ（`claude_two_letter_fanout1_2026-11-01.md`）。可換群では ord ≤ (r+2)θ̄²、H_n = Z/(2ⁿ−1) ⋊ Z/n では ‖G‖ ≥ 2^{(2/3−o(1))n}、一般の群では |H_ab| ≤ (r+2)θ̄²（`chatgpt_problemG_2026-11-01.md`）。一般の有限群は未解決。

## 2. 2026-11-08 の新しい観察（Claude、このスレッド。未検証の部分は明記）

### (N1) 二つとも Clark–Eyraud 代入可能な部分標的では下界は出ない【証明は一行・要確認】

L′ ⊊ L がともに C_{1,s_triv}（型付けなしの一穴代入可能）に入るなら、L∖L′ は長さ O(‖G‖θ̄_G) の語を含む。
理由：`cor:trivial-exact` により B_{1,s_triv} は長さ O(‖G‖θ̄_G) の特徴標本 F を持ち、`lem:distinguishing`（B_{1,s_triv} に適用）により F は L∖L′ の語を含む。
帰結：下界に使う部分標的 L′ は**型付けなしの代入可能性を破らねばならない**。s_{U,2} なら「純な a の因子と b を含む因子が文脈を共有して分布が違う」、c ならさらに「b⁺ の因子と混合の因子」も使える。群の原像 L は C_{1,s_triv} に入るが、型の削除 L′ = L∖a⁺ はそこから外れるので矛盾はない。

### (N2) 問題G は「混合時間」に帰着する【2026-11-08 に証明を書き下した：`claude_problemG_mixing_2026-11-08.md` 定理M。独立検証待ち】

H を有限群、φ を全射（a, b の正の語で H を生成）、L = φ⁻¹(1)∩Σ⁺、G を L の ε なしの CFG とする。長さ ℓ の一様な語の値の分布を P_ℓ とし、d を恒等語の長さの gcd、H₀ = ker(χ: H → Z/d)（a, b ↦ 1）とする。t を「ℓ ≥ t なら P_ℓ が自分の剰余類の上で一様の (1±ε) 倍以内」となる最小の長さ（sup ノルムの混合時間）とする。L ≡ 0 (mod d), L ≥ 6t とし、F = L の長さ L の語全体を取る。
- |F| ≥ (1−ε)2^L/|H₀|。
- 長さ L/3〜2L/3 の区間 [p,q) では前後の長さの和が L/3 以上なので、どちらかが L/6 ≥ t。独立性から、因子の値が g となる F の語は高々 (1+ε)²2^L/|H₀|²。
- `chatgpt_problemG` の計数補題（中間部分木と、非終端ごとの群値の一意性）から

  ‖G‖ + 2 ≥ (1−ε)|H₀| / ((1+ε)²(L+1)²)、従って ord φ(a) ≤ |H| ≤ d·C_ε·(‖G‖+2)(6t+d+1)²。

  d ≤ |H_ab| ≤ (r+2)θ̄²（定理4）。
- **帰結**：問題G の反例となる群の族は、**混合時間 t が ‖G‖, θ̄ に対して超多項式**でなければならない。同時に、厚さを小さく保つには φ(a)^{2^j} などに短い正の語が要る（指数的な歪み）。「混合は遅いのに、a の冪には近道がある」群が要る。
- 計算による確認（証明ではない）：H_n の sup 混合時間（相対誤差 < 1/2）は n = 3..12 で ≈ 1.15 n log₂ n（`reviews/check_claude_hn_mixing_2026-11-08.py`、数秒）。**[2026-11-08 Astra により撤回]** この外挿は誤り：商 Z/n への射影で t = Ω(n²)（n ≤ 12 の数値は n² 級とも矛盾しない）。
- 未確認：(a) 計数補題の適用条件（二分化、単位規則）を書き下すこと、(b) 周期 d の扱い、(c) 一般の有向 Cayley 図での混合時間を、直径や θ̄ で抑えられるか。(c) が肯定なら**問題G は肯定で、群の道は閉じる**。

- **2026-11-08（8）**：道N の新しい枠組み（Claude、証明つきの観察、未検証）：**消去的モノイドの原像**。M を消去的モノイド、ψ: {a,b}* → M、L := ψ⁻¹(m) とすると L は型付けなしで一穴代入可能（共通の文脈から ψ(x) = ψ(y)）。a^N ∈ L なら純な語は（ψ(a) が無限位数なら）a^N だけで、L∖{a^N} は C_{1,c} に入るので、c と s_{U,2} の特徴標本は a^N を含む（N1 とも矛盾しない：L∖{a^N} は型付けなしでは代入可能でない）。有限群は定理G で除かれ、M が群のときと違い **ψ⁻¹(m) は有限でもよい**（例：Baumslag–Solitar の正のモノイド ⟨a,b | ba = a²b⟩ では b の個数が一定で、原像は有限）。必要条件（証明）：M を含む群 Ĝ について、**Ĝ の可換化は有限**でなければならない。理由：λ: Ĝ → Q を準同型とする。a^N の導出の重い節点 B の短い生成語 ω_B は a^p ω_B a^q ∈ L から ψ(ω_B) = ψ(a^{n_B})、よって λ(ω_B) = n_Bλ(a)。λ(a) > 0 なら λ(b) > λ(a)（さもなくば n_B ≤ |ω_B| ≤ θ̄）で、L は非負の加法的な重みの一つの水準に入り、README (100) で μ_a ≤ (r+1)²θ̄³。λ(a) = 0 なら λ(ω_B) = λ(b)·#_b(ω_B) = 0 から λ(b) = 0。従って反例には「可換化が有限で、正のモノイドの中で a が指数的に歪み、しかも正の原像が小さく薄い CFG を持つ」無限群（または有限群でない消去的モノイド）が要る。BS(1,2) は可換化が Z なので不可（b の個数が保存され、純な語が作れない）。候補の方向：性質 (T) を持つ格子（SL(3,Z) など：可換化有限、冪単元の指数的な歪み）だが、正のモノイドの中での歪みと、原像の文脈自由性はどちらも不明。

  - 命題D：像モノイドが群で一つの原像が文脈自由なら virtually free（Muller–Schupp）、従って無限位数の元は歪まない。**群全体を正に生成する場合は (C2)(C3) が両立しない**。残るのは真の部分モノイドだけ。
