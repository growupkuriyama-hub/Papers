## 1. 現在の問い

**内容型付け c_Σ（ある固定アルファベット Σ）について、次を満たす族 (L_n, G_n) を作ること。**
- (i) L_n ∈ C_{2,c_Σ}（ファンアウト1と2の両方の代入可能性）
- (ii) ‖G_n‖ と θ̄_{G_n} が n の多項式（G_n は reduced good、ランク2、ファンアウト ≤ 2）
- (iii) ある実現される内容型 A の最短の語の長さ μ_A(L_n) が n について超多項式

これができれば、`prop:rare-type` と `prop:sl-reduction` により、**全てのファンアウトで境界は LG** と確定します（論文の看板になります）。

## 2. Claude の観察（今回の出発点。外部の検証はまだ）

**観察A（強制される語は Parikh ベクトルを保つ）**
- (2,s)-代入可能性が強制する語は、全て既存の語と同じ Parikh ベクトル（各文字の個数）を持ちます。
- 理由：共通の文脈 E で E[x], E[y] ∈ L なら、x と y の成分の文字数の合計は同じです。したがって F[x] ∈ L から強制される F[y] は、F[x] と同じ Parikh ベクトルを持ちます。
- 内容型付けでは成分ごとの内容も等しいので、F[y] の内容型も F[x] と同じです。
- 冪の移行（`lem:power-transfer`）も、前回の切り直し（補題5、定理7）も、この特別な場合です。

**観察B（失敗の本当の原因）**
- 括弧付き倍増族も Thue–Morse 案も、「**稀な型の語がただ一つ**」という硬い設計でした。強制された語は同じ長さの別の語なので、それを受け入れる余地がなく、クラスから外れました。
- そこで、**稀な型の語の集まりを、並べ替えに閉じたもの**にすれば、強制先は最初から言語に入っています。例えば、内容型 {a, b} の語の集まり R_n を「a と b がちょうど 2^{n−1} 個ずつの語全部」とします。強制される語は同じ Parikh ベクトルを持つので R_n に入り、害がありません。稀さ（最短の長さ 2ⁿ）はそのまま保てます。

**観察C（残る制約）**
1. **二繊維型の定理**（DeepSeek、検証済み）：純な語（稀な型の語）が全て一つの加法量の値 h₁ を持ち、混合の語（印を使う語）も全て一つの値 h_ζ ≠ h₁ を持つなら、どの表示でも μ₁ ≤ (2r+1)|V|θ̄。→ **混合の側の加法量を、複数の値にばらつかせる**必要があります。
2. **長さの種類の定理**（あなたの定理10）：有限の族で指数の稀な型を持つには、語の長さが指数種類必要です。
3. **混合の側と、純な側と混合の側をまたぐ交換の整合**：ここが本当の山です。例えば、x と y が同じ内容で、混合の語の中の共通の文脈を持つと、純な語の中の文脈でも交換できなければなりません。その結果、x と y の長さの差（Parikh ベクトルの差）が、混合の側の構造に強く縛られます。
4. **文法の大きさ**：R_n（並べ替え全体）を大きさ O(n)・θ̄ = O(n) の文法で作れるか。倍増の規則 D_i → D_{i−1} D_{i−1} だけでは、a と b の個数をちょうど半分ずつにできません。二次元の倍増（個数の組を追跡する非終端）や、ファンアウト2の成分を使う工夫が要るかもしれません。また、θ̄ を小さくするには、各段の規則が短い文で使われる必要があり、そのために印を使う短い枝が要ります。

## 3. 調べてほしいこと

**T0（観察A の命題化）**
観察A を正確な命題として証明してください（任意の型付け、任意のファンアウト f）。そこから、「稀な型の語の集まりが並べ替えに閉じていれば、その型について代入可能性が強制する語は全てその集まりに入る」という形の系を導けるか、確かめてください。ただし、強制される語の**内容型が稀な型に留まるか**、別の型に移る可能性があるかも検討してください。

**T1（族の設計：本題）**
観察B・C に沿って、(i)〜(iii) を満たす族を設計し、証明してください。次の順で考えるとよいと思います。
- (a) 稀な型の語の集まり R_n をどう選ぶか。並べ替えに閉じた集合のほか、「ある正則な枠の中で Parikh ベクトルが決まった語全部」でもよい。
- (b) 小さい文法で R_n を作る方法。必要なら印を使う短い枝を加え、θ̄ を O(n) にする。
- (c) 混合の側の加法量を複数の値に散らし、二繊維型の定理を避ける方法。
- (d) (2, c_Σ)-代入可能性の証明。特に、純な側と混合の側をまたぐ交換の扱い。

**T2（障害が見つかった場合）**
T1 が通らない場合は、どの制約がぶつかるのかを、できるだけ一般的な補題として定式化してください。例えば「並べ替えに閉じた稀な型を持つ (2,c_Σ)-代入可能な言語では、混合の側の加法量が一つの値に縛られる」のような形です。それが成り立つなら、二繊維型の定理と合わせて、**稀な型の議論では SL の反例は作れない**、という強い否定の結果になります。それも論文に価値のある結果です（その場合、反例は稀な型以外の議論で作る必要があることになります）。
