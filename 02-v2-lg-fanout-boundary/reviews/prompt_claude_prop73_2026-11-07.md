### 問題の位置づけ
三文字 Σ = {a,b,c} の内容型付け c_Σ(w) = cont(w) で、ファンアウト ≤ 2 の代入可能な言語（C_{2,c_Σ}：arity 1 と 2 の内容型付き代入可能性 SUB₁・SUB₂）の、内容 {a,b} の最短語の長さ μ_{ab} が、文法の非終端の数 v と厚さ θ̄ の多項式で抑えられるか（未解決問題 `op:fanout-two` の核）。否定の十分条件は、‖G_n‖, θ̄(G_n) = poly(n) で μ_{ab} が超多項式の C_{2,c_Σ} の族（`prop:rare-type`）。

SUB_d の規約：文脈 E = v₀□₁v₁…□_d v_d（両端は空でもよい、d = 2 の内部 v₁ は非空）、穴の成分は非空。cont(x_i) = cont(y_i) かつ E[x], E[y], F[x] ∈ L なら F[y] ∈ L。

### パリク飽和な言語（一頂点のクラス）で分かっていること
L = π⁻¹(Q)（Q ⊆ ℕ³∖{0}、π はパリクベクトル、座標の順 a, b, c）。Q₂, Q₃ は支持 {a,b}, {a,b,c} の部分、Π₂, Π₃ は対応する格子点の集合、H₂ = ⟨Q₂ − Q₂⟩、H₃ = ⟨Q₃ − Q₃⟩、H₃⁰ = H₃ ∩ 平面（c = 0）、**V := (q₃ + H₃) ∩ 平面**。

- **定理2.1（閉包報告）：** L が SUB₁ ⟺ 条件 (T)。一頂点では SUB₁ ⇒ 全ての SUB_d（系2.2）。
- **移動（補題2.3）：** q, q′ ∈ Q（同じ支持）、h = q′ − q。α ∈ ℕ³ が supp h の上で α_σ ≥ 1 かつ α_σ + h_σ ≥ 1 なら、α ∈ Q ⟺ α + h ∈ Q。
- **(P⁺)**（両座標が狭義に大きい二つの ab の点がある）なら、どの表示でも μ_{ab} ≤ max{9(r+1)vθ, 226v³θ³}（閉包報告の系3.6）。
- **定理 A（7.2 報告）：** Q₃ が無限なら、同じ上界。
- **補題1・系2(a)（7.2 報告）：** 最短の ab 語 W の導出に、比較不能な印のない重い節点の組がある（場合 (ii)）なら π(W) ∈ V ∩ Q₂。従って **V ∩ Q₂ = ∅ なら μ_{ab} ≤ 9(r+1)vθ**（Q₃ の有限・無限によらない）。
- **定理3.7（閉包報告）：** μ_{ab} ≤ max{9(r+1)vθ, 2050F_L³v³θ³}。F_L := min_{K₂ 許容的}[K₂ + H₃⁰ : K₂]（K₂ が許容的 ⟺ (q₂ + K₂) ∩ Π₂ = Q₂）。
- **補題3.9 の精密化（7.2 報告）：** μ_{ab} ≤ max{9(r+1)vθ, 2B_{ab} − 2}。B_{ab} := abc 語の a と b の個数の和の最大。**ただし B_{ab} は言語の量で、文法では抑えられない。** このため、Q₃ が有限の場合は閉じていない。
- **補題 W（7.2 報告）：** a と b を含む L(G) の語が全て、λ(a), λ(b) ≥ 1、λ(c) = 0 の一つの重みの水準に乗るなら、比によらず μ_{ab} ≤ 7(r+1)v²θ²（代入可能性不要）。

## 1. 依頼：命題7.3

> **命題7.3。** L = π⁻¹(Q) が SUB₁、(P⁺) が成り立たず、Q₃ が有限で空でなく、V ∩ Q₂ ≠ ∅ とする。L の任意の既約 good な表示 G で μ_{ab}(L) ≤ poly_r(v, θ̄_G) か？

これが解ければ、**パリク飽和な代入可能な言語は完全に閉じます**（7.2 報告の系 A′ と補題1 により、この仮定の外は全て max{9(r+1)vθ, 226v³θ³} で抑えられる）。否定的に解ければ、それがこのクラスでの唯一の反例の候補で、`op:fanout-two` の否定につながります。

**仮定は空でない：**
- X：Q = {(5,1,0)} ∪ {(3,2,1), (1,3,2), (2,1,3)}。F_L = 2。
- **Y₂₃：** Q = {(10,23,0)} ∪ {(1,2,5), (1,26,1), (11,10,2), (24,3,1)}。Q₃ は水準 a + b + 6c = 33 に乗り、H₃ はその平面の格子全体、H₃⁰ = ℤ(1,−1)、V = {a + b = 33} ∋ (10,23)。許容的な K₂ は ℤ(M,−M)（M ≥ 23）で、**F_L = 23**。μ_{ab} = 33、B_{ab} = 27。（別スレッドの Claude が、条件 (T) を定義から直接、全数で確認済み。）
- 計算上の観察（7.2 報告 §6.3）：乱択の有限閉包で SUB₁ を厳密に満たした 346 個は**全て**、Q₃ が狭義に正の法線を持つ平面（λ > 0 の一つの水準）に乗った。

**反例が満たすべき条件**（7.2 報告から）：最短の ab 語の導出で場合 (ii) が起きる（さもなくば系2(a)）、F_L が超多項式（さもなくば定理3.7）、B_{ab} ≥ μ_{ab}/2（補題3.9 の精密化）。言語はパリク飽和で、Q₃ は有限。

## 2. 課題

### 課題1（構造：有限の Q₃ は正の水準に乗るか）
**予想：** SUB₁ を満たす一頂点の L で Q₃ が有限（かつ (P⁺) が成り立たない）なら、Q₃ は狭義に正の重み λ（λ(a), λ(b), λ(c) > 0）の一つの水準に乗る。

証明するか、反例を示すこと。Stiemke の補題（格子 H₃ が非零の非負ベクトルを含まない ⟺ 狭義に正の直交ベクトルがある）の形が自然です。H₃ が非負の非零ベクトルを含むなら、移動で Q₃ が無限になる、という向きの議論が考えられます（7.2 報告の F3 と Dickson の補題の逆向き）。

### 課題2（肯定の向き：命題7.3 の証明）
次のどれか、または組み合わせで、命題7.3 を示すこと。
- **(a) 補題 W の λ(c) > 0 版。** 課題1 が正しければ、a, b, c を全て含む語は正の水準に乗る。ab 語は一般に水準に乗らない（Q₂ と Q₃ は別の高さ）。そこで、「c を含む語だけが水準にある」という仮定の下で、補題 W の議論（重い文字の出現を全て印にする、最初の交差で θ ≥ 比を得る）が延びるかを調べる。
- **(b) 文法の側から F_L を抑える。** 場合 (ii) の構成（W_t, W_{t′}, W_{tt′}、定理 H の証人）を使い、定理3.7 の写像 χ を「Q₂ に実際に効く移動」だけで作り直す（7.2 報告 §6.4 の (ii)）。Y₂₃ では F_L ≈ B_{ab} なので、言語の量だけでは F_L を小さくできず、文法を使う必要がある。
- **(c) 有限のパリク飽和な言語の文法の下界。** L は有限で、長い ab のパリクベクトル（例えば (10,23)）を持つなら、その全ての並べ替えを含む。小さな厚さ θ̄ で、そのような有限の可換な言語を生成できるかを調べる。README (177) の定理B2（言語の長さの集合に 1 と M の間の空白があれば θ̄ ≥ M）の一般化（長さの集合の構造と θ̄ の関係）が使えないか。

### 課題3（否定の向き：Y₂₃ を含む族）
F_L → ∞ となる、命題7.3 の仮定を満たす Q の族を系統的に作ること。
- Y₂₃ の四点の構造（水準 a + b + Kc = C 上の有限の閉じた集合で、同じ高さの差が一つだけ）を保つ変形に絞って探す。7.2 報告によると、単純な拡大（K = 3..12 の四点の形）は K = 6 以外で閉じた集合にならなかった。
- 族ができたら、場合 (ii) を実際に起こす、‖G_n‖, θ̄ = poly(n) の文法が作れるかを調べる。作れない場合は、課題2(c) の障壁として述べる。
- 文法を作る場合は、全ての規則、言語の一致の完全な証明、`prop:rare-type` の仮定の確認を示す。
