## 1. 設定と、用いる既知の性質の点検

`Σ={a,b,c}`、`c(w)` を非空語の文字集合とする。`L∈𝒞^{mcf}_{2,c}`、`G=(V,Σ,P,S,fan)` は `L∩Σ⁺` の reduced good MCFG、`fan≤2`、規則ランク `≤r` (`r≥2`)、`v=|V|≥1`、`θ=\bar θ_G≥1` とする。`k=μ_a(L)=min{j≥1:a^j∈L}≥5`。`T` は `a^k` の成功導出のうち**節点数最小**のもの。節点 `u` の生成組の総長を `ℓ_u`、`ℓ_u>θ` を**重い**とする。

原稿 `def:grammar-properties` における good は `λ`-free・nondeleting・nonpermuting・nonmerging。原稿 `lem:thickness-equivalence` の (i),(ii) から、各規則が直接記す終端数は `≤θ`、各非終端 `B` には総長 `≤θ` の生成組がある。nondeleting によって反鎖の節点の出力位置は重複せず、独立に別の導出へ置換できる。

`a^k` の最小性と `T` の節点数最小性から、同名非終端は一本の祖先―子孫経路上に繰り返されない：上側を下側の導出に置換すれば、出力はやはり正の `a` の冪で、短くなるか、同長のまま節点が減る。よって `height(T)≤v`、同名ラベルの出現は反鎖になる。

`N` を重い節点の総数とする。重い節点は祖先について上閉であり、各節点の直書き `≤θ` と高々 `r` 個の非重い子の出力 `≤θ` を数えると、根が重い場合

\[
 k\le (r+1)\theta N.\tag{1.1}
\]

根が重くない場合は `k≤θ`。重い `B` に総長 `≤θ` の**純粋 `a`** 生成組があると、これへの置換で `a^j∈L`、`1≤j<k` が生じる。したがって重いラベルの短い生成組は必ず `b` または `c` を含む。

定理Sの必要箇所も再点検する。`a^k` に `a⁴` が現れるので、arity 2 の共通文脈 `□₁a□₂` において `(a,aa)` と `(aa,a)` の分布が一致し、離れた `a` ラン間の一文字移送が可能である。同一 `a` 骨格 `σ_a(w)`（極大 `a` ランを一文字にした語）の二つの受理語に `0<δ<k` の `a` 個数差があれば、余分な `a` を一つのランへ集め、arity 1 から `D_L(a)=D_L(a^{1+δ})` を得る。これを `a^k` に適用すると `a^{k−δ}∈L` で矛盾する。従って

> **(S)** `1≤|w|_a,|w'|_a<k` かつ `σ_a(w)=σ_a(w')`、`w,w'∈L` なら `|w|_a=|w'|_a`。

また、`L_x=L∩{a,x}⁺` (`x=b,c`) は `(2,c)`-tuple-substitutable である。原稿付録の `lem:app-two-runs` と `lem:app-two-alternate` の議論を二文字影に適用すると、`L_x` が Parikh-saturated でなければ、`aa` と二つ以上の内部 `x` ランを持つ受理語は存在しない。この使い方には、**切り出した影の文法厚さを `θ` で抑える仮定は不要**である。

## 2. 新しい剛性：同名非終端の生成総長は等しい

**補題2.1（純粋最短導出におけるラベル長剛性）**。`T` における同名非終端 `B` の任意の二出現 `u,u'` について、`ℓ_u=ℓ_{u'}`。これを `ℓ_B` と記す。特に `B` の全出現は同時に重いか、同時に重くないかのいずれかである。

**証明**。`u,u'` の生成組は、いずれも各成分が非空の純粋 `a` 語である。仮に `ℓ_u>ℓ_{u'}` なら、`u` の部分導出を `u'` の部分導出に置き換える。MCFGの規則は非削除的であり、同名ラベルはファンアウトも同じだから、この置換は有効で、根の語は `a^{k−ℓ_u+ℓ_{u'}}` となる。指数は正で `k` より小さく、`k` の最小性に矛盾する。逆の不等号も同様。□

**注意**。同じなのは**生成組の総長**であって、ファンアウト2の各成分長が個別に一致すると主張していない。この補題には定理Sも Parikh 飽和性も要らない。最小の純粋語と文法の非削除性だけで十分である。

重い `B` に総長 `≤θ` で `b,c` をともに含む生成組 `ρ_B` を固定し、`p_B=|ρ_B|_a` とすると、その全出現を置換する際の損失は同じ正整数

\[
 d_B:=\ell_B-p_B\ge \ell_B-\theta>0.\tag{2.1}
\]

これで依頼文の「同じ長さ `ℓ` と同じ損失 `d`」は、両文字型の場合にも正当化できた。ただし**その帰結だけでは** `d_B` や出現数が多項式とはいえない。

## 3. 局所化をさらに縮めた定理

### 3.1 三つのスペクトル

全域スペクトルは第七報と同じく

\[
 \mathcal A_{abc}(L;k)=\{j\in\{1,\ldots,k-1\}:\exists w\in L,\ c(w)=\Sigma,\ |w|_a=j\},\quad m=|\mathcal A_{abc}(L;k)|.
\]

**依頼の局所スペクトル `m_T`**：`T` の重い節点から任意の反鎖を選び、選んだ節点ごとに当該非終端の総長 `≤θ` の任意の生成組で部分導出を置き換えた全成功語のうち、内容 `Σ`、`a` 個数 `1,…,k−1` のものの相異なる `a` 個数の数（空反鎖は寄与しない）。明らかに `m_T≤m`。以下の論証はその定義のうち、もっと狭い族しか使わない。

各重いラベル `B` を、総長 `≤θ` で `b` または `c` の**一方だけ**を含む（他の非 `a` 文字を含まない）代表 `ω_B` を持つ**一色型**と、そうでない**両文字型**に分ける。後者では全ての短い代表が `b,c` の両方を含むので、一つ `ρ_B` を固定する。両文字型重いラベルの集合を `\mathscr B` とする。

`T` の最左の `a` 一文字を保護する。`B∈\mathscr B` の重い出現数を `q_B`、その保護位置を所有しない出現数を `q_B^*` とすると、同名ラベルが反鎖をなすので `q_B−1≤q_B^*≤q_B`。それらを任意の順に `u_{B,1},…,u_{B,q_B^*}` と並べ、最初の `j` 個だけを `ρ_B` に置換した受理語を `W_{B,j}` (`1≤j≤q_B^*`) とする。保護 `a` が残り、`b,c` が導入されるから

\[
 c(W_{B,j})=\Sigma,\qquad |W_{B,j}|_a=k-jd_B\in\{1,\ldots,k-1\}.\tag{3.1}
\]

より小さな**ラベル別連続置換スペクトル**を

\[
 \mathcal H_T:=\bigcup_{B\in\mathscr B}\{jd_B:1\le j\le q_B^*\},\qquad h_T:=|\mathcal H_T|\tag{3.2}
\]

と定義する。これは `a` 個数ではなく `k` からの損失を記しているが、写像 `d↦k−d` は単射だから同じ種類数である。直ちに

\[
 0\le h_T\le m_T\le m,\qquad
 \#\{\text{両文字型の重い節点}\}=\sum_{B\in\mathscr B}q_B\le v(h_T+1).\tag{3.3}
\]

**ここでは全反鎖も、異なるラベル間の同時置換も不要**。各 `B` について保護外の出現を一つずつ増やす一本の列だけを使う。`q_B^*` 個の `jd_B` はすべて異なるので `q_B^*≤h_T`、あとは `q_B≤q_B^*+1` を足し合わせただけである。

### 3.2 主定理

**定理3.2（強い局所スペクトル版）**。§1の全条件の下で、任意の節点数最小導出 `T` と、上記の任意の許された短い代表の選択について

\[
\boxed{\displaystyle
 k\le 19(r+1)^3v^3\theta^3(\theta+h_T+20)^3
 \le 19(r+1)^3v^3\theta^3(\theta+m_T+20)^3.}\tag{3.4}
\]

従って第七報の定理3.1で `m` を `m_T` に置き換えることは正しい。さらに **`h_T` への置換も正しい**。

**証明**。第七報の `m` が現れる箇所を探すと、両文字型の出現を数える補題2.1と、それを全例外節点数に加算する式 (3.5) だけである。ただし単なる参照ではなく、残りの依存関係を以下に再構成する。

1. 一色 `x∈{b,c}` を固定する。`L_x` が非 Parikh-saturated なら、同色の重い出現の任意の反鎖は9個以下である。仮に10個あれば `a^k` の先頭末尾各2文字を保護して少なくとも6出現を残せる。各出現は高々2区間を所有するので、その区間の隣接グラフの最大次数は4、よって互いに隣接しない2出現を選べる。双方を一色代表に置換すると、受理語は二文字影 `L_x` に属し、`aa` と二つの分離した内部 `x` ランを持つ。原稿 `lem:app-two-runs`、`lem:app-two-alternate` の二文字帰結に反する。高さ `≤v` より、非飽和色二つを合わせた重い例外は `≤18v`。
2. `L_x` が Parikh-saturated の場合、同じ正の `x` 個数を持つ二受理語の `a` 個数差が `1,…,k−1` になることはない（Sの arity-1 縮約と `a^k` の最小性により矛盾）。当該色で重い出現が `>θ` 個のラベルを**頻出**とする。短い一色代表の `a,x` 個数を `p_B,q_B`、`q_B≥1` とすると、補題2.1によって `d_B=ℓ_B−p_B>0` は同ラベルで一定である。同色の頻出ラベル `B,C` について、`q_C≤θ` 個の `B` 出現と `q_B≤θ` 個の `C` 出現を別々に置換すると、どちらも他の純粋 `a` 出現が残って `a` 個数が正、かつ `x` 個数が `q_Bq_C` となる。従って `q_Cd_B=q_Bd_C`。この色の頻出ラベルは共通比 `α_x=d_B/q_B>0` を持ち、`α_x≤ℓ_B=p_B+α_xq_B≤θ(1+α_x)`。
3. 非頻出飽和ラベルはラベルごとに重い出現 `≤θ`、合計 `≤vθ`。項1と式 (3.3) を足すと、頻出でない重い**例外節点数**は
   \[
   E:=v(\theta+h_T+19)\tag{3.5}
   \]
   以下（`18v+vθ+v(h_T+1)`）。残る頻出節点の比は `α_b,α_c` の高々2種類である。
4. `H:=vθ+E=v(2θ+h_T+19)` と置き、
   \[
   A_1=(r+1)θH,\quad P_1=θ(1+A_1),\quad
   A_2=H(θ+rP_1),\quad P_2=θ(1+A_2).\tag{3.6}
   \]
   比の小さい方 `α_1` が `≤θ` ならそのまま `α_1≤A_1`。大きければ、その色の一頻出節点 `u` の下では、任意の頻出節点の生成長が `≥α_1`、一深さの頻出節点数が `≤θ(1+α_1)/α_1<θ+1`、ゆえに `≤θ`。高さ `≤v` と例外 `≤E` により重い節点は `≤H`。式 (1.1) の部分木版で `α_1≤ℓ_u≤(r+1)θH=A_1`。従って小さい比の全頻出節点長は `≤P_1`。
5. 二色の比があるとき、大きい方 `α_2` が `≤P_1` ならよい。そうでなければ、その頻出節点の下で小さい比の頻出節点（長さ `≤P_1`）と非重い節点を停止し、大きい比の頻出節点と例外のみを core とする。前者の各深さの幅は項4と同じ数え方で `≤θ`、例外総数は `≤E`、core は `≤H`。各 core 節点が直書きする長さは `≤θ`、停止した子は `≤P_1` なので `α_2≤ℓ_u≤H(θ+rP_1)=A_2`。全頻出節点長は `≤P_2`。
6. 長さが `>P_2` の節点は全て例外で `≤E`。根がそれ以下なら `k≤P_2`、そうでなければ直書きと高々 `rE` 個の短い子を数えて
   \[
   k\le Eθ+(1+rE)P_2.\tag{3.7}
   \]
   `Q=θ+h_T+20` とし、`r≥2,v,θ≥1,h_T≥0` を用いると `E≤vQ`、`H≤2vQ`、`P_1≤3(r+1)vθ²Q`、`P_2≤9r(r+1)v²θ³Q²`、`1+rE≤2rvQ`。式 (3.7) は `vQθ+18r²(r+1)v³θ³Q³` 以下となり、`19(r+1)³v³θ³Q³` 以下である。□

**確認上の留意点**：本証明は全体の Parikh 飽和性、影の文法厚さ、短い代表が各成分とも同一色であることなどを黙示的に仮定していない。二穴文脈の非空セパレータは、`a⁴` による移送と、二文字影のラン交換で満たされている。先行報告の定数19は、§付録の整数検算に加え、上記の代数的不等式で検証している。

## 4. 反例に必要な、より強い局所障害

**系4.1（任意の最短導出に長い同名反鎖が必要）**。上記条件において

\[
 h_T\ge \max\left\{0,
 \left(\frac{k}{19(r+1)^3v^3θ^3}\right)^{1/3}-θ-20\right\}.\tag{4.1}
\]

また `\mathscr B` が空でなければ、両文字型のあるラベル `B` は保護位置外だけで少なくとも `h_T/v` 個の重い出現を持つ。

**証明**。第一式は定理3.2を変形したもの。第二式は `h_T≤∑_{B∈\mathscr B}q_B^*≤v max_B q_B^*` による。□

したがって `r` を固定し、`v_n,θ_n=n^{O(1)}` だが `k_n=n^{ω(1)}` となる適格な反例族が存在するとすれば、**どの節点数最小導出 `T_n` も**、同一の両文字型非終端が `n^{ω(1)}` 個現れる反鎖を含む。特に `k_n≥2^{cn}` のとき、`h_{T_n}` とそのラベルの出現数は `2^{Ω(n)}` に達する（多項式因子を除く）。これは第七報の「言語全体に指数的スペクトルが必要」より強い、**一つの導出木中で明示的に到達可能なスペクトル**についての必要条件である。

`\mathscr B=∅` なら `h_T=0` なので `k=O_r(v³θ⁶)`。逆に、両文字型が**ちょうど一ラベル**でも `h_T=q_B^*` としか分からず、`q_B^*≤poly(v,θ)` は本結果から出ない。**「両文字型が一種類」「その fan-out が1」だけの場合の上界は未解決**である。

## 5. 交差の置換と定理Sが、そのままでは閉じない理由

### 5.1 単一ラベルでは骨格衝突が自動的に無力

**命題5.1（単一ラベルの単調置換族における骨格の自明な整合性）**。両文字型のラベル `B` を一つ固定し、`T` のその出現の任意の部分集合 `J` を同じ `ρ_B` に置換した語を `W_J` とする。`β_B=|ρ_B|_b≥1`、`γ_B=|ρ_B|_c≥1` とすれば

\[
 (|W_J|_a,|W_J|_b,|W_J|_c)
 =(k-|J|d_B,\ |J|β_B,\ |J|γ_B).\tag{5.1}
\]

特に `σ_a(W_J)=σ_a(W_{J'})` なら `|J|=|J'|`、したがって `|W_J|_a=|W_{J'}|_a` である。

**証明**。反鎖の独立置換、補題2.1、純粋語 `a^k` の非 `a` 文字数が0であることから式 (5.1)。`a` 骨格は `b,c` の文字数を保存するので、骨格が等しければ `|J|β_B=|J'|β_B`。`β_B>0` より `|J|=|J'|`。□

**意味**：同じ `B` の置換数を増やすと、`a` 個数は変わるが `b,c` 個数も必ず変わる。よって定理Sの「同じ骨格なのに小さい `a` 個数差」という禁止状況は、**この置換族だけでは決して作れない**。逆に同じ置換数なら `a` 個数が元から等しい。これは定理Sが弱いという意味ではなく、提案された単一ラベルの単純な組合せが定理Sの適用条件を生まない、という厳密な障害である。

### 5.2 交差置換の有効範囲

ファンアウト1の `B` の二出現が純粋語中で `P a^{ℓ_B} R a^{ℓ_B} S` と並び、`R=a^t`、`t≥1` とする。`ρ=ρ_B` は `b,c` を含む。片側と両側を置換した

\[
 W_1=PρRa^{ℓ_B}S,\qquad W_2=PρRρS
\]

は確かに `L` の語であり、`X=ρRa^{ℓ_B}`、`Y=ρRρ` はともに内容 `Σ` で、一穴文脈 `P□S` を共有する。ゆえに arity 1 から **`D_L(X)=D_L(Y)` は正しい**。

ただし、この等式は**全内容の因子どうし**の分布等式である。`a^{ℓ_B}` と `ρ` の分布等式、純粋 `a` 語の短縮、または同一骨格で異なる `a` 個数を持つ二語の存在は導かれない。命題5.1の同ラベル置換に戻る限り、比較対象の `b,c` 個数が違えば骨格も違い、等しければ `a` 個数も等しい。ファンアウト2では、二成分を一つの連続因子とみなせないうえ、**二穴の間の固定語の非空性と成分ごとの内容一致**も必要であり、この一穴議論をそのまま二穴へ移していない。

### 5.3 `b⁴` と `c⁴` の存在は影の抽出を保証しない

第七報の厳密な例

\[
 L_k^\dagger=\{a^k,b^4,c^4\}\cup
 \{w:c(w)=Σ,\ |w|_a=|w|_b,\ |w|_c=4\}
\]

は全arityで内容代入可能、`μ_a=k`、全内容語の `a` 個数は `1,…,k−1` をすべて実現するが、`{a,b}` の両方を含む語および `{a,c}` の両方を含む語は存在しない。原稿の `arity 1,2` 条件だけ、あるいは `b⁴,c⁴∈L` だけでは二文字影に逃げられない。**この例に小さい reduced good 表示があるとは確認しておらず、反例族として流用しない**。

## 6. 指数的局所スペクトルが現れるが、代入可能性に失敗する厳密な近接例

**命題6.1（通常厚さも小さい near-miss）**。`n≥2` に対し、ファンアウト1、ランク2の文法 `G_n` を

```text
start A_n
A_0 -> a | D
A_i -> A_(i-1) A_(i-1) | D     (1 <= i <= n)
D   -> bc | bc D
```

とする。`L_n=L(G_n)`。このとき：

1. `G_n` は reduced good、`fan≤1≤2`、`rank≤2`、原稿 `def:standard-mcfg` のサイズで **`||G_n||=9n+15`**。
2. **`θ̄_{G_n}=2n+1`**、`μ_a(L_n)=2^n`。
3. `T` を唯一の純粋 `a` 導出とし、`i_n=min{i:2^i>2n+1}` とする。`i_n≤n` のとき、ラベル `A_{i_n}` は `2^{n−i_n}` 回重く出現し、短い代表 `bc` への連続置換だけで
   \[
   h_T\ge2^{n-i_n}-1\ge\frac{2^n}{2(2n+1)}-1.\tag{6.1}
   \]
   従って `||G_n||,θ̄_{G_n}=O(n)` に対し `h_T,m_T` は指数的に大きい。
4. **しかし** `L_2∉𝒞^{mcf}_{2,c}`。すでに arity 1 で失敗する。

**証明**。

(i) 全テンプレートは `λ`-free・nondeleting・nonpermuting・nonmerging。全非終端は `A_n` から到達可能で生産的。`|V|=n+2`、規則のサイズ寄与は `A_0` の2+3、各 `A_i` の5+3、`D` の3+5で、合計 `(n+2)+5+8n+8=9n+15`。

(ii) `D` には必ず `b,c` が現れる。よって純粋 `a` 語を作るには全 `A_i` が二分岐し、各 `A_0` が `a` を選ぶしかない。唯一の純粋語は `a^{2^n}`。通常厚さを正確に計算する。`A_j` の最短生成長は `j=0` で1、`j≥1` で2。`A_n` から一つの `A_0` へ至るまでの兄弟出力の最小長は `2(n−1)+1=2n−1` なので、規則 `A_0→D` を使う最短成功語は長さ `2n+1`。他の `A_0` 規則は `≤2n`、`A_i→D` と `A_i→A_{i-1}A_{i-1}` (`i≥1`) は最短使用語 `≤2n`、`D` の二規則は `A_n→D` の下で長さ2または4の成功語に現れる。`n≥2` だから最大は `2n+1`。

(iii) 唯一の純粋導出では `A_i` が `2^{n−i}` 個、各生成長は `2^i`。`2^i>θ` なら重い。`bc` はどの `A_i` からも生成でき、総長2、`a` 個数0。保護位置を所有しない `A_i` の `2^{n−i}−1` 個を順次置換すると、受理語の `a` 個数は `2^n−j2^i`、`b,c` 個数は各 `j`。この損失列は全て異なる。`i=i_n` の最小性から `2^{i_n}≤2(2n+1)`。

(iv) `n=2` とし、`X=bcbc`,`Y=bc` を取る。両者の内容は `{b,c}` で、`E=□` により `E[X],E[Y]∈L_2`。他方 `F=□a` では、`F[X]=bcbca∈L_2`（`A_2→A_1A_1`、左 `A_1→D→bc`、右 `A_1→A_0A_0→bc\,a`）なのに `F[Y]=bca∉L_2`。後者は `D` の語でなく、`A_2→A_1A_1` は各 `A_1` が最短2文字なので長さ3では生成不能。従って同じ内容の共通受理因子が異なる分布を持ち、arity 1 の代入可能性に反する。□

この例は**「小さい文法＋小さい通常厚さ＋巨大な局所スペクトル」だけでは矛盾しない**ことを示す。ただしそれは代入可能性を欠くからであり、`m_T≤poly(v,θ)` を `𝒞^{mcf}_{2,c}` 内で反証したことには決してならない。

## 7. できなかったことと、次に絞る一点

**未解決A**：一般の `L∈𝒞^{mcf}_{2,c}` で `h_T≤poly(v,θ)`（従って `m_T` の多項式上界に十分な条件）を証明すること。`\mathscr B` が一ラベル、あるいはそのラベルがファンアウト1の場合でさえ、ここで証明した補題からは出現数 `q_B` を抑えられない。

**未解決B**：`𝒞^{mcf}_{2,c}` に属する `G_n` で、`||G_n||,θ̄_{G_n}=poly(n)`、`μ_a(L_n)=n^{ω(1)}` を同時に満たすものを作ること。命題6.1はこのうち代入可能性の条件だけを明確に破る。

**次の一点**：**同じ両文字型ラベル `B` の多数出現を、異なるラベルの短い生成組または重なり合う二穴文脈との「交差」で結び、`b,c` の骨格を変えずに `a` 個数だけを変える仕組みを証明する（あるいはそれが不可能な文法構造を分類する）**。命題5.1により、`B` だけを固定代表 `ρ_B` へ置換する部分集合の算術では、定理Sへの矛盾が構造的に起こらない。最初に研究すべきなのは単一 `B` の置換数の再計数ではなく、`B` 以外の出現や二穴の非空セパレータを使う*交差同一骨格生成*である。

本報告は**新しい特徴標本下界を確立していない**。仮に今後、固定アルファベット `Σ={a,b,c}` の `L_n∈𝒞^{mcf}_{2,c}` と reduced good、fan-out `≤2`、rank `≤r` (`r≥2` 固定) の `G_n` で `μ_a(L_n)` の超多項式性を証明できれば、原稿 `prop:rare-type` により、少なくとも型 `{a}` の語を含む正例が必要になり、その長さは `μ_a(L_n)` 以上となる。これは**`\mathcal B^{≤r}_{2,c}`、`\mathcal B_{2,c}`、およびクラス全体に特徴標本を持つ集合駆動作用素**に対する特徴標本の**総符号長**下界であって、任意の Gold 学習器の実行時間・収束時点の下界ではない。命題6.1の `L_n` にこの議論を適用することはできない。

## 付録：Python 3 標準ライブラリによる正確な所属判定と算術検算

以下は全文。Windows の `py -3 spectrum_check.py` で実行できる。`belongs(n,w)` は無限言語 `L(G_n)` について、`D=(bc)^+` の正確な判定と `A_i→A_{i-1}A_{i-1}` の全分割をメモ化再帰で調べる**厳密な所属判定器**である。`L_2` の arity-1 違反には有限探索の非発見を使わず、**具体的な反例証明書**を用いている。定数係数の864件の整数検算は上記の代数的証明の代用ではない。

```python
"""Checks for the 2026-11-03 m-spectrum report; Python 3 stdlib only."""
from functools import lru_cache


def is_bc_plus(w):
    return len(w) >= 2 and len(w) % 2 == 0 and w == 'bc' * (len(w) // 2)


def belongs(n, word):
    """Exact membership for A_0 -> a | D, A_i -> A_(i-1)^2 | D,
    D -> bc | bc D, with start A_n. Works on arbitrary input words.
    """
    @lru_cache(None)
    def rec(i, x):
        if is_bc_plus(x):
            return True
        if i == 0:
            return x == 'a'
        return any(rec(i - 1, x[:j]) and rec(i - 1, x[j:])
                   for j in range(1, len(x)))
    return rec(n, word)


def sample_parameters(n):
    theta = 2 * n + 1
    i = 0
    while 2 ** i <= theta:
        i += 1
    if i > n:
        return theta, None, 0, 0
    q = 2 ** (n - i)
    return theta, i, q, max(0, q - 1)


def check_bounds():
    # The inequalities below are algebraically proved in the report.
    # This is merely a small implementation check, not evidence of a theorem.
    tests = 0
    for r in range(2, 6):
        for v in range(1, 5):
            for theta in range(1, 7):
                for h in range(9):
                    Q = theta + h + 20
                    E = v * (theta + h + 19)
                    H = v * (2 * theta + h + 19)
                    A1 = (r + 1) * theta * H
                    P1 = theta * (1 + A1)
                    A2 = H * (theta + r * P1)
                    P2 = theta * (1 + A2)
                    coarse = E * theta + (1 + r * E) * P2
                    bound = 19 * (r + 1) ** 3 * v ** 3 * theta ** 3 * Q ** 3
                    assert coarse <= bound, (r, v, theta, h)
                    tests += 1
    return tests


def main():
    checks = [('bcbc', True), ('bc', True),
              ('bcbca', True), ('bca', False),
              ('a' * 4, True), ('a' * 3, False)]
    for word, expected in checks:
        observed = belongs(2, word)
        assert observed == expected, (word, observed, expected)
        print('A_2:', repr(word), observed)
    print('A_2: arity-1 certificate: common E=hole, '
          'separating F=hole+a')
    for n in (6, 8, 10, 12, 16):
        theta, i, q, local_witnesses = sample_parameters(n)
        print('n=%d k=%d theta=%d i=%s q=%d chain>=%d' %
              (n, 2 ** n, theta, i, q, local_witnesses))
    print('finite bound arithmetic tests:', check_bounds())


if __name__ == '__main__':
    main()
```
