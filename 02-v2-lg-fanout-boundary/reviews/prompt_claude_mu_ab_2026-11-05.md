## 1. 設定と、分かっていること

Σ = {a, b, c}、内容型付け c、L ∈ C_{2,c}、G は L∩Σ⁺ の reduced good な表示で、ファンアウト ≤ 2、ランク ≤ r。v = |V|、θ = θ̄_G とする。

型 {a,b} の語があるとし、その最短の長さを μ_{ab}(L) と書く。
- μ_{ab} が超多項式なら、`prop:rare-type` により特徴標本の長さも超多項式になり、`op:fanout-two` は否定で解決する。
- 逆に、文字の欠けた型の代表の長さ τ を全て抑えられれば、肯定の向きの大きな一歩になる。

**侵入への帰着（確かめること）。** W を型 {a,b} の最短の語、T を W の節点数が最小の導出とする。W の a と b の出現を一つずつ印にする。
- 印を含まない重い節点（生成の長さ > θ）は、長さ θ 以下の c を含まない生成を持てない。持てば、それに置き換えて、型 {a,b} のより短い語ができてしまうからである。
- したがって、その節点の短い生成は全て c を含む。これを侵入節点と呼ぶ。
- よって、侵入節点の反鎖の幅が多項式なら、μ_{ab} は多項式である（(138) の議論の特別な場合）。

**否定の向きの経験（(149)(150)）。** 唯一の ab 語 (ab)^{2^n} と、c を含む安い逃げ道 a^i cb を持つ候補は、侵入反鎖の幅は指数になる。しかし次の二つで壊れた。
- **スロット移送（二穴）：** 文脈 □ab□ を共有する組を交換すると、c を全ての位置に置いた語が強制される。
- **近道（一穴の二段）：** c を含む語どうしの段で一つの語を強制し、次の段でそれを W の文脈に戻すと、W より短い ab 語が強制される。

支持集合の不変性により、ab 語の強制には、W を含む語の段が必ず要る。近道はその最小の形になっているらしい。

## 2. 探索の仮説（Claude の読み、確かめること）

**(H) 近道の補題。** 侵入節点が多い（反鎖の幅が大きい）と、c を含む短い逃げ道どうしが共通の文脈を持つ組が必ず現れる。そこから近道の二段で、W より短い ab 語が強制される。

もし (H) が多項式の閾値で成り立てば、μ_{ab} は多項式になる。成り立たないなら、近道を生まない逃げ道の配置が、反例の設計図になる。

## 3. してほしいこと（優先順）

1. **侵入への帰着を確かめる。** 印、配置 π、ファンアウト2の二成分の扱いに注意すること。
   - 二文字の付録の `lem:app-two-insertion` が、三文字の型 {a,b} でどこまで使えるかも調べる。この補題は、短い置き換えが作る連を数える。
   - c が入ると、置き換えた後の語はもう型 {a,b} ではない。そこで、その語を比べる相手（橋）が必要になる。
2. **小さい模型で強制閉包を計算する。** 侵入節点を二つか三つ持つ W の近傍を、抽象的な文字で表す。
   - 例：W = P y_1 Q y_2 R と、c を含む逃げ道 β_1, β_2 からなる語の集合。y_i, β_i の形を何通りか変える。
   - 健全な規則（共通の許容文脈を持つ、成分ごとの内容が同じ組は分布が等しい）だけで強制閉包を計算する。
   - W より短い ab 語が強制されるのは、どの配置か。強制されないのは、どの配置か。表にする。
3. **見つかった証明書を持ち上げる。** 抽象的な文字の基礎の証明書を、非消去準同型で具体的な語へ持ち上げる（(137)(139) と同じ方法）。持ち上げの健全性の条件は次のとおり。
   - 成分ごとの内容が保たれること
   - 二穴の中央が空でないこと
   - 種の像が仮定に含まれること
   - 持ち上げた証明書も、具体例で再生して検査する。
4. **(H) を証明するか、反例の設計図を書く。**
   - 証明できた範囲で、μ_{ab} の上界を定数付きで書く。例えば、場合分け（a⁴, b⁴ が現れるか）や、ファンアウト1の表示に限ってもよい。
   - 近道を生まない配置が見つかった場合は、それを持つ小さい文法の族を設計し、所属を証明に進めるか、どこで壊れるかを書く。
5. どれも完了しない場合は、次の三つを書いて終える。
   - 証明できたこと
   - 止まった場所
   - 次に絞るべき一点

## 4. 計算について

Python 3 の標準ライブラリだけで書き、全文を載せる（Windows の `py -3 script.py` で動く形）。コードを実行できる環境なら実際に動かし、出力をそのまま載せる。実行できない場合は「未実行」と明記し、出力を推測で書かない。

- 強制閉包では、強制した語ごとに、種から再生できる証明書（各段の E, x, y, F）を残す。再生は別の関数で独立に行う。
- 閉包を長さで切る場合、「短い ab 語が強制された」は切っても正しいが、「強制されない」は切った範囲での観察にすぎない。この区別を明記する。
- 所属を文法で判定するときは、長さで切った集合ではなく、文法から厳密に判定する。
- 計算の量に気をつける。閉包はすぐに大きくなるので、長さの上限と段数の上限を決め、早く止める条件を入れる。
- 有限の検査の結果から、無限の族の代入可能性を推定しない。

  - 型 {a,b} の結果を、他の文字の欠けた型（成分の一方だけが ab など）に広げて書かない。
  - μ の結果を τ に広げて書かない。
- 反例を主張するのは、所属・下界・文法の大きさの全てを証明した場合だけ。
- 「最大の特徴標本」と書かない。
- 「境界がファンアウトで動く」は、三文字の全ての内容型・全ての場合を証明した場合にだけ書く。
