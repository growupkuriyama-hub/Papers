# 依頼：二文字・ファンアウト1で、型付け s_{U,2} の特徴データは多項式か（`op:S1` の肯定の向き）

（2026-11-08。Astra 向け。報告書名：`astra_S1_positive_2026-11-08.md`（＋必要なら `.py`）。冒頭に判定表。この依頼文だけで読めるように書いてある。リポジトリ `growupkuriyama-hub/Papers` の `02-v2-lg-fanout-boundary/reviews/` の報告を参照してよい。）

## 1. 問題

Σ = {a, b}。型付け s_{U,2}：純な a の語（a⁺）は型 1、b を含む語は全て型 ζ。

- **(1, s_{U,2})-代入可能**：同じ型の空でない語 x, y が言語 L の中で一つの文脈 (l, r)（lxr, lyr ∈ L）を共有すれば、x と y の文脈の集合（分布）は等しい。このクラスを C₁ と書く。b を含む因子は全て互いに比べられ、純な a の因子どうしも比べられるが、純な a の因子と b を含む因子は比べない。
- G は L∩Σ⁺ の reduced・ε なし・ランク ≤ r（r ≥ 2）の CFG。‖G‖ = |V| + Σ_{X→γ}(1+|γ|)。**規則の厚さ** θ := θ̄_G は、各規則について「その規則を使う開始記号からの導出が生成する最短の語の長さ」の最大値。
- **問い（`op:S1`）**：L ∈ C₁ で a⁺ ∩ L ≠ ∅ のとき、最短の純な a の語 a^N について N ≤ poly(‖G‖, θ) か。（特徴データ全体の多項式には、型付き非終端ごとの同じ評価が要るが、まず開始記号でよい。）

**意味**：肯定なら「U₁ への型付けは、二文字では全てのファンアウトで多項式、三文字ではファンアウト1で指数的」という、字母の大きさによる境界になる（三文字の指数族は論文の定理C、二文字のファンアウト ≥ 2 の多項式は論文の `thm:two-letter-content`）。否定なら、二文字で同じ型付けのままファンアウトが境界を動かす分離定理になる。**どちらの答えも歓迎する。**

## 2. 既に分かっていること（全て証明済み）

1. **値の一様性**（C.0）：非終端 X の同じ型の生成語 y, z は X の成功文脈を共有するので分布が等しい。従って任意の U, V について UyV ∈ L ⇔ UzV ∈ L（UyV が X の導出に由来しなくてよい）。
2. **消去律**：x, y が同じ型で、zx が L の因子として現れ zx ≡ zy なら x ≡ y（右も同じ）。
3. **重い節点**：a^N の節点数最小の導出 T で、生成語の長さが θ を超える節点を重いと呼ぶ。重い節点のラベル B は長さ ≤ θ の生成語 ω_B（b を含む）を持つ。T の各節点の生成語は、そのラベルの最短の純な生成語。
4. **重い分岐が無ければ多項式**：どの規則も a-重い非終端の子を二つ以上持たなければ N ≤ (r+1)|V|θ（`claude_two_letter_fanout1_2026-11-01.md` 命題B.2）。
5. **整列の強制**（同 補題C.0, 命題C.1, C.2）：二重化 E_i → E_{i−1}E_{i−1} | μ_i と多段の積の族は、上の段の短い語が下の段の幅だけずれた位置に置かれた語を要求されて崩れる。
6. **群の原像は多項式**（`claude_problemG_mixing_2026-11-08.md` 定理G、Astra 検証済み）：有限群 H、φ⁻¹(1) の文法について |H| ≤ C(r‖G‖θ)^κ。証明は「全ての単位元語を数える計数＋混合時間」。
7. **加法的な重みの水準は二次**（`astra_cancellative_preimage_2026-11-08.md` 定理A）：全ての語が α|w|_a + β|w|_b = αN を満たすなら N ≤ (r+1)θ²。
8. **消去的モノイドの原像**（同 報告）：像が群なら（文脈自由な原像 ⇒ virtually free ⇒ 歪みなし）多項式。一関係子・Adian 非循環の二文字表示も不可。真の部分モノイドは未解決。
9. **下界側**：s_{U,2} の特徴データは θ̄²/4 を超えることがある（‖G‖ = O(log θ̄)、論文の退避中の `prop:binary-u1-quadratic`）。従って肯定の多項式は θ について次数 ≥ 2。

## 3. 有限の標的についての Claude の整理（証明つき、未検証）

L が有限で L ∈ C₁ とする。

- **(F1) 反鎖**：x ≡ y（同じ型）なら、どちらも他方の真の因子でない（y = uxv, uv ≠ ε なら x の文脈 (lu, vr) が y の文脈になり、l u^k x v^k r ∈ L が無限個できる）。
- **(F2)** L の b を含む語は全て文脈 (ε, ε) を共有するので互いに ≡、従って **L ∩ Σ*bΣ* は因子の反鎖**。同様に各非終端の b を含む生成語も反鎖。純な a の語は a^N 一つ。
- **(F3) 置き場所**：b を含む短い語 ω について P(ω) := {(x, y) : a^x ω a^y ∈ L}。(F2) から P(ω) は積順序の反鎖（x < x′ ⇒ y > y′）。特に x が y を決める。
- **(F4) 重みの整合**：T から得られる置き場所は ω_B について直線 x + y = N − n_B の上にある（n_B は B の純な生成語の長さ）。1. で強制される置き場所（例：B → C D なら、C が置ける全ての位置に B が置ける）も同じ直線の上に乗る。従って矛盾は「同じ b を含む語 z が、重みの違う二つの置き場所 a^x z a^y, a^{x′} z a^{y′}（x+y ≠ x′+y′）を持つ」ときにしか生じない。これは 3 文字のファンアウト2の研究で「骨格衝突（補題C）」と呼ばれた現象と同じ形。
- **(F5)** 群の原像では置き場所の重みが mod ord φ(a) で整合し、衝突しない（その代わり定理G で文法が大きくなる）。加法的な重みでも衝突しない（その代わり定理A で N が小さくなる）。

## 4. 依頼

**課題1（本命）.** 有限の標的で `op:S1` の肯定を証明する：N ≤ poly(‖G‖, θ, r)。方針の候補：
- (a) 整列の強制で生じる置き場所を全て集めた「重み」W を b を含む語の上に定義し、W が (i) 加法的なら定理A、(ii) 加法的でないなら衝突（F4）が起きる、という二択を示す。
- (b) 定理G の証明の型（全ての語の計数）を使う：(F2) の反鎖と文法の大きさの関係（反鎖の語の数と中間の部分木の値の数）から、置き場所の多様性を文法の大きさで抑える。
- (c) 最下部の重い節点から始める帰納法（定理A の証明の型）：最下部の重い節点 B（θ < n_B ≤ (r+1)θ）で「b を a で換算するレート」を抑え、上の段へ伝える。

**課題2.** 一般（無限の標的も含む）の肯定。有限の場合の議論のどこが壊れるか（群の原像は無限で (F1) が使えない）。定理G の方法と有限の場合の方法をつなぐ二択（「消去的な構造が群のように広がって文法が大きい」か「整列の強制で短い純な語が出る」か）。

**課題3（否定の向き）.** 課題1の議論が通らない箇所から、**加法的でないのに衝突しない重み**を持つ有限言語の族を設計し、C₁ への所属、文法の大きさ・厚さを確かめる（必要条件は 2. と 3.）。小さい場合の全数検査は補助として可（`claude_two_letter_fanout1_2026-11-01.md` §7 のスクリプト、`reviews/check_*` 参照）。

**課題4（任意）.** 3. の (F1)–(F4) の検証。
