## 1. 課題1：定理P∞ の新しい部分の検査

反例を探すつもりで一行ずつ読んだ。誤りは見つからなかった。以下、確かめた内容と、見つけた強化。

### 1.1 補題Π

- **(a) 加法**：a^{p+q}z₀ = a^p(a^qz₀) ≡ a^pz₀ ≡ z₀。合同性だけ。正しい。
- **(a) 差**：p < q ∈ P₀ で a^pz₀ ≡ z₀ ≡ a^p·(a^{q−p}z₀)。補題2.1 を z = a^p、x = z₀、y = a^{q−p}z₀ に使う。要るのは (1) x, y が同じ型（どちらも b を含む）、(2) zx = a^pz₀ の分布が空でない。(2) は a^pz₀ ≡ z₀ と、z₀ = ω_Ya^{g₀} が W₁ = a^{x}ω_Ya^{g₀}ω_Ya^{y} の因子であることから出る。**依頼の確認点は正しい。**
- **(b)**：f < f′ ∈ F(l, r) なら a^fz₀, a^{f′}z₀ は b を含み、文脈 (l, r) を共有するので ≡。消去の zx = a^fz₀ は文脈 (l, r) を持つので分布は空でない。逆向きは合同性。正しい。
- **補足（明記すべき）**：F は下にも閉じる。f ∈ F、f ≥ p₀ なら a^fz₀ = a^{f−p₀}(a^{p₀}z₀) ≡ a^{f−p₀}z₀ なので f − p₀ ∈ F。従って **f_min < p₀ で、F = {f ≥ 0 : f ≡ f_min (mod p₀)}**。補題2.3‴ の「val(u) − d ∈ F ⇔ val(u) − d ≡ e\* (mod p₀)」はこれがないと「≥ f_min」の条件が抜ける。結論は正しいが、この一行を足すべき。

### 1.2 補題S と、その強化（補題S′）

**補題S の検査**：
- 左：W = a^{x₁}ω_Ya^{y₁} = a^{x₁−D}(a^Dz₀)a^{y₁−g₀} ≡ a^{x₁−D}ω_Ya^{y₁}。a^{x₁} と a^{x₁−D} は文脈 (ε, ω_Ya^{y₁}) を共有する。x₁ = D+1 でも x₁ − D = 1 ≥ 1 で、空でない純な語どうしなので C₁ が使える。x₁ + n_Y + y₁ = N、n_Y ≥ 1 なので x₁ < N で、a^{x₁} は a^N の因子（文脈 (ε, a^{N−x₁})）。a^{N−D} ∈ L、N − D ≥ x₁ − D ≥ 1。最短性に反する。正しい。
- 右：y₁ − D > g₀ ≥ 0 なので右の塊は空でない。N − D ≥ y₁ − D ≥ 1。正しい。
- y₁ ≥ g₀：u₂ は u₁ の右にあるので y₁ ≥ (x₂ − x₁ − n_Y) + n_Y = d ≥ g₀。正しい。

**補題S′.** L ∈ C₁（s_{U,2} でも c でもよい）、z の分布が空でなく、p ≥ 1 について a^pz ≡ z なら **N ≤ p**。z a^p ≡ z でも同じ。

*証明.* (l, r) を z の文脈とする。a^pz ≡ z、a^{2p}z ≡ z から l a^{p}z r, l a^{2p}z r ∈ L。従って a と a^{1+p} は文脈 (l a^{p−1}, z r) を共有する（l a^{p−1}·a·z r = l a^pz r、l a^{p−1}·a^{1+p}·z r = l a^{2p}z r）。両方とも空でない純な語（型 {a}）なので C₁ から a ≡ a^{1+p}。N ≥ p + 1 なら a^N = a^{N−1−p}·a^{1+p} の a^{1+p} を a に替えて a^{N−p} ∈ L∩Σ⁺ となり、最短性に反する。右も同様。□

**帰結.**
- P₀ ≠ {0} なら N ≤ p₀ ≤ D。V\* ≤ N なので **Λ = V\* が常に成り立つ**。定理P∞ の最後の場合分けの「Λ = D < V\*」は空で、補題S は使われない。
- 依頼の「D < N となる無限の正則な C₁ 言語」は**存在しない**。付属スクリプト (C-iii) が D < N の例を一つも持たなかったのは必然である。
- 比べるのは二つの純な語なので、内容型付け c でもそのまま成り立つ。付属スクリプト (S′) で c と s の両方を検査した（§5）。

### 1.3 補題2.3‴

- 補題2.2′ から u ≡ a^{val(u)−d}z₀（u は崩壊する語を含むので val(u) ≥ d）。
- l u r ∈ L ⇔ val(u) − d ∈ F(l, r) ⇔（§1.1 の補足）val(u) − d ≡ e\* (mod p₀)。
- val(u) と V\* = e\* + d はどちらも d の倍数なので、mod p₀ と mod d の同時の合同、すなわち mod lcm(d, p₀) と同値。逆向きも同じ。
- **正しい**（§1.1 の補足を前提に）。

### 1.4 (P4′)、(P6′)、最後の場合分け

- **(P4′)**：取るのは Λ/2 以下の値だけで、各値は前の値の 2 倍を超える。和 Σ は最後の値の 2 倍未満なので Σ < Λ ≤ D。止め方 (α)(β) と M = 0 の場合（v_{i\*} > Λ/2 なら Λ < 2B₁）も確かめた。正しい。
- **(P6′) の依頼の確認点**：記録の論証で移した語は l·u″·Q·r。u″ の価値は、π の外側の符号、二つのまたぎの符号（π と π′ で番号とずれが一致）、π′ の内側の符号の和になる。w_π の価値と比べると
  - val(u″) − Σv = Σ_{I(π′)} − Σ_{I(π)}。
  - I(π), I(π′) はどちらも**取った M 個の符号の添字集合**（重複なし）なので、部分和はどちらも [0, Σ) ⊂ [0, D) に入る。
  - 補題2.3‴ から差は ≡ 0 (mod D)。両者が [0, D) にあるので整数として等しい。超増加なので部分和は集合を決め、I(π′) = I(π)。
  - **全ての部分和が D 未満か、の答え：はい。** 正しい。
- **簡約**：補題S′ により D ≥ p₀ ≥ N > Σ なので、mod p₀ で足り、lcm も場合分けも要らない。定理P∞ の結論は **N ≤ max{K(K+2)θ, Φ(K, θ) + 2d}** に締まる（2Φ + 2d ではなく）。指数は変わらない。

### 1.5 群の原像での試金石

**構造.** φ: Σ\* → H を全射、L = φ⁻¹(1)∩Σ⁺ とする。D_L(x) = D_L(y) ⇔ φ(x) = φ(y)。
- (C1′) の z₀z₀ ≡ a^dz₀ から φ(z₀) = φ(a)^d、すなわち z₀ ≡ a^d。
- 非終端 X の語は全て同じ φ の値を持つ（一つの文脈で決まる）。従って重いラベル X の短い語 ω_X（≤ θ）は φ(a)^{n_X} を表す。
- p₀ = ord φ(a) = N、D ≥ N なので Λ = V\*。
- つまり群の場合、定理P∞ の論証は「重い道に沿う長さ ≤ θ + 2d の語で、φ(a) の冪の指数が超増加する Θ(log N) 個が取れる。その置換の積が全て L に入るので、置換の言語に対する CFG の大きさの下界（定理C\* の数え上げ）が効く」に帰着する。これは透明に正しく、混合時間を使わないのも自然である。

**既知の例との照合.**

| 例 | N = ord φ(a) | 既知の ‖G‖, θ の下界 | 定理P∞ との関係 |
|---|---|---|---|
| 巡回群 Z/n、a ↦ 1、b ↦ 0 | n | **θ ≥ n**（根の規則の子 X は n_X ∈ [1, n−1] で、X の語は a を ≥ n_X 個含む。根の規則を使う L の語は a の個数が正で n の倍数なので ≥ n）。既知の ord ≤ (r+2)θ̄² とも整合 | N ≤ θ。自明に両立 |
| 二面体群 D_n、a ↦ 回転、b ↦ 鏡映 | n | φ(a)^k を表す最短の語は長さ min(k, n−k+2) 程度。n_X ≈ N/2 の重いラベルがあるので θ ≥ Ω(n) | 両立 |
| H_n = Z/(2ⁿ−1) ⋊ Z/n | 2ⁿ − 1 | ‖G‖ ≥ 2^{(2/3−o(1))n}（`chatgpt_problemG`） | 定理P∞ が要求するのは (‖G‖+2)^{76}θ^{21} ≥ 2ⁿ/C だけ。定理P∞ の論証自身が出す下界は ‖G‖ ≳ 3^{M/3}/poly ≈ N^{log 3/(3 log 6)} ≈ 2^{0.20n}/poly で、既知の下界より**弱い**。両立 |
| 対称群 S_n、n-サイクルと互換 | n | ‖G‖, θ ≥ 1 | N = n は何の多項式でもよい。両立 |

**判定**：矛盾なし。**ただしこの試金石の検出力は弱い**。定理G（独立検証済み）が既に |H| ≤ poly を与えるので、群の範囲で定理P∞ に反する例は定理G にも反する。また定理P∞ の定数は大きく、小さい例では不等式が自明に成り立つ。定理P∞ の誤りが群の外でだけ効く種類のものなら、この試金石では捕まらない。

## 2. 課題2：内容型付け c での `op:S1`（定理P∞-c）

以下 L ∈ C_{1,c}（無限でもよい）。型は {a}（純な a）、{b}（b⁺）、{a,b}（混合）。補題2.1 は「同じ内容」の x, y について成り立つ。

### 2.1 型を使わない部分（そのまま移る）

- 補題P1 (a)–(e)、n_X が T の中で well-defined、ω_X の存在（P1 (b)：使うのは純な語の最短性だけ。ω_X は b⁺ でも混合でもよい）。
- 定理C\* の記録の論証（部分木の差し替えだけ）、補題2.2′（合同性だけ）。
- 補題S′（純な語どうしの比較、§1.2）。
- (P3)、(P4′)、(P5)、(P6′) の算術。

型が効くのは**補題R の消去**、**(P2) の C.0**、**補題Π の消去**の三箇所。

### 2.2 補題R^c

T の二つの種 u₁, u₂（ラベル Y、位置 x₁ < x₂、d = x₂ − x₁、g₀ = d − n_Y ≥ 0）、ω := ω_Y、x := x₁、y := N − x₂ − n_Y。W₁ = a^xωa^{g₀}ωa^y、W₂ = a^xωa^{d+y}、W₃ = a^{x+d}ωa^y ∈ L。

**補題R^c.**
- **(通常の場合) g₀ ≥ 1 または ω が混合**：z₀ := ωa^{g₀}、c := d で a^dz₀ ≡ z₀a^d ≡ z₀z₀。
- **(悪い場合) g₀ = 0 かつ ω ∈ b⁺**：z₀ := ωa^d、c := 2d で a^dz₀ ≡ z₀a^d、z₀z₀ ≡ a^{2d}z₀。

どちらでも z₀ は**混合**で、(C1′)（g := d、g | c）が成り立つ。

*証明.*
- W₂, W₃ は a^d（d ≥ 1）と b を含むので混合。W₁ が b⁺ なのは x = g₀ = y = 0 かつ ω ∈ b⁺ のときだけで、そのとき根の語は二つの種だけからなり、種が > K ≥ 2 個という前提に反する。従って三語は混合で文脈 (ε, ε) を共有し、W₁ ≡ W₂ ≡ W₃。
- **(ii) a^dω ≡ ωa^d は両方の場合で成り立つ**：W₂ ≡ W₃ の左の a^x を消す（残り ωa^{d+y} と a^dωa^y はどちらも混合）。次に右の a^y を消す（残り ωa^d と a^dω はどちらも混合で、ωa^d は W₂ の因子）。
- (通常の場合)：W₁ ≡ W₂ から a^x を消し（ωa^{g₀}ωa^y、ωa^{d+y} はどちらも混合）、a^y を消す（ωa^{g₀}ω、ωa^d はどちらも混合）。以下 `claude_S1_problemC` の補題R と同じ。
- (悪い場合)：ωω ≡ ωa^d は型が違うので出せない（実際に偽になりうる。付属スクリプトで 6642 例）。代わりに、x ≥ 1 か y ≥ 1（上の議論から）の側に a を一つ残す。
  - y ≥ 1 なら W₁ ≡ W₂ から a^x と a^{y−1} を消して **ωωa ≡ ωa^{d+1}**（どちらも混合、ωωa は W₁ の因子）。
    z₀z₀ = ωa^dωa^d ≡ ωωa^{2d} = (ωωa)a^{2d−1} ≡ ωa^{3d} = z₀a^{2d} ≡ a^{2d}z₀。
  - y = 0, x ≥ 1 なら a^{x−1} だけ消して **aωω ≡ aωa^d**。
    z₀z₀ ≡ a^{2d}ωω = a^{2d−1}(aωω) ≡ a^{2d}ωa^d = a^{2d}z₀。
  - a^dz₀ = a^dωa^d ≡ ωa^{2d} = z₀a^d。□

**(P3) の目標**：悪い場合は y₁ ≥ d が要る。y₁ ≥ x₂ − x₁ = d なので成り立つ。a^{x₁}ω_Ya^{y₁} = a^{x₁}z₀a^{y₁−d} から e\*, ρ, ρ′ を同じように取り、V\* := e\* + c = N − ρ − ρ′（n_Y = d を使う）。

### 2.3 補題C.0^c（依頼文の「本当の障害」）

0 < i ≤ i\* とする。X_i は T の根でないので、T の中の X_i の純な文脈 (a^{p_i}, a^{q_i}) は p_i + q_i = N − n_{X_i} ≥ 1 を満たす。Ω_i := a^{L_i}ω_Ya^{R_i}（X_i の部分木で u₁ を ω_Y に替えた語）は、L_i + R_i = n_{X_i} − n_Y ≥ 1 なので混合。

**補題C.0^c.**
- ω_{X_i} が混合なら ω_{X_i} ≡ Ω_i。
- ω_{X_i} ∈ b⁺ で p_i ≥ 1 なら aω_{X_i} ≡ aΩ_i。p_i = 0（従って q_i ≥ 1）なら ω_{X_i}a ≡ Ω_ia。

*証明.* a^{p_i}ω_{X_i}a^{q_i} と a^{p_i}Ω_ia^{q_i} はどちらも T の X_i の部分木を差し替えた導出の語なので L に入る。混合の場合は二語が文脈 (a^{p_i}, a^{q_i}) を共有する。b⁺ の場合、aω_{X_i} と aΩ_i はどちらも混合で、文脈 (a^{p_i−1}, a^{q_i}) を共有する。C_{1,c} から ≡。□

**詰め物つきの符号.**
- 左から借りた場合：s′_i ∈ [1, d] を d | L_i + s′_i となるように取る。
- それ以外：s′_i ∈ [0, d) とする。
- s_i は、通常の場合 R_i + s_i ≡ g₀ (mod d)、悪い場合 R_i + s_i ≡ 0 (mod d) となるように取る。範囲は、右から借りた場合と悪い場合は [1, d]、それ以外は [0, d)。
- ẑ_i := a^{s′_i}ω_{X_i}a^{s_i} とおく。補題C.0^c と合同性（借りた a は詰め物の中に含まれる）から ẑ_i ≡ a^{s′_i}Ω_ia^{s_i} = a^{s′_i+L_i}z₀a^{κd}（κ ≥ 0。悪い場合は R_i + s_i ≥ d なので κ ≥ 0 になる）≡ a^{e_i}z₀、d | e_i。
