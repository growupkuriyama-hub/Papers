# 消去的モノイドの原像と二文字・ファンアウト1の下界

2026-11-08。依頼文の定義を用いた独立調査・証明報告。

**総合判定：この枠組み全体から反例が作れないとは証明していない。しかし、一関係子／通常の Adian 非循環表示から探す方針は二文字では排除できる。(O4) は正しく、外部の重み付き言語の報告に依存せず、より強い二次上界が証明できる。**

本稿の「証明」は以下に記載した論証を指し、独立の他者査読済みを意味しない。定理Gと特徴標本の rare-type 命題は依頼文の前提として受け取り、再検証していない。文献の定性的な歪みを、文法族についての一様な多項式評価と混同しない。

## 1. 設定と量化の修正

\(S=\psi(\{a,b\}^*)\) と置く。以後の「単元」「準同型」「群になる」は、特記しない限り周囲の \(M\) ではなく **像モノイド \(S\)** に関する。

\(L=\psi^{-1}(m)\cap\{a,b\}^+\) を reduced、ε規則なし、ランク高々 \(r\) の CFG \(G\) が生成し、\(a^N\in L\)、\(\theta=\bar\theta_G\) とする。

### 1.1 (O1)、(O2) と非終端の値

\(l x r,l y r\in L\) から両側の消去によって \(\psi(x)=\psi(y)\)。従って任意の文脈で同時に所属し、一穴代入可能性が成立する。\(x,y\) が非空なので、\(\Sigma^+\) への制限による例外もない。

到達可能・生産的な非終端 \(B\) には、終端文脈 \(u,v\) を固定して \(uL(B)v\subseteq L\) とできる。消去律から \(\psi(L(B))\) は一点集合である。

消去的モノイドでは \(a^p=a^q\), \(p<q\) なら \(a^{q-p}=1\)。したがって「\(\psi(a)\) が無限位数」はここでは正の冪が互いに異なるという意味でよく、その場合 \(L\cap a^+=\{a^N\}\) である。

### 1.2 (C1) の正確な意味

\(\operatorname{Hom}(S,(\mathbb Q,+))=0\) が本来の条件である。\(S\) の普遍群を \(U(S)\) とすれば、これは \(U(S)_{\rm ab}\) が有限であることと同値。理由は、群への準同型の普遍性と、二生成ゆえ \(U(S)_{\rm ab}\) が有限生成アーベル群であること。

\(S\hookrightarrow H=\langle S\rangle_{\rm grp}\) という特定の群埋込みがある場合、(C1) から \(H_{\rm ab}\) 有限は従う。しかし一般には逆向きの推論に追加の根拠が要る。\(S\) 上の準同型が、任意に選んだ周囲の群 \(H\) に延長するとは限らない。普遍群と周囲の群を同一視しないこと。

### 1.3 (C2) は必要条件としては強すぎる

反例族から直ちに必要になるのは

\[
\ell^+_S(\psi(a)^{N_n})\le\theta_n
\]

という**標的冪の短い正の表示**である。これは開始記号の短い生成語から従う。重い節点についても同様の短い表示が必要になる。

しかし \(N_n\) が \(n\) の超多項式、\(\theta_n\le\operatorname{poly}(n)\) であるだけでは、\(\theta_n\le\operatorname{poly}(\log N_n)\) は従わない。例えば数値関係 \(N_n\asymp\exp((\log n)^2)\), \(\theta_n=n\) は前者を満たし後者を満たさない。さらに特定の部分木の冪についての短縮から、全ての \(a^{2^j}\) の短縮も従わない。

**従って、依頼文の強い (C2) を否定しても、rare-type による全ての反例を否定したことにはならない。** また \(S_n,a_n,b_n\) が変化する族では、各個の群で巡回部分群が非歪曲でも、その線形下界の定数が族について一様かを別に調べる必要がある。

## 2. 主結果：二文字の加法的重みに対する二次上界

### 定理 A（符号任意の重み）

上記の CFG \(G\) に対し、実数 \(\alpha,\beta\) が \((\alpha,\beta)\ne(0,0)\) を満たし、全ての \(w\in L(G)\) について

\[
\alpha |w|_a+\beta |w|_b=\alpha N
\tag{2.1}
\]

とする。このとき、\(L(G)\) に含まれる最短の純な \(a\) 語の長さ \(N_{\min}\) は

\[
\boxed{N_{\min}\le (r+1)\theta^2.}
\tag{2.2}
\]

\(\alpha\ne0\) なら純な \(a\) 語の長さは一意なので \(N=N_{\min}\)。\(\alpha=0\) のときは (2.2) の \(N_{\min}\) を任意の \(N\) に置き換えてはならない。

#### 証明

**厚さからの二つの事実。** 各非終端 \(B\) は長さ高々 \(\theta\) の生成語 \(\omega_B\) を持つ。実際、\(B\) の規則を一度使う長さ高々 \(\theta\) の開始記号からの導出を取り、その部分木を抜き出せばよい。また任意の規則の右辺に直接書かれている終端の個数も \(\theta\) 以下である。ε規則なしなので導出中の終端が消失することはない。

**場合1：\(\alpha=0\)。** \(\beta\ne0\) なので (2.1) より全ての生成語は \(a\) だけからなる。開始記号の短い生成語を取れば \(N_{\min}\le\theta\)。

**場合2：\(\alpha\ne0\)。** \(\alpha\) で割って \(w(a)=1,w(b)=t=\beta/\alpha\) と正規化する。この時点で \(t\) の符号は仮定しない。

任意の非終端の生成語は同じ重みを持つ。これは固定した到達文脈に代入し、(2.1) から文脈の重みを差し引けば分かる。消去的モノイドはこの議論には不要である。

\(N\le\theta\) なら結論は明らか。\(N>\theta\) とし、\(a^N\) の導出木で、生成する部分語の長さが \(\theta\) を超える非終端節点を重いと呼ぶ。子の非終端節点が全て重くない、最下部の重い節点を一つ選ぶ。そのラベルを \(B\)、生成する純な語を \(a^d\) とする。子の数は高々 \(r\)、各子の長さは高々 \(\theta\)、直接の終端数も高々 \(\theta\) だから

\[
\theta<d\le(r+1)\theta.
\tag{2.3}
\]

短い生成語 \(\omega_B\) の文字数を \(p=|\omega_B|_a,q=|\omega_B|_b\) とすると

\[
d=p+tq,\qquad p+q\le\theta.
\]

もし \(q=0\) 又は \(t\le1\) なら \(d\le\theta\) となり矛盾する。従って \(q\ge1,t>1\)。さらに

\[
t=(d-p)/q\le d\le(r+1)\theta.
\tag{2.4}
\]

開始記号の短い生成語 \(\omega_S\) に戻ると

\[
N=|\omega_S|_a+t|\omega_S|_b
\le t|\omega_S|\le(r+1)\theta^2.
\]

これで証明された。□

### 系 A.1（(O4) の独立証明）

消去的モノイドの原像の設定で \(S\to\mathbb Q\) に非自明な準同型があれば、最短の純な \(a\) 語は (2.2) を満たす。

\(\alpha=\lambda(\psi(a)),\beta=\lambda(\psi(b))\) と置けばよい。\(a,b\) が \(S\) を生成するので両方が0なら \(\lambda\) は自明である。

従って \(N_n>(r_n+1)\theta_n^2\) を満たす反例候補の各項では (C1) が必要である。\(r_n\le\|G_n\|\) なのでランクを固定しなくても、サイズと厚さが多項式なら上界も多項式になる。

**監査結果：** 依頼文の非負重みに関する別報告は不要。負の重み、片方が0、非整数の重みを全て処理できる。「両方が正である」という追加仮定も不要。依頼文の三次上界は、本設定では二次上界で置換できる。

## 3. 一関係子と Adian 非循環表示の経路は排除できる

### 命題 B（二文字一関係子）

\(S=\operatorname{Mon}\langle a,b\mid u=v\rangle\) なら、非自明な \(S\to\mathbb Q\) が存在する。消去性も関係子の非空性も、この主張には不要。

**証明。** \(\Delta=(|u|_a-|v|_a,|u|_b-|v|_b)\) とする。\(\Delta\cdot(\alpha,\beta)=0\) は高々一本の同次線形方程式なので、非零の有理数解を持つ。文字の重みをその解で定義すると、関係式が重みを保存するため商モノイドに降りる。□

よって **像モノイド自体がこの二文字一関係子表示を持つ場合**、本依頼の超多項式下界は作れない。一関係子モノイドから更に別の商を取った像には、そのまま適用できない。

依頼文の「一関係子モノイドで Parikh 差が \(\mathbb Q^2\) を張る」は不可能である。一本の関係式から得られる差ベクトルは一本だけである。

### 命題 C（通常の二文字 Adian 非循環表示）

関係式の両辺が非空である通常の Adian 左右グラフでは、各関係式が一本の辺を与え、ループも多重辺も保持する。二頂点の森は辺を高々一本しか持たない。従って二文字の非循環表示では、非自明な関係式は高々一本であり、(C1) は成立しない。

二本の関係式がどちらも \(a,b\) を始端にもつ場合、二本の平行辺は長さ2の閉路である。単純グラフに潰して「閉路なし」と判定する実装は誤りになる。始端が同じなら既にループで失敗する。

このグラフの定義と埋込み定理は Adian [1, §II, Theorems 3–5] で確認した。**判定条件を満たさないことは、非消去性の証明ではない。** 排除されるのは通常の非循環条件によって消去性を保証する探索経路であって、全ての二関係子消去的モノイドではない。

### 3.1 有限範囲の全探索

両辺を長さ1–4の二文字語に限定し、関係式の向きと二関係式の順序を同一視して列挙した。

| 項目 | 個数 |
|---|---:|
| 使用する非空語 | 30 |
| 相異なる両辺からなる一関係式 | 435 |
| 左右 Adian 非循環を満たす一関係式 | 113 |
| 相異なる二関係式の組 | 94,395 |
| Parikh 差の階数が2の組 | 66,559 |
| そのうち左右 Adian 非循環のもの | **0** |

これは命題Cの実装確認である。残る66,559件について消去性や語問題を決定したわけではない。一般候補の完備な探索を行ったと解釈してはならない。

### 3.2 「階数2になった」だけでは消去性を失う例

\[
T=\operatorname{Mon}\langle a,b\mid a^2=b^3,\ a^3=b^2\rangle.
\]

差ベクトル \((2,-3),(3,-2)\) の行列式は5なので \(T\to\mathbb Q\) は全て自明。しかし

\[
b^9=(a^2)^3=a^6=(a^3)^2=b^4.
\]

消去的なら \(b^5=1\)。一方、この**通常のモノイド表示**では空語はどの関係式にも現れず、非空語と等しくなれない。従って \(b^5\ne1\) であり、\(T\) は非消去的。

対応する群表示は \(C_5\) になる。\(a^3(a^2)^{-1}=b^2(b^3)^{-1}\) から \(a=b^{-1}\)、残りは \(b^5=1\)。この群における結論を、元のモノイドの消去性の証明にしてはいけない。

## 4. 像が群である場合の障害

### 命題 D（一原像から全語問題へ）

\(S=\psi(\Sigma^*)\) 自体が群とする。一つの非空な原像 \(L_m=\psi^{-1}(m)\cap\Sigma^+\) が文脈自由なら、\(S\) は virtually free である。

**証明。** 必要なら \(m=1\) のときだけ ε を付加し、完全な原像 \(\widetilde L_m\subseteq\Sigma^*\) にする。\(\psi(t)=m\) となる固定語を選べば

\[
t^{-1}\widetilde L_m=\{w:tw\in\widetilde L_m\}=\psi^{-1}(1).
\]

左商の閉性から、正のアルファベットでの恒等元原像が文脈自由になる。像が群なので各生成元の逆元にも正の表示があり、対称生成アルファベットからそれらの表示への準同型を作れる。逆準同型像の閉性により通常の群語問題も文脈自由。Muller–Schupp と Dunwoody の結果 [2] により virtually free。□

正則の場合も同じ帰着ができ、像の群は有限となる。逆に有限群の原像は正則である。

### 系 D.1（固定した群での強い (C2) と (C3)）

有限生成 virtually free 群の無限巡回部分群は非歪曲である。したがって固定した \(S,a,b\) について、無限位数 \(a\) の冪が正の語で \(\operatorname{poly}(\log n)\) 長に短縮されることと、一つの原像が文脈自由であることは両立しない。

非歪曲性は、有限指数正規自由部分群 \(F\) を取り、\(a^q\in F\) とすることで確認できる。自由群では非自明な元の冪の被約長が冪指数に線形に増加し、有限指数部分群の語距離は群の語距離と比較できる。正の語長は対称生成集合での語長以上である。

**限界。** 任意の真の部分モノイド \(S\subsetneq H\) にこの帰着は使えない。逆元の正の表示が欠けるからである。また、この定性的議論だけで変動する群族について \(N\le\operatorname{poly}(\|G\|,\theta)\) が出たとは主張しない。

### 4.1 (C1) と文脈自由性そのものは矛盾しない：二文字例

\[
P=\operatorname{Mon}\langle a,b\mid b^3=1,\ (ab^2)^2=1\rangle.
\tag{4.1}
\]

\(b^{-1}=b^2\)。\((ab^2)^2=1\) より \(ab^2\) も可逆であり、\(a=(ab^2)b\) は可逆元の積である。従って全ての生成元が可逆で、\(P\) は群である。\(x=ab^2,y=b\) と置くと

\[
P\cong\langle x,y\mid x^2=1,y^3=1\rangle=C_2*C_3,\qquad a=xy.
\]

- 消去性：群なので成立。
- (C1)：\(3\lambda(b)=0\), \(2\lambda(a)+4\lambda(b)=0\) から両方0。
- \(a\) の位数：自由積の被約形 \((xy)^N\) から無限。
- 全ての一原像：virtually free 群なので文脈自由。
- 正の最短長：\(\ell^+(a^N)=N\)。任意の正の表示を \(x,y\) に展開すると \(x\) の個数は元の \(a\) の個数。自由積の簡約は \(x\) の個数を増やさず、標的には \(N\) 個必要なので、表示は少なくとも \(N\) 文字ある。
- 原像：\(b^3\) を挿入できるので無限。
- 厚さ：どの CFG でも、生成語全体の最短長が \(N\) なので \(\theta\ge N\)。

従ってこれは (C1) と qualitative な (C3) の両立例であり、下界の構成ではない。例えば \(N=1\) の固定言語なら一つの固定 CFG を取れ、そのサイズ・厚さは定数である。しかし \(N\) を超多項式に増やして厚さを抑えることはできない。

## 5. 文献調査：どの結果をどこまで使えるか

|---|---|---|

**語問題の区別。** \(\psi^{-1}(1)\)、一つの \(\psi^{-1}(m)\)、全ての原像がCFであること、Duncan–Gilman の \(\{u\#v^{\rm rev}:\psi(u)=\psi(v)\}\) は、一般のモノイドでは別条件。単に自動的構造、正則な正規形、決定可能な語問題があることも、一原像がCFである証明にはならない。

**LMR の例で分かる範囲。** \(SL_3(\mathbb Z)\) を全ての \(E_{ij}(\pm1)\) でモノイド生成すれば群全体になる。各初等行列が交換子として書けるため、有理数値準同型は自明。\(E_{12}(1)\) は無限位数で、その冪は [5] によって \(O(\log n)\) の語を持つ。このアルファベットなら逆元も文字として正に使える。よって、多文字では (C1)+(C2) の具体例となる。しかしこれは十二文字の例であって二文字への解答ではなく、\(SL_3(\mathbb Z)\) は \(\mathbb Z^2\) を含んで virtually free ではないため、命題Dよりどの一原像もCFにならない。

この文献調査から、一般の二文字の真の部分モノイドに対する Muller–Schupp 型の必要十分条件は得られなかった。未確認の分類定理を補って結論を出すことはしない。

## 6. 有限原像の完全解析と数値

### 6.1 正の Baumslag–Solitar モノイド

\[
B^+=\operatorname{Mon}\langle a,b\mid ba=a^2b\rangle.
\]

\(a:x\mapsto x+1\), \(b:x\mapsto2x\) とする。語を左から写像の積として読むと、\(b\) の数を \(k\)、\(i\) 個目までの \(b\) の後の \(a\) の個数を \(c_i\) として

\[
w\mapsto(x\mapsto2^kx+\sum_{i=0}^k2^ic_i).
\]

関係式によって全ての語を \(a^t b^k\) に直せ、この写像で異なる \((t,k)\) は異なる。従ってこれは忠実な群への埋込みであり、消去性が分かる。

元 \((t,k)\) の原像は \(\sum 2^ic_i=t\) の非負整数解に対応するので有限。ただし **\(b\) の個数一定という事実だけでは有限性の証明にならず、この第二座標の評価が必要**である。

標的 \(a^N\) については \(k=0\) が必要なので、原像はちょうど \(\{a^N\}\)。\(a\) は無限位数、\(\ell^+(a^N)=N\)。\(\lambda(a)=0,\lambda(b)=1\) という非自明な準同型もある。\(N=2^j\) の倍増文法はサイズ \(4j+3\)、厚さ \(N\)。

### 6.2 有限原像で大きな短縮が起きる対照例

\[
T_K=\operatorname{Mon}\langle a,b\mid a^K=b^2\rangle,\qquad K\ge2.
\]

始端・終端の左右グラフはそれぞれ一本の \(a\)–\(b\) 辺であり、Adian [1] により消去的。重み \(\lambda(a)=2,\lambda(b)=K\) が存在するので \(a\) は無限位数、全ての原像は有限である。

\(a^K\) から可能な関係式の適用は、語全体を \(b^2\) にする操作とその逆しかない。したがって **原像全体が**

\[
L_K=\{a^K,b^2\}
\tag{6.1}
\]

である。これは長さを切って推測した列挙ではない。

一般に \(a^N\) と等しい語は \(b\) を偶数個含む。\(a\mapsto0,b\mapsto1\) の \(\mathbb Z/2\mathbb Z\) 値準同型から分かる。\(|w|_b=2h\) とすると重みから \(|w|_a=N-Kh\)。\(0\le h\le\lfloor N/K\rfloor\) なので

\[
\ell^+_{T_K}(a^N)=2\lfloor N/K\rfloor+(N\bmod K).
\tag{6.2}
\]

下界は文字数から、達成は \(a^{N\bmod K}b^{2\lfloor N/K\rfloor}\) から従う。

**小文法と厚さ。** \(K=2^j\), \(j\ge1\) とし、

\[
A_0\to a,\quad A_i\to A_{i-1}A_{i-1}\ (1\le i\le j),
\quad S\to A_j\mid bb
\]

を取る。ランク2、\(\|G\|=4j+9\)、\(\bar\theta_G=2^j\)。\(S\to bb\) 以外の規則は \(a^K\) の導出でしか使えない。

さらに**別の文法にしても厚さは下がらない**。\(a^K\) の導出で文字 \(a\) を直接出す規則を一つ選ぶと、その規則を使う開始記号からの生成語は \(a\) を含み、(6.1) より必ず \(a^K\)。従って任意の同言語の εなし CFG で \(\theta\ge K\)。

これは「標的には長さ2の表示もあり、純な語は指数的に長く、小さいCFGもある」が、**厚さだけが指数的になる**例である。固定した \(K\) では (6.2) は線形であり、本来の漸近的な指数歪曲ではない。

## 7. 有限原像・非終端の値から何が言えるか

### 7.1 有限原像には正の恒等元語がない

\(z\in\Sigma^+\), \(\psi(z)=1\) があれば、任意の \(w\in L\) に対して \(wz^k\in L\) が無限個できる。従って非空有限原像があるなら、\(S\) は非自明な単元を持たず、非空語による1の表示もない。

ただし「周囲の群で可逆」と「像モノイドで可逆」は異なる。群への埋込みだけで有限原像を排除してはいけない。

### 7.2 値の一意性だけでは指数倍増を排除できない

\(a\) が無限位数なら、純な \(a\) の導出で同じ非終端は同じ指数の部分語しか生成しない。節点数最小の導出では同じ非終端が一つの枝に二回現れることもない。二回現れれば、その間の文脈は純な \(a\) の語であり、値の一意性から長さ0。その経路を縮められて最小性に反する。

従って枝の非終端数は高々 \(|V|\)。一規則の直接終端数は高々 \(\theta\) だから、一般に得られるのは例えば

\[
N\le\theta\sum_{i=0}^{|V|-1}r^i
=\theta\frac{r^{|V|}-1}{r-1}
\tag{7.1}
\]

という指数上界である。これは多項式上界ではない。\(1,2,4,\ldots,2^j\) の値を \(j+1\) 個の非終端に割り当てる倍増文法は、値の一意性と完全に整合する。

有限原像で文法が非循環化できるというだけでも、同じ障害が残る。有限言語は自動的に正則だが、小さい CFG と小さい厚さを同時に持つことは別条件である。

## 8. 残った問題と次の探索条件

一般否定を証明するために不足しているのは、次の局所的情報から多項式評価を導く原理である。

1. 純な導出木の各非終端には一意な \(a\) の冪の値が付く。
2. 各非終端は長さ高々 \(\theta\) の正の代表語も生成する。
3. 全ての規則は同じ非終端値の乗法等式を満たす。
4. 開始記号は一つの値の**全原像**を生成する。

特に4を外して、同じ値になる語をいくつか集めた有限言語を作るだけでは依頼を満たさない。

今後の二関係子探索では、Parikh 差の階数2を入口にしつつ、通常の Adian 非循環性以外の消去性証明が必要となる。具体的な行列や変換の部分モノイドとして定義すれば消去性は確保できるが、次は全原像のCF性と厚さが未解決になる。群全体を正に生成してしまう場合は§4の障害に戻る。

**今回の到達点は、定理Aと命題B・Cの一般的な排除結果である。真の部分モノイドにおける超多項式下界の存在、及び一般の一様多項式上界は、どちらも未解決のままである。**

## 付録：実行した再現用コード

標準 Python 3 のみ。表示の全探索は長さ1–4に限定される。一方 `closure` には長さ打切りを設けておらず、ここで扱う \(a^K=b^2\) の原像は完全閉包である。未知の表示に無条件で適用すると停止しない可能性がある。

```python
from itertools import product, combinations
from collections import defaultdict, deque
from math import inf

def delta(rel):
    u,v=rel
    return (u.count('a')-v.count('a'),u.count('b')-v.count('b'))
def forest(rels, end):
    parent={c:c for c in 'ab'}
    def root(c):
        while parent[c]!=c: c=parent[c]
        return c
    for u,v in rels:
        x,y=root(u[end]),root(v[end])
        if x==y:return False
        parent[x]=y
    return True
words=[''.join(t) for k in range(1,5) for t in product('ab',repeat=k)]
rels=list(combinations(words,2))
singles=sum(forest([p],0) and forest([p],-1) for p in rels)
full=0; accepted=0
for p,q in combinations(rels,2):
    x,y=delta(p),delta(q)
    if x[0]*y[1]!=x[1]*y[0]:
        full+=1
        accepted+=forest([p,q],0) and forest([p,q],-1)
print('words, relations, Adian single relations:',len(words),len(rels),singles)
print('two-relation sets, full-rank sets, full-rank Adian sets:',len(rels)*(len(rels)-1)//2,full,accepted)
assert accepted==0

def closure(seed, rels):
    seen={seed}; todo=deque([seed])
    while todo:
        w=todo.popleft()
        for u,v in rels+[(v,u) for u,v in rels]:
            for i in range(len(w)-len(u)+1):
                if w[i:i+len(u)]==u:
                    z=w[:i]+v+w[i+len(u):]
                    if z not in seen:
                        seen.add(z);todo.append(z)
    return seen

def substitutable(language, typed=False):
    dist=defaultdict(set)
    for w in language:
        for i in range(len(w)):
            for j in range(i+1,len(w)+1):
                dist[w[i:j]].add((w[:i],w[j:]))
    for x,y in combinations(dist,2):
        if (not typed or set(x)==set(y)) and dist[x]&dist[y]:
            if dist[x]!=dist[y]:return False
    return True
for K in (2,4,8,16,32,64):
    L=closure('a'*K,[('a'*K,'bb')])
    assert L=={'a'*K,'bb'}
    assert substitutable(L) and substitutable(L,True)
print('finite torus fibers K=2,4,8,16,32,64: complete closure, both substitution checks passed')
print('j,N,BS positive,torus K16, C2*C3:')
for j in range(11):
    N=2**j
    ell=min(N-16*t+2*t for t in range(N//16+1))
    assert ell==N%16+2*(N//16)
    print(j,N,N,ell,N)
```
