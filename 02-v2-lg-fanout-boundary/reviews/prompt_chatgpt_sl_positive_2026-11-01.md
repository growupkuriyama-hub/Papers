## 1. 問い

`prop:sl-reduction` により、次は同値です。
- ファンアウト2で、境界は LG ではない（境界がファンアウトで動く）
- SL がファンアウト2で一様な多項式データを持つ
- 全ての有限アルファベット Σ で、内容型付け c_Σ（語に現れる文字の集合）が、ファンアウト2で多項式の特徴データを持つ

**目標**：固定した Σ と r_max ≥ 2 について、多項式 p があり、全ての L ∈ C_{2,c_Σ} と全ての reduced good な表示 G について、作用素 B^{≤r_max}_{2,c_Σ} の特徴標本で長さ ≤ p(‖G‖, θ̄) のものがあることを示す。`cor:distribution-representatives` により、**各型付き非終端の同値類に、長さが多項式の代表があること（τ が多項式）**を示せば足ります。

**注意（難しさ）**：`lem:typing-monotone` より、c_Σ で多項式が言えれば、Σ 上の全ての半束型付けで多項式が言えます。特に三文字の U₁ 型付け（a, b ↦ 1、c ↦ ζ）、つまり S2 も解けます。S2 はこれまで3回の挑戦で未解決です。したがって、完全な解決は難しいことを前提に、**段階的な結果**を狙ってください。

## 2. 手がかり

- **二文字の U₁ の証明の骨組み**（`thm:binary-u1-polydata`）：
  - 「深い挿入」（ある語が因子 a⁶ z a⁶ を持ち、z が b を含む）があるかで場合分けします。
  - 無ければ、純な根の成分の両端6文字に印を付けて短縮すれば、型が保たれ、τ = O(‖G‖θ̄)。
  - あれば、a⁶ のまわりの二穴の文脈で (aⁱ, aʲ) と (a^{i'}, a^{j'})（i+j = i'+j'）が同一視され、ab と ba の分布が等しくなり、言語は Parikh 飽和になります。Parikh 飽和なら節点最小の導出の解析で τ = O(‖G‖²θ̄⁵)。
- **内容型付けとの違い**：s_{U,2} では b だけの語と a, b 両方を含む語が同じ型 ζ ですが、c_Σ では {b} と {a,b} が別の型です。つまり c_{{a,b}} では {a} と {b} の両方が「稀になりうる純な型」です。ab と ba は c_{{a,b}} でも同じ型 {a,b} なので、Parikh 飽和に至る議論はそのまま使える見込みがあります。
- **今日の障害の補題は、肯定の向きの部品にもなりえます**。
  - 切り直し：一つの語を二通りに切ると、同じ内容・同じ長さの別の語が強制されます。
  - ずれの漏れ：混合の側で同じ内容・違う Parikh の組が共通の文脈を持つと、純な側でも交換が強制されます。
  - 長さの種類：有限の標的で語の長さが k 種類なら、全ての語の長さは θ̄ + k(k−1)|V|(‖G‖ + rθ̄) 以下です。
  - 冪の移行（`lem:power-transfer`）。
  - これらは「長い語があると、別の語の所属が強制される」という性質です。うまく組み合わせれば、「稀な型の長い語があれば、同じ型の短い語もある」ことを示す道具になるかもしれません。
- **DeepSeek の観察**（途中経過）：小さな倍増の型1296通りのうち、n = 3 でファンアウト2を生き残ったのは、語が一つだけの言語だけでした。失敗の証人の多くは切り直しでした。

## 3. 調べてほしいこと（優先順）

**P1（二文字の内容型付け）**
Σ = {a, b}、c_Σ（型は {a}、{b}、{a,b}）、ファンアウト2で、多項式の特徴データを証明してください。`thm:binary-u1-polydata` の証明を、{a} と {b} の両方が純な型になる状況に広げるのが第一案です。どの補題がそのまま通り、どこに修正が要るかを、補題ごとに表で示してください。

**P2（三文字以上への見通し）**
P1 の方法が Σ = {a, b, c} の内容型付けにどこまで伸びるかを調べてください。特に次の二点です。
- 純な型が二文字以上の集合（例えば {a, b}）のとき、深い挿入と Parikh 飽和の議論はどう変わるか。
- Astra の報告で止まった「純な成分の内部に入った c の修復」が、内容型付けのもとで（型付けが細かいぶん）易しくなるか、難しくなるか。
完全な証明が無理なら、条件付きの定理（例えば「Parikh 飽和な標的では多項式」「深い挿入を持たない標的では多項式」）を、Σ を一般にした形で証明してください。

**P3（障害が見つかった場合）**
肯定の証明が通らない場所が見つかったら、それを反例の族の設計仕様として書き出してください（どんな構造なら二穴の交換を全て生き延びて、かつ稀な型が長くなるか）。その場合、反例の向きを次に狙う材料になります。
