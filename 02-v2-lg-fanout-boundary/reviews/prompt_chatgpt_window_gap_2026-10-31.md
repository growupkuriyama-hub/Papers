## 1. 設定（要点）

- **型付け**：全射な半群準同型 s: Σ⁺ ↠ S（S は有限）。学習者は、空でない組の成分を s の値が一致するときだけ比べる。
- **窓の型付け** s_{k,ℓ}：m₀ = max{1, k+ℓ} として、|w| < m₀ なら w 自身、|w| ≥ m₀ なら ⟨長さ k の接頭辞, 長さ ℓ の接尾辞⟩。s ⪯ s_{k,ℓ}（s が s_{k,ℓ} の値で決まる）とき、s を窓の型付けと呼ぶ。
- **クラス** C_{f,s}：ファンアウト f 以下の MCFL で、(f,s)-組代入可能なもの。すなわち、1 ≤ d ≤ f、空でない成分の d 組 x, y について、成分ごとの s の値が等しく、かつ共通の許容文脈（内部の区切りは空でない）を持つなら、x と y の d 組分布は等しい。f = 1 では「同じ型の因子が文脈を一つ共有すれば分布が等しい」。
- **表示の尺度**：G は reduced good（λ-free・非削除・非置換・非併合）な MCFG。ランクは r_max 以下（固定）。‖G‖ は記号単位の大きさ。θ_G(R) は規則 R を使う最短の文の長さで、θ̄_G = max{1, max_R θ_G(R)}。
- **作用素** B_{f,s}(K)：観測した組 x ごとに非終端 [x] を置き、次の規則を持つ文法。Const [x] → x。Comp [z] → ρ([u₁],…,[u_r])（z = ρ(u₁,…,u_r) と分解できるとき）。Link [x] → [y]（同じ型で、K の中に共通の文脈を持つとき）。開始規則 Ŝ → [(w)]（w ∈ K）。
- **特徴標本** F：F ⊆ K ⊆ L を満たす任意の有限集合 K について L(B(K)) = L となるもの。長さは ‖F‖₊ = Σ_{w∈F}(|w|+1)。特徴標本に語を足しても特徴標本のままなので、意味があるのは**最短の**特徴標本の長さだけです。「最大の特徴標本」という言い方はしないでください。

## 2. 既知の結果

- **上界**（`thm:local-group-polydata`、`thm:window-group-polydata`）：S が局所群（窓の型付けを含む）なら、どのファンアウトでも O(‖G‖²θ̄)。定数は f, r_max, s に依存してよい。
- **下界**（`prop:linear-factor-all-fanout`）：4f+1 文字以上なら、どの型付けでも Ω(‖G‖θ̄) が必要。標識の族で、どのクラス全体の集合駆動作用素についても成り立つ。
- **自明な型付け**（`cor:trivial-exact`）：Θ(‖G‖θ̄)。
- **データの上界の形**（`cor:distribution-representatives`）：‖K‖₊ ≤ N_typ·(1 + 2θ̄ + r_max·τ)。ここで N_typ = O(‖G‖) は型付き非終端と型付き規則の数。τ は型付き非終端の同値類の中の最短の代表の長さの最大値で、μ* ≤ τ ≤ t_typ が成り立つ。μ* は、実現される各型について、その型の最短の語の長さをとり、その最大値をとったもの。
- **稀な型の下界**（`prop:rare-type`）：実現される型ごとに、その型の語が少なくとも1つ必要。
- **余分な ‖G‖ の出どころ**（`lem:heavy-node-count`）：λ-最小な導出で、印を含む「背骨」の経路の長さを、ラベルの数 |V||N|^f で抑えている部分。結論の Tightness 段落にあるとおり、この因子は証拠の作り方では本物（s_{1,1} の例）ですが、データとして本物かは分かっていません。

## 3. 新しい観察（Claude、計算による。証明ではない）

族 F_n（ファンアウト1、ランク2、アルファベット {a, l, c, r}）：
```
E_0 → a,    E_i → l E_{i-1} E_{i-1}  |  c E_{i-1} r    (1 ≤ i ≤ n),   開始 E_n
```
括弧付き倍増族 E_i → ⌊E E⌋ | ⌈E⌉ から、⌊ の側の閉じ括弧を外したものです。
- n = 1, 2, 3, 4（語数 2, 6, 42, 1806）で、**Clark–Eyraud の代入可能性**（自明な型付けでの f=1 の条件）を全数検査で確認しました。したがって、どの型付けでも C_{1,s} に入ります。
- 末尾の文字による窓の型付け s_{0,1} で、末尾が a の最短の語の長さは n(n+1)+1 です（n ≤ 4 で一致）。いっぽう ‖G‖ = O(n)、θ̄ ≤ 4n−1 です。
- よって μ* ≥ n(n+1)+1 = Θ(‖G‖θ̄) となり、**τ = O(θ̄) は窓の型付けでも一般には成り立ちません**。
- ただし、末尾が a の長い語 W（右の背骨が全て l の分岐）は、各段の「末尾が a の」型付き非終端の生成物を、接尾辞としてまとめて含みます。一本の長い語を多くの規則で使い回せる（償却できる）可能性があります。

## 4. 調べてほしいこと（優先順）

**Q1（族 F_n の確定）**
(a) 全ての n で F_n が Clark–Eyraud の意味で代入可能であることを証明してください。括弧付き倍増族の決定的構文解析器による証明（01 の論文 arXiv:1409.6247v5 の付録 C）が参考になります。⌊ の側に閉じ記号が無いので、「分岐の同期」の段（閉じ記号の違いで場合 (b) を排除する部分）がそのまま通るかを確かめてください。通らなければ反例を示してください。
(b) ‖G_n‖、θ̄、μ_a を正確に求めてください。

**Q2（F_n の特徴データ長）**
s_{0,1}（と、できれば s_{1,1}）、B_{1,s} について、最短の特徴標本の長さは Θ(n²)（= Θ(‖G‖θ̄)）ですか、それとも Θ(n³)（= Θ(‖G‖²θ̄)）ですか。
- 上界：長さ O(n²) の特徴標本を具体的に作れるか。Link と Comp に必要な観測を、少数の長い語で同時にまかなう構成を考えてください。
- 下界：Ω(n³) が要るなら、その証明。少なくとも B_{1,s} について、できればクラス全体の集合駆動作用素について。稀な型の議論では Ω(n²) までしか出ない点に注意してください。

**Q3（本題）**
窓の型付け（s ⪯ s_{k,ℓ}）、ファンアウト f で、最短の特徴標本の長さは O(‖G‖θ̄) ですか。
- **肯定**なら証明してください。まず f = 1、k + ℓ が小さい場合からで構いません。τ を直接抑えるのではなく、長い代表を共有する「償却された」標本の構成が要るはずです。必要なら、作用素 B_{f,s} の性質（Link の推移性など）を使ってください。
- **否定**なら、ω(‖G‖θ̄)（理想は Ω(‖G‖²θ̄)）が必要な族を作ってください。必要な条件は三つです。①クラスに入ることの証明、②‖G‖・θ̄ の計算、③どの作用素についての下界かの明示。

**Q4（余力があれば）** Q3 の答えが可換群の型付け、一般の局所群の型付けに伸びるか。
