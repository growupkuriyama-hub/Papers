## 1. 設定と規約

- Σ = {a,b,c}、π(w) ∈ ℕ³ はパリクベクトル（座標の順は a, b, c）、supp(m) = {σ : m_σ > 0}、cont(w) = supp(π(w))。
- **記号の分離（前回の指摘 (iii)）：** 導出木と生成の組は ū, p_z（語・組）と書き、そのパリクベクトルは必ず π(·) を付ける。格子・ベクトルは m, h, δ。
- D は有向多重グラフで各文字 σ がちょうど一本の辺 tail(σ) → head(σ)。**境界写像は「入る − 出る」**：∂m = Σ_σ m_σ(𝟙_{head σ} − 𝟙_{tail σ})。s から t への歩道 w について ∂π(w) = 𝟙_t − 𝟙_s。
- φ : Σ* → A は可換群への準同型、Φ : ℤ³ → A は φ = Φ∘π を満たす線形写像。
- ψ(w) = (π_D(w), φ(w), cont(w))、L = ψ⁻¹(P)。**以下では P は経路の像の部分集合とする**（L ⊆ ⋃_{s,t} Path_D(s,t)）。零（経路でない語）を受理する P は扱わない（§7.3 の残りの項目）。
- 経路の語 w の**型** τ(w) = (s, t, φ(w), cont(w))（s = 最初の文字の tail、t = 最後の文字の head）。P_{s,t,M} = {g : (s,t,g,M) ∈ P}、Λ_{s,t,M} = {φ(w) : w は s → t の歩道、cont(w) = M}（実現できる値）。
- **一頂点**（D の頂点が一つで三本ともループ）のとき：全ての語が経路で、L はパリクベクトルの集合 Q = π(L) ⊆ ℕ³∖{0} で決まる（L = π⁻¹(Q)）。逆に、任意の Q ⊆ ℕ³∖{0} は A = ℤ³、Φ = id で ψ⁻¹(P) と書ける。従って**一頂点のクラスはパリク飽和な言語全体**である。Q_M = {q ∈ Q : supp q = M}、Π_M = {m ∈ ℕ³ : supp m = M}。Q₂ = Q_{ab}、Q₃ = Q_{abc}、Π₂、Π₃ も同様。「平面」= ℤ² × {0}。
- 代入可能性 SUB_d は依頼文 §0 の規約（内容型付け c_Σ、成分は全て非空、d = 2 の内側の区切りは非空）。
- 文法 G は既約で good（λ-free・非削除・非置換・非併合）。証明で使うのは**線形・非削除・λ-free**だけ（λ-free は端の印を使う §4 の議論でだけ使う）。r はランク、v = |N|、f はファンアウト。

## 2. 共通の補題

**補題 0.1（ψ の分解）** [証明済み]。経路の語 w について ψ(w) は (s, t, π(w) mod K₀, cont(w)) で決まる（K₀ = ker Φ）。従って A = ℤ³/K₀（Φ は単射）と仮定してよい。

*証明。* π_D(w) = (s,t)、φ(w) = Φ(π(w))、Φ は K₀ 上で 0。ℤ³/K₀ → A は単射なので、P を引き戻しても L は変わらない。∎

**補題 0.2（同じ内容の語は合同）** [証明済み]。x, y ∈ L、cont(x) = cont(y) なら、全ての arity 1 の文脈 F について F[x] ∈ L ⟺ F[y] ∈ L。

*証明。* E = □ は許容的な文脈で、E[x] = x, E[y] = y ∈ L。SUB₁ から分布が等しい。∎

**補題 0.3（型で決まる）** [証明済み]。経路の因子 x, y の型が等しければ（端点・値・内容）、全ての arity d の文脈について受理は一致する。従って SUB_d は型の上の有限の条件で、A が有限なら決定できる（スクリプト §S4 の厳密な判定はこれによる）。

*証明。* u x v が経路であることは「u = ε か head(u) = x の始点」と「v = ε か tail(v) = x の終点」で決まり、型(u x v) は型(u)、型(x)、型(v) で決まる。arity 2 も同様。∎

## 3. 課題1：特徴づけ

### 3.1 一頂点：正確な特徴づけ

**定理 2.1** [証明済み]。D が一頂点、Q = π(L) とする。L が (1, c_Σ)-代入可能 ⟺ 次の (T)：

> (T) 全ての q, q′ ∈ Q（supp q = supp q′、h := q′ − q ≠ 0、S := supp h）と全ての γ ∈ ℕ³ について
> h⁻ + 𝟙_S + γ ∈ Q ⟺ h⁺ + 𝟙_S + γ ∈ Q。

（h⁺, h⁻ は正部分・負部分で h = h⁺ − h⁻。）

*証明。* (⇒) M := supp q = supp q′ ⊇ S ≠ ∅。π(x) = h⁻ + 𝟙_S、π(y) = h⁺ + 𝟙_S の語 x, y を取る。cont(x) = cont(y) = S。n := q − π(x) = (q ∧ q′) − 𝟙_S（q ∧ q′ = q − h⁻ は成分ごとの最小）。σ ∈ S ⊆ M では (q ∧ q′)_σ ≥ 1 なので n ≥ 0。π(u) = n の語 u と文脈 u□ を取ると、π(ux) = q ∈ Q、π(uy) = q − h⁻ + h⁺ = q′ ∈ Q。SUB₁ から x と y の分布は等しく、π(z) = γ の語 z について zx ∈ L ⟺ zy ∈ L、すなわち (T)。
(⇐) cont(x) = cont(y) = S′ ≠ ∅ の x, y が文脈 (u,v) を共有するとする。q := π(uxv)、q′ := π(uyv) ∈ Q、supp q = supp q′ = S′ ∪ cont(uv)。h := q′ − q = π(y) − π(x)。h = 0 なら x と y のパリクは等しく分布も等しい。h ≠ 0 なら S := supp h ⊆ S′。γ₀ := π(x) − h⁻ − 𝟙_S ≥ 0 を確かめる：σ ∈ S で h_σ > 0 なら h⁻_σ = 0、π(x)_σ ≥ 1。h_σ < 0 なら π(x)_σ = π(y)_σ + |h_σ| ≥ 1 + |h_σ|。σ ∉ S では h⁻_σ = 0。さらに π(y) = π(x) + h = h⁺ + 𝟙_S + γ₀。任意の文脈 (u′,v′)（γ′ = π(u′v′)）について u′xv′ ∈ L ⟺ h⁻ + 𝟙_S + γ₀ + γ′ ∈ Q ⟺（(T)）h⁺ + 𝟙_S + γ₀ + γ′ ∈ Q ⟺ u′yv′ ∈ L。∎

**系 2.2** [証明済み。README (57)(c) と同じ内容の再証明]。一頂点では SUB₁ ⇒ 全ての d で SUB_d。

*証明。* x = (x₁,…,x_d)、y = (y₁,…,y_d)（cont(x_i) = cont(y_i)）が文脈 E = v₀□v₁…□v_d を共有するとする。語 x̃ = x₁⋯x_d と ỹ = y₁⋯y_d は内容が等しく、arity 1 の文脈 v₀v₁⋯v_d□ を共有する（パリクが等しいので）。SUB₁ から、全ての n ∈ ℕ³ で π(x̃) + n ∈ Q ⟺ π(ỹ) + n ∈ Q。arity d の任意の文脈 F について F[x] ∈ L ⟺ π(F) + π(x̃) ∈ Q なので、分布は等しい。∎

**補題 2.3（一歩の移動）** [証明済み、定理 2.1 の言い換え]。q, q′ ∈ Q（同じ支持）、h = q′ − q とする。α ∈ ℕ³ が「σ ∈ supp h で α_σ ≥ 1 かつ α_σ + h_σ ≥ 1」を満たすなら、α ∈ Q ⟺ α + h ∈ Q。（このとき「α での h-移動は有効」と言う。α の supp h の外の座標、特に c 座標は任意。）

*証明。* γ := α − h⁻ − 𝟙_{supp h} ≥ 0 で、α = h⁻ + 𝟙 + γ、α + h = h⁺ + 𝟙 + γ。(T) を使う。∎

### 3.2 二次元の完全性

**補題 2.4** [証明済み]。一頂点で L が SUB₁、Q₂ ≠ ∅、H₂ := ⟨Q₂ − Q₂⟩ とする。任意の q ∈ Q₂ について Q₂ = (q + H₂) ∩ Π₂。

*証明。* D₂ := Q₂ − Q₂（対称、H₂ を生成）。α, α + d ∈ Π₂（d ∈ D₂）なら補題 2.3 の移動は有効で、α ∈ Q₂ ⟺ α + d ∈ Q₂（両方とも支持は {a,b}）。⊆ は明らか。⊇ を階数で示す。
- **階数 0**：Q₂ = {q}。
- **階数 1**：H₂ = ℤg。I := {k ∈ ℤ : q + kg ∈ Π₂} は 0 を含む整数の区間（Π₂ は凸集合の格子点）。J := {k : q + kg ∈ Q₂} ⊆ I、J − J は ℤ を生成し、|J| ≥ 2。δ := J − J の最小の正の元。δ > 1 と仮定すると、gcd = 1 なので k₀, k₁ ∈ J で k₁ ≢ k₀ (mod δ) のものがある。k₀ < k₁ としてよい（逆も同様）。k₀ + iδ ≤ k₁ の範囲は I に入り（区間）、δ-移動で帰納的に J に入る。i* を最大に取ると 0 < k₁ − (k₀ + i*δ) < δ で、どちらも J の元。δ の最小性に反する。よって δ = 1 で、I の全ての点が ±1 の移動で 0 とつながり、J = I。
- **階数 2**：
  (a) Q₂ は無限。有限と仮定する。q ≤ q′（成分ごと、q ≠ q′）の組があれば d = q′ − q ≥ 0 で、q′ + d ∈ Π₂ への移動は有効、帰納的に q + kd ∈ Q₂（全ての k）となり矛盾。よって Q₂ は反鎖で、x 座標の順に s_1, …, s_n（x は狭義増加、y は狭義減少）。階数 2 なので n ≥ 3。d := s_2 − s_1 = (Δx, −Δy)（Δx, Δy > 0）。j ≥ 2 で s_j − d の x 座標は x_j − Δx ≥ x_1 ≥ 1、y 座標は y_j + Δy ≥ 1 なので s_j − d ∈ Π₂、移動から s_j − d ∈ Q₂。j についての帰納法で s_{j+1} − s_j = d を示す：s_{j+1} − d の x 座標は x_{j+1} − Δx > x_j − Δx = x_{j−1}（帰納法の仮定、j = 2 では x_1）で x_{j+1} 未満。Q₂ の中で x 座標がこの範囲にあるのは s_j だけなので s_{j+1} − d = s_j。従って全ての s_j が一直線上にあり階数 1、矛盾。
  (b) 狭義に正の u ∈ D₂ がある。Q₂ は無限なので Dickson の補題から q ≤ q′（q ≠ q′）の組があり u₀ := q′ − q ≥ 0。u₀ の両座標が正なら u := u₀。そうでなければ u₀ = (k, 0)（または (0,k)、対称）。階数 2 なので d_y ≠ 0 の d = s′ − s ∈ D₂ があり、D₂ は対称なので d_y > 0 としてよい。+u₀ の移動は常に有効なので s′ + ju₀ ∈ Q₂、よって d + ju₀ = (s′ + ju₀) − s ∈ D₂。j を大きく取れば u := d + ju₀ > 0。
  (c) t ∈ (q + H₂) ∩ Π₂ とする。t − q = Σ_{i=1}^m d_i（d_i ∈ D₂）。B := Σ‖d_i‖_∞、N·min(u_x, u_y) ≥ B の N を取る。q + Nu ∈ Q₂（+u の移動）。q + Nu + Σ_{i≤j} d_i は全て ≥ q ≥ (1,1) で Π₂ に入るので各移動は有効、t + Nu ∈ Q₂。t + ju（j ≥ 0）は全て Π₂ に入るので −u の移動で t ∈ Q₂。∎

### 3.3 一頂点・有限群：一つの剰余類と、共通の文字の上での共有

A_S := ⟨φ(σ) : σ ∈ S⟩（A_∅ = 0）。A が有限なら Φ(ℕ^S) = A_S（有限群の中の有限生成の部分モノイドは部分群）なので Λ_M = Φ(𝟙_M) + A_M。さらに任意の v ∈ Λ_M と N について、Φ(α) = v、α_σ ≥ N（σ ∈ M）の α ∈ Π_M がある（e_σ の位数倍を足す）。これを「大きな実現」と呼ぶ。

**定理 2.5** [証明済み]。一頂点、A 有限。L が SUB₁ ⟺ P_M ≠ ∅ の全ての M, M′ について
(i) P_M = p + H′_M（p ∈ P_M、H′_M := ⟨P_M − P_M⟩）、かつ
(ii) H′_M ∩ A_{M∩M′} = H′_{M′} ∩ A_{M∩M′}。

*証明。* (⇒)(i) p, p′ ∈ P_M。p′ − p ∈ A_M なので h ∈ ℕ^M で Φ(h) = p′ − p のものがある。Φ(q) = p の q ∈ Q_M を取り q′ := q + h ∈ Π_M（Φ(q′) = p′ なので q′ ∈ Q_M）。h ≥ 0 なので Π_M の全ての α で h-移動は有効（補題 2.3）。全ての v ∈ Λ_M は Π_M の点で実現されるので、v ∈ P_M ⟺ v + (p′ − p) ∈ P_M。P_M は ⟨P_M − P_M⟩ の剰余類の和で p を含むので P_M = p + H′_M。
(ii) S := M ∩ M′、g ∈ H′_M ∩ A_S（g ≠ 0、よって S ≠ ∅）。h ∈ ℕ^S で Φ(h) = g のものを取る。p ∈ P_M の大きな実現 q ∈ Q_M について q + h ∈ Π_M、Φ(q + h) = p + g ∈ P_M（(i)）。この組 (q, q + h) の h-移動（h ≥ 0、supp h ⊆ S ⊆ M′）は Π_{M′} の全ての点で有効なので、全ての v ∈ Λ_{M′} で v ∈ P_{M′} ⟺ v + g ∈ P_{M′}。(i) から P_{M′} は H′_{M′} の剰余類で、その安定化群は H′_{M′} なので g ∈ H′_{M′}。対称性から等号。
(⇐) (T) を確かめる。q, q′ ∈ Q_M、h = q′ − q、S = supp h ⊆ M、γ ∈ ℕ³。α := h⁻ + 𝟙_S + γ と α + h = h⁺ + 𝟙_S + γ の支持は等しい（M′ とおく、S ⊆ M′）。Φ(h) = Φ(q′) − Φ(q) ∈ H′_M ∩ A_S ⊆ H′_M ∩ A_{M∩M′} = H′_{M′} ∩ A_{M∩M′}（P_{M′} ≠ ∅ のとき）。P_{M′} は H′_{M′} の剰余類なので Φ(α) ∈ P_{M′} ⟺ Φ(α) + Φ(h) ∈ P_{M′}。P_{M′} = ∅ なら両辺とも偽。∎

**系 2.6** [証明済み]。一頂点、A 有限、SUB₁ なら、a, b を含む部分は (16) の形：H := H′_{abc}（P_abc = ∅ なら H′_ab）、g_ab, g_abc を P_ab, P_abc の元として P_ab = (g_ab + H) ∩ Λ_ab、P_abc = g_abc + H。

*証明。* (ii) を M = ab、M′ = abc で使うと H′_ab ∩ A_ab = H ∩ A_ab、H′_ab ⊆ A_ab なので H′_ab = H ∩ A_ab。Λ_ab = g_ab + A_ab から (g_ab + H) ∩ Λ_ab = g_ab + (H ∩ A_ab) = P_ab。∎

**依頼文の予想との関係。** 有限群・一頂点では、受理値は「剰余類の和」ではなく**一つの剰余類**で、「同じ H′ の共有」は正確には**共通の文字が生成する部分群の上での一致** (ii) である。{a,b} と {a,b,c} の間では (ii) がちょうど (16) を与える。

### 3.6 一般の D・有限群

経路の世界での記号：x の上の閉じた歩道（x から x への空でない歩道）の集合で内容 ⊆ M のもののパリクが生成する格子を C_x^M、s → t で内容 M の歩道のパリクの差が生成する格子を D_{stM}、V_ab := 辺 a, b の端点。

**(CW)**（端点の組 (s,t) についての条件）
- (CW1) M ∈ {ab, abc} のうち s → t の歩道があるものについて D_{stM} ⊆ C_s^M + C_t^M。
- (CW2) ab と abc の歩道が両方あるとき：内容 ⊆ abc で c を含む閉じた歩道が s か t の上にあり、ある ab 歩道 w₂ と abc 歩道 w₃ について π(w₃) − π(w₂) ∈ C_s^{abc} + C_t^{abc}。
- (CW3) 同じとき：ある r ∈ V_ab について D_{st,ab} ⊆ C_r^{ab}。

**補題 2.9a（詰め物）** [証明済み]。A 有限。g ∈ Φ(C_s^M + C_t^M) なら、s の上の閉じた歩道 α と t の上の閉じた歩道 β（空でもよい、内容 ⊆ M）で φ(α) + φ(β) = g のものがある。M ⊆ abc で c を含む閉じた歩道が s か t の上にあれば、c ∈ cont(αβ) とできる。

*証明。* s の上の閉じた歩道の値（と 0）は連結について閉じた有限群の部分モノイドなので、Φ(C_s^M) と一致する。t も同様。c 付きにするには c を含む閉じた歩道 γ を一つ付け、残りを g − φ(γ) で選ぶ。∎

**補題 2.9b（挿入）** [証明済み]。A 有限。r の上の閉じた歩道 y, y′ が cont(y) = cont(y′) = S で、分布が等しいとする。r を通り S ⊆ cont(u) の経路の語 u について、型(u) ∈ P ⟺ 型(u) + (φ(y′) − φ(y)) ∈ P（値だけを動かす）。

*証明。* u = u₁u₂ を r で分ける（u が r から始まれば u₁ = ε）。o を φ(y) の位数とすると ũ := u₁y^o u₂ は u と同じ型。ũ′ := u₁y^{o−1}y′u₂ は y と y′ の分布が等しいので ũ ∈ L ⟺ ũ′ ∈ L で、型(ũ′) は値が φ(y′) − φ(y) だけ違う（端点と内容は同じ）。∎

**定理 2.9** [証明済み（(CW) を仮定）]。A 有限、L が SUB₁、(s,t) が (CW) を満たすとする。
(K1) M ∈ {ab, abc} で P_{stM} ≠ ∅ なら P_{stM} = p + ⟨P_{stM} − P_{stM}⟩（⊆ Λ_{stM}）。
(K2) a,b を含む L ∩ Path(s,t) は (16) の形：H := H′_abc（abc が空なら H′_ab）、P_{st,ab} = (g_ab + H) ∩ Λ_{st,ab}。

*証明。* (K1) p, p′ ∈ P_{stM} の語 w, w′ は合同（補題 0.2）。x ∈ Λ_{stM} について x − p ∈ Φ(D_{stM}) ⊆ Φ(C_s^M + C_t^M)（(CW1)）。補題 2.9a の α, β で αwβ の型は (s,t,x,M)、αw′β の型は (s,t,x + p′ − p,M)。合同から x ∈ P ⟺ x + (p′ − p) ∈ P。同じ構成で Λ_{stM} = p + Φ(D_{stM}) もわかり、平行移動は Λ を保つ。従って P は ⟨P − P⟩ の剰余類。
(K2) H′₂ := ⟨P_ab − P_ab⟩、H′₃ := ⟨P_abc − P_abc⟩（ここでは添字 st を省く）。

**(CW) の検査** [計算機による観察（長さ 7 以下の歩道で生成した格子）]。一文字一辺の有向グラフは同型を除いて 203 種。そのうち「長い ab 経路があり、c が内部に来うる」ものは 17 種（強連結なもの 5 種：一頂点、二サイクル a: p→q, b: q→p に c のループか平行辺。残り 12 種：a のループと b の辺など）。その全ての端点の組 41 個で (CW1)(CW2)(CW3) が成り立った（§S5）。残りの 186 種は §4 の補題 3.8 か「ab 経路の長さ ≤ 2」で自明に片付く。

### 4.2 端点の組が複数ある場合（端の印）

**端の印。** W を最短の ab 語、N = |W| ≥ 2。W の最初と最後の位置を印にし、それで a と b の両方が覆われなければ足りない文字の位置を一つ加える。印の数は k ≤ 3。

**補題 3.2′（端点を保つ代表）** [証明済み]。節点 z の**印の型** κ_z は、z の部分木にある印から、それが入っている y(z) の成分の番号への写像（と各印の文字）。B ∈ N と型 κ について、rep(B, κ) を「κ の印の文字を全て含み、最初の印があれば成分 κ(最初) の先頭の文字が W の先頭の文字、最後の印があれば成分 κ(最後) の末尾の文字が W の末尾の文字」である最短の生成とする。このとき |rep(B,κ)| ≤ k·v·(f+1)^k·θ（k ≤ 3、f = 2 で ≤ 81vθ）。

*証明。* 条件を満たす生成の導出 D と、その中の印の位置を取る（文字の印は条件を満たす出現を一つずつ、最初・最後の印は該当する成分の先頭・末尾）。背骨＝印を含む部分木の根。
(1) 背骨の外の子を最短の生成に置き換える。印は背骨の部分木にあるので残り、λ-free なので成分の先頭・末尾の位置も変わらない。
(2) y が y′ の真の祖先で、ラベルと印の型（印の集合と成分番号）が等しいとき、y の部分木を y′ の部分木に置き換える。y の成分 j は y′ の成分 j で置き換わる（線形・非削除なので文脈の穴はそれぞれ一回）。y′ の成分 j にある印は新しい組でも同じ穴に入る。最初の印 x が B の成分 i の先頭なら、x を含む y の成分 j は x から始まり、文脈の成分 i は穴 j から始まる。x は y′ の成分 j に入り（型が等しい）、それは y の成分 j の因子で x を含むので x から始まる。よって置き換え後も B の成分 i は x から始まる。末尾も同様。
(3) (2) を繰り返すと節点数が減るので止まる。根から一つの印への道の上で (ラベル, 型) は相異なり、型は高々 (f+1)^k 通りなので道は ≤ v(f+1)^k 節点、背骨は ≤ k·v(f+1)^k 節点。各背骨の節点が直接書く文字と背骨外の子の最短の生成の和は (T3) で θ 以下。∎

μ_ab ≤ max{16(r+1)vθ, 10 121 122·v³θ³}。

*証明。* (s,t) を W の端点の組とする。
**場合 A**（abc の部分が空、または g_abc − g_ab ∉ H_{st}）。印のない重い節点 t（|y(t)| > θ）について、長さ ≤ θ の A_t の生成（(T1) から存在）は全て c を含む（含まなければ W[t←ω] ∈ L は印を全て含む、より短い ab 語）。λ-free なので、最初・最後の位置が t の外にあれば W[t←ω] の最初・最後の文字は W と同じで、端点は (s,t)。比較不能な印のない重い t, t′ があれば、W_t, W_{t′}, W_{tt′} は Path(s,t) の abc 語で、H 報告の補題 4.2 と同じ計算で g_abc − g_ab ∈ H_{st}、または abc が空なのに W_t ∈ L で矛盾。よって印のない重い葉は ≤ 1、印のある重い葉は ≤ k ≤ 3。印の集合は根から葉へ単調に減り（≤ k+1 = 4 通り）、同じ値の区間でラベルは相異なる（H 報告の補題 3.1 の短絡は印の文字を保つので、結果は L = L(G) の ab 語。端点は変わってよい）。重い節点 ≤ 4·4v、μ_ab ≤ 16(r+1)vθ。

### 4.3 剰余類の和

**定理 3.3（場合 A 型、J 個の剰余類）** [証明済み、代入可能性は不要]。G は既約で good。全ての (s,t) について、P_{st,abc} ⊆ ⋃_{j=1}^J (g_j + H_{st}) かつ P_{st,ab} ∩ ⋃_j (g_j + H_{st}) = ∅ とする。このとき μ_ab ≤ 4(r+1)vθ(J + 3)。

（J = 1 は定理 H の場合 A。）

### 7.3 残った穴

**命題 7.2（残る穴）。** D が一頂点（L はパリク飽和）、A = ℤ³（パリクそのもの）、L ∈ C_{2,c_Σ}、G は L の既約 good な表示とする。L の ab 語が (P⁺) を満たさず、abc 語の長さが有界でないとき、μ_ab(L) ≤ poly_r(v, θ̄_G) か？

- **言い換えでない理由：** 一頂点のクラスのうち、系 3.6(a)（(P⁺) か A 有限）、定理 3.7（F_L が小さい）、補題 3.9（abc 語が有界）のどれでも覆えない部分だけを残した命題で、仮定は言語の性質だけ。結論と同値な条件（最短語の枠など）は含まない。
- **仮定が空でない理由：** 部分的にしか確かめていない。(P⁺) が成り立たない代入可能な言語は T_n・L_N・Q₂ = {(2,4)} の三角形の言語など多くあるが、これらは abc 語が有界。**abc 語が無限で (P⁺) が成り立たず F_L が大きい代入可能な言語は、まだ一つも構成していない**（§6 の三番目）。もしそういう言語が存在しないことが示せれば、一頂点の場合は完全に閉じる。逆に存在すれば、それが反例の唯一の候補になる。
- この他に残る範囲：一般の D で A が無限の場合（(16) の外は定理 3.3・3.4 だけ）、P が零（経路でない語）を受理する場合、一般の D での SUB₁ ⇒ SUB₂（観察では成立）、(CW) の手による証明。
