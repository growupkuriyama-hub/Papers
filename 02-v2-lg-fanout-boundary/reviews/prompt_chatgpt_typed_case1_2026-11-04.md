## 1. 到達点と隔たり

Σ = {a, b, c}、内容型付け c、L ∈ C_{2,c} とする。G は L∩Σ⁺ の reduced good な表示で、ファンアウト ≤ 2、ランク ≤ r。v = |V|、θ = θ̄_G とおく。**場合 I** は、a⁴、b⁴、c⁴ が全て L の語の因子として現れる場合とする。

- **定理 I（検証済み）**：場合 I で純粋な a 語があれば、μ_a(L) ≤ max{4θ+12, K_I^{313}R^{312}θ}。文字の名前を入れ替えれば、純粋な b 語・c 語も同じである。
- **定理 I の証明が使っていること**（`chatgpt_verify_case1` §6 の指摘を含む）：
  1. 最短の語の導出の全ての節点の出力が純粋な a 語である。そのため、同じラベルの部分木を入れ替えても出力の型が変わらず、一様化 (U) ができる。
  2. 重い節点を短い代表 ρ に替えると、a の損失 d が一つの数で測れる。
  3. 余った a を一つの a の連に集めて比べられる（定理S、(R)）。
- **隔たり**：`op:fanout-two` の肯定に要るのは、全ての型付き非終端 X（非終端と、出力の成分ごとの内容の組）について、X の出力と分布が同じ組（同値類）の中で一番短いものの長さ τ_X を、poly(‖G‖, θ) で抑えることである。原稿の `cor:distribution-representatives` により μ* ≤ τ なので、μ_m（内容 m の最短語の長さ）の上界は τ の上界から出るが、逆は出ない。μ_a はその μ_m の一つにすぎない。
- **二文字の手本**：付録 `app:two-letter-content` は、型付き非終端 X の最短の組の最小導出 T を取り、重い反鎖の大きさを抑えて τ（非飽和なら t_typ）を抑えている。途中で型が変わる差し替えは `lem:app-two-insertion`（短い差し替えが作る連）で扱っている。

## 2. 観察（確かめること）

この系列の検証を担当している Claude の観察で、まだ証明されていません。

**(T1) 型付き非終端への一様化。** 型付き非終端 X の最短の組の、節点数最小の導出 T を考える。同じラベルの二つの節点を入れ替えると、出力の文字は X の型に含まれたままだが、**型が小さくなる**（ある成分からある文字が消える）ことがある。純粋な a 語のときはこれが起きなかった。

そこで確かめたいのは、次の二点である。
- 「最短」を「型 X のまま最短」と取れば、型を保つ入れ替えだけで (U) の類似が成り立つか。
- 型を変える入れ替えは、二文字の `lem:app-two-insertion` の類似で、何個かの例外の節点に押し込めるか。

**(T2) 型が一文字の成分。** 型付き非終端 X の成分の内容が {a} のように一文字なら、その成分の中では定理 I の議論（a の損失、(R)）がそのまま使えるかもしれない。成分ごとに文字が一つの型と、二文字・三文字の成分を含む型とで、場合を分けるのが自然か。

**(T3) 文脈つきの μ_a。** 二文字の証明は、途中で「文脈 C の穴に入る最短の純粋 a の組」P_a(C) に帰着している（`reviews/claude_binary_content_core_2026-11-01.md`）。三文字の場合 I でも、定理 I を「固定部分つきの文脈の中の純粋 a の穴」に広げられれば、τ に近づくか。定理 I の証明のどこが文脈の固定部分で壊れるか（補題 F′ の融合が固定部分の b, c と合流する、など）を確かめる。
