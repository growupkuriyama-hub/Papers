# MCFG §§2–3 数学査読メモ（2026-10-27）

対象: `02_fixed-h-mcfg/main.tex` および `japanese/main_JP.tex`。PR #85 で改訂された §2 Preliminaries / §3 Reconstruction and Qualitative Learning を、節内の定義・定理、付録の対応する証明、前版の文言と突き合わせた。原稿の日英は同時に修正した。

## 確定した修正点

1. **§2 型付けの新単位元（中程度）**：「fresh identity only evaluates empty terminal gaps in templates」は不正確。新単位元添加は `def:output-refinement` で終端生成語タプルの型を付与し、型付き非終端・規則を構成する。正語に新単位元型が追加されるわけではない。導入 §1 と整合する形へ修正。
2. **§2 有限モノイド実装による刈り込み精密化の一致（実質的な適用範囲の誤り）**：元の文は任意の標準MCFGにも一致が成立すると読めた。`lem:semigroup-transfer` (ii) の仮定は **good MCFG**（特に `lambda`-free）であり、その範囲でのみ成功導出の型付き非終端が正語像 `S_0` に属することを使える。実際、\(\Sigma=\{a\}\)、\(q:\Sigma^*\to\{1\}\) を自明モノイド準同型、標準文法 \(S\to\varepsilon\mid a\) とすると、\(q\) の細分化では \(S_{1}\) が両方を生成する一方、\(\widehat{q|_{\Sigma^+}}\) の細分化では \(S_{\mathbf1_\sharp}\) と \(S_1\) に分離し、刈り込み後も一致しない。したがって本文を「標的クラス・観測ベースの再構成は一致、刈り込み細分化の一致は good 文法のみ」に限定。
3. **§2 文法サイズ（表記上の明確化）**：新しく導入した \(\|G\|\) は記号単位の文法サイズであり、非終端名の二進エンコーディングの厳密なbit数ではない点を明記。
4. **§2 アーベル型フィルタの証明（軽微）**：「(c) above」は命題内の(i)/(ii)でなく命題直前の観察(c)である。参照範囲と \(f\)-MCFL 条件を明記。
5. **§3 独創性の記述（軽微）**：「none of which is new」を、Yoshinaka の質的原理を独立の新規寄与とは主張しない、という厳密な文に改めた。任意ランク作用素と型一致だが非導出的な代表に関する自前の補助証明は維持。

## 重点的に点検した論理

- `lem:filling-identity`：非消去・非置換・非融合と外側の非空セパレータにより誘導子文脈の穴は順序どおりで、穴間は非空。テンプレートと置換の恒等式も成立。
- `lem:witnessed-composition`：分布同値な子タプルを一つずつ置き換えるとき誘導文脈を使用でき、固定テンプレートの `s` 型は準同型性で保たれる。
- `prop:reconstruction-soundness`：Constは恒等、Linkは共通観測文脈とターゲットのtuple substitutability、Compは前項の合同的置換により導出高さ帰納が通る。
- `prop:completeness`：各型付き規則について \(\iota(X)\) と \(\rho(\iota(Y_1),\ldots)\) は親生成語型が一致するため、同じ \(\chi(X)\) の二証拠から Link を構成でき、Const/Comp は具体的な観測成分分割から得られる。子 \(\iota(Y_j)\) の導出可能性を仮定していないことも、証拠と規則の構成に照らして矛盾しない。
- `thm:exact-reconstruction` は健全性＋完全性＋\(\varepsilon\) の開始規則による。\(r_G\) のrank capは正規化で維持。
- `thm:poly` の列挙上界は固定 \(f,r_{max}\) と標本上のカット位置の全列挙によるものであり、「文法サイズが入力に含まれる可変 \(f,r\) でも同じ多項式」という主張ではない。
- `lem:semigroup-transfer` の実際の付録証明は good grammar の場合に成立し、その定理自体は変更しない。
