## 2. 問いと記号

Σ = {a, b, c}、内容型付け c、L ∈ C_{2,c}。G は L∩Σ⁺ の reduced good な表示で、ファンアウト ≤ 2、ランク ≤ r。v = |V|、θ = θ̄_G とおく。k := μ_a(L)（a^j ∈ L となる最小の j、k ≥ 5）とし、T を a^k の節点数最小の導出とする。生成組の総長が θ を超える節点を「重い」と呼ぶ。

> **Q：μ_a(L) ≤ poly(‖G‖, θ) か。**

- 肯定なら、`op:fanout-two` の三文字の核の、a だけの語の部分が片付く。

## 4. 次の報告（README (115)）で確かめること

- **(U) 一様な最小導出**（Claude の観察で、まだ報告では証明されていない）
  - 主張：T は、同じラベルの部分木が全て同一になるように取り直せる。
  - 理由：同名の部分木は総長が等しく、節点数も等しい（違えば節点数の最小性に反する）。そこで、ラベルごとに全出現を一つの部分木へ同時に差し替えればよい。
  - 帰結：a^k は v 個以下の規則からなる直線的プログラムになる。
  - 確かめる点：ファンアウト2で成分の長さが違う部分木を差し替えてよいか。私の見立てでは、語は a だけなのでよい。
- **違うラベルどうしの交差**：一色型の C（b だけ）と C'（c だけ）を B と組み合わせると、b と c の個数が等しく a の個数が違う二語が作れる場合がある。それを同じ a 骨格に揃える仕組み（三文字の「飽和／非飽和」の二分法）があるか。
- **否定側の候補**：「a の個数の漏れ」（bcbc と bc が文脈 □a で分かれる型）をどう避けているかを、まず確かめる。
