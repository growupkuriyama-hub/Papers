# TCS Lean Phase 2 — bracketed CFG and fixed-typing verification

Paper: Takayuki Kuriyama, *Distributional Learning of Context-Free Languages under Fixed Finite-Monoid Typing*, TCS-D-26-00494.

## Source and exact reference

The canonical `01_fixed-h-cfg/main.tex` was examined at main commit `011a9f5ae4463241b7fe24a16f6d21169b14c4ba`, with manuscript blob SHA `db070f7c4b8b70fe1afb6bfe682f90f8c3f068b9`, internal manuscript v211 (2026-10-16). Phase 1 was based on v209 and is unchanged. Between these versions the literal **binary** brackets changed from triangle symbols to floor symbols, and **unary** brackets to ceiling symbols; the naming of characteristic samples also changed. These are notation changes and do not alter Proposition 6.3's construction or mathematical bounds. The existing Lean constructors `left`/`right` now denote the floor terminals, while `squareLeft`/`squareRight` denote ceiling terminals. This mapping is explicit in `TCSPhase2.lean`.

Phase 2 is based on the verified Phase 1 Git commit `5ece996e51591e3f2e62bb8d937ef95d8dea02e6`. `TCSPhase1.lean` was not modified. The existing Lean 4.24.0 toolchain and Mathlib v4.24.0 tag were reused. Only `lakefile.lean` was extended with two more Lean libraries.

## Scope

**Unconditional and machine verified:** Specialized CFG derivation exactly matching the displayed rules, its start rule and finite enumeration semantics, finite target language, witness generated by E_n, uniqueness of the no-ceiling-bracket word, free-word homomorphism into the concrete two-element zero monoid, type-one singleton, and type-zero punctured target.

**Conditional and machine verified:** Characteristic-sample exponential lower bound for the concrete grammar language, assuming the *same operator* has a characteristic sample for L_n^- (and taking S characteristic for L_n); the bridge from CE(L_n) to fixed-h substitutability of L_n^-.

**Not yet verified:** CE(L_n) itself (Appendix C), concrete characteristic-sample existence for Rec_h, Theorem 4.2 soundness, the full class membership of L_n^- in the paper's fixed-typing CFG learning class, and Corollary 6.4.

No TCS submission manuscript, metadata, translations, reviewer reply, or PDF was modified.
