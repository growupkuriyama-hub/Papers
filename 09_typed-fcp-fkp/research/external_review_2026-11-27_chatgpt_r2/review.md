### 2.1 捕獲と一語削除（814–849）

左商を D_T={y:yT∈L'} と書けば (4.1) は D_T\D_{T°}={R}。z=p x q_0 T、R=p x q_0 とする。SPP の到達枠から pK_B q_0 T⊆L'。一方 p x q_0 T°∉L' であり、x∈K_B^{▷◁} なので (p,q_0T°) は K_B の共通枠ではない。したがって e∈K_B で peq_0T°∉L' のものがあり、peq_0∈D_T\D_{T°}。よって peq_0=pxq_0、自由モノイドの左右消去で e=x。空語の場合も同じ。これは核のサイズに対する「任意の有限 CFG」レベルの真正な制約である。

補題4.5は T≠T° で RT≠RT°、削除後も RT が残る。任意の yT∈L' から yT°∈L、削除後に失敗することは yT°=RT° と同値。右消去で y=R。逆向きも成立。M_n において最右 E_1 は [aa]、その後は n−1 個の ]。T° の長さは n+3、|w*_n|=3·2^n−2 より |R|=3·2^n−n−5。任意の yT∈L_n で {a} が E_1 の完全な部分木であることは一意な整形式括弧構造から従う。置換後も同じ深さの E_1 である。計算結果は独立実装 n=2,3,4 および著者検査と一致。n=2 で R=5>0。

### 2.2 一般の核下界（851–888）と数値伝播

有限性は到達可能な繰返し非終端記号から長さ増大のポンピングを禁じるために使われる。導出木のノード数最小化は、長さの増えないサイクル（αβ=ε）を除くために別途必要。祖先・子孫が同じ A であれば、周囲の部分木の terminal yield を固定して A⇒*αAβ⇒*αyβ を反復できるので、αβ≠ε なら異なる長さが無限に出る。εの場合は同じ A の子孫部分木に置換して木が真に縮む。型はラベルの一部で固定されるので問題なし。

R,T がともに非空なら境界の左右2位置を含むノードは一本の祖先鎖をなし、最低共通祖先まで続く。任意の R の位置を含む最深鎖ノードでは、その位置は RHS の終端か、非鎖の子の yield にある。後者が T にも及べば鎖ノードとなり矛盾。空 yield の子は被覆に不要。各鎖ノードの RHS 各位置に高々一つの区間を割当てれば、ρ|N| 個以下、各長さ≤max(κ,1)。capture によって非終端の区間の実際の yield が核に入る。無反復により鎖ノードの規則も互いに異なり、全 RHS 長 q によるより強い |R|≤q max(κ,1) が得られる。型付き→型なしは Lemma 3 の kernel reduction（656–676）で同一 CFG・同一核を維持。型数による余分な因子はない。これは本論文の特に良い点。

**GAP:** 865–866 は R=ε または T=ε を排除していない。R=ε は結論自明。T=ε、R≠ε では根そのものが R に収まり、補題4.4で R∈K_S。よって κ≥|R|、ρ≥1、|N|≥1。反例でなく証明の欠落。実際 L={a,ab}, w=ab, R=a, T=ε,T°=b は補題4.5を満たす。定理6.9の全長もこの場合は核寄与だけで Λ≥|R|+1≥2√|R|。非退化の場合は q>0、Λ≥q+max(κ,1)。κ>0なら核寄与、κ=0なら少なくとも1規則の +1 を利用できる（1469–1477）。これで一般形を完全に証明できる。

数値の伝播: 4.7/4.8(iii)、A(ii)、C(ii)、6.8(b,d) は整合。5.2 は ρ≤2、|N|≤||K||²/2、κ≤||K|| なので ||K||³≥R。5.4 は m 個の部分語から空でない高々 k の部分集合が m^k 以下（順序を固定して最後の元を繰返す単射）、型付きでも核は一意の型を持つため余分な型数は不要。ρ≤(2r+1)||D||、κ≤||D|| で指数 1/(2k+2)。固定 r,k 以外では定数指数を主張していない。表1120–1135も一致。F_n の RHS 和は 3(n−1)2^n+7n−3、H_n の 6n−4 規則も再計数可能。核上界 H_n の 8n max(3·2^{n−1}−2,2n+1) と下界の比は O(n) で正しい。

### 2.3 イデアル制限（1389–1436）：具体的な偽命題

forces の定義 ŝ(u) S^sharp ŝ(v)⊆I は、すべての x∈Σ* で ŝ(uxv)∈I と同値（ŝ は fresh identity への全射）。非可換でも成立。初期の許可型 μ∈I では任意の外枠が I に留まるのは両側イデアル性から正しい。非初期の枠は相対言語 L→L' で denotation が不変。空の枠集合も問題ない。

しかし 1398–1402 の G' は G^s の初期集合だけを取り替え、旧初期記号の I 外コピーを N から除いていない。1417,1420 の (i) or (ii) はそのコピーの左辺に適用できない。以下は全仮定を満たす反例。

- Σ={a,b}、L={a,b}、G の唯一の初期 S、規則 S→a|b、C_S={(ε,ε)}。強い1-FCP。初期は RHS に現れず、非初期の条件は空虚に成立。
- s=h_{b}、I={ζ}、L'={b}。G^s の (S,1)→a は残存し初期ではない。
- L' 相対の C_S^{◁'}∩F_1=∅、しかし L(G',(S,1))={a}。よってその規則で pre-fixed point 条件が破れ、strong どころか very weak SPP でもない。

**修正:** G' の定義で旧初期 S の μ∉I のコピーとその LHS 規則を削除する（RHS に旧初期がないため他の規則に影響なし）。残存ノード A は非初期か許可初期型なので (i),(ii) の網羅性が回復し、証明通り。さらに trim してもよい。max RHS 長は削除で低下し得るため「the same ρ」を「right-hand sides of length at most ρ」に変更（1404,1500）。修正は定理6.9の存在結論には影響しない。6.8 の H_n は明示構成によりもともと正しい。反例は independent.py で確認済み。

注意6.7 は E_n を初期に指定する際、定義の G_n (689) の S_0→E_n を除くことを明記する。そうでなければ E_n が非初期か RHS に出るため仮定が破れる。正しく選んだ G_n において、i≤n−2 では n−i≥2 個の { が枠にある。E_{n−1} は ([,u_{n−1}]) の枠に n−1≥2 個あり、左の開き括弧で二分岐、右の完全な高さ n−1 の部分木を固定するので fill は E_{n−1} そのもの。枠長=2n+1。飽和加法で #_{「{」}≥2 は両側イデアル。n=2 ではこの特定枠は force しないため n≥3 は適切。二標識の場合を核下界に使っていない点も適切。

### 2.4 定理6.9（1493–1511）

修正6.6の仮定により L∩ŝ^{-1}(I)=L\{w}。補題4.5の左商包含から (4.1)、有限性から4.6、全長は q の証明で導出。s は上界を与える固定観測器、下界側は任意の型付けであり両者の量化は衝突しない。なお 6.9 自体は指数差を無条件で言う定理ではなく、パラメータ上界と |R| の大小を結ぶ条件付き定量定理。型付け後の規則総数は rank に依存するため一般に全長多項式上界を与えていない。固定 semigroup、固定 rank、元の全長 poly(n) と |R| exp(n) なら初めて全長分離が従う。このコロラリを明示すると意義が強くなる。

### 2.5 印付きノードと混合（1520–1559）

補題6.10: x=u v_j v、x'=u w*_j v（u,v は局所部分語）。型付きでは ŝ(v_j)=ŝ(w*_j) とモノイド準同型性で ŝ(x)=ŝ(x')。SPP の到達枠は x' を許せず、型は同じなので拒否理由は少なくとも一つの指定枠 c にある。c[x]∈M_n で v_j の occurrence はノード（括弧の first-return と高さから）。置換は L_n 内、拒否されたなら唯一の除外語 w*_n。したがって |c|=|w*_n|−|x'|=|z_π|−|x|=|p|+|q|。単に不等式でなくこの等式が核心。印の有無を見る observer なら型が拒否理由になり、同じ論証はできない。空枠集合の場合でも x' が同型で SPP に入る矛盾から、該当ノードに必ず非空の枠集合がある。n=2,3,4 で任意の印包含区間について拒否枠を調べた。型付きの部分は準同型の証明であり計算だけから結論していない。

補題6.11: P_π 内の未閉 [ は n−j 個、Q_π' 内の対応しない ] も n−j 個。中央 v_j は完全に balanced、左右 sibling も balanced なので、未閉 [ と ] のマッチングは外から内へ強制される。各 ancestor の内側の主子と、π_k=r なら左 sibling、π'_k=l なら右 sibling が存在する。二分岐規則の子数は2なので、二つの条件のうちちょうど一方が真、よって π_k=π'_k。向きの逆転やレベルのずれなし。逆は定義。独立スタック認識器で n=2..6 全 j、全パス対を検査。混合は二分岐構造に依存するが、§4 の別の言語族では長さのみで実現できる。

### 2.6 定理6.12（1561–1610）

(a) 最低ノード: v_j は長さ≥3。根はその全区間を含み、子は順序付き非交差 yield 区間なので全区間を含む子は高々一つ。有限木を下降して最低非終端に到達。ε 子は正長区間を含み得ない。最低性からどの子も v_j 全体を含まない。最初の { を含む RHS 位置 e は一意で、終端なら d=1、非終端ならその yield の終点が v_j の最後より手前。したがって 1≤d≤|v_j|−1、|v_j|=3·2^{j−1}。これを1574–1582で明示すると盤石。

(b) q_π: node の右端は v_j の末尾以降だから q_π は Q_π の接尾辞、Q_π は w*_n の接尾辞。|q_π|≤ℓ は6.10。従って |q_π|=|q_π'| なら文字列自体が等しい（q=εも可）。

(c) 混合: 同じ規則 A→σ_1…σ_r の e までを π の木から、e+1 以降を π' の木から採る。終端位置は同じ文字、非終端は同じラベル、型付きならそのラベルの τ は固定。異なる子の選択に相互依存する条件は CFG には存在しない。従って正しい導出木。両木の全 yield を e の終点で分割すると P_π v_j[:d] と v_j[d:]Q_π、同様に π'。π の外側接尾辞 q を残すが等長=同一なので、右側全体が v_j[d:]Q_π' に一致。結果は P_π v_j Q_π'。6.11 により π=π'。すべての導出木の選択で成立。

(d) 計数: (production,e) の選択は RHS の実際の各位置を数えて Σ|α|。空規則は印を含めず寄与0。d の候補は |v_j|−1=3·2^{j−1}−1、|q| は整数 0..ℓ。よって式(6.12)の不等式は正しい。特定文法の非終端数・型数を余分に掛ける必要はない。

(e) 全長: ℓ は実際の最大枠長と選ぶ。任意の上界 ℓ で最初の積不等式は成立するが、Λ≥Σ|α|+ℓ+1 は実際の最大値に限る。非空の C_A があるなら最長枠の |u|+|v|+1 を加える（枠自体が (ε,ε) でも +1）。全 C_A が空なら ℓ=0 と定義され、少なくとも一規則があるため規則の LHS の +1 が補う。そもそも印を含むノードは拒否枠を要するので後者はこの設定では実現しないが、計数は正しい。j=1 では積≥2^{n−2}、AM–GM で Λ≥2^{n/2}。証明上重大な欠陥は発見しない。

(f) 偶奇: |v_1|=3,|w*_1|=4 は異なり、|v_2|=6,|w*_2|=10 は同じ。j=2 を用いるのは n≥3。5(ℓ+1)Σ|α|≥2^{n−2}、Λ≥2^{n/2}/√5。n=2 では Λ≥1 で同じ数値が自明。F_n の O(n²) 近似最適性は **最大枠長が2n以下という制限下** のみ。無制限の f(n) に対しては指数のギャップが残る。固定 j の衝突一つで指数下界が出ることを明示する。「mark at the bottom を見る」は必要条件であって十分条件ではない。

### 2.7 実験の監査

既存3本は対象コミットの blob SHA を照合して default 引数で python3 -I を実行。すべて終了コード0。check_general_capture.py は n≤4 で左右商・全区間の置換を確認するが任意 CFG の鎖や T=ε の場合を検査しない。check_ideal_restriction.py は許可された初期型だけをチェックしており、まさに除外型の旧初期コピーを検査しない。これは命題6.6のバグがすり抜けた直接の理由。さらに force 判定 typ(p+q)∈I はこの可換吸収型の例には十分だが任意非可換 semigroup では全 μ に対する p μ q∈I の検査が必要。check_frame_total_length.py は混合、長さ、型衝突、具体的 F_n との整合性を確認するが、全 CFG の最低ノード・混合操作・最小全長を実験的に証明するものではない。独立実装は有限言語全探索・スタック認識・拒否枠の検査を行い、既存検査を import していない。全称命題は上の数学的論証に依拠する。
