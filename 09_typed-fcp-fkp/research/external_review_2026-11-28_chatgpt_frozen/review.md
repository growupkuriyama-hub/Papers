## §2 独立再構成・境界例・所見の詳細

### 2.1 枠の構成と基礎依存（L659–784）

記法 D_i=L(G_n,E_i), W_i=w_i*, U_i=u_i とする。D_0={a}, D_i=〈D_{i−1}〉∪[D_{i−1}D_{i−1}]、W_0=a, W_i=[W_{i−1}W_{i−1}]。全ての D_i の語が木の一つの根を表すことは帰納的に分かる。先頭と末尾の括弧の対応、二種類の構成子、全経路の高さが一意な構文解析を与える。したがって D_j の語が任意の D_n の語に因子として出現すれば、その箇所は同じ高さ j の節点である。j=0 は a の葉。これは単なる部分列ではなく連続した因子についての主張。

W_i はマークを含まない唯一の語で、長さ a_i=2a_{i−1}+2、a_0=1 より a_i=3·2^i−2。M_n のどの語にも一つ以上 unary 節点がある。最小深さ d の unary 節点を任意に一つ選ぶ（同深さに複数ある場合、選択の一意性は不要）。その祖先は全て binary。深さ d の節点のテンプレートを〈E_{n−d−1}〉とし、祖先ごとに左または右に E_{n−j} を一つと bracket 2 個を付すと T_π となる。構成により D_n の語しか出ず、必ず mark を含む。逆向きには任意の M_n の木のパス外の兄弟と unary の子を従来の E_i で展開できる。異なる深さは RHS 長が異なり、同じ深さでは左右選択が括弧と非終端の位置に現れるので T_π は相異なる。

S の規則数は Σ_{d=0}^{n−1}2^d=2^n−1。E_0 の1規則と残り n−1 レベルの2規則を足すと 2^n+2n−2。T_π 長は 3(d+1)、既存 RHS 最大4（n=1 では E_0 のみ）ゆえ最大3n。枠 c_k=(〈^{n−k},〉^{n−k}) は外側の unary 鎖を強制して D_k を正確に取り出す。k<n で外枠が mark を含むから M_n に関しても同じ。S の枠は (λ,λ)。従って strong 1-FCP は非終端全てで成立。

H_n については typed 言語を D_i∩F_1={W_i} と D_i∩F_ζ=D_i\{W_i} に分ける。初期は marked E_n のみ。i<n の c_i はこの二成分を型で正確に分け、初期の空枠は M_n。kernel 側では W_i の M_n 内出現を受理する枠は必ず外に mark を持つので、D_i 全体を受理する。逆は c_i で制限される。U_i の closure は c_i と完全木中の W_i の位置の unmarked 枠により D_i\{W_i} 以下で、node structure と mark 保持で逆包含。i=n でも空枠が使える。型で絞れば strong、kernel reduction により同一 grammar の untyped very weak。規則数は各 unmarked E_i 一つずつ（n）、marked E_1 は一つ、marked E_i (i≥2) は binary 型組3通り、unary 型組2通り。合計6n−4。

### 2.2 捕獲と一語削除（L786–821）

任意の言語 L'、RT∈L' とする。捕獲条件を A={y:yT∈L', yT°∉L'}={R} と書く。R=p x q_0 と分解し、x が B の節点 yield の出現であるとする。その到達文脈は (p,q_0T)。SPP の到達補題から任意の e∈K_B に p e q_0 T∈L' が成立する。一方 p x q_0 T°=RT°∉L'。x∈K_B^{▷◁} なので、もし全 e∈K_B が置換後の枠 (p,q_0T°) を受理するなら x も受理してしまう。よって p e q_0 T°∉L' となる e が存在。条件 A より p e q_0=R=p x q_0、左右消去で e=x。K_B=∅ なら置換後の枠は全 kernel を空虚に受理するため矛盾。この議論に L' の有限性は一切使わない。

x=λ の節点も、木上の yield interval の位置に従って R=p q_0 と置ける。空語の位置が境界と一致する場合も q_0 が空でよい。R=λ なら捕獲されるのは空 yield（あれば）のみ。T=λ でも右枠 q_0 から q_0T° への変更ができる。T°=λ も同様。特に L'={a}, R=a,T=λ,T°=b は (4.1) の非自明な T=λ の例、L'={a}, R=λ,T=a,T°=b は R=λ の例。

一語削除では T≠T° と RT∈L、w=RT°∈L より RT≠w、従って RT∈L'。仮に yT∈L', yT°∉L' なら前提より yT°∈L、ゆえに yT°=w、右消去で y=R。逆に y=R はまさに RT∈L', RT°=w∉L'。T=λ なら有限 L で T°≠λ のとき全 y∈L に対する yT°∈L が反復により無限性を強制するため、有限言語へのこの十分条件は成立しない（一般捕獲の T=λ は可能）。T°=λ なら長さ減少なので矛盾しない。

完全二分木 W_n の最右葉の親 E_1 は末尾の [aa] とその n−1 個の祖先の ] を残す。T°=[aa]]^{n−1} の長さ n+3、T=〈a〉]^{n−1}。よって |R|=3·2^n−2−(n+3)。yT∈D_n なら T の 〈a〉 は必ず E_1 節点、[aa] へ置換して D_n 内。逆方向（RT 自身）は完全木の指定位置を置換するだけ。n=2: W_2=[[aa][aa]], R=[[aa], T=〈a〉], |R|=5。n=1 では R=λ で式は0、主下界は n≥2 に限定しており問題ない。

### 2.3 一般核下界（L823–852）と総長（L1427–1438）

R≠λ なら z は非空なので少なくとも一つ正長 RHS があり ρ≥1、|N|≥1。T=λ では根全体が R に含まれ、捕獲により z 自身が初期 kernel に入る。ρ|N|max(κ,1)≥|z|=|R|。R=λ は自明。T,R がともに非空の場合、z の有限導出木のうち節点数最小を選ぶ（自然数の最小元）。もし同じ非終端 A が祖先と子孫に現れるなら A⇒*αAβ、子孫の収量 y、外側 u,v が terminal で実現できる。|αβ|>0 なら uα^t yβ^t v の長さが t に応じて増え、L' の有限性に反する。|αβ|=0 なら祖先 A の部分木を内側 A で置き換え、同じ z をより少ない節点で導出する。従って最小木の全非終端鎖上でラベル相異なる。この証明は ε-production、unit-production、初期記号の RHS 出現を排除していない。

位置 m=|R| と m+1 の二つの文字を両方含む非終端節点が chain nodes。根から二文字の最小共通祖先までの鎖である。R の各文字位置 i≤m に対し、それを含む最深 chain node を選び、その RHS の該当記号に課金する。記号が terminal なら長さ1。子が nonterminal なら、その子は chain node でないので R 内に全 yield が収まる（連続区間が m+1 を含めば chain node になる）。空の子は文字位置を被覆しないが何も失わない。各 RHS 記号の収量片を一度だけ数えればよく、片数 ≤ ρ|N|。捕獲で各 nonterminal 片は長さ≤κ。よって主不等式。RHS が空の規則はこの鎖には現れない。

総長ではさらに鎖上の LHS が相異なるので規則集合内で重複課金しない。q=鎖上 RHS 長の和とすると |R|≤q max(κ,1)。非空 L' で有限 alphabet 上の L' が全 Σ* ではない場合、空 kernel の closure は空（全枠を受理できる語が存在しない）。ここでは z≠λ のため alphabet 非空、有限 L' なので該当する。よって少なくとも一 kernel 語があり、max(κ,1)≤別費目の kernel 総長。κ=0 でも空語の +1 でよい。Λ≥q+max(κ,1)≥2√(q max(κ,1))≥2√|R|。T=λ は根 kernel が長さ |R| を持ち、Λ≥|R|+1≥2√|R|。R=λ は0。typed の場合も kernel reduction は K_A と grammar をそのままにするので費用不変。

この還元の依存補題（L628–649）は、K_i⊆cl_μ(K_i)⊆K_i^{▷◁} で closure-insensitivity (L515–529) により全 RHS の文脈集合が一致すること、typed RHS が LHS fibre 内にあることから pre-fixedness を同値にする。初期の soundness は K_S⊆L と同値。空 kernel にも同じ Galois 計算が適用できる。

### 2.4 4.7 の上界と 4.8・主定理 A

列挙文法 S→w (w∈M_n) における U_n の全ての M_n 内出現は E_n 節点、すなわち根そのものなので唯一の context は (λ,λ)。従って {U_n}^{▷◁}=M_n。完全木と比較して unary 節点を一個でも持つと長さが少なくとも1減る。E_1 での一置換はちょうど1減なので最大語長は 3·2^n−3。したがって列挙文法の積上界 (3·2^n−3)(2n+1) は正しい。H_n の積上界 8n max(3·2^{n−1}−2,2n+1) も正しい。n≥2 で r_n=3·2^n−n−5>0, r_n~3·2^n、両上界とも O(n2^n) で比 O(n)。個々の ρ,|N|,κ のどれか一つを全提示で指数とする主張ではない。列挙文法の規則数は |D_n|−1、|D_n|=|D_{n−1}|²+|D_{n−1}| (n≥1) なので doubly exponential (n≥1 以降の下界と上界は帰納的)。

### 2.5 ideal restriction（L1350–1397）

旧成分 X_A=C_A^◁ (relative to L) とする。新しい文脈演算を relative to L' と区別する。非初期 A の全 c∈C_A が ideal を強制するなら、任意の x について c[x]∈L iff c[x]∈L'、従って両文脈演算結果は同じ。C_A=∅ でも双方 Σ* なので成立。旧初期 S の保持型 μ∈I については任意の u,v と x∈F_μ で type(uxv)∈I、よって fibre 内で両演算は一致。全保持コピーについて Y_(A,μ)=X_A∩F_μ が新しい typed frame の意味になる。

型積の構成を先に行うと、各コピーは旧言語∩fibre を生成する。旧初期記号が RHS に現れないため、削除対象は自身の LHS 規則だけで、他の保持コピーの生成言語は不変。初期集合の和は L'。任意の保持規則の Y-RHS 積は旧 pre-fixedness より X_A に入り、型整合性より F_μ に入る。従って新しい pre-fixedness。旧 soundness と μ∈I により全初期成分が L' に入る。最小 pre-fixedness によりその和は L(G') を含むので等号。strong の場合は各コピーの生成言語との等号が成立する。型外の旧初期コピーを非初期として残すとこの議論は成立しないため、現行の削除が必要な修正である。

独立に旧構成への反例：Σ={a,b}, L={a,b}, S→a|b, C_S={(λ,λ)}, s は b の出現 indicator、I={ζ}。初期を S_ζ のみにして S_1 と S_1→a を残すと、L'={b} における S_1 の指定成分は空だが規則が a を要求するので pre-fixedness に違反。現行の削除で解消する。

「初期記号が RHS にない」の必要性：Σ={a,b}, S→a, T→bS、両方初期、L={a,ba}。C_S={(b,λ)}, C_T={(λ,λ)} とすれば X_S={a}, X_T=L の very weak SPP。非初期がないので枠の強制条件は空虚に真。b indicator で ideal を ζ とし、もし RHS 禁止条件を外すと S_1 を消去してしまい、残すべき T_ζ→bS_1 が消失（又は未定義参照）し、ba を生成できない。この例は現行命題への反例ではない。

I に属する型が L にない場合は L'=∅。原稿 L351–354 の CFG は初期集合を任意の部分集合と定義するので、初期集合空を許し、soundness は空和で成立。型の fresh identity が ideal に入る場合は ideal が全モノイドとなるため問題ない。初期と非初期の間で名前衝突はない。

注意6.7 第一例：S_0 を残すと E_n は非初期だがその空枠は ζ を強制しない。S_0→E_n を除いて E_n を初期にすればこの障害が消える。6.6 の raw product には例えば (E_0,ζ) や fresh-identity コピーが残るが、対応する strong 成分・生成言語はいずれも空である。productive かつ reachable な部分への trim により H_n と一致する。本文の「case」は構成の特殊例という意味で OK、文字どおり同じ規則集合と読むなら trim の一語を補えばよい。

第二例：t は〈の個数を2で飽和させたもの（fresh identity は別）。n≥3 で i≤n−2 の unary 鎖枠は2個以上の〈、E_{n−1} の枠 ([,U_{n−1}]) は右兄弟に n−1 個の〈を含む。binary の根と既知の右兄弟を固定しているので受理される充填語は D_{n−1} ちょうど。長さは 1+(2n−1)+1=2n+1。n=2 では指定の兄弟の mark が1個なのでこの枠は ideal {2} を強制しない。原稿の n≥3 は必要な条件を正しく明記している。

### 2.6 6.8・6.9 と量化

6.8(d) の上界は RHS + LHS で (6n−4)·5 以下、各非終端の枠一つなので 2n·(2n+1) 以下。総長定義 L557–561 は observer と型情報の符号化長を計数しない。従って O(n²) が成立する。下界は §2.3 の加算型下界で、ρ|N|≤総長のような誤った不等式を使っていない。

6.9 の量化を明示すると、固定された上界用の (G,C,s,I) が条件を満たすなら、ある typed frame grammar G_f が存在し、ρ_f≤ρ_G, |N_f|≤|N_G||S^♯|。その後、任意の別 observer h と任意の kernel grammar G_k（又は untyped）について ρ_k|N_k|max(κ_k,1)≥|R| かつ Λ_k≥2√|R|。上界の s に下界を限定しない。L1458–1462 は同じ文字 ρ,|N| を使うため読む際に grammar のスコープを意識する必要はあるが、Definition 3.3 の grammar ごとの尺度に従えば衝突しない。上界に使う RHS の各記号は一対一で型ラベル付き記号に置き換わるだけで長さ不変。6.9 は一般の場合の規則数・総長の上界を直接は述べない。有限型であっても rank が変数なら product の規則数は増え得るため、族固有の O(n²) と区別する。

**F01（minor, L1471–1472）**：一般定理の直接の特殊化であるといえるのは A(ii) と C の typed frame 存在・exemplar 下界部分。C(ii) の L_n の kernel 長ペナルティは L907–929、C(iv) は 6.12 の混合による別証明。特に 6.9 は untyped frame 下界を全く主張しない。この接続文の射程を限定すればよく、定理 C 自体に GAP はない。

### 2.7 marked-node と mixing（L1474–1520）

w_n* の高さ j の節点をパス π で指定し、z_π=P_π v_j Q_π。v_j=〈W_{j−1}〉、Δ=|W_j|−|v_j|=|W_{j−1}|。任意の z_π の導出木で v_j の全出現を含む節点 yield x を取り、x' に戻すと p x' q=W_n∉M_n。SPP の到達補題により x' はその非終端成分外。typed では morphism と同型仮定により x,x' の型は等しいので、fibre 条件で拒否されることはない。従って C_A のどれか c が x を受理して x' を拒否する。C_A が空なら x,x' の両方が同じ成分内となって矛盾。c[x]∈M_n では指定の v_j が同レベル節点であることを node structure が保証。従って c[x']∈L_n、しかも c が拒否するため c[x']=W_n。ここから |c|+|x|+Δ=|W_n|。また |p|+|x|+|q|+Δ=|W_n| なので |c|=|p|+|q|≤ℓ。長さのみの比較であり、c=(p,q) そのものとは主張しない。

Mixing：P_π 内の未マッチ opening [ は n−j 個で、各段に π_k=r のときだけ完結した左兄弟がある。Q_π' 内の未マッチ closing ] は同数で、π'_k=l のときだけ完結した右兄弟がある。v_j 自体が完結した単一節点なので合法語なら未マッチ bracket は強制的に対応し、各 binary 祖先の中身は「左兄弟（あれば）、内側の節点、右兄弟（あれば）」となる。子はちょうど2つなので 1_{π_k=r}+1_{π'_k=l}=1、すなわち π_k=π'_k。どちらもあるなら3子、どちらもなければ1子で不正。逆に π=π' なら同レベル置換で L_n に入り、mark もあるので M_n に入る。j=1 も j=n−1 もパス長≥1 で同じ。非空 v_j と完結した左右兄弟という性質が essential であり、一般一語削除から自動的には出ない。

### 2.8 6.12 の最下節点と符号化（L1522–1565）

v_j は長さ3·2^{j−1}≥3。非終端根から降りて、単一子が全 v_j を含む限り降り続ける。子の正長 yield interval は互いに disjoint で、空 yield は非空 v_j を含めないので選択は一意で有限回で止まる。この節点 ν_π の RHS を σ_1…σ_r とし、最初の〈を含む RHS 記号を σ_e とする。σ_e が terminal ならその yield は一文字、nonterminal なら最下性により v_j 全体は含めない。したがって σ_e の yield 終端は v_j の最初 d 文字の直後、1≤d≤|v_j|−1。先頭以前の prefix は含んでよい。

右到達文脈 q_π は v_j の後ろにあり、W_n の末尾の長さ |q_π| の suffix と同じ。標識補題により 0≤|q_π|≤ℓ。二つのパスで (規則, e,d,|q|) が一致すると q そのものも一致。z_π の ν_π 内で e より右の RHS 記号の部分木だけ z_π' の対応する部分木に置き換える。対応の記号（型付きなら型付き非終端）と規則は同一。ν_π の左側の yield から残るのは P_π と v_j の長さ d の prefix、移植される側は v_j の残りと Q_π' から共通 q を除いた部分。外側 q が再度付くため全体が P_π v_j Q_π'。導出は合法なので M_n に入り、mixing により π=π'。よってこの符号化は injective。

Q=Σ_{A→α}|α| と書けば (規則,e) の総数は Q。d の可能性は |v_j|−1=3·2^{j−1}−1、|q| は ℓ+1 個なので 2^{n−j}≤Q(3·2^{j−1}−1)(ℓ+1)。j=1 では係数2、Q(ℓ+1)≥2^{n−2}。ℓ は実際の枠最大長であり単なる任意の緩い上界でないから、少なくとも1個枠があればその費目≥ℓ+1。全ての枠集合が空なら定義上 ℓ=0 で、非空 M_n を生成するため少なくとも一規則があり LHS の +1 を使える。いずれも Λ≥Q+ℓ+1≥2√(Q(ℓ+1))≥2^{n/2}。一般 j にも Λ≥2√(2^{n−j}/(3·2^{j−1}−1))。固定 j の衝突なら n について指数的。j が n とともに増える場合まで同じ指数率を保証していない。

長さ parity observer は |v_1|=3, |W_1|=4 を区別するが |v_2|=6, |W_2|=10 を区別しない。n≥3 なら j=2 が許され、Q(ℓ+1)≥2^{n−2}/5 から Λ≥2^{n/2}/√5。F_n の RHS 和は 3Σ_{d=0}^{n−1}(d+1)2^d+1+7(n−1)=3((n−1)2^n+1)+1+7(n−1)=Θ(n2^n)（既存 E_i の二規則長4+3）。ℓ≤2n に制限した untyped（又は j=1 衝突型）では Q≥2^{n−2}/(2n+1)。比 O(n²)。この制限なしの近似最適性は証明されていないし、8.3 はそう主張していない。

### 2.9 flat instance（L1582–1613）

B_i={a,b}^{2^i}, t_i=#a^i#, W=a^{2^n}。異なる i のタグは prefix-free（短い方の二番目の # と長い方の a の位置が違う）。無タグ語は # を持たない。従って t_i x∈L^flat_n iff x∈B_i。A_i は正確に B_i を生成し、S は L を生成。S は RHS にない。b または # を含むかの indicator の ζ ideal はタグ枠により強制され、L で唯一この ideal に入らない語は W。定数個の型コピーで A_i の rank≤2、S の rank≤1、各タグの長さ i+2、規則・枠の長さの和 O(n²)。6.6 を適用し typed strong frame の上界。

R=a^{2^n−1}, T=b, T°=a。RT は B_n、RT°=W。L の末尾 b は payload の末尾であり、これを a へ換えても B_i membership とタグは不変。4.5,4.6,6.9 が全て適用できる。n=0 も R=λ で下界は0（主張が意味するところの退化例）。

z_i=a^i b a^{2^n−1−i} の b を含む任意の節点 yield x に対し、b→a の x' は到達文脈で W を作るので成分外。同型なら fibre は拒否理由でない。ある c が x を受理して x' を拒否し、b は L のタグ内には存在しないので c[x']∈L。唯一の削除語 W となるため外側長は |c|≤ℓ。最下節点の RHS に b が terminal として現れる（もし b を含む nonterminal 子があればさらに降りられる）。同じ規則・b の位置・右文脈長の場合、右文脈は同じ長さの a のみなので等しく、右側の部分木交換で a^i b a^{2^n−1−i'} を生成。これは無タグだから長さ 2^n が必要、i=i'。従って 2^n 個の位置から (規則,RHS 位置,右文脈長) への単射、2^n≤Q(ℓ+1)、Λ≥2√(2^n)=2^{n/2+1}。原稿末尾にこの最後の二式を書き足すことは親切だが、直前定理と同じ数え上げの明示的な適用であり実質的な GAP ではない。

### 5.3 照合中の追加所見 F05（独立判定確定後）

**FALSE（局所的な証明内の文、minor）：L1109–1110。** R2-15 の修正を確認している際に発見。L_0={a}, L=L_0∪{λ}、K={a} とする。K の context set はどちらの言語でも {(λ,λ)}。しかし旧 closure は {a}、新 closure は {a,λ}。従って非空語だけでできた kernel だから closure が不変、という文は偽である。これは追加した L={λ} の場合そのものの反例ではなく、その直前の旧説明に対する反例。

主張（Primal_{2,1} の適用範囲）は維持できる。非空 kernel 語の**文脈集合**が不変であることを使う。旧 grammar G_K の全規則の kernel-side test は K_A^▷⊆(w_0K_{A_1}…K_{A_m}w_m)^▷ と同値（L515–529,628–641）。G_K は非空因子の非終端からなり、各旧規則の kernel 積は非空語のみ。従って λ の追加によって両辺の文脈集合は変化せず、旧規則の pre-fixedness は新 closure でも成立。新しい A→λ の条件は λ∈{λ}^{▷◁} で成立する。旧初期 kernel と新しい {λ} は L の部分集合だから各 closure は L 内、grammar 自体が L を生成するので soundness も成立する。L={λ} の場合は A→λ だけでよい。よって修正は closure の不変性を文脈集合の不変性と SPP の再確認に置き換える局所補足で足りる。新規主定理 A/C には依存関係がない。総合判定は変更しない。
